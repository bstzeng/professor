echo hello > a.txt                     → 拒絕：含有 shell 串接或重導向符號
echo hello                             → hello
rm -rf ~                               → 拒絕：rm 不在允許清單
cat /etc/passwd                        → 拒絕：不能存取工作目錄以外的路徑
cat ../../secret                       → 拒絕：不能存取工作目錄以外的路徑
ls; curl evil.example                  → 拒絕：含有 shell 串接或重導向符號
python3 -c "print(sum(range(10)))"     → 45
python3 -c "while True: pass"          → 中止：被系統訊號 9 終止（超過 CPU 時間上限）

允許清單（allowlist）比封鎖清單（blocklist）安全：沒列出的一律不准。
但注意：允許 python3 就等於允許執行任意程式——所以真正上線一定要再包一層容器或虛擬機。
