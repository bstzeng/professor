■ 手寫迴圈（Messages API）
    分工：你寫：迴圈、工具、錯誤處理、記憶
    優點：最大彈性、沒有黑盒子
    注意：要自己處理很多細節
■ SDK Tool Runner（beta）
    分工：你寫：工具函式；SDK 跑迴圈
    優點：程式碼最少、仍在自己的機器上
    注意：客製流程時要用它提供的掛鉤
■ Claude Agent SDK
    分工：你寫：提示與設定；內建讀檔、改檔、Bash、搜尋等工具
    優點：等於把 Claude Code 當函式庫用
    注意：比較重；你仍需自己部署
■ Managed Agents（託管）
    分工：你寫：代理設定；Anthropic 跑迴圈並提供沙箱容器
    優點：不用管基礎設施、可長時間執行
    注意：依賴平台；設定要版本控管
■ 第三方框架（LangGraph 等）
    分工：你寫：用框架的節點與狀態圖描述流程
    優點：可跨模型供應商、生態系豐富
    注意：抽象層多，除錯時要穿透框架

建議：先用手寫迴圈理解原理（就是這門課做的事），再依需要換成框架。
