Problem

Given a binary string s, return the number of non-empty substrings that have the same number of 0's and 1's, and all the 0's and all the 1's in these substrings are grouped consecutively.

Substrings that occur multiple times are counted the number of times they occur.

中文翻譯

給你一個二進位字串 s，計算有多少個非空子字串滿足：0 和 1 的數量相同，而且所有 0 是連在一起的、所有 1 也是連在一起的（例如 "0011"、"10"）。

重複出現的子字串要依出現次數分別計算。

範例

範例 1 輸入：s = "00110011" 輸出：6 範例 2 輸入：s = "10101" 輸出：4

限制條件

  • 1 ≤ s.length ≤ 10⁵
  • s[i] is either '0' or '1'.

LeetCode 原題

解題思路

【合法的子字串長什麼樣？】 一段 0 後面接一段等長的 1（或反過來），而且一定跨越一個「0/1 交界」。 【依段落思考】 s = 00111011 -> 段落長度 [2, 3, 1, 2] 相鄰兩段（長度 a, b）跨越它們之間的交界： 可以取 01、0011、... 最多 min(a, b) 種。 答案 = Σ min(相鄰兩段長度)。 【一趟掃描】 只要記住上一段與目前這一段的長度。
解法

相鄰段落長度

class Solution: def countBinarySubstrings(self, s: str) -> int: res, prev, cur = 0, 0, 1 # prev：上一段連續相同字元的長度；cur：目前這一段 for i in range(1, len(s)): if s[i] == s[i - 1]: cur += 1 else: res += min(prev, cur) # ★ 相鄰兩段可以組成 min(兩段長度) 個合法子字串 prev, cur = cur, 1 return res + min(prev, cur)

驗證方式：和枚舉所有子字串的暴力法比對 3000 組。

複雜度說明
時間O(n)
空間O(1)

邊界條件檢查清單

  • 全部相同 → 0。
  • "10101" → 4。
