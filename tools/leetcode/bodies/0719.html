Problem

The distance of a pair of integers a and b is defined as the absolute difference between a and b.

Given an integer array nums and an integer k, return the kth smallest distance among all the pairs nums[i] and nums[j] where 0 <= i < j < nums.length.

中文翻譯

兩個數 a、b 的距離是 |a − b|。給你整數陣列 nums 和整數 k，回傳所有數對 (nums[i], nums[j])（i < j）的距離中第 k 小的。

範例

範例 1 輸入：nums = [1,3,1], k = 1 輸出：0 範例 2 輸入：nums = [1,1,1], k = 2 輸出：0 範例 3 輸入：nums = [1,6,1], k = 3 輸出：5

限制條件

  • n == nums.length
  • 2 ≤ n ≤ 10⁴
  • 0 ≤ nums[i] ≤ 10⁶
  • 1 ≤ k ≤ n * (n - 1) / 2

LeetCode 原題

解題思路

【數對太多】 n = 10⁴ -> 約 5×10⁷ 個數對，全部列出來排序太慢。 【二分答案】 f(d) = 距離 <= d 的數對個數，隨 d 單調不減。 第 k 小的距離 = 最小的 d 使 f(d) >= k。 d 的範圍 [0, max - min]。 【f(d)：排序 + 雙指標】 對每個右端 r，找最小的 l 使 nums[r] - nums[l] <= d， 那麼 (l, r), (l+1, r), ..., (r-1, r) 都符合 -> r - l 個。 r 往右時 l 只會往右 -> O(n)。 總時間 O(n log n + n log W)。
解法

排序 + 二分答案 + 雙指標計數

class Solution: def smallestDistancePair(self, nums: List[int], k: int) -> int: nums.sort() n = len(nums) def count(d): # 距離 <= d 的數對有幾個（雙指標） c = l = 0 for r in range(n): while nums[r] - nums[l] > d: l += 1 c += r - l # 以 r 為右端、左端在 [l, r) 的數對 return c lo, hi = 0, nums[-1] - nums[0] while lo < hi: # ★ 二分答案：最小的 d 使得「距離 <= d 的數對」>= k mid = (lo + hi) // 2 if count(mid) >= k: hi = mid else: lo = mid + 1 return lo

驗證方式：和列出所有距離排序比對 1500 組。

複雜度說明
時間O(n log n + n log W)W 為最大值與最小值的差
空間O(1)

邊界條件檢查清單

  • 重複值 → 距離 0。
  • k = 1 → 排序後相鄰差的最小值。
