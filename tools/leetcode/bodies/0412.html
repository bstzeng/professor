Problem

Given an integer n, return a string array answer (1-indexed) where:

  • answer[i] == "FizzBuzz" if i is divisible by 3 and 5.
  • answer[i] == "Fizz" if i is divisible by 3.
  • answer[i] == "Buzz" if i is divisible by 5.
  • answer[i] == i (as a string) if none of the above conditions are true.

中文翻譯

給你一個整數 n，回傳字串陣列 answer（從 1 開始）：

  • i 同時是 3 和 5 的倍數 → "FizzBuzz"
  • 只是 3 的倍數 → "Fizz"
  • 只是 5 的倍數 → "Buzz"
  • 都不是 → i 本身（字串）

範例

範例 輸入：n = 15 輸出：["1","2","Fizz","4","Buzz","Fizz","7","8","Fizz","Buzz","11","Fizz","13","14","FizzBuzz"]

限制條件

  • 1 ≤ n ≤ 10⁴

LeetCode 原題

解題思路

【最常見的錯誤：判斷順序】 if i % 3 == 0: "Fizz" elif i % 5 == 0: "Buzz" elif i % 15 == 0: "FizzBuzz" ✘ 永遠到不了（15 已經在第一個條件被抓走） 必須先判斷 15，或用「字串相加」的寫法。 【字串相加】 是 3 的倍數就加 "Fizz"，是 5 的倍數就加 "Buzz"， 兩個都是就自然變成 "FizzBuzz"； 空字串代表都不是 -> 用數字。 這個寫法很容易擴充（例如再加「7 的倍數 -> Bazz」）。
解法

字串相加

class Solution: def fizzBuzz(self, n: int) -> List[str]: res = [] for i in range(1, n + 1): s = "" if i % 3 == 0: s += "Fizz" if i % 5 == 0: s += "Buzz" # ★ 15 的倍數兩個都會加上 -> "FizzBuzz" res.append(s or str(i)) return res
複雜度說明
時間O(n)
空間O(1)不計輸出

邊界條件檢查清單

  • 15 的倍數 → 必須是 "FizzBuzz"，注意判斷順序。
  • n = 1 → ["1"]。
