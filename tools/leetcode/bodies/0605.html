Problem

You have a long flowerbed in which some of the plots are planted, and some are not. However, flowers cannot be planted in adjacent plots.

Given an integer array flowerbed containing 0's and 1's, where 0 means empty and 1 means not empty, and an integer n, return true if n new flowers can be planted in the flowerbed without violating the no-adjacent-flowers rule and false otherwise.

中文翻譯

一排花壇 flowerbed，1 代表已種花、0 代表空地，相鄰的地不能同時種花。給你整數 n，判斷能否再種下 n 朵花而不違反規則。

範例

範例 1 輸入：flowerbed = [1,0,0,0,1], n = 1 輸出：true 範例 2 輸入：flowerbed = [1,0,0,0,1], n = 2 輸出：false

限制條件

  • 1 ≤ flowerbed.length ≤ 2 * 10⁴
  • flowerbed[i] is 0 or 1.
  • There are no two adjacent flowers in flowerbed.
  • 0 ≤ n ≤ flowerbed.length

LeetCode 原題

解題思路

【貪心：能種就種】 由左往右，遇到「自己、左、右都是 0」的位置就種。 為什麼越早種越好？在 i 種花只影響 i+1； 如果不在 i 種而改在 i+1 種，會影響 i+2，只會更差。 【邊界處理】 頭尾各補一個 0，第一格和最後一格就不用特判。
解法

貪心

class Solution: def canPlaceFlowers(self, flowerbed: List[int], n: int) -> bool: bed = [0] + flowerbed + [0] # 頭尾補 0，省去邊界判斷 for i in range(1, len(bed) - 1): if bed[i - 1] == bed[i] == bed[i + 1] == 0: bed[i] = 1 # ★ 貪心：能種就種，越早種越不會浪費空間 n -= 1 return n <= 0

驗證方式：和枚舉所有種法的暴力法比對 1500 組。

複雜度說明
時間O(n)
空間O(n)補 0 的副本；直接在原陣列判斷邊界則 O(1)

邊界條件檢查清單

  • n = 0 → True。
  • 只有一格且是 0 → 可以種 1 朵。

常見追問

直接數連續 0 的長度

一段長度為 k、兩邊都是花的空地可以種 (k−1)//2 朵；靠邊的空地少了一側限制，補 0 後就統一成同一個公式。
