Problem

We define a harmonious array as an array where the difference between its maximum value and its minimum value is exactly 1.

Given an integer array nums, return the length of its longest harmonious subsequence among all its possible subsequences.

中文翻譯

和諧陣列是最大值與最小值的差恰好為 1 的陣列。給你整數陣列 nums，回傳它所有子序列中最長的和諧子序列長度。

範例

範例 1 輸入：nums = [1,3,2,2,5,2,3,7] 輸出：5 範例 2 輸入：nums = [1,2,3,4] 輸出：2 範例 3 輸入：nums = [1,1,1,1] 輸出：0

限制條件

  • 1 ≤ nums.length ≤ 2 * 10⁴
  • -10⁹ ≤ nums[i] ≤ 10⁹

LeetCode 原題

解題思路

【子序列 = 挑一些元素，順序不影響最大最小值】 所以只要決定「挑哪些值」。 【和諧 <=> 只含 x 和 x+1 兩種值（兩種都要有）】 挑了 x 和 x+1 之後，所有等於它們的元素都挑進來最好。 長度 = cnt[x] + cnt[x+1]。 【注意】 x+1 必須存在，否則只有一種值，差是 0 不是 1。
解法

雜湊表計數

class Solution: def findLHS(self, nums: List[int]) -> int: cnt = Counter(nums) # ★ 和諧子序列只能由 x 和 x+1 兩種值組成：把兩者的出現次數加起來 return max((cnt[x] + cnt[x + 1] for x in cnt if x + 1 in cnt), default=0)

驗證方式：和枚舉所有子序列的暴力法比對 2000 組。

複雜度說明
時間O(n)
空間O(n)

邊界條件檢查清單

  • 全部相同 → 0（差是 0）。
  • 沒有相差 1 的值 → 0。
