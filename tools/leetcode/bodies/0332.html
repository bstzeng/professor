Problem

You are given a list of airline tickets where tickets[i] = [fromi, toi] represent the departure and the arrival airports of one flight. Reconstruct the itinerary in order and return it.

All of the tickets belong to a man who departs from "JFK", thus, the itinerary must begin with "JFK". If there are multiple valid itineraries, you should return the itinerary that has the smallest lexical order when read as a single string.

  • For example, the itinerary ["JFK", "LGA"] has a smaller lexical order than ["JFK", "LGB"].

You may assume all tickets form at least one valid itinerary. You must use all the tickets once and only once.

中文翻譯

給你一串機票 tickets，tickets[i] = [fromi, toi] 代表一趟航班的出發與抵達機場。請重建行程。

所有機票都屬於一位從 "JFK" 出發的旅客，所以行程必須從 "JFK" 開始。如果有多種合法行程，回傳字典序最小的那一個。

保證至少有一種合法行程。每張機票都必須恰好使用一次。

範例

範例 1 輸入：tickets = [["MUC","LHR"],["JFK","MUC"],["SFO","SJC"],["LHR","SFO"]] 輸出：["JFK","MUC","LHR","SFO","SJC"] 範例 2 輸入：tickets = [["JFK","SFO"],["JFK","ATL"],["SFO","ATL"],["ATL","JFK"],["ATL","SFO"]] 輸出：["JFK","ATL","JFK","SFO","ATL","SFO"]

限制條件

  • 1 ≤ tickets.length ≤ 300
  • fromi.length == 3，toi.length == 3，都是大寫英文字母
  • fromi != toi

LeetCode 原題

解題思路

【每張機票恰好用一次 = 歐拉路徑】 機場是節點，機票是有向邊。 要找一條從 JFK 出發、每條邊恰好走一次的路徑 —— 歐拉路徑。 【貪心「每次走字典序最小的」會錯】 JFK -> KUL、JFK -> NRT、NRT -> JFK 貪心先走 KUL，結果 KUL 是死路，NRT 那兩張票用不到 ✘ 【Hierholzer 演算法】 DFS，每走一條邊就把它刪掉。 當某個節點「沒有邊可走」時，才把它加入 route。 最後把 route 反轉。 為什麼可以？ 第一個卡住的節點一定是歐拉路徑的終點（死路）。 之後回溯時再從別的節點繞出去的「環」， 會在反轉後被插在正確的位置。 【字典序最小】 每個節點的出邊排序，DFS 時先走小的。 即使先走進死路，死路也會被放到最後， 其他部分仍然是字典序最小的選擇。
解法一

Hierholzer（遞迴）

class Solution: def findItinerary(self, tickets: List[List[str]]) -> List[str]: graph = defaultdict(list) for a, b in sorted(tickets, reverse=True): # 反向排序：pop() 拿到字典序最小的 graph[a].append(b) route = [] def visit(airport: str) -> None: while graph[airport]: visit(graph[airport].pop()) # 每張機票只用一次 route.append(airport) # ★ 無路可走時才加入（後序） visit("JFK") return route[::-1] # 後序的反轉 = 歐拉路徑
複雜度說明
時間O(E log E)排序主導
空間O(E)
解法二

Hierholzer（迭代）

class Solution: def findItinerary(self, tickets: List[List[str]]) -> List[str]: graph = defaultdict(list) for a, b in sorted(tickets, reverse=True): graph[a].append(b) stack, route = ["JFK"], [] while stack: while graph[stack[-1]]: # 一路往下走 stack.append(graph[stack[-1]].pop()) route.append(stack.pop()) # 卡住了：加入路線，退回上一站 return route[::-1]
複雜度說明
時間O(E log E)
空間O(E)

邊界條件檢查清單

  • 重複的機票（同一條航線兩張）→ 兩條平行邊，都要用。
  • 先遇到死路 → 死路會被放到行程最後。
  • 用 list.pop() 取最小 → 所以要反向排序；也可以用堆積。

常見追問

歐拉路徑存在的條件

有向圖：所有節點入度 = 出度（歐拉迴路），或恰好一個節點出度比入度多 1（起點）、一個入度比出度多 1（終點），而且邊都連通。本題保證有解。第 753 題「破解保險箱」和第 2097 題也是 Hierholzer。
