Problem

Given an array of integers nums and an integer k, return the number of unique k-diff pairs in the array.

A k-diff pair is an integer pair (nums[i], nums[j]), where the following are true:

  • 0 <= i, j < nums.length
  • i != j
  • |nums[i] - nums[j]| == k

Notice that |val| denotes the absolute value of val.

中文翻譯

給你整數陣列 nums 和整數 k，回傳不同的 k-diff 數對的數量。

k-diff 數對 (nums[i], nums[j]) 需滿足 i != j 且 |nums[i] − nums[j]| == k。數對以「值」區分：(1, 3) 和 (3, 1) 算同一對。

範例

範例 1 輸入：nums = [3,1,4,1,5], k = 2 輸出：2 範例 2 輸入：nums = [1,2,3,4,5], k = 1 輸出：4 範例 3 輸入：nums = [1,3,1,5,4], k = 0 輸出：1

限制條件

  • 1 ≤ nums.length ≤ 10⁴
  • -10⁷ ≤ nums[i] ≤ 10⁷
  • 0 ≤ k ≤ 10⁷

LeetCode 原題

解題思路

【數對以值區分 -> 先去重計數】 cnt = 每個值的出現次數。 【k > 0】 每一對 (x, x + k) 用較小的 x 代表，只數一次： 答案 = 有多少個不同的 x 使得 x + k 也存在。 【k = 0】 (x, x) 需要兩個不同的索引 -> x 至少出現兩次。 【注意】 k = 0 時若套用 k > 0 的公式，每個值都會和自己配成一對，錯誤。
解法

雜湊表計數

class Solution: def findPairs(self, nums: List[int], k: int) -> int: cnt = Counter(nums) if k == 0: return sum(c >= 2 for c in cnt.values()) # ★ 差為 0：同一個值至少出現兩次 return sum(x + k in cnt for x in cnt) # 以較小的值 x 為代表，避免重複計算
複雜度說明
時間O(n)
空間O(n)

邊界條件檢查清單

  • k = 0 → 只數重複出現的值。
  • 重複值 → [1,1,3], k=2 只算 1 對。

常見追問

排序 + 雙指標

排序後用雙指標找差為 k 的數對，跳過重複值。O(n log n)、O(1) 額外空間。
