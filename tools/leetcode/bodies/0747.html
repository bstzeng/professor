Problem

You are given an integer array nums where the largest integer is unique.

Determine whether the largest element in the array is at least twice as much as every other number in the array. If it is, return the index of the largest element, or return -1 otherwise.

中文翻譯

給你整數陣列 nums，其中最大的數是唯一的。判斷最大的數是否至少是其他每個數的兩倍；是則回傳最大數的索引，否則回傳 -1。

範例

範例 1 輸入：nums = [3,6,1,0] 輸出：1 範例 2 輸入：nums = [1,2,3,4] 輸出：-1

限制條件

  • 2 ≤ nums.length ≤ 50
  • 0 ≤ nums[i] ≤ 100
  • The largest element in nums is unique.

LeetCode 原題

解題思路

【只看第二大】 最大值 >= 2 × 第二大 -> 第二大以下的數更小，自然也成立。 一趟掃描同時記錄最大與第二大即可。
解法

最大值與第二大值

class Solution: def dominantIndex(self, nums: List[int]) -> int: i = max(range(len(nums)), key=nums.__getitem__) # 最大值的位置 # ★ 只要比第二大的兩倍還大，就比所有其他數的兩倍都大 second = max((x for j, x in enumerate(nums) if j != i), default=0) return i if nums[i] >= 2 * second else -1
複雜度說明
時間O(n)
空間O(1)

邊界條件檢查清單

  • 其他數都是 0 → 成立。
  • 剛好兩倍 → 成立（至少）。
