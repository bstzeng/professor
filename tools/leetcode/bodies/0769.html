Problem

You are given an integer array arr of length n that represents a permutation of the integers in the range [0, n - 1].

We split arr into some number of chunks (i.e., partitions), and individually sort each chunk. After concatenating them, the result should equal the sorted array.

Return the largest number of chunks we can make to sort the array.

中文翻譯

給你一個長度為 n 的陣列 arr，它是 [0, n−1] 的一個排列。把它切成若干區塊，各自排序後接起來要等於排序後的陣列。回傳最多能切成幾塊。

範例

範例 1 輸入：arr = [4,3,2,1,0] 輸出：1 範例 2 輸入：arr = [1,0,2,3,4] 輸出：4

限制條件

  • n == arr.length
  • 1 ≤ n ≤ 10
  • 0 ≤ arr[i] < n
  • arr 中的元素互不相同

LeetCode 原題

解題思路

【排列的特性】 前 i+1 個數是 0..i 的排列 <=> 它們排序後恰好放在正確位置 <=> 可以在 i 後面切。 【怎麼判斷前 i+1 個數恰好是 0..i？】 它們是 i+1 個不同的非負整數， 最大值 == i <=> 剛好是 0..i（不可能有更小的缺口）。 一趟掃描維護前綴最大值。
解法

前綴最大值

class Solution: def maxChunksToSorted(self, arr: List[int]) -> int: res = mx = 0 for i, x in enumerate(arr): mx = max(mx, x) if mx == i: # ★ 前 i+1 個數的最大值是 i：它們恰好是 0..i，可以切 res += 1 return res

驗證方式：和枚舉所有切法的暴力法比對 2000 組。

複雜度說明
時間O(n)
空間O(1)

邊界條件檢查清單

  • 已經排序 → n。
  • [1, 0, ...] → 前兩個必須在同一塊。
