Problem

Given the head of a linked list, remove the n-th node from the end of the list and return its head.

Follow up: Could you do this in one pass?

中文翻譯

給你一個鏈結串列的頭節點 head，刪掉倒數第 n 個節點，然後回傳串列的頭節點。

進階：能不能只走一趟就做到？

兩個技巧，這題就是在教這兩個

技巧 1：虛擬頭節點（dummy node） 沒有 dummy 時，「刪掉第一個節點」要特別處理： if 要刪的是 head: return head.next else: ...正常的刪法... 有了 dummy 之後： dummy -> 1 -> 2 -> 3 「刪掉 1」和「刪掉 2」變成完全一樣的操作， 因為 1 也有「前一個節點」了。 這個技巧在所有「可能會刪／改到頭節點」的串列題都適用。 技巧 2：快慢指標製造固定間距 要找「倒數第 n 個」，不必先知道總長度。 讓一個指標先走 n 步，然後兩個一起走 —— 快的到終點時，慢的就在倒數第 n 個。 這是「一趟」的關鍵。

範例

範例 1 輸入：head = [1,2,3,4,5], n = 2 輸出：[1,2,3,5] 說明：倒數第 2 個是 4，把它刪掉。 範例 2 輸入：head = [1], n = 1 輸出：[] 說明：刪掉唯一的節點，變成空串列。 範例 3 輸入：head = [1,2], n = 1 輸出：[1]

限制條件

  • 串列節點數是 sz，1 ≤ sz ≤ 30
  • 0 ≤ Node.val ≤ 100
  • 1 ≤ n ≤ sz（保證 n 不會超出範圍）

LeetCode 原題

先看懂限制在說什麼

  • 保證 1 ≤ n ≤ sz，所以不用處理「n 太大」或「n 是 0」。但你的程式在 n == sz（刪頭）和 n == 1（刪尾）這兩個邊界上都必須正確。
  • 串列至少有一個節點，但刪完之後可能變成空的，所以回傳值要能是 None。
  • 規模只有 30，效率完全不是重點。這題考的是指標操作的乾淨度，以及你知不知道 dummy node 這個技巧。

解題思路

解法一

兩趟：先數長度，再走到位置

最直觀：第一趟數出總長度 L，倒數第 n 個就是正數第 L − n 個（0-indexed）。第二趟走 L − n 步停在它前面。

class Solution: def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]: # 第一趟：算出總長度 length = 0 node = head while node: length += 1 node = node.next # 倒數第 n 個 = 正數第 (length - n) 個（0-indexed） # 我們要停在它「前面」那個節點 dummy = ListNode(0, head) # 虛擬頭節點，讓「刪掉第一個」不用特判 prev = dummy for _ in range(length - n): prev = prev.next prev.next = prev.next.next return dummy.next

為什麼是走 L − n 步而不是 L − n − 1？

L = 5, n = 2，要刪的是值 4（0-indexed 的第 3 個） 從 dummy 出發： 走 0 步 -> dummy 走 1 步 -> 節點 1 走 2 步 -> 節點 2 走 3 步 -> 節點 3 <- 這就是「要刪的那個」的前一個 L - n = 5 - 2 = 3 ✔ 關鍵：因為起點是 dummy（在 head 前面一格）， 走 k 步會停在「第 k 個節點」， 而不是「第 k+1 個節點」。 dummy 幫我們自動處理掉這個 off-by-one。

這個解法完全正確，只是走了兩趟。題目的 follow-up 就是在問：能不能一趟？

複雜度說明
時間O(L)走兩趟，共 2L 步
空間O(1)只有幾個指標
解法二

一趟：快慢指標固定間距（標準解）

核心想法：不需要知道總長度，只需要知道「間距」。讓 fast 先走 n + 1 步，然後兩個一起走。當 fast 走到 None 時，slow 和終點的距離就是 n + 1 —— 也就是說它剛好停在「倒數第 n 個」的前一個。

class Solution: def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]: dummy = ListNode(0, head) fast = slow = dummy # 先讓 fast 走 n + 1 步，製造出「n 的間距」 # （多走 1 步是為了讓 slow 最後停在「要刪的那個」前面） for _ in range(n + 1): fast = fast.next # 兩個一起走，fast 到底時 slow 剛好在正確位置 while fast: fast = fast.next slow = slow.next slow.next = slow.next.next return dummy.next

為什麼是 n + 1 步而不是 n 步？

如果只走 n 步： fast 到 None 時，slow 停在「倒數第 n 個」本身。 但要刪除一個節點，你需要它的「前一個」（單向串列沒辦法往回走）。 多走 1 步，slow 就落後一格，剛好停在前一個。 驗算（L = 5, n = 2）： dummy -> 1 -> 2 -> 3 -> 4 -> 5 -> None ↑ both fast 走 3 步：fast 在節點 3，slow 在 dummy 一起走：fast=4, slow=1 一起走：fast=5, slow=2 一起走：fast=None, slow=3 <- 停 slow.next = slow.next.next -> 3 指向 5，刪掉 4 ✔

n == L（刪頭）為什麼也對？

L = 1, n = 1： dummy -> 1 -> None fast 走 n+1 = 2 步：dummy -> 1 -> None，fast = None while fast: 不執行 slow 還在 dummy slow.next = slow.next.next -> dummy.next = None return dummy.next = None ✔ 空串列 沒有 dummy 的話，這裡 slow 會是 None， slow.next 直接 AttributeError。 這就是 dummy 最大的價值。

「先讓一個指標走 k 步製造間距」是快慢指標的一種。另外兩種常見的是「一步 vs 兩步」（找中點、判斷有沒有環）和「同速但起點不同」（找兩個串列的交點）。三種都要會。

複雜度說明
時間O(L)只走一趟
空間O(1)兩個指標
解法三

遞迴：回傳「倒數第幾個」

遞迴天生就是「從後往前」的 —— 遞迴回來的時候，正好是從尾巴往頭走。利用這一點，讓每一層回報「我是倒數第幾個」。

class Solution: def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]: def helper(node): """回傳 (處理後的子串列, 這個節點是倒數第幾個)""" if node is None: return None, 0 node.next, idx = helper(node.next) idx += 1 # 加上自己 if idx == n: # 自己就是要刪的那個 return node.next, idx return node, idx new_head, _ = helper(head) return new_head

為什麼 node.next, idx = helper(node.next) 這一行同時做兩件事？

它把「子串列處理完的結果」接回來（可能少了一個節點），同時拿到「子串列有幾個節點」。加上自己就是 idx + 1，如果剛好等於 n，就回傳 node.next（跳過自己）。

優點：完全不需要 dummy node —— 「刪掉頭節點」被 return node.next 自然處理掉了。

缺點：O(L) 的遞迴堆疊。L = 30 沒問題，但如果串列有 10⁵ 個節點，Python 預設的遞迴上限（1000）會直接爆掉。

面試時寫這個版本要主動提到堆疊深度的問題 —— 不然會被認為沒想到。

複雜度說明
時間O(L)走一趟（遞迴下去再回來）
空間O(L)遞迴堆疊

邊界條件檢查清單

  • 只有一個節點，刪它：([1], 1) → []。回傳 None。
  • 刪頭：([1,2], 2) → [2]。沒有 dummy 就會在這裡炸掉。
  • 刪尾：([1,2], 1) → [1]。
  • n 等於長度：([1,2,3], 3) → [2,3]。
  • n 等於 1：([1,2,3], 1) → [1,2]。
  • fast 走 n+1 步時可能剛好走到 None：這是合法的（表示要刪頭），不能在迴圈裡加 if fast is None: return 之類的早退。

常見追問

追問一：如果 n 可能超過串列長度呢？

快慢指標版本會在「先走 n+1 步」的迴圈裡對 None 取 .next 而崩潰。要加一個檢查：

for _ in range(n + 1): if fast is None: return head # n 太大，什麼都不刪（或依規格拋錯） fast = fast.next

題目保證了 n 合法，所以不用寫。但面試官很可能追問這個。

追問二：如果是雙向串列呢？

雙向串列可以從尾巴往前走 n 步，直接找到目標，而且刪除只要改兩個指標（node.prev.next = node.next、node.next.prev = node.prev）。但如果沒有存 tail 指標，還是得先走到尾巴 —— 複雜度一樣。

追問三：這個「固定間距」的技巧還能用在哪？

  • 找中點（第 876 題）：一步 vs 兩步，快的到終點時慢的在中間
  • 判斷有沒有環（第 141 題）：快慢指標會相遇
  • 找環的起點（第 142 題）：相遇後從頭再放一個指標，同速前進
  • 找兩串列的交點（第 160 題）：走完自己再走對方，抵銷長度差

這四題加上本題，構成了鏈結串列雙指標的完整套路。
