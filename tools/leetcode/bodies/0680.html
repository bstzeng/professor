Problem

Given a string s, return true if the s can be palindrome after deleting at most one character from it.

中文翻譯

給你字串 s，判斷最多刪除一個字元後，它能否成為迴文。

範例

範例 1 輸入：s = "aba" 輸出：true 範例 2 輸入：s = "abca" 輸出：true 範例 3 輸入：s = "abc" 輸出：false

限制條件

  • 1 ≤ s.length ≤ 10⁵
  • s 只含小寫英文字母

LeetCode 原題

解題思路

【雙指標從兩端往內】 相同 -> 繼續。 第一次不同（s[l] != s[r]）： 這兩個至少要刪一個，否則不可能是迴文。 刪 s[l]：檢查 s[l+1..r] 是否迴文 刪 s[r]：檢查 s[l..r-1] 是否迴文 任一成立即可。 【為什麼不用往外找其他刪除位置？】 l 左邊、r 右邊已經兩兩配對好了， 刪那裡的字元只會破壞已經對好的部分。
解法

雙指標 + 兩種刪法

class Solution: def validPalindrome(self, s: str) -> bool: def is_pal(l, r): return all(s[l + k] == s[r - k] for k in range((r - l + 1) // 2)) l, r = 0, len(s) - 1 while l < r: if s[l] != s[r]: # ★ 第一個不匹配：刪左邊或刪右邊，剩下的部分必須是迴文 return is_pal(l + 1, r) or is_pal(l, r - 1) l += 1 r -= 1 return True

驗證方式：和「嘗試刪除每個位置」的暴力法比對 3000 組。

複雜度說明
時間O(n)
空間O(1)

邊界條件檢查清單

  • 本身就是迴文 → True。
  • "abca" → True（刪 b 或 c）。
  • 兩種刪法都要試 → "cupuufuc" 只能刪特定一邊。
