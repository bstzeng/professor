Problem

We build a table of n rows (1-indexed). We start by writing 0 in the 1st row. Now in every subsequent row, we look at the previous row and replace each occurrence of 0 with 01, and each occurrence of 1 with 10.

  • For example, for n = 3, the 1st row is 0, the 2nd row is 01, and the 3rd row is 0110.

Given two integer n and k, return the kth (1-indexed) symbol in the nth row of a table of n rows.

中文翻譯

第一列是 "0"。之後每一列由上一列產生：把每個 0 換成 01、每個 1 換成 10。

給你 n 和 k，回傳第 n 列的第 k 個符號（索引從 1 開始）。

範例

範例 1 輸入：n = 1, k = 1 輸出：0 範例 2 輸入：n = 2, k = 1 輸出：0 範例 3 輸入：n = 2, k = 2 輸出：1

限制條件

  • 1 ≤ n ≤ 30
  • 1 ≤ k ≤ 2n - 1

LeetCode 原題

解題思路

【看成一棵完全二元樹】 第 n 列的第 k 個，是第 n-1 列第 ⌈k/2⌉ 個的孩子： 左孩子（k 奇數）= 和父節點相同 右孩子（k 偶數）= 和父節點相反 遞迴往上，根是 0。 【翻轉幾次？】 用 0 起算的索引 k-1，它的二進位從高到低就是「從根往下走的路線」， 每個 1 代表走右孩子 = 翻轉一次。 答案 = popcount(k-1) % 2。 與 n 無關！（只要 k 在範圍內） 這就是 Thue–Morse 數列：0 1 1 0 1 0 0 1 ...
解法

位元計數

class Solution: def kthGrammar(self, n: int, k: int) -> int: # ★ 第 k 個（從 1 開始）的值 = (k-1) 的二進位中 1 的個數的奇偶 return bin(k - 1).count("1") % 2

驗證方式：直接生成前 14 列，檢查每一個位置。

複雜度說明
時間O(log k)
空間O(1)

邊界條件檢查清單

  • k = 1 → 0。
  • n 很大 → 不能真的生成（第 30 列有 2²⁹ 個字元）。

Thue–Morse 數列

這個數列有許多有趣的性質：它不包含任何三次重複（XXX）的片段；用它決定兩人輪流挑選的順序（ABBABAAB…）比單純輪流更公平。
