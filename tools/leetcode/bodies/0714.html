Problem

You are given an array prices where prices[i] is the price of a given stock on the ith day, and an integer fee representing a transaction fee.

Find the maximum profit you can achieve. You may complete as many transactions as you like, but you need to pay the transaction fee for each transaction.

Note:

  • You may not engage in multiple transactions simultaneously (i.e., you must sell the stock before you buy again).
  • The transaction fee is only charged once for each stock purchase and sale.

中文翻譯

給你每天的股價 prices 與每筆交易的手續費 fee。可以交易任意多次，但同一時間最多持有一股（必須先賣出才能再買），每筆交易（一買一賣）要付一次手續費。

回傳能獲得的最大利潤。

範例

範例 1 輸入：prices = [1,3,2,8,4,9], fee = 2 輸出：8 範例 2 輸入：prices = [1,3,7,5,10,3], fee = 3 輸出：6

限制條件

  • 1 ≤ prices.length ≤ 5 * 10⁴
  • 1 ≤ prices[i] < 5 * 10⁴
  • 0 ≤ fee < 5 * 10⁴

LeetCode 原題

解題思路

【兩個狀態】 cash：今天結束時手上沒有股票的最大收益 hold：今天結束時持有股票的最大收益 【轉移】 cash = max(昨天就沒有, 昨天持有今天賣出 hold + p - fee) hold = max(昨天就持有, 昨天沒有今天買入 cash - p) 【同一天買又賣？】 用新的 cash 算 hold 等於當天賣了又買， 手續費讓這種操作只會虧，不影響答案； 但同時賦值最乾淨。 和第 122 題（無限次交易）只差一個 fee。
解法

持有／不持有兩狀態 DP

class Solution: def maxProfit(self, prices: List[int], fee: int) -> int: cash, hold = 0, -prices[0] # cash：手上沒股票的最大收益；hold：持有股票 for p in prices[1:]: # ★ 賣出時付手續費；用舊的 hold 算新的 cash cash, hold = max(cash, hold + p - fee), max(hold, cash - p) return cash

驗證方式：和記憶化搜尋比對 1500 組。

複雜度說明
時間O(n)
空間O(1)

邊界條件檢查清單

  • 手續費大於任何價差 → 0。
  • 單日 → 0。
