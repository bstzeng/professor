Problem

Design a data structure that stores words and lets you check whether a query matches any stored word. Implement the WordDictionary class:

  • WordDictionary() creates an empty dictionary.
  • void addWord(word) stores word.
  • bool search(word) returns true if some stored word matches word. The query may contain the character '.', which matches any single letter.

中文翻譯

設計一個資料結構，可以存入單字，並查詢某個字串是否能和已存的單字匹配。請實作 WordDictionary 類別：

  • WordDictionary()：建立空的字典。
  • addWord(word)：存入 word。
  • search(word)：如果有已存的單字能匹配 word，回傳 true。查詢字串中的 '.' 可以匹配任意一個字母。

範例

範例 操作：["WordDictionary","addWord","addWord","addWord","search","search","search","search"] 參數：[[],["bad"],["dad"],["mad"],["pad"],["bad"],[".ad"],["b.."]] 輸出：[null,null,null,null,false,true,true,true]

限制條件

  • 1 ≤ word.length ≤ 25
  • addWord 的 word 只包含小寫英文字母
  • search 的 word 包含 '.' 或小寫英文字母
  • 每次 search 的查詢字串中，'.' 最多出現 2 個
  • addWord 和 search 合計最多呼叫 10⁴ 次

LeetCode 原題

解題思路

【沒有 '.' 的話，這就是第 208 題的字典樹】 【遇到 '.' 怎麼辦？】 '.' 可以是任何字母 -> 在字典樹的這一層，【每個子節點都要試一次】。 只要有一條路能走到結尾而且是結束節點，就回傳 true。 這自然是一個 DFS（回溯）： dfs(節點, 查詢位置 i) i 走完 -> 看是不是結束節點 字母 -> 只走那一個子節點 '.' -> 每個子節點都試 【最壞複雜度】 每個 '.' 讓分支變成最多 26 倍。 題目限制 '.' 最多 2 個 -> 最多 26² = 676 條路， 每條路長度 ≤ 25 -> 一次查詢最多幾萬步，完全可接受 ✔
解法一

字典樹 + DFS

class WordDictionary: def __init__(self): self.root = {} def addWord(self, word: str) -> None: node = self.root for ch in word: node = node.setdefault(ch, {}) node["$"] = True def search(self, word: str) -> bool: def dfs(node: dict, i: int) -> bool: if i == len(word): return "$" in node ch = word[i] if ch == ".": # ★ 萬用字元：每個子節點都試 return any(dfs(child, i + 1) for key, child in node.items() if key != "$") return ch in node and dfs(node[ch], i + 1) return dfs(self.root, 0)
【key != "$" 那個條件】 "$" 是結束標記，不是字元，走 '.' 時要跳過它， 否則會試圖把 True 當成節點往下走 ✘ 【any(...) 會短路】 找到一條能成功的路就立刻停止，不會浪費時間試剩下的。
複雜度說明
時間add O(L)，search 最壞 O(26ᵈ · L)d = '.' 的個數（≤ 2）
空間O(總字元數)
解法二

依長度分組 + 逐一比對

class WordDictionary: def __init__(self): self.by_len = defaultdict(set) # 長度 -> 這個長度的單字 def addWord(self, word: str) -> None: self.by_len[len(word)].add(word) def search(self, word: str) -> bool: cands = self.by_len[len(word)] if "." not in word: return word in cands # 沒有萬用字元：O(L) return any(all(p == "." or p == c for p, c in zip(word, w)) for w in cands)

只和長度相同的單字比。沒有 '.' 時是 O(L)，有 '.' 時要掃過所有同長度的單字。在這題的限制下也能通過，但如果單字很多，字典樹比較穩。

複雜度說明
時間search 最壞 O(N·L)N = 同長度的單字數
空間O(總字元數)

邊界條件檢查清單

  • 查詢全是 '.'（例如 "..."）→ 只要有任何長度 3 的單字就是 true。
  • 查詢比所有單字都長 → 走不到底，false。
  • 查詢只是某個單字的前綴 → 不是結束節點，false。
  • '.' 時沒跳過結束標記 → 程式出錯。

常見追問

追問：如果 '.' 的數量沒有限制？

最壞情況（查詢全是 '.'）會走遍整棵字典樹中所有長度 L 的路徑 —— 這在所有做法中都是無法避免的，因為答案本來就可能依賴任何一個單字。 可以額外在每個節點記錄「以下有沒有長度剛好是 k 的單字」來剪枝。
