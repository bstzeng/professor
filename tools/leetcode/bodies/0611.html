Problem

Given an integer array nums, return the number of triplets chosen from the array that can make triangles if we take them as side lengths of a triangle.

中文翻譯

給你一個非負整數陣列 nums，回傳從中選出三個數（索引不同）可以構成三角形三邊長的組合數。

範例

範例 1 輸入：nums = [2,2,3,4] 輸出：3 範例 2 輸入：nums = [4,2,3,4] 輸出：4

限制條件

  • 1 ≤ nums.length ≤ 1000
  • 0 ≤ nums[i] ≤ 1000

LeetCode 原題

解題思路

【三角不等式】 排序後 a <= b <= c，只需檢查 a + b > c（另外兩個自動成立）。 【固定最長邊 c = nums[k]】 在 nums[0..k-1] 中找有幾對 (i, j) 使 nums[i] + nums[j] > nums[k]。 雙指標 i = 0、j = k-1： nums[i] + nums[j] > c： i 換成 i..j-1 任何一個（都 >= nums[i]）也成立 -> 一次加 j - i 對，j 左移 否則：nums[i] 太小，i 右移 【0 的處理】 0 + b > c 不可能（b <= c），自然被排除。
解法一

排序 + 二分

固定 i、j，用二分找最大的 k 使 nums[k] < nums[i] + nums[j] 時間 O(n² log n)
複雜度說明
時間O(n² log n)
空間O(1)
解法二

排序 + 雙指標

class Solution: def triangleNumber(self, nums: List[int]) -> int: nums.sort() res = 0 for k in range(len(nums) - 1, 1, -1): # 固定最長邊 nums[k] i, j = 0, k - 1 while i < j: if nums[i] + nums[j] > nums[k]: res += j - i # ★ i..j-1 和 j 配對都成立（它們都 >= nums[i]） j -= 1 else: i += 1 # 太小：左邊加大 return res

驗證方式：和三重迴圈比對 2000 組。

複雜度說明
時間O(n²)
空間O(1)

邊界條件檢查清單

  • 含 0 → 不可能是邊。
  • 少於 3 個數 → 0。
  • 重複值 → 不同索引視為不同組合。
