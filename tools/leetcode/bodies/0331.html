Problem

One way to serialize a binary tree is to use preorder traversal. When we encounter a non-null node, we record the node's value. If it is a null node, we record using a sentinel value such as '#'.

Given a string of comma-separated values preorder, return true if it is a correct preorder traversal serialization of a binary tree.

It is guaranteed that each comma-separated value in the string must be either an integer or a character '#' representing null pointer. You may assume that the input format is always valid.

Note: You are not allowed to reconstruct the tree.

中文翻譯

二元樹的一種序列化方式是前序遍歷：遇到非空節點記下它的值，遇到空節點記下 '#'。

給你一個以逗號分隔的字串 preorder，判斷它是不是某棵二元樹正確的前序序列化結果。

每個值保證是整數或 '#'，格式一定正確。

注意：不能把樹重建出來。

範例

範例 1 輸入：preorder = "9,3,4,#,#,1,#,#,2,#,6,#,#" 輸出：true 範例 2 輸入：preorder = "1,#" 輸出：false 範例 3 輸入：preorder = "9,#,#,1" 輸出：false

限制條件

  • 1 ≤ preorder.length ≤ 10⁴
  • preorder 由 [0, 100] 的整數和 '#' 以逗號分隔組成

LeetCode 原題

解題思路

【數「空位」（slots）】 想像一棵樹是一個一個「位置」被填上去的： 一開始只有 1 個空位（根的位置） 每讀一個 token，佔掉 1 個空位 如果是非空節點，它又提供 2 個新空位（左孩子、右孩子） 如果是 #，不提供新空位 合法 <=> 途中每次要放節點時都還有空位（slots > 0） 而且最後空位剛好用完（slots == 0） 【範例 "1,#"】 slots: 1 -> 讀 1：0 + 2 = 2 -> 讀 #：1 結束時 slots = 1 != 0 -> 還有一個右孩子的位置沒填 ✘ 【範例 "9,#,#,1"】 slots: 1 -> 9：2 -> #：1 -> #：0 -> 讀 1 時 slots = 0 ✘ 【另一個角度：出度 = 入度】 樹中 非空節點數 + 1 = 空節點數（每個非空節點有 2 條往下的邊）。 slots 就是在即時追蹤這個差。
解法一

堆疊化簡

class Solution: def isValidSerialization(self, preorder: str) -> bool: stack = [] for tok in preorder.split(","): stack.append(tok) # 「數字, #, #」代表一棵完整的葉子子樹 -> 化簡成一個 # while len(stack) >= 3 and stack[-1] == stack[-2] == "#" and stack[-3] != "#": del stack[-3:] stack.append("#") return stack == ["#"]

每當堆疊頂端是「數字, #, #」，就代表一棵完整的小子樹，把它化簡成一個 #。合法的序列最後會只剩一個 #。

複雜度說明
時間O(n)
空間O(n)
解法二

計算空位

class Solution: def isValidSerialization(self, preorder: str) -> bool: slots = 1 # ★ 目前有幾個「空位」可以放節點（一開始留給根） for tok in preorder.split(","): if slots == 0: # 沒有空位了卻還有節點 return False slots -= 1 # 每個節點（含 #）佔掉一個空位 if tok != "#": slots += 2 # 非空節點帶來兩個新空位（左、右孩子） return slots == 0 # 所有空位剛好填滿
複雜度說明
時間O(n)
空間O(1)不計 split

邊界條件檢查清單

  • "#" → 空樹，true。
  • 提早用完空位（"#,1"）→ false。
  • 多位數的值 → 用逗號切開，不能逐字元處理。
