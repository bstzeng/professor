Problem

You're given strings jewels representing the types of stones that are jewels, and stones representing the stones you have. Each character in stones is a type of stone you have. You want to know how many of the stones you have are also jewels.

Letters are case sensitive, so "a" is considered a different type of stone from "A".

中文翻譯

字串 jewels 代表哪些種類的石頭是寶石（字母互不相同），stones 代表你擁有的石頭。回傳你擁有的石頭中有幾顆是寶石（區分大小寫）。

範例

範例 1 輸入：jewels = "aA", stones = "aAAbbbb" 輸出：3 範例 2 輸入：jewels = "z", stones = "ZZ" 輸出：0

限制條件

  • 1 ≤ jewels.length, stones.length ≤ 50
  • jewels and stones 只含英文字母
  • jewels 中的元素互不相同

LeetCode 原題

解題思路

【集合查詢】 逐一檢查每顆石頭是否在寶石集合中。 用 list 查詢是 O(|J|)，用 set 是 O(1)。
解法

雜湊集合

class Solution: def numJewelsInStones(self, jewels: str, stones: str) -> int: J = set(jewels) # ★ 用集合查詢 O(1) return sum(c in J for c in stones)
複雜度說明
時間O(|J| + |S|)
空間O(|J|)

邊界條件檢查清單

  • 大小寫不同 → 視為不同種類。

常見追問

位元遮罩

字母只有 52 種，可以用一個 64 位元整數當集合：第 (ord(c) − 65) 位代表該字母是寶石。
