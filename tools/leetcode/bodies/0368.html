Problem

Given a set of distinct positive integers nums, return the largest subset answer such that every pair (answer[i], answer[j]) of elements in this subset satisfies:

  • answer[i] % answer[j] == 0, or
  • answer[j] % answer[i] == 0

If there are multiple solutions, return any of them.

中文翻譯

給你一組互不相同的正整數 nums，找出最大的子集，使得子集中任意兩個數都有整除關係（一個能整除另一個）。

有多個答案時回傳任意一個。

範例

範例 1 輸入：nums = [1,2,3] 輸出：[1,2] 說明：[1,3] 也可以。 範例 2 輸入：nums = [1,2,4,8] 輸出：[1,2,4,8]

限制條件

  • 1 ≤ nums.length ≤ 1000
  • 1 ≤ nums[i] ≤ 2 × 10⁹
  • nums 中的整數互不相同

LeetCode 原題

解題思路

【排序後，整除子集就是一條「整除鏈」】 排序後的子集 a₁ < a₂ < ... < aₖ， 任兩個都有整除關係 <=> a₁ | a₂ | a₃ | ... | aₖ（每個整除下一個） 為什麼？整除有遞移性：a | b 且 b | c => a | c。 所以只要相鄰的整除，任兩個都整除。 【這就是最長遞增子序列（第 300 題）的變形】 「遞增」換成「整除」： dp[i] = 以 nums[i] 結尾（最大元素）的最長整除鏈長度 dp[i] = 1 + max(dp[j])，對所有 j < i 且 nums[i] % nums[j] == 0 【要回傳子集本身】 多記一個 prev[i]，最後從 dp 最大的位置往回追。
nums = [1, 2, 3, 4, 6, 8, 12, 24] dp = 1 2 2 3 3 4 4 5 24 <- 12 <- 4 <- 2 <- 1 （或 24 <- 12 <- 6 <- 2 <- 1）
解法

排序 + LIS 式 DP + 回溯

class Solution: def largestDivisibleSubset(self, nums: List[int]) -> List[int]: nums.sort() n = len(nums) dp = [1] * n # dp[i]：以 nums[i] 為「最大元素」的整除子集大小 prev = [-1] * n # 用來回溯出子集 for i in range(n): for j in range(i): # ★ 排序後，只要 nums[i] 被「目前子集的最大值」nums[j] 整除， # 就被子集裡所有數整除（整除有遞移性） if nums[i] % nums[j] == 0 and dp[j] + 1 > dp[i]: dp[i] = dp[j] + 1 prev[i] = j i = max(range(n), key=lambda t: dp[t]) res = [] while i != -1: res.append(nums[i]) i = prev[i] return res[::-1]
複雜度說明
時間O(n²)
空間O(n)

邊界條件檢查清單

  • 只有一個數 → 它本身。
  • 互質的數 → 答案大小 1（或包含 1 時大小 2）。
  • 包含 1 → 1 可以放進任何鏈的開頭。

常見追問

為什麼不能用 O(n log n) 的 LIS？

二分 LIS 依賴「結尾越小越好」的全序關係；整除只是偏序（2 和 3 互不整除），無法用 tails 陣列二分。
