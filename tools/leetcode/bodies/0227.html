Problem

Given a string s which represents an expression, evaluate this expression and return its value.

The expression consists of non-negative integers, '+', '-', '*', '/' operators and spaces. The integer division should truncate toward zero. The given expression is always valid.

You are not allowed to use any built-in function which evaluates strings as expressions, such as eval().

中文翻譯

給你一個代表算式的字串 s，計算並回傳它的值。

算式由非負整數、'+'、'-'、'*'、'/' 和空白組成（沒有括號）。整數除法向零取整。算式一定合法。

不能使用 eval() 之類的內建函式。

範例

範例 1 輸入：s = "3+2*2" 輸出：7 範例 2 輸入：s = " 3/2 " 輸出：1 範例 3 輸入：s = " 3+5 / 2 " 輸出：5

限制條件

  • 1 ≤ s.length ≤ 3 × 10⁵
  • s 只包含整數與 '+'、'-'、'*'、'/'、空白
  • 所有整數都是非負的，而且在 [0, 2³¹ − 1] 之間
  • 答案保證在 32 位元有號整數範圍內

LeetCode 原題

解題思路

【把算式看成「若干項相加」】 3 + 5 / 2 - 4 * 2 = (+3) + (+5/2) + (-4*2) 每一項由乘除組成；項與項之間用加減連接。 【堆疊存「項」】 讀完一個數字 num，看它【前面】的運算子 op： + -> 新的一項 +num，推進堆疊 - -> 新的一項 -num，推進堆疊 * -> 和上一項合併：堆疊頂端 × num / -> 和上一項合併：堆疊頂端 ÷ num（向零取整） 最後把堆疊全部加總。 【為什麼看「前面」的運算子？】 讀到數字的當下還不知道後面是什麼， 但前面的運算子已經讀過了 -> 用變數 op 記住。 【向零取整的陷阱】 Python 的 // 是向下取整：-3 // 2 = -2 ✘（題目要 -1） 用 int(a / b) ✔（數值在 2³¹ 內，浮點數精度足夠） 【最後一個數字】 字串結尾沒有運算子觸發結算 -> 判斷 i == len(s) - 1 時也要處理。
解法一

堆疊存每一項

class Solution: def calculate(self, s: str) -> int: stack = [] # 存放「要相加的項」 num = 0 op = "+" # ★ num 前面的運算子（第一個數字視為 +） for i, ch in enumerate(s): if ch.isdigit(): num = num * 10 + int(ch) if (not ch.isdigit() and ch != " ") or i == len(s) - 1: # 讀完一個數字：依照它「前面」的運算子處理 if op == "+": stack.append(num) elif op == "-": stack.append(-num) elif op == "*": stack.append(stack.pop() * num) else: # "/"：向零取整 stack.append(int(stack.pop() / num)) op, num = ch, 0 return sum(stack)
【模擬】s = "3+5/2" 讀 3，遇到 '+' op='+' -> push 3 stack=[3] op='+' 讀 5，遇到 '/' op='+' -> push 5 stack=[3,5] op='/' 讀 2（結尾） op='/' -> pop 5, 5/2=2 stack=[3,2] sum = 5 ✔
複雜度說明
時間O(n)
空間O(n)
解法二

只保留最後一項（O(1) 空間）

class Solution: def calculate(self, s: str) -> int: total = 0 # 已經確定的項的總和 last = 0 # 最後一項（可能還會被乘除） num, op = 0, "+" for i, ch in enumerate(s): if ch.isdigit(): num = num * 10 + int(ch) if (not ch.isdigit() and ch != " ") or i == len(s) - 1: if op in "+-": total += last # 上一項確定了 last = num if op == "+" else -num elif op == "*": last *= num else: last = int(last / num) op, num = ch, 0 return total + last
【觀察】乘除只會影響「最後一項」 更早的項已經不會再變了 -> 直接加進 total。 所以不需要整個堆疊，一個變數 last 就夠。
複雜度說明
時間O(n)
空間O(1)

解法對照

解法時間空間
一、堆疊O(n)O(n) ✔（最好擴充）
二、只存最後一項O(n)O(1)

邊界條件檢查清單

  • 負數除法（"1-5/2"）→ 項是 −5/2，向零取整 = −2，答案 −1。
  • 結尾有空白 → 最後一個字元是空白時，要確保最後一個數字仍被結算。本解法中 i == len(s)-1 也涵蓋空白字元，此時 op 是前一個運算子、num 是剛讀完的數字 ✔
  • 連續乘除（"2*3*4"）→ 同一項一直被更新。
  • 只有一個數字 → 直接回傳。
