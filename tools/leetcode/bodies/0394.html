Problem

Given an encoded string, return its decoded string.

The encoding rule is: k[encoded_string], where the encoded_string inside the square brackets is being repeated exactly k times. Note that k is guaranteed to be a positive integer.

You may assume that the input string is always valid; there are no extra white spaces, square brackets are well-formed, etc. Furthermore, you may assume that the original data does not contain any digits and that digits are only for those repeat numbers, k. For example, there will not be input like 3a or 2[4].

中文翻譯

給你一個編碼過的字串，回傳解碼後的結果。

編碼規則：k[encoded_string] 代表方括號內的字串重複 k 次（k 是正整數）。括號可以巢狀。

輸入保證合法：沒有多餘空白、括號配對正確；原始資料中不含數字，數字只用來表示重複次數。

範例

範例 1 輸入：s = "3[a]2[bc]" 輸出："aaabcbc" 範例 2 輸入：s = "3[a2[c]]" 輸出："accaccacc" 範例 3 輸入：s = "2[abc]3[cd]ef" 輸出："abcabccdcdcdef"

限制條件

  • 1 ≤ s.length ≤ 30
  • s 由小寫英文字母、數字、'['、']' 組成
  • 所有整數都在 [1, 300] 之間
  • 輸出長度不超過 10⁵

解題思路

【巢狀括號 -> 堆疊（第 224 題的同一個套路）】 cur = 目前這一層正在組的字串 num = 正在讀的重複次數 '['：把 (cur, num) 推進堆疊，括號內從空字串重新開始 ']'：彈出 (prev, k)，cur = prev + cur × k 字母：cur += ch 數字：num = num × 10 + d（次數可能是多位數，例如 10[a]） 【模擬】s = "3[a2[c]]" 讀 3 num=3 讀 [ push ("", 3) cur="" 讀 a cur="a" 讀 2 num=2 讀 [ push ("a", 2) cur="" 讀 c cur="c" 讀 ] pop ("a", 2) cur = "a" + "c"×2 = "acc" 讀 ] pop ("", 3) cur = "" + "acc"×3 = "accaccacc" ✔
解法一

堆疊

class Solution: def decodeString(self, s: str) -> str: stack = [] # 進入括號前的 (目前字串, 重複次數) cur, num = "", 0 for ch in s: if ch.isdigit(): num = num * 10 + int(ch) # 次數可能是多位數 elif ch == "[": stack.append((cur, num)) # ★ 暫存外層，括號內從空字串開始 cur, num = "", 0 elif ch == "]": prev, k = stack.pop() cur = prev + cur * k # 括號內重複 k 次，接回外層 else: cur += ch return cur
複雜度說明
時間O(輸出長度)
空間O(輸出長度)
解法二

遞迴下降

class Solution: def decodeString(self, s: str) -> str: i = 0 def parse() -> str: # 讀到 "]" 或結尾為止 nonlocal i out = [] while i < len(s) and s[i] != "]": if s[i].isdigit(): k = 0 while s[i].isdigit(): k = k * 10 + int(s[i]) i += 1 i += 1 # 跳過 "[" inner = parse() i += 1 # 跳過 "]" out.append(inner * k) else: out.append(s[i]) i += 1 return "".join(out) return parse()
複雜度說明
時間O(輸出長度)
空間O(輸出長度)

邊界條件檢查清單

  • 多位數次數（10[a]）→ 數字要累積。
  • 括號外的字母（2[a]bc）→ 直接接在 cur 後面。
  • 巢狀 → 堆疊處理。
