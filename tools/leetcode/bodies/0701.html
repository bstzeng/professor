Problem

You are given the root node of a binary search tree (BST) and a value to insert into the tree. Return the root node of the BST after the insertion. It is guaranteed that the new value does not exist in the original BST.

Notice that there may exist multiple valid ways for the insertion, as long as the tree remains a BST after insertion. You can return any of them.

中文翻譯

給你一棵二元搜尋樹的根節點和一個值 val（保證不在樹中），把它插入 BST，回傳插入後的根節點。

可能有多種合法的插入方式，回傳任意一種即可。

範例

範例 1 輸入：root = [4,2,7,1,3], val = 5 輸出：[4,2,7,1,3,5] 範例 2 輸入：root = [40,20,60,10,30,50,70], val = 25 輸出：[40,20,60,10,30,50,70,null,null,25] 範例 3 輸入：root = [4,2,7,1,3,null,null,null,null,null,null], val = 5 輸出：[4,2,7,1,3,5]

限制條件

  • 節點數在 [0, 10⁴] 範圍內
  • -10⁸ ≤ Node.val ≤ 10⁸
  • All the values Node.val are unique.
  • -10⁸ ≤ val ≤ 10⁸
  • It's guaranteed that val does not exist in the original BST.

LeetCode 原題

解題思路

【最簡單的插入：當成葉子】 像搜尋 val 一樣往下走：小往左、大往右。 走到空的位置 -> val 本來應該在這裡 -> 放一個新節點。 不需要調整任何既有的節點。 【空樹】 新節點就是根。
解法

迭代找到空位

class Solution: def insertIntoBST(self, root: Optional[TreeNode], val: int) -> Optional[TreeNode]: if not root: return TreeNode(val) nd = root while True: if val < nd.val: if not nd.left: nd.left = TreeNode(val) # ★ 找到空位就放進去：新節點一定是葉子 return root nd = nd.left else: if not nd.right: nd.right = TreeNode(val) return root nd = nd.right

驗證方式：插入後中序走訪必須是排序好的全部值。

複雜度說明
時間O(h)
空間O(1)

邊界條件檢查清單

  • 空樹 → 回傳新節點。
  • 插入後樹可能不平衡 → 題目不要求平衡。

常見追問

保持平衡

一直插入遞增的值會讓樹退化成鏈。AVL 樹、紅黑樹在插入後用旋轉恢復平衡；Python 沒有內建平衡 BST，常用 sortedcontainers.SortedList 代替。
