Problem

Given the root of a Binary Search Tree (BST), return the minimum absolute difference between the values of any two different nodes in the tree.

Note: This question is the same as 783: https://leetcode.com/problems/minimum-distance-between-bst-nodes/

中文翻譯

給你一棵二元搜尋樹的根節點，回傳樹中任意兩個不同節點值之差的最小值。

（本題與第 783 題相同。）

範例

範例 1 輸入：root = [4,2,6,1,3] 輸出：1 範例 2 輸入：root = [1,0,48,null,null,12,49] 輸出：1

限制條件

  • 節點數在 [2, 10⁴] 範圍內
  • 0 ≤ Node.val ≤ 10⁵

LeetCode 原題

解題思路

【排序陣列的最小差】 排好序後，最小差一定出現在某對相鄰元素之間 （隔一個的差 = 兩段相鄰差的和，只會更大）。 【BST 的中序走訪就是排序】 中序走訪時記住上一個值 prev， 每個節點和 prev 比較，更新最小差。 不需要真的把序列存下來。
解法

中序走訪 + 相鄰差

class Solution: def getMinimumDifference(self, root: Optional[TreeNode]) -> int: res, prev = float("inf"), None def inorder(nd): nonlocal res, prev if not nd: return inorder(nd.left) if prev is not None: res = min(res, nd.val - prev) # ★ 中序有序：最小差一定出現在相鄰兩個值之間 prev = nd.val inorder(nd.right) inorder(root) return res
複雜度說明
時間O(n)
空間O(h)

邊界條件檢查清單

  • 只有兩個節點 → 它們的差。
  • 非相鄰的節點（例如根和左子樹最右節點）→ 中序走訪會自然處理。
