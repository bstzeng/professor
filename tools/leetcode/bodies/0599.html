Problem

Given two arrays of strings list1 and list2, find the common strings with the least index sum.

A common string is a string that appeared in both list1 and list2.

A common string with the least index sum is a common string such that if it appeared at list1[i] and list2[j] then i + j should be the minimum value among all the other common strings.

Return all the common strings with the least index sum. Return the answer in any order.

中文翻譯

給你兩個字串陣列 list1、list2（各自的字串互不重複）。共同字串是同時出現在兩個陣列中的字串。

回傳所有「兩邊索引和最小」的共同字串（順序不限）。

範例

範例 1 輸入：list1 = ["Shogun","Tapioca Express","Burger King","KFC"], list2 = ["Piatti","The Grill at Torrey Pines","Hungry Hunter Steakhouse","Shogun"] 輸出：["Shogun"] 範例 2 輸入：list1 = ["Shogun","Tapioca Express","Burger King","KFC"], list2 = ["KFC","Shogun","Burger King"] 輸出：["Shogun"] 範例 3 輸入：list1 = ["happy","sad","good"], list2 = ["sad","happy","good"] 輸出：["sad","happy"]

限制條件

  • 1 ≤ list1.length, list2.length ≤ 1000
  • 1 ≤ list1[i].length, list2[i].length ≤ 30
  • list1[i] and list2[i] consist of spaces ' ' and English letters.
  • list1 中的元素互不相同
  • list2 中的元素互不相同
  • There is at least a common string between list1 and list2.

解題思路

【雜湊表查索引】 list1 建成 {字串: 索引}。 掃 list2 的每個字串，若在表中，索引和 = i + j。 【維護最小值與答案】 更小 -> 清空答案，只放這個 相等 -> 加進答案
解法

雜湊表

class Solution: def findRestaurant(self, list1: List[str], list2: List[str]) -> List[str]: pos = {s: i for i, s in enumerate(list1)} # list1 中每個字串的索引 best, res = float("inf"), [] for j, s in enumerate(list2): if s in pos: t = pos[s] + j if t < best: best, res = t, [s] # ★ 更小：重新開始 elif t == best: res.append(s) # 並列：加進去 return res
複雜度說明
時間O(m + n)
空間O(m)

邊界條件檢查清單

  • 多個並列 → 全部回傳。
  • 只有一個共同字串 → 就是它。

提早結束

掃到 j > best 時就可以停：之後的索引和至少是 j，不可能更小。
