Problem

Given a string s, find the longest palindromic subsequence's length in s.

A subsequence is a sequence that can be derived from another sequence by deleting some or no elements without changing the order of the remaining elements.

中文翻譯

給你字串 s，回傳它的最長迴文子序列長度。

子序列是刪除某些（或不刪）字元、但不改變其餘字元順序後得到的序列（不需要連續）。

範例

範例 1 輸入：s = "bbbab" 輸出：4 範例 2 輸入：s = "cbbd" 輸出：2

限制條件

  • 1 ≤ s.length ≤ 1000
  • s 只含小寫英文字母

LeetCode 原題

解題思路

【區間 DP】 dp[i][j] = s[i..j] 中最長迴文子序列的長度。 s[i] == s[j]： 這兩個字元可以當迴文的頭尾 -> dp[i+1][j-1] + 2 s[i] != s[j]： 它們不可能同時當頭尾，至少丟掉一個 -> max(dp[i+1][j], dp[i][j-1]) 【計算順序】 dp[i][j] 依賴 i+1 的列 -> i 由大到小；j 由小到大。 【另一個角度】 迴文正著讀、反著讀一樣， 所以「最長迴文子序列」= LCS(s, reverse(s))（第 1143 題）。
解法一

區間 DP

class Solution: def longestPalindromeSubseq(self, s: str) -> int: n = len(s) dp = [[0] * n for _ in range(n)] # dp[i][j]：s[i..j] 的最長迴文子序列長度 for i in range(n - 1, -1, -1): # i 由大到小，才能用到 dp[i+1][...] dp[i][i] = 1 for j in range(i + 1, n): if s[i] == s[j]: dp[i][j] = dp[i + 1][j - 1] + 2 # ★ 兩端相同：一起收進來 else: dp[i][j] = max(dp[i + 1][j], dp[i][j - 1]) # 丟掉其中一端 return dp[0][n - 1]
複雜度說明
時間O(n²)
空間O(n²)可以壓成一維 O(n)
解法二

轉成 LCS

class Solution: def longestPalindromeSubseq(self, s: str) -> int: # 等價於 s 與 reverse(s) 的最長共同子序列（LCS） t = s[::-1] n = len(s) prev = [0] * (n + 1) for i in range(1, n + 1): cur = [0] * (n + 1) for j in range(1, n + 1): cur[j] = prev[j - 1] + 1 if s[i - 1] == t[j - 1] else max(prev[j], cur[j - 1]) prev = cur return prev[n]
複雜度說明
時間O(n²)
空間O(n)

邊界條件檢查清單

  • 單一字元 → 1。
  • 全部相同 → n。
  • 子序列 vs 子字串 → 本題不需要連續（對照第 5 題）。
