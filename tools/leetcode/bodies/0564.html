Problem

Given a string n representing an integer, return the closest integer (not including itself), which is a palindrome. If there is a tie, return the smaller one.

The closest is defined as the absolute difference minimized between two integers.

中文翻譯

給你一個用字串表示的整數 n，回傳最接近它的迴文整數（不包含它自己）。

若有兩個一樣近，回傳較小的那個。「最接近」指兩數之差的絕對值最小。

範例

範例 1 輸入：n = "123" 輸出："121" 範例 2 輸入：n = "1" 輸出："0"

限制條件

  • 1 ≤ n.length ≤ 18
  • n 只含數字
  • n does not have leading zeros.
  • n is representing an integer in the range [1, 10¹⁸ - 1].

LeetCode 原題

解題思路

【迴文由前半段決定】 長度 L 的迴文，只要知道前 ⌈L/2⌉ 位，後半段就是鏡射。 要離 n 最近 -> 前半段應該和 n 的前半段差不多： prefix - 1、prefix、prefix + 1，各自鏡射成迴文。 【位數改變的情況】 n = 99 -> 最近的是 101（位數變多） n = 1000 -> 最近的是 999（位數變少） n = 10 -> 9 所以再加兩個候選：10^L + 1、10^(L-1) - 1。 【從 5 個候選中挑】 排除 n 自己，選 |c - n| 最小，平手選較小的。 【注意奇偶長度】 奇數長度時中間位不能重複：鏡射時跳過反轉後的第一個字元。
解法

五個候選

class Solution: def nearestPalindromic(self, n: str) -> str: L, x = len(n), int(n) cands = {10 ** L + 1, 10 ** (L - 1) - 1} # 位數變多（10..01）或變少（9..9）的情況 prefix = int(n[:(L + 1) // 2]) # 前半段（奇數長度含中間位） for p in (prefix - 1, prefix, prefix + 1): # ★ 前半段 ±1，再鏡射成迴文 s = str(p) cands.add(int(s + s[::-1][L % 2:])) # 奇數長度時中間位不重複 cands.discard(x) # 不能是自己 return str(min(cands, key=lambda c: (abs(c - x), c)))

驗證方式：1～3000 全部，加上 300 個隨機八位數，和「往兩側逐一找迴文」的暴力法比對。

複雜度說明
時間O(L)
空間O(L)

邊界條件檢查清單

  • n = "1" → "0"。
  • n = "10" → "9"。
  • n 本身是迴文（如 "121"）→ 不能回傳自己，答案是 111 或 131 中較近／較小的。
  • 平手 → 取較小。

常見追問

為什麼 5 個候選就夠？

同樣位數的迴文中，最接近 n 的一定由 n 的前半段或它的 ±1 產生（前半段差 2 以上，整數差距至少是 10^(L/2) 等級，比 ±1 的候選更遠）；位數不同的迴文中，最近的就是 9…9 或 10…01。
