Problem

You are given an integer num. You can swap two digits at most once to get the maximum valued number.

Return the maximum valued number you can get.

中文翻譯

給你一個非負整數 num，最多交換其中兩位數字一次，回傳能得到的最大值。

範例

範例 1 輸入：num = 2736 輸出：7236 範例 2 輸入：num = 9973 輸出：9973

限制條件

  • 0 ≤ num ≤ 10⁸

LeetCode 原題

解題思路

【貪心】 越高位越重要：從左往右找第一個「可以變大」的位置 i。 可以變大 <=> 後面有比 d[i] 大的數字。 【換成誰？】 後面最大的數字 big。 若 big 出現多次，選「最後一次」出現的位置： 被換到後面的 d[i] 比較小，放在越低位越好。 例：1993 -> 換第一個 1 和最後一個 9 -> 9913（而不是 9193）。 【實作】 last[數字] = 最後出現的位置。 對每個 i，從 9 往下試到 d[i]+1，找到在 i 後面的就換。
解法

貪心 + 最後出現位置

class Solution: def maximumSwap(self, num: int) -> int: d = list(str(num)) last = {int(c): i for i, c in enumerate(d)} # 每個數字最後出現的位置 for i, c in enumerate(d): for big in range(9, int(c), -1): # ★ 從 9 往下找比 d[i] 大、而且在後面的數字 if last.get(big, -1) > i: j = last[big] # 選最後一個，換過來後較小的數字放在最右邊 d[i], d[j] = d[j], d[i] return int("".join(d)) return num

驗證方式：和枚舉所有交換的暴力法比對 3000 個數。

複雜度說明
時間O(位數 · 10)
空間O(10)

邊界條件檢查清單

  • 已經是非遞增（如 9973）→ 不交換。
  • 重複的最大數字 → 換最後一個。
  • 單一位數 → 不變。
