Problem

Two strings s and t of equal length are called isomorphic if the characters of s can be replaced to produce t.

Every occurrence of a character must be replaced by the same character, keeping the order of characters unchanged. Two different characters may not map to the same character, but a character is allowed to map to itself.

Return true if s and t are isomorphic.

中文翻譯

兩個等長字串 s 和 t，如果可以把 s 的字元替換成別的字元而得到 t，就稱它們同構。

規則：同一個字元的每次出現都必須換成同一個字元，字元的順序不能改變；兩個不同的字元不能對應到同一個字元，但一個字元可以對應到它自己。

如果 s 和 t 同構，回傳 true。

範例

範例 1 輸入：s = "egg", t = "add" 輸出：true 說明：e -> a、g -> d。 範例 2 輸入：s = "foo", t = "bar" 輸出：false 說明：o 要同時對應 a 和 r，不行。 範例 3 輸入：s = "paper", t = "title" 輸出：true 範例 4 輸入：s = "badc", t = "baba" 輸出：false 說明：b -> b、d -> b，兩個不同的字元對應到同一個 b，不行。

限制條件

  • 1 ≤ s.length ≤ 5 × 10⁴
  • t.length == s.length
  • s 和 t 由任意有效的 ASCII 字元組成

LeetCode 原題

解題思路

【同構 = 字元之間存在一個「一對一」的對應（雙射）】 兩個條件缺一不可： 1. s 的同一個字元，永遠對到 t 的同一個字元（是函數） 2. s 的不同字元，不能對到 t 的同一個字元（是單射） 【最常見的錯誤：只檢查第一個條件】 s = "badc", t = "baba" b -> b, a -> a, d -> b, c -> a 只看 s -> t 的方向，每個 s 字元都只對一個 t 字元 ✔ 但 b 和 d 都對到 b ✘ 所以要同時維護 s -> t 和 t -> s 兩張表。 【另一個角度：比較「形狀」】 "paper" -> 第幾個新字元：[0, 1, 0, 2, 3] "title" -> 第幾個新字元：[0, 1, 0, 2, 3] 形狀一樣 -> 同構 ✔
解法一

雙向雜湊表

class Solution: def isIsomorphic(self, s: str, t: str) -> bool: s2t, t2s = {}, {} for a, b in zip(s, t): if s2t.get(a, b) != b or t2s.get(b, a) != a: # ★ 兩個方向都要一致 return False s2t[a] = b t2s[b] = a return True
【s2t.get(a, b) != b 的意思】 如果 a 還沒有對應 -> get 回傳 b -> 相等，不衝突 如果 a 已經對應 x -> 看 x 是不是 b 一行同時處理「第一次出現」和「已經出現」兩種情況。

只檢查單向為什麼會錯

class Solution: def isIsomorphic(self, s: str, t: str) -> bool: s2t = {} for a, b in zip(s, t): if a in s2t and s2t[a] != b: return False s2t[a] = b return True # ✘ 只檢查了一個方向

上面這個版本在 s = "badc", t = "baba" 會回傳 true——錯。

複雜度說明
時間O(n)
空間O(k)k 是字元種類數（ASCII 最多 128）
解法二

比較首次出現的「形狀」

class Solution: def isIsomorphic(self, s: str, t: str) -> bool: def pattern(x: str) -> List[int]: first = {} return [first.setdefault(c, len(first)) for c in x] # 第幾個出現的字元 return pattern(s) == pattern(t)

把每個字元換成「它是第幾種出現的字元」，兩個字串的形狀相同就同構。這個想法可以直接推廣到第 290 題單詞規律。

複雜度說明
時間O(n)
空間O(n)形狀陣列
解法三

集合計數（一行）

class Solution: def isIsomorphic(self, s: str, t: str) -> bool: return len(set(s)) == len(set(t)) == len(set(zip(s, t)))
【為什麼三個集合大小相等就代表同構？】 set(zip(s, t)) 是所有出現過的「配對」。 - 如果某個 s 字元對到兩種 t 字元， 配對數 > s 的字元種類數。 - 如果兩個 s 字元對到同一個 t 字元， 配對數 > t 的字元種類數。 三者相等 -> 既是函數又是單射 ✔
複雜度說明
時間O(n)
空間O(n)

邊界條件檢查清單

  • 長度 1 → 一定同構。
  • 字元對應到自己（"ab", "ab"）→ 允許。
  • 兩個不同字元對應同一個（"ab", "aa"）→ 不同構。
  • 只檢查單向 → "badc", "baba" 會誤判。
  • 字元不只英文字母 → 題目說是任意 ASCII，別用長度 26 的陣列。
