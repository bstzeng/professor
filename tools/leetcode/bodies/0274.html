Problem

Given an array of integers citations where citations[i] is the number of citations a researcher received for their ith paper, return the researcher's h-index.

According to the definition of h-index on Wikipedia: The h-index is defined as the maximum value of h such that the given researcher has published at least h papers that have each been cited at least h times.

中文翻譯

給你一個整數陣列 citations，citations[i] 是某位研究者第 i 篇論文被引用的次數。回傳這位研究者的 h 指數。

h 指數的定義：最大的 h，使得這位研究者至少有 h 篇論文、每篇至少被引用 h 次。

範例

範例 1 輸入：citations = [3,0,6,1,5] 輸出：3 說明：有 3 篇論文（3、6、5）被引用至少 3 次； 要 h = 4 需要 4 篇至少被引用 4 次，但只有 2 篇。 範例 2 輸入：citations = [1,3,1] 輸出：1

限制條件

  • n == citations.length
  • 1 ≤ n ≤ 5000
  • 0 ≤ citations[i] ≤ 1000

LeetCode 原題

解題思路

【排序之後很直觀】 由大到小排序：c[0] >= c[1] >= ... 如果 c[h-1] >= h，代表前 h 篇都至少 h 次 -> h 可行。 從 h = 1 往上試，找到最後一個可行的。 【圖形意義】 把排序後的引用數畫成長條圖， h 是「能塞進長條圖左下角的最大正方形」的邊長。 【計數排序：O(n)】 h 最多是 n（論文總數）。 引用數 >= n 的論文，對 h 的判斷來說都一樣 -> 全部歸到 n 這一格。 從 h = n 往下，累加「引用數 >= h 的篇數」， 第一個滿足 total >= h 的 h 就是答案。
解法一

排序

class Solution: def hIndex(self, citations: List[int]) -> int: citations.sort(reverse=True) # 由多到少 h = 0 # ★ 第 i 篇（0 起算）的引用數 >= i+1 -> 至少有 i+1 篇引用 >= i+1 while h < len(citations) and citations[h] >= h + 1: h += 1 return h
複雜度說明
時間O(n log n)
空間O(1)原地排序
解法二

計數排序

class Solution: def hIndex(self, citations: List[int]) -> int: n = len(citations) cnt = [0] * (n + 1) # cnt[k]：引用數恰為 k 的篇數（>= n 的都算在 n） for c in citations: cnt[min(c, n)] += 1 total = 0 # 引用數 >= h 的篇數 for h in range(n, -1, -1): # 從大到小試 total += cnt[h] if total >= h: return h
複雜度說明
時間O(n)
空間O(n)

邊界條件檢查清單

  • 全部是 0 → h = 0。
  • 只有一篇、引用很多（[100]）→ h = 1（受論文數限制）。
  • 每篇引用數都很大 → h = n。
