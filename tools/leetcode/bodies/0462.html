Problem

Given an integer array nums of size n, return the minimum number of moves required to make all array elements equal.

In one move, you can increment or decrement an element of the array by 1.

Test cases are designed so that the answer will fit in a 32-bit integer.

中文翻譯

給你一個整數陣列，每一步可以把任一個元素 +1 或 −1。回傳讓所有元素相等的最少步數。

範例

範例 1 輸入：nums = [1,2,3] 輸出：2 說明：[1,2,3] => [2,2,3] => [2,2,2] 範例 2 輸入：nums = [1,10,2,9] 輸出：16

限制條件

  • 1 ≤ nums.length ≤ 10⁵
  • −10⁹ ≤ nums[i] ≤ 10⁹

LeetCode 原題

解題思路

【選一個目標值 t，總步數 = Σ |x - t|】 要讓絕對距離和最小 -> t 取中位數。 【為什麼是中位數？】 把數排序後，最小和最大配成一對： 不管 t 放在它們之間哪裡，這一對的距離和都是 (max - min)； 放在外面只會更多。 第二小和第二大再配一對…… 中位數同時在所有配對的中間 -> 每一對都達到最小。 【配對的寫法】 答案 = Σ (nums[n-1-i] - nums[i])，i < n/2 完全不需要算出中位數是多少。 【O(n)】 用快速選擇（第 215 題）找中位數，平均 O(n)。
解法一

排序 + 中位數

class Solution: def minMoves2(self, nums: List[int]) -> int: nums.sort() median = nums[len(nums) // 2] # ★ 全部移到中位數，總距離最小 return sum(abs(x - median) for x in nums)
複雜度說明
時間O(n log n)
空間O(1)
解法二

排序 + 頭尾配對

class Solution: def minMoves2(self, nums: List[int]) -> int: nums.sort() i, j, moves = 0, len(nums) - 1, 0 while i < j: # 最小和最大配對：要移動的距離就是它們的差 moves += nums[j] - nums[i] i += 1 j -= 1 return moves
複雜度說明
時間O(n log n)
空間O(1)

邊界條件檢查清單

  • 偶數個元素 → 兩個中位數之間的任何值都一樣好。
  • 只有一個 → 0。

常見追問

中位數 vs 平均數

絕對距離和 Σ|x − t| 的最小值在中位數；平方距離和 Σ(x − t)² 的最小值在平均數。第 296 題（最佳碰頭地點，付費）是二維的中位數問題。
