Problem

Given the head of a singly linked list, reverse the list and return the head of the reversed list.

中文翻譯

給你一個單向鏈結串列的頭節點 head，請把串列反轉，並回傳反轉後的頭節點。

範例

範例 1 輸入：head = [1,2,3,4,5] 輸出：[5,4,3,2,1] 範例 2 輸入：head = [1,2] 輸出：[2,1] 範例 3 輸入：head = [] 輸出：[]

限制條件

  • 串列的節點數在 [0, 5000] 之間
  • −5000 ≤ Node.val ≤ 5000

LeetCode 原題

題目的追問

「A linked list can be reversed either iteratively or recursively. Could you implement both?」

這題是鏈結串列的基本功：第 25、92、234、143 等題都會用到「反轉一段串列」。

解題思路

【反轉 = 把每一個箭頭的方向顛倒】 1 -> 2 -> 3 -> None 變成 None <- 1 <- 2 <- 3 【難點】 改掉 cur.next 的那一刻，就失去了通往後面的路。 所以要先用 nxt 記住後面，再改。 【三個指標的角色】 prev：已經反轉好的那一段的頭 cur ：正在處理的節點 nxt ：還沒處理的那一段的頭（暫存） 【迴圈不變量】 每一輪開始時： prev 之前（含 prev）是反轉好的串列 cur 之後（含 cur）是原本的串列 cur 走到 None -> prev 就是整條反轉好的串列的頭 ✔
解法一

迭代（三指標）

class Solution: def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]: prev, cur = None, head while cur: nxt = cur.next # 1. 先記住下一個 cur.next = prev # 2. 反轉指標 prev = cur # 3. prev 前進 cur = nxt # 4. cur 前進 return prev # ★ cur 走到 None 時，prev 是新的頭

一定要背熟的模板，四行的順序固定：存下一個、改箭頭、prev 前進、cur 前進。

複雜度說明
時間O(n)每個節點一次
空間O(1)三個指標
解法二

遞迴

class Solution: def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]: if head is None or head.next is None: return head new_head = self.reverseList(head.next) # 先把後面反轉好 head.next.next = head # ★ 讓後一個節點指回自己 head.next = None # 斷開舊的指標 return new_head
【遞迴的想法】 假設 head.next 之後的部分已經反轉好了： 1 -> 2 <- 3 <- 4 <- 5 ^ head.next（現在是反轉後的尾巴） 只要讓 2 指回 1：head.next.next = head 再把 1 的 next 清掉：head.next = None 【最容易漏的一行】 head.next = None 漏掉的話，1 和 2 互相指著 -> 環 ✘ 【new_head 一路往上傳】 最深一層回傳原本的尾巴（5）， 每一層都原封不動地回傳它 -> 最後就是新的頭 ✔ 【缺點】 遞迴深度 n = 5000，超過 Python 預設上限 1000。 LeetCode 有調高，但實務上要小心。
複雜度說明
時間O(n)
空間O(n)遞迴堆疊
解法三

堆疊

class Solution: def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]: stack = [] while head: stack.append(head) head = head.next dummy = tail = ListNode() while stack: tail.next = stack.pop() tail = tail.next tail.next = None # ★ 原本的頭現在是尾，要斷開，否則成環 return dummy.next

把節點依序推進堆疊，再依序彈出接起來。最後一定要把尾巴的 next 設成 None，否則原本的頭（現在的尾）還指著第二個節點，形成環。

複雜度說明
時間O(n)
空間O(n)堆疊存 n 個節點

解法對照

解法時間空間備註
一、迭代O(n)O(1)標準答案 ✔
二、遞迴O(n)O(n)要會寫，理解遞迴很好的練習
三、堆疊O(n)O(n)直觀，但要記得斷開尾巴

邊界條件檢查清單

  • 空串列 → 回傳 None。
  • 只有一個節點 → 回傳它自己。
  • 遞迴漏了 head.next = None → 形成環。
  • 堆疊法漏了斷開尾巴 → 形成環。
  • 迭代時先改 cur.next 再存 nxt → 後面的節點全部遺失。

常見追問

追問一：只反轉第 left 到 right 個節點？

這是第 92 題。做法： 1. 用虛擬頭走到第 left-1 個節點 pre。 2. 對接下來的 right-left+1 個節點做「頭插法」： 每次把 cur.next 拿出來，插到 pre 後面。 3. 一次走訪就完成，O(n) 時間、O(1) 空間。

追問二：每 k 個一組反轉？

這是第 25 題（Hard）。 每次先檢查後面是否還有 k 個節點， 有的話用本題的迭代法反轉這 k 個，再接回前後。
