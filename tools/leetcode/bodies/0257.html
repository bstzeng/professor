Problem

Given the root of a binary tree, return all root-to-leaf paths in any order.

A leaf is a node with no children.

中文翻譯

給你一棵二元樹的根節點 root，以任意順序回傳所有「從根到葉」的路徑。

葉節點是沒有任何孩子的節點。

範例

範例 1 輸入：root = [1,2,3,null,5] 輸出：["1->2->5","1->3"] 1 / \ 2 3 \ 5 範例 2 輸入：root = [1] 輸出：["1"]

限制條件

  • 節點數在 [1, 100] 之間
  • −100 ≤ Node.val ≤ 100

LeetCode 原題

解題思路

【DFS + 回溯的標準題】 從根往下走，沿路把值放進 path。 走到葉節點 -> path 就是一條完整路徑，存起來。 離開節點時把它從 path 移除（回溯）， 讓兄弟節點能繼續使用同一個 path。 【判斷葉節點】 左右孩子都是 None。 只有一個孩子的節點不是葉 -> 不能在那裡結束。 （如果改成「走到 None 就存」，範例 1 的節點 2 會多產生一條 "1->2" ✘） 【字串 vs 串列】 每層都 path + "->" + val 產生新字串：寫法簡單， 但每次複製 O(路徑長) -> 總共 O(n · h)。 用串列 append / pop，只在葉節點 join 一次：比較省。
解法一

遞迴 DFS + 回溯

class Solution: def binaryTreePaths(self, root: Optional[TreeNode]) -> List[str]: res = [] path = [] # 目前路徑上的值 def dfs(node): path.append(str(node.val)) if not node.left and not node.right: # ★ 葉節點：一條完整的路徑 res.append("->".join(path)) else: if node.left: dfs(node.left) if node.right: dfs(node.right) path.pop() # 回溯 dfs(root) return res
複雜度說明
時間O(n · h)每條路徑 join 一次
空間O(h)不計輸出
解法二

迭代 DFS（堆疊存路徑字串）

class Solution: def binaryTreePaths(self, root: Optional[TreeNode]) -> List[str]: res = [] stack = [(root, str(root.val))] # (節點, 從根到它的路徑字串) while stack: node, s = stack.pop() if not node.left and not node.right: res.append(s) # 先推右再推左，讓左邊先出來，順序和遞迴版相同 if node.right: stack.append((node.right, s + "->" + str(node.right.val))) if node.left: stack.append((node.left, s + "->" + str(node.left.val))) return res

每個堆疊元素自帶一份到目前為止的路徑字串，不需要回溯。

複雜度說明
時間O(n · h)
空間O(n · h)堆疊裡的字串

解法對照

解法時間空間
一、遞迴 + 回溯O(n·h)O(h) ✔
二、迭代O(n·h)O(n·h)

邊界條件檢查清單

  • 只有根 → ["1"]，沒有箭頭。
  • 負數 → "-1->-2"，照樣轉字串。
  • 只有一個孩子的節點 → 不是葉節點，不能在那裡產生路徑。
