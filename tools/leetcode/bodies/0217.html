Problem

Given an integer array nums, return true if some value occurs at least twice, and false if all values are distinct.

中文翻譯

給你一個整數陣列 nums。如果有任何值出現至少兩次，回傳 true；如果每個值都不同，回傳 false。

範例

範例 1 輸入：nums = [1,2,3,1] 輸出：true 範例 2 輸入：nums = [1,2,3,4] 輸出：false 範例 3 輸入：nums = [1,1,1,3,3,4,3,2,4,2] 輸出：true

限制條件

  • 1 ≤ nums.length ≤ 10⁵
  • −10⁹ ≤ nums[i] ≤ 10⁹

LeetCode 原題

解題思路

【三種思路，對應三種時間/空間取捨】 1. 雜湊集合：邊走邊記，看到見過的就回傳 true。 O(n) 時間、O(n) 空間。 2. 排序：相同的值會相鄰，檢查相鄰元素。 O(n log n) 時間、O(1)~O(n) 空間（看排序是否原地）。 3. 兩兩比較：O(n²)，n = 10^5 時超時 ✘ 【面試時值得說出來的】 - 集合法可以「提早結束」：第一對重複出現就停。 len(set(nums)) 的寫法則一定會處理完整個陣列。 - 如果不能用額外空間，就原地排序（nums.sort()）， 但這會改動輸入 —— 要先確認可不可以。
解法一

雜湊集合，邊走邊查

class Solution: def containsDuplicate(self, nums: List[int]) -> bool: seen = set() for x in nums: if x in seen: return True # ★ 一發現就提早結束 seen.add(x) return False
複雜度說明
時間O(n)
空間O(n)
解法二

比較集合大小（一行）

class Solution: def containsDuplicate(self, nums: List[int]) -> bool: return len(set(nums)) != len(nums)

最簡潔，但一定會建完整個集合——即使前兩個元素就重複了。

複雜度說明
時間O(n)
空間O(n)
解法三

排序後比較相鄰

class Solution: def containsDuplicate(self, nums: List[int]) -> bool: nums = sorted(nums) # 排序後，相同的值一定相鄰 return any(nums[i] == nums[i + 1] for i in range(len(nums) - 1))

sorted 會建立新陣列（O(n) 空間）；改用 nums.sort() 可以原地排序，但會改到輸入。

複雜度說明
時間O(n log n)
空間O(1)~O(n)看排序是否原地

解法對照

解法時間空間備註
一、集合邊走邊查O(n)O(n)可提早結束 ✔
二、集合大小O(n)O(n)一行
三、排序O(n log n)O(1)~O(n)不能用額外空間時

邊界條件檢查清單

  • 只有一個元素 → false。
  • 負數、很大的數 → 集合法不受影響。
  • 全部相同 → true，集合法在第二個元素就結束。
