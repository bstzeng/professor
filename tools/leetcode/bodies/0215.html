Problem

Given an integer array nums and an integer k, return the k-th largest element of the array.

This means the k-th largest in sorted order, counting duplicates — not the k-th largest distinct value.

中文翻譯

給你一個整數陣列 nums 和整數 k，回傳陣列中第 k 大的元素。

這裡指的是排序後的第 k 大（重複的值要分開算），不是「第 k 大的不同值」。

範例

範例 1 輸入：nums = [3,2,1,5,6,4], k = 2 輸出：5 範例 2 輸入：nums = [3,2,3,1,2,4,5,5,6], k = 4 輸出：4 說明：由大到小是 6,5,5,4,…，第 4 個是 4。

限制條件

  • 1 ≤ k ≤ nums.length ≤ 10⁵
  • −10⁴ ≤ nums[i] ≤ 10⁴

LeetCode 原題

題目的追問

「Can you solve it without sorting?」

排序是 O(n log n)。這題想看你會不會用堆積（O(n log k)）或快速選擇（平均 O(n)）。

解題思路

【三個方向】 1. 排序：最簡單，O(n log n)。 2. 大小為 k 的最小堆積： 堆裡永遠保存「目前看過的最大 k 個」。 新元素比堆頂（這 k 個裡最小的）大，就替換掉堆頂。 最後堆頂 = 第 k 大 ✔ O(n log k)，k 小時很快。 3. 快速選擇（Quickselect）： 快速排序的分割，但只遞迴「答案所在的那一邊」。 平均 O(n)，最壞 O(n²)（樞紐每次都選到極端值）。 用隨機樞紐 + 三路切分避免最壞情況。 4. 計數： 值域只有 [-10^4, 10^4]，可以直接數每個值出現幾次。 O(n + 值域)。 【三路切分為什麼重要？】 nums 全部是同一個數時，兩路切分每次只能分出 1 個元素 -> 退化成 O(n²)。 三路切分把「等於樞紐」的全部放在中間，一次就結束 ✔
解法一

排序

class Solution: def findKthLargest(self, nums: List[int], k: int) -> int: return sorted(nums, reverse=True)[k - 1]

一行解。面試時可以先說出來，再說明追問要求更快的做法。

複雜度說明
時間O(n log n)
空間O(n)
解法二

大小為 k 的最小堆積

class Solution: def findKthLargest(self, nums: List[int], k: int) -> int: heap = nums[:k] heapq.heapify(heap) # 大小為 k 的最小堆積 for x in nums[k:]: if x > heap[0]: heapq.heapreplace(heap, x) # 踢掉目前第 k 大（最小的那個） return heap[0] # ★ 堆頂就是第 k 大
【為什麼用「最小」堆積找「第 k 大」？】 我們要保留最大的 k 個， 需要隨時能踢掉「這 k 個裡最小的」—— 最小堆積的堆頂正好就是它。 【heapreplace 比 heappop + heappush 快】 一次完成「彈出堆頂、放入新元素」。
複雜度說明
時間O(n log k)
空間O(k)
解法三

快速選擇（三路切分 + 隨機樞紐）

class Solution: def findKthLargest(self, nums: List[int], k: int) -> int: def select(a: List[int], k: int) -> int: pivot = random.choice(a) # ★ 隨機樞紐，避免最壞情況 big = [x for x in a if x > pivot] eq = [x for x in a if x == pivot] if k <= len(big): return select(big, k) if k <= len(big) + len(eq): return pivot # ★ 三路切分：大量重複值也不會退化 small = [x for x in a if x < pivot] return select(small, k - len(big) - len(eq)) return select(nums, k)

每次期望把問題規模縮小一個常數比例：n + n/2 + n/4 + … = 平均 O(n)。這個寫法用額外的 list 讓邏輯清楚；原地版本（Hoare / Lomuto 分割）空間更省，但更容易寫錯。

複雜度說明
時間平均 O(n)最壞 O(n²)，機率極低
空間O(n)切分用的 list
解法四

計數（利用值域很小）

class Solution: def findKthLargest(self, nums: List[int], k: int) -> int: lo = min(nums) cnt = [0] * (max(nums) - lo + 1) # 值域只有 2×10^4 + 1 種 for x in nums: cnt[x - lo] += 1 for v in range(len(cnt) - 1, -1, -1): # 從大到小數 k -= cnt[v] if k <= 0: return v + lo

只有在值域有界時才能用。這題值域只有 20001 種，O(n + 值域)，實測非常快。

複雜度說明
時間O(n + V)V = 值域大小
空間O(V)

解法對照

解法時間空間備註
一、排序O(n log n)O(n)最簡單
二、最小堆積O(n log k)O(k)也適用於資料串流 ✔
三、快速選擇平均 O(n)O(n)要三路切分防退化
四、計數O(n + V)O(V)值域小時最快

邊界條件檢查清單

  • 有重複值 → 重複的要分開算（範例 2）。
  • k = 1 → 最大值；k = n → 最小值。
  • 全部相同 → 兩路切分的快速選擇會退化成 O(n²)。
  • 用最大堆積彈 k 次 → 也對，O(n + k log n)；Python 要把值取負號。
