Problem

You are given an integer array coins representing coins of different denominations and an integer amount representing a total amount of money.

Return the number of combinations that make up that amount. If that amount of money cannot be made up by any combination of the coins, return 0.

You may assume that you have an infinite number of each kind of coin.

The final answer is guaranteed to fit into a signed 32-bit integer.

中文翻譯

給你不同面額的硬幣 coins 和總金額 amount，每種硬幣數量無限。回傳湊出 amount 的組合數；湊不出來則回傳 0。

（1, 2 和 2, 1 算同一種組合。）答案保證在 32 位元有號整數範圍內。

範例

範例 1 輸入：amount = 5, coins = [1,2,5] 輸出：4 範例 2 輸入：amount = 3, coins = [2] 輸出：0 範例 3 輸入：amount = 10, coins = [10] 輸出：1

限制條件

  • 1 ≤ coins.length ≤ 300
  • 1 ≤ coins[i] ≤ 5000
  • coins 中的元素互不相同
  • 0 ≤ amount ≤ 5000

LeetCode 原題

解題思路

【完全背包】 dp[x] = 湊出金額 x 的組合數，dp[0] = 1。 用硬幣 c 更新：dp[x] += dp[x - c]。 x 由小到大 -> dp[x - c] 可能已經用過 c -> 允許重複使用。 【迴圈順序決定是「組合」還是「排列」】 外層硬幣、內層金額： 先處理完所有 1，再處理 2…… 每種組合只會以「1 都在 2 前面」的順序出現一次 -> 組合數（本題）。 外層金額、內層硬幣： 每個金額都嘗試「最後一枚是哪個硬幣」 1+2 和 2+1 會被分別數到 -> 排列數（第 377 題）。
解法

完全背包（組合數）

class Solution: def change(self, amount: int, coins: List[int]) -> int: dp = [0] * (amount + 1) # dp[x]：湊出 x 的組合數 dp[0] = 1 # 什麼都不選，湊出 0 for c in coins: # ★ 外層是硬幣：每種組合只會以固定的硬幣順序被數一次 for x in range(c, amount + 1): dp[x] += dp[x - c] # 由小到大 -> 同一種硬幣可以重複用 return dp[amount]

驗證方式：和記憶化遞迴（「用第 i 種硬幣」或「跳到下一種」）比對 1000 組。

複雜度說明
時間O(amount · len(coins))
空間O(amount)

邊界條件檢查清單

  • amount = 0 → 1（空組合）。
  • 湊不出來 → 0。
  • 迴圈順序寫反 → 會變成排列數。
