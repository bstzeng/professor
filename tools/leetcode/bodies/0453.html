Problem

Given an integer array nums of size n, return the minimum number of moves required to make all array elements equal.

In one move, you can increment n - 1 elements of the array by 1.

中文翻譯

給你一個長度為 n 的整數陣列，每一步可以把其中 n − 1 個元素各加 1。回傳讓所有元素相等的最少步數。

範例

範例 1 輸入：nums = [1,2,3] 輸出：3 說明：[1,2,3] => [2,3,3] => [3,4,3] => [4,4,4] 範例 2 輸入：nums = [1,1,1] 輸出：0

限制條件

  • 1 ≤ nums.length ≤ 10⁵
  • −10⁹ ≤ nums[i] ≤ 10⁹
  • 答案保證在 32 位元整數範圍內

LeetCode 原題

解題思路

【換個角度：相對差距】 我們只在乎「所有數相等」，也就是它們之間的差距都是 0。 「n-1 個數各加 1」對差距的影響， 和「剩下那 1 個數減 1」完全一樣。 【所以問題變成：每一步把一個數減 1】 所有數都要減到最小值 -> 步數 = Σ (x - min) 【為什麼是減到最小值而不是更小？】 減到比最小值更小，每個數都要多減一樣多次，只會更多。
解法

轉換成「一個數減 1」

class Solution: def minMoves(self, nums: List[int]) -> int: # ★ 「n-1 個數各加 1」等價於「1 個數減 1」（相對大小的變化一樣） # 所以問題變成：把所有數減到和最小值一樣，要減幾次 m = min(nums) return sum(x - m for x in nums)

驗證方式：和「每次把最大值以外的數加 1」的直接模擬比對。

複雜度說明
時間O(n)
空間O(1)

邊界條件檢查清單

  • 已經全部相等 → 0。
  • 只有一個數 → 0。
  • 負數 → 公式照樣成立。
