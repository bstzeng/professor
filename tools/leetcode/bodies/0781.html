Problem

There is a forest with an unknown number of rabbits. We asked n rabbits "How many other rabbits have the same color as you?" and collected the answers in an integer array answers where answers[i] is the answer of the ith rabbit.

Given the array answers, return the minimum number of rabbits that could be in the forest.

中文翻譯

森林裡有一些兔子，每隻兔子有一種顏色。你問了其中一些兔子：「還有多少隻兔子跟你同色？」答案記在 answers 中。

回傳森林中兔子的最少數量。

範例

範例 1 輸入：answers = [1,1,2] 輸出：5 範例 2 輸入：answers = [10,10,10] 輸出：11

限制條件

  • 1 ≤ answers.length ≤ 1000
  • 0 ≤ answers[i] < 1000

LeetCode 原題

解題思路

【回答 x 的意思】 牠的顏色共有 x + 1 隻（包含自己）。 【同樣回答 x 的兔子】 可能是同一種顏色，但一種顏色最多只能容納 x+1 隻回答者。 c 隻回答 x -> 至少 ⌈c / (x+1)⌉ 種顏色， 每種顏色都有 x+1 隻（沒被問到的也算）。 貢獻 ⌈c / (x+1)⌉ × (x+1)。 【回答不同的兔子】 一定是不同顏色（同色的回答必須相同），各自獨立計算。
解法

分組計數

class Solution: def numRabbits(self, answers: List[int]) -> int: res = 0 for x, c in Counter(answers).items(): g = x + 1 # 回答 x 的兔子，同色的一群恰好 x+1 隻 res += -(-c // g) * g # ★ c 隻回答 x 的兔子至少需要 ⌈c / g⌉ 群 return res
複雜度說明
時間O(n)
空間O(n)

邊界條件檢查清單

  • 回答 0 → 每隻都是獨一無二的顏色。
  • [10, 10, 10] → 同一群就夠，11 隻。
  • [1, 1, 1] → 一群最多 2 隻，需要兩群，4 隻。

常見追問

向上取整

Python 中 ⌈a / b⌉ 可以寫成 −(−a // b)，避免浮點數；其他語言常寫成 (a + b − 1) / b。
