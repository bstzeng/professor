Problem

Given a string expression representing an expression of fraction addition and subtraction, return the calculation result in string format.

The final result should be an irreducible fraction. If your final result is an integer, change it to the format of a fraction that has a denominator 1. So in this case, 2 should be converted to 2/1.

中文翻譯

給你一個只含分數加減的運算式字串，例如 "-1/2+1/2+1/3"，回傳計算結果的字串。

結果必須是最簡分數；若結果是整數，也要寫成分母為 1 的分數，例如 "2/1"。

範例

範例 1 輸入：expression = "-1/2+1/2" 輸出："0/1" 範例 2 輸入：expression = "-1/2+1/2+1/3" 輸出："1/3" 範例 3 輸入：expression = "1/3-1/2" 輸出："-1/6"

限制條件

  • The input string only contains '0' to '9', '/', '+' and '-'. So does the output.
  • Each fraction (input and output) has the format ±numerator/denominator. If the first input fraction or the output is positive, then '+' will be omitted.
  • The input only contains valid irreducible fractions, where the numerator and denominator of each fraction will always be in the range [1, 10]. If the denominator is 1, it means this fraction is actually an integer in a fraction format defined above.
  • The number of given fractions will be in the range [1, 10].
  • The numerator and denominator of the final result are guaranteed to be valid and in the range of 32-bit int.

LeetCode 原題

解題思路

【切出每個分數】 正規表示式 ([+-]?\d+)/(\d+)： 分子連同前面的正負號一起抓，省去處理運算子。 【通分相加】 a/b + c/d = (a·d + c·b) / (b·d) 每次加完用 gcd 約分，數字不會爆大。 【符號】 分母永遠是正的，負號都在分子上； gcd 對負數也回傳正值，約分後符號保持在分子。
解法

正規表示式 + 逐一通分

class Solution: def fractionAddition(self, expression: str) -> str: num, den = 0, 1 for a, b in re.findall(r"([+-]?\d+)/(\d+)", expression): # 每個分數連同正負號一起抓 a, b = int(a), int(b) num, den = num * b + a * den, den * b # ★ 通分相加 g = math.gcd(num, den) num, den = num // g, den // g # 隨時約分，避免數字變大 return "%d/%d" % (num, den)

驗證方式：和 Python 的 Fraction 精確計算比對 2000 個隨機運算式。

複雜度說明
時間O(k · log M)k 個分數
空間O(1)

邊界條件檢查清單

  • 結果為 0 → "0/1"。
  • 開頭是負號 → 正規表示式把它併入第一個分子。
  • 結果是整數 → 分母 1。
