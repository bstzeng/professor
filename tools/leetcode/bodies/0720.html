Problem

Given an array of strings words representing an English Dictionary, return the longest word in words that can be built one character at a time by other words in words.

If there is more than one possible answer, return the longest word with the smallest lexicographical order. If there is no answer, return the empty string.

Note that the word should be built from left to right with each additional character being added to the end of a previous word. 

中文翻譯

給你一個字串陣列 words，找出最長的單字，使得它能由陣列中的其他單字每次加一個字母逐步建出（它的每個前綴都在陣列中）。

若有多個，回傳字典序最小的；沒有則回傳空字串。

範例

範例 1 輸入：words = ["w","wo","wor","worl","world"] 輸出："world" 範例 2 輸入：words = ["a","banana","app","appl","ap","apply","apple"] 輸出："apple"

限制條件

  • 1 ≤ words.length ≤ 1000
  • 1 ≤ words[i].length ≤ 30
  • words[i] 只含小寫英文字母

LeetCode 原題

解題思路

【能被建出的條件】 w 的每個前綴都在 words 中 <=> w[:-1] 能被建出，而且 w 在 words 中。 （歸納：一路往回推到單一字母。） 【排序後依序處理】 字典序排序保證 w[:-1] 在 w 之前出現， 所以處理 w 時已經知道 w[:-1] 能不能建出。 【平手】 同長度時字典序小的先被處理，只有「更長」才更新答案。 【字典樹】 把所有單字插入字典樹，從根做 DFS， 只走「節點本身是某個單字結尾」的路徑，最深的就是答案。
解法

排序 + 雜湊集合

class Solution: def longestWord(self, words: List[str]) -> str: ok = {""} # 可以「一次加一個字母」逐步建出來的單字 best = "" for w in sorted(words): # 依字典序排序：前綴一定排在它前面 if w[:-1] in ok: # ★ 去掉最後一個字母後也能建出來 ok.add(w) if len(w) > len(best): # 同長度時，先出現的字典序較小，不更新 best = w return best

驗證方式：和「檢查每個單字的所有前綴是否都在集合中」的暴力法比對 2000 組。

複雜度說明
時間O(Σ L log n)排序比較字串的成本
空間O(Σ L)

邊界條件檢查清單

  • 沒有單一字母的單字 → ""。
  • 同長度 → 字典序小的。
