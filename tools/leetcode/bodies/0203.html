Problem

You are given the head of a singly linked list and an integer val. Delete every node whose value equals val, and return the head of the resulting list.

中文翻譯

給你一個單向鏈結串列的頭節點 head 和一個整數 val，請刪除所有值等於 val 的節點，並回傳新的頭節點。

範例

範例 1 輸入：head = [1,2,6,3,4,5,6], val = 6 輸出：[1,2,3,4,5] 範例 2 輸入：head = [], val = 1 輸出：[] 範例 3 輸入：head = [7,7,7,7], val = 7 輸出：[]

限制條件

  • 串列的節點數在 [0, 10⁴] 之間
  • 1 ≤ Node.val ≤ 50
  • 0 ≤ val ≤ 50

LeetCode 原題

解題思路

【刪除一個節點，需要的是它的「前一個」節點】 prev -> target -> after prev.next = after # target 就被跳過了 【麻煩在頭節點】：頭節點沒有前一個節點。 範例 3 [7,7,7,7] 的每一個節點都要刪， 包括頭 —— 如果把「刪頭」和「刪中間」分開寫， 很容易漏掉「連續好幾個頭都要刪」的情況。 【解法：虛擬頭節點（dummy node）】 dummy -> 7 -> 7 -> 7 -> 7 現在每個真正的節點都有「前一個」了， 刪頭和刪中間變成同一件事 ✔ 最後回傳 dummy.next。 【一個容易錯的細節】 刪掉 prev.next 之後，prev 【不要】前進 —— 新的 prev.next 還沒檢查過，它可能也要刪。 [1, 6, 6, 2]，val = 6： prev=1，刪第一個 6 -> prev 還是 1 prev=1，刪第二個 6 -> prev 還是 1 prev=1，下一個是 2，保留，前進 ✔
解法一

虛擬頭節點 + 一次走訪

class Solution: def removeElements(self, head: Optional[ListNode], val: int) -> Optional[ListNode]: dummy = ListNode(0, head) # ★ 虛擬頭節點：頭也能被刪 prev = dummy while prev.next: if prev.next.val == val: prev.next = prev.next.next # 刪掉，prev 不動 else: prev = prev.next # 保留，prev 前進 return dummy.next

虛擬頭節點是鏈結串列題最常用的技巧，只要「頭節點可能會變」就可以考慮它。

複雜度說明
時間O(n)每個節點看一次
空間O(1)只有一個 dummy
解法二

遞迴

class Solution: def removeElements(self, head: Optional[ListNode], val: int) -> Optional[ListNode]: if head is None: return None head.next = self.removeElements(head.next, val) # 先處理後面 return head.next if head.val == val else head
【遞迴的想法】 removeElements(head) = 先把 head 後面的串列處理好（遞迴），接回 head.next， 再決定 head 自己要不要留。 【為什麼不推薦在實務上用？】 串列最長 10^4，遞迴深度也是 10^4， 超過 Python 預設的遞迴上限（約 1000）-> RecursionError ✘ LeetCode 的 Python 環境有調高上限，所以能過， 但這是一個值得在面試中主動點出的風險。
複雜度說明
時間O(n)
空間O(n)遞迴堆疊深度 n
解法三

不用虛擬頭節點

class Solution: def removeElements(self, head: Optional[ListNode], val: int) -> Optional[ListNode]: while head and head.val == val: # 先把開頭連續要刪的去掉 head = head.next cur = head while cur and cur.next: if cur.next.val == val: cur.next = cur.next.next else: cur = cur.next return head

先用一個 while 把開頭連續要刪的節點去掉，剩下的頭就一定要保留，再用一般的方式處理後面。能做，但要多寫一個迴圈，也多一個出錯的地方。

複雜度說明
時間O(n)
空間O(1)

解法對照

解法時間空間備註
一、虛擬頭節點O(n)O(1)推薦 ✔
二、遞迴O(n)O(n)簡潔，但長串列有遞迴深度風險

邊界條件檢查清單

  • 空串列 → 回傳 None。
  • 全部都要刪 → 回傳 None。
  • 開頭連續好幾個要刪 → 虛擬頭節點自然處理。
  • 連續好幾個要刪 → 刪完之後 prev 不能前進。
  • val 不在串列裡 → 原樣回傳。

常見追問

追問一：如果是雙向鏈結串列呢？

刪除節點 x 時要改兩個指標： x.prev.next = x.next if x.next: x.next.prev = x.prev 同樣可以用虛擬頭（甚至虛擬尾）避免邊界判斷。

追問二：虛擬頭節點還能用在哪些題？

  • 第 19 題 刪除倒數第 N 個節點：刪的可能是頭。
  • 第 21 題 合併兩個有序串列：從 dummy 開始接。
  • 第 82 題 刪除排序串列中的重複元素 II：頭可能整段被刪。
