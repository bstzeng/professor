Problem

Given an integer n, return true if it is a power of four. Otherwise, return false.

An integer n is a power of four, if there exists an integer x such that n == 4x.

Follow up: Could you solve it without loops/recursion?

中文翻譯

給你一個整數 n，判斷它是不是 4 的冪次（存在整數 x 使 n == 4x）。

進階：能不用迴圈或遞迴嗎？

範例

範例 1 輸入：n = 16 輸出：true 範例 2 輸入：n = 5 輸出：false 範例 3 輸入：n = 1 輸出：true

限制條件

  • −2³¹ ≤ n ≤ 2³¹ − 1

解題思路

【4 的冪一定是 2 的冪】 4^k = 2^(2k) -> 二進位只有一個 1，而且在【偶數位】： 1 = 1 （第 0 位） 4 = 100 （第 2 位） 16 = 10000 （第 4 位） 2 的冪但不是 4 的冪：2 = 10、8 = 1000 —— 1 在奇數位。 【方法一：遮罩】 0x55555555 = 0101 0101 ... 0101（所有偶數位都是 1） n & 0x55555555 != 0 <=> 那個唯一的 1 在偶數位。 【方法二：mod 3】 4 ≡ 1 (mod 3) -> 4^k ≡ 1 (mod 3) 2·4^k ≡ 2 (mod 3) 所以 2 的冪中，mod 3 == 1 的就是 4 的冪。 【不能用 3 的冪那招】 4 不是質數：2 也整除 4^15，但 2 不是 4 的冪。

解法一

2 的冪 + 偶數位遮罩

class Solution: def isPowerOfFour(self, n: int) -> bool: # ★ 2 的冪（只有一個 1），而且那個 1 在偶數位（第 0、2、4… 位） return n > 0 and n & (n - 1) == 0 and n & 0x55555555 != 0
複雜度說明
時間O(1)
空間O(1)
解法二

2 的冪 + mod 3

class Solution: def isPowerOfFour(self, n: int) -> bool: # 4^k ≡ 1 (mod 3)，而 2·4^k ≡ 2 (mod 3) return n > 0 and n & (n - 1) == 0 and n % 3 == 1
複雜度說明
時間O(1)
空間O(1)

邊界條件檢查清單

  • n = 1 → true（4⁰）。
  • 2 的奇數次冪（2、8、32…）→ 是 2 的冪但不是 4 的冪。
  • n ≤ 0 → false。
