Problem

Given an array nums containing n distinct numbers in the range [0, n], return the only number in the range that is missing from the array.

Follow up: Could you implement a solution using only O(1) extra space complexity and O(n) runtime complexity?

中文翻譯

給你一個陣列 nums，包含 [0, n] 範圍內 n 個互不相同的數字，找出範圍內唯一缺少的那個數。

進階：能用 O(1) 額外空間、O(n) 時間完成嗎？

範例

範例 1 輸入：nums = [3,0,1] 輸出：2 說明：n = 3，範圍 [0, 3]，缺少 2。 範例 2 輸入：nums = [0,1] 輸出：2 說明：n = 2，範圍 [0, 2]，缺少 2。 範例 3 輸入：nums = [9,6,4,2,3,5,7,0,1] 輸出：8

限制條件

  • n == nums.length
  • 1 ≤ n ≤ 10⁴
  • 0 ≤ nums[i] ≤ n
  • nums 中的數字互不相同

LeetCode 原題

解題思路

【n+1 個候選，只拿到 n 個】 【方法一：高斯求和】 0 + 1 + ... + n = n(n+1)/2 減掉陣列實際總和 = 缺的那個數。 （其他語言要注意溢位；n ≤ 10⁴ 時沒問題。） 【方法二：XOR】 把 0..n 全部 XOR，再和陣列所有元素 XOR： 出現兩次的都抵銷，只剩缺的那個。 技巧：索引 i 剛好是 0..n-1，再補一個 n -> 一次迴圈完成。 【方法三：排序後二分】 排序後，缺的數之前 nums[i] == i，之後 nums[i] == i + 1。 找第一個 nums[i] != i 的位置。 如果陣列本來就排好序，這是 O(log n)。
解法一

雜湊集合

class Solution: def missingNumber(self, nums: List[int]) -> int: s = set(nums) for x in range(len(nums) + 1): if x not in s: return x
複雜度說明
時間O(n)
空間O(n)
解法二

排序 + 二分

class Solution: def missingNumber(self, nums: List[int]) -> int: nums.sort() lo, hi = 0, len(nums) # 找第一個 nums[i] != i 的位置 while lo < hi: mid = (lo + hi) // 2 if nums[mid] == mid: lo = mid + 1 else: hi = mid return lo
複雜度說明
時間O(n log n)已排序時 O(log n)
空間O(1)原地排序
解法三

高斯求和

class Solution: def missingNumber(self, nums: List[int]) -> int: n = len(nums) return n * (n + 1) // 2 - sum(nums) # ★ 0+1+...+n 減掉實際總和
複雜度說明
時間O(n)
空間O(1)
解法四

XOR

class Solution: def missingNumber(self, nums: List[int]) -> int: res = len(nums) # 先放 n（索引只到 n-1） for i, x in enumerate(nums): res ^= i ^ x # 索引 0..n-1 和值配對抵銷 return res

和求和法的想法一樣（成對抵銷），但不會溢位。

複雜度說明
時間O(n)
空間O(1)

解法對照

解法時間空間備註
一、集合O(n)O(n)
二、排序 + 二分O(n log n)O(1)會修改輸入
三、求和O(n)O(1)最簡潔 ✔
四、XORO(n)O(1)不怕溢位

邊界條件檢查清單

  • 缺的是 0 → 求和法照樣成立。
  • 缺的是 n（[0,1]）→ 二分法的 hi 要從 n 開始。
  • n = 1 → [0] 缺 1，[1] 缺 0。
