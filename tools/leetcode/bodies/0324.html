Problem

Given an integer array nums, reorder it such that nums[0] < nums[1] > nums[2] < nums[3]....

You may assume the input array always has a valid answer.

Follow Up: Can you do it in O(n) time and/or in-place with O(1) extra space?

中文翻譯

給你一個整數陣列 nums，把它重新排列成 nums[0] < nums[1] > nums[2] < nums[3]...（嚴格的一小一大交錯）。

保證一定有合法的答案。

進階：能在 O(n) 時間、O(1) 額外空間內原地完成嗎？

範例

範例 1 輸入：nums = [1,5,1,1,6,4] 輸出：[1,6,1,5,1,4] 說明：[1,4,1,5,1,6] 也可以。 範例 2 輸入：nums = [1,3,2,2,3,1] 輸出：[2,3,1,3,1,2]

限制條件

  • 1 ≤ nums.length ≤ 5 × 10⁴
  • 0 ≤ nums[i] ≤ 5000
  • 保證有合法答案

LeetCode 原題

解題思路

【直覺：小的放偶數位置、大的放奇數位置】 排序後切成兩半：小半 S、大半 L，交錯放 S L S L ... 每個 L 都 >= 兩邊的 S。 【陷阱：中位數重複】 nums = [4, 5, 5, 6] 小半 [4, 5]、大半 [5, 6] 順著放：4 5 5 6 -> 5 和 5 相鄰，5 < 5 不成立 ✘ 【解法：兩半都「反轉」再交錯】 小半反轉 [5, 4]、大半反轉 [6, 5] 交錯：5 6 4 5 ✔ 反轉後，小半的中位數被放到最前面，大半的中位數被放到最後面， 相等的中位數在陣列中離得最遠，不會相鄰。 【O(n) 時間】 值域只有 0..5000 -> 計數排序。 （更一般的 O(n) + O(1) 空間做法：快速選擇找中位數 + 三向切分 + 虛擬索引映射， 非常精巧但不好寫。）
排序後 [1, 1, 1, 4, 5, 6] 小半反轉 [1, 1, 1] 大半反轉 [6, 5, 4] 交錯 1 6 1 5 1 4 ✔
解法一

排序 + 兩半反轉交錯

class Solution: def wiggleSort(self, nums: List[int]) -> None: """ Do not return anything, modify nums in-place instead. """ s = sorted(nums) half = (len(nums) + 1) // 2 # ★ 小的一半、大的一半各自「反轉」後交錯放：避免相等的中位數相鄰 nums[::2] = s[:half][::-1] # 偶數位置放較小的一半（由大到小） nums[1::2] = s[half:][::-1] # 奇數位置放較大的一半（由大到小）
複雜度說明
時間O(n log n)
空間O(n)
解法二

計數排序（值域小）

class Solution: def wiggleSort(self, nums: List[int]) -> None: cnt = [0] * 5001 # 值域 0..5000：計數排序 for x in nums: cnt[x] += 1 v = 5000 # 先填奇數位置（放大的），再填偶數位置，都從大到小取 for start in (1, 0): for i in range(start, len(nums), 2): while cnt[v] == 0: v -= 1 nums[i] = v cnt[v] -= 1

從最大值開始，先填滿所有奇數位置，再填偶數位置——和解法一的「反轉交錯」是同一個排列。

複雜度說明
時間O(n + V)V = 值域大小 5001
空間O(V)

解法對照

解法時間空間
一、排序O(n log n)O(n)
二、計數排序O(n + V)O(V) ✔

邊界條件檢查清單

  • 中位數重複很多次 → 一定要反轉，否則相等元素會相鄰。
  • 奇數長度 → 小半比大半多一個（偶數位置比較多）。
  • n = 1 → 不變。

常見追問

第 280 題（付費）

Wiggle Sort I 允許相等（≤ ≥ ≤），只要一趟掃描：相鄰兩個不符合就交換，O(n)。嚴格版本就難多了。
