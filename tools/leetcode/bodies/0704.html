Problem

Given an array of integers nums which is sorted in ascending order, and an integer target, write a function to search target in nums. If target exists, then return its index. Otherwise, return -1.

You must write an algorithm with O(log n) runtime complexity.

中文翻譯

給你一個遞增排序、元素互不相同的整數陣列 nums 和 target，找到 target 的索引，不存在則回傳 -1。要求 O(log n)。

範例

範例 1 輸入：nums = [-1,0,3,5,9,12], target = 9 輸出：4 範例 2 輸入：nums = [-1,0,3,5,9,12], target = 2 輸出：-1

限制條件

  • 1 ≤ nums.length ≤ 10⁴
  • -10⁴ < nums[i], target < 10⁴
  • nums 中的元素互不相同
  • nums 已依非遞減順序排序

LeetCode 原題

解題思路

【閉區間模板】 搜尋範圍 [lo, hi]，兩端都可能是答案。 lo <= hi 時範圍非空，繼續： nums[mid] == target -> 找到 nums[mid] < target -> 答案在 [mid+1, hi] nums[mid] > target -> 答案在 [lo, mid-1] mid 已經檢查過，下一輪不包含它 -> 範圍一定縮小，不會無窮迴圈。 【常見錯誤】 區間定義和迴圈條件、更新方式不一致： 例如用 [lo, hi) 半開區間卻寫 lo <= hi，或寫 hi = mid 卻用閉區間。
解法

閉區間二分

class Solution: def search(self, nums: List[int], target: int) -> int: lo, hi = 0, len(nums) - 1 # 搜尋範圍 [lo, hi]（閉區間） while lo <= hi: mid = (lo + hi) // 2 if nums[mid] == target: return mid if nums[mid] < target: lo = mid + 1 # ★ target 在右半邊，mid 本身已經排除 else: hi = mid - 1 return -1
複雜度說明
時間O(log n)
空間O(1)

邊界條件檢查清單

  • 只有一個元素 → lo == hi 時仍要檢查。
  • target 比全部都小或都大 → −1。

常見追問

整數溢位

其他語言中 (lo + hi) / 2 可能溢位，改寫成 lo + (hi − lo) / 2。Java 的 Arrays.binarySearch 曾經就有這個 bug（2006 年才修正）。
