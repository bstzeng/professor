Problem

There are buckets buckets of liquid, where exactly one of the buckets is poisonous. To figure out which one is poisonous, you feed some number of (poor) pigs the liquid to see whether they will die or not. Unfortunately, you only have minutesToTest minutes to determine which bucket is poisonous.

You can feed the pigs according to these steps:

  1. Choose some live pigs to feed.
  2. For each pig, choose which buckets to feed it. The pig will consume all the chosen buckets simultaneously and will take no time. Each pig can feed from any number of buckets, and each bucket can be fed from by any number of pigs.
  3. Wait for minutesToDie minutes. You may not feed any other pigs during this time.
  4. After minutesToDie minutes have passed, any pigs that have been fed the poisonous bucket will die, and all others will survive.
  5. Repeat this process until you run out of time.

Given buckets, minutesToDie, and minutesToTest, return the minimum number of pigs needed to figure out which bucket is poisonous within the allotted time.

中文翻譯

有 buckets 桶液體，其中恰好一桶有毒。你可以讓豬喝液體，看牠會不會死，來找出毒桶。總共只有 minutesToTest 分鐘。

每一輪：選一些活著的豬，讓每隻豬同時喝任意幾桶（每桶也可以給任意多隻豬喝），然後等 minutesToDie 分鐘，喝到毒的豬會死。時間夠就可以再進行下一輪。

回傳能保證找出毒桶的最少豬數。

範例

範例 1 輸入：buckets = 4, minutesToDie = 15, minutesToTest = 15 輸出：2 說明：只有一輪。豬 A 喝 1、2 桶，豬 B 喝 2、3 桶： 都活著 → 第 4 桶；只有 A 死 → 第 1 桶； 只有 B 死 → 第 3 桶；都死 → 第 2 桶。 範例 2 輸入：buckets = 1000, minutesToDie = 15, minutesToTest = 60 輸出：5

限制條件

  • 1 ≤ buckets ≤ 1000
  • 1 ≤ minutesToDie ≤ minutesToTest ≤ 100

LeetCode 原題

解題思路

【資訊量的角度】 可以進行 T = minutesToTest / minutesToDie 輪。 一隻豬的「結局」有 T + 1 種： 第 1 輪死、第 2 輪死、……、第 T 輪死、活到最後。 p 隻豬的結局組合有 (T + 1)^p 種， 每一種組合要對應到一個桶 -> 需要 (T + 1)^p >= buckets。 【真的做得到嗎？—— 用 (T+1) 進位編號】 把桶編號寫成 p 位的 (T+1) 進位數。 第 k 隻豬負責第 k 位： 第 r 輪，喝「第 k 位是 r-1」的所有桶。 豬在第 r 輪死 -> 毒桶的第 k 位是 r-1； 活到最後 -> 第 k 位是 T。 p 隻豬的結果剛好拼出毒桶的完整編號。 【範例 1：T = 1，2 種結局】 2 隻豬 -> 2² = 4 >= 4 桶 ✔（就是二進位編號）
桶編號（二進位）豬 A 喝？（第 1 位）豬 B 喝？（第 0 位）
0 = 00
1 = 01✔
2 = 10✔
3 = 11✔✔
解法

資訊量：(T+1)^p ≥ buckets

class Solution: def poorPigs(self, buckets: int, minutesToDie: int, minutesToTest: int) -> int: states = minutesToTest // minutesToDie + 1 # ★ 每隻豬的結局有幾種：第 1 輪死、第 2 輪死……或活到最後 pigs = 0 while states ** pigs < buckets: # pigs 隻豬能區分 states^pigs 種情況 pigs += 1 return pigs
複雜度說明
時間O(log buckets)
空間O(1)

邊界條件檢查清單

  • 只有 1 桶 → 0 隻豬（不用測就知道）。
  • T = 0（minutesToTest < minutesToDie）→ 題目限制保證至少一輪。
  • 用浮點 log 計算 → 邊界可能差 1，用整數次方比較最安全。

常見追問

資訊論下界

這題是「用最少的測試分辨 N 種可能」的經典模型：每次測試有 k 種結果，需要 log_k N 次。二分搜尋（k = 2）、秤重找假幣（k = 3，天平有三種結果）都是它的特例。
