Problem

Given a string s and a string array dictionary, return the longest string in the dictionary that can be formed by deleting some of the given string characters. If there is more than one possible result, return the longest word with the smallest lexicographical order. If there is no possible result, return the empty string.

中文翻譯

給你字串 s 和字串陣列 dictionary，找出字典中最長、而且可以由 s 刪除一些字元得到的單字。

若有多個，回傳字典序最小的；都不行則回傳空字串。

範例

範例 1 輸入：s = "abpcplea", dictionary = ["ale","apple","monkey","plea"] 輸出："apple" 範例 2 輸入：s = "abpcplea", dictionary = ["a","b","c"] 輸出："a"

限制條件

  • 1 ≤ s.length ≤ 1000
  • 1 ≤ dictionary.length ≤ 1000
  • 1 ≤ dictionary[i].length ≤ 1000
  • s and dictionary[i] 只含小寫英文字母

LeetCode 原題

解題思路

【「刪除一些字元得到」= 子序列】 逐一檢查每個單字是不是 s 的子序列（雙指標 O(|s|)）。 【挑最好的】 更長的優先；一樣長時字典序小的優先。 【小最佳化】 先比較「這個單字有沒有可能比目前答案好」， 有可能才做子序列檢查，省掉很多無用功。 【另一種寫法】 先依 (-長度, 字典序) 排序字典，第一個是子序列的就是答案。
解法

逐一子序列判斷

class Solution: def findLongestWord(self, s: str, dictionary: List[str]) -> str: best = "" for w in dictionary: # 比較條件：更長，或一樣長但字典序更小 if len(w) > len(best) or (len(w) == len(best) and w < best): it = iter(s) if all(c in it for c in w): # ★ w 是 s 的子序列（雙指標） best = w return best

邊界條件檢查清單

  • 沒有任何單字符合 → ""。
  • 同長度比字典序 → "a" 勝過 "b"。

字典很大時

預處理 s：next[i][c] = 位置 i 之後第一個字元 c 的位置。之後每個單字的子序列判斷只要 O(|w|)，和第 792 題（匹配子序列的單字數）相同。
