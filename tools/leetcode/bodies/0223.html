Problem

Two axis-aligned rectangles are given in the plane. Rectangle A has bottom-left corner (ax1, ay1) and top-right corner (ax2, ay2); rectangle B has bottom-left corner (bx1, by1) and top-right corner (bx2, by2).

Return the total area covered by the two rectangles together.

中文翻譯

平面上有兩個邊與座標軸平行的矩形。矩形 A 的左下角是 (ax1, ay1)、右上角是 (ax2, ay2)；矩形 B 的左下角是 (bx1, by1)、右上角是 (bx2, by2)。

請回傳兩個矩形合起來覆蓋的總面積。

範例

範例 1 輸入：ax1 = -3, ay1 = 0, ax2 = 3, ay2 = 4, bx1 = 0, by1 = -1, bx2 = 9, by2 = 2 輸出：45 說明：A 面積 24、B 面積 27，重疊部分 3 × 2 = 6，24 + 27 − 6 = 45。 範例 2 輸入：ax1 = -2, ay1 = -2, ax2 = 2, ay2 = 2, bx1 = -2, by1 = -2, bx2 = 2, by2 = 2 輸出：16 說明：兩個矩形完全重合。

限制條件

  • −10⁴ ≤ ax1 ≤ ax2 ≤ 10⁴
  • −10⁴ ≤ ay1 ≤ ay2 ≤ 10⁴
  • −10⁴ ≤ bx1 ≤ bx2 ≤ 10⁴
  • −10⁴ ≤ by1 ≤ by2 ≤ 10⁴

LeetCode 原題

解題思路

【排容原理】 總面積 = A + B − 重疊 【重疊區域怎麼算？】 兩個軸對齊矩形的交集，還是一個軸對齊矩形（或空的）。 x 方向的重疊區間：[max(ax1, bx1), min(ax2, bx2)] y 方向的重疊區間：[max(ay1, by1), min(ay2, by2)] 長度 = 右端 − 左端；如果是負數，代表不重疊 -> 取 0。 重疊面積 = x 重疊長度 × y 重疊長度 【最常見的錯誤】 只寫 min(ax2, bx2) - max(ax1, bx1)，沒有和 0 取 max -> 兩個方向都不重疊時，兩個負數相乘變成正數 ✘ （例如兩個矩形在對角線方向完全分開）
解法一

逐格標記（只適合小座標）

class Solution: def computeArea(self, ax1: int, ay1: int, ax2: int, ay2: int, bx1: int, by1: int, bx2: int, by2: int) -> int: cells = set() # 逐格標記（只適合小座標，用來驗證） for x1, y1, x2, y2 in ((ax1, ay1, ax2, ay2), (bx1, by1, bx2, by2)): for x in range(x1, x2): for y in range(y1, y2): cells.add((x, y)) return len(cells)

座標到 ±10⁴ 時最多要標記 4×10⁸ 格，太慢。只用來驗證公式。

複雜度說明
時間O(面積)
空間O(面積)
解法二

排容原理

class Solution: def computeArea(self, ax1: int, ay1: int, ax2: int, ay2: int, bx1: int, by1: int, bx2: int, by2: int) -> int: area_a = (ax2 - ax1) * (ay2 - ay1) area_b = (bx2 - bx1) * (by2 - by1) # ★ 重疊部分：x 方向與 y 方向的重疊長度相乘（不重疊時長度取 0） w = max(0, min(ax2, bx2) - max(ax1, bx1)) h = max(0, min(ay2, by2) - max(ay1, by1)) return area_a + area_b - w * h
複雜度說明
時間O(1)
空間O(1)

解法對照

解法時間空間
一、逐格標記O(面積)O(面積)
二、排容原理O(1)O(1) ✔

邊界條件檢查清單

  • 完全不重疊 → 重疊寬或高至少一個取 0。
  • 對角分開（兩個方向都不重疊）→ 一定要和 0 取 max，否則負負得正。
  • 只有邊或角接觸 → 重疊長度 0，面積 0。
  • 一個包住另一個 → 重疊就是小的那個。
  • 退化成一條線或一個點（面積 0）→ 公式照樣成立。

常見追問

追問：如果有 n 個矩形，要算聯集面積？

這是第 850 題：排容原理的項數會爆炸（2^n）， 改用「掃描線 + 座標壓縮」：沿 x 方向掃描，每一段計算被覆蓋的 y 長度總和。
