Problem

The Hamming distance between two integers is the number of positions at which the corresponding bits are different.

Given two integers x and y, return the Hamming distance between them.

中文翻譯

兩個整數的漢明距離是它們二進位表示中，對應位元不同的位置數量。

給你 x 和 y，回傳它們的漢明距離。

範例

範例 1 輸入：x = 1, y = 4 輸出：2 說明： 1 (0 0 0 1) 4 (0 1 0 0) ↑ ↑ 範例 2 輸入：x = 3, y = 1 輸出：1

限制條件

  • 0 ≤ x, y ≤ 2³¹ − 1

LeetCode 原題

解題思路

【XOR：相同為 0、不同為 1】 x ^ y 的每一個 1，就是一個不同的位元。 問題變成：數 x ^ y 有幾個 1（第 191 題）。 【Brian Kernighan：z &= z - 1】 每次清掉最低位的 1，執行幾次就有幾個 1。 比逐位檢查快：只跑「1 的個數」次。
解法

XOR + 數 1 的個數

class Solution: def hammingDistance(self, x: int, y: int) -> int: z = x ^ y # ★ 不同的位元在 XOR 後是 1 count = 0 while z: z &= z - 1 # 每次清掉最低位的 1 count += 1 return count

Python 也可以直接寫 bin(x ^ y).count("1")，或 3.10 以上的 (x ^ y).bit_count()。

複雜度說明
時間O(1)最多 31 次
空間O(1)

邊界條件檢查清單

  • x = y → 0。
  • 其中一個是 0 → 另一個的 1 的個數。
