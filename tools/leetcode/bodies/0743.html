Problem

You are given a network of n nodes, labeled from 1 to n. You are also given times, a list of travel times as directed edges times[i] = (ui, vi, wi), where ui is the source node, vi is the target node, and wi is the time it takes for a signal to travel from source to target.

We will send a signal from a given node k. Return the minimum time it takes for all the n nodes to receive the signal. If it is impossible for all the n nodes to receive the signal, return -1.

中文翻譯

有 n 個網路節點（編號 1～n）。times[i] = (u, v, w) 表示訊號從 u 傳到 v 需要 w 的時間（有向邊）。

從節點 k 發出訊號，回傳所有節點都收到訊號所需的最短時間；若有節點收不到，回傳 -1。

範例

範例 1 輸入：times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2 輸出：2 範例 2 輸入：times = [[1,2,1]], n = 2, k = 1 輸出：1 範例 3 輸入：times = [[1,2,1]], n = 2, k = 2 輸出：-1

限制條件

  • 1 ≤ k ≤ n ≤ 100
  • 1 ≤ times.length ≤ 6000
  • times[i].length == 3
  • 1 ≤ ui, vi ≤ n
  • ui != vi
  • 0 ≤ wi ≤ 100
  • All the pairs (ui, vi) are unique. (i.e., no multiple edges.)

LeetCode 原題

解題思路

【所有節點都收到 = 最晚收到的那個】 答案 = max(從 k 到每個節點的最短距離)。 【Dijkstra（邊權非負）】 最小堆積存 (目前距離, 節點)。 每次取出距離最小的節點 u： 若已經確定過，跳過； 否則它的距離就是最短的（之後不可能有更短的路，因為邊權 >= 0）， 用它更新鄰居。 【為什麼第一次取出就是最短？】 堆積裡其他候選的距離都 >= d， 經過它們再走非負的邊，只會更長。
解法

Dijkstra（堆積）

class Solution: def networkDelayTime(self, times: List[List[int]], n: int, k: int) -> int: adj = defaultdict(list) for u, v, w in times: adj[u].append((v, w)) dist = {} pq = [(0, k)] while pq: d, u = heapq.heappop(pq) if u in dist: continue # 已經確定過最短距離 dist[u] = d # ★ Dijkstra：第一次從堆積取出時，距離就是最短的 for v, w in adj[u]: if v not in dist: heapq.heappush(pq, (d + w, v)) return max(dist.values()) if len(dist) == n else -1

驗證方式：和 Bellman-Ford（鬆弛 n 輪）比對 1500 組隨機圖。

複雜度說明
時間O(E log E)
空間O(V + E)

邊界條件檢查清單

  • 有節點到不了 → −1。
  • 只有一個節點 → 0。
  • 邊權為 0 → Dijkstra 仍然正確（非負即可）。

常見追問

最短路徑演算法比較

Dijkstra：非負邊權，O(E log V)。Bellman-Ford：可有負邊、能偵測負環，O(VE)。Floyd-Warshall：所有點對，O(V³)。0-1 BFS：邊權只有 0 和 1，O(V + E)。
