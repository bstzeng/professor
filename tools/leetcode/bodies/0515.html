Problem

Given the root of a binary tree, return an array of the largest value in each row of the tree (0-indexed).

中文翻譯

給你二元樹的根節點，回傳每一層（由上到下）的最大值所組成的陣列。

範例

範例 1 輸入：root = [1,3,2,5,3,null,9] 輸出：[1,3,9] 範例 2 輸入：root = [1,2,3] 輸出：[1,3]

限制條件

  • 節點數在 [0, 10⁴] 範圍內
  • -2³¹ ≤ Node.val ≤ 2³¹ - 1

LeetCode 原題

解題思路

【層序走訪】 用一個 list 存目前這一層的所有節點： 取這一層的最大值； 下一層 = 所有節點的孩子。 直到某一層是空的。 這種「整層換整層」的寫法比 deque + 計數更直觀。
解法

逐層 BFS

class Solution: def largestValues(self, root: Optional[TreeNode]) -> List[int]: res = [] level = [root] if root else [] while level: res.append(max(nd.val for nd in level)) # 這一層的最大值 level = [c for nd in level for c in (nd.left, nd.right) if c] # 下一層 return res
複雜度說明
時間O(n)
空間O(w)

邊界條件檢查清單

  • 空樹 → []。
  • 負數節點 → 不能用 0 當最大值初始值。

常見追問

DFS 版本

前序走訪帶著深度 d：若 d == len(res) 就 append，否則 res[d] = max(res[d], val)。
