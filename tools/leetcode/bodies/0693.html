Problem

Given a positive integer, check whether it has alternating bits: namely, if two adjacent bits will always have different values.

中文翻譯

給你一個正整數，判斷它的二進位表示中，相鄰的兩個位元是否永遠不同（例如 5 = 101、10 = 1010）。

範例

範例 1 輸入：n = 5 輸出：true 範例 2 輸入：n = 7 輸出：false 範例 3 輸入：n = 11 輸出：false

限制條件

  • 1 ≤ n ≤ 2³¹ - 1

LeetCode 原題

解題思路

【逐位檢查】 反覆比較最低兩位，右移，O(log n)。 【位元技巧】 n = 1 0 1 0 1 n >> 1 = 0 1 0 1 0 異或 = 1 1 1 1 1 <- 交替時每一位都和右邊那位不同 所以：交替 <=> x = n ^ (n >> 1) 是全 1。 【怎麼判斷全 1？】 全 1 的數 x = 2^k - 1，x + 1 = 2^k， 兩者沒有共同的 1 -> x & (x + 1) == 0。
解法

位元運算

class Solution: def hasAlternatingBits(self, n: int) -> bool: x = n ^ (n >> 1) # ★ 位元交替 <=> 每一位都和右邊那位不同 <=> 異或後全是 1 return x & (x + 1) == 0 # 全是 1（形如 0b111...1）<=> 加 1 後和自己沒有共同的 1

驗證方式：1～20000 全部和逐位檢查比對。

複雜度說明
時間O(1)
空間O(1)

邊界條件檢查清單

  • n = 1 → True。
  • n = 3（11） → False。

常見位元判斷

x & (x − 1) == 0：x 是 2 的次方（第 231 題）；x & (x + 1) == 0：x 是全 1；x & −x：取出最低位的 1。
