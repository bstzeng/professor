Problem

Given the root of a binary search tree and the lowest and highest boundaries as low and high, trim the tree so that all its elements lies in [low, high]. Trimming the tree should not change the relative structure of the elements that will remain in the tree (i.e., any node's descendant should remain a descendant). It can be proven that there is a unique answer.

Return the root of the trimmed binary search tree. Note that the root may change depending on the given bounds.

中文翻譯

給你一棵二元搜尋樹和邊界 low、high，修剪這棵樹，使所有節點值都落在 [low, high] 內。

修剪不能改變留下來節點的相對結構（原本是父子關係的仍是祖先後代關係）。回傳修剪後的根（可能會改變）。

範例

範例 1 輸入：root = [1,0,2], low = 1, high = 2 輸出：[1,null,2] 範例 2 輸入：root = [3,0,4,null,2,null,null,1], low = 1, high = 3 輸出：[3,2,null,1]

限制條件

  • 節點數在 [1, 10⁴] 範圍內
  • 0 ≤ Node.val ≤ 10⁴
  • The value of each node in the tree is unique.
  • root 保證是合法的二元搜尋樹
  • 0 ≤ low ≤ high ≤ 10⁴

LeetCode 原題

解題思路

【利用 BST 性質】 root.val < low： root 的左子樹都比 root 小 -> 也都 < low，全部丟掉。 答案只可能在右子樹 -> 回傳 trim(root.right)。 root.val > high：對稱，回傳 trim(root.left)。 否則 root 保留，左右各自遞迴修剪。 被丟掉的節點的「合法後代」會被接到它原本的父節點上， 相對結構不變。
解法

遞迴

class Solution: def trimBST(self, root: Optional[TreeNode], low: int, high: int) -> Optional[TreeNode]: if not root: return None if root.val < low: return self.trimBST(root.right, low, high) # ★ 根太小：它和整個左子樹都不要 if root.val > high: return self.trimBST(root.left, low, high) # 根太大：它和整個右子樹都不要 root.left = self.trimBST(root.left, low, high) root.right = self.trimBST(root.right, low, high) return root

驗證方式：檢查結果的中序走訪等於原值中落在範圍內的排序結果，而且仍是 BST。

複雜度說明
時間O(n)
空間O(h)

邊界條件檢查清單

  • 根被剪掉 → 回傳的新根是某個後代。
  • 全部被剪掉 → None。

常見追問

迭代寫法

先往下找到第一個在範圍內的節點當新根；再分別沿著左邊與右邊的鏈修剪：左邊遇到 < low 的就用它的右孩子取代它。O(1) 額外空間。
