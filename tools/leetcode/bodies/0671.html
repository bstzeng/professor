Problem

Given a non-empty special binary tree consisting of nodes with the non-negative value, where each node in this tree has exactly two or zero sub-node. If the node has two sub-nodes, then this node's value is the smaller value among its two sub-nodes. More formally, the property root.val = min(root.left.val, root.right.val) always holds.

Given such a binary tree, you need to output the second minimum value in the set made of all the nodes' value in the whole tree.

If no such second minimum value exists, output -1 instead.

中文翻譯

給你一棵特殊的二元樹：每個節點的孩子數是 0 或 2；若有兩個孩子，節點值等於兩個孩子值中的較小者。

回傳樹中所有不同值中第二小的值；不存在則回傳 -1。

範例

範例 1 輸入：root = [2,2,5,null,null,5,7] 輸出：5 範例 2 輸入：root = [2,2,2] 輸出：-1

限制條件

  • 節點數在 [1, 25] 範圍內
  • 1 ≤ Node.val ≤ 2³¹ - 1
  • root.val == min(root.left.val, root.right.val) for each internal node of the tree.

LeetCode 原題

解題思路

【性質：每個節點都是子樹中的最小值】 所以根是全樹最小值 first。 【找比 first 大的最小值】 DFS： nd.val > first -> 它是這棵子樹中最小的值， 也就是這棵子樹中「比 first 大」的最小候選，直接回傳。 nd.val == first -> 答案可能在兩邊，兩邊都找，取存在的較小值。 剪枝讓很多子樹不用走到底。
解法

DFS + 剪枝

class Solution: def findSecondMinimumValue(self, root: Optional[TreeNode]) -> int: first = root.val # ★ 根一定是最小值（每個節點 = 兩個孩子的較小者） def dfs(nd): if not nd: return -1 if nd.val > first: return nd.val # 比最小值大：這棵子樹裡它就是最小的，不用再往下 l, r = dfs(nd.left), dfs(nd.right) if l == -1 or r == -1: return max(l, r) return min(l, r) return dfs(root)

驗證方式：隨機產生符合題目性質的樹，和「收集所有不同值排序取第二個」比對。

複雜度說明
時間O(n)
空間O(h)

邊界條件檢查清單

  • 所有值都相同 → −1。
  • 只有根 → −1。

常見追問

這種樹是什麼？

每個節點是孩子的最小值——這是「錦標賽樹」（tournament tree）：葉子是參賽者，每個內部節點是那場比賽的勝者，根是冠軍。找第二名只需要看和冠軍比過的對手。
