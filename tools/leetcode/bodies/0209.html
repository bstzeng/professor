Problem

Given an array of positive integers nums and a positive integer target, find the length of the shortest contiguous subarray whose sum is greater than or equal to target. If no such subarray exists, return 0.

中文翻譯

給你一個正整數陣列 nums 和一個正整數 target，找出總和大於等於 target 的最短連續子陣列，回傳它的長度。如果不存在這樣的子陣列，回傳 0。

範例

範例 1 輸入：target = 7, nums = [2,3,1,2,4,3] 輸出：2 說明：子陣列 [4,3] 的和是 7，長度 2 是最短的。 範例 2 輸入：target = 4, nums = [1,4,4] 輸出：1 範例 3 輸入：target = 11, nums = [1,1,1,1,1,1,1,1] 輸出：0

限制條件

  • 1 ≤ target ≤ 10⁹
  • 1 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁴

LeetCode 原題

題目的追問

「If you have figured out the O(n) solution, try coding another solution of which the time complexity is O(n log n).」

少見的「做出最佳解之後，請再做一個比較慢的」——目的是練習前綴和 + 二分搜尋。

解題思路

【關鍵：所有元素都是正數】 正數代表： 視窗往右擴 -> 和一定變大 視窗左邊縮 -> 和一定變小 這個「單調性」讓滑動視窗成立： 右指標一路往右加； 一旦和 >= target，就記錄長度，然後盡量縮左邊。 【為什麼左指標不需要往回走？】 假設以 right 結尾時，最短合法的起點是 left。 right 往右移之後，新的最短起點只會 >= left （往右擴只會讓和變大，起點不需要往左）。 所以 left 只會往右，總共最多移動 n 次 -> O(n) ✔ 【如果有負數呢？】 單調性消失，滑動視窗不成立 -> 要改用「前綴和 + 單調佇列」（第 862 題，Hard）。 【模擬】target = 7, nums = [2,3,1,2,4,3] right=3：[2,3,1,2]=8 ≥ 7，長度 4；縮掉 2 -> [3,1,2]=6 right=4：[3,1,2,4]=10 ≥ 7，長度 4；縮掉 3 -> [1,2,4]=7，長度 3； 縮掉 1 -> [2,4]=6 right=5：[2,4,3]=9 ≥ 7，長度 3；縮掉 2 -> [4,3]=7，長度 2 ✔
解法一

暴力列舉起點

class Solution: def minSubArrayLen(self, target: int, nums: List[int]) -> int: best = float("inf") for i in range(len(nums)): total = 0 for j in range(i, len(nums)): total += nums[j] if total >= target: best = min(best, j - i + 1) break # 再往右只會更長 return 0 if best == float("inf") else best

每個起點往右加到夠為止。最壞 O(n²)，n = 10⁵ 時是 10¹⁰ 次，超時。

複雜度說明
時間O(n²)
空間O(1)
解法二

前綴和 + 二分搜尋（追問要求的 O(n log n)）

class Solution: def minSubArrayLen(self, target: int, nums: List[int]) -> int: pre = [0] for x in nums: pre.append(pre[-1] + x) # 前綴和嚴格遞增（元素都 > 0） best = float("inf") for i in range(len(nums)): # 找最小的 j 使 pre[j] - pre[i] >= target j = bisect.bisect_left(pre, pre[i] + target) if j <= len(nums): best = min(best, j - i) return 0 if best == float("inf") else best
【前綴和】pre[k] = nums[0] + … + nums[k-1] 子陣列 nums[i..j-1] 的和 = pre[j] - pre[i] 【要找】最小的 j，使 pre[j] >= pre[i] + target 因為元素都是正數，pre 嚴格遞增 -> 可以二分 ✔ 【bisect_left 回傳 len(pre) 代表找不到】 這時 j = n + 1 > n，要跳過。
複雜度說明
時間O(n log n)n 次二分
空間O(n)前綴和陣列
解法三

滑動視窗

class Solution: def minSubArrayLen(self, target: int, nums: List[int]) -> int: best = float("inf") total = left = 0 for right, x in enumerate(nums): total += x while total >= target: # ★ 夠了就試著縮左邊 best = min(best, right - left + 1) total -= nums[left] left += 1 return 0 if best == float("inf") else best
【內層 while 看起來是巢狀迴圈，為什麼是 O(n)？】 left 在整個過程中只往右移，最多移 n 次。 所以 while 的「總」執行次數 ≤ n， 加上外層 n 次 -> O(2n) = O(n) ✔ 【為什麼是 while 而不是 if？】 加進一個大數之後，可能可以一次縮掉好幾個左邊的元素。
複雜度說明
時間O(n)每個元素進出視窗各一次
空間O(1)

解法時間空間備註

邊界條件檢查清單

  • 全部加起來都不夠 → 回傳 0（別回傳 inf）。
  • 單一元素就夠 → 回傳 1。
  • 「大於等於」而不是「等於」 → 別寫成 == target。
  • 用 if 代替 while 縮左邊 → 會漏掉更短的答案。

常見追問

追問：如果陣列裡有負數？

滑動視窗失效，因為縮左邊不一定讓和變小。 正確做法：前綴和 + 單調遞增的雙端佇列（第 862 題）： 對每個 j，從佇列前端彈出所有 pre[j] - pre[front] >= target 的 i 並更新答案； 從佇列後端彈出所有 pre[back] >= pre[j] 的 i（它們不可能比 j 更好）。 整體 O(n)。
