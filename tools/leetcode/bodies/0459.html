Problem

Given a string s, check if it can be constructed by taking a substring of it and appending multiple copies of the substring together.

中文翻譯

給你一個字串 s，判斷它能不能由它的某個子字串重複多次（至少兩次）組成。

範例

範例 1 輸入：s = "abab" 輸出：true 說明："ab" 重複兩次。 範例 2 輸入：s = "aba" 輸出：false 範例 3 輸入：s = "abcabcabcabc" 輸出：true

限制條件

  • 1 ≤ s.length ≤ 10⁴
  • s 只包含小寫英文字母

LeetCode 原題

解題思路

【方法一：枚舉子字串長度】 子字串長度 L 必須整除 n，檢查 s[:L] 重複 n/L 次是否等於 s。 O(n × 因數個數)。 【方法二：s + s 的技巧】 如果 s = t 重複 k 次（k >= 2）， s + s = t 重複 2k 次，去掉第一個和最後一個字元後， 中間仍然包含一個完整的 s（從第二個 t 開始）。 反過來，如果 s 出現在 (s+s)[1:-1] 裡， 代表 s 旋轉某個非零位移後等於自己 -> s 有週期 -> 由重複組成。 【方法三：KMP 前綴函數】 pi[n-1] = s 最長的「相等前綴與後綴」長度。 最小週期 = n - pi[n-1]。 週期能整除 n（而且 pi > 0）-> 由重複組成。
解法一

枚舉子字串長度

class Solution: def repeatedSubstringPattern(self, s: str) -> bool: n = len(s) for L in range(1, n // 2 + 1): # 枚舉子字串長度（必須整除 n） if n % L == 0 and s[:L] * (n // L) == s: return True return False
複雜度說明
時間O(n · d(n))d(n) = n 的因數個數
空間O(n)
解法二

s + s 技巧

class Solution: def repeatedSubstringPattern(self, s: str) -> bool: # ★ s 由某個子字串重複組成 <=> s 出現在 (s + s) 去掉頭尾字元之後的字串裡 return s in (s + s)[1:-1]
複雜度說明
時間O(n)Python 的子字串搜尋平均很快
空間O(n)
解法三

KMP 前綴函數

class Solution: def repeatedSubstringPattern(self, s: str) -> bool: n = len(s) pi = [0] * n # KMP 前綴函數：最長相等前後綴 for i in range(1, n): k = pi[i - 1] while k and s[i] != s[k]: k = pi[k - 1] if s[i] == s[k]: k += 1 pi[i] = k period = n - pi[-1] # 最小週期 return pi[-1] > 0 and n % period == 0
複雜度說明
時間O(n)保證線性
空間O(n)

邊界條件檢查清單

  • 長度 1 → false（至少要重複兩次）。
  • 全部相同（"aaaa"）→ true。
  • 週期不整除長度（"abaab"）→ false。
