Problem

You have n coins and you want to build a staircase with these coins. The staircase consists of k rows where the ith row has exactly i coins. The last row of the staircase may be incomplete.

Given the integer n, return the number of complete rows of the staircase you will build.

中文翻譯

你有 n 枚硬幣，要排成階梯：第 i 列放 i 枚。最後一列可能放不滿。

回傳能排出幾列完整的階梯。

範例

範例 1 輸入：n = 5 輸出：2 說明：第 3 列只有 2 枚，不完整。 範例 2 輸入：n = 8 輸出：3

限制條件

  • 1 ≤ n ≤ 2³¹ − 1

LeetCode 原題

解題思路

【要找最大的 k，使 1 + 2 + ... + k = k(k+1)/2 <= n】 【方法一：二分搜尋】 k(k+1)/2 隨 k 遞增 -> 二分。 【方法二：解二次不等式】 k² + k - 2n <= 0 k <= (-1 + √(1 + 8n)) / 2 取整數部分。 【浮點數的陷阱】 n 很大時，math.sqrt 的浮點誤差可能讓結果差 1。 用 math.isqrt（精確的整數平方根）就沒有這個問題。
解法一

二分搜尋

class Solution: def arrangeCoins(self, n: int) -> int: lo, hi = 0, n while lo < hi: mid = (lo + hi + 1) // 2 # 偏右，避免 lo = mid 時卡住 if mid * (mid + 1) // 2 <= n: lo = mid else: hi = mid - 1 return lo
複雜度說明
時間O(log n)
空間O(1)
解法二

公式（整數平方根）

class Solution: def arrangeCoins(self, n: int) -> int: # ★ 找最大的 k 使 k(k+1)/2 <= n：解二次不等式 return (math.isqrt(8 * n + 1) - 1) // 2
複雜度說明
時間O(1)isqrt 本身是 O(log n) 位元運算
空間O(1)

邊界條件檢查清單

  • n = 1 → 1。
  • n 剛好是三角數（1, 3, 6, 10…）→ 最後一列剛好滿。
  • n 很大 → 8n + 1 在其他語言要用 64 位元。

常見追問

二分的「偏右」寫法

找「最後一個滿足條件的」時，mid 要取 (lo + hi + 1) // 2，否則 lo = mid 時區間不會縮小，陷入無窮迴圈。
