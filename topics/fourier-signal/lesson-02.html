模組 A｜所有訊號都是正弦波的和 · 第 2 課

正交性

這一課的目標

  • 理解函數的內積
  • 證明正弦與餘弦的正交性
  • 理解它和向量分解的類比

向量的分解

一個三維向量 \(\vec v\)，要知道它在 x 方向有多少，就和單位向量做內積：\(v_x = \vec v\cdot\hat x\)。這之所以可行，是因為 \(\hat x, \hat y, \hat z\) 彼此正交（內積為零）——在 x 方向的成分，不會「混進」y 方向。

函數的內積

把函數看成「無限多維的向量」（每一個時間點是一個分量），內積就是把對應的分量相乘、加總——變成積分：

\[\langle f, g\rangle = \int_{-\pi}^{\pi}f(t)\,g(t)\,dt\]

證明：正交性

對正整數 \(m \ne n\)，用積化和差公式 \(\sin A\sin B = \tfrac12[\cos(A - B) - \cos(A + B)]\)：

\[\int_{-\pi}^{\pi}\sin(mt)\sin(nt)\,dt = \frac12\int_{-\pi}^{\pi}\left[\cos((m - n)t) - \cos((m + n)t)\right]dt = 0\]

因為 \(m - n\) 與 \(m + n\) 都是非零整數，餘弦在一個完整週期上的積分為零。同理：

  • \(\int\cos(mt)\cos(nt)\,dt = 0\)（\(m \ne n\)）
  • \(\int\sin(mt)\cos(nt)\,dt = 0\)（任何 \(m, n\)）
  • \(\int\sin^2(nt)\,dt = \int\cos^2(nt)\,dt = \pi\)（\(n \ge 1\)）

所以 \(\{1, \cos t, \sin t, \cos 2t, \sin 2t, \dots\}\) 是函數空間中的一組互相正交的「方向」。

意義

正交性讓分解變得極為簡單：要知道一個函數在 \(\sin(nt)\) 這個「方向」上有多少，只要和它做內積就好，不受其他頻率的干擾。這就是下一課求係數的關鍵。

這個想法——把一個複雜的東西，分解成一組正交的基本成分——在量子力學（能量本徵態）、線性代數（特徵向量，見〈線性代數〉）、機器學習（主成分分析）中一再出現。

🧭 這一課的重點

向量分解依賴正交基底的內積；把函數看成無限維向量，內積是乘積的積分；以積化和差證明不同頻率的正弦、餘弦互相正交，自身平方積分為 π，因此 1、cos、sin 構成一組正交方向，可以用內積直接取出各頻率的成分。

🎵 本課的推導以主要步驟為主，省略部分數學嚴格性（例如收斂條件）；互動模擬為教學用的小型版本。
