視窗函數：排名、移動平均與累計

這一課的目標

  • 理解視窗函數與 GROUP BY 的差別
  • 掌握 PARTITION BY、ORDER BY 與視窗範圍
  • 應用排名、前後列比較與移動平均

GROUP BY 把一組資料「壓扁」成一列；視窗函數則在保留每一列的同時，看見同一組的其他列。

SELECT 姓名, 系所, 成績, RANK() OVER (PARTITION BY 系所 ORDER BY 成績 DESC) AS 系內排名, AVG(成績) OVER (PARTITION BY 系所) AS 系所平均, 成績 - AVG(成績) OVER (PARTITION BY 系所) AS 與平均差距 FROM 成績表;

三個組成

  • PARTITION BY：把資料分成幾個「視窗」（類似 GROUP BY，但不壓扁）。
  • ORDER BY：視窗內的排序。
  • 框架：視窗內要看哪幾列，例如 ROWS BETWEEN 6 PRECEDING AND CURRENT ROW（包含自己共 7 列）。

常用函數

函數用途例子
ROW_NUMBER、RANK、DENSE_RANK排名（處理同分的方式不同）每個系的前三名
LAG、LEAD取前一列、後一列的值和昨天比，股價漲跌多少
SUM … OVER (ORDER BY …)累計今年到目前為止的累計營收
AVG … ROWS BETWEEN n PRECEDING移動平均股價的 5 日、20 日均線
NTILE分成 n 等分把客戶依消費金額分成十等分
-- 股價的 5 日均線與日報酬率 SELECT 日期, 收盤價, AVG(收盤價) OVER (ORDER BY 日期 ROWS BETWEEN 4 PRECEDING AND CURRENT ROW) AS 五日均線, 收盤價 / LAG(收盤價) OVER (ORDER BY 日期) - 1 AS 日報酬 FROM 股價 WHERE 代號 = '2330';

🧭 這一課的重點

視窗函數在保留每一列的同時看見同組其他列，不像 GROUP BY 會壓扁資料。組成包括分割視窗的 PARTITION BY、視窗內排序的 ORDER BY 與指定範圍的框架（如 ROWS BETWEEN 6 PRECEDING AND CURRENT ROW）。常用函數有 ROW_NUMBER、RANK、DENSE_RANK 排名，LAG、LEAD 取前後列，SUM OVER 累計，AVG 搭配框架計算移動平均（如股價 5 日均線），NTILE 分等分。

🗄️ 本課程以原理為主，程式範例用 SQL 與 Python（以 Python 實作簡化版的 B+ 樹、WAL、LSM 樹等核心結構）。各資料庫的實際行為依產品與版本而異，文中以 PostgreSQL、MySQL（InnoDB）與 SQLite 為主要參考。
