聚合：GROUP BY 與 HAVING

這一課的目標

  • 掌握聚合函數與 GROUP BY
  • 區分 WHERE 與 HAVING
  • 理解聚合與 NULL 的關係
SELECT 系所, COUNT(*) AS 學生數, AVG(成績) AS 平均成績, MAX(成績) AS 最高分 FROM 學生 s JOIN 選課 e ON s.學號 = e.學號 WHERE e.課程 <> '體育' -- 先過濾「資料列」 GROUP BY 系所 HAVING AVG(成績) >= 80 -- 再過濾「分組」 ORDER BY 平均成績 DESC;

規則

  • SELECT 中的欄位，要嘛出現在 GROUP BY 裡，要嘛被聚合函數包起來。否則資料庫不知道一組裡的多個值要顯示哪一個。
  • WHERE 在分組之前過濾資料列，不能用聚合函數。
  • HAVING 在分組之後過濾，可以用聚合函數。

聚合與 NULL

  • COUNT(*) 計算列數；COUNT(欄位) 只計算該欄位不是 NULL 的列。
  • SUM、AVG 會忽略 NULL：三個人的成績是 80、NULL、100，AVG 是 90 而不是 60。
  • 一列都沒有時，COUNT 回傳 0，SUM 回傳 NULL——用 COALESCE(SUM(x), 0) 處理。

資料庫內部怎麼分組

  • 雜湊聚合：用雜湊表，以分組鍵為鍵，邊讀邊累計。速度快，但分組很多時需要大量記憶體。
  • 排序聚合：先依分組鍵排序，相同的鍵就會相鄰，依序累計即可。若資料已經依索引排序，就特別划算。

🧭 這一課的重點

聚合函數 COUNT、AVG、MAX 等搭配 GROUP BY 把多列變成一列，SELECT 欄位必須在 GROUP BY 中或被聚合。WHERE 在分組前過濾資料列、不能用聚合函數，HAVING 在分組後過濾、可用聚合函數。COUNT(*) 計算列數、COUNT(欄位) 不計 NULL，SUM 與 AVG 忽略 NULL，無資料時 SUM 回傳 NULL 可用 COALESCE 處理。內部以雜湊聚合（快但耗記憶體）或排序聚合（資料已排序時划算）實作。

🗄️ 本課程以原理為主，程式範例用 SQL 與 Python（以 Python 實作簡化版的 B+ 樹、WAL、LSM 樹等核心結構）。各資料庫的實際行為依產品與版本而異，文中以 PostgreSQL、MySQL（InnoDB）與 SQLite 為主要參考。
