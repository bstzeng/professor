為什麼需要資料庫

這一課的目標

  • 理解直接用檔案存資料的問題
  • 認識資料庫管理系統提供的能力
  • 建立整門課的問題意識

假設你用一個 Excel 檔管理一家網路商店的訂單。一開始很好用；但當公司長大，問題一個一個出現：

問題例子資料庫怎麼解決
同時修改兩位客服同時修改同一筆訂單，後存檔的人覆蓋了前一個人的修改交易與並行控制（模組 E）
當機存檔到一半斷電，檔案損毀日誌與當機復原（第 34 課）
資料量一千萬筆訂單，打開檔案就要好幾分鐘；找一筆要從頭看到尾儲存結構與索引（模組 C）
資料不一致客戶地址存在三個檔案裡，改了一個忘了另外兩個正規化與約束（第 6、12 課）
複雜查詢「上個月每個縣市、每種商品的營收」要手動寫一堆公式SQL 與查詢最佳化（模組 B、D）
權限工讀生不該看到客戶的信用卡資料權限管理（第 50 課）

資料庫管理系統（DBMS）

DBMS 是專門管理資料的軟體，提供四個核心能力：

  1. 資料獨立性：你只要說「要什麼」（SQL），不用管資料在磁碟上怎麼放。
  2. 有效率的存取：索引、快取、查詢最佳化，讓十億筆資料也能毫秒級查詢。
  3. 交易：多人同時讀寫不會互相干擾，當機也不會壞掉（ACID）。
  4. 完整性與安全：約束確保資料正確，權限確保資料不外洩。

本課程的路線

這門課重在原理：除了學會用 SQL，更要理解資料庫內部怎麼存資料（B+ 樹、LSM 樹）、怎麼執行查詢（Join 演算法、最佳化器）、怎麼保證交易正確（鎖、MVCC、WAL），以及怎麼擴展到多台機器（複製、分片、共識）。許多核心結構會用 Python 寫一個簡化版。

🧭 這一課的重點

用 Excel 或檔案管理資料，會遇到同時修改互相覆蓋、存檔到一半當機損毀、資料量大時開啟與查找緩慢、同一資料存多處而不一致、複雜查詢難寫，以及缺乏權限控制。資料庫管理系統提供資料獨立性（只說要什麼）、有效率的存取（索引、快取、最佳化）、交易（ACID）與完整性安全。本課程重在原理，理解資料如何儲存、查詢如何執行、交易如何保證正確與如何擴展到多台機器，並以 Python 實作簡化版核心結構。

🗄️ 本課程以原理為主，程式範例用 SQL 與 Python（以 Python 實作簡化版的 B+ 樹、WAL、LSM 樹等核心結構）。各資料庫的實際行為依產品與版本而異，文中以 PostgreSQL、MySQL（InnoDB）與 SQLite 為主要參考。
