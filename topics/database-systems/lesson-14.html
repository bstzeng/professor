關聯代數：SQL 背後的數學

這一課的目標

  • 認識關聯代數的基本運算
  • 把 SQL 轉成關聯代數
  • 理解等價改寫與最佳化的關係

SQL 是給人寫的；資料庫內部會先把它轉成關聯代數——一組作用在資料表上、結果仍是資料表的運算。

運算符號意思
選擇\(\sigma_{\text{cond}}(R)\)保留符合條件的列（WHERE）
投影\(\pi_{A,B}(R)\)只保留某些欄位（SELECT 的欄位）
連接\(R \bowtie_{\text{cond}} S\)JOIN
聯集、差集、交集\(R \cup S,\; R - S,\; R \cap S\)UNION、EXCEPT、INTERSECT
笛卡兒積\(R \times S\)CROSS JOIN
分組聚合\(\gamma_{\text{dept},\,\text{AVG(score)}}(R)\)GROUP BY

一個查詢的代數形式

SELECT 姓名 FROM 學生 s JOIN 選課 e ON s.學號 = e.學號 WHERE e.成績 >= 90;
\[\pi_{\text{name}}\left(\sigma_{\text{score} \ge 90}\left(\text{Student} \bowtie \text{Enroll}\right)\right)\]

等價改寫：最佳化的基礎

同一個結果有很多種等價的代數式，成本可以差上千倍。最重要的一條規則是選擇下推：先過濾、再連接。

\[\sigma_{\text{score} \ge 90}(S \bowtie E) \equiv S \bowtie \sigma_{\text{score} \ge 90}(E)\]

如果選課有一百萬筆、成績 90 分以上只有五萬筆，先過濾再連接，Join 的輸入就少了 95%。

# 用 Python 實作三個基本運算（資料表 = 字典的串列） def select(R, pred): return [r for r in R if pred(r)] def project(R, cols): return [{c: r[c] for c in cols} for r in R] def join(R, S, key): idx = {} for s in S: idx.setdefault(s[key], []).append(s) # 雜湊連接（第 24 課） return [{**r, **s} for r in R for s in idx.get(r[key], [])] students = [{"sid": 1, "name": "王小明"}, {"sid": 2, "name": "林小華"}] enroll = [{"sid": 1, "course": "資料庫", "score": 92}, {"sid": 2, "course": "資料庫", "score": 78}] print(project(join(students, select(enroll, lambda e: e["score"] >= 90), "sid"), ["name"]))

🧭 這一課的重點

資料庫內部先把 SQL 轉成關聯代數：選擇 σ（WHERE）、投影 π（SELECT 欄位）、連接 ⋈（JOIN）、聯集差集交集（UNION、EXCEPT、INTERSECT）、笛卡兒積 ×（CROSS JOIN）與分組聚合 γ（GROUP BY），運算結果仍是資料表。同一結果有多種等價代數式，成本可差上千倍，最重要的改寫規則是選擇下推：先過濾再連接，可大幅縮小 Join 輸入。三個基本運算可用 Python 簡單實作。

🗄️ 本課程以原理為主，程式範例用 SQL 與 Python（以 Python 實作簡化版的 B+ 樹、WAL、LSM 樹等核心結構）。各資料庫的實際行為依產品與版本而異，文中以 PostgreSQL、MySQL（InnoDB）與 SQLite 為主要參考。
