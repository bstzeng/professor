Fork：參與別人的專案

這一課的目標

  • 理解 fork 是什麼
  • 走過 fork 貢獻流程
  • 區分 fork 與 clone

你想修正某個開源專案的錯字，但你沒有它的寫入權限。做法是 fork：在 GitHub 上把整個倉庫複製一份到你的帳號底下，你對這份有完整權限。

  1. 在原專案頁面右上角按 Fork。
  2. git clone 你的 fork（不是原專案）。
  3. 開分支、修改、commit，push 到你的 fork。
  4. 到 GitHub 上按 Contribute → Open pull request，PR 的方向是「你的 fork 的分支 → 原專案的 main」。
  5. 原專案的維護者審查、合併。

有寫入權限的團隊成員通常不用 fork，直接在原倉庫開分支就好；fork 主要用在開源專案的外部貢獻者。

🧭 這一課的重點

Fork 是 GitHub 功能：把別人的倉庫複製到你的帳號下，讓沒有寫入權限的人也能貢獻。流程：按 Fork、clone 你的 fork、開分支修改並 push 到 fork、在 GitHub 從 fork 的分支向原專案發 PR、由維護者審查合併。clone 是 Git 指令、從 GitHub 到電腦；fork 是在 GitHub 帳號之間複製。團隊成員通常直接開分支。

🐙 本課程的 Git 指令範例都在 Git 2.43 實際執行過，畫面上的輸出就是當時的結果（日期固定，所以雜湊值可重現）；範例中的「GitHub 遠端」是用本機的裸倉庫模擬的，指令與真正連到 GitHub 時相同，只有網址不同。GitHub 網站的按鈕位置與名稱偶爾會改版，以官方說明為準。
