模組 D｜分支 · 第 22 課

建立與切換分支

這一課的目標

  • 建立新分支
  • 在分支之間切換
  • 理解切換分支時檔案的變化

▶ 動手做　實際執行的輸出

$ git branch * main $ git switch -c feature-login Switched to a new branch 'feature-login' $ printf 'def login(): pass\n' > login.py $ git add login.py && git commit -q -m "加入登入功能" $ git branch -v * feature-login f6776ff 加入登入功能 main edad20f 加入 app.py $ git switch main Switched to branch 'main' $ ls README.md app.py $ git log --oneline --all --graph * f6776ff 加入登入功能 * edad20f 加入 app.py * 582091b 初始提交：加入 README

重點觀察：在 feature-login 上 commit 了 login.py，切回 main 之後 login.py 就不見了——因為 main 的快照裡沒有它。檔案沒有消失，它安全地存在 feature-login 分支裡，切回去就會出現。

指令作用
git branch列出分支，* 是目前所在
git branch 名稱建立分支（但不切換）
git switch 名稱切換到分支
git switch -c 名稱建立並切換（最常用）
git branch -v列出分支與各自最新的 commit
git branch -d 名稱刪除已合併的分支（未合併要用 -D）

舊教學常用 git checkout 名稱 和 git checkout -b 名稱，效果一樣。checkout 一個指令做太多事（切分支、還原檔案⋯⋯），所以 Git 2.23 拆成了 switch（切分支）和 restore（還原檔案）。

切換分支前，如果有尚未 commit 的修改會跟目標分支衝突，Git 會拒絕切換以保護你的修改。這時先 commit 或 stash（第 17 課）。

分支命名慣例：feature/login、fix/typo-in-readme、docs/api——用類別前綴加簡短描述，不要用空白。

🧭 這一課的重點

git switch -c 名稱 建立並切換分支，git branch 列出、branch -v 顯示最新 commit、branch -d 刪除已合併分支（未合併用 -D）。切換分支時工作目錄會變成該分支的快照，在其他分支建立的檔案會暫時不見。舊寫法 checkout／checkout -b 效果相同，2.23 拆成 switch 與 restore。有衝突的未提交修改會阻止切換。

🐙 本課程的 Git 指令範例都在 Git 2.43 實際執行過，畫面上的輸出就是當時的結果（日期固定，所以雜湊值可重現）；範例中的「GitHub 遠端」是用本機的裸倉庫模擬的，指令與真正連到 GitHub 時相同，只有網址不同。GitHub 網站的按鈕位置與名稱偶爾會改版，以官方說明為準。
