gh、Codespaces 與 Copilot

這一課的目標

  • 用 gh 命令列操作 GitHub
  • 認識 Codespaces 雲端開發環境
  • 了解 Copilot 的用途與注意事項

gh：GitHub 官方命令列工具

git 管理本機的版本歷史；gh 則讓你在終端機操作 GitHub 網站上的功能（PR、Issue、Release、Actions），不用切到瀏覽器。安裝：cli.github.com，或 brew install gh、winget install GitHub.cli。

$ gh auth login # 登入並設定 Git 驗證 $ gh repo create my-app --public --clone $ gh pr create --fill # 用 commit 訊息自動填寫 PR $ gh pr list $ gh pr checkout 42 # 把別人的 PR 抓下來測試 $ gh pr merge 42 --squash --delete-branch $ gh issue create --title "匯出失敗" --body "重現步驟⋯⋯" $ gh run watch # 即時看 Actions 執行 $ gh release create v1.2.0 --generate-notes

Codespaces

在倉庫按 Code → Codespaces → Create codespace，GitHub 會在雲端開一台已經 clone 好專案的開發機器，用瀏覽器或本機 VS Code 連上去。用 .devcontainer/devcontainer.json 設定好語言與工具，新成員打開就能開始寫，不用花一天裝環境。個人帳號每月有免費額度，用完記得關閉以免計費。

GitHub Copilot

Copilot 是 GitHub 的 AI 程式助手：在編輯器裡自動補全程式碼、用對話解釋與修改程式，也可以幫忙審查 PR、撰寫 PR 摘要，甚至接受 Issue 指派後自己開 PR。注意：

  • AI 產生的程式碼一定要自己讀過、測過，它可能有錯誤或安全問題。
  • 把它當成「很快但需要監督的新同事」，責任仍然在你。
  • 公司使用前先確認政策（程式碼是否能送到外部服務）。

🧭 這一課的重點

gh 是 GitHub 官方命令列工具，可在終端機登入（gh auth login）、建立倉庫、開與合併 PR、抓 PR 測試、建 Issue、看 Actions、發布 Release。Codespaces 在雲端建立已 clone 專案的開發機，用 devcontainer.json 設定環境，有免費額度、用完要關閉。Copilot 是 AI 程式助手，可補全、對話、協助審查，但產生的程式碼必須自己檢查並確認公司政策。

🐙 本課程的 Git 指令範例都在 Git 2.43 實際執行過，畫面上的輸出就是當時的結果（日期固定，所以雜湊值可重現）；範例中的「GitHub 遠端」是用本機的裸倉庫模擬的，指令與真正連到 GitHub 時相同，只有網址不同。GitHub 網站的按鈕位置與名稱偶爾會改版，以官方說明為準。
