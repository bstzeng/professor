commit 是什麼

這一課的目標

  • 理解 commit 是快照不是差異
  • 認識 commit 的雜湊值
  • 理解 commit 之間的父子關係

一個 commit 是專案在某個時間點的完整快照，加上一些說明資料：

  • 作者與時間
  • commit 訊息（你寫的說明）
  • 父 commit（parent）：上一個版本是誰
  • 一個 40 位十六進位的雜湊值（hash），例如 edad20f121e019738a20f1cf7b2026fc83cbc709，平常只寫前 7 位 edad20f

雜湊值是從 commit 的全部內容（包括檔案、訊息、作者、時間、父 commit）算出來的。只要任何一點不同，雜湊就完全不同。這帶來兩個重要性質：

  • 無法偷改歷史：改了一個舊 commit，它的雜湊會變，所有後代的雜湊也都跟著變，大家一看就知道。
  • 全世界唯一：同一個雜湊，在你的電腦和 GitHub 上一定指同一個 commit。

說「快照」而不說「差異」，是因為 Git 概念上每次都存整個專案的樣子；沒變的檔案不會重複存，而是直接指向舊的那份（第 46 課會打開 .git 看）。

🧭 這一課的重點

commit 是專案在某時間點的完整快照，附帶作者、時間、訊息、父 commit，以及從全部內容算出的 40 位雜湊值（常只寫前 7 位）。雜湊讓歷史無法被偷偷修改、且全世界唯一。沒變的檔案不會重複存，而是指向舊的那份。

🐙 本課程的 Git 指令範例都在 Git 2.43 實際執行過，畫面上的輸出就是當時的結果（日期固定，所以雜湊值可重現）；範例中的「GitHub 遠端」是用本機的裸倉庫模擬的，指令與真正連到 GitHub 時相同，只有網址不同。GitHub 網站的按鈕位置與名稱偶爾會改版，以官方說明為準。

  2. 為什麼改了舊 commit，後面所有 commit 的雜湊都會變？
  3. 為什麼說 commit 是「快照」？
