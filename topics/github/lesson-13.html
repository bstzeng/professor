status、diff、log

這一課的目標

  • 用 git status 與 status --short
  • 用 git diff 看修改內容
  • 用 git log 查歷史

日常最常打的三個指令：status（現在怎樣）、diff（改了什麼）、log（之前發生過什麼）。

▶ 動手做　實際執行的輸出

$ printf 'print("hello")\nprint("world")\n' > app.py $ git status --short M app.py $ git diff diff --git a/app.py b/app.py index 11b15b1..3ef823c 100644 --- a/app.py +++ b/app.py @@ -1 +1,2 @@ print("hello") +print("world") $ git add app.py $ git diff $ git diff --staged diff --git a/app.py b/app.py index 11b15b1..3ef823c 100644 --- a/app.py +++ b/app.py @@ -1 +1,2 @@ print("hello") +print("world") $ git commit -q -m "app.py 多印一行"

讀懂 diff：--- 是舊版、+++ 是新版；@@ -1 +1,2 @@ 表示舊版從第 1 行起 1 行、新版從第 1 行起 2 行；+ 開頭是新增的行，- 是刪除的行。

注意：git add 之後再打 git diff 是空的！因為 git diff 比較的是工作目錄 vs. 暫存區；要看已 add 的內容，要用 git diff --staged（暫存區 vs. 最新 commit）。

status --short 代碼意思
??未追蹤的新檔案
M（M 在右）已修改，尚未 add
M （M 在左）已修改，已 add
A 新檔案，已 add
D已刪除

▶ 查歷史　實際執行的輸出

$ git log --oneline 880269e app.py 多印一行 edad20f 加入 app.py 582091b 初始提交：加入 README $ git log --oneline --stat -1 880269e app.py 多印一行 app.py | 1 + 1 file changed, 1 insertion(+) $ git show HEAD commit 880269ee3e1168386e4635baa2f0ab75825cdcd7 Author: Ming Chen <ming@example.com> Date: Sun Mar 1 10:06:00 2026 +0800 app.py 多印一行 diff --git a/app.py b/app.py index 11b15b1..3ef823c 100644 --- a/app.py +++ b/app.py @@ -1 +1,2 @@ print("hello") +print("world") $ git log --oneline -- README.md 582091b 初始提交：加入 README

git log --oneline 一行一個 commit；--stat 列出改了哪些檔案；git show 看單一 commit 的完整內容；在最後加 -- 檔名 只看跟這個檔案有關的 commit。圖形版：git log --oneline --graph --all。

🧭 這一課的重點

git status 看目前狀態，--short 用兩欄代碼（左欄暫存區、右欄工作目錄，?? 是未追蹤）；git diff 比較工作目錄與暫存區，--staged 比較暫存區與最新 commit；diff 中 + 是新增、- 是刪除。git log --oneline、--stat、--graph --all、git show、-- 檔名 用來查歷史。

🐙 本課程的 Git 指令範例都在 Git 2.43 實際執行過，畫面上的輸出就是當時的結果（日期固定，所以雜湊值可重現）；範例中的「GitHub 遠端」是用本機的裸倉庫模擬的，指令與真正連到 GitHub 時相同，只有網址不同。GitHub 網站的按鈕位置與名稱偶爾會改版，以官方說明為準。
