第一次設定

這一課的目標

  • 設定使用者名稱與 Email
  • 設定預設分支名稱
  • 了解設定的三個層級

每個 commit 都會記錄作者。安裝後第一件事，就是告訴 Git 你是誰：

▶ 動手做　實際執行的輸出

$ git config --global user.name "Ming Chen" $ git config --global user.email "ming@example.com" $ git config --global init.defaultBranch main $ git config --global --list user.name=Ming Chen user.email=ming@example.com init.defaultbranch=main
  • user.name：顯示在 commit 上的名字，可以用真名或暱稱。
  • user.email：GitHub 用它把 commit 連結到你的帳號。如果不想公開 Email，可以在 GitHub 設定中取得一個 …@users.noreply.github.com 的隱私信箱來用。
  • init.defaultBranch main：新倉庫的預設分支叫 main（舊版 Git 預設叫 master，GitHub 自 2020 年起預設為 main）。
層級參數存在哪裡影響範圍
系統--systemGit 安裝目錄這台電腦的所有使用者
全域--global~/.gitconfig你的所有倉庫
倉庫（不加）.git/config只有這個倉庫

範圍越小優先權越高。例如公司專案想用公司信箱：在那個倉庫裡執行 git config user.email "me@company.com"（不加 --global）就好。

另外建議設定編輯器（commit 時若沒寫 -m 會打開它）：git config --global core.editor "code --wait"（VS Code）或 nano。

🧭 這一課的重點

第一次使用要設定 user.name 與 user.email（GitHub 用 Email 連結帳號，可用 noreply 隱私信箱），以及 init.defaultBranch main。設定有系統、全域（~/.gitconfig）、倉庫（.git/config）三層，範圍越小優先權越高。也可設定 core.editor。

🐙 本課程的 Git 指令範例都在 Git 2.43 實際執行過，畫面上的輸出就是當時的結果（日期固定，所以雜湊值可重現）；範例中的「GitHub 遠端」是用本機的裸倉庫模擬的，指令與真正連到 GitHub 時相同，只有網址不同。GitHub 網站的按鈕位置與名稱偶爾會改版，以官方說明為準。

  2. 三個設定層級各存在哪裡？
  3. 想讓某個專案用不同 Email 該怎麼設？
