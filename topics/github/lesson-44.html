Markdown 與 README

這一課的目標

  • 掌握 GitHub Flavored Markdown 語法
  • 寫出好的 README
  • 認識其他標準檔案

GitHub 上的 README、Issue、PR、留言都用 Markdown 撰寫——用簡單的符號表示格式。GitHub 版本叫 GFM（GitHub Flavored Markdown）：

寫法效果
# 標題、## 小標題標題（# 越多層級越小）
**粗體**、*斜體*、~~刪除~~文字樣式
- 項目、1. 項目清單
- [ ] 待辦、- [x] 完成勾選清單（在 Issue 中可以直接點）
[文字](網址)、![說明](圖片網址)連結與圖片
`code`行內程式碼
三個反引號加語言名稱有語法上色的程式碼區塊
| A | B | 加 |---|---|表格
> [!NOTE]提示框（NOTE、TIP、IMPORTANT、WARNING、CAUTION）

GitHub 還支援 ```mermaid 畫流程圖、$...$ 寫數學公式、:smile: 表情符號。

好的 README 包含

  1. 這是什麼：一兩句話說明專案用途，附截圖。
  2. 安裝：照著貼上就能跑的指令。
  3. 使用方式：最常見的用法範例。
  4. 如何貢獻：或連到 CONTRIBUTING.md。
  5. 授權：用什麼授權條款。
檔案用途
LICENSE授權條款（第 51 課）
CONTRIBUTING.md貢獻指南
CODE_OF_CONDUCT.md行為準則
SECURITY.md漏洞回報方式
.github/pull_request_template.mdPR 說明範本

小彩蛋：建立一個與使用者名稱同名的倉庫（如 ming/ming），它的 README 會顯示在你的個人頁面最上方，可以當作自我介紹。

🧭 這一課的重點

GitHub 用 GFM Markdown：# 標題、**粗體**、- 清單、- [ ] 勾選清單、[文字](網址)、反引號程式碼、| 表格、> [!NOTE] 提示框，並支援 mermaid、數學與表情符號。好的 README 說明是什麼、安裝、使用、如何貢獻、授權。其他標準檔案：LICENSE、CONTRIBUTING.md、CODE_OF_CONDUCT.md、SECURITY.md、PR 範本。與使用者名稱同名的倉庫 README 會顯示在個人頁面。

🐙 本課程的 Git 指令範例都在 Git 2.43 實際執行過，畫面上的輸出就是當時的結果（日期固定，所以雜湊值可重現）；範例中的「GitHub 遠端」是用本機的裸倉庫模擬的，指令與真正連到 GitHub 時相同，只有網址不同。GitHub 網站的按鈕位置與名稱偶爾會改版，以官方說明為準。
