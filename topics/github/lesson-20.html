圖形介面工具

這一課的目標

  • 認識常見的 Git 圖形介面
  • 把圖形介面的按鈕對應到指令
  • 判斷何時用哪一種

不想打指令也可以用圖形介面。它們背後執行的就是同樣的 Git 指令：

工具特色
GitHub DesktopGitHub 官方、免費，Windows／macOS；介面最簡單，適合入門
VS Code 原始碼控制編輯器內建（左側分支圖示），可以逐行挑選要 stage 的部分
JetBrains IDE（IntelliJ、PyCharm）整合度高，合併衝突工具很好用
Sourcetree、GitKraken、Fork以分支圖為中心的專用工具
圖形介面上的按鈕對應的指令
勾選檔案／Stagegit add
Commit to maingit commit
Push origin／Syncgit push（Sync 通常是 pull 加 push）
Fetch origingit fetch
Current branch → New branchgit switch -c
Discard changesgit restore
Stash changesgit stash

建議：先學指令，再用圖形介面。圖形介面讓日常操作更快、看 diff 更舒服；但出了問題（衝突、復原、救援）時，網路上的解法幾乎都是指令，看得懂指令才知道按鈕做了什麼。

🧭 這一課的重點

常見圖形介面有 GitHub Desktop（官方、最簡單）、VS Code 原始碼控制、JetBrains IDE、Sourcetree／GitKraken／Fork。按鈕背後就是 git add、commit、push、fetch、switch -c、restore、stash 等指令。建議先學指令再用圖形介面，出問題時才看得懂解法。

🐙 本課程的 Git 指令範例都在 Git 2.43 實際執行過，畫面上的輸出就是當時的結果（日期固定，所以雜湊值可重現）；範例中的「GitHub 遠端」是用本機的裸倉庫模擬的，指令與真正連到 GitHub 時相同，只有網址不同。GitHub 網站的按鈕位置與名稱偶爾會改版，以官方說明為準。

  3. 為什麼建議先學指令？
