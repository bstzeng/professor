Git 和 GitHub 不一樣

這一課的目標

  • 分清楚 Git 與 GitHub
  • 知道 GitHub 提供了哪些 Git 沒有的東西
  • 認識其他類似平台

很多人把 Git 和 GitHub 混為一談，其實它們是兩樣東西：

GitGitHub
是什麼一個版本控制工具（軟體）一個網站（雲端服務）
在哪裡跑你的電腦上GitHub 的伺服器上
誰做的Linus Torvalds 在 2005 年為了管理 Linux 原始碼而寫2008 年成立的公司，2018 年被微軟收購
沒網路能用嗎可以，完全離線也能工作不行
提供什麼記錄歷史、分支、合併存放倉庫、Pull Request、Issue、Actions、網頁、權限管理⋯⋯

比喻：Git 像是「文書處理軟體裡的追蹤修訂」，GitHub 像是「讓大家一起編輯文件的雲端硬碟＋討論區」。你可以只用 Git 不用 GitHub；但 GitHub 上的一切，都建立在 Git 之上。

類似 GitHub 的平台還有 GitLab、Bitbucket、Gitea 等。它們底層都是 Git，所以本課程的 Git 部分在這些平台上通用；只有網站操作（Pull Request 在 GitLab 叫 Merge Request）略有不同。

🧭 這一課的重點

Git 是 Linus Torvalds 在 2005 年寫的版本控制工具，在你的電腦上運作、可完全離線；GitHub 是 2008 年成立、2018 年被微軟收購的雲端平台，在 Git 之上提供存放倉庫、Pull Request、Issue、Actions 等協作功能。GitLab、Bitbucket 等平台底層也是 Git。

🐙 本課程的 Git 指令範例都在 Git 2.43 實際執行過，畫面上的輸出就是當時的結果（日期固定，所以雜湊值可重現）；範例中的「GitHub 遠端」是用本機的裸倉庫模擬的，指令與真正連到 GitHub 時相同，只有網址不同。GitHub 網站的按鈕位置與名稱偶爾會改版，以官方說明為準。

檢查你的理解

  1. Git 和 GitHub 哪一個需要網路？
  2. Git 是誰、為了什麼寫的？
  3. GitHub 提供了哪些 Git 本身沒有的功能？
