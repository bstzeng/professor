clone：把倉庫複製下來

這一課的目標

  • 用 git clone 下載倉庫
  • 認識 origin
  • 理解 clone 拿到了什麼

在 GitHub 倉庫頁面按綠色的 Code 按鈕，複製網址（HTTPS 或 SSH），然後：

$ git clone https://github.com/ming/demo.git $ cd demo

下面是實際執行的結果（範例中用本機路徑模擬 GitHub 網址）：

▶ 動手做　實際執行的輸出

$ git clone github/ming/demo.git demo Cloning into 'demo'... done. $ cd demo $ git remote -v origin /home/ming/github/ming/demo.git (fetch) origin /home/ming/github/ming/demo.git (push)

clone 做了三件事：

  1. 建立一個同名資料夾，下載完整的歷史（不只最新版）。
  2. 自動把來源記成一個叫 origin 的遠端（remote）——之後 push、pull 預設就是對它。
  3. 把預設分支（main）的檔案放到工作目錄。

origin 只是一個慣用的名字，代表「我是從這裡 clone 的」。一個倉庫可以有好幾個遠端，例如 fork 時常會再加一個 upstream（第 33 課）。

想下載別人的公開專案來研究，也是用 clone——不需要任何權限。但要 push 回去，就需要寫入權限（或用 fork）。

🧭 這一課的重點

git clone 網址 會建立同名資料夾、下載完整歷史、自動把來源命名為遠端 origin，並把預設分支的檔案放到工作目錄。origin 只是慣用名稱，倉庫可以有多個遠端。clone 公開專案不需權限，但 push 需要寫入權限。

🐙 本課程的 Git 指令範例都在 Git 2.43 實際執行過，畫面上的輸出就是當時的結果（日期固定，所以雜湊值可重現）；範例中的「GitHub 遠端」是用本機的裸倉庫模擬的，指令與真正連到 GitHub 時相同，只有網址不同。GitHub 網站的按鈕位置與名稱偶爾會改版，以官方說明為準。

檢查你的理解

  1. clone 會下載最新版還是完整歷史？
  2. origin 是什麼？
  3. 沒有權限可以 clone 別人的公開倉庫嗎？
