註冊 GitHub、安裝 Git

這一課的目標

  • 註冊 GitHub 帳號
  • 在 Windows 與 macOS 安裝 Git
  • 確認安裝成功

註冊 GitHub

到 github.com 按 Sign up，填 Email、密碼、使用者名稱。使用者名稱會出現在你所有倉庫的網址裡（github.com/你的名稱/專案），建議取一個正式、好記的。註冊後建議立刻開啟兩步驟驗證（2FA）——GitHub 已要求所有會貢獻程式碼的帳號啟用。

安裝 Git

系統方法
Windows到 git-scm.com 下載 Git for Windows 安裝程式，一路按「下一步」即可（預設選項就很好）。它會附帶 Git Bash，一個可以打本課程所有指令的終端機。
macOS打開「終端機」輸入 git --version，若沒有安裝，系統會跳出視窗請你安裝 Xcode 命令列工具；或用 Homebrew：brew install git。
Linux用套件管理員，例如 sudo apt install git（Ubuntu／Debian）。

安裝完成後，在終端機確認：

$ git --version

看到類似 git version 2.4x.x 就成功了。本課程的範例使用 Git 2.43；2.23 之後的版本才有 git switch 與 git restore，如果你的版本太舊，請更新。

本課程的指令都在終端機輸入：Windows 用 Git Bash，macOS 用「終端機」。開頭的 $ 是提示符號，不用打。

🧭 這一課的重點

到 github.com 註冊，使用者名稱會出現在倉庫網址中，並應開啟兩步驟驗證。Windows 安裝 Git for Windows（附 Git Bash），macOS 用 Xcode 命令列工具或 Homebrew，Linux 用套件管理員。用 git --version 確認；git switch／restore 需 2.23 以上。指令前的 $ 不用打。

🐙 本課程的 Git 指令範例都在 Git 2.43 實際執行過，畫面上的輸出就是當時的結果（日期固定，所以雜湊值可重現）；範例中的「GitHub 遠端」是用本機的裸倉庫模擬的，指令與真正連到 GitHub 時相同，只有網址不同。GitHub 網站的按鈕位置與名稱偶爾會改版，以官方說明為準。

檢查你的理解

  1. GitHub 使用者名稱會出現在哪裡？
  2. Windows 上要在哪裡輸入 Git 指令？
  3. git switch 需要哪個版本以上？
