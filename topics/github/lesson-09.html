建立第一個倉庫

這一課的目標

  • 用 git init 在本機建立倉庫
  • 在 GitHub 網站建立倉庫
  • 認識 README、.gitignore、LICENSE

倉庫（repository，常簡稱 repo）就是一個被 Git 管理的資料夾。在本機建立：

▶ 動手做　實際執行的輸出

$ mkdir demo $ cd demo $ git init Initialized empty Git repository in /home/ming/demo/.git/ $ ls -a . .. .git $ git status On branch main No commits yet nothing to commit (create/copy files and use "git add" to track)

git init 在資料夾裡建立了一個隱藏的 .git 資料夾——整個歷史都住在這裡。刪掉 .git，這個資料夾就變回普通資料夾。

在 GitHub 上建立

右上角「＋」→ New repository。要填的欄位：

欄位說明
Repository name倉庫名稱，會成為網址的一部分；習慣用小寫與連字號，如 my-first-repo
Public／Private公開（全世界看得到）或私有（只有你和你邀請的人）
Add a README專案的說明首頁，用 Markdown 寫（第 44 課）
Add .gitignore選一個語言範本，自動忽略該語言常見的暫存檔（第 14 課）
Choose a license開源授權條款；不選代表「保留所有權利」（第 51 課）

兩種起點都可以：如果你在 GitHub 上建立並勾選了 README，就用 git clone 下載（第 10 課）；如果本機已經有專案，就在 GitHub 建立空的倉庫（不要勾 README），再把本機的推上去（第 12 課）。

🧭 這一課的重點

git init 會在資料夾中建立隱藏的 .git，整個歷史都存在那裡。在 GitHub 用 New repository 建立時要填名稱、選擇公開或私有，並可加入 README、.gitignore 範本與授權條款。GitHub 上先建立就用 clone；本機已有專案則在 GitHub 建立空倉庫再推上去。

🐙 本課程的 Git 指令範例都在 Git 2.43 實際執行過，畫面上的輸出就是當時的結果（日期固定，所以雜湊值可重現）；範例中的「GitHub 遠端」是用本機的裸倉庫模擬的，指令與真正連到 GitHub 時相同，只有網址不同。GitHub 網站的按鈕位置與名稱偶爾會改版，以官方說明為準。

檢查你的理解

  1. git init 做了什麼？
  2. 刪掉 .git 會怎樣？
  3. 本機已有專案時，GitHub 上的倉庫該不該勾 README？
