買賣權平價

這一課的目標

  • 推導買賣權平價關係
  • 理解無套利的論證
  • 用平價關係檢查市場價格

兩個組合

考慮同一個標的、同一個履約價 K、同一個到期日的歐式買權 C 與賣權 P。比較兩個組合：

  • 組合 A：買一口買權 + 存入 \(Ke^{-rT}\) 的現金（到期時變成 K）。
  • 組合 B：買一口賣權 + 持有一單位標的。

到期時：

S_T > KS_T < K
組合 A(S_T − K) + K = S_T0 + K = K
組合 B0 + S_T = S_T(K − S_T) + S_T = K

兩個組合在到期時的價值完全相同。所以它們今天的價格也必須相同：

買賣權平價

\[C + Ke^{-rT} = P + S\]

無套利

如果市場上的價格違反了這個等式，例如 \(C+Ke^{-rT} > P+S\)，交易者就可以賣出貴的組合 A、買進便宜的組合 B，今天立刻賺到差價，到期時兩邊完全抵銷，沒有任何風險。這叫做套利。

在有效率的市場中，套利機會會被迅速消除。無套利原則，是整個選擇權定價理論的基石——它不需要知道市場會漲還是跌，也不需要知道任何人的偏好。

應用

  • 已知買權的價格，可以算出賣權的價格。
  • 用買權、賣權與現金，可以「合成」出標的或期貨（合成期貨）。
  • 在台指選擇權中，用同履約價的買權與賣權，可以推算市場隱含的期貨價格。

🧭 這一課的重點

同標的、同履約價、同到期的歐式買權 C 與賣權 P，組合 A 買買權加存 Ke^{−rT}、組合 B 買賣權加持有標的，到期時 S_T>K 兩者都是 S_T、S_T
