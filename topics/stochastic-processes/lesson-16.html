多步轉移

這一課的目標

  • 計算 n 步轉移機率
  • 理解查普曼—柯摩哥洛夫方程
  • 用矩陣乘法表示分布演化

兩步後從 i 到 j 的機率，要把中間所有可能的狀態 k 加起來：

\[P^{(2)}_{ij} = \sum_k P_{ik}P_{kj} = (P^2)_{ij}\]

推廣到 n 步就是矩陣的 n 次方 \(P^n\)。一般形式叫查普曼—柯摩哥洛夫方程：\(P^{(m+n)} = P^{(m)}P^{(n)}\)。

如果現在的機率分布是列向量 \(\pi_0\)（例如今天確定下雨：(0, 0, 1)），那麼 n 天後的分布是

\[\pi_n = \pi_0 P^n\]

例：今天下雨，明天的分布就是 P 的第三列 (0.2, 0.4, 0.4)；後天是 (0.2, 0.4, 0.4) × P = (0.34, 0.36, 0.30)。計算到很多天以後，就會看到分布收斂（模組 D）。

🧭 這一課的重點

n 步轉移機率是轉移矩陣的 n 次方；分布的演化是 πₙ = π₀Pⁿ。
