伊藤引理

這一課的目標

  • 理解伊藤引理
  • 會用伊藤引理計算
  • 看見伊藤修正項

若 \(dX = \mu\,dt + \sigma\,dW\)，f(X) 的變化用泰勒展開到二階，再套用 (dW)² = dt（數學段落）：

\[df = \left(f'(X)\,\mu + \tfrac12 f''(X)\,\sigma^2\right)dt + f'(X)\,\sigma\,dW\]

多出來的 \(\tfrac12 f''\sigma^2\,dt\) 就是伊藤修正。一般微積分中二階項會消失，但這裡因為 (dW)² = dt，它和一階項一樣大。

例：W² 的變化

f(W) = W²：\(d(W^2) = 2W\,dW + dt\)。所以 \(E[W(t)^2] = t\)，和布朗運動的變異數一致。如果用一般微積分，會漏掉 dt 這一項，得到錯誤的 E[W²] = 0。

伊藤引理是隨機微分方程的核心工具，下一課會用它推出股價模型的性質。

🧭 這一課的重點

伊藤引理是隨機版的連鎖律，多出 ½f″σ² dt 的修正項，因為 (dW)² = dt 不可忽略。

🎲 推導段落可以跳過，只看圖、互動與「重點」也能掌握概念。模擬結果每次會因隨機性略有不同。涉及股價與金融的內容僅為教育用途，不構成投資建議。
