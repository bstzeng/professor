迴圈最佳化

這一課的目標

  • 理解迴圈最佳化的重要
  • 認識常見的迴圈最佳化
  • 了解自動向量化

九成的時間在一成的程式碼

程式大部分的執行時間，花在少數的迴圈中。所以編譯器在迴圈上投入最多的最佳化。

迴圈不變量外提

for (i = 0; i < n; i++) t = sqrt(k) * 2; a[i] = b[i] + sqrt(k) * 2; → for (i = 0; i < n; i++) a[i] = b[i] + t;

sqrt(k) * 2 在每一圈都一樣，搬到迴圈外面只算一次。

迴圈展開

把迴圈主體複製幾份，一圈做 4 次工作，減少判斷與跳躍的次數，也讓 CPU 有更多可以同時執行的指令。代價是程式碼變大。

自動向量化

現代 CPU 有 SIMD 指令（第 3 課在 GPU 課程中有介紹），一條指令可以同時處理 4、8 甚至 16 個數。編譯器會嘗試把迴圈轉換成向量指令：

for (i = 0; i < n; i++) c[i] = a[i] + b[i]; // 向量化後：每次載入 8 個 a、8 個 b，一條指令相加 8 對

但只有在編譯器能證明安全時才會這麼做：例如 a、b、c 指向的記憶體不重疊（指標別名分析），每一圈之間沒有相依關係。C 語言的 restrict 關鍵字，就是讓程式設計師向編譯器保證「沒有重疊」。

其他

  • 迴圈交換：調換巢狀迴圈的順序，讓記憶體存取連續（對快取友善）。
  • 迴圈融合與分割：合併兩個迴圈減少走訪次數，或拆開讓各自更容易向量化。
  • 歸納變數：把 a[i] 的位址計算 base + i × 4，改成每圈加 4。

🧭 這一課的重點

程式大部分執行時間花在少數迴圈，編譯器在迴圈投入最多最佳化；迴圈不變量外提把每圈都一樣的 sqrt(k)*2 搬到外面只算一次；迴圈展開把主體複製幾份減少判斷跳躍讓 CPU 有更多可同時執行的指令但程式變大；自動向量化把迴圈轉成 SIMD 一條指令處理 4 8 16 個數，只有能證明安全時才做（記憶體不重疊的指標別名分析、每圈無相依），C 的 restrict 向編譯器保證沒重疊；其他有迴圈交換讓存取連續、迴圈融合與分割、歸納變數把位址乘法改成每圈加 4。
