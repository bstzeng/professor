模組 D｜中介碼與最佳化 · 第 22 課

LLVM

這一課的目標

  • 了解 LLVM 的歷史與設計
  • 認識 LLVM IR
  • 了解 LLVM 的影響

起源

LLVM 是克里斯・拉特納在伊利諾大學的研究計畫，2003 年首次發布。後來他加入蘋果，LLVM 與 C 語言前端 Clang 成為蘋果的主要編譯器。拉特納後來也主導設計了 Swift 語言。

模組化的設計

LLVM 的核心是一種定義清楚、文件完整的 IR，以及一系列可以自由組合的最佳化「pass」。任何語言只要能產生 LLVM IR，就能免費得到世界級的最佳化與多種處理器的後端（第 3 課的 M + N 設計）。

; LLVM IR：int add(int a, int b) { return a + b; } define i32 @add(i32 %a, i32 %b) { entry: %sum = add nsw i32 %a, %b ret i32 %sum }

LLVM IR 是 SSA 形式、有明確的型別，可以用文字形式閱讀，方便除錯與教學。

影響

  • 語言：Clang（C、C++、Objective-C）、Swift、Rust、Julia、Zig 等都使用 LLVM 作為後端。
  • 工具：靜態分析、程式碼格式化（clang-format）、記憶體錯誤偵測（AddressSanitizer）。
  • GPU 與 AI：NVIDIA 的 CUDA 編譯器、AMD 的 GPU 編譯器都以 LLVM 為基礎；AI 框架使用的 MLIR 也出自 LLVM 專案（見〈GPU 與平行運算〉）。

2012 年，LLVM 獲得了 ACM 軟體系統獎。另一個重要的開源編譯器是歷史更久的 GCC（1987 年起），兩者的競爭推動了彼此的進步。
