文法與 BNF

這一課的目標

  • 理解上下文無關文法
  • 學會讀 BNF
  • 理解語法的歧義

文法

程式語言的結構是遞迴的：一個算式裡可以有括號，括號裡又是一個算式；一個 if 裡可以有另一個 if。描述這種結構，要用上下文無關文法——一組「某個東西可以由哪些東西組成」的規則。

BNF

1960 年，巴科斯與諾爾在定義 ALGOL 60 語言時，使用了一種記法，後來稱為巴科斯—諾爾範式（BNF）：

<expr> ::= <expr> "+" <term> | <expr> "-" <term> | <term> <term> ::= <term> "*" <factor> | <term> "/" <factor> | <factor> <factor> ::= NUMBER | IDENTIFIER | "(" <expr> ")"

讀法：「一個 expr 可以是 expr 加 term，或 expr 減 term，或單獨一個 term。」注意 factor 可以是括號裡的 expr——這就是遞迴，讓括號可以任意深。

歧義

如果文法寫成 expr ::= expr + expr | expr * expr | NUMBER，那麼 1 + 2 * 3 可以有兩棵不同的語法樹：(1 + 2) * 3 = 9，或 1 + (2 * 3) = 7。這種文法是有歧義的。上面的 BNF 用 expr、term、factor 三層，讓乘法「綁得比加法緊」，消除了歧義。

懸置的 else

經典的歧義：if (a) if (b) x(); else y();——else 屬於哪一個 if？大多數語言規定它屬於最近的 if。Python 用縮排、Rust 與 Go 強制寫大括號，從根本上避免了這個問題。

文法定義了「什麼樣的程式是合法的」，但不定義意義。"hello" * true 在文法上可能完全合法，卻沒有意義——那是語意分析的工作（模組 C）。

🧭 這一課的重點

程式語言結構是遞迴的，括號裡又是算式 if 裡又有 if，要用上下文無關文法描述；1960 年巴科斯與諾爾定義 ALGOL 60 用 BNF 記法，expr term factor 三層規則，factor 可以是括號裡的 expr 讓括號任意深；若寫成 expr＋expr | expr*expr，1＋2*3 有兩棵樹（9 或 7）是歧義，三層讓乘法綁得比加法緊消除歧義；懸置的 else 屬於最近的 if，Python 縮排、Rust Go 強制大括號避免；文法定義什麼是合法程式但不定義意義，那是語意分析的工作。
