詞法分析

這一課的目標

  • 理解 token 的概念
  • 理解詞法分析器的工作
  • 認識常見的 token 類型

從字元到 token

對電腦來說，原始碼只是一長串字元：i、f、空白、(……。詞法分析器（lexer、scanner）的工作是把它們分組成有意義的單位——token，就像閱讀時先把字母組成單字。

常見的 token

類型例子
關鍵字if、while、return、int
識別字total、price、getUser
數字字面值42、3.14、0xFF、1e-9
字串字面值"hello"
運算子+、==、&&、+=
分隔符號( ) { } ; ,

詞法分析器還做什麼

  • 丟掉空白與註解（在 Python 中，縮排卻是有意義的，會被轉成 INDENT、DEDENT token）。
  • 記錄每個 token 的行號與欄位，讓錯誤訊息能指出位置。
  • 最長匹配：看到 >= 時，要當成一個「大於等於」，而不是「大於」加「等於」；看到 iffy 時，是識別字而不是關鍵字 if 加 fy。

一個有名的難題：C++ 早期的 vector<vector<int>> 中，>> 會被詞法分析器當成「右移」運算子，所以必須寫成 > >。C++11 才修正了這個規則。

🧭 這一課的重點

原始碼對電腦只是一長串字元，詞法分析器把它們分組成 token 像閱讀時先把字母組成單字；常見 token 有關鍵字、識別字、數字字面值、字串字面值、運算子、分隔符號；詞法分析器還丟掉空白註解（Python 縮排轉成 INDENT DEDENT）、記錄行號欄位讓錯誤能指出位置、最長匹配 >= 是一個運算子 iffy 是識別字；C++ 早期 vector<vector<int>> 的 >> 被當右移須寫成 > >，C++11 才修正。

🛠️ 互動工具實作了一個極小的算式語言（數字、變數、+ − × ÷ ^ 與括號），用來示範編譯器的各個階段。
