型別檢查

這一課的目標

  • 理解型別系統的目的
  • 區分靜態與動態型別
  • 理解強型別與弱型別

型別的意義

型別告訴我們一個值是什麼、可以對它做什麼。整數可以相加，字串可以串接；把字串當成函式呼叫，則沒有意義。型別檢查在 AST 上走一遍，為每個運算式算出型別，並檢查每個運算是否合法。

靜態與動態

靜態型別動態型別
何時檢查編譯時執行時
例子C、Java、Rust、Go、TypeScriptPython、JavaScript、Ruby
優點及早發現錯誤；編譯器能產生更快的程式碼；IDE 的自動完成更準確寫起來靈活快速
缺點需要寫型別（或靠推論）錯誤可能在執行到那一行時才出現

近年的趨勢是兩者融合：Python 加入了型別提示並有 mypy 等檢查工具，JavaScript 有了 TypeScript。大型的程式碼庫，特別需要型別帶來的安全感。

強與弱

另一個維度是隱式轉換的多寡。JavaScript 中 "5" - 2 得到 3、"5" + 2 得到 "52"、[] + {} 得到奇怪的字串——這被稱為「弱型別」。Python 則會對 "5" + 2 直接報錯。

型別安全

一個型別安全的語言保證：通過型別檢查的程式，不會在執行時把某種型別的資料誤當成另一種型別使用。C 語言不是型別安全的（可以任意轉換指標），這是許多安全漏洞的根源；Rust 則在型別系統中加入了「所有權」，在編譯時就防止記憶體錯誤。

🧭 這一課的重點

型別告訴我們值是什麼能做什麼，型別檢查在 AST 上算出每個運算式的型別並檢查運算是否合法；靜態型別編譯時檢查（C Java Rust Go TypeScript）能及早發現錯誤產生更快程式碼 IDE 更準但要寫型別，動態型別執行時檢查（Python JavaScript Ruby）靈活但錯誤到執行才出現，趨勢是融合（Python 型別提示 mypy、TypeScript）；強弱是隱式轉換多寡，JavaScript "5"−2＝3、"5"＋2＝"52" 為弱型別，Python 會報錯；型別安全保證不會把一種型別誤當另一種，C 可任意轉指標是許多漏洞根源，Rust 用所有權在編譯時防止記憶體錯誤。

🛠️ 互動工具實作了一個極小的算式語言（數字、變數、+ − × ÷ ^ 與括號），用來示範編譯器的各個階段。
