Touch ID、Apple ID 與螢幕解鎖

這一課的目標

  • 理解 Apple ID 的角色
  • 知道 Touch ID 能做什麼
  • 設好螢幕解鎖與安全

有兩樣東西掌管你的 Mac 與 Apple 生態系:Apple ID(你的帳號)和Touch ID(你的指紋)。這一課講清楚。

1. Apple ID:一個帳號打通一切

Apple ID 是你的 Apple 帳號。App Store 下載、iCloud 雲端、訊息、備份、購買、跨裝置同步——全都靠它。它就是你進入整個 Apple 生態系的鑰匙(第 35 課)。

因為它這麼重要:務必記好帳密,並開啟兩步驟驗證(登入時除了密碼,還要另一台裝置確認),保護你的雲端資料和購買紀錄。

2. Touch ID:指紋解鎖

如果你的 Mac 有 Touch ID(鍵盤右上角的指紋感應),可以用它:解鎖電腦、填密碼、App Store 付款、確認購買。比每次打密碼快又安全(指紋不會被偷看)。到系統設定 →Touch ID 與密碼可以登錄指紋。

3. 螢幕解鎖與自動鎖定

  • 一定要設一個登入密碼(即使有 Touch ID,重開機時仍需要密碼)。
  • 設定閒置多久自動鎖定螢幕,離開座位時保護資料。
  • 如果你有 Apple Watch,還能設定「戴著錶靠近就自動解鎖」。

把 Apple ID 顧好、Touch ID 設好、自動鎖定開起來,你的 Mac 就既方便又安全。

動手試試

到系統設定 →Touch ID 與密碼,登錄一枚指紋(如果還沒)。之後解鎖、裝 App 時用手指碰一下,體驗有多方便。順便確認你的 Apple ID 開了兩步驟驗證。
