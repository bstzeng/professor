最該先背的 20 個快捷鍵

這一課的目標

  • 記住最常用的快捷鍵
  • 學會截圖快捷鍵
  • 知道去哪查完整清單

這一課給你一份精選清單。不用一次全背,先熟前面幾組,其他用到再查。

1. 文字編輯(和 Windows 一樣,只是 Ctrl→⌘)

動作快捷鍵
複製 / 貼上 / 剪下⌘C / ⌘V / ⌘X
復原 / 重做⌘Z / ⌘⇧Z
全選⌘A
存檔 / 列印⌘S / ⌘P
尋找⌘F

2. 視窗與 App

動作快捷鍵
關閉視窗⌘W
結束 App⌘Q
切換 App⌘Tab(按住 ⌘ 連點 Tab)
切換同一 App 的視窗⌘`(數字 1 左邊那個鍵)
強制結束當掉的 App⌘⌥⎋(Esc)

3. 截圖(這個 Windows 沒有的好用內建)

動作快捷鍵
整個螢幕⌘⇧3
自己框選範圍⌘⇧4(然後拖出範圍)
某個視窗⌘⇧4,再按空白鍵,點視窗
截圖工具列(可錄影)⌘⇧5

截圖預設存到桌面。截完右下角會出現縮圖,點它可以馬上標註、裁切。

4. 神級一鍵

⌘空白(Spotlight,搜尋任何東西,第 15 課)、空白鍵(在 Finder 選檔案按一下快速預覽,第 7 課)。完整快捷鍵清單在速查表,也可以到本主題的互動快捷鍵練習器邊玩邊記。

動手試試

現在試三個新的:⌘⇧4 框一塊螢幕截圖(圖會在桌面)、⌘Tab 切換 App、⌘W 關掉當前視窗。多按幾次就記住了。

檢查你的理解

  1. 截取「整個螢幕」和「自己框選範圍」的快捷鍵各是什麼?
  2. 切換不同 App 用哪個快捷鍵?
  3. 截圖預設存到哪裡?
