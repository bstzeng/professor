副檔名去哪了:Mac 怎麼判斷檔案類型

這一課的目標

  • 理解 Mac 為何預設隱藏副檔名
  • 知道怎麼顯示所有副檔名
  • 連結到檔案類型與安全

你注意到 Mac 上的檔案常常看不到副檔名(.docx、.jpg 不見了)。這不是它沒有,而是藏起來了。

1. 為什麼藏起來

Windows 很依賴副檔名決定用什麼開。Mac 則主要靠檔案內部的資訊判斷類型(這點在 檔案格式課的「魔術數字」講過),所以它預設把副檔名藏起來,讓畫面看起來乾淨。

2. 怎麼把副檔名顯示出來(建議打開)

  1. 打開 Finder。
  2. 螢幕最上方選單:Finder →設定(或按 ⌘,)。
  3. 點 進階分頁。
  4. 勾選「顯示所有檔案副檔名」。

打開後,就跟 Windows 一樣每個檔案都看得到 .docx、.jpg 了。

3. 為什麼建議顯示

  • 你會更清楚每個檔案到底是什麼,不會把 .pages 誤當 .docx。
  • 比較不會被偽裝的檔案騙(例如把程式偽裝成文件,見 偽裝附檔名)。
  • 改名時能連副檔名一起看到,不會不小心改錯或漏改。

小提醒:如果你改檔名時把副檔名也改掉(例如 .jpg 改成 .txt),Mac 會跳出警告問你確定嗎——因為改副檔名可能讓檔案打不開,這點和 Windows 一樣。

動手試試

照上面步驟打開「顯示所有副檔名」。你桌面和下載裡的檔案,現在應該都露出 .pdf、.jpg、.docx 等尾巴了。
