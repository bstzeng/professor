當機、卡住、App 沒回應:Mac 版的工作管理員

這一課的目標

  • 學會強制結束當掉的 App
  • 認識活動監視器
  • 知道對應 Windows 的工具

App 卡住轉圈圈、整個沒反應——每台電腦都會遇到。Mac 有對應 Windows「工作管理員」的工具來處理。

1. 強制結束當掉的 App

當一個 App 沒反應(游標變成轉圈圈的彩球),先等幾秒看它會不會恢復。真的卡死了,就強制結束它:

  • 按 ⌘⌥⎋(Command＋Option＋Esc),跳出「強制結束」清單,選那個當掉的 App,按強制結束。
  • 或從蘋果選單 →強制結束。
  • 或在 Dock 圖示上按住 ⌥ 右鍵 →強制結束。

強制結束後重開那個 App,通常就正常了(沒存的資料可能會丟,這點和 Windows 一樣)。

2. 活動監視器:Mac 的工作管理員

想看每個程式在吃多少資源?打開活動監視器(應用程式 →工具程式,或 Spotlight 打「活動監視器」)。它對應 Windows 的工作管理員:

  • 看每個程序的 CPU、記憶體、能耗、網路用量。
  • 揪出某個吃掉大量 CPU 或記憶體、害電腦變慢的程式。
  • 選中它,按左上角的 ✕ 可以結束它(相當於強制結束)。

下次電腦變慢、風扇狂轉,打開活動監視器看看是誰在搞鬼,常常一目了然。

動手試試

打開活動監視器,點「CPU」欄排序,看看現在哪個程式最耗 CPU。(先別結束任何東西,只是觀察。)這就是 Mac 的工作管理員。

  3. 想知道哪個程式讓電腦變慢,可以怎麼查?
