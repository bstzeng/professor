Windows 常用軟體的 Mac 對應表

這一課的目標

  • 對照常見 Windows 軟體的 Mac 版本
  • 知道去哪找這些工具
  • 建立「換名字」的習慣

很多困擾其實只是「同一個工具換了名字」。這一課把 Windows 常用軟體對應到 Mac,你會發現大部分東西 Mac 都有,只是叫法不同。

1. 對照表

WindowsMac在哪找
記事本TextEdit／備忘錄應用程式(第 13 課)
檔案總管FinderDock 最左邊的藍笑臉(第 7 課)
小畫家預覽程式(簡單標註)／繪圖 App應用程式／App Store
小算盤計算機或直接在 Spotlight 打算式
工作管理員活動監視器應用程式 →工具程式(第 39 課)
控制台系統設定蘋果選單 →系統設定(第 29 課)
命令提示字元終端機應用程式 →工具程式(第 38 課)
剪取工具⌘⇧4 截圖內建快捷鍵(第 20 課)

2. 怎麼找到它們

這些內建工具大多在「應用程式」資料夾裡,比較底層的(活動監視器、終端機)在其中的「工具程式」子資料夾。但最快的方法永遠是:按 ⌘空白,打名字(第 15 課)。

3. 商業軟體多半也有 Mac 版

Office(Word、Excel、PowerPoint)、Chrome、LINE、Zoom、Photoshop 等大牌軟體都有 Mac 版,到官方網站或 App Store 下載即可。少數只有 Windows 的軟體,可以找 Mac 上的替代品,或用虛擬機(進階,本課不深入)。

完整的對照(含快捷鍵、名詞)整理在本主題的「Windows → Mac 對照速查表」,可以加入書籤隨時查。

動手試試

挑三個你在 Windows 最常用的軟體,用 Spotlight 找找看它們的 Mac 版或對應工具。大部分你都能立刻找到。
