Command 不是 Ctrl:四個修飾鍵與它們的角色

這一課的目標

  • 認識四個修飾鍵
  • 理解 ⌘ 相當於 Windows 的 Ctrl
  • 知道各修飾鍵的用途

快捷鍵是 Windows 老手轉 Mac 最卡的地方——不是不會,而是手指按錯鍵。關鍵只有一句話:Windows 的 Ctrl,在 Mac 大多換成 ⌘(Command)。

1. 四個修飾鍵

鍵符號角色
Command⌘主修飾鍵,相當於 Windows 的 Ctrl
Option⌥輔助鍵:打特殊符號、看進階選項
Control⌃較少用:終端機、搭配點按當右鍵
Shift⇧選取、大寫,常和 ⌘ 一起用

2. 就是把 Ctrl 換成 ⌘

你在 Windows 熟的那些:複製 Ctrl+C、貼上 Ctrl+V、存檔 Ctrl+S、全選 Ctrl+A——在 Mac 通通把 Ctrl 換成 ⌘ 就對了:⌘C、⌘V、⌘S、⌘A。這一個轉換,解決你九成的快捷鍵困惑。

3. Control 鍵的定位

Mac 也有一個 Control(⌃) 鍵,但它不是 Windows 的 Ctrl!它比較少用,主要在終端機(第 38 課)或「按住 ⌃ 再點」當右鍵。初學最容易搞混的就是這個——記得:日常快捷鍵用的是 ⌘,不是 ⌃。

下一課把最該背的快捷鍵一次列給你(第 20 課)。

動手試試

打開任何一個有文字的地方,選一段字,按 ⌘C 複製、⌘V 貼上。刻意用 ⌘ 而不是 Ctrl,幾次之後手指就記住了。
