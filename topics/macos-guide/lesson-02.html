macOS 的身世:一個來自 Unix 的作業系統

這一課的目標

  • 知道 macOS 源自 Unix
  • 理解這個血統帶來哪些特徵
  • 明白為什麼不能硬套 Windows 規矩

要理解 Mac 的邏輯,先認識它的身世。macOS 和 Windows 是兩條完全不同的血脈。

1. 它是個 Unix 系統

macOS 的底層是 Unix——一個 1970 年代誕生、以穩定和一致著稱的作業系統家族(Linux 也是這個家族)。這和 Windows 那條血脈毫無關係。

2. 這解釋了很多事

  • 路徑用斜線 /,而且只有一個根,沒有「C 槽 D 槽」(第 6 課)。
  • 內建終端機,底層可以像 Linux 一樣操作(第 38 課)。
  • 多工穩定、和開發/伺服器環境親近——這是很多工程師愛用 Mac 的原因。
  • 很多檔案與權限的規矩,其實是 Unix 的規矩。

3. 對你的意義:別硬套 Windows

最重要的心態是:不要把 Windows 的規矩硬套到 Mac 上。「為什麼不能像 Windows 那樣?」這個問題常常沒有意義,因為它們的設計出發點就不同。與其對抗,不如先理解 Mac 自己的規則——而且好消息是,Unix 的邏輯很一致,學一次,到處通用。

你不需要懂 Unix 的技術細節,只要記得:Mac 有它自己一套自洽的規則,這門課會帶你把它摸熟。

動手試試

這一課不用動手,只要記住一句話:「Mac 是 Unix,不是 Windows 的另一個版本。」帶著這個認知,後面很多設計就會變得合理。

檢查你的理解

  1. macOS 的底層是哪一種作業系統?
  2. 這個血統帶來了哪些特徵?(舉兩個)
  3. 面對「為什麼不能像 Windows 那樣」,正確的心態是什麼?
