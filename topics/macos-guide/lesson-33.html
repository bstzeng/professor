備份就是 Time Machine:一鍵還原的安心感

這一課的目標

  • 認識 Time Machine 備份
  • 理解它如何讓你「回到過去」
  • 知道換電腦時的好處

如果這門課的維護部分只能記一件事,就是這個:設定 Time Machine 備份。它是 Mac 內建、超簡單的備份工具,會在你誤刪檔案或電腦出事時救你。

1. 怎麼設定

  1. 接上一顆外接硬碟(容量最好大於你的 Mac)。
  2. 到系統設定 →一般 →Time Machine,把它選為備份磁碟。
  3. 開啟後,它就自動定時備份,你不用再管。

2. 回到過去

Time Machine 每小時備份、保留多個時間點。當你誤刪了檔案,或想找回某個檔案的舊版本:進入 Time Machine,畫面會變成一條時間軸,你可以往回翻到那個檔案還在的時間,選它、按「還原」,就抓回來了。

3. 換新 Mac 的救星

買新 Mac 時,可以用 Time Machine 備份,把舊 Mac 的檔案、設定、App 一次搬到新機,開機就跟原本一模一樣,不用重灌重設。

4. 為什麼一定要做

硬碟會壞、檔案會誤刪、電腦會遺失。這時候有沒有備份,是天堂和地獄的差別。這也呼應了 檔案格式課的教訓:真正保命的是備份,不是事後修復。花十分鐘設好 Time Machine,換來的是長久的安心。

動手試試

如果你有閒置的外接硬碟,接上去,到系統設定把它設為 Time Machine 備份磁碟。沒有的話,把「買一顆硬碟做備份」放進待辦清單——這是最值得的投資之一。
