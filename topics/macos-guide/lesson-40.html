模組 H｜進階與疑難排解 · 第 40 課

常見疑難排解與給 Windows 老手的最後叮嚀

這一課的目標

  • 掌握常見問題的處理順序
  • 知道何時該求助
  • 回顧整門課的核心觀念

最後一課,給你一套通用的排錯思路,以及整門課最重要的幾個提醒。

1. 排錯的通用順序

  1. 某個 App 出問題 → 先強制結束再重開它(第 39 課)。
  2. 整台怪怪的、變慢 → 重新開機(關掉再開)。八成問題這一招就解決。
  3. 某功能失常 → 檢查那個 App 或系統有沒有更新(第 34 課)。
  4. 網路問題 → 關開 Wi-Fi、重開路由器。
  5. 周邊(滑鼠、耳機)沒反應 → 拔插、換孔、檢查藍牙。
  6. 真的搞不定 → 上 Apple 支援網站查,或預約 Apple Store 的技術服務。

排錯時記得第 3 課的分層思考(第 3 課):先判斷是 App、系統、還是硬體的問題,方向就清楚了。

2. 給 Windows 老手的最後叮嚀

  1. 把「Ctrl」的反射換成「⌘」(第 19 課)。
  2. 什麼都先按 ⌘＋空白搜尋(第 15 課)。
  3. 找不到功能?抬頭看螢幕最上方的選單列(第 5 課)。
  4. 關視窗 ≠ 結束 App,⌘Q 才是結束(第 4 課)。
  5. 學會觸控板手勢(第 21 課)。
  6. 一定要設 Time Machine 備份(第 33 課)。
  7. 別硬套 Windows 邏輯——先理解 Mac 自己的規則。

3. 恭喜你

從作業系統的血統、檔案結構、找程式裝程式、鍵盤快捷鍵、視窗多工、系統設定,到疑難排解——你已經從「帶著 Windows 腦袋操作 Mac」進化成「用 Mac 的邏輯用 Mac」。接下來就是多用、多試,讓這些新習慣變成肌肉記憶。歡迎來到 Mac 的世界!

想更深入了解「檔案、副檔名、.app、磁碟映像」的底層原理,可以接著看姊妹課程 《檔案格式解剖學》。

動手試試

  2. 排錯時的「分層思考」是指什麼?
