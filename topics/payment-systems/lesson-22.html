QR code 支付

這一課的目標

  • 理解掃碼支付的兩種方式
  • 理解共通 QR code 的意義
  • 了解 QR code 支付的風險

兩種掃法

  • 主掃：你用手機掃商店的 QR code，在手機上確認金額與付款。適合小店家，只要貼一張 QR code 就能收款。
  • 被掃：你出示手機上的付款碼，讓商店的掃描器讀取。適合有收銀系統的連鎖店，速度快。

各自為政的問題

每一家支付業者都有自己的 QR code 格式，商店的櫃台上常常貼滿了不同的 QR code；消費者也要確認商店支援自己用的 App。

共通 QR code

台灣由財金公司推動共通的 QR code 標準（TWQR）：商店只要一張共通的 QR code，就能接受多家銀行與電子支付業者的 App 付款。財金公司在中間負責轉接與清算。依新聞報導，各家專營的電子支付機構已在 2024 年陸續加入。

其他國家的例子

中國的行動支付由兩大平台主導；印度以國家級的即時支付平台（UPI）串連所有銀行，QR code 支付迅速普及；新加坡等國也推動全國共通的 QR code。

風險

  • 偽造的 QR code：詐騙者把自己的 QR code 貼在商店或停車收費機上，讓錢付到錯誤的地方。
  • 釣魚連結：QR code 也可能連到假的網站。
  • 付款前確認收款人的名稱與金額。

🧭 這一課的重點
