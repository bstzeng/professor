網路商店的金流

這一課的目標

  • 理解網路商店如何收款
  • 認識支付閘道與第三方支付
  • 了解訂閱與自動扣款

網路商店怎麼收錢

一家小型的網路商店，不太可能自己和每一家銀行、每一種支付方式簽約。它通常會使用金流服務商：

  • 支付閘道：提供結帳頁面與 API，把交易送給收單行，並處理 3D 驗證、代碼化等。
  • 第三方支付（支付服務商）：以自己的名義向收單行收款，再撥款給旗下的眾多小商家。小商家不必自己通過收單行的審核。
  • 多元付款：信用卡、ATM 虛擬帳號轉帳、超商代碼繳費、電子支付等，都整合在同一個結帳頁面。

一筆網購的金流

  1. 消費者在結帳頁面選擇付款方式。
  2. 金流服務商把交易送到對應的通道（卡組織、銀行、超商系統）。
  3. 付款成功後，金流服務商以「回呼通知」告訴商店，商店把訂單改為已付款。
  4. 金流服務商定期把款項（扣除手續費）撥給商店。

訂閱與自動扣款

串流平台、雲端服務的月費，是用代碼化的卡片資料定期扣款。商店不能隨意扣款：需要事先取得你的授權，並讓你能夠取消。

代收代付的信任

第三方支付在買賣雙方之間扮演代收代付的角色，有時還提供「確認收貨後才撥款」的機制，降低網購的詐騙風險。

小型網路商店通常使用金流服務商：支付閘道提供結帳頁面 API 送收單行處理 3D 驗證代碼化、第三方支付以自己名義向收單行收款再撥給旗下小商家、多元付款信用卡 ATM 虛擬帳號超商代碼電子支付整合在同一結帳頁；網購金流選付款方式、送對應通道、付款成功回呼通知商店改訂單、定期扣手續費撥款；訂閱用代碼化卡片資料定期扣款須事先授權可取消；第三方支付代收代付有時確認收貨後才撥款降低網購詐騙。
