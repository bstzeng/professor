會走路的機器人，與車輛的自行車模型

這一課的目標

  • 直覺理解雙足平衡的原理
  • 認識四足與雙足的差別
  • 理解自駕車的自行車模型

雙足為什麼難

人站立時，腳底只有兩小塊面積接觸地面。走路時有一大半時間只有一隻腳著地——本質上是一連串「受控的跌倒」。

ZMP：零力矩點

ZMP（零力矩點）是地面反作用力的等效作用點。直覺地說：只要這個點保持在腳掌（支撐面）範圍內，機器人就不會翻倒。本田 ASIMO 等早期人形機器人就是靠精確規劃 ZMP 來走路，所以步伐很小心、膝蓋總是彎著。

新一代的人形機器人改用全身控制與強化學習（第 16、29 課），可以跑、跳、被推了還能站穩，動作也越來越像人。

四足比較簡單

  • 四條腿走路時，常常有兩到三隻腳同時著地，支撐面大得多。
  • 四足的重心低、平衡容易，所以比人形機器人更早商用（波士頓動力 Spot、宇樹）。

自駕車的自行車模型

汽車有四個輪子，但做路徑規劃時常把它簡化成一台自行車：前輪負責轉向、後輪負責推進。這個模型告訴我們一個重要的限制：車子不能橫著走，轉彎半徑由軸距與轉向角決定。

import numpy as np def bicycle_step(x, y, yaw, v, steer_deg, L=2.8, dt=0.1): """自行車模型：軸距 L，前輪轉向角 steer""" yaw += v / L * np.tan(np.radians(steer_deg)) * dt x += v * np.cos(yaw) * dt y += v * np.sin(yaw) * dt return x, y, yaw state = (0.0, 0.0, 0.0) for _ in range(50): # 以每秒 5 公尺、轉向 15 度行駛 5 秒 state = bicycle_step(*state, v=5, steer_deg=15) print(state) # 車子畫出一段圓弧

🧭 這一課的重點

雙足行走是一連串受控的跌倒，ZMP 零力矩點是地面反作用力的等效作用點，只要保持在支撐面內就不會翻倒，ASIMO 等早期機器人以此規劃步伐；新一代人形改用全身控制與強化學習，能跑跳並抵抗推擠。四足機器人支撐面大、重心低，因此更早商用。自駕車規劃常用自行車模型，前輪轉向、後輪推進，顯示車子不能橫向移動、轉彎半徑由軸距與轉向角決定。
