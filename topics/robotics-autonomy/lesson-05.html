座標轉換：機器人眼中的世界

這一課的目標

  • 理解為什麼需要多個座標系
  • 理解旋轉與平移的組合
  • 用 Python 做座標轉換

機器人身上到處都是座標系：地圖有一個、車身有一個、每顆鏡頭各有一個、每個關節也各有一個。同一個杯子，在鏡頭座標中是「前方 0.5 公尺」，在手掌座標中可能是「右邊 0.1 公尺」。

轉換 = 先旋轉，再平移

要把一個點從 A 座標系轉到 B 座標系，只需要知道 A 相對 B 的兩件事：

  • 旋轉：A 的座標軸相對 B 轉了幾度。
  • 平移：A 的原點在 B 的哪裡。

把旋轉矩陣與平移向量合在一個 4×4 的齊次轉換矩陣裡，就能用一次矩陣乘法完成轉換；多個座標系串起來，就是矩陣連乘（本站《線性代數》課有完整介紹）。

import numpy as np def T(yaw_deg, tx, ty): """2D 齊次轉換：先繞 z 軸旋轉 yaw，再平移 (tx, ty)""" c, s = np.cos(np.radians(yaw_deg)), np.sin(np.radians(yaw_deg)) return np.array([[c, -s, tx], [s, c, ty], [0, 0, 1]]) world_T_car = T(30, 100, 50) # 車在地圖上 (100, 50)，車頭朝 30 度 car_T_cam = T(0, 1.5, 0.3) # 鏡頭在車頭前方 1.5 m、偏左 0.3 m cup_in_cam = np.array([4.0, -1.0, 1]) # 鏡頭看到：前方 4 m、右邊 1 m cup_in_world = world_T_car @ car_T_cam @ cup_in_cam print(cup_in_world[:2]) # 這個行人在地圖上的位置

在真實系統中

  • ROS（機器人作業系統）用一個叫 tf 的工具，隨時追蹤數十個座標系之間的關係。
  • 自駕車出廠前要做感測器校正：精確量出每顆鏡頭、光達相對車身的位置與角度。誤差 1 度，在 50 公尺外就差將近 1 公尺。

🧭 這一課的重點

機器人身上有地圖、車身、鏡頭、關節等多個座標系，同一物體在不同座標系中的位置不同。座標轉換由旋轉與平移組成，可合併為 4×4 齊次轉換矩陣，多個座標系串接即為矩陣連乘。ROS 以 tf 追蹤數十個座標系的關係，自駕車出廠前須做感測器校正，角度誤差 1 度在 50 公尺外就差將近 1 公尺。
