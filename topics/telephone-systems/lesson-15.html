SIP 伺服器的角色

這一課的目標

  • 認識各種 SIP 伺服器
  • 理解代理伺服器與 B2BUA 的差別
  • 了解邊界控制器的功能

不同的角色

角色做什麼比喻
使用者代理（UA）電話機、軟體電話——發出與接收通話的端點打電話的人
註冊伺服器記錄每個使用者目前的位址通訊錄
代理伺服器（Proxy）轉送 SIP 訊息，幫忙找到對方；不介入通話的內容郵差
重新導向伺服器告訴發話端「請改撥這個位址」，自己不轉送問路時指路的人
背對背使用者代理（B2BUA）對兩邊各自是一個端點，把兩段通話接起來；可以完全控制通話接線生
邊界控制器（SBC）放在網路的邊界，保護內部系統、處理 NAT、轉換編碼大樓的警衛室

代理伺服器 vs. 背對背代理

這是理解轉接最重要的區分：

  • 代理伺服器：A 和 B 之間是一個 SIP 對話，代理只是幫忙傳話。它通常不知道、也不介入通話中發生的事。
  • 背對背使用者代理（B2BUA）：A 和 B2BUA 之間是一個對話，B2BUA 和 B 之間是另一個對話。B2BUA 在中間把兩段接起來，可以隨時把其中一段換掉。

幾乎所有的企業總機（例如 Asterisk、FreeSWITCH 與商用的 IP 總機）都是 B2BUA。這就是為什麼在總機上轉接時，你的通話不會斷：你一直只和總機通話（第 18、22 課）。

邊界控制器（SBC）

  • 安全：隱藏內部網路的架構，阻擋攻擊與大量的騷擾電話。
  • NAT 與媒體中繼：解決位址轉換的問題。
  • 互通：不同廠商的 SIP 實作常有差異，SBC 負責修正與轉換；也可以轉換編碼。
  • 企業連接電信業者的 SIP 中繼線，通常都會經過 SBC。

🧭 這一課的重點

角色：使用者代理 UA 電話機軟體電話端點、註冊伺服器記錄使用者位址像通訊錄、代理伺服器轉送 SIP 訊息找對方不介入像郵差、重新導向伺服器告訴改撥位址、背對背使用者代理 B2BUA 對兩邊各是一個端點把兩段接起來完全控制像接線生、邊界控制器 SBC 在網路邊界保護處理 NAT 轉編碼像警衛室；代理伺服器 A 和 B 是一個對話只傳話，B2BUA 是 A 與 B2BUA 一個對話 B2BUA 與 B 另一個在中間接起來可隨時換掉一段；幾乎所有企業總機 Asterisk FreeSWITCH 都是 B2BUA 所以轉接不會斷你一直只和總機通話；SBC 安全隱藏內部阻擋攻擊騷擾、NAT 媒體中繼、互通修正不同廠商差異轉編碼、企業連業者的 SIP 中繼線通常經過 SBC。
