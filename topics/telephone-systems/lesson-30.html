雲端話務中心與 CRM 整合

這一課的目標

  • 了解雲端話務中心的特色
  • 理解 CTI 與 CRM 整合
  • 認識 WebRTC 與通訊 API

雲端話務中心

越來越多企業不再自己架設總機，而是使用雲端話務中心：總機、語音選單、話務分配、錄音都在服務商的雲端，客服人員只要用瀏覽器登入就能接聽電話。好處是不必維護設備、可以依人數彈性付費、客服可以在家工作；代價是依賴網路品質與服務商。

電腦電話整合（CTI）

CTI 讓電話系統與電腦系統互相溝通：

  • 來電彈出：電話一響，客服的螢幕就自動顯示這位客戶的資料、訂單與過去的聯絡紀錄。
  • 點擊撥號：在客戶資料上點一下，就撥出電話。
  • 自動記錄：通話的時間、錄音、轉接紀錄自動寫進客戶關係管理系統（CRM）。
  • 資料隨著轉接：轉接時，客戶資料與語音選單的選擇一起傳給下一位客服。

WebRTC

WebRTC 讓瀏覽器直接進行語音與視訊通話，不需要安裝軟體。它使用 ICE（第 14 課）穿越 NAT、使用 Opus 等編碼，並強制加密媒體。WebRTC 本身沒有規定信令，常見的做法是用 WebSocket 傳送 SIP 或自訂的訊息。

通訊 API

雲端通訊平台把電話功能變成 API：開發者可以用程式「買一個電話號碼」、「當有人打進來時播放這段語音」、「把這通電話轉給那個號碼」、「發送語音驗證碼」。這讓電話功能可以很快地整合進各種應用程式。

AI 與語音

語音辨識、即時翻譯、通話摘要、情緒分析，以及以大型語言模型驅動的語音客服，正在改變話務中心。但它們仍然建立在本課程介紹的基礎之上：通話段、橋接、轉接與排隊。

🧭 這一課的重點

雲端話務中心總機 IVR ACD 錄音在服務商雲端客服用瀏覽器登入，好處不必維護彈性付費可在家工作，代價依賴網路與服務商；CTI 電腦電話整合：來電彈出客戶資料訂單紀錄、點擊撥號、自動記錄寫進 CRM、資料隨轉接傳給下一位；WebRTC 瀏覽器直接語音視訊不需安裝，用 ICE 穿越 NAT 用 Opus 強制加密，本身沒規定信令常用 WebSocket 傳 SIP 或自訂訊息；雲端通訊平台把電話變 API 買號碼來電播語音轉接發語音驗證碼；語音辨識翻譯摘要情緒分析大型語言模型語音客服仍建立在通話段橋接轉接排隊之上。
