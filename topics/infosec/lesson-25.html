中間人攻擊與公共 Wi-Fi

這一課的目標

  • 理解中間人攻擊的原理
  • 認識 ARP 與 DNS 欺騙
  • 了解 HTTPS 與 HSTS 如何保護你

原理

中間人攻擊（MITM）是攻擊者把自己放在你與目標之間，偷看、甚至竄改雙方的通訊，而兩邊都以為是直接在對話。

怎麼站到中間

手法做法
假冒 Wi-Fi 熱點在咖啡店架一個名字一樣的「Free_WiFi」，大家連上後所有流量都經過攻擊者
ARP 欺騙在同一個區域網路中，騙其他電腦「我才是路由器」
DNS 欺騙讓你查詢 bank.com 時，得到攻擊者的 IP
惡意路由器或代理入侵家用路由器，修改它的 DNS 設定

HTTPS 的保護

站到中間之後，如果你的連線是 HTTPS，攻擊者看到的只是加密的資料；如果他想冒充網站，拿不出正確的憑證，瀏覽器會跳出警告（第 9 課）。所以今天在公共 Wi-Fi 上，只要網站都用 HTTPS、你不忽略憑證警告，風險已經比十年前低得多。

降級攻擊與 HSTS

一個老問題：你在網址列打「bank.com」，瀏覽器先用 HTTP 連線，再被轉到 HTTPS。中間人可以在第一步攔截，讓你一直停留在 HTTP（SSL stripping）。解法是 HSTS：網站告訴瀏覽器「以後只能用 HTTPS 連我」，主要網站甚至被直接寫進瀏覽器的預載清單。

中間人仍然能看到什麼

  • 你連到哪些網域（從 DNS 查詢與連線資訊中）。
  • 沒有加密的 App 流量（少數設計不良的 App）。
  • 假冒的登入頁：熱點的「登入頁面」要你用社群帳號登入。

公共 Wi-Fi 的建議

確認熱點名稱是店家的官方名稱；不要忽略憑證警告；不要在熱點的登入頁輸入重要帳號的密碼；敏感操作改用手機行動網路；需要時使用可信任的 VPN。

🧭 這一課的重點

中間人攻擊是攻擊者在你與目標之間偷看或竄改通訊。手法有假冒同名 Wi-Fi 熱點、在區域網路假冒路由器的 ARP 欺騙、回傳錯誤 IP 的 DNS 欺騙，以及入侵路由器修改 DNS。HTTPS 讓攻擊者只看到加密資料，冒充網站會觸發憑證警告，不忽略警告則風險大幅降低。SSL stripping 在 HTTP 轉 HTTPS 前攔截，HSTS 讓瀏覽器只用 HTTPS 連線並有預載清單。中間人仍能看到你連的網域、未加密的 App 流量與假冒登入頁。公共 Wi-Fi 建議確認熱點名稱、不忽略警告、不在登入頁輸入重要密碼、敏感操作改用行動網路或可信 VPN。

🛡️ 本課程只介紹攻擊的原理與防禦方法，所有示範都是在瀏覽器內的模擬，不會連線到任何系統。未經授權入侵他人系統是違法行為（刑法第 358～363 條妨害電腦使用罪）；想練習請使用合法的靶場與 CTF。
