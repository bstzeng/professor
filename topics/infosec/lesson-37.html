滲透測試、紅藍隊與 CTF

這一課的目標

  • 理解滲透測試與紅隊演練
  • 認識 CTF 競賽的類型
  • 知道合法的練習資源

滲透測試

滲透測試是組織聘請專業人員，在書面授權、明確範圍內，模擬攻擊者找出漏洞，並提出報告與修補建議。

  • 範圍：哪些系統可以測、哪些不行；可以用哪些手法（例如是否包含社交工程）。
  • 時間：避免在營運尖峰造成影響。
  • 規則：發現嚴重漏洞時立刻通知；不刪改資料。

紅隊、藍隊、紫隊

隊伍角色
紅隊扮演真實的攻擊者，目標導向（例如「拿到財務系統的資料」），測試整個組織的偵測與應變，而不只是找漏洞
藍隊防守方：監控、偵測、應變
紫隊紅藍合作：紅隊每做一步，就和藍隊一起檢查「這個我們偵測得到嗎？」

CTF 奪旗賽

CTF（Capture The Flag）是資安競賽：題目中藏著一段特殊字串（旗子），解開題目就能拿到。

類別內容
Web網頁漏洞（本課程模組 C 的內容）
Pwn二進位漏洞利用，如緩衝區溢位（第 20 課）
Reverse逆向工程：分析程式在做什麼
Crypto密碼學：找出加密設計的弱點
Forensics數位鑑識：從封包、硬碟映像、記憶體中找線索
Misc雜項：隱寫術、程式設計、開放情報
  • 解題式（Jeopardy）：各類題目，解越多分越高，適合入門。
  • 攻防式（Attack-Defense）：每隊有自己的伺服器，要修補自己的漏洞，同時攻擊別人。
  • 台灣有 HITCON CTF 等國際知名的賽事，台灣的隊伍也曾在 DEF CON CTF 決賽中名列前茅。

合法的練習資源

  • PortSwigger Web Security Academy：免費、完整的網頁安全教材與實驗室。
  • OWASP Juice Shop：故意寫得很不安全的網站，可以在自己的電腦上執行。
  • picoCTF：卡內基美隆大學為學生設計的入門 CTF。
  • Hack The Box、TryHackMe 等線上靶場平台。
  • 在自己的電腦用虛擬機架設實驗環境。

再提醒一次

這些技能只能用在自己的系統、合法的靶場與有書面授權的對象。好奇心是成為資安人的起點，但未經授權的測試可能讓你吃上官司（第 5 課）。

🧭 這一課的重點

滲透測試是在書面授權與明確範圍內模擬攻擊者找漏洞並提出報告，需約定範圍、時間與規則。紅隊扮演目標導向的攻擊者測試偵測與應變，藍隊是防守方，紫隊是紅藍合作檢查偵測能力。CTF 奪旗賽的類別有 Web、Pwn、Reverse、Crypto、Forensics 與 Misc，分為適合入門的解題式與修補兼攻擊的攻防式，台灣有 HITCON CTF，台灣隊伍曾在 DEF CON CTF 名列前茅。合法練習資源有 PortSwigger Web Security Academy、OWASP Juice Shop、picoCTF、Hack The Box、TryHackMe 與自架虛擬機。技能只能用在自己的系統、靶場與有書面授權的對象。

🛡️ 本課程只介紹攻擊的原理與防禦方法，所有示範都是在瀏覽器內的模擬，不會連線到任何系統。未經授權入侵他人系統是違法行為（刑法第 358～363 條妨害電腦使用罪）；想練習請使用合法的靶場與 CTF。
