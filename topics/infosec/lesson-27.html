零日漏洞與漏洞市場

這一課的目標

  • 理解漏洞的生命週期與 CVE、CVSS
  • 理解零日漏洞與漏洞市場
  • 認識商業間諜軟體的爭議

漏洞的生命週期

  1. 漏洞被引入程式碼（可能已經存在很多年）。
  2. 有人發現了它——研究者、廠商，或攻擊者。
  3. 廠商得知並開發修補。
  4. 修補發布，漏洞公開。
  5. 使用者安裝更新——這一步常常最慢。

零日漏洞是指廠商還不知道、或還沒有修補的漏洞——防守方有「零天」的時間準備。

CVE 與 CVSS

  • CVE：每一個公開的漏洞得到一個編號，例如 CVE-2021-44228（Log4Shell），讓全世界用同一個名字指稱它。
  • CVSS：0～10 分的嚴重度評分，考慮能否遠端利用、是否需要登入、影響範圍等。9.0 以上為「嚴重」。
  • 每年公開的 CVE 數量已經達到數萬個——沒有人能全部修補，必須依風險排序。

修補的賽跑

修補一公開，攻擊者就能比對新舊版本的差異，反推出漏洞的位置。重大漏洞常常在公開後幾天甚至幾小時內就被大規模利用。許多入侵事件利用的不是零日，而是早已有修補、卻沒有更新的「N 日漏洞」。

漏洞市場

買家目的
廠商的漏洞獎勵計畫修補漏洞
漏洞仲介公司轉賣給政府客戶，用於情報與執法
犯罪集團用於攻擊與勒索

可以遠端、不需要使用者任何操作就入侵最新版手機的「零點擊」漏洞鏈，價格可達數百萬美元。

商業間諜軟體

以色列 NSO 集團的 Pegasus 間諜軟體，利用零點擊漏洞入侵手機，可以讀取訊息、開啟麥克風與鏡頭。它號稱只賣給政府用於反恐，但調查發現它被用來監視記者、律師與異議人士。美國在 2021 年把 NSO 列入出口管制的實體清單。

為什麼要開自動更新

對一般人來說，零日攻擊很少見；真正的威脅是已經公開的漏洞。開啟自動更新，就是對抗「修補的賽跑」最有效的方法。

🧭 這一課的重點

漏洞的生命週期是引入、被發現、廠商修補、公開、使用者更新，最後一步最慢；零日漏洞是廠商未知或未修補的漏洞。CVE 為每個公開漏洞編號，CVSS 以 0～10 分評嚴重度，每年數萬個 CVE 必須依風險排序。修補公開後攻擊者能比對差異，重大漏洞幾天甚至幾小時內被大規模利用，許多入侵利用的是未更新的 N 日漏洞。漏洞買家有獎勵計畫、轉賣給政府的仲介與犯罪集團，零點擊漏洞鏈價格可達數百萬美元。NSO 的 Pegasus 以零點擊入侵手機，被用來監視記者與異議人士，2021 年被美國列入實體清單。對一般人最有效的是開啟自動更新。

🛡️ 本課程只介紹攻擊的原理與防禦方法，所有示範都是在瀏覽器內的模擬，不會連線到任何系統。未經授權入侵他人系統是違法行為（刑法第 358～363 條妨害電腦使用罪）；想練習請使用合法的靶場與 CTF。
