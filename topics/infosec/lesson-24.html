DDoS 分散式阻斷服務

這一課的目標

  • 理解 DDoS 的原理與類型
  • 理解反射放大攻擊
  • 認識 DDoS 的防禦方法

原理

阻斷服務攻擊不偷資料，而是破壞可用性：用大量的請求塞滿網路頻寬、耗盡伺服器資源，讓正常的使用者無法連線。「分散式」是指攻擊來自成千上萬台被控制的裝置——殭屍網路，很難單純封鎖來源。

三種類型

類型目標例子
流量型塞滿網路頻寬大量的 UDP 封包、反射放大攻擊
協定型耗盡伺服器或防火牆的連線表SYN 洪水：只開始、不完成 TCP 連線
應用層耗盡應用程式的運算資源大量請求搜尋、登入等很耗資源的頁面，看起來像正常使用者

反射放大

有些網路服務，收到一個小小的查詢，會回覆一個大很多的回應。攻擊者偽造來源 IP為受害者的位址，向大量的這類伺服器發出查詢——所有的大回應都湧向受害者：

\[\text{打到受害者的流量} = \text{攻擊者送出的流量} \times \text{放大倍數}\]

DNS、NTP 的放大倍數可達數十到數百倍；2018 年攻擊者利用設定錯誤的 memcached 伺服器（放大倍數可上萬倍），對 GitHub 發動了約 1.35 Tbps 的攻擊。

Mirai：物聯網殭屍網路

2016 年的 Mirai 惡意程式，掃描網路上使用預設帳號密碼的網路攝影機、路由器，控制了數十萬台裝置，對 DNS 服務商 Dyn 發動攻擊，讓 Twitter、Netflix、GitHub 等大網站在美國部分地區無法連線。原始碼公開後，衍生出大量變種。

防禦

  • CDN 與清洗中心：用分散在全球的龐大頻寬吸收攻擊流量，過濾後再把正常流量送到網站。
  • 限速、驗證碼、對異常的請求模式做挑戰。
  • 雲端的自動擴展——但要注意帳單也會跟著擴展。
  • 網路業者過濾偽造來源 IP 的封包（BCP 38），從源頭減少反射攻擊。
  • 改掉物聯網裝置的預設密碼，避免自己的裝置成為殭屍。

台灣的經驗

台灣政府與企業網站常在政治敏感的時刻遭受 DDoS，例如 2022 年美國眾議院議長裴洛西訪台期間，多個政府網站一度無法連線。DDoS 常與假訊息搭配，製造「政府系統癱瘓」的恐慌。

🧭 這一課的重點

阻斷服務攻擊破壞可用性，以大量請求塞滿頻寬或耗盡資源，分散式攻擊來自大量被控制的殭屍網路。類型有塞滿頻寬的流量型、耗盡連線表的協定型如 SYN 洪水，以及耗盡運算資源、看似正常使用者的應用層攻擊。反射放大偽造受害者 IP 向大量伺服器查詢，小查詢換大回應，DNS、NTP 放大數十到數百倍，2018 年 memcached 對 GitHub 發動約 1.35 Tbps。2016 年 Mirai 控制數十萬台用預設密碼的物聯網裝置攻擊 Dyn，使多個大網站斷線。防禦有 CDN 與清洗中心、限速與挑戰、雲端擴展、業者過濾偽造來源（BCP 38）、改掉預設密碼。台灣在 2022 年裴洛西訪台時多個政府網站遭 DDoS。

🛡️ 本課程只介紹攻擊的原理與防禦方法，所有示範都是在瀏覽器內的模擬，不會連線到任何系統。未經授權入侵他人系統是違法行為（刑法第 358～363 條妨害電腦使用罪）；想練習請使用合法的靶場與 CTF。
