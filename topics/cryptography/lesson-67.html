名詞與流程速查

這一課的目標

  • 取得名詞速查表
  • 掌握常用的判斷流程
  • 總結速查模組

本課是名詞與流程的整理。

1. 基本名詞

名詞意思
明文加密前的原始資料
密文加密後的資料
對稱式加密加解密用同一把金鑰
公開金鑰密碼加解密用不同的金鑰，公鑰可公開
雜湊把任意長度壓成固定長度，不可逆
鹽每個使用者不同的隨機值，與密碼一起雜湊
初始向量讓相同明文產生不同密文的隨機起始值
熵不可預測性的量，以位元計
前向保密長期金鑰外洩後，過去的通訊仍安全
不可否認性簽署者事後無法否認

2. 攻擊相關

名詞意思
已知明文攻擊攻擊者知道部分明文與對應密文
選擇明文攻擊攻擊者可指定明文要求加密
中間人攻擊攻擊者分別與雙方通訊並轉譯
生日攻擊利用配對數量找碰撞，強度減半
旁通道攻擊由時間、耗電等物理特徵推出秘密
預言機攻擊利用系統回應的差異逐步取得資訊
降級攻擊誘使雙方使用較弱的演算法
深度攻擊利用重複使用的金鑰流

3. 三個判斷流程

我該用什麼來保護資料

  1. 要保密嗎 → 對稱式加密（用驗證加密模式）
  2. 雙方怎麼取得金鑰 → 金鑰交換或公鑰加密
  3. 要確認對方是誰嗎 → 簽章與憑證
  4. 只要確認沒被改嗎 → 雜湊加金鑰（訊息驗證碼）
  5. 要能對第三方證明嗎 → 必須用簽章

我該用多長的金鑰

  1. 先決定要保護幾年
  2. 查安全強度對照表，找到對應的長度
  3. 資料保密期超過十年 → 考慮後量子或混合方案
  4. 寧可選長一點——加長的成本遠低於事後遷移

我懷疑某個做法有問題

  1. 有沒有重複使用任何應該一次性的東西
  2. 亂數是不是來自安全的來源
  3. 有沒有只加密而沒有驗證
  4. 錯誤處理會不會洩漏資訊
  5. 金鑰存在哪裡，會不會進到版本控制
  6. 用的演算法有沒有被淘汰

模組 R 重點回顧

  • DES、MD5、SHA-1、ECB 模式皆已淘汰
  • 不同類型演算法的位元數須查強度對照表，不可直接比較
  • 恩尼格瑪的兩個結構缺陷都源自反射器
  • 三個判斷流程可涵蓋多數實務情境
