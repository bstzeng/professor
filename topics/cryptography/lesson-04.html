模組 A｜序幕：密碼學到底在解決什麼 · 第 4 課

課程地圖與閱讀路徑

這一課的目標

  • 取得完整課程地圖
  • 知道各區塊的依賴關係
  • 依需求選擇路徑

本課程共十九個模組、六十九課，分為四個區塊。

2. 依賴關係

  • 恩尼格瑪四個模組（C 到 F）可以獨立閱讀，只需要模組 A 與 B 的背景
  • 模組 I（數論）是 K 與 L 的前置，跳過它會看不懂 RSA 為何成立
  • M、N、O、P 彼此獨立，可依興趣選讀

3. 閱讀路徑

你的目的路徑
只想搞懂恩尼格瑪A → B → C → D → E → F
想理解 HTTPS 怎麼運作A → H → J → M → N
想真正弄懂 RSAA → I → J → K
寫程式要用密碼學A → H → M → O → Q → R
關心量子電腦的威脅A → J → K → P
從歷史線切入B → C → D → E → G → J

4. 前置知識

需要程度備註
恩尼格瑪部分不需要任何數學只需要能理解電流走過一條線路
模組 I 到 L國中程度的整數運算模運算會從零教起
模組 M 到 P基本的程式概念會有幫助非必要

本課程不需要微積分，也不需要抽象代數。 最難的一段是模組 K 的 RSA 推導，用到的工具在模組 I 會完整鋪好。

模組 A 重點回顧

  • 三個目標是保密、驗證與完整，後兩者往往更關鍵
  • 柯克霍夫原則：設計全公開，安全性只能靠金鑰
  • 安全是成本問題；現代標準假設攻擊者能選擇明文
  • 恩尼格瑪四個模組可獨立閱讀，數論是 RSA 的前置

檢查你的理解

  1. 說出課程的四個區塊
  2. 指出哪個模組是 RSA 的必要前置
  3. 依自己的需求選出一條路徑
