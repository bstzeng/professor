模組 G｜現代密碼學的起點 · 第 28 課

維諾那計畫：重複使用的代價

這一課的目標

  • 認識維諾那計畫
  • 理解重複使用為何致命
  • 掌握這個案例的普遍意義

上一課說「金鑰只能用一次」。本課看違反它的代價。

1. 背景

項目內容
時間美國自一九四〇年代初展開，持續數十年
目標蘇聯以一次性密碼本加密的外交與情報電文
理論上應該完全無法破解
實際上相當數量的電文被解讀

2. 出了什麼事

戰時的生產壓力下，蘇聯的密碼本製作單位 重複印製了部分頁面。

於是同一段金鑰被用在了兩則不同的訊息上。

3. 為什麼這是災難

假設兩則訊息用了同一段金鑰：

\[ c_1 = m_1 \oplus k, \qquad c_2 = m_2 \oplus k \]

把兩個密文互斥或起來：

\[ c_1 \oplus c_2 = (m_1 \oplus k) \oplus (m_2 \oplus k) = m_1 \oplus m_2 \]

金鑰完全消失了。

攻擊者手上現在有兩段明文互斥或的結果—— 而這等於是一個「兩段自然語言疊在一起」的問題， 可以用模組 B 的統計方法逐步拆開。

這種攻擊有個名字：深度攻擊。 只要有兩則以上共用金鑰的訊息，破解就變得可行； 訊息愈多，愈容易。

4. 後果

  • 解讀出的內容揭露了多起重大的情報滲透案
  • 包括涉及核武計畫的情報外洩
  • 計畫本身高度保密，直到一九九〇年代才公開

注意這個模式與恩尼格瑪完全一致：

  • 演算法在數學上無懈可擊
  • 失敗發生在製作與使用的環節
  • 被破的一方長期不知情

5. 這個教訓的現代版本

「金鑰或隨機值不可重複使用」在今天有更多具體的形式：

場景重複使用的後果
串流加密的初始向量重複與本課完全相同的深度攻擊
特定加密模式的隨機值重複可能直接導致金鑰外洩
數位簽章的隨機數重複私鑰可以被直接算出來
密碼儲存不加鹽相同密碼產生相同雜湊，可批次破解

第三列曾經造成真實的重大事故。 某些系統因為簽章時使用的隨機數重複或可預測， 導致私鑰被完整還原——這類事件在遊戲主機與加密貨幣領域都發生過。

一次性的東西用了兩次，代價往往不是「安全性下降一半」， 而是「完全歸零」。

模組 G 重點回顧

  • 夏農定義了完美保密，並證明它需要與訊息等長的金鑰
  • 一次性密碼本是唯一達成完美保密的方法，但金鑰分發是死結
  • 重複使用金鑰會讓金鑰在互斥或中消失，導致深度攻擊
  • 「一次性的東西用兩次」在現代仍持續造成完全性的失敗
