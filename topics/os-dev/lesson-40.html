寫一個 Shell

這一課的目標

  • 理解 shell 的基本迴圈
  • 實作執行外部指令
  • 知道為什麼 cd 是內建指令
// user/sh.c：一個迷你 shell int main(void) { char line[256], *argv[16]; for (;;) { write(1, "$ ", 2); if (read_line(line, sizeof line) <= 0) break; int argc = split(line, argv); // "ls -l" → {"ls", "-l", NULL} if (argc == 0) continue; if (strcmp(argv[0], "cd") == 0) { chdir(argv[1]); continue; } // 內建指令 if (strcmp(argv[0], "exit") == 0) break; pid_t pid = fork(); if (pid == 0) { execvp(argv[0], argv); write(2, "not found\n", 10); _exit(127); } waitpid(pid, NULL, 0); } return 0; }

為什麼 cd 必須是內建指令？因為「目前目錄」是行程自己的屬性。如果 cd 是外部程式，它改的是子行程的目錄，子行程結束後 shell 的目錄並沒有變。

到這一步，我們的作業系統終於可以開機後讓使用者打字、執行程式了。

🧭 這一課的重點

shell 就是一個讀取、拆解、fork＋exec＋wait 的迴圈；改變自身狀態的指令必須內建。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
