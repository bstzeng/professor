CPU 模式：真實、保護、長模式

這一課的目標

  • 認識 x86 的三種模式
  • 理解 GDT 的角色
  • 知道進入長模式的條件

為了相容 1978 年的 8086，今天的 x86 CPU 開機時仍處於 16 位元真實模式。進入 64 位元長模式需要：

  1. 建立 GDT（全域描述表），定義程式碼與資料區段。
  2. 建立頁表（長模式強制要求分頁）。
  3. 開啟 CR4.PAE、設定 EFER.LME，最後開啟 CR0.PG 分頁。
  4. 遠跳躍到 64 位元的程式碼區段。
; 64 位元下仍然需要一個極簡的 GDT gdt: dq 0 ; 空描述子 dq 0x00AF9A000000FFFF ; 核心程式碼（64 位元） dq 0x00AF92000000FFFF ; 核心資料 dq 0x00AFFA000000FFFF ; 使用者程式碼（權限 3） dq 0x00AFF2000000FFFF ; 使用者資料

即使開機程式已經切好模式，核心仍會載入自己的 GDT，因為之後要加入使用者模式的區段與 TSS（第 26 課）。

🧭 這一課的重點

x86 從 16 位元真實模式一路切到 64 位元長模式；長模式需要 GDT 與分頁。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
