模組 F｜檔案系統與裝置 · 第 35 課

設計一個簡單的檔案系統

這一課的目標

  • 理解檔案系統的磁碟配置
  • 認識 inode 的區塊指標
  • 實作路徑查找
struct disk_inode { uint16_t mode; uint32_t size; uint32_t direct[12]; // 前 12 個區塊直接指向 uint32_t indirect; // 這個區塊裡存的是更多區塊編號 }; struct dirent { uint32_t ino; char name[28]; }; // 目錄內容就是一串 dirent uint32_t lookup(const char* path) { // "/home/a.txt" uint32_t ino = ROOT_INO; for (char* part = strtok(path, "/"); part; part = strtok(NULL, "/")) ino = dir_find(ino, part); // 讀目錄 inode 的內容，找名稱 return ino; }

有了這個結構，open＝查路徑得到 inode；read＝依位置算出第幾個區塊、讀出來；write 可能需要從資料點陣圖配置新區塊。這就是 Unix 檔案系統（以及 ext2）的基本設計。

🧭 這一課的重點

檔案系統用超級區塊、點陣圖、inode 表與資料區塊組織磁碟；目錄是名稱到 inode 的對照表。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
