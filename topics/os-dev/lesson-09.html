在螢幕上印字

這一課的目標

  • 理解記憶體映射 I/O
  • 寫出 VGA 文字輸出
  • 知道 framebuffer 的做法
// 傳統 BIOS 開機：寫入 0xB8000 就會出現在螢幕上 static volatile uint16_t* const vga = (uint16_t*)0xB8000; static int col = 0, row = 0; void vga_putc(char c) { if (c == '\n') { col = 0; row++; return; } vga[row * 80 + col] = (uint16_t)c | (0x07 << 8); // 0x07：黑底灰字 if (++col == 80) { col = 0; row++; } }

這叫記憶體映射 I/O：某段實體位址其實不是 RAM，而是連到顯示卡。UEFI 開機時沒有文字模式，開機程式會給我們一塊像素 framebuffer（位址、寬、高、每列位元組數），核心需要自己畫字型點陣。

🧭 這一課的重點

寫入特定的記憶體位址就能控制硬體（記憶體映射 I/O）；文字模式最簡單，framebuffer 更通用。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
