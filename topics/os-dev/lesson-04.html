模組 A｜開始之前 · 第 4 課

專案結構

這一課的目標

  • 認識教學核心的專案結構
  • 理解連結器腳本
  • 知道核心映像的組成
myos/ ├── boot/ # 開機設定（使用 Limine 開機程式） ├── kernel/ │ ├── arch/x86_64/ # 與 CPU 相關：進入點、GDT、IDT、情境切換（組合語言） │ ├── mm/ # 記憶體管理 │ ├── sched/ # 行程與排程 │ ├── fs/ # 檔案系統 │ ├── drivers/ # 序列埠、鍵盤、磁碟 │ └── main.c # kmain() ├── libc/ # 給使用者程式用的迷你 C 函式庫 ├── user/ # 使用者程式：init、sh └── linker.ld
/* linker.ld：告訴連結器核心要放在記憶體的哪裡 */ ENTRY(_start) SECTIONS { . = 0xffffffff80000000; /* 核心位於位址空間最上方 2 GB */ .text : { *(.text*) } .rodata : { *(.rodata*) } .data : { *(.data*) } .bss : { *(COMMON) *(.bss*) } }

注意 arch/ 資料夾：和 CPU 架構有關的程式集中在這裡，其他部分用 C 寫成與架構無關，Linux 也是這樣組織的（第 44 課）。

🧭 這一課的重點

核心專案依子系統分資料夾，把架構相關程式碼集中；連結器腳本決定核心在記憶體中的位置。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
