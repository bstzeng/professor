驅動程式模型

這一課的目標

  • 理解驅動程式的分層
  • 認識裝置的三種類型
  • 知道驅動與裝置的配對
struct block_device_ops { // 區塊裝置介面：上層只認識這些函式 int (*read)(struct block_dev*, uint64_t lba, void* buf, size_t count); int (*write)(struct block_dev*, uint64_t lba, const void* buf, size_t count); }; struct pci_driver nvme_driver = { .name = "nvme", .class_code = 0x010802, // 大容量儲存／非揮發性記憶體／NVMe .probe = nvme_probe, // 找到符合的裝置時呼叫 };
類型特點例子
字元裝置一個位元組一個位元組地讀寫鍵盤、序列埠、終端機
區塊裝置以固定大小的區塊隨機存取硬碟、SSD
網路裝置收發封包網卡

🧭 這一課的重點

驅動程式把各種硬體翻譯成統一的介面；匯流排負責發現裝置並找到對應的驅動。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
