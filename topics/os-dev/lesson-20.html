核心堆積：kmalloc 與 slab

這一課的目標

  • 理解核心堆積的需求
  • 認識 slab 配置器
  • 實作簡單的 kmalloc
// 依大小分級：8、16、32、64……2048 位元組各一個快取 struct cache { size_t obj_size; void* free_list; }; static struct cache caches[9]; void* kmalloc(size_t n) { struct cache* c = pick_cache(n); // 找到 >= n 的最小級距 if (!c->free_list) refill(c); // 從頁框配置器拿一頁，切成小格串起來 void* obj = c->free_list; c->free_list = *(void**)obj; // 空閒格的開頭存著下一個空閒格 return obj; } void kfree(void* p) { struct cache* c = cache_of(p); *(void**)p = c->free_list; c->free_list = p; }

Linux 為常用的核心物件（行程描述、inode、網路封包）各建專用快取，配置與釋放都非常快，也減少碎片。這個想法最早由 Sun 的 Solaris 提出。

🧭 這一課的重點

頁框配置器只給整頁；slab 把頁切成固定大小的格子，提供快速的 kmalloc／kfree。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
