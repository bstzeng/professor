計時器中斷

這一課的目標

  • 認識計時器硬體
  • 理解中斷控制器
  • 實作系統時鐘
// 舊式 PIT（8254）：輸入頻率約 1.193182 MHz，除以 N 得到中斷頻率 void pit_init(int hz) { uint16_t div = 1193182 / hz; outb(0x43, 0x36); // 通道 0，方波模式 outb(0x40, div & 0xFF); outb(0x40, div >> 8); } volatile uint64_t ticks; void timer_irq(struct regs* r) { ticks++; send_eoi(0); // 通知中斷控制器：處理完了 schedule_tick(); // 讓排程器決定要不要換行程（第 25 課） }
  • 中斷控制器：舊的 8259 PIC 預設把 IRQ 0～7 對應到向量 8～15，正好和 CPU 例外重疊，所以第一件事是把它重新對應到 32 以後。現代系統改用 APIC。
  • EOI：每次處理完都要告訴中斷控制器，否則不會再收到同一條線的中斷。
  • 現代做法：每顆 CPU 有自己的 Local APIC 計時器；Linux 也支援「無滴答」模式，閒置時不產生定時中斷以省電。

🧭 這一課的重點

計時器中斷提供時間來源並讓核心定期取回控制權；記得重新對應 PIC 並送出 EOI。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
