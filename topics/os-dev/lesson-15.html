鍵盤驅動

這一課的目標

  • 理解掃描碼
  • 寫出鍵盤中斷處理
  • 認識環形緩衝區
// PS/2 鍵盤：IRQ1；從連接埠 0x60 讀掃描碼 static const char keymap[128] = { 0, 27, '1','2','3','4','5','6','7','8','9','0','-','=','\b', '\t','q','w','e','r','t','y','u','i','o','p','[',']','\n', /* … */ }; static char buf[256]; static uint8_t head, tail; // 環形緩衝區 void keyboard_irq(struct regs* r) { uint8_t sc = inb(0x60); if (!(sc & 0x80)) { // 最高位元 1 表示放開，0 表示按下 char c = keymap[sc]; if (c) buf[head++] = c; // uint8_t 自動在 256 繞回 } send_eoi(1); } int kbd_getc(void) { // 給終端機用（第 39 課） while (head == tail) asm volatile("hlt"); // 沒有字就睡到下一次中斷 return buf[tail++]; }

中斷處理程式要越短越好：只把資料放進緩衝區就返回，真正的處理留給之後的程式。這個「上半部／下半部」的分工在 Linux 驅動中非常普遍。

🧭 這一課的重點

鍵盤中斷讀取掃描碼放進環形緩衝區；中斷處理程式只做最少的事。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
