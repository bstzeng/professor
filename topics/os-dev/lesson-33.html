模組 F｜檔案系統與裝置 · 第 33 課

磁碟驅動

這一課的目標

  • 理解區塊與 LBA
  • 認識 AHCI、NVMe、virtio
  • 知道 DMA 的作用
介面特點
AHCI（SATA）一個命令佇列、最多 32 個命令
NVMe為 SSD 設計：最多 65535 個佇列，每個 CPU 可以有自己的佇列
virtio-blk虛擬機專用：QEMU 等模擬器提供的簡化介面，最適合教學核心
// 概念：送出一個讀取請求（以 NVMe 風格的佇列為例） struct cmd c = { .opcode = READ, .lba = 2048, .count = 8, .dma_addr = virt_to_phys(buf) }; sq[sq_tail] = c; // 放進「提交佇列」 sq_tail = (sq_tail + 1) % QSIZE; mmio_write(doorbell, sq_tail); // 按門鈴：通知控制器 // ……控制器用 DMA 把資料直接寫進 buf，完成後在「完成佇列」放一筆記錄並發出中斷
  • LBA：以區塊編號定位，不再用磁頭、磁柱這些物理概念。區塊常見 512 或 4096 位元組。
  • DMA：裝置直接讀寫記憶體，CPU 不必一個個位元組搬運，可以去做別的事。

🧭 這一課的重點

磁碟以 LBA 區塊存取；現代控制器用命令佇列＋門鈴＋DMA＋完成中斷運作。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
