載入第一個使用者程式

這一課的目標

  • 理解 ELF 的程式標頭
  • 實作簡單的 ELF 載入器
  • 準備使用者堆疊
int exec_elf(struct process* p, const uint8_t* img) { Elf64_Ehdr* eh = (Elf64_Ehdr*)img; if (memcmp(eh->e_ident, "\x7f" "ELF", 4) != 0) return -ENOEXEC; Elf64_Phdr* ph = (Elf64_Phdr*)(img + eh->e_phoff); for (int i = 0; i < eh->e_phnum; i++) { if (ph[i].p_type != PT_LOAD) continue; map_user_range(p, ph[i].p_vaddr, ph[i].p_memsz, flags_of(ph[i].p_flags)); memcpy_to_user(p, ph[i].p_vaddr, img + ph[i].p_offset, ph[i].p_filesz); // p_memsz > p_filesz 的部分（.bss）保持為 0 } setup_user_stack(p, argv, envp); // 放入 argc、argv 指標、環境變數 p->entry = eh->e_entry; return 0; }

真實系統還要處理動態連結：程式標頭裡有 PT_INTERP 時，核心先載入動態連結器（如 ld-linux.so），由它載入共用函式庫。完整過程見 〈執行檔是怎麼跑起來的〉。

🧭 這一課的重點

核心依 ELF 的 PT_LOAD 程式標頭建立映射、複製內容、準備堆疊，再跳到進入點。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
