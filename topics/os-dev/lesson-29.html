fork、exec、wait、exit

這一課的目標

  • 理解四個行程系統呼叫
  • 知道殭屍與孤兒行程
  • 看見寫入時複製的作用
pid_t pid = fork(); // 一次呼叫，兩次回傳 if (pid == 0) { // 子行程 execl("/bin/ls", "ls", "-l", NULL); _exit(127); // exec 成功就不會回到這裡 } else { // 父行程 int status; waitpid(pid, &status, 0); // 等子行程結束 }
概念說明
殭屍行程已經結束、但父行程還沒 wait 的行程；PCB 保留著結束碼
孤兒行程父行程先結束了，由 init（PID 1）收養
寫入時複製fork 不真的複製記憶體（第 22 課）
Windows 的做法CreateProcess 一次完成「建立＋載入程式」，沒有 fork

🧭 這一課的重點

fork 複製行程、exec 換成新程式、wait 回收子行程、exit 結束；寫入時複製讓這套組合很有效率。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
