網路堆疊概觀

這一課的目標

  • 理解網路堆疊的分層
  • 知道封包的收送路徑
  • 認識 socket 介面
int s = socket(AF_INET, SOCK_STREAM, 0); // 建立 TCP socket（它也是檔案描述元） connect(s, (struct sockaddr*)&addr, sizeof addr); write(s, "GET / HTTP/1.0\r\n\r\n", 18); read(s, buf, sizeof buf);
  • 收封包：網卡用 DMA 放進環形緩衝區 → 中斷 → 驅動交給 IP 層 → TCP 依連接埠找到 socket → 喚醒在 read 等待的行程。
  • socket 是檔案描述元：VFS 的威力再次出現（第 34 課）。
  • 現代最佳化：中斷合併、多佇列網卡、零複製傳送。

各層協定的細節見 〈網路〉。

🧭 這一課的重點

核心的網路堆疊由驅動、鏈結、網路、傳輸層組成，最後以 socket 這個檔案描述元交給程式。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。

  2. 為什麼 socket 可以用 read／write？
  3. 多佇列網卡有什麼好處？
