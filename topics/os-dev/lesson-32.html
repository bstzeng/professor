PCI 與裝置探索

這一課的目標

  • 理解 PCI 設定空間
  • 寫出列舉 PCI 裝置的程式
  • 認識 BAR
// 每個 PCI 功能有 256 位元組（PCIe 為 4 KB）的設定空間 // 0x00：廠商 ID 0x02：裝置 ID 0x0B：類別碼 0x10～0x24：BAR0～BAR5 for (int bus = 0; bus < 256; bus++) for (int dev = 0; dev < 32; dev++) for (int fn = 0; fn < 8; fn++) { uint16_t vendor = pci_read16(bus, dev, fn, 0x00); if (vendor == 0xFFFF) continue; // 這個位置沒有裝置 uint16_t device = pci_read16(bus, dev, fn, 0x02); uint32_t cls = pci_read32(bus, dev, fn, 0x08) >> 8; kprintf("%x:%x.%x %x:%x class %x\n", bus, dev, fn, vendor, device, cls); match_driver(bus, dev, fn, vendor, device, cls); }
  • BAR（基底位址暫存器）：告訴我們裝置的暫存器被映射到哪段實體位址，驅動再把它映射到核心位址空間（記憶體映射 I/O）。
  • PCIe 的 ECAM：設定空間本身也映射到記憶體，位址來自 ACPI 的 MCFG 表。
  • MSI 中斷：現代裝置用寫入特定記憶體位址的方式發出中斷，不再依賴共用的中斷線。

Linux 的 lspci 指令就是讀這些資訊。

🧭 這一課的重點

列舉 PCI 設定空間就能找到所有裝置；BAR 告訴驅動裝置暫存器在哪裡。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
