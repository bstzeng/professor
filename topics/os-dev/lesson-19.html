核心的位址空間

這一課的目標

  • 理解位址空間的分配
  • 認識上半部核心
  • 知道直接映射的用途
  • 上半部核心：核心放在位址空間最上方，使用者程式用下半部；這樣每個行程的位址空間都可以「共用」同一份核心映射。
  • 直接映射：把所有實體記憶體連續映射到核心空間的某一段（Linux 稱為 direct map），核心要存取某個實體位址時，只要加上固定偏移。
  • 非正規位址：48 位元虛擬位址的高 16 位必須和第 47 位相同，中間的巨大空洞不能使用（存取會觸發 #GP）。
#define HHDM_OFFSET 0xffff800000000000ull // 直接映射的起點（由開機程式提供） static inline void* phys_to_virt(uint64_t p) { return (void*)(p + HHDM_OFFSET); }

🧭 這一課的重點

核心在上半部、使用者在下半部；直接映射讓核心能方便地存取任何實體記憶體。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
