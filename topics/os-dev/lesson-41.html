管線與重新導向

這一課的目標

  • 理解檔案描述元
  • 實作重新導向
  • 實作管線
// 重新導向：cmd > out.txt if (fork() == 0) { int fd = open("out.txt", O_WRONLY | O_CREAT | O_TRUNC, 0644); dup2(fd, 1); // 讓 1 號（stdout）指向 out.txt close(fd); execvp(cmd[0], cmd); // 程式完全不知道輸出被導向檔案了 } // 管線：ls | grep txt int p[2]; pipe(p); // p[0] 讀端、p[1] 寫端 if (fork() == 0) { dup2(p[1], 1); close(p[0]); close(p[1]); execlp("ls", "ls", NULL); } if (fork() == 0) { dup2(p[0], 0); close(p[0]); close(p[1]); execlp("grep", "grep", "txt", NULL); } close(p[0]); close(p[1]); wait(NULL); wait(NULL);

關鍵：fork 會複製檔案描述元表，exec 會保留它。shell 在 fork 之後、exec 之前調整描述元，程式本身完全不需要知道輸入輸出從哪裡來——這是 Unix「小工具組合」哲學的基礎。

🧭 這一課的重點

重新導向與管線都是在 fork 與 exec 之間用 dup2 調整檔案描述元。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
