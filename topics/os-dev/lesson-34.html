虛擬檔案系統（VFS）

這一課的目標

  • 理解 VFS 的抽象
  • 認識 inode、dentry、file
  • 知道掛載的意義
struct file_ops { // 每種檔案系統（或裝置）實作這組函式 long (*read)(struct file*, char* buf, size_t n); long (*write)(struct file*, const char* buf, size_t n); }; struct inode { uint64_t ino; uint64_t size; mode_t mode; struct file_ops* ops; void* fs_private; }; struct file { struct inode* inode; uint64_t pos; int flags; }; // 開啟後的狀態（位置、模式）
物件代表
inode一個檔案本身（中繼資料、資料位置）
dentry路徑中的一個名稱 → inode（有快取）
file一次「開啟」：讀寫位置、模式
超級區塊一個已掛載的檔案系統

掛載（mount）把一個檔案系統接到目錄樹的某個位置。「一切都是檔案」讓終端機、管線、甚至行程資訊（/proc）都能用 read、write 操作。

🧭 這一課的重點

VFS 定義統一的物件與函式介面，讓各種檔案系統與裝置都能用同一組系統呼叫存取。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
