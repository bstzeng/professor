第一行核心程式碼

這一課的目標

  • 寫出核心進入點
  • 理解堆疊的設定
  • 知道核心停機的方式
; arch/x86_64/entry.asm section .bss align 16 stack_bottom: resb 16384 ; 16 KB 的核心堆疊 stack_top: section .text global _start extern kmain _start: cli ; 先關中斷：還沒有中斷表 mov rsp, stack_top ; 設定堆疊——C 函式需要它 call kmain .hang: hlt ; 讓 CPU 休眠 jmp .hang
// kernel/main.c void kmain(void) { serial_init(); kprintf("Hello from myos!\n"); for (;;) asm volatile("hlt"); }
  • C 語言需要堆疊才能呼叫函式、存區域變數；在設定 rsp 之前不能呼叫任何 C 函式。
  • .bss 區段不佔核心檔案的空間，開機程式會把它清成 0。
  • kmain 永遠不應該回傳——回到哪裡呢？所以最後停在 hlt 迴圈。

🧭 這一課的重點

進入點用組合語言設定堆疊後呼叫 kmain；核心的主函式永遠不回傳。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
