中斷描述表（IDT）

這一課的目標

  • 理解 IDT 的結構
  • 寫出 IDT 入口
  • 知道中斷處理程式的骨架
struct idt_entry { // 長模式下每個入口 16 位元組 uint16_t offset_lo; uint16_t selector; // 核心程式碼區段 uint8_t ist; // 中斷堆疊表索引（雙重錯誤用） uint8_t type_attr; // 0x8E：存在、權限 0、中斷閘 uint16_t offset_mid; uint32_t offset_hi; uint32_t zero; } __attribute__((packed)); static struct idt_entry idt[256]; void idt_set(int n, void* handler) { uint64_t a = (uint64_t)handler; idt[n] = (struct idt_entry){ a & 0xFFFF, KERNEL_CS, 0, 0x8E, (a >> 16) & 0xFFFF, a >> 32, 0 }; }
; 每個向量一小段組合語言：保存暫存器後呼叫共同的 C 處理函式 isr_stub_14: ; 分頁錯誤：CPU 已經推了錯誤碼 push 14 ; 向量編號 jmp isr_common isr_common: push rax push rcx ; ……保存所有通用暫存器 mov rdi, rsp ; 第一個參數：指向保存的暫存器 call interrupt_dispatch ; ……還原暫存器 add rsp, 16 ; 丟掉向量編號與錯誤碼 iretq

🧭 這一課的重點

IDT 有 256 個入口，每個指向一段處理程式；組合語言樁保存暫存器後交給 C 處理。

🖥️ 本課的核心程式碼為教學用的極簡範例（C 與 x86-64 組合語言），省略了許多錯誤處理與邊界情況；真實作業系統（Linux、Windows、macOS）的實作複雜得多，細節以其原始碼與文件為準。
