巴塞爾問題

這一課的目標

  • 了解巴塞爾問題
  • 理解歐拉的推導
  • 認識 ζ 函數

一個無窮級數

1644 年，義大利數學家門戈利問：所有平方數倒數的和

\[1 + \frac14 + \frac19 + \frac1{16} + \cdots = \sum_{n=1}^\infty\frac1{n^2}\]

等於多少？它收斂（大約 1.645），但它的精確值是什麼？伯努利家族（他們住在瑞士的巴塞爾）等當時最好的數學家都試過，沒人解得出來——因此稱為巴塞爾問題。

歐拉的大膽推導（1734～1735）

28 歲的歐拉用一個大膽（當時並不嚴格）的論證：

  1. sin x 的零點在 \(0, \pm\pi, \pm2\pi, \dots\)。把多項式「依零點分解」的想法推廣到無窮：\(\frac{\sin x}{x} = \left(1 - \frac{x^2}{\pi^2}\right)\left(1 - \frac{x^2}{4\pi^2}\right)\left(1 - \frac{x^2}{9\pi^2}\right)\cdots\)
  2. 展開右邊，\(x^2\) 項的係數是 \(-\left(\frac1{\pi^2} + \frac1{4\pi^2} + \frac1{9\pi^2} + \cdots\right)\)。
  3. 左邊用泰勒展開：\(\frac{\sin x}{x} = 1 - \frac{x^2}{6} + \cdots\)，\(x^2\) 的係數是 \(-1/6\)。
  4. 比較係數：
\[\sum_{n=1}^\infty\frac1{n^2} = \frac{\pi^2}{6}\]

一個關於整數的和，竟然等於和圓有關的 π。這個結果讓歐拉一舉成名。後來他也嚴格地證明了這一步。

ζ 函數

把平方換成任意的次方 s：

\[\zeta(s) = \sum_{n=1}^\infty\frac1{n^s} = 1 + \frac1{2^s} + \frac1{3^s} + \cdots\]

歐拉算出了所有正偶數的值：\(\zeta(4) = \pi^4/90\)、\(\zeta(6) = \pi^6/945\)……而 ζ(3)、ζ(5) 等奇數的值，至今沒有簡單的公式（1978 年阿培里證明了 ζ(3) 是無理數）。

當 s = 1，它是調和級數 \(1 + \tfrac12 + \tfrac13 + \cdots\)，發散到無限大。

🧭 這一課的重點

1644 年門戈利問平方數倒數和等於多少，伯努利家族都解不出，稱巴塞爾問題；1734～1735 年 28 歲的歐拉把 sin x/x 依零點分解成無窮乘積，比較 x² 係數得 Σ1/n²=π²/6，整數之和等於 π 讓他成名，後來也嚴格證明；推廣為 ζ(s)=Σ1/n^s，歐拉算出所有正偶數值如 π⁴/90，奇數值無簡單公式（1978 年阿培里證明 ζ(3) 無理），s=1 為發散的調和級數。

🔢 本課的推導以主要步驟與直覺為主，省略部分嚴格的證明；互動模擬中的 ζ 零點以歐拉—麥克勞林公式與黎曼—席格公式即時計算，為數值近似。
