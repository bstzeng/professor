歐拉乘積

這一課的目標

  • 推導歐拉乘積公式
  • 用它再次證明質數無窮多
  • 理解它的深遠意義

推導

1737 年，歐拉發現了一個驚人的等式。從

\[\zeta(s) = 1 + \frac1{2^s} + \frac1{3^s} + \frac1{4^s} + \frac1{5^s} + \cdots\]

兩邊乘以 \(1/2^s\)，得到所有偶數項 \(\frac1{2^s} + \frac1{4^s} + \frac1{6^s} + \cdots\)。相減：

\[\left(1 - \frac1{2^s}\right)\zeta(s) = 1 + \frac1{3^s} + \frac1{5^s} + \frac1{7^s} + \cdots\]

所有 2 的倍數都被篩掉了！再乘以 \((1 - 1/3^s)\)，篩掉 3 的倍數……這正是埃拉托斯特尼篩法（第 2 課）！把所有質數都篩完，只剩下 1：

\[\zeta(s) = \prod_{p\ \text{質數}}\frac{1}{1 - p^{-s}}\]

左邊是對所有正整數的和，右邊是對所有質數的乘積。等號成立，正是因為算術基本定理（第 1 課）：展開右邊的每一項 \(1 + p^{-s} + p^{-2s} + \cdots\)，把它們乘起來，每一個整數 \(n\) 恰好以它的質因數分解出現一次。

再證一次質數無窮多

令 \(s\to 1\)。左邊是調和級數，發散到無限大。如果質數只有有限多個，右邊是有限個有限的數相乘，是有限的。矛盾。

歐拉進一步證明了更強的結果：所有質數倒數的和 \(\tfrac12 + \tfrac13 + \tfrac15 + \tfrac17 + \cdots\) 也發散（雖然非常慢，大約像 \(\ln\ln x\)）。質數「比平方數多」。

意義

歐拉乘積是一座橋：關於質數的問題，可以轉換成關於 ζ 函數的問題。黎曼將沿著這座橋，走到一個歐拉沒有到過的地方——複數。

🧭 這一課的重點

1737 年歐拉把 ζ(s) 乘以 (1−1/2^s) 篩掉 2 的倍數，再依序篩掉每個質數的倍數，正是埃拉托斯特尼篩法，得 ζ(s)=Π_p 1/(1−p^{−s})；所有整數之和等於所有質數之積，是因為算術基本定理使每個整數恰出現一次；s→1 時左邊發散而有限個質數的乘積有限，再證質數無窮多，歐拉還證明質數倒數和像 ln ln x 一樣慢慢發散；歐拉乘積把質數問題轉換成 ζ 函數問題，黎曼將把它帶到複數。

🔢 本課的推導以主要步驟與直覺為主，省略部分嚴格的證明；互動模擬中的 ζ 零點以歐拉—麥克勞林公式與黎曼—席格公式即時計算，為數值近似。
