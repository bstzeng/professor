模組 B｜GPU 架構 · 第 7 課

SM、核心與 Tensor Core

這一課的目標

  • 認識 GPU 的階層結構
  • 理解 SM 的組成
  • 了解 Tensor Core 的角色

階層結構

以 NVIDIA 的 GPU 為例，晶片由數十到一百多個串流多處理器（SM）組成。每一個 SM 就像一個小型的平行處理器，裡面有：

  • 數十到上百個 CUDA 核心：做整數與浮點數的加減乘除。
  • Tensor Core：專門做小矩陣的乘加運算（例如一次算一個 4×4 或更大的矩陣乘法），速度比 CUDA 核心快一個數量級以上。
  • 特殊功能單元：計算 sin、exp、平方根等。
  • 暫存器檔：數萬個暫存器，比 CPU 多得多。
  • 共享記憶體／L1 快取：晶片上的高速記憶體，由同一個區塊的執行緒共享（第 16 課）。
  • warp 排程器：決定每個時脈週期由哪一組執行緒執行。

大量的執行緒

一個 SM 可以同時「掛著」上千個執行緒。這不是因為它有上千個核心，而是為了隱藏延遲：當某一組執行緒在等記憶體（可能要等數百個週期），排程器立刻切換到另一組已經準備好的執行緒。CPU 用大快取來避免等待，GPU 則用大量的執行緒來容忍等待。

其他廠商

AMD 的 GPU 用「運算單元」（CU）、Intel 用「Xe 核心」，名稱不同，但階層的概念相似。為了方便，本課程主要使用 NVIDIA 與 CUDA 的術語。

🧭 這一課的重點

以 NVIDIA 為例晶片由數十到一百多個串流多處理器 SM 組成，每個 SM 有數十到上百個 CUDA 核心做整數浮點運算、專做小矩陣乘加快一個數量級以上的 Tensor Core、算 sin exp 平方根的特殊功能單元、數萬個暫存器、同區塊共享的共享記憶體 L1、warp 排程器；一個 SM 同時掛上千執行緒是為了隱藏延遲，某組等記憶體（數百週期）時立刻切換到另一組，CPU 用大快取避免等待 GPU 用大量執行緒容忍等待；AMD 用 CU、Intel 用 Xe 核心概念相似。
