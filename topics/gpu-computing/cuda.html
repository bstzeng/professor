CUDA 速查表

語法意思
__global__kernel：由 CPU 啟動、在 GPU 執行
__device__只能在 GPU 上被呼叫的函式
__shared__區塊共享記憶體
threadIdx, blockIdx執行緒在區塊中、區塊在網格中的索引
blockDim, gridDim區塊與網格的大小
__syncthreads()區塊內的柵欄同步
atomicAdd()原子加法
cudaMalloc / cudaFree配置／釋放 GPU 記憶體
cudaMemcpy / cudaMemcpyAsyncCPU 與 GPU 之間複製資料
cudaDeviceSynchronize()CPU 等待 GPU 完成所有工作

全域索引的公式

int i = blockIdx.x * blockDim.x + threadIdx.x; // 一維 int x = blockIdx.x * blockDim.x + threadIdx.x; // 二維 int y = blockIdx.y * blockDim.y + threadIdx.y; int blocks = (n + threads - 1) / threads; // 無條件進位
