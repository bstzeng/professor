矩陣乘法的優化

這一課的目標

  • 理解矩陣乘法為什麼是 AI 的核心
  • 了解逐步優化的過程
  • 認識 cuBLAS 與 CUTLASS

AI 就是矩陣乘法

神經網路的全連接層、注意力機制中的 QKᵀ 與 softmax 後乘 V、卷積（可以轉換成矩陣乘法）——現代 AI 絕大部分的運算量，都是矩陣乘法（GEMM）。讓矩陣乘法跑得快，就是讓 AI 跑得快。

逐步優化

一個 N×N 的矩陣乘法需要 2N³ 次浮點運算。從最天真的寫法開始，工程師一步步優化，效能可以相差上百倍：

版本做法大約的效能
天真版每個執行緒算 C 的一個元素，直接從全域記憶體讀峰值的幾個百分點
合併存取調整索引，讓 warp 讀連續的位址提升數倍
共享記憶體 tiling一塊一塊載入並重複使用（第 16 課）再提升數倍
暫存器 tiling每個執行緒算一小塊（例如 8×8）C，資料留在暫存器再提升
向量化載入、雙緩衝一次讀 4 個 float；一邊算這塊，一邊載入下一塊接近函式庫
Tensor Core使用專用的矩陣單元與低精度再快一個數量級

每一步都是在提高運算強度（第 11 課）：讓同一筆資料被用更多次，越來越靠近 Roofline 的右側。

函式庫

實務上，矩陣乘法由 NVIDIA 的 cuBLAS 等函式庫提供，針對每一代 GPU 與每一種矩陣形狀精心調校；CUTLASS 則把這些技巧做成可組合的模板，讓研究者寫出自己的融合 kernel。OpenAI 的 Triton 語言讓研究者用類似 Python 的語法寫出接近手寫 CUDA 效能的 kernel。

🧭 這一課的重點

神經網路全連接層、注意力的 QKᵀ 與乘 V、卷積都可轉成矩陣乘法 GEMM，讓它快就是讓 AI 快；N×N 需 2N³ 次運算，從天真版每執行緒算一元素直接讀全域記憶體只有峰值幾個百分點，經合併存取、共享記憶體 tiling、暫存器 tiling 每執行緒算一小塊、向量化載入與雙緩衝、Tensor Core 低精度，效能相差上百倍，每步都在提高運算強度靠近 Roofline 右側；實務用 cuBLAS 針對每代 GPU 與形狀調校，CUTLASS 做成可組合模板，OpenAI 的 Triton 用類 Python 語法寫出接近手寫 CUDA 的 kernel。
