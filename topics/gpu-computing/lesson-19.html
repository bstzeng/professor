最佳化檢查清單

  1. 先測量，找出瓶頸（Roofline、Nsight）。
  2. 減少 CPU 與 GPU 之間的資料搬運。
  3. 確保全域記憶體的存取是合併的。
  4. 用共享記憶體重複使用資料（tiling）。
  5. 避免 warp 內的分支發散。
  6. 維持足夠的佔用率來隱藏延遲。
  7. 用串流重疊傳輸與計算。

實務上，大部分的人不會從零寫這些 kernel，而是使用高度最佳化的函式庫（cuBLAS、cuDNN）或框架（PyTorch）。但理解底層的原理，才知道為什麼某些寫法快、某些寫法慢。下一個模組，我們看看這些原理如何驅動 AI。

🧭 這一課的重點

CUDA 程式設計模組：kernel 一執行緒一筆資料、執行緒區塊網格與區塊獨立、合併存取與 SoA、共享記憶體 tiling 與 bank 衝突、同步原子操作樹狀歸約、串流非同步 CUDA Graphs；最佳化清單是先測量、減少 CPU GPU 搬運、合併存取、共享記憶體重用、避免分支發散、維持佔用率、串流重疊；實務多用 cuBLAS cuDNN PyTorch 但懂原理才知快慢；下模組看 AI。
