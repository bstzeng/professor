Tensor Core 與低精度

這一課的目標

  • 理解 Tensor Core 的作用
  • 認識各種數值格式
  • 理解低精度的取捨

專用的矩陣單元

2017 年起，NVIDIA 的資料中心 GPU 加入了 Tensor Core：一個時脈週期內完成一個小矩陣的乘加（D = A × B + C）。由於矩陣乘法的結構固定，專用硬體比通用核心的效率高得多。

數值格式

格式位元特性用途
FP3232單精度；傳統科學計算的標準一般計算
FP1616範圍小，容易溢位早期混合精度訓練
BF1616和 FP32 一樣的指數範圍，精度較低AI 訓練的主流
FP88兩種變體（E4M3、E5M2）新一代訓練與推論
INT8、INT4、FP48 或 4需要縮放因子推論（量化）

位元數減半，同樣的晶片面積可以放進大約兩倍的運算單元，記憶體與頻寬的需求也減半。從 FP32 到 FP8，理論吞吐量可以提高許多倍。

為什麼神經網路可以用低精度

神經網路對雜訊有很強的容忍度：權重差一點點，輸出幾乎一樣。訓練時常用混合精度：矩陣乘法用低精度，累加與權重的主副本用高精度，並用縮放避免數值太小而變成零。推論時，模型常被量化成 8 位元甚至 4 位元，大幅減少記憶體與頻寬（見〈一次 LLM 推論〉）。

科學計算的另一面

天氣預報、流體模擬、分子動力學等傳統科學計算需要 FP64（雙精度）。AI 導向的 GPU 越來越偏重低精度，讓部分超級電腦的使用者擔心；也有研究者嘗試用低精度的 Tensor Core「模擬」高精度計算。

🧭 這一課的重點

2017 年起 NVIDIA 資料中心 GPU 加入 Tensor Core 一週期完成小矩陣乘加 D＝A×B＋C，結構固定專用硬體效率高；格式有 FP32 單精度、FP16 範圍小易溢位、BF16 與 FP32 同指數範圍精度低是訓練主流、FP8 兩種變體 E4M3 E5M2、INT8 INT4 FP4 需縮放因子用於推論量化；位元減半同面積放約兩倍運算單元記憶體頻寬需求也減半；神經網路對雜訊容忍度強，訓練用混合精度矩陣乘法低精度累加與主權重高精度並縮放，推論量化成 8 甚至 4 位元；天氣流體分子動力學需 FP64，AI GPU 偏重低精度讓超級電腦使用者擔心，有人用低精度 Tensor Core 模擬高精度。
