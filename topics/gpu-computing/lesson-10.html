記憶體階層

這一課的目標

  • 認識 GPU 的各層記憶體
  • 理解延遲與頻寬的差異
  • 理解 HBM 的角色

從快到慢

記憶體位置容量（量級）延遲（量級）誰能存取
暫存器SM 內每 SM 數百 KB1 個週期單一執行緒
共享記憶體／L1SM 內每 SM 一兩百 KB數十個週期同一區塊的執行緒
L2 快取晶片上數十 MB約兩百個週期全部
全域記憶體（HBM／GDDR）晶片旁數十～數百 GB數百個週期全部，以及 CPU（經由複製）

越靠近運算單元的記憶體越快、越小。GPU 程式最佳化的核心，往往就是讓資料留在快的地方、盡量少去慢的地方。

延遲與頻寬

延遲是「一筆資料要等多久才到」，頻寬是「每秒能送來多少資料」。高速公路的比喻：延遲是從台北開到高雄要幾小時，頻寬是高速公路有幾線道。GPU 的全域記憶體延遲並不低，但頻寬極高——只要同時有大量的請求在路上，就能把頻寬填滿。

HBM

資料中心 GPU 使用高頻寬記憶體（HBM）：把多層 DRAM 晶片垂直堆疊，用數千條細小的連線與 GPU 並排封裝在一起，頻寬可達每秒數 TB——比一般電腦的記憶體高一個數量級以上。HBM 的產能與先進封裝，是 AI 晶片供應鏈的關鍵瓶頸（第 28 課）。

CPU 與 GPU 之間

GPU 的記憶體與 CPU 的記憶體通常是分開的，資料必須經由 PCIe 等介面複製，這條路比 GPU 內部慢得多。所以一個常見的原則是：資料搬上 GPU 後，盡量在上面做完所有的事，不要來回搬運。

🧭 這一課的重點

從快到慢：暫存器 SM 內每 SM 數百 KB 1 週期單一執行緒、共享記憶體 L1 每 SM 一兩百 KB 數十週期同區塊、L2 晶片上數十 MB 約兩百週期、全域記憶體 HBM GDDR 數十到數百 GB 數百週期；越靠近越快越小，最佳化核心是讓資料留在快的地方；延遲是等多久頻寬是每秒多少，台北到高雄要幾小時與高速公路幾線道，GPU 全域記憶體延遲不低但頻寬極高需大量請求填滿；HBM 把多層 DRAM 垂直堆疊用數千條連線與 GPU 並排封裝頻寬每秒數 TB，是 AI 供應鏈瓶頸；CPU GPU 記憶體分開經 PCIe 複製較慢，資料搬上 GPU 後盡量在上面做完。
