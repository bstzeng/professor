課程總結：平行的世界

這一課的目標

  • 回顧整個課程
  • 整理核心觀念
  • 規劃下一步

回顧

模組核心
A 為什麼要平行功耗牆、資料平行、阿姆達定律
B GPU 架構SM、warp、分支發散、記憶體階層、Roofline
C CUDA 程式設計kernel、執行緒階層、合併存取、共享記憶體、同步、串流
D 矩陣乘法與 AIGEMM 優化、Tensor Core、FlashAttention、多 GPU
E 生態與產業CUDA 護城河、其他加速器、資料中心、台積電

五個核心觀念

  1. 吞吐量勝過延遲：GPU 用大量簡單核心與執行緒，換取驚人的總產出。
  2. 搬資料比計算貴：Roofline、tiling、FlashAttention 都在減少搬運。
  3. 32 個一起走：warp 決定了合併存取與分支發散的規則。
  4. 序列部分決定上限：阿姆達定律提醒我們找出真正的瓶頸。
  5. 軟硬體共同演化：AI 塑造了 GPU，GPU 也塑造了 AI。

下一步

  • 動手：在雲端或自己的電腦上安裝 CUDA，寫一個向量相加，再寫一個 tiled 矩陣乘法，和 cuBLAS 比較。
  • 用 PyTorch 的 profiler 觀察一個模型的 kernel 時間。
  • 延伸閱讀：〈計算機概論〉、〈一次 LLM 推論到底發生什麼〉、〈神經網路與深度學習〉、〈半導體元件物理〉、〈晶片是怎麼畫出來的〉。

🧭 這一課的重點
