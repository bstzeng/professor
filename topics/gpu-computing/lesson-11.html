Roofline 模型

這一課的目標

  • 理解運算強度
  • 學會讀 Roofline 圖
  • 判斷程式的瓶頸

運算強度

一個 kernel 每從記憶體搬一個位元組，做多少次浮點運算？這叫做運算強度（arithmetic intensity），單位是 FLOP/byte。

  • 向量相加 c[i] = a[i] + b[i]：讀兩個數、寫一個數（12 位元組），只做一次加法——運算強度約 0.08，非常低。
  • 大型矩陣乘法：每個元素被重複使用許多次，運算強度可以達到數百。

屋頂

\[\text{可達效能}=\min(\text{峰值運算},\ \text{頻寬}\times\text{運算強度})\]

畫在對數座標上，就像一個屋頂：左邊是一條斜線（受頻寬限制），右邊是一條水平線（受運算能力限制），兩者的交點叫做轉折點。

AI 的兩種工作

現代資料中心 GPU 的峰值運算非常高，轉折點常在數百 FLOP/byte。這意味著大多數的程式其實都被記憶體卡住。

  • 訓練與處理長輸入（prefill）：大型矩陣乘法，運算強度高，能把 GPU 用滿。
  • 逐字生成（decode）：每生成一個字，都要把整個模型的權重從記憶體讀一遍，但只做少量的運算——嚴重受頻寬限制。這就是為什麼 LLM 推論要用批次、量化與 KV cache 等技巧（見〈一次 LLM 推論到底發生什麼〉）。

🧭 這一課的重點

kernel 每搬一位元組做多少次浮點運算叫運算強度 FLOP/byte，向量相加讀兩寫一共 12 位元組做一次加法約 0.08 很低，大型矩陣乘法元素被重複使用可達數百；可達效能＝min(峰值運算, 頻寬×運算強度)，對數座標像屋頂，左斜線受頻寬限制右水平受運算限制，交點叫轉折點；現代 GPU 轉折點常在數百，大多數程式其實被記憶體卡住；訓練與 prefill 是大矩陣乘法能用滿 GPU，逐字生成 decode 每個字都要讀一遍全部權重只做少量運算嚴重受頻寬限制，所以 LLM 推論用批次量化 KV cache。

🟩 互動模擬為教學用的簡化模型；硬體數字為代表性的量級，實際依產品與世代而異。
