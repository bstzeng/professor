模組 D｜矩陣乘法與 AI · 第 23 課

多 GPU 與互連

這一課的目標

  • 理解大型模型為什麼需要多 GPU
  • 認識各種平行策略
  • 了解 GPU 之間的互連

一張 GPU 放不下

一個有數千億參數的模型，光是權重就需要數百 GB 到數 TB 的記憶體，訓練時還要存梯度、最佳化器的狀態與中間結果。單張 GPU 的記憶體只有數十到數百 GB，計算量更需要數千到數萬張 GPU 同時工作數週到數月。

平行策略

策略怎麼切需要的通訊
資料平行每張 GPU 有完整的模型，處理不同的資料；每一步把梯度平均每一步一次 all-reduce
張量平行把每一個矩陣切開，分給多張 GPU非常頻繁，需要極快的互連
管線平行把不同的層放在不同的 GPU，像生產線層與層之間傳遞中間結果
專家平行MoE 模型的不同專家放在不同的 GPUall-to-all

大型訓練通常同時組合好幾種策略（「3D 平行」），並用 ZeRO 等技巧把最佳化器狀態分散存放。

互連

  • PCIe：一般電腦的擴充介面，對大型訓練來說太慢。
  • NVLink／NVSwitch：NVIDIA 的 GPU 專用高速互連，讓一台伺服器（甚至一整個機櫃）中的 GPU 像一個大 GPU 一樣溝通。
  • InfiniBand、高速乙太網路：連接數千台伺服器。
  • NCCL：NVIDIA 的集合通訊函式庫，實作 all-reduce 等操作。

在大型叢集中，通訊常常比計算更難擴展；任何一張 GPU 出錯，都可能讓整個訓練停下來，所以需要定期存檔與快速恢復的機制。

🧭 這一課的重點

數千億參數的模型權重需數百 GB 到數 TB，訓練還要存梯度最佳化器狀態中間結果，單張 GPU 只有數十到數百 GB，計算量需數千到數萬張 GPU 工作數週到數月；平行策略有資料平行每卡完整模型處理不同資料每步 all-reduce 平均梯度、張量平行切開每個矩陣需極快互連、管線平行不同層放不同 GPU 像生產線、專家平行 MoE 不同專家放不同 GPU 用 all-to-all，常組合成 3D 平行並用 ZeRO 分散最佳化器狀態；互連有 PCIe 太慢、NVLink NVSwitch 讓伺服器或機櫃中 GPU 像一個大 GPU、InfiniBand 高速乙太網路連數千伺服器、NCCL 集合通訊函式庫；大叢集通訊比計算難擴展，任一卡出錯可能讓訓練停下需定期存檔快速恢復。
