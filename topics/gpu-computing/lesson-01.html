CPU 與 GPU

這一課的目標

  • 理解 CPU 與 GPU 的設計差異
  • 理解 GPU 擅長的工作
  • 知道本課程的路線

兩種設計哲學

CPU 像幾位非常聰明的教授：每一位都能處理複雜的邏輯、快速應付各種突發狀況，但人數不多（一般是幾個到幾十個核心）。GPU 像一整座體育館的學生：每一位只會做簡單的算術，但有成千上萬人同時做。

CPUGPU
核心數數個～數十個（大而複雜）數千個運算單元（小而簡單）
晶片面積用在大量快取、分支預測、亂序執行大量運算單元
擅長低延遲、複雜邏輯、依序的工作高吞吐量、大量相同的計算
比喻跑車：載少數人，非常快公車隊：一次載很多人

GPU 擅長什麼

當一個問題可以拆成大量獨立、相同的小計算時，GPU 就能發揮威力：螢幕上數百萬個像素、矩陣中的數百萬個元素、神經網路中的數十億次乘加運算。反過來，需要大量判斷、彼此依賴的工作（例如作業系統、編譯器），仍然是 CPU 的天下。

🧭 這一課的重點

CPU 像幾位聰明教授能處理複雜邏輯但人少（數個到數十核），GPU 像體育館的學生只會簡單算術但成千上萬同時做；CPU 晶片面積用在快取分支預測亂序執行擅長低延遲複雜依序的工作像跑車，GPU 用在大量運算單元擅長高吞吐量相同計算像公車隊；問題能拆成大量獨立相同小計算時 GPU 發揮威力（像素矩陣神經網路），需大量判斷彼此依賴的工作仍是 CPU 天下；課程分為為什麼要平行、GPU 架構、CUDA 程式設計、矩陣乘法與 AI、生態與產業。

🟩 互動模擬為教學用的簡化模型；硬體數字為代表性的量級，實際依產品與世代而異。
