Jog Wheel：怎麼用一個轉輪同時模擬刷碟與快轉

這一課的目標

  • 理解 Jog Wheel 的基本感應原理
  • 說明 Vinyl Mode 與 CDJ Mode 兩種操作模式的差異
  • 認識觸控感應與轉速控制如何被整合在同一個轉輪上

Jog Wheel是CDJ上那個圓形的轉輪——它同時扮演了「模擬唱片手感」與「精確定位播放位置」兩種功能。

1. 內部感應：光學或電容式編碼器

轉輪內部裝有感應器（多為光學或電容式編碼器），能精確偵測轉輪被轉動的方向、角度與速度——這些數據會即時傳給CDJ內部的處理器，轉換成對音樂播放進度的控制指令。

2. 兩種模式：Vinyl Mode 與 CDJ Mode

模式觸摸轉輪表面時的效果適合用途
Vinyl Mode如同按住黑膠唱片，播放會暫停或倒轉，放開後恢復播放刷碟、模擬黑膠手感的抓拍
CDJ Mode轉輪表面觸摸不影響播放，只有轉動外圈才會微調速度純粹的抓拍微調，避免誤觸暫停

「觸控」與「轉動」是兩種獨立的輸入

Jog Wheel的表面有觸控感應，外圈則是可以轉動的機構——這兩者被設計成獨立的輸入訊號：在Vinyl Mode下，光是「碰到表面」就會觸發暫停效果（模擬手按住唱片）；而轉動外圈產生的是另一種「微調速度」的訊號，兩種動作可以同時或分別發生。

3. 為什麼要模擬「暫停」的手感

刷碟的核心動作是「按住讓它停下來或倒轉」——Jog Wheel的Vinyl Mode正是為了讓數位系統也能重現這個動作，讓模組 F介紹的所有刷碟手法，都能直接移植到CDJ上操作。

4. 觸控螢幕與轉輪的分工

現代CDJ通常還有獨立的觸控螢幕顯示波形與曲目資訊——螢幕負責「看」（視覺化波形、節拍網格），Jog Wheel負責「動手」，兩者分工合作，讓DJ可以同時用眼睛確認波形對齊情況、用手做實際的操作調整。
