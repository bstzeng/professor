作業系統到底在管什麼:四大工作

這一課的目標

  • 認識 OS 的四大核心工作
  • 理解 OS 是硬體與程式之間的橋樑
  • 建立「總管」的整體圖像

既然作業系統是硬體和程式之間的總管(第 19 課),它具體管些什麼?可以歸納成四大工作。抓住這四項,你就掌握了任何作業系統的骨架——不論是 DOS、Windows、macOS 還是 Linux。

1. 管理硬體(裝置驅動)

OS 提供一套統一的方式去操作各種硬體。程式只要說「我要讀這個檔」,OS 就透過對應的驅動程式去操作實際的磁碟——程式不必知道那是哪一牌的磁碟。

2. 管理檔案(檔案系統)

磁碟本身只是一大片能記 0/1 的空間。OS 把它組織成檔案和資料夾,讓你能用名字存取資料,而不必記「我的報告在磁碟第幾格」。這套規則叫檔案系統(DOS 用的是 FAT,第 26 課)。

3. 管理記憶體

多支程式要共用有限的 RAM,OS 負責分配:誰用哪一塊、用多少,並盡量避免它們互相踩到。記憶體怎麼管,是 DOS 和 Windows 的一大分水嶺(後面 640K 與保護模式會詳談,第 28 課、第 38 課)。

4. 管理程式(執行)

OS 負責載入、啟動、切換、結束程式。「一次只能跑一個」還是「能同時跑很多個」,正是 DOS 和後來系統的關鍵差別(第 27 課)。

有了這張「四大工作」的清單,接下來我們會一項項看 DOS 是怎麼做的。但在那之前,先補一個 OS 和硬體溝通時非常核心的機制:中斷(第 21 課)。

想一想

用這四項當「檢查表」,你可以快速理解任何作業系統:它怎麼管硬體?怎麼組織檔案?怎麼分配記憶體?怎麼跑程式?從 DOS 到最新的手機系統,骨架都是這四塊,差別在於「做得多精緻」。
