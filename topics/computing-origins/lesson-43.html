破解迷思與總整理:電腦如何無中生有啟動自己

這一課的目標

  • 破解關於 DOS/Windows/開機的常見迷思
  • 用一句話總結整趟旅程
  • 帶走一個看待科技的視角

旅程的終點。這一課先破解幾個常見迷思——很多是似是而非、聽起來對其實錯的說法——再把整門課收束成一句話。

1. 幾個最常見的誤解

  • 「DOS 是 Windows 的一部分」——其實反了。早期 Windows 是跑在 DOS 上的程式(第 35 課)。
  • 「Windows 一開始就是作業系統」——3.1 及更早,它是 DOS 上的圖形環境,不是獨立 OS。
  • 「開機是瞬間的事」——它是一連串「小程式載入大程式」的接力(第 18 課)。
  • 「CPU 很聰明」——它只是超快地「看到數字就做動作」(第 9 課),聰明的是「組合」。
  • 「命令列已淘汰」——它仍是專家與伺服器的高效利器(第 30 課)。

2. 一句話總結整趟旅程

如果只能記住一句話,那就是:電腦的一切,都是用大量簡單的東西,一層層堆疊出來的。

  1. 開關 → 邏輯 → 運算:電晶體堆成邏輯閘,再堆成會算數的電路(模組 A)。
  2. 記憶 → 機器 → 執行:加上會記的正反器,組成 CPU,靠取指循環跑程式(模組 A、B)。
  3. 開機接力 → 作業系統:硬體起頭、軟體接力,把 DOS 叫醒接管全機(模組 C、D、E)。
  4. 文字 → 圖形 → 視窗:在 DOS 上疊出 GUI,成就 Windows 的桌面(模組 F、G)。

3. 帶走一個視角

回到你最初的問題:「電腦剛開始到底是怎麼啟動的?沒有介面的年代,程式怎麼進去的?」答案是一個既樸素又優雅的故事:硬體在電路裡寫死一個起點,然後用「小程式載入大程式」的接力,把自己一步步叫醒。而 DOS、Windows,都是在這個地基上層層堆疊、一路相容長出來的。

下次你按下電源、看著螢幕亮起,希望你眼中的不再是魔法,而是一條清晰、可理解的因果鏈——從一個開關,到你眼前的整個世界。這種「把複雜拆回簡單」的眼光,遠比記住任何細節更值得帶走。

想一想

恭喜你走完整門課!你現在能回答自己最初的疑問了。把這個「複雜=簡單的層層堆疊」的視角,用到任何你覺得高深的東西上:AI、網路、區塊鏈……它們也都是一層層樸素想法堆出來的。看穿這一點,世界會少很多「魔法」,多很多「原來如此」。
