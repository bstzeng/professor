為什麼是 3.1 讓視窗真正普及

這一課的目標

  • 理解「不是最早、而是剛好夠好」的道理
  • 認識 3.1 普及的幾個因素
  • 看出技術普及需要「天時地利」

這個模組的最後,回答一個好問題:Windows 在 3.1 之前已經有好幾版,為什麼偏偏是 3.1 這一版,讓圖形視窗真正走進千家萬戶?答案不是「它最早」,而是它剛好夠好、又遇上對的時機。

1. 夠好用、夠穩定

前幾版 Windows 常被嫌不夠成熟、不夠穩。到了 3.x 這代,介面成熟了、也穩定了不少,一般人終於能順手地用,而不是三天兩頭出狀況。體驗跨過了「堪用」的門檻,是普及的前提。

2. 漂亮的字型與豐富的軟體

  • 它帶來了漂亮的螢幕字型,讓文書處理、排版變得好看又實用——這對辦公族很有吸引力。
  • 愈來愈多應用軟體為 Windows 而寫:文書、試算表、繪圖……人們終於能用它做正事,而不只是看個介面。

3. 生態系的正向循環

當硬體夠強了(第 34 課)、系統夠好用了、軟體夠多了,就啟動了一個正向循環:使用者變多 → 開發者更願意為它寫軟體 → 軟體更多又吸引更多使用者……廠商、使用者、開發者一起投入,視窗介面就此成為主流。

4. 從此 DOS 退居幕後

3.1 的成功替「視窗成為標準」鋪好了路。此後,圖形介面逐漸成為預設,而曾經是主角的 DOS,慢慢退到幕後——雖然它的許多遺產,至今仍在(最後一個模組會回頭看,第 42 課)。

到這裡,你已經走完了「從一個開關,到 DOS,再到視窗 3.1」的完整旅程。最後一個模組,把整條路線串成一張大圖,並看看這些老東西今天還藏在哪(第 41 課)。

想一想

「不是最早,而是剛好夠好又遇上對的時機」——這幾乎是所有成功技術的共同劇本。第一個做的人常常先烈,真正普及的往往是「集大成、又碰上天時地利」的那一版。看科技史時,別只問「誰最早」,更要問「誰在對的時機把它做到夠好」。
