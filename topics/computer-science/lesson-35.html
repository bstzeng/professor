排序演算法：從氣泡排序到快速排序

這一課的目標

  • 理解氣泡排序的邏輯：反覆比較相鄰元素，把較大的往後推
  • 理解快速排序的分治邏輯：選定基準值，切分成兩組，各自遞迴排序
  • 能用具體陣列，手動模擬兩種排序演算法的前幾個步驟

前面幾課建立了資料怎麼被組織——陣列、鏈結串列、堆疊、佇列、樹、圖。這一課 要看資料組織好之後，怎麼被「處理」：把一堆雜亂的數字排成順序，是幾乎所有 程式都會遇到的基本操作。這一課延用第11課TOY-CPU執行過的那組陣列 [3, 7, 2, 9, 5]，實際走一遍兩種經典排序演算法。

1. 氣泡排序：兩兩比較，把較大的往後推

氣泡排序（Bubble Sort）的邏輯很直覺：從陣列開頭開始，比較 每一對相鄰元素，如果前面比後面大就交換位置，一路比到陣列尾端；跑完一輪之後， 整個陣列裡最大的元素一定會被「推」到最後一個位置（因為只要它出現在比較裡， 一定會被判定為較大而往後移）。重複跑這樣的整輪比較，每輪都能把當時剩下範圍 裡最大的元素定位到正確位置，直到某一輪完全沒有發生交換，代表陣列已經排序 完成。

2. 手動走一遍：[3, 7, 2, 9, 5]的前兩輪

第一輪：

  • 比較3,7：3<7，不交換 → [3,7,2,9,5]
  • 比較7,2：7>2，交換 → [3,2,7,9,5]
  • 比較7,9：7<9，不交換 → [3,2,7,9,5]
  • 比較9,5：9>5，交換 → [3,2,7,5,9]

第一輪結束：[3, 2, 7, 5, 9]——最大值9已經被推到最後一格。

第二輪（最後一格已排定，只需比較前四個元素）：

  • 比較3,2：3>2，交換 → [2,3,7,5,9]
  • 比較3,7：3<7，不交換 → [2,3,7,5,9]
  • 比較7,5：7>5，交換 → [2,3,5,7,9]

第二輪結束：[2, 3, 5, 7, 9]——這個例子恰好在第二輪結束後就已經完全排序好了， 但演算法本身要再多跑一輪、確認完全沒有交換發生，才能判定排序完成。氣泡排序 的代價在於：每一輪都要重新掃過一次剩下的範圍，兩層迴圈疊在一起，資料量一大， 比較次數會增加得很快（第36課會用大O記號精確描述這件事）。

3. 快速排序：分治法——切開，各自解決，再合併

快速排序（Quicksort）採用完全不同的策略，稱為 分治法（Divide and Conquer）：先從陣列裡選出一個基準值 （pivot），把其餘元素依照「比基準值小」跟「比基準值大」分成兩組 （這個切分過程稱為partition），基準值本身就落在它排序後該在的正確位置； 接著對這兩組各自遞迴地重複同樣的流程，直到每組只剩下一個或零個元素為止。

4. 手動走一遍：[3, 7, 2, 9, 5]的切分過程

選第一個元素3當基準值，其餘元素[7, 2, 9, 5]依大小分組：比3小的只有[2]， 比3大的有[7, 9, 5]。切分後排列：[2, 3, 7, 9, 5]——3已經落在最終正確的 位置。接著對右邊的[7, 9, 5]遞迴：選7當基準值，其餘[9, 5]分組，比7小的是 [5]，比7大的是[9]，切分後：[5, 7, 9]。[2]跟[5]跟[9]都只剩一個元素，是 遞迴的終止情形（base case），不需要再切分。把所有結果依序合併： [2, 3] + [5, 7, 9] = [2, 3, 5, 7, 9]——跟氣泡排序算出的結果一致。

關鍵洞察：為什麼快速排序通常比氣泡排序快

氣泡排序每一輪只能確定一個元素的最終位置，資料量n大時要跑將近n輪，每輪 又要掃過剩下的範圍，比較次數隨n成平方成長。快速排序透過每次切分同時縮小 兩個子問題的規模，平均情況下比較次數隨n log n成長——這個差距，n越大就越 懸殊，下一課會用具體數字說明差距有多大。

檢查你的理解

  1. 能手動模擬氣泡排序在[3, 7, 2, 9, 5]上的前兩輪過程
  2. 能說明快速排序「分治法」的核心概念：選基準、切分、遞迴
