LeetCode 732

My Calendar III
我的日程安排表 III

Hard · 困難 設計 線段樹 二分搜尋 有序集合

Problem

A k-booking happens when k events have some non-empty intersection (i.e., there is some time that is common to all k events.)

You are given some events [startTime, endTime), after each given event, return an integer k representing the maximum k-booking between all the previous events.

Implement the MyCalendarThree class:

  • MyCalendarThree() Initializes the object.
  • int book(int startTime, int endTime) Returns an integer k representing the largest integer such that there exists a k-booking in the calendar.

中文翻譯

當 k 個事件有非空的共同時間時，稱為 k 重預訂。

實作 book(startTime, endTime)：預訂 [startTime, endTime)（一定成功），並回傳目前所有事件中最大的 k。

範例

範例 輸入 ["MyCalendarThree", "book", "book", "book", "book", "book", "book"] [[], [10, 20], [50, 60], [10, 40], [5, 15], [5, 10], [25, 55]] 輸出 [null, 1, 1, 2, 3, 3, 3]

限制條件

  • 0 ≤ startTime < endTime ≤ 10⁹
  • 最多呼叫 400 次（book）

LeetCode 原題

解題思路

【差分（掃描線）】 每個事件：開始時間 +1、結束時間 -1。 依時間順序累加，得到每個時刻同時進行的事件數， 最大值就是答案。 每次 book 都重新掃描：O(n)，總共 O(n²)，n <= 400 時很快。 【線段樹：O(log C)】 時間範圍到 10⁹，用動態開點線段樹： 區間 +1（懶標記）、查詢整體最大值（根節點）。
解法一

差分 + 掃描線

class MyCalendarThree: def __init__(self): self.times = [] # 所有出現過的時間點（排序） self.delta = {} # 時間點 -> 這裡開始 +1 / 結束 -1 的淨變化 def book(self, startTime: int, endTime: int) -> int: for t, d in ((startTime, 1), (endTime, -1)): if t not in self.delta: bisect.insort(self.times, t) self.delta[t] = 0 self.delta[t] += d cur = best = 0 for t in self.times: # ★ 掃描線：依時間累加差分，途中的最大值就是最大重疊數 cur += self.delta[t] best = max(best, cur) return best

驗證方式：在整數座標上和計數陣列模擬比對 400 組。

複雜度說明
時間book：O(n)
空間O(n)
解法二

動態開點線段樹

節點表示 [l, r) 的區間，存 (區間最大值, 懶標記) book：對 [start, end) 區間加 1，回傳根節點的最大值 節點在第一次被走到時才建立
複雜度說明
時間book：O(log C)C 為時間範圍 10⁹
空間O(n log C)

邊界條件檢查清單

  • 相接的事件 → 結束的 −1 與開始的 +1 在同一點相消，不算重疊。
  • 完全相同的事件 → 重疊數疊加。
