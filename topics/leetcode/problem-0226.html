LeetCode 226

Invert Binary Tree
翻轉二元樹

Easy · 簡單 樹 深度優先搜尋 廣度優先搜尋 二元樹

Problem

Given the root of a binary tree, invert the tree, and return its root.

中文翻譯

給你一棵二元樹的根節點 root，把它左右翻轉（鏡像），回傳翻轉後的根節點。

範例

範例 1 輸入：root = [4,2,7,1,3,6,9] 輸出：[4,7,2,9,6,3,1] 4 4 / \ / \ 2 7 -> 7 2 / \ / \ / \ / \ 1 3 6 9 9 6 3 1 範例 2 輸入：root = [2,1,3] 輸出：[2,3,1] 範例 3 輸入：root = [] 輸出：[]

限制條件

  • 節點數在 [0, 100] 之間
  • −100 ≤ Node.val ≤ 100

LeetCode 原題

解題思路

【鏡像 = 每一個節點都把左右孩子交換】 只交換根的左右孩子是不夠的 —— 子樹內部也要翻轉。 【遞迴定義】 invert(空) = 空 invert(node)： 新的左子樹 = invert(原本的右子樹) 新的右子樹 = invert(原本的左子樹) 【順序不重要】 每個節點都交換一次，不管是前序、後序、層序都可以。 唯一的陷阱：中序（先處理左、交換、再處理「右」）—— 交換之後原本的左子樹跑到右邊，會被翻兩次 ✘ 【一行寫法的注意】 root.left, root.right = invert(root.right), invert(root.left) 右邊兩個呼叫先全部算完，才同時賦值 ✔ 分兩行寫的話要先暫存，否則 root.left 被覆蓋後就找不到了。
解法一

遞迴

class Solution: def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]: if root is None: return None # ★ 左右交換，並且各自再翻轉（先翻後換、先換後翻都可以） root.left, root.right = self.invertTree(root.right), self.invertTree(root.left) return root
複雜度說明
時間O(n)
空間O(h)遞迴深度 = 樹高
解法二

BFS（迭代）

class Solution: def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]: q = deque([root] if root else []) while q: # 每個節點都交換自己的左右孩子 node = q.popleft() node.left, node.right = node.right, node.left if node.left: q.append(node.left) if node.right: q.append(node.right) return root

每個節點出佇列時交換它的兩個孩子。沒有遞迴深度的限制。

複雜度說明
時間O(n)
空間O(w)w = 最寬一層

解法對照

解法時間空間
一、遞迴O(n)O(h) ✔
二、BFSO(n)O(w)

邊界條件檢查清單

  • 空樹 → 回傳 None。
  • 只有一邊的孩子 → 交換後變成另一邊。
  • 非常偏斜的樹 → 遞迴深度 = n；n ≤ 100 沒問題。

常見追問

這題為什麼有名？

Homebrew 的作者 Max Howell 2015 年發推文： 「Google：我們 90% 的工程師都在用你寫的軟體（Homebrew）， 但你不會在白板上翻轉二元樹，所以滾吧。」 這題因此成為「白板面試是否合理」爭論的象徵。
