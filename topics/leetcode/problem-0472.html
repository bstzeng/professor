Concatenated Words
連接詞

Hard · 困難 深度優先搜尋 字典樹 陣列 字串 動態規劃

Problem

Given an array of strings words (without duplicates), return all the concatenated words in the given list of words.

A concatenated word is defined as a string that is comprised entirely of at least two shorter words (not necessarily distinct) in the given array.

中文翻譯

給你一個沒有重複的字串陣列 words，回傳其中所有的連接詞。

連接詞：完全由陣列中至少兩個（可以相同的）更短的單字串接而成的字串。

範例

範例 1 輸入：words = ["cat","cats","catsdogcats","dog","dogcatsdog","hippopotamuses","rat","ratcatdogcat"] 輸出：["catsdogcats","dogcatsdog","ratcatdogcat"] 範例 2 輸入：words = ["cat","dog","catdog"] 輸出：["catdog"]

限制條件

  • 1 ≤ words.length ≤ 10⁴
  • 1 ≤ words[i].length ≤ 30
  • 所有字串互不相同，總長度不超過 10⁵

LeetCode 原題

解題思路

【對每個單字做一次「單字拆分」（第 139 題）】 dp[i] = w 的前 i 個字元能不能由字典中的單字拼成。 dp[i] = 存在 j < i，dp[j] 為真而且 w[j:i] 在字典裡。 【至少兩個單字】 字典裡本來就有 w 自己 -> 必須排除「整個 w 就是一個單字」的那種拆法（j = 0 且 i = n）。 【另一種寫法：依長度排序】 由短到長處理，只用「比自己短、已經處理過的」單字當字典， 自然排除了 w 自己。
解法

每個單字做單字拆分 DP

class Solution: def findAllConcatenatedWordsInADict(self, words: List[str]) -> List[str]: words_set = set(words) def can_form(w: str) -> bool: n = len(w) # dp[i]：w[:i] 能不能由字典中的單字組成（至少一個） dp = [True] + [False] * n for i in range(1, n + 1): for j in range(i): # ★ j == 0 且 i == n 代表整個 w 本身，不算（要兩個以上的單字） if dp[j] and (j, i) != (0, n) and w[j:i] in words_set: dp[i] = True break return dp[n] return [w for w in words if w and can_form(w)]
複雜度說明
時間O(Σ L³)L ≤ 30，每次切片 O(L)
空間O(N · L)

邊界條件檢查清單

  • 空字串（有些版本會出現）→ 不算連接詞，而且不能當拼接材料造成誤判。
  • 同一個單字用多次（"catcat"）→ 可以。
  • 只由自己組成 → 不算。

常見追問

Trie 優化

把所有單字放進 Trie，DP 時從位置 j 沿 Trie 往下走，一次找出所有「從 j 開始的字典單字」，省掉切片和雜湊的成本。
