Convert BST to Greater Tree
把二元搜尋樹轉換為累加樹

Medium · 中等 樹 深度優先搜尋 二元搜尋樹 二元樹

Problem

Given the root of a Binary Search Tree (BST), convert it to a Greater Tree such that every key of the original BST is changed to the original key plus the sum of all keys greater than the original key in BST.

As a reminder, a binary search tree is a tree that satisfies these constraints:

  • The left subtree of a node contains only nodes with keys less than the node's key.
  • The right subtree of a node contains only nodes with keys greater than the node's key.
  • Both the left and right subtrees must also be binary search trees.

Note: This question is the same as 1038: https://leetcode.com/problems/binary-search-tree-to-greater-sum-tree/

中文翻譯

給你一棵二元搜尋樹（節點值互不相同），把它轉成累加樹：每個節點的新值 = 原樹中大於或等於它的所有節點值之和。

（本題與第 1038 題相同。）

範例

範例 1 輸入：root = [4,1,6,0,2,5,7,null,null,null,3,null,null,null,8] 輸出：[30,36,21,36,35,26,15,null,null,null,33,null,null,null,8] 範例 2 輸入：root = [0,null,1] 輸出：[1,null,1]

限制條件

  • 節點數在 [0, 10⁴] 範圍內
  • -10⁴ ≤ Node.val ≤ 10⁴
  • 樹中所有節點值互不相同
  • root 保證是合法的二元搜尋樹

LeetCode 原題

解題思路

【需要「所有比我大的值的和」】 如果由大到小走訪，走到每個節點時， 已經走過的節點正好是所有比它大的 -> 維護一個累加和 total，加上自己後寫回。 【由大到小 = 反向中序】 中序（左、根、右）是由小到大； 反過來（右、根、左）就是由大到小。
解法

反向中序走訪

class Solution: def convertBST(self, root: Optional[TreeNode]) -> Optional[TreeNode]: total = 0 def rev_inorder(nd): # ★ 反向中序（右 -> 根 -> 左）：由大到小走訪 nonlocal total if nd: rev_inorder(nd.right) total += nd.val # total = 所有 >= 目前值的節點和 nd.val = total rev_inorder(nd.left) rev_inorder(root) return root
複雜度說明
時間O(n)
空間O(h)

邊界條件檢查清單

  • 最大的節點 → 值不變。
  • 負數節點 → 累加照樣正確。

常見追問

O(1) 空間

反向的 Morris 走訪：把「左右」對調，借用後繼節點的空左指標當線索。
