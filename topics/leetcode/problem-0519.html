Random Flip Matrix
隨機翻轉矩陣

Medium · 中等 水塘抽樣 雜湊表 數學 隨機化

Problem

There is an m x n binary grid matrix with all the values set 0 initially. Design an algorithm to randomly pick an index (i, j) where matrix[i][j] == 0 and flips it to 1. All the indices (i, j) where matrix[i][j] == 0 should be equally likely to be returned.

Optimize your algorithm to minimize the number of calls made to the built-in random function of your language and optimize the time and space complexity.

Implement the Solution class:

  • Solution(int m, int n) Initializes the object with the size of the binary matrix m and n.
  • int[] flip() Returns a random index [i, j] of the matrix where matrix[i][j] == 0 and flips it to 1.
  • void reset() Resets all the values of the matrix to be 0.

中文翻譯

有一個 m x n 的二元矩陣，一開始全是 0。設計一個演算法：

  • flip()：在所有值為 0 的格子中均勻隨機選一個，把它設成 1，並回傳它的座標 [i, j]。
  • reset()：把矩陣恢復成全 0。

盡量減少呼叫內建亂數函式的次數，並最佳化時間與空間。

範例

範例 輸入 ["Solution", "flip", "flip", "flip", "reset", "flip"] [[3, 1], [], [], [], [], []] 輸出 [null, [1, 0], [2, 0], [0, 0], null, [2, 0]]

限制條件

  • 1 ≤ m, n ≤ 10⁴
  • There will be at least one free cell for each call to flip.
  • 最多呼叫 1000 次（flip and reset）

LeetCode 原題

解題思路

【攤平成一維】 格子 (i, j) <-> 編號 i·n + j，總共 m·n 個。 【不能真的建陣列】 m, n 最多 10⁴，m·n 可達 10⁸，建陣列太大。 但 flip 最多呼叫 1000 次。 【Fisher–Yates + 雜湊表】 想像一個虛擬陣列 a = [0, 1, ..., total-1]（還沒翻的編號）。 flip： 隨機選 k ∈ [0, total)，答案是 a[k]； 把 a[total-1] 搬到 a[k]，total 減 1 -> a[k] 就被「刪除」了。 虛擬陣列大部分格子 a[i] = i，只有被搬過的才不一樣 -> 用雜湊表只記錄那些格子。 每次 flip 只呼叫一次亂數，O(1)。
解法

虛擬陣列的 Fisher–Yates

class Solution: def __init__(self, m: int, n: int): self.m, self.n = m, n self.total = m * n self.swap = {} # 虛擬陣列中「被換過」的位置：索引 -> 實際值 def flip(self) -> List[int]: k = random.randrange(self.total) # 在還沒翻的 total 個裡均勻選一個 self.total -= 1 idx = self.swap.get(k, k) # 虛擬陣列第 k 格的真正值 # ★ 把最後一格的值搬到第 k 格（Fisher–Yates 的一步），最後一格就被「刪掉」了 self.swap[k] = self.swap.get(self.total, self.total) return [idx // self.n, idx % self.n] def reset(self) -> None: self.total = self.m * self.n self.swap.clear()

驗證方式：每次翻完 m·n 次正好得到所有格子各一次；三萬次抽樣檢查分布均勻。

複雜度說明
時間flip / reset：O(1) 均攤
空間O(呼叫次數)reset 清空雜湊表的成本由之前的 flip 均攤

邊界條件檢查清單

  • 翻到最後一格 → k == total，雜湊表記錄自己，不影響正確性。
  • reset 後 → total 恢復、雜湊表清空。

拒絕抽樣的版本

也可以用集合記錄已翻過的格子，隨機到翻過的就重抽。翻得越多重抽越多次，最壞情況很慢——本題要求減少亂數呼叫，所以 Fisher–Yates 更好。
