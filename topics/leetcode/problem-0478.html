Generate Random Point in a Circle
在圓內隨機生成點

Medium · 中等 數學 幾何 拒絕抽樣 隨機化

Problem

Given the radius and the position of the center of a circle, implement the function randPoint which generates a uniform random point inside the circle.

Implement the Solution class:

  • Solution(double radius, double x_center, double y_center) initializes the object with the radius of the circle radius and the position of the center (x_center, y_center).
  • randPoint() returns a random point inside the circle. A point on the circumference of the circle is considered to be in the circle. The answer is returned as an array [x, y].

中文翻譯

給你圓的半徑和圓心，實作 randPoint()：在圓內（含圓周）均勻地隨機產生一個點。

範例

範例 Solution(1.0, 0.0, 0.0) randPoint() -> 例如 [-0.02493, -0.38077] randPoint() -> 例如 [0.82314, 0.38945]

限制條件

  • 0 < radius ≤ 10⁸
  • −10⁷ ≤ x_center, y_center ≤ 10⁷
  • 最多呼叫 3 × 10⁴ 次

LeetCode 原題

解題思路

【方法一：拒絕抽樣】 在外接正方形 [-r, r] × [-r, r] 均勻取點， 落在圓外就丟掉重來。 接受的機率 = 圓面積 / 正方形面積 = π/4 ≈ 78.5%， 期望取樣 4/π ≈ 1.27 次。 【方法二：極座標 —— 陷阱在距離】 角度 θ 均勻取 [0, 2π) ✔ 距離 d 均勻取 [0, r] ✘ 外圈的周長比內圈大，但分到的點一樣多 -> 點擠在圓心附近。 正確：半徑 d 以內的面積 ∝ d²， 要讓面積均勻，d² 要均勻 -> d = r × √U（U 均勻在 [0,1)）。 這叫「逆變換抽樣」。 【驗證均勻性】 半徑 r/2 的內圈面積是 1/4 -> 均勻的話約 25% 的點落在內圈； 錯誤版本會有約 50% 落在內圈。
錯誤示範

距離直接均勻取

class Solution: def __init__(self, radius: float, x_center: float, y_center: float): self.r, self.x, self.y = radius, x_center, y_center def randPoint(self) -> List[float]: theta = random.uniform(0, 2 * math.pi) d = self.r * random.random() # ✘ 沒有開根號：點會擠在圓心附近 return [self.x + d * math.cos(theta), self.y + d * math.sin(theta)]

四萬個點中約一半落在半徑 r/2 的內圈，而正確答案應該是四分之一。

解法一

拒絕抽樣

class Solution: def __init__(self, radius: float, x_center: float, y_center: float): self.r, self.x, self.y = radius, x_center, y_center def randPoint(self) -> List[float]: while True: # ★ 拒絕抽樣：在外接正方形取點 dx = random.uniform(-self.r, self.r) dy = random.uniform(-self.r, self.r) if dx * dx + dy * dy <= self.r * self.r: # 落在圓內才接受（機率 π/4） return [self.x + dx, self.y + dy]
複雜度說明
時間期望 O(1)期望取樣 4/π 次
空間O(1)
解法二

極座標 + 開根號

class Solution: def __init__(self, radius: float, x_center: float, y_center: float): self.r, self.x, self.y = radius, x_center, y_center def randPoint(self) -> List[float]: theta = random.uniform(0, 2 * math.pi) # ★ 距離要取 sqrt：半徑 r 以內的面積和 r² 成正比 d = self.r * math.sqrt(random.random()) return [self.x + d * math.cos(theta), self.y + d * math.sin(theta)]
複雜度說明
時間O(1)
空間O(1)

逆變換抽樣

想要某個分布 F，就用 F⁻¹(U)。圓的半徑分布 F(d) = (d/r)²，F⁻¹(u) = r√u。同樣的方法可以產生指數分布（−ln U / λ）等。
