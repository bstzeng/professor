LeetCode 554

Brick Wall
磚牆

Medium · 中等 陣列 雜湊表

Problem

There is a rectangular brick wall in front of you with n rows of bricks. The ith row has some number of bricks each of the same height (i.e., one unit) but they can be of different widths. The total width of each row is the same.

Draw a vertical line from the top to the bottom and cross the least bricks. If your line goes through the edge of a brick, then the brick is not considered as crossed. You cannot draw a line just along one of the two vertical edges of the wall, in which case the line will obviously cross no bricks.

Given the 2D array wall that contains the information about the wall, return the minimum number of crossed bricks after drawing such a vertical line.

中文翻譯

一面磚牆有 n 列，每列的磚塊高度相同、寬度不同，但每列的總寬度相同。wall[i] 是第 i 列由左到右的磚塊寬度。

從牆頂畫一條垂直線到底，若線剛好經過磚縫就不算穿過該磚。回傳這條線最少要穿過幾塊磚。不能沿著牆的兩側邊緣畫。

範例

範例 1 輸入：wall = [[1,2,2,1],[3,1,2],[1,3,2],[2,4],[3,1,2],[1,3,1,1]] 輸出：2 範例 2 輸入：wall = [[1],[1],[1]] 輸出：3

限制條件

  • n == wall.length
  • 1 ≤ n ≤ 10⁴
  • 1 ≤ wall[i].length ≤ 10⁴
  • 1 ≤ sum(wall[i].length) ≤ 2 * 10⁴
  • sum(wall[i]) is the same for each row i.
  • 1 ≤ wall[i][j] ≤ 2³¹ - 1

LeetCode 原題

解題思路

【換個角度數】 在位置 x 畫線：穿過的磚數 = 列數 - 在 x 有磚縫的列數。 要最少穿過 -> 找磚縫最多的位置。 【數磚縫】 每一列做前綴和，每個前綴和（最後一個除外）就是一條磚縫的位置。 用雜湊表數每個位置的磚縫數。 牆寬可能高達 2^31，不能枚舉 x； 但磚縫總數 = 磚塊總數，最多 2×10⁴。
解法

前綴和 + 雜湊表數磚縫

class Solution: def leastBricks(self, wall: List[List[int]]) -> int: edges = Counter() for row in wall: pos = 0 for w in row[:-1]: # 最右邊的磚縫是牆的邊界，不算 pos += w edges[pos] += 1 # 這個位置有一條磚縫 # ★ 穿過磚縫最多的位置，切到的磚最少 return len(wall) - max(edges.values(), default=0)
複雜度說明
時間O(磚塊總數)
空間O(磚塊總數)

邊界條件檢查清單

  • 每列只有一塊磚 → 沒有磚縫，答案是列數（max 用 default=0）。
  • 最右邊的邊界 → 不能算成磚縫。

常見追問

補集思維

「最少穿過幾塊」= 總列數 −「最多避開幾塊」。當直接數很難時，數它的補集常常比較容易。
