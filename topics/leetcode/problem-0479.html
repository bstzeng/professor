LeetCode 479

Largest Palindrome Product
最大回文數乘積

Hard · 困難 數學 列舉

Problem

Given an integer n, return the largest palindromic integer that can be represented as the product of two n-digits integers. Since the answer can be very large, return it modulo 1337.

中文翻譯

給你一個整數 n，找出能表示成兩個 n 位數乘積的最大回文數，回傳它 mod 1337 的結果。

範例

範例 1 輸入：n = 2 輸出：987 說明：99 × 91 = 9009，9009 % 1337 = 987 範例 2 輸入：n = 1 輸出：9

限制條件

  • 1 ≤ n ≤ 8

LeetCode 原題

解題思路

【暴力枚舉兩個因數：O(10²ⁿ)，n = 8 不可能】 【改成由大到小枚舉「回文數」】 兩個 n 位數的乘積最多 2n 位。 2n 位的回文數由左半邊（n 位）唯一決定： 左半 9889 -> 回文 98899889 從最大的左半邊往下試，第一個「能拆成兩個 n 位數相乘」的就是答案。 【怎麼檢查能不能拆？】 從最大的 n 位數 f = 10ⁿ - 1 往下試， p % f == 0 且 p / f 也是 n 位數就成立。 只需要試到 f² >= p（f 再小，另一個因數就會超過 n 位）。 【為什麼很快？】 答案通常很接近上界，只要試少數幾個左半邊就找到了。 （n >= 2 時，答案都是 2n 位的回文數。）
解法

由大到小枚舉回文數 + 檢查因數

class Solution: def largestPalindrome(self, n: int) -> int: if n == 1: return 9 hi = 10 ** n - 1 # 最大的 n 位數 lo = 10 ** (n - 1) for left in range(hi, lo - 1, -1): # ★ 由大到小枚舉「回文的左半邊」，組出 2n 位的回文數 p = int(str(left) + str(left)[::-1]) # 找一個 n 位數的因數 f，使 p / f 也是 n 位數 f = hi while f * f >= p: # f 從大往小試，只需要試到 √p if p % f == 0: return p % 1337 f -= 1 return -1

驗證方式：n = 1、2、3 和暴力枚舉所有因數對比對；n = 4、5、6 和已知答案比對。

複雜度說明
時間實際上很快理論上界難以精確分析
空間O(1)

邊界條件檢查清單

  • n = 1 → 9（= 9 × 1 或 3 × 3），是 1 位數的回文，特判。
  • 答案要 mod 1337 → 最後才取模。

常見追問

「枚舉答案」而不是「枚舉輸入」

當答案空間比輸入組合小很多、而且可以由大到小嘗試時，直接枚舉答案往往更快——第一個成立的就是最大值。第 906 題（超級回文數）也是枚舉回文的一半。
