LeetCode 628

Maximum Product of Three Numbers
三個數的最大乘積

Easy · 簡單 陣列 數學 排序

Problem

You are given an integer array nums.

Find three numbers whose product is maximum and return the maximum product.

中文翻譯

給你一個整數陣列（可能有負數），找出三個數使它們的乘積最大，回傳這個乘積。

範例

範例 1 輸入：nums = [1,2,3] 輸出：6 範例 2 輸入：nums = [1,2,3,4] 輸出：24 範例 3 輸入：nums = [-1,-2,-3] 輸出：-6

限制條件

  • 3 ≤ nums.length ≤ 10⁴
  • -1000 ≤ nums[i] ≤ 1000

LeetCode 原題

解題思路

【沒有負數】最大的三個相乘。 【有負數】 兩個負數相乘是正數。如果最小的兩個是很大的負數， min1 × min2 × max1 可能更大。 例：[-10, -10, 1, 2, 3] 最大三個：1×2×3 = 6 兩負一正：(-10)×(-10)×3 = 300 【其他組合不可能更好】 一個負數兩個正數 -> 乘積為負（除非沒得選，那也包含在上面兩種中）。 三個負數 -> 選絕對值最小的三個 = 最大的三個，已包含。 【只需要 5 個數】 最大的 3 個、最小的 2 個，一次掃描 O(n) 即可。
解法

最大三個與最小兩個

class Solution: def maximumProduct(self, nums: List[int]) -> int: a = heapq.nlargest(3, nums) b = heapq.nsmallest(2, nums) # ★ 兩種候選：最大的三個；或兩個最小（可能是兩個大負數，相乘變大正數）× 最大 return max(a[0] * a[1] * a[2], b[0] * b[1] * a[0])

驗證方式：和枚舉所有三元組比對 3000 組。

複雜度說明
時間O(n)
空間O(1)

邊界條件檢查清單

  • 全是負數 → 最大的三個（絕對值最小）。
  • 含 0 → 照樣被候選涵蓋。
  • 剛好 3 個數 → 兩個候選相同。

常見追問

排序版

排序後答案 = max(a[-1]·a[-2]·a[-3], a[0]·a[1]·a[-1])，寫起來最短，O(n log n)。
