LeetCode 414

Third Maximum Number
第三大的數

Easy · 簡單 陣列 排序

Problem

Given an integer array nums, return the third distinct maximum number in this array. If the third maximum does not exist, return the maximum number.

Follow up: Can you find an O(n) solution?

中文翻譯

給你一個整數陣列 nums，回傳第三大的不同數值；如果不同的數值不足三個，回傳最大值。

進階：能做到 O(n) 嗎？

範例

範例 1 輸入：nums = [3,2,1] 輸出：1 範例 2 輸入：nums = [1,2] 輸出：2 說明：不同的值只有兩個，回傳最大值。 範例 3 輸入：nums = [2,2,3,1] 輸出：1 說明：不同的值是 3、2、1。

限制條件

  • 1 ≤ nums.length ≤ 10⁴
  • −2³¹ ≤ nums[i] ≤ 2³¹ − 1

LeetCode 原題

解題思路

【維護前三大（互不相同）】 first > second > third 讀到 x： 已經是三者之一 -> 跳過（「不同的」第三大） x > first -> 全部往下擠一格 x > second -> second、third 往下擠 x > third -> 取代 third 【初始值的陷阱】 用 -2³¹ 當「還沒有」會出錯： [1, 2, -2³¹] 的第三大就是 -2³¹，無法分辨「真的有」還是「還沒有」。 用 None（或 -∞）當哨兵最安全。
解法一

集合 + 排序

class Solution: def thirdMax(self, nums: List[int]) -> int: top = sorted(set(nums), reverse=True) return top[2] if len(top) >= 3 else top[0]
複雜度說明
時間O(n log n)
空間O(n)
解法二

一趟維護前三大

class Solution: def thirdMax(self, nums: List[int]) -> int: first = second = third = None # 前三大（互不相同） for x in nums: if x in (first, second, third): # ★ 重複的值不算 continue if first is None or x > first: first, second, third = x, first, second elif second is None or x > second: second, third = x, second elif third is None or x > third: third = x return first if third is None else third # 不同的值不足三個 -> 回傳最大
複雜度說明
時間O(n)
空間O(1)

解法對照

解法時間空間
一、排序O(n log n)O(n)
二、前三大O(n)O(1) ✔

邊界條件檢查清單

  • 重複值 → 只算一次。
  • 不同的值少於三個 → 回傳最大值。
  • 值等於 −2³¹ → 不能用它當「不存在」的標記。
