LeetCode 347

Top K Frequent Elements
前 K 個高頻元素

Medium · 中等 陣列 雜湊表 分治 桶排序 計數 快速選擇 排序 堆積（優先佇列）

Problem

Given an integer array nums and an integer k, return the k most frequent elements. You may return the answer in any order.

It is guaranteed that the answer is unique.

Follow up: Your algorithm's time complexity must be better than O(n log n), where n is the array's size.

中文翻譯

給你一個整數陣列 nums 和整數 k，回傳出現次數最多的 k 個元素，順序不限。

保證答案唯一。

進階：時間複雜度必須優於 O(n log n)。

範例

範例 1 輸入：nums = [1,1,1,2,2,3], k = 2 輸出：[1,2] 範例 2 輸入：nums = [1], k = 1 輸出：[1]

限制條件

  • 1 ≤ nums.length ≤ 10⁵
  • −10⁴ ≤ nums[i] ≤ 10⁴
  • k 介於 1 和不同元素的個數之間
  • 保證答案唯一

LeetCode 原題

解題思路

【第一步都一樣：計數】 Counter(nums) -> {值: 次數}，O(n)。 【第二步：取次數最多的 k 個】 排序：O(m log m)，m = 不同元素個數 堆積：大小維持 k 的最小堆積，O(m log k) 桶排序：次數最多是 n -> 開 n+1 個桶，bucket[f] 放出現 f 次的值， 從最大的桶往下拿，拿滿 k 個為止。O(n) ✔ 【為什麼桶排序在這裡可行？】 「次數」的範圍是 1..n，有上界而且不大， 可以直接當索引。
解法一

Counter.most_common

class Solution: def topKFrequent(self, nums: List[int], k: int) -> List[int]: return [x for x, _ in collections.Counter(nums).most_common(k)]

most_common(k) 內部用 heapq.nlargest，O(m log k)。

複雜度說明
時間O(n + m log k)
空間O(m)
解法二

大小為 k 的最小堆積

class Solution: def topKFrequent(self, nums: List[int], k: int) -> List[int]: cnt = collections.Counter(nums) heap = [] # 大小為 k 的最小堆積（依頻率） for x, f in cnt.items(): heapq.heappush(heap, (f, x)) if len(heap) > k: heapq.heappop(heap) # 丟掉目前頻率最低的 return [x for f, x in heap]
複雜度說明
時間O(n + m log k)
空間O(m)
解法三

桶排序

class Solution: def topKFrequent(self, nums: List[int], k: int) -> List[int]: cnt = collections.Counter(nums) # ★ 桶排序：bucket[f] 放「出現 f 次」的數；頻率最多是 n bucket = [[] for _ in range(len(nums) + 1)] for x, f in cnt.items(): bucket[f].append(x) res = [] for f in range(len(nums), 0, -1): # 從高頻往低頻拿 res.extend(bucket[f]) if len(res) >= k: return res[:k] return res
複雜度說明
時間O(n)
空間O(n)

解法對照

解法時間備註
排序O(n + m log m)
一、most_commonO(n + m log k)一行
二、堆積O(n + m log k)資料流也適用
三、桶排序O(n)最快 ✔

邊界條件檢查清單

  • k = 不同元素個數 → 全部回傳。
  • 所有元素都一樣 → 只有一個。
  • 負數 → 計數時沒影響。
