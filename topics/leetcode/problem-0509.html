LeetCode 509

Fibonacci Number
斐波那契數

Easy · 簡單 遞迴 記憶化搜尋 數學 動態規劃

Problem

The Fibonacci numbers, commonly denoted F(n) form a sequence, called the Fibonacci sequence, such that each number is the sum of the two preceding ones, starting from 0 and 1. That is,

F(0) = 0, F(1) = 1 F(n) = F(n - 1) + F(n - 2), for n > 1.

Given n, calculate F(n).

中文翻譯

斐波那契數列定義為 F(0) = 0、F(1) = 1，F(n) = F(n − 1) + F(n − 2)（n > 1）。給你 n，計算 F(n)。

範例

範例 1 輸入：n = 2 輸出：1 範例 2 輸入：n = 3 輸出：2 範例 3 輸入：n = 4 輸出：3

限制條件

  • 0 ≤ n ≤ 30

LeetCode 原題

解題思路

【直接照定義遞迴：O(φⁿ)】 fib(n) 呼叫 fib(n-1) 和 fib(n-2)，大量重複計算。 fib(30) 約一百多萬次呼叫。 【記憶化 / 由下往上】 每個 F(i) 只算一次 -> O(n)。 而且 F(i) 只依賴前兩項 -> 兩個變數滾動，O(1) 空間。 【矩陣快速冪：O(log n)】 [F(n+1)] [1 1] [F(n) ] [F(n) ] = [1 0] [F(n-1)] 所以 [[1,1],[1,0]]^n 一次就得到 F(n)。 矩陣次方用「平方再平方」，只要 log n 次乘法。
解法一

滾動變數

class Solution: def fib(self, n: int) -> int: a, b = 0, 1 # F(0), F(1) for _ in range(n): a, b = b, a + b # ★ 只需要前兩項：滾動變數 return a
複雜度說明
時間O(n)
空間O(1)
解法二

矩陣快速冪

class Solution: def fib(self, n: int) -> int: def mul(A, B): return [[A[0][0] * B[0][0] + A[0][1] * B[1][0], A[0][0] * B[0][1] + A[0][1] * B[1][1]], [A[1][0] * B[0][0] + A[1][1] * B[1][0], A[1][0] * B[0][1] + A[1][1] * B[1][1]]] res, M = [[1, 0], [0, 1]], [[1, 1], [1, 0]] while n: # 快速冪：[[1,1],[1,0]]^n = [[F(n+1),F(n)],[F(n),F(n-1)]] if n & 1: res = mul(res, M) M = mul(M, M) n >>= 1 return res[0][1]

n 很大（而且要取模）時才有優勢；本題 n ≤ 30，解法一就夠了。

複雜度說明
時間O(log n)
空間O(1)

常見追問

線性遞迴的通解

任何「下一項是前 k 項的線性組合」的數列，都能寫成 k×k 矩陣的次方，用快速冪在 O(k³ log n) 算出第 n 項。第 1137 題（泰波那契）、第 70 題（爬樓梯）是同一族。
