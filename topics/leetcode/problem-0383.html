LeetCode 383

Ransom Note
贖金信

Easy · 簡單 雜湊表 字串 計數

Problem

Given two strings ransomNote and magazine, return true if ransomNote can be constructed by using the letters from magazine and false otherwise.

Each letter in magazine can only be used once in ransomNote.

中文翻譯

給你兩個字串 ransomNote（勒索信）和 magazine（雜誌），判斷能不能用雜誌上剪下來的字母拼出勒索信。

雜誌上的每個字母只能用一次。

範例

範例 1 輸入：ransomNote = "a", magazine = "b" 輸出：false 範例 2 輸入：ransomNote = "aa", magazine = "ab" 輸出：false 範例 3 輸入：ransomNote = "aa", magazine = "aab" 輸出：true

限制條件

  • 1 ≤ ransomNote.length, magazine.length ≤ 10⁵
  • 只包含小寫英文字母

LeetCode 原題

解題思路

【每種字母：雜誌提供的數量 >= 信需要的數量】 【計數】 先數雜誌裡每個字母有幾個（庫存）， 再逐字扣掉信需要的，任何一種扣到負數就不夠。 【Counter 的寫法】 Counter(信) - Counter(雜誌)： 相減之後只保留正數 -> 剩下的是「還缺的字母」， 空的代表不缺。
解法一

Counter 相減

class Solution: def canConstruct(self, ransomNote: str, magazine: str) -> bool: # Counter 相減會丟掉 <= 0 的項：剩下的就是「不夠的字母」 return not (collections.Counter(ransomNote) - collections.Counter(magazine))
複雜度說明
時間O(m + n)
空間O(1)最多 26 種字母
解法二

26 格計數陣列

class Solution: def canConstruct(self, ransomNote: str, magazine: str) -> bool: cnt = [0] * 26 for ch in magazine: # 雜誌提供的字母 cnt[ord(ch) - 97] += 1 for ch in ransomNote: # 信需要的字母 i = ord(ch) - 97 cnt[i] -= 1 if cnt[i] < 0: # ★ 不夠用了 return False return True
複雜度說明
時間O(m + n)
空間O(1)

解法對照

解法時間空間
一、CounterO(m + n)O(1)
二、26 格陣列O(m + n)O(1) ✔

  • 重複字母 → 數量要夠。
