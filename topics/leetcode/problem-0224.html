LeetCode 224

Basic Calculator
基本計算器

Hard · 困難 數學 字串 堆疊 遞迴

Problem

Given a string s representing a valid arithmetic expression, evaluate it and return the result.

The expression contains non-negative integers, '+', '-', '(', ')', and spaces. '-' may be used as a unary minus (for example "-1" or "-(2 + 3)"), but '+' is never unary.

You may not use any built-in function that evaluates strings as expressions, such as eval().

中文翻譯

給你一個字串 s，代表一個合法的算式，請計算並回傳結果。

算式只包含非負整數、'+'、'-'、'('、')' 和空白。'-' 可以當作一元負號（例如 "-1"、"-(2 + 3)"），但 '+' 不會是一元的。

不能使用 eval() 這類直接計算字串的內建函式。

範例

範例 1 輸入：s = "1 + 1" 輸出：2 範例 2 輸入：s = " 2-1 + 2 " 輸出：3 範例 3 輸入：s = "(1+(4+5+2)-3)+(6+8)" 輸出：23

限制條件

  • 1 ≤ s.length ≤ 3 × 10⁵
  • s 由數字、'+'、'-'、'('、')'、' ' 組成
  • s 是合法的算式
  • 不會出現連續兩個運算子
  • 所有數字與運算過程的結果都在 32 位元有號整數範圍內

LeetCode 原題

解題思路

【沒有括號時】 只有加減，由左到右：每個數字帶著它前面的正負號加總。 "2 - 1 + 2" = (+2) + (-1) + (+2) = 3 一元負號自然成立："-1" 就是 (sign = -1) × 1。 【有括號時】 一對括號 = 一個小算式，它的值要整體帶著前面的正負號： "3 - (4 - 5)" = 3 + (-1) × (4 - 5) = 4 【用堆疊暫存外層的狀態】 遇到 '(' ： 把目前的 result 和括號前的 sign 推進堆疊， 括號內從 result = 0、sign = +1 重新開始。 遇到 ')' ： 結算括號內的值 inner， 彈出外層的 (prev_result, prev_sign)： result = prev_result + prev_sign × inner 【最容易漏的】 ')' 之前的最後一個數字、字串結尾的最後一個數字， 都要記得 result += sign × num。
解法一

一次掃描 + 堆疊

class Solution: def calculate(self, s: str) -> int: result = 0 # 目前這一層括號內的累計結果 num = 0 # 正在讀的數字 sign = 1 # 這個數字前面的正負號 stack = [] # 進入括號時，存下外層的 (result, sign) for ch in s: if ch.isdigit(): num = num * 10 + int(ch) elif ch in "+-": result += sign * num # 前一個數字結算 num = 0 sign = 1 if ch == "+" else -1 elif ch == "(": stack.append((result, sign)) # ★ 暫存外層，括號內從 0 重新開始 result, sign = 0, 1 elif ch == ")": result += sign * num # 括號內最後一個數字 num = 0 prev_result, prev_sign = stack.pop() result = prev_result + prev_sign * result # ★ 括號整體帶著前面的符號 # 空白直接略過 return result + sign * num
【模擬】s = "1 - (2 + 3)" 讀 1 num = 1 讀 '-' result = 1, sign = -1 讀 '(' push (1, -1)；result = 0, sign = 1 讀 2, '+' result = 2, sign = 1 讀 3, ')' result = 2 + 3 = 5；pop (1, -1) result = 1 + (-1) × 5 = -4 結尾 -4 + 1 × 0 = -4 ✔
複雜度說明
時間O(n)
空間O(n)堆疊深度 = 括號層數
解法二

遞迴下降

class Solution: def calculate(self, s: str) -> int: i = 0 def expr() -> int: # 讀到 ')' 或字串結尾為止 nonlocal i total, sign, num = 0, 1, 0 while i < len(s): ch = s[i] i += 1 if ch.isdigit(): num = num * 10 + int(ch) elif ch in "+-": total += sign * num num, sign = 0, (1 if ch == "+" else -1) elif ch == "(": num = expr() # ★ 遞迴算出括號的值，當成一個數字 elif ch == ")": break return total + sign * num return expr()
【遇到 '(' 就遞迴呼叫 expr()】 它會讀到對應的 ')' 為止，回傳括號內的值， 這個值被當成一個普通數字 num，接著由外層的 sign 處理。 【nonlocal i】 所有層級共用同一個讀取位置， 內層讀過的字元，外層不會再讀一次。 【遞迴深度】 = 括號巢狀層數。極端情況（上萬層括號）會超過遞迴上限。
複雜度說明
時間O(n)
空間O(n)遞迴深度

邊界條件檢查清單

  • 開頭就是負號（"-1"）→ sign 一開始變成 −1，自然處理。
  • 括號前的負號（"-(2+3)"）→ 整個括號取負。
  • 括號內開頭是負號（"1-(-2)"）→ 括號內 sign 重新從 +1 開始，才能正確處理。
  • 多位數 → num = num * 10 + d。
  • 大量空白 → 直接略過。
  • 忘了結算最後一個數字 → 答案少一項。

常見追問

追問：如果加上乘除（第 227 題）？

乘除優先順序比加減高 —— 遇到加減時把數字（帶正負號）推進堆疊； 遇到乘除時彈出堆疊頂端，算完再推回去； 最後把堆疊全部加總。

追問：加減乘除再加括號（第 772 題，付費）？

把第 227 題的做法放進遞迴下降：每遇到 '(' 就遞迴，括號內用堆疊處理乘除。
