Subarray Sum Equals K
和為 K 的子陣列

Medium · 中等 陣列 雜湊表 前綴和

Problem

Given an array of integers nums and an integer k, return the total number of subarrays whose sum equals to k.

A subarray is a contiguous non-empty sequence of elements within an array.

中文翻譯

給你整數陣列 nums（可能有負數）和整數 k，回傳和為 k 的連續子陣列的個數。

範例

範例 1 輸入：nums = [1,1,1], k = 2 輸出：2 範例 2 輸入：nums = [1,2,3], k = 3 輸出：2

限制條件

  • 1 ≤ nums.length ≤ 2 * 10⁴
  • -1000 ≤ nums[i] ≤ 1000
  • -10⁷ ≤ k ≤ 10⁷

LeetCode 原題

解題思路

【為什麼不能用滑動視窗？】 有負數 -> 視窗擴大不一定讓和變大，失去單調性。 【前綴和】 nums[i+1..j] 的和 = P[j] - P[i]。 它等於 k <=> P[i] = P[j] - k。 【雜湊表記次數】 掃到 j 時，以 j 結尾、和為 k 的子陣列個數 = 之前有幾個前綴和等於 P[j] - k。 先查、再把 P[j] 加入（避免和自己配對成空陣列）。 空前綴 P = 0 預先放一次。
解法

前綴和 + 雜湊表計數

class Solution: def subarraySum(self, nums: List[int], k: int) -> int: seen = Counter({0: 1}) # 前綴和 -> 出現次數（空前綴的和是 0） s = res = 0 for x in nums: s += x res += seen[s - k] # ★ 之前有幾個前綴和等於 s - k，就有幾段以這裡結尾、和為 k seen[s] += 1 return res
複雜度說明
時間O(n)
空間O(n)

邊界條件檢查清單

  • k = 0 → 前綴和重複出現的次數。
  • 負數 → 同一個前綴和可能出現多次，所以要記次數。
  • 先查後加 → 順序反了會把空子陣列算進去（k = 0 時）。
