LeetCode 674

Longest Continuous Increasing Subsequence
最長連續遞增序列

Easy · 簡單 陣列

Problem

Given an unsorted array of integers nums, return the length of the longest continuous increasing subsequence (i.e. subarray). The subsequence must be strictly increasing.

A continuous increasing subsequence is defined by two indices l and r (l < r) such that it is [nums[l], nums[l + 1], ..., nums[r - 1], nums[r]] and for each l <= i < r, nums[i] < nums[i + 1].

中文翻譯

給你一個未排序的整數陣列，找出最長且連續的嚴格遞增子陣列，回傳它的長度。

範例

範例 1 輸入：nums = [1,3,5,4,7] 輸出：3 範例 2 輸入：nums = [2,2,2,2,2] 輸出：1

限制條件

  • 1 ≤ nums.length ≤ 10⁴
  • -10⁹ ≤ nums[i] ≤ 10⁹

LeetCode 原題

解題思路

【連續 -> 不需要 DP】 cur = 以目前位置結尾的連續遞增長度。 nums[i] > nums[i-1] -> cur + 1 否則 -> 從 1 重新開始 對照第 300 題：不要求連續（子序列）就需要 DP 或二分。
解法

一趟掃描

class Solution: def findLengthOfLCIS(self, nums: List[int]) -> int: res = cur = 1 for i in range(1, len(nums)): cur = cur + 1 if nums[i] > nums[i - 1] else 1 # ★ 遞增就延長，否則重新開始 res = max(res, cur) return res
複雜度說明
時間O(n)
空間O(1)

邊界條件檢查清單

  • 相等 → 不算遞增，重設。
  • 單一元素 → 1。

常見追問

子陣列 vs 子序列

連續（子陣列）：通常一趟掃描或滑動視窗；不連續（子序列）：通常需要 DP。
