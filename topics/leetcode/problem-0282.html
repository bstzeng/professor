LeetCode 282

Expression Add Operators
給表達式添加運算子

Hard · 困難 數學 字串 回溯

Problem

Given a string num that contains only digits and an integer target, return all possibilities to insert the binary operators '+', '-', and/or '*' between the digits of num so that the resultant expression evaluates to the target value.

Note that operands in the returned expressions should not contain leading zeros.

中文翻譯

給你一個只包含數字的字串 num 和整數 target。在數字之間插入 '+'、'-'、'*'（也可以不插，讓相鄰數字合成多位數），回傳所有計算結果等於 target 的算式。

運算元不能有前導零（例如 "05" 不合法，但單獨的 "0" 可以）。

範例

範例 1 輸入：num = "123", target = 6 輸出：["1*2*3","1+2+3"] 範例 2 輸入：num = "232", target = 8 輸出：["2*3+2","2+3*2"] 範例 3 輸入：num = "3456237490", target = 9191 輸出：[]

限制條件

  • 1 ≤ num.length ≤ 10
  • num 只包含數字
  • −2³¹ ≤ target ≤ 2³¹ − 1

LeetCode 原題

解題思路

【回溯：每一步決定「下一個運算元有多長」和「前面放什麼運算子」】 num = "123"： 1 | 2 | 3、12 | 3、1 | 23、123 每個切點之間可以放 + - *。 【難點：乘法的優先順序】 邊走邊算 value 時，遇到乘法不能直接 value * x： 1 + 2 * 3 ≠ (1 + 2) * 3 解法：多記一個 last = 最後一「項」的值（含正負號）。 1 + 2 value = 3, last = 2 1 + 2 * 3 撤銷 last：value - last = 1 新的 last = 2 * 3 = 6 value = 1 + 6 = 7 ✔ 減法：last = -x，所以 1 - 2 * 3 也正確： value = -1, last = -2 -> value = -1 - (-2) + (-6) = -5 ✔ 【前導零】 從 num[i] 開始切，如果 num[i] == '0'，只能切出單獨的 "0"。 【複雜度】 n-1 個切點，每個有 4 種選擇（不切、+、-、*）-> O(4ⁿ)， 再乘上每次組字串 O(n)。n ≤ 10 -> 4¹⁰ ≈ 10⁶，可以接受。
解法

回溯 + 記錄最後一項

class Solution: def addOperators(self, num: str, target: int) -> List[str]: res = [] n = len(num) def dfs(i: int, expr: str, value: int, last: int): # value：目前算式的值；last：最後一「項」（乘法會改到它） if i == n: if value == target: res.append(expr) return for j in range(i, n): if j > i and num[i] == "0": # ★ 不能有前導零（"05" 不是合法數字） break s = num[i:j + 1] x = int(s) if i == 0: # 第一個數字前面不能放運算子 dfs(j + 1, s, x, x) else: dfs(j + 1, expr + "+" + s, value + x, x) dfs(j + 1, expr + "-" + s, value - x, -x) # ★ 乘法：撤銷上一項，改成 上一項 × x dfs(j + 1, expr + "*" + s, value - last + last * x, last * x) dfs(0, "", 0, 0) return res
【模擬】num = "232", target = 8 2 value=2, last=2 2+3 value=5, last=3 2+3*2 value=5-3+6=8 ✔ 2*3 value=2-2+6=6, last=6 2*3+2 value=8 ✔ 23 value=23, last=23 ...
複雜度說明
時間O(n · 4ⁿ)
空間O(n)遞迴深度，不計輸出

邊界條件檢查清單

  • 前導零（"105"）→ "1*05" 不合法，但 "1*0+5" 可以。
  • 全是 0（"00", 0）→ "0+0"、"0-0"、"0*0"；"00" 不合法。
  • 大數（"9999999999"）→ Python 沒有溢位問題；其他語言用 long。
  • 只有一位數 → 只有它本身。

常見追問

為什麼只需要記「最後一項」？

乘法只會和緊鄰在它左邊的那一項結合；更早的項已經被 + 或 − 隔開，不會再改變。這和第 227 題「只保留最後一項」的想法相同。
