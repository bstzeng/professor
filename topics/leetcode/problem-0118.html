LeetCode 118

Pascal's Triangle
楊輝三角

Easy · 簡單 陣列 動態規劃

Problem

Given an integer numRows, return the first numRows of Pascal's triangle.

In Pascal's triangle, each number is the sum of the two numbers directly above it.

中文翻譯

給你一個整數 numRows，回傳楊輝三角（Pascal's triangle）的前 numRows 列。

在楊輝三角裡，每個數字都等於它正上方兩個數字的和。

範例

範例 1 輸入：numRows = 5 輸出：[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]] 1 1 1 1 2 1 1 3 3 1 1 4 6 4 1 範例 2 輸入：numRows = 1 輸出：[[1]]

限制條件

  • 1 ≤ numRows ≤ 30

LeetCode 原題

解題思路

遞迴式： row[i][0] = row[i][i] = 1 兩端永遠是 1 row[i][j] = row[i-1][j-1] + row[i-1][j] 中間的是左上 + 右上 實作技巧：【先把整列填成 1，再回頭改中間的】 row = [1] * (i + 1) for j in range(1, i): row[j] = res[i-1][j-1] + res[i-1][j] 這樣兩端就完全不用特判 ✔ 注意 range(1, i) 而不是 range(1, i+1) —— 第 i 列有 i+1 個元素（索引 0..i）， 要改的是索引 1..i-1。 i = 0: range(1,0) 空 -> [1] ✔ i = 1: range(1,1) 空 -> [1,1] ✔ i = 2: range(1,2) -> 改 row[1] -> [1,2,1] ✔ 【「先填預設值、再改需要改的」是避免邊界特判的通用技巧。】 複雜度： 第 i 列有 i+1 個元素，總共 1+2+...+n = O(n²) 個數字。 【這是輸出的大小，所以 O(n²) 是下界 —— 不可能更快。】
解法一

逐列遞推（標準答案）

class Solution: def generate(self, numRows: int) -> List[List[int]]: res = [] for i in range(numRows): row = [1] * (i + 1) # 先全填 1，兩端就不用特判 for j in range(1, i): # 中間的才要算（j 從 1 到 i-1） row[j] = res[i - 1][j - 1] + res[i - 1][j] res.append(row) return res

五行。[1] * (i+1) 這一手省掉了所有邊界判斷。

時間 O(n²)、空間 O(n²)（就是輸出本身）。n ≤ 30，所以最多 465 個數字。

複雜度說明
時間O(n²)輸出的大小
空間O(n²)輸出本身
解法二

移位相加（Python 最漂亮的寫法）

class Solution: def generate(self, numRows: int) -> List[List[int]]: res, row = [], [1] for _ in range(numRows): res.append(row) # 把這一列左移一格、右移一格，逐項相加 -> 下一列 row = [a + b for a, b in zip([0] + row, row + [0])] return res

一行生出下一列

row = [a + b for a, b in zip([0] + row, row + [0])] [0] + row = 把這一列往【右】推一格（左邊補 0） row + [0] = 把這一列往【左】推一格（右邊補 0） 逐項相加，就是「左上 + 右上」✔ 驗證 row = [1, 3, 3, 1]： [0, 1, 3, 3, 1] + [1, 3, 3, 1, 0] = [1, 4, 6, 4, 1] ✔ 而且長度自動加一 ✔ 兩端也自動是 1（0 加上原本的 1）✔ 【零個特判。】

★ 注意「先 append 再遞推」的順序

res, row = [], [1] for _ in range(numRows): res.append(row) # 先把目前這一列收下 row = [a + b for ...] # 再算出下一列 【順序反過來就錯了】： res, row = [], [] for _ in range(numRows): row = [a+b for a,b in zip([0]+row, row+[0])] res.append(row) 第一輪：row = [] [0] + [] = [0] [] + [0] = [0] zip([0], [0]) -> [(0, 0)] -> row = [0] ✘ 應該是 [1] 整個三角形會從 [0] 開始，全部錯掉。 要讓它對，初始值必須是 row = [1]， 而且【要先收下再遞推】。 【這是「漂亮的一行式」最典型的風險】： 邏輯本身沒問題，但邊界（第一輪）要另外想清楚。 一行式把迴圈的骨架壓縮掉了， 連帶也把「第一輪長什麼樣」藏了起來。 【寫完一行式，一定要手算 n = 0, 1, 2 三個情況。】 這一段不是在勸你別寫一行式 —— 而是提醒：越短的程式碼，越需要邊界驗算。

複雜度和解法一完全相同，而且不需要回頭去查 res[i-1]。

複雜度說明
時間O(n²)輸出的大小
空間O(n²)輸出本身
解法三

直接算組合數

import math class Solution: def generate(self, numRows: int) -> List[List[int]]: # 第 i 列第 j 項就是組合數 C(i, j) return [[math.comb(i, j) for j in range(i + 1)] for i in range(numRows)]
第 i 列第 j 項 = C(i, j) 為什麼？ 從三角形頂端走到位置 (i, j)： 每一步往左下或往右下，共走 i 步， 其中恰好 j 步往右下。 路徑數 = C(i, j) ✔ 而「每個數是上面兩個的和」正是 C(i, j) = C(i-1, j-1) + C(i-1, j) 這個遞迴式（帕斯卡法則）。 證明：從 i 個東西選 j 個， 分成「有沒有選第 i 個」兩種情況： 選了 -> 從剩下 i-1 個選 j-1 個 -> C(i-1, j-1) 沒選 -> 從剩下 i-1 個選 j 個 -> C(i-1, j) 【「選或不選」的分解 —— 和 01 背包、 第 115 題（不同子序列）是完全一樣的思路。】

一行，但 math.comb 每次呼叫要 O(j) 時間，總共 O(n³) —— 比遞推慢，但 n ≤ 30 完全無所謂。

價值在於它點出了「這個三角形就是組合數表」這件事。

複雜度說明
時間O(n³)每次 comb 是 O(j)
空間O(n²)輸出本身

解法時間空間行數備註

邊界條件檢查清單

  • numRows = 1 → [[1]]。
  • numRows = 0（題目保證不會）→ []。三種解法都自然正確。
  • range(1, i) 寫成 range(1, i+1) → res[i-1][i] 索引越界。
  • 沒有先填 1 就直接算 → 兩端要特判，容易漏。
  • numRows = 30 → 最大的數是 C(29,14) = 77558760，遠小於 2³¹，不會溢位。
  • 移位版初始值寫成 row = []、或先遞推再 append → 第一列會變成 [0]，整個三角形全錯。

常見追問

追問一：如果只要「第 k 列」呢？

第 119 題。可以只用 O(k) 空間 —— 在一個陣列上倒著更新，或直接用乘除算組合數。

追問二：楊輝三角還有哪些性質？

第 i 列的和 = 2^i （二項式定理：(1+1)^i） 第 i 列的交錯和 = 0 (i>0) （(1-1)^i = 0） 沿對角線加 = 費氏數列 第 i 列所有數的 gcd：i 是質數時，中間各項都被 i 整除 對 2 取模後畫出來 = 謝爾賓斯基三角形（碎形！） 第 i 列的最大值在中間，約為 2^i / sqrt(πi/2) 【最後一條是史特林近似的應用】—— 它解釋了為什麼 C(2n,n) 大約是 4^n / sqrt(πn)， 也就是第 96 題卡塔蘭數的漸進大小。 「對 2 取模是碎形」這件事特別有趣： C(i,j) 是奇數 ⟺ j 的二進位是 i 的二進位的「子集」 （Kummer 定理 / Lucas 定理）

追問三：如果 numRows 很大（例如 10⁵）呢？

輸出本身就有 10¹⁰ 個數字 —— 不可能存下來。

那時題目一定會改成「只要第 k 列」或「只要某一項」，而且會要求對某個質數取模（否則數字本身就是天文數字）。取模之後就可以用 Lucas 定理在 O(log n) 內算單一項。

追問四：「路徑數」的解釋能推廣嗎？

能 —— 那就是第 62 題（不同路徑）：m×n 網格從左上走到右下的路徑數 = C(m+n-2, m-1)。

楊輝三角本質上就是「把網格旋轉 45 度」。第 62、63、118、119 題是同一個東西的四種包裝。

延伸題目

  • 第 119 題 Pascal's Triangle II —— 只要第 k 列，O(k) 空間
  • 第 62 題 Unique Paths —— 同一個組合數，換成網格
  • 第 96 題 Unique Binary Search Trees —— 卡塔蘭數也是組合數
  • 第 115 題 Distinct Subsequences —— 同樣的「選或不選」分解
