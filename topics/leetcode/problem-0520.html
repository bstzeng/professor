LeetCode 520

Detect Capital
檢測大寫字母

Easy · 簡單 字串

Problem

We define the usage of capitals in a word to be right when one of the following cases holds:

  • All letters in this word are capitals, like "USA".
  • All letters in this word are not capitals, like "leetcode".
  • Only the first letter in this word is capital, like "Google".

Given a string word, return true if the usage of capitals in it is right.

中文翻譯

以下三種情況，我們說一個單字的大寫用法是正確的：

  1. 全部字母都大寫，例如 "USA"。
  2. 全部字母都小寫，例如 "leetcode"。
  3. 只有第一個字母大寫，例如 "Google"。

給你字串 word，判斷它的大寫用法是否正確。

範例

範例 1 輸入：word = "USA" 輸出：true 範例 2 輸入：word = "FlaG" 輸出：false

限制條件

  • 1 ≤ word.length ≤ 100
  • word consists of lowercase and uppercase English letters.

LeetCode 原題

解題思路

【直接檢查三種情況】 word.isupper() 或 word.islower() 或 (首字大寫且其餘小寫)。 【計數的寫法】 數大寫字母個數 cap： cap == 0 -> 全小寫 cap == len(word) -> 全大寫 cap == 1 且首字是大寫 -> 首字母大寫 【小陷阱】 "g".isupper() 是 False，但 word[1:] 是空字串時， "".islower() 也是 False —— 單一字母的情況要靠前兩個條件涵蓋。
解法

三種情況判斷

class Solution: def detectCapitalUse(self, word: str) -> bool: # 三種合法情況：全大寫、全小寫、只有第一個字母大寫 return word.isupper() or word.islower() or (word[0].isupper() and word[1:].islower())
複雜度說明
時間O(n)
空間O(1)

邊界條件檢查清單

  • 單一字母 → 一定合法（被 isupper 或 islower 涵蓋）。
  • "FlaG" → 不合法。

常見追問

Python 字串方法的細節

isupper()/islower() 要求「至少有一個有大小寫之分的字元」，空字串回傳 False。這在組合條件時要特別注意。
