Find K Pairs with Smallest Sums
查找和最小的 K 對數字

Medium · 中等 陣列 堆積（優先佇列）

Problem

You are given two integer arrays nums1 and nums2 sorted in non-decreasing order and an integer k.

Define a pair (u, v) which consists of one element from the first array and one element from the second array.

Return the k pairs (u1, v1), (u2, v2), ..., (uk, vk) with the smallest sums.

中文翻譯

給你兩個非遞減排序的整數陣列 nums1、nums2，以及整數 k。

一個數對 (u, v) 由第一個陣列的一個元素和第二個陣列的一個元素組成。

回傳和最小的 k 個數對。

範例

範例 1 輸入：nums1 = [1,7,11], nums2 = [2,4,6], k = 3 輸出：[[1,2],[1,4],[1,6]] 範例 2 輸入：nums1 = [1,1,2], nums2 = [1,2,3], k = 2 輸出：[[1,1],[1,1]]

限制條件

  • 1 ≤ nums1.length, nums2.length ≤ 10⁵
  • −10⁹ ≤ nums1[i], nums2[i] ≤ 10⁹
  • 兩個陣列都是非遞減排序
  • 1 ≤ k ≤ 10⁴，k ≤ nums1.length × nums2.length

解題思路

【所有數對排成一張表】 nums2 -> nums1 (0,0) (0,1) (0,2) ... | (1,0) (1,1) (1,2) ... v (2,0) (2,1) ... 每一列（固定 i）由左到右和遞增；每一欄由上到下也遞增。 【多路合併（第 23 題的套路）】 把每一列看成一條有序串列。 堆積裡放每一列「目前最小的那一個」： 一開始是 (i, 0)，對所有 i 彈出 (i, j) 後，放入同一列的下一個 (i, j+1) 彈 k 次就是答案。 【只需要前 k 列】 第 k 列之後的 (i, 0) 至少比 (0,0)..(k-1,0) 這 k 個都大， 不可能擠進前 k 名。 所以堆積大小最多 k -> 每次 O(log k)。 【為什麼不用 visited？】 有些寫法從 (0,0) 開始，同時往右、往下擴展，需要集合去重。 「每列一條串列、只往右走」的寫法每個格子只會被放入一次，不需要去重。
解法

最小堆積多路合併

class Solution: def kSmallestPairs(self, nums1: List[int], nums2: List[int], k: int) -> List[List[int]]: # 把每個 nums1[i] 想成一條有序串列：(i,0), (i,1), (i,2), ... # ★ 多路合併：一開始放每條串列的第一個（最多 k 條就夠） heap = [(nums1[i] + nums2[0], i, 0) for i in range(min(k, len(nums1)))] heapq.heapify(heap) res = [] while heap and len(res) < k: _, i, j = heapq.heappop(heap) res.append([nums1[i], nums2[j]]) if j + 1 < len(nums2): # 同一條串列的下一個 heapq.heappush(heap, (nums1[i] + nums2[j + 1], i, j + 1)) return res
複雜度說明
時間O(k log k)
空間O(k)

邊界條件檢查清單

  • 重複值 → 不同位置的相同數對要分別算（範例 2）。
  • k 大於某一個陣列的長度 → 初始只放 min(k, len(nums1)) 列。
  • 負數 → 不影響，排序關係照樣成立。

常見追問

k 很大時

對「和」二分搜尋：給定 x，用雙指標 O(m + n) 數出和 ≤ x 的數對有幾個，找到第 k 小的和，再收集答案。和第 378 題（有序矩陣第 K 小）是同一個想法。
