Employee Importance
員工的重要性

Medium · 中等 樹 深度優先搜尋 廣度優先搜尋 陣列

Problem

You have a data structure of employee information, including the employee's unique ID, importance value, and direct subordinates' IDs.

You are given an array of employees employees where:

  • employees[i].id is the ID of the ith employee.
  • employees[i].importance is the importance value of the ith employee.
  • employees[i].subordinates is a list of the IDs of the direct subordinates of the ith employee.

Given an integer id that represents an employee's ID, return the total importance value of this employee and all their direct and indirect subordinates.

中文翻譯

每位員工有唯一的 id、重要性 importance，以及直接下屬的 id 清單 subordinates。

給你所有員工資料和一個 id，回傳這位員工與他所有直接和間接下屬的重要性總和。

範例

範例 1 輸入：employees = [[1,5,[2,3]],[2,3,[]],[3,3,[]]], id = 1 輸出：11 範例 2 輸入：employees = [[1,2,[5]],[5,-3,[]]], id = 5 輸出：-3

限制條件

  • 1 ≤ employees.length ≤ 2000
  • 1 ≤ employees[i].id ≤ 2000
  • All employees[i].id are unique.
  • -100 ≤ employees[i].importance ≤ 100
  • One employee has at most one direct leader and may have several subordinates.
  • The IDs in employees[i].subordinates are valid IDs.

LeetCode 原題

解題思路

【組織圖是一棵樹（森林）】 從指定員工出發，DFS 或 BFS 走過整棵子樹，加總重要性。 【先建索引】 員工資料是清單，按 id 查詢要 O(n)； 先建雜湊表 id -> 員工，每次查詢 O(1)。
解法

雜湊表 + DFS

class Solution: def getImportance(self, employees: List['Employee'], id: int) -> int: emp = {e.id: e for e in employees} # id -> 員工，O(1) 查詢 def total(i): e = emp[i] return e.importance + sum(total(s) for s in e.subordinates) # ★ 自己 + 所有下屬（遞迴） return total(id)
複雜度說明
時間O(n)
空間O(n)

邊界條件檢查清單

  • 沒有下屬 → 只有自己的重要性。
  • 負的重要性 → 照樣加總。

常見追問

很深的組織？

遞迴深度可能很深時改用 BFS 或顯式堆疊。
