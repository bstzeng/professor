Island Perimeter
島嶼的周長

Easy · 簡單 深度優先搜尋 廣度優先搜尋 陣列 矩陣

Problem

You are given row x col grid representing a map where grid[i][j] = 1 represents land and grid[i][j] = 0 represents water.

Grid cells are connected horizontally/vertically (not diagonally). The grid is completely surrounded by water, and there is exactly one island (i.e., one or more connected land cells).

The island doesn't have "lakes", meaning the water inside isn't connected to the water around the island. One cell is a square with side length 1. The grid is rectangular, width and height don't exceed 100. Determine the perimeter of the island.

中文翻譯

給你一張地圖 grid，1 是陸地、0 是水。格子只以上下左右相連。地圖外圍都是水，而且恰好有一座島（沒有湖）。

每格邊長 1，回傳島的周長。

範例

範例 1 輸入：grid = [[0,1,0,0],[1,1,1,0],[0,1,0,0],[1,1,0,0]] 輸出：16 範例 2 輸入：grid = [[1]] 輸出：4

限制條件

  • 1 ≤ row, col ≤ 100
  • grid[i][j] 是 0 或 1
  • 恰好有一座島

LeetCode 原題

解題思路

【每塊陸地貢獻 4 條邊】 但兩塊相鄰的陸地之間那條邊不在周長上 —— 它被兩塊陸地各算了一次，所以要扣 2。 周長 = 4 × 陸地數 - 2 × 相鄰的陸地對數 【數相鄰對：只看上和左】 每一對相鄰只會被數一次（在右邊或下邊那一格數到它）。 【另一種寫法】 對每塊陸地，數它四個方向中「是水或出界」的邊。
解法

計數：4 × 陸地 − 2 × 共用邊

class Solution: def islandPerimeter(self, grid: List[List[int]]) -> int: land = shared = 0 for i, row in enumerate(grid): for j, v in enumerate(row): if v: land += 1 if i and grid[i - 1][j]: # 和上面的陸地共用一條邊 shared += 1 if j and row[j - 1]: # 和左邊的陸地共用一條邊 shared += 1 # ★ 每塊陸地 4 條邊；每條共用邊讓兩塊各少 1 return 4 * land - 2 * shared
複雜度說明
時間O(mn)
空間O(1)

邊界條件檢查清單

  • 單一格子 → 4。
  • 一排陸地 → 2 × 長度 + 2。
  • 貼著地圖邊界 → 出界也算周長。

常見追問

如果有湖？

湖的內側邊也算周長的話，公式照樣成立（湖邊也是「陸地旁邊是水」）。題目說沒有湖，是為了定義清楚。
