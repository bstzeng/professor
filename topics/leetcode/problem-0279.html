LeetCode 279

Perfect Squares
完全平方數

Medium · 中等 數學 動態規劃 廣度優先搜尋

Problem

Given an integer n, return the least number of perfect square numbers that sum to n.

A perfect square is an integer that is the square of an integer; in other words, it is the product of some integer with itself. For example, 1, 4, 9, and 16 are perfect squares while 3 and 11 are not.

中文翻譯

給你一個整數 n，回傳和為 n 的完全平方數的最少個數。

完全平方數是某個整數的平方，例如 1、4、9、16；3 和 11 則不是。

範例

範例 1 輸入：n = 12 輸出：3 說明：12 = 4 + 4 + 4 範例 2 輸入：n = 13 輸出：2 說明：13 = 4 + 9

限制條件

  • 1 ≤ n ≤ 10⁴

LeetCode 原題

解題思路

【完全背包】 物品：1, 4, 9, 16, ...（每個可以用無限次） 目標：湊出 n，物品個數最少。 和第 322 題「零錢兌換」一模一樣。 dp[x] = min(dp[x - s] + 1) 對所有平方數 s <= x 【貪心不行】 12：先拿最大的 9，剩 3 = 1+1+1 -> 4 個 但 4 + 4 + 4 只要 3 個 ✘ 【BFS：最少步數】 從 n 出發，每一步減掉一個平方數， 第一次走到 0 的層數就是答案。 【數學：答案只可能是 1、2、3、4】 拉格朗日四平方定理：每個正整數都能寫成 4 個平方數的和。 勒讓德三平方定理：n 需要 4 個 <=> n = 4^a × (8b + 7)。 所以： n 是平方數 -> 1 n = 4^a(8b+7) -> 4 n = i² + j² 有解 -> 2 其他 -> 3
解法一

動態規劃（完全背包）

class Solution: def numSquares(self, n: int) -> int: squares = [i * i for i in range(1, math.isqrt(n) + 1)] dp = [0] + [n] * n # dp[x]：組成 x 最少要幾個平方數 for x in range(1, n + 1): for s in squares: if s > x: break dp[x] = min(dp[x], dp[x - s] + 1) # ★ 最後一個平方數是 s return dp[n]
複雜度說明
時間O(n√n)
空間O(n)
解法二

BFS

class Solution: def numSquares(self, n: int) -> int: squares = [i * i for i in range(1, math.isqrt(n) + 1)] level, frontier, seen = 0, {n}, {n} while frontier: level += 1 # 再用一個平方數 nxt = set() for x in frontier: for s in squares: if s > x: break if s == x: return level # ★ 剛好減到 0：BFS 第一次到達就是最少 if x - s not in seen: seen.add(x - s) nxt.add(x - s) frontier = nxt return level

每一層代表多用一個平方數。答案最多 4，所以最多 4 層；但每層節點可能很多，實際速度和 DP 差不多。

複雜度說明
時間O(n√n)
空間O(n)
解法三

數論（四平方定理 + 三平方定理）

class Solution: def numSquares(self, n: int) -> int: def is_square(x: int) -> bool: r = math.isqrt(x) return r * r == x if is_square(n): # 1 個 return 1 m = n while m % 4 == 0: # 去掉 4 的因數 m //= 4 if m % 8 == 7: # ★ 勒讓德三平方定理：4^a(8b+7) 需要 4 個 return 4 for i in range(1, math.isqrt(n) + 1): if is_square(n - i * i): # 2 個 return 2 return 3 # 其他都是 3 個
複雜度說明
時間O(√n)
空間O(1)

邊界條件檢查清單

  • n 本身是平方數 → 1。
  • n = 7 → 4 + 1 + 1 + 1 = 4 個（8b+7 型）。
  • n = 12 → 貪心會錯。
