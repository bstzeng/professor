LeetCode 440

K-th Smallest in Lexicographical Order
字典序的第 K 小數字

Hard · 困難 字典樹

Problem

Given two integers n and k, return the kth lexicographically smallest integer in the range [1, n].

中文翻譯

給你兩個整數 n 和 k，回傳 [1, n] 中字典序第 k 小的整數。

範例

範例 1 輸入：n = 13, k = 2 輸出：10 說明：字典序是 [1, 10, 11, 12, 13, 2, 3, 4, 5, 6, 7, 8, 9]。 範例 2 輸入：n = 1, k = 1 輸出：1

限制條件

  • 1 ≤ k ≤ n ≤ 10⁹

LeetCode 原題

解題思路

【第 386 題的進階版】 第 386 題把所有數依字典序列出來 —— n = 10⁹ 時不可能一個一個走。 【字典序 = 十叉樹的前序遍歷】 節點 x 的孩子是 x0, x1, ..., x9。 要找前序中的第 k 個節點。 【一次跳過整棵子樹】 在節點 cur： 算出 cur 這棵子樹有幾個節點（<= n 的）：size size <= k -> 答案不在這棵子樹，整棵跳過：k -= size，cur 換到右兄弟 cur + 1 size > k -> 答案在這棵子樹裡：往下走，k -= 1（cur 本身），cur = cur × 10 【子樹大小怎麼算？】 一層一層往下： 第 0 層：[cur, cur] 第 1 層：[cur×10, cur×10 + 9] 第 2 層：[cur×100, cur×100 + 99] 每層和 [1, n] 取交集的長度加起來。 【複雜度】 每次往下或往右，最多 O(10 × 位數) 步，每步算子樹大小 O(位數) -> O(log² n)。
解法

十叉樹上的跳躍

class Solution: def findKthNumber(self, n: int, k: int) -> int: def subtree_size(prefix: int) -> int: # 以 prefix 開頭、而且 <= n 的數有幾個（十叉樹中 prefix 這棵子樹的大小） size, lo, hi = 0, prefix, prefix while lo <= n: size += min(hi, n) - lo + 1 # 這一層：[lo, hi] 和 [1, n] 的交集 lo, hi = lo * 10, hi * 10 + 9 # 往下一層 return size cur = 1 k -= 1 # cur = 1 本身算第 1 個 while k: s = subtree_size(cur) if s <= k: # ★ 整棵子樹都在第 k 個之前：直接跳過 k -= s cur += 1 # 換到右邊的兄弟 else: # 答案在這棵子樹裡：往下走一層 k -= 1 cur *= 10 return cur
複雜度說明
時間O(log² n)
空間O(1)

邊界條件檢查清單

  • k = 1 → 1。
  • n = 10⁹ → 不能列舉，必須跳過子樹。
  • 子樹大小剛好等於 k → 跳過（第 k 個在後面）。
