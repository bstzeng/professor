Delete Node in a BST
刪除二元搜尋樹中的節點

Medium · 中等 樹 二元搜尋樹 二元樹

Problem

Given a root node reference of a BST and a key, delete the node with the given key in the BST. Return the root node reference (possibly updated) of the BST.

Basically, the deletion can be divided into two stages:

  1. Search for a node to remove.
  2. If the node is found, delete the node.

Follow up: Could you solve it with time complexity O(height of tree)?

中文翻譯

給你二元搜尋樹的根節點和一個 key，刪除值為 key 的節點，回傳（可能改變的）根節點。

分兩步：先找到節點，再刪除它。刪除後仍然必須是二元搜尋樹。

進階：能做到 O(樹高) 嗎？

範例

範例 1 輸入：root = [5,3,6,2,4,null,7], key = 3 輸出：[5,4,6,2,null,null,7]（[5,2,6,null,4,null,7] 也對） 範例 2 輸入：root = [5,3,6,2,4,null,7], key = 0 輸出：[5,3,6,2,4,null,7] 說明：樹中沒有 0。

限制條件

  • 節點數在 [0, 10⁴] 之間
  • −10⁵ ≤ Node.val ≤ 10⁵
  • 每個節點的值都不同

LeetCode 原題

解題思路

【找到節點：依 BST 性質往左或往右】 【刪除：三種情況】 1. 沒有孩子 -> 直接刪掉（回傳 None） 2. 只有一個孩子 -> 讓孩子頂替自己 3. 兩個孩子 -> 最麻煩： 找「中序後繼」：右子樹中最小的節點（一路往左走） 它比左子樹的全部大、比右子樹其他節點都小 -> 把它的值搬到目前位置，再從右子樹中刪掉它。 後繼一定沒有左孩子，所以刪它時是情況 1 或 2。 【遞迴寫法的好處】 每一層回傳「刪除後的子樹根」，父節點接上即可， 不需要另外記錄父節點。 【也可以用前驅】 左子樹的最大值，對稱的做法。
解法

遞迴 + 中序後繼取代

class Solution: def deleteNode(self, root: Optional[TreeNode], key: int) -> Optional[TreeNode]: if root is None: return None if key < root.val: root.left = self.deleteNode(root.left, key) elif key > root.val: root.right = self.deleteNode(root.right, key) else: # 找到要刪的節點 if root.left is None: # 只有右孩子（或沒有孩子） return root.right if root.right is None: # 只有左孩子 return root.left # ★ 兩個孩子：用右子樹的最小值（後繼）取代自己，再把後繼刪掉 succ = root.right while succ.left: succ = succ.left root.val = succ.val root.right = self.deleteNode(root.right, succ.val) return root

驗證方式：隨機建 BST、刪除任意值，檢查結果仍是 BST，而且中序遍歷剛好少了那個值。

複雜度說明
時間O(h)
空間O(h)遞迴深度

邊界條件檢查清單

  • key 不存在 → 樹不變。
  • 刪除根節點 → 回傳新的根。
  • 刪除葉子 → 直接移除。
