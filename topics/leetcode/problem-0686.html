LeetCode 686

Repeated String Match
重複疊加字串匹配

Medium · 中等 字串 字串匹配

Problem

Given two strings a and b, return the minimum number of times you should repeat string a so that string b is a substring of it. If it is impossible for b​​​​​​ to be a substring of a after repeating it, return -1.

Notice: string "abc" repeated 0 times is "", repeated 1 time is "abc" and repeated 2 times is "abcabc".

中文翻譯

給你兩個字串 a、b，回傳把 a 重複疊加的最少次數，使 b 成為疊加後字串的子字串；做不到則回傳 -1。

範例

範例 1 輸入：a = "abcd", b = "cdabcdab" 輸出：3 範例 2 輸入：a = "a", b = "aa" 輸出：2

限制條件

  • 1 ≤ a.length, b.length ≤ 10⁴
  • a and b 只含小寫英文字母

LeetCode 原題

解題思路

【下界】 長度至少要 >= |b| -> k >= ceil(|b| / |a|)。 【上界】 b 在疊加字串中的起點，一定可以落在第一份 a 之內（起點 < |a|）。 從那裡開始，長度 |b| 最多跨越 ceil(|b|/|a|) + 1 份 a。 所以只要檢查 k 和 k+1。 兩個都不行 -> 再多重複也沒用（只是重複同樣的模式）。 【子字串檢查】 Python 的 in 平均很快；最壞情況可用 KMP 或 Rabin-Karp 保證 O(|a| + |b|)。
解法

只檢查 k 與 k+1

class Solution: def repeatedStringMatch(self, a: str, b: str) -> int: k = -(-len(b) // len(a)) # 至少要重複 ceil(|b| / |a|) 次，長度才夠 for t in (k, k + 1): # ★ 最多再多一次（b 可能從 a 的中間開始） if b in a * t: return t return -1

驗證方式：和從 1 開始逐一嘗試的暴力法比對 3000 組。

複雜度說明
時間O(|a| + |b|)使用線性的字串匹配時
空間O(|a| + |b|)

邊界條件檢查清單

  • b 中有 a 沒有的字元 → −1。
  • b 從 a 中間開始 → 需要 k+1。
  • b 比 a 短 → k = 1 或 2。
