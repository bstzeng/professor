Arithmetic Slices II - Subsequence
等差數列劃分 II - 子序列

Hard · 困難 陣列 動態規劃

Problem

Given an integer array nums, return the number of all the arithmetic subsequences of nums.

A sequence of numbers is called arithmetic if it consists of at least three elements and if the difference between any two consecutive elements is the same.

A subsequence of an array is a sequence that can be formed by removing some elements (possibly none) of the array.

The test cases are generated so that the answer fits in 32-bit integer.

中文翻譯

給你一個整數陣列 nums，回傳其中等差子序列的個數（至少三個元素、相鄰差相同；子序列可以不連續）。

不同位置的元素組成的子序列視為不同（即使數值相同）。

範例

範例 1 輸入：nums = [2,4,6,8,10] 輸出：7 說明：[2,4,6] [4,6,8] [6,8,10] [2,4,6,8] [4,6,8,10] [2,4,6,8,10] [2,6,10] 範例 2 輸入：nums = [7,7,7,7,7] 輸出：16 說明：任選至少三個位置都可以：C(5,3)+C(5,4)+C(5,5) = 10+5+1 = 16。

限制條件

  • 1 ≤ nums.length ≤ 1000
  • −2³¹ ≤ nums[i] ≤ 2³¹ − 1

LeetCode 原題

解題思路

【子序列不連續 -> 需要知道「公差」】 dp[i][d] = 以 nums[i] 結尾、公差為 d 的子序列個數 【長度 >= 3 的限制怎麼處理？】 技巧：dp 記錄「長度 >= 2」的個數（稱為「弱等差子序列」）。 對每一對 j < i，d = nums[i] - nums[j]： 所有以 nums[j] 結尾、公差 d 的弱等差子序列（dp[j][d] 個）， 接上 nums[i] 之後長度 >= 3 -> 都是合格的，加進答案 dp[i][d] += dp[j][d] + 1 └ 新的長度 2：[nums[j], nums[i]] 【為什麼用雜湊表？】 公差的範圍可能到 2³²，不能開陣列； 每個 i 最多只有 i 種公差 -> 總狀態數 O(n²)。
解法

dp[i][公差] 的雜湊表 DP

class Solution: def numberOfArithmeticSlices(self, nums: List[int]) -> int: n = len(nums) # dp[i][d]：以 nums[i] 結尾、公差為 d、長度 >= 2 的子序列個數 dp = [collections.defaultdict(int) for _ in range(n)] total = 0 for i in range(n): for j in range(i): d = nums[i] - nums[j] cnt = dp[j][d] # 以 nums[j] 結尾、公差 d 的（長度 >= 2） total += cnt # ★ 接上 nums[i] 之後長度 >= 3：計入答案 dp[i][d] += cnt + 1 # +1 是新的長度 2 子序列 [nums[j], nums[i]] return total
複雜度說明
時間O(n²)
空間O(n²)

邊界條件檢查清單

  • 全部相同 → 公差 0，任選 ≥ 3 個位置。
  • 長度 < 3 → 0。
  • 差值很大 → Python 沒有溢位；其他語言要用 long 當鍵。
