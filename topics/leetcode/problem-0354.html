Russian Doll Envelopes
俄羅斯套娃信封問題

Hard · 困難 陣列 二分搜尋 動態規劃 排序

Problem

You are given a 2D array of integers envelopes where envelopes[i] = [wi, hi] represents the width and the height of an envelope.

One envelope can fit into another if and only if both the width and height of one envelope are greater than the other envelope's width and height.

Return the maximum number of envelopes you can Russian doll (i.e., put one inside the other).

Note: You cannot rotate an envelope.

中文翻譯

給你一個二維陣列 envelopes，envelopes[i] = [wi, hi] 是信封的寬和高。

一個信封能放進另一個信封，當且僅當它的寬和高都嚴格小於另一個。

回傳最多能有幾個信封像俄羅斯套娃一樣一層套一層。信封不能旋轉。

範例

範例 1 輸入：envelopes = [[5,4],[6,4],[6,7],[2,3]] 輸出：3 說明：[2,3] => [5,4] => [6,7] 範例 2 輸入：envelopes = [[1,1],[1,1],[1,1]] 輸出：1

限制條件

  • 1 ≤ envelopes.length ≤ 10⁵
  • envelopes[i].length == 2
  • 1 ≤ wi, hi ≤ 10⁵

LeetCode 原題

解題思路

【二維的最長遞增子序列】 如果只有一個維度，就是第 300 題 LIS。 兩個維度都要嚴格遞增 -> 先用排序處理掉一個維度。 【按寬度排序，對高度做 LIS】 寬度遞增之後，只要高度也嚴格遞增就能套 —— 但寬度「相同」的信封不能互套！ 【關鍵技巧：寬度相同時，高度遞減排】 [6, 4], [6, 7]：寬度相同 如果高度遞增排：4, 7 -> LIS 會把它們都選進去 ✘ 如果高度遞減排：7, 4 -> 遞減的兩個數不可能同時在遞增序列裡 ✔ 這樣同寬度的信封最多只會被選一個， 剩下的問題就是純粹的一維 LIS，可以用 O(n log n) 的二分解法。
排序後（寬遞增、同寬時高遞減）： [2,3] [5,4] [6,7] [6,4] 高度： 3 4 7 4 LIS：3, 4, 7 -> 長度 3 ✔ 若同寬時高度遞增排（[6,4] 在 [6,7] 前），高度 3, 4, 4, 7 可能把兩個寬 6 的都選進去 ✘
解法一

排序 + O(n²) DP

class Solution: def maxEnvelopes(self, envelopes: List[List[int]]) -> int: envelopes.sort() n = len(envelopes) dp = [1] * n # dp[i]：以第 i 個信封為最外層的最多層數 for i in range(n): for j in range(i): if envelopes[j][0] < envelopes[i][0] and envelopes[j][1] < envelopes[i][1]: dp[i] = max(dp[i], dp[j] + 1) return max(dp)

n = 10⁵ 時會超時。

複雜度說明
時間O(n²)
空間O(n)
解法二

特殊排序 + 二分 LIS

class Solution: def maxEnvelopes(self, envelopes: List[List[int]]) -> int: # ★ 寬度遞增；寬度相同時高度「遞減」—— 讓同寬度的信封不可能互相套 envelopes.sort(key=lambda e: (e[0], -e[1])) tails = [] # 對高度做 LIS（第 300 題） for _, h in envelopes: i = bisect.bisect_left(tails, h) if i == len(tails): tails.append(h) else: tails[i] = h return len(tails)
複雜度說明
時間O(n log n)
空間O(n)

解法對照

解法時間空間
一、DPO(n²)O(n)
二、排序 + LISO(n log n)O(n) ✔

邊界條件檢查清單

  • 寬度相同 → 不能互套；排序技巧處理。
  • 高度相同 → 不能互套；LIS 用 bisect_left（嚴格遞增）處理。
  • 完全相同的信封 → 只能選一個。
