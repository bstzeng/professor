LeetCode 547

Number of Provinces
省份數量

Medium · 中等 深度優先搜尋 廣度優先搜尋 聯合查找 圖

Problem

There are n cities. Some of them are connected, while some are not. If city a is connected directly with city b, and city b is connected directly with city c, then city a is connected indirectly with city c.

A province is a group of directly or indirectly connected cities and no other cities outside of the group.

You are given an n x n matrix isConnected where isConnected[i][j] = 1 if the ith city and the jth city are directly connected, and isConnected[i][j] = 0 otherwise.

Return the total number of provinces.

中文翻譯

有 n 個城市。isConnected[i][j] = 1 表示城市 i 和 j 直接相連。相連具有傳遞性：a 連 b、b 連 c，則 a 和 c 間接相連。

省份是一組直接或間接相連的城市，組外沒有城市與它們相連。回傳省份的數量。

範例

範例 1 輸入：isConnected = [[1,1,0],[1,1,0],[0,0,1]] 輸出：2 範例 2 輸入：isConnected = [[1,0,0],[0,1,0],[0,0,1]] 輸出：3

限制條件

  • 1 ≤ n ≤ 200
  • n == isConnected.length
  • n == isConnected[i].length
  • isConnected[i][j] is 1 or 0.
  • isConnected[i][i] == 1
  • isConnected[i][j] == isConnected[j][i]

LeetCode 原題

解題思路

【就是數連通分量】 鄰接矩陣表示的無向圖，求連通分量數。 【DFS】 對每個還沒拜訪的城市，從它出發 DFS 標記整個分量，計數加一。 【聯合查找（Union-Find）】 一開始 n 個分量。 每條邊 (i, j)：若 i、j 不在同一個集合就合併，分量數減一。 路徑壓縮讓 find 接近 O(1)。
解法

聯合查找

class Solution: def findCircleNum(self, isConnected: List[List[int]]) -> int: n = len(isConnected) parent = list(range(n)) def find(x): while parent[x] != x: parent[x] = parent[parent[x]] # 路徑壓縮（隔代指向） x = parent[x] return x count = n for i in range(n): for j in range(i + 1, n): if isConnected[i][j]: a, b = find(i), find(j) if a != b: parent[a] = b count -= 1 # ★ 每次成功合併，連通分量少一個 return count
複雜度說明
時間O(n² α(n))
空間O(n)

邊界條件檢查清單

  • 沒有任何邊 → n。
  • 全部相連 → 1。
  • 矩陣是對稱的 → 只看上三角即可。

常見追問

聯合查找的兩個最佳化

路徑壓縮（find 時把節點直接接到根附近）和按秩合併（矮的樹接到高的下面）。兩者一起用，均攤複雜度是反阿克曼函數 α(n)，實務上視為常數。
