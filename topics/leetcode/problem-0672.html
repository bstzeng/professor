Bulb Switcher II
燈泡開關 II

Medium · 中等 位元運算 深度優先搜尋 廣度優先搜尋 數學

Problem

There is a room with n bulbs labeled from 1 to n that all are turned on initially, and four buttons on the wall. Each of the four buttons has a different functionality where:

  • Button 1: Flips the status of all the bulbs.
  • Button 2: Flips the status of all the bulbs with even labels (i.e., 2, 4, ...).
  • Button 3: Flips the status of all the bulbs with odd labels (i.e., 1, 3, ...).
  • Button 4: Flips the status of all the bulbs with a label j = 3k + 1 where k = 0, 1, 2, ... (i.e., 1, 4, 7, 10, ...).

You must make exactly presses button presses in total. For each press, you may pick any of the four buttons to press.

Given the two integers n and presses, return the number of different possible statuses after performing all presses button presses.

中文翻譯

房間裡有 n 盞燈（編號 1～n），一開始全亮。有四個按鈕：

  1. 翻轉所有燈。
  2. 翻轉編號為偶數的燈。
  3. 翻轉編號為奇數的燈。
  4. 翻轉編號為 3k + 1 的燈（1, 4, 7, …）。

恰好按 presses 次按鈕（每次任選一個）後，回傳燈的狀態可能有幾種不同情形。

範例

範例 1 輸入：n = 1, presses = 1 輸出：2 範例 2 輸入：n = 2, presses = 1 輸出：3 範例 3 輸入：n = 3, presses = 1 輸出：4

限制條件

  • 1 ≤ n ≤ 1000
  • 0 ≤ presses ≤ 1000

LeetCode 原題

解題思路

【每個按鈕只在乎按了奇數次還是偶數次】 翻兩次等於沒翻。所以只有 2⁴ = 16 種組合。 組合的按鈕數 k 要滿足 k <= presses 且 (presses - k) 是偶數 （多出來的次數可以兩兩抵消）。 【燈的狀態有週期】 四個按鈕的週期是 1、2、2、3 -> 整體週期 6。 再細看：燈 4 = 燈 1 ⊕ 燈 2 ⊕ 燈 3（可以驗證）， 燈 5、6 也能由前 3 盞推出 -> 只看前 min(n, 3) 盞就夠了。 【結果只有幾種】 n=1：presses>=1 時 2 種 n=2：presses=1 時 3 種，>=2 時 4 種 n>=3：presses=1：4 種；presses=2：7 種；>=3：8 種
解法

分析後列表

class Solution: def flipLights(self, n: int, presses: int) -> int: n = min(n, 3) # ★ 燈的狀態以 6 為週期，而且前 3 盞就能決定全部 if presses == 0: return 1 if presses == 1: return [2, 3, 4][n - 1] if presses == 2: return [2, 4, 7][n - 1] return [2, 4, 8][n - 1]

驗證方式：n ≤ 12、presses ≤ 6 的所有組合，和「枚舉 16 種奇偶組合實際模擬」比對。

複雜度說明
時間O(1)
空間O(1)

邊界條件檢查清單

  • presses = 0 → 1。
  • n = 1 → 最多 2 種。
  • presses = 2、n ≥ 3 → 7（缺了某一種需要三個按鈕才能做到的狀態）。

常見追問

如果不想背表？

直接用暴力法：枚舉 16 種奇偶組合，模擬前 min(n, 6) 盞燈的狀態，用集合去重。仍然是 O(1)，而且不容易出錯。
