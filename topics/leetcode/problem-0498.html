Diagonal Traverse
對角線遍歷

Medium · 中等 陣列 矩陣 模擬

Problem

Given an m x n matrix mat, return an array of all the elements of the array in a diagonal order.

中文翻譯

給你一個 m x n 的矩陣，依照對角線來回的順序回傳所有元素：第一條往右上、第二條往左下、第三條往右上……

範例

範例 1 輸入：mat = [[1,2,3],[4,5,6],[7,8,9]] 輸出：[1,2,4,7,5,3,6,8,9] 說明：對角線依序是 [1]、[2,4]（往左下）、[7,5,3]（往右上）、[6,8]、[9]。 範例 2 輸入：mat = [[1,2],[3,4]] 輸出：[1,2,3,4]

限制條件

  • 1 ≤ m, n ≤ 10⁴
  • 1 ≤ m × n ≤ 10⁴

LeetCode 原題

解題思路

【同一條對角線：i + j 相同】 d = i + j，從 0 到 m + n - 2。 【每條對角線上 i 的範圍】 j = d - i 必須在 [0, n-1]：i >= d - n + 1 i 本身在 [0, m-1] -> i 從 max(0, d-n+1) 到 min(d, m-1) 【方向交替】 d 偶數：往右上走 -> i 由大到小 d 奇數：往左下走 -> i 由小到大 不需要模擬「撞到邊界要轉彎」的複雜規則。
解法

依對角線編號 i + j 分組

class Solution: def findDiagonalOrder(self, mat: List[List[int]]) -> List[int]: m, n = len(mat), len(mat[0]) res = [] for d in range(m + n - 1): # ★ 同一條對角線上 i + j = d # 這條對角線上 i 的範圍 lo, hi = max(0, d - n + 1), min(d, m - 1) rows = range(hi, lo - 1, -1) if d % 2 == 0 else range(lo, hi + 1) # d 偶數：往右上走（i 由大到小）；d 奇數：往左下走（i 由小到大） for i in rows: res.append(mat[i][d - i]) return res
複雜度說明
時間O(mn)
空間O(1)不計輸出

邊界條件檢查清單

  • 只有一列或一欄 → 每條對角線只有一個元素。
  • 長方形 → i 的範圍要同時考慮 m 和 n。
