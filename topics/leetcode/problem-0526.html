Beautiful Arrangement
優美的排列

Medium · 中等 位元運算 陣列 動態規劃 回溯

Problem

Suppose you have n integers labeled 1 through n. A permutation of those n integers perm (1-indexed) is considered a beautiful arrangement if for every i (1 <= i <= n), either of the following is true:

  • perm[i] is divisible by i.
  • i is divisible by perm[i].

Given an integer n, return the number of the beautiful arrangements that you can construct.

中文翻譯

把 1 到 n 排成一個排列 perm（索引從 1 開始）。如果對每個位置 i 都滿足以下其中一個條件，就稱它為優美的排列：

  • perm[i] 能被 i 整除
  • i 能被 perm[i] 整除

給你 n，回傳優美排列的數量。

範例

範例 1 輸入：n = 2 輸出：2 範例 2 輸入：n = 1 輸出：1

限制條件

  • 1 ≤ n ≤ 15

LeetCode 原題

解題思路

【回溯：一個位置一個位置填】 填第 i 個位置時，試所有還沒用過、且和 i 互相整除的數。 整除條件很嚴格，剪枝效果很好。 【狀態壓縮 + 記憶化】 「已經用了哪些數」用一個 n 位元的遮罩 mask 表示。 已用的數的個數 = popcount(mask) -> 就知道現在填第幾個位置。 所以 dfs(mask) 的結果只跟 mask 有關 -> 可以記憶化。 狀態數 2ⁿ，每個狀態試 n 個數 -> O(n · 2ⁿ)。
解法

位元遮罩 DP（記憶化回溯）

class Solution: def countArrangement(self, n: int) -> int: @cache def dfs(mask): i = bin(mask).count("1") + 1 # 已經放了幾個數 -> 現在要填第 i 個位置 if i > n: return 1 total = 0 for x in range(1, n + 1): # ★ x 還沒用過，而且和位置 i 互相整除 if not mask >> (x - 1) & 1 and (x % i == 0 or i % x == 0): total += dfs(mask | 1 << (x - 1)) return total return dfs(0)

驗證方式：n ≤ 8 時和枚舉所有排列比對；n = 15 的答案是 24679。

複雜度說明
時間O(n · 2ⁿ)
空間O(2ⁿ)

邊界條件檢查清單

  • n = 1 → 1。
  • 1 可以放任何位置、任何數可以放在位置 1。

常見追問

從後往前填更快

從位置 n 往 1 填：大位置的候選數很少，越早剪枝。位置 1 最後填，因為任何數都能放。
