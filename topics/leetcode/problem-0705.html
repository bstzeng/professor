LeetCode 705

Design HashSet
設計雜湊集合

Easy · 簡單 設計 陣列 雜湊表 鏈結串列

Problem

Design a HashSet without using any built-in hash table libraries.

Implement MyHashSet class:

  • void add(key) Inserts the value key into the HashSet.
  • bool contains(key) Returns whether the value key exists in the HashSet or not.
  • void remove(key) Removes the value key in the HashSet. If key does not exist in the HashSet, do nothing.

中文翻譯

不使用任何內建的雜湊表函式庫，設計一個雜湊集合，支援 add(key)、remove(key)、contains(key)。鍵的範圍是 [0, 10⁶]。

範例

範例 輸入 ["MyHashSet", "add", "add", "contains", "contains", "add", "contains", "remove", "contains"] [[], [1], [2], [1], [3], [2], [2], [2], [2]] 輸出 [null, null, null, true, false, null, true, null, false]

限制條件

  • 0 ≤ key ≤ 10⁶
  • 最多呼叫 10⁴ 次（add, remove, and contains）

LeetCode 原題

解題思路

【最簡單：布林陣列】 鍵範圍只有 10⁶ -> 開 10⁶+1 的陣列，O(1) 但浪費空間。 【真正的雜湊表】 1. 雜湊函數：key % 桶數，決定放在哪個桶。 2. 碰撞處理：不同的鍵可能落在同一個桶， 鏈結法 —— 每個桶是一個串列。 3. 桶數選質數：讓餘數分布更均勻。 【效能】 鍵數 / 桶數 = 負載因子 α，每個操作平均 O(1 + α)。 實際的雜湊表會在 α 太大時擴容（重新雜湊）。
解法

鏈結法雜湊表

class MyHashSet: def __init__(self): self.size = 1009 # 質數個桶，讓餘數分布比較均勻 self.buckets = [[] for _ in range(self.size)] def _bucket(self, key): return self.buckets[key % self.size] # ★ 雜湊函數：取餘數決定放哪個桶 def add(self, key: int) -> None: b = self._bucket(key) if key not in b: b.append(key) # 碰撞：同一個桶裡用串列存放（鏈結法） def remove(self, key: int) -> None: b = self._bucket(key) if key in b: b.remove(key) def contains(self, key: int) -> bool: return key in self._bucket(key)

驗證方式：和內建 set 對照執行兩萬次隨機操作。

複雜度說明
時間平均 O(1 + α)
空間O(桶數 + 鍵數)

邊界條件檢查清單

  • 重複 add → 不重複放。
  • remove 不存在的鍵 → 不做事。

常見追問

另一種碰撞處理：開放定址

所有鍵都放在同一個陣列裡，碰撞時往後找下一個空位（線性探測）。Python 的 dict 就是開放定址（用擾動過的探測序列）。刪除時要留「墓碑」標記，否則會切斷探測鏈。
