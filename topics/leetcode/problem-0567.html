Permutation in String
字串的排列

Medium · 中等 雜湊表 雙指標 字串 滑動視窗

Problem

Given two strings s1 and s2, return true if s2 contains a permutation of s1, or false otherwise.

In other words, return true if one of s1's permutations is the substring of s2.

中文翻譯

給你兩個字串 s1、s2，判斷 s2 是否包含 s1 的某個排列作為子字串。

範例

範例 1 輸入：s1 = "ab", s2 = "eidbaooo" 輸出：true 範例 2 輸入：s1 = "ab", s2 = "eidboaoo" 輸出：false

限制條件

  • 1 ≤ s1.length, s2.length ≤ 10⁴
  • s1 and s2 只含小寫英文字母

LeetCode 原題

解題思路

【排列 <=> 字元計數相同】 要找 s2 中長度為 len(s1)、字元計數和 s1 相同的子字串。 【固定長度的滑動視窗】 視窗每次右移一格：加入新進來的字元、移除離開的字元。 每次比較兩個計數表（26 個字母，O(1)）。 【更細的最佳化】 維護「有幾個字母的計數已經相等」diff， 每次只更新進出的兩個字母，比較變成 O(1) 的整數檢查。
解法

固定長度滑動視窗 + 計數

class Solution: def checkInclusion(self, s1: str, s2: str) -> bool: k = len(s1) if k > len(s2): return False need = Counter(s1) win = Counter(s2[:k]) if win == need: return True for i in range(k, len(s2)): # ★ 固定長度 k 的視窗往右滑 win[s2[i]] += 1 win[s2[i - k]] -= 1 if win[s2[i - k]] == 0: del win[s2[i - k]] # 刪掉計數為 0 的鍵，Counter 才能直接比較 if win == need: return True return False
複雜度說明
時間O(n · 26)
空間O(26)

邊界條件檢查清單

  • s1 比 s2 長 → False。
  • 計數為 0 的鍵 → Counter 比較時要刪掉（或改用長度 26 的陣列）。
