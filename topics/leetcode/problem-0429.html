N-ary Tree Level Order Traversal
N 叉樹的層序遍歷

Medium · 中等 樹 廣度優先搜尋

Problem

Given an n-ary tree, return the level order traversal of its nodes' values.

Nary-Tree input serialization is represented in their level order traversal, each group of children is separated by the null value.

中文翻譯

給你一棵 N 元樹（每個節點可以有任意多個孩子），回傳它的層序遍歷結果：每一層的節點值放在一個串列裡。

範例

範例 1 輸入：root = [1,null,3,2,4,null,5,6] 1 / | \ 3 2 4 / \ 5 6 輸出：[[1],[3,2,4],[5,6]]

限制條件

  • 樹的高度不超過 1000
  • 節點總數在 [0, 10⁴] 之間

LeetCode 原題

解題思路

【和二元樹的層序遍歷（第 102 題）一樣】 只是「左孩子、右孩子」換成「children 串列」。 【一層一層處理】 level = 目前這一層的所有節點 記下它們的值， 下一層 = 所有節點的 children 依序接起來。 重複直到沒有節點。 這種寫法不需要記錄每層的大小，比「一個佇列 + 計數」更直觀。
解法

逐層展開

""" class Node: def __init__(self, val=None, children=None): self.val = val self.children = children """ class Solution: def levelOrder(self, root: 'Node') -> List[List[int]]: if root is None: return [] res, level = [], [root] while level: res.append([node.val for node in level]) # ★ 下一層 = 這一層所有節點的孩子，依序串起來 level = [child for node in level for child in node.children] return res
複雜度說明
時間O(n)
空間O(w)w = 最寬一層

邊界條件檢查清單

  • 空樹 → []。
  • 只有根 → [[val]]。
  • 葉子的 children → 空串列（不是 None，但寫法也要能處理）。
