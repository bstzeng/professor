LeetCode 630

Course Schedule III
課程表 III

Hard · 困難 貪心 陣列 排序 堆積（優先佇列）

Problem

There are n different online courses numbered from 1 to n. You are given an array courses where courses[i] = [durationi, lastDayi] indicate that the ith course should be taken continuously for durationi days and must be finished before or on lastDayi.

You will start on the 1st day and you cannot take two or more courses simultaneously.

Return the maximum number of courses that you can take.

中文翻譯

有 n 門課，courses[i] = [duration, lastDay]：這門課要連續上 duration 天，而且必須在第 lastDay 天（含）之前上完。

從第 1 天開始，一次只能上一門課。回傳最多能修完幾門課。

範例

範例 1 輸入：courses = [[100,200],[200,1300],[1000,1250],[2000,3200]] 輸出：3 範例 2 輸入：courses = [[1,2]] 輸出：1 範例 3 輸入：courses = [[3,2],[4,3]] 輸出：0

限制條件

  • 1 ≤ courses.length ≤ 10⁴
  • 1 ≤ durationi, lastDayi ≤ 10⁴

LeetCode 原題

解題思路

【選定一組課之後，怎麼排？】 依截止日由早到晚上（交換論證：截止日早的先上不會更差）。 所以先依 lastDay 排序，依序決定要不要選。 【貪心 + 反悔】 依序把每門課加進來，累計時間 t。 若 t 超過這門課的截止日： 必須丟掉一門課。丟哪一門？丟「時長最長」的！ - 課程數不變（加一門、丟一門） - 總時間減最多 -> 對之後的課最有利 用最大堆積隨時取出最長的課。 【為什麼丟掉之後一定合法？】 丟掉的課時長 >= 剛加入的這門， 總時間不會超過「加入前」的 t，而之前是合法的。
解法

依截止日排序 + 最大堆積反悔

class Solution: def scheduleCourse(self, courses: List[List[int]]) -> int: courses.sort(key=lambda c: c[1]) # 依截止日排序 heap, t = [], 0 # heap：已選課程的時長（最大堆積）；t：目前總時間 for dur, last in courses: heapq.heappush(heap, -dur) t += dur if t > last: t += heapq.heappop(heap) # ★ 超時：丟掉已選課程中最長的那一門 return len(heap)

驗證方式：和枚舉所有子集（依截止日排序檢查可行性）的暴力法比對 1000 組。

複雜度說明
時間O(n log n)
空間O(n)

邊界條件檢查清單

  • 時長超過截止日的課 → 加入後馬上被自己丟掉。
  • 截止日相同 → 排序穩定性不影響結果。
