LeetCode 242

Valid Anagram
有效的字母異位詞

Easy · 簡單 雜湊表 字串 排序

Problem

Given two strings s and t, return true if t is an anagram of s, and false otherwise.

An anagram is a word or phrase formed by rearranging the letters of a different word or phrase, using all the original letters exactly once.

Follow up: What if the inputs contain Unicode characters? How would you adapt your solution to such a case?

中文翻譯

給你兩個字串 s 和 t，判斷 t 是不是 s 的字母異位詞。

字母異位詞：把一個字串的字母重新排列得到的字串，每個字母恰好用一次。

進階：如果輸入包含 Unicode 字元，要怎麼調整？

範例

範例 1 輸入：s = "anagram", t = "nagaram" 輸出：true 範例 2 輸入：s = "rat", t = "car" 輸出：false

限制條件

  • 1 ≤ s.length, t.length ≤ 5 × 10⁴
  • s 和 t 只包含小寫英文字母

LeetCode 原題

解題思路

【異位詞 = 每個字母出現的次數完全相同】 順序無關，只看「字母組成」。 【方法一：排序】 兩個字串排序後相同 <=> 互為異位詞。 【方法二：計數】 只有 26 個小寫字母 -> 長度 26 的陣列。 s 的字母 +1、t 的字母 -1， 最後全部為 0 就代表組成相同。 【先比長度】 長度不同一定不是，直接回傳 false。 【Unicode 進階】 字元種類太多，不能用固定長度的陣列 -> 改用雜湊表（Counter / dict）。 另外要注意：有些字元可以用不同的碼位序列表示 （例如 é 可以是一個字元，也可以是 e + 組合重音）， 嚴謹的比較要先做 Unicode 正規化（unicodedata.normalize）。
解法一

排序比較

class Solution: def isAnagram(self, s: str, t: str) -> bool: return sorted(s) == sorted(t)
複雜度說明
時間O(n log n)
空間O(n)sorted 產生新串列
解法二

26 格計數陣列

class Solution: def isAnagram(self, s: str, t: str) -> bool: if len(s) != len(t): return False cnt = [0] * 26 for a, b in zip(s, t): # s 的字母 +1，t 的字母 -1 cnt[ord(a) - 97] += 1 cnt[ord(b) - 97] -= 1 return all(c == 0 for c in cnt) # ★ 全部抵銷 = 字母組成相同
複雜度說明
時間O(n)
空間O(1)固定 26 格
解法三

雜湊計數（Counter）

class Solution: def isAnagram(self, s: str, t: str) -> bool: return collections.Counter(s) == collections.Counter(t) # 也適用於 Unicode
複雜度說明
時間O(n)
空間O(k)k = 字元種類，適用 Unicode

解法對照

解法時間空間備註
一、排序O(n log n)O(n)最簡單
二、26 格陣列O(n)O(1)只限小寫字母 ✔
三、CounterO(n)O(k)Unicode 也適用

邊界條件檢查清單

  • 長度不同 → 直接 false。
  • 相同的字串 → true（自己是自己的異位詞）。
  • 重複字母（"aab" vs "abb"）→ 次數不同，false。
