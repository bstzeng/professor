Relative Ranks
相對名次

Easy · 簡單 陣列 排序 堆積（優先佇列）

Problem

You are given an integer array score of size n, where score[i] is the score of the ith athlete in a competition. All the scores are guaranteed to be unique.

The athletes are placed based on their scores, where the 1st place athlete has the highest score, the 2nd place athlete has the 2nd highest score, and so on. The placement of each athlete determines their rank:

  • The 1st place athlete's rank is "Gold Medal".
  • The 2nd place athlete's rank is "Silver Medal".
  • The 3rd place athlete's rank is "Bronze Medal".
  • For the 4th place to the nth place athlete, their rank is their placement number (i.e., the xth place athlete's rank is "x").

Return an array answer of size n where answer[i] is the rank of the ith athlete.

中文翻譯

給你 n 位選手的分數 score（互不相同）。依分數由高到低排名：第 1 名是 "Gold Medal"、第 2 名 "Silver Medal"、第 3 名 "Bronze Medal"，第 4 名以後就是名次數字字串。

回傳每位選手（依原本順序）的名次。

範例

範例 1 輸入：score = [5,4,3,2,1] 輸出：["Gold Medal","Silver Medal","Bronze Medal","4","5"] 範例 2 輸入：score = [10,3,8,9,4] 輸出：["Gold Medal","5","Bronze Medal","Silver Medal","4"]

限制條件

  • n == score.length
  • 1 ≤ n ≤ 10⁴
  • 0 ≤ score[i] ≤ 10⁶
  • score 中的元素互不相同

LeetCode 原題

解題思路

【排序索引】 要依分數排序，但答案要放回原本的位置 -> 排序的對象是「索引」，用分數當排序鍵： order = sorted(range(n), key=lambda i: -score[i]) order[0] 是第一名的索引，order[1] 是第二名…… res[order[r]] = 第 r+1 名的字串。 「排序索引」（argsort）是很常用的技巧。
解法

排序索引（argsort）

class Solution: def findRelativeRanks(self, score: List[int]) -> List[str]: order = sorted(range(len(score)), key=lambda i: -score[i]) # 依分數由高到低排索引 medals = ["Gold Medal", "Silver Medal", "Bronze Medal"] res = [""] * len(score) for rank, i in enumerate(order): res[i] = medals[rank] if rank < 3 else str(rank + 1) # ★ 答案寫回原本的位置 return res
複雜度說明
時間O(n log n)
空間O(n)

邊界條件檢查清單

  • 只有 1～3 人 → 只有獎牌。
  • 名次從 1 開始 → 第 4 名寫 "4"，不是 "3"。

常見追問

分數範圍很小時

若分數上限 M 不大，可用計數陣列（桶）代替排序：O(n + M)。
