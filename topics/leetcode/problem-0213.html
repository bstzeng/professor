LeetCode 213

House Robber II
打家劫舍 II

Medium · 中等 陣列 動態規劃

Problem

A thief plans to rob houses arranged in a circle, so the first house is adjacent to the last one. Each house i holds nums[i] money. Robbing two adjacent houses on the same night triggers the alarm.

Return the maximum amount of money that can be stolen without triggering the alarm.

中文翻譯

小偷要搶一排圍成一圈的房子，所以第一間和最後一間是相鄰的。第 i 間房子裡有 nums[i] 元。同一晚搶了兩間相鄰的房子就會觸發警報。

請回傳在不觸發警報的情況下，最多能搶到多少錢。

範例

範例 1 輸入：nums = [2,3,2] 輸出：3 說明：第 0 間和第 2 間相鄰，不能都搶，所以只搶中間的 3。 範例 2 輸入：nums = [1,2,3,1] 輸出：4 說明：搶第 0 間（1）和第 2 間（3）。 範例 3 輸入：nums = [1,2,3] 輸出：3

限制條件

  • 1 ≤ nums.length ≤ 100
  • 0 ≤ nums[i] ≤ 1000

LeetCode 原題

解題思路

【和第 198 題的差別只有一個】：頭尾相鄰。 【把「環」拆成兩條「線」】 最佳解一定不會同時搶第 0 間和第 n-1 間，所以它屬於： 情況一：不搶最後一間 -> nums[0 .. n-2] 是一條線 情況二：不搶第一間 -> nums[1 .. n-1] 是一條線 兩種情況各用第 198 題的方法求最大值，答案取較大者 ✔ 【為什麼兩種情況重疊沒關係？】 「兩間都不搶」的方案同時屬於兩種情況 —— 我們取的是最大值，重複算不影響正確性。 【唯一的特例：n = 1】 nums[:-1] 和 nums[1:] 都是空的，會回傳 0 ✘ 但只有一間房子時，它雖然「和自己相鄰」，當然可以搶。
解法一

拆成兩次直線 DP（滾動變數）

class Solution: def rob(self, nums: List[int]) -> int: def rob_line(a: List[int]) -> int: # 第 198 題：排成一直線 take = skip = 0 # 搶/不搶 目前這間 的最大金額 for x in a: take, skip = skip + x, max(take, skip) return max(take, skip) if len(nums) == 1: return nums[0] # ★ 只有一間，頭尾是同一間 # ★ 頭尾不能同時搶 -> 拆成「不含最後一間」和「不含第一間」 return max(rob_line(nums[:-1]), rob_line(nums[1:]))
【rob_line 的狀態】 take：搶了目前這間的最大金額 skip：沒搶目前這間的最大金額 下一間 x： 新 take = 舊 skip + x （上一間不能搶） 新 skip = max(舊 take, 舊 skip)
複雜度說明
時間O(n)兩次線性掃描
空間O(n)切片複製；改用索引可降為 O(1)
解法二

DP 陣列版（用索引區間）

class Solution: def rob(self, nums: List[int]) -> int: n = len(nums) if n == 1: return nums[0] def best(lo: int, hi: int) -> int: # nums[lo..hi] 排成直線 dp = [0] * (hi - lo + 2) # dp[i]：前 i 間的最大金額 for i in range(lo, hi + 1): k = i - lo + 1 dp[k] = max(dp[k - 1], (dp[k - 2] if k >= 2 else 0) + nums[i]) return dp[-1] return max(best(0, n - 2), best(1, n - 1))

用索引區間代替切片，比較接近其他語言的寫法。dp[k] 表示「只看區間內前 k 間」的最大金額。

複雜度說明
時間O(n)
空間O(n)dp 陣列

解法對照

解法時間空間備註
一、兩次直線（滾動）O(n)O(n) / O(1)簡潔 ✔
二、DP 陣列O(n)O(n)狀態比較直觀

邊界條件檢查清單

  • 只有一間 → 直接回傳 nums[0]（最常漏掉的特例）。
  • 兩間 → 只能搶一間，取較大者。
  • 三間 → 任兩間都相鄰，只能搶一間。
  • 全部是 0 → 回傳 0。

常見追問

追問：房子排成一棵樹呢？

這是第 337 題。對每個節點回傳 (搶它的最大值, 不搶它的最大值)： 搶它 = 它的錢 + 左子不搶 + 右子不搶 不搶它 = max(左子兩種) + max(右子兩種) 後序遍歷一次，O(n)。
