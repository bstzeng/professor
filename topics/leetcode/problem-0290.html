LeetCode 290

Word Pattern
單字規律

Easy · 簡單 雜湊表 字串

Problem

Given a pattern and a string s, find if s follows the same pattern.

Here follow means a full match, such that there is a bijection between a letter in pattern and a non-empty word in s. Specifically:

  • Each letter in pattern maps to exactly one unique word in s.
  • Each unique word in s maps to exactly one letter in pattern.
  • No two letters map to the same word, and no two words map to the same letter.

中文翻譯

給你一個規律 pattern 和字串 s，判斷 s 是否遵循相同的規律。

「遵循」是指 pattern 的字母和 s 的單字之間存在雙射（一對一對應）：

  • 每個字母只對應一個單字。
  • 每個單字只對應一個字母。
  • 不同的字母不能對應到同一個單字，反之亦然。

範例

範例 1 輸入：pattern = "abba", s = "dog cat cat dog" 輸出：true 範例 2 輸入：pattern = "abba", s = "dog cat cat fish" 輸出：false 範例 3 輸入：pattern = "aaaa", s = "dog cat cat dog" 輸出：false

限制條件

  • 1 ≤ pattern.length ≤ 300
  • pattern 只包含小寫英文字母
  • 1 ≤ s.length ≤ 3000
  • s 只包含小寫英文字母和空白
  • s 沒有前導或結尾空白，單字之間恰好一個空白

LeetCode 原題

解題思路

【和第 205 題「同構字串」一模一樣】 只是右邊從「字元」換成了「單字」。 【為什麼要兩個方向？】 只檢查 字母 -> 單字： "ab" 對 "dog dog"：a->dog, b->dog，每個字母都只對應一個單字 ✔ 但兩個字母對到同一個單字，不是雙射 ✘ 所以還要檢查 單字 -> 字母。 【長度不同】 pattern 的長度和單字數不同 -> 直接 false。 （zip 會默默截斷，一定要先檢查！） 【其他寫法】 - 「第一次出現的位置」序列相同 <=> 結構相同 - 集合大小：字母種類 = 單字種類 = (字母, 單字) 配對種類 <=> 雙射
解法一

兩個雜湊表

class Solution: def wordPattern(self, pattern: str, s: str) -> bool: words = s.split() if len(words) != len(pattern): return False p2w, w2p = {}, {} # ★ 兩個方向都要一對一 for ch, w in zip(pattern, words): if p2w.setdefault(ch, w) != w or w2p.setdefault(w, ch) != ch: return False return True

setdefault(k, v)：k 不存在時設成 v 並回傳 v；存在時回傳原本的值。一行同時完成「查」和「設」。

複雜度說明
時間O(n + |s|)
空間O(n)
解法二

第一次出現的位置

class Solution: def wordPattern(self, pattern: str, s: str) -> bool: words = s.split() if len(words) != len(pattern): return False # 兩個序列「第一次出現的位置」逐項相同 <=> 結構相同 return [pattern.index(c) for c in pattern] == [words.index(w) for w in words]

index 是 O(n)，整體 O(n²)。n ≤ 300 可以接受，寫法最短。

複雜度說明
時間O(n²)
空間O(n)
解法三

集合大小

class Solution: def wordPattern(self, pattern: str, s: str) -> bool: words = s.split() # 雙射 <=> 字母種類數 = 單字種類數 = 配對種類數 return len(words) == len(pattern) and \ len(set(pattern)) == len(set(words)) == len(set(zip(pattern, words)))
【為什麼三個大小相等 <=> 雙射？】 配對數 >= 字母種類數，等號成立 <=> 每個字母只和一種單字配對。 配對數 >= 單字種類數，等號成立 <=> 每個單字只和一種字母配對。 兩個都成立 -> 雙射 ✔
複雜度說明
時間O(n + |s|)
空間O(n)

解法對照

解法時間備註
一、兩個雜湊表O(n)最標準 ✔
二、第一次出現位置O(n²)最短
三、集合大小O(n)巧妙

邊界條件檢查清單

  • 長度不同 → false；zip 會截斷，一定要先檢查。
  • 不同字母對到同一個單字（"ab", "x x"）→ false。
  • 同一個字母對到不同單字 → false。
