Longest Univalue Path
最長同值路徑

Medium · 中等 樹 深度優先搜尋 二元樹

Problem

Given the root of a binary tree, return the length of the longest path, where each node in the path has the same value. This path may or may not pass through the root.

The length of the path between two nodes is represented by the number of edges between them.

中文翻譯

給你二元樹的根節點，回傳最長路徑的邊數，這條路徑上所有節點的值都相同。路徑不一定經過根。

範例

範例 1 輸入：root = [5,4,5,1,1,null,5] 輸出：2 範例 2 輸入：root = [1,4,5,4,4,null,5] 輸出：2

限制條件

  • 節點數在 [0, 10⁴] 範圍內
  • -1000 ≤ Node.val ≤ 1000
  • 樹的深度不超過 1000

LeetCode 原題

解題思路

【和第 543 題相同的骨架】 arm(nd) = 從 nd 往下、全部同值的最長鏈（邊數）。 以 nd 為最高點的路徑 = 左臂 + 右臂。 【多一個條件】 孩子的值和 nd 不同 -> 那一側的臂長為 0（接不上）。 但仍要遞迴進去，因為孩子的子樹裡可能有其他同值路徑。
解法

後序走訪

class Solution: def longestUnivaluePath(self, root: Optional[TreeNode]) -> int: res = 0 def arm(nd): # 從 nd 往下、值都和 nd 相同的最長鏈（邊數） nonlocal res if not nd: return 0 L, R = arm(nd.left), arm(nd.right) L = L + 1 if nd.left and nd.left.val == nd.val else 0 # ★ 孩子值不同就接不上 R = R + 1 if nd.right and nd.right.val == nd.val else 0 res = max(res, L + R) # 以 nd 為轉折點的路徑 return max(L, R) arm(root) return res

驗證方式：從每個節點出發只走同值鄰居做 BFS，取最遠距離，比對 1500 棵隨機樹。

複雜度說明
時間O(n)
空間O(h)

邊界條件檢查清單

  • 空樹或單一節點 → 0。
  • 孩子值不同 → 臂長歸零，但仍要遞迴。
