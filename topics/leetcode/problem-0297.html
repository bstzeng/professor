LeetCode 297

Serialize and Deserialize Binary Tree
二元樹的序列化與反序列化

Hard · 困難 字串 樹 深度優先搜尋 廣度優先搜尋 設計 二元樹

Problem

Serialization is the process of converting a data structure or object into a sequence of bits so that it can be stored in a file or memory buffer, or transmitted across a network connection link to be reconstructed later in the same or another computer environment.

Design an algorithm to serialize and deserialize a binary tree. There is no restriction on how your serialization/deserialization algorithm should work. You just need to ensure that a binary tree can be serialized to a string and this string can be deserialized to the original tree structure.

中文翻譯

序列化是把資料結構轉成一串字元（或位元），方便存檔或透過網路傳送，之後再反序列化還原回來。

請設計一套演算法，把二元樹序列化成字串，並能從字串還原成完全相同的樹。格式由你自己決定。

範例

範例 1 輸入：root = [1,2,3,null,null,4,5] 輸出：[1,2,3,null,null,4,5] 範例 2 輸入：root = [] 輸出：[]

限制條件

  • 節點數在 [0, 10⁴] 之間
  • −1000 ≤ Node.val ≤ 1000

LeetCode 原題

解題思路

【只存前序或中序不夠 —— 要把「空節點」也寫進去】 只有前序 [1, 2, 3]： 1 的左孩子是 2 還是右孩子是 2？無法確定 ✘ 加上空節點標記 "#"： 1,2,#,#,3,#,# -> 唯一確定 ✔ 【前序 + 空標記】 serialize：根、左、右，空節點寫 "#" deserialize：用同一個順序讀： 讀一個 token： "#" -> 回傳 None 數字 -> 建節點，遞迴建左子樹，再遞迴建右子樹 左子樹的遞迴會「剛好」消耗掉屬於它的所有 token， 接下來讀到的自然就是右子樹的開頭。 【層序（BFS）+ 空標記】 就是 LeetCode 自己用的格式 [1,2,3,null,null,4,5]。 反序列化時用佇列，每個節點依序讀出兩個孩子。 【為什麼需要分隔符號？】 值可能是多位數或負數（-1000）-> 用逗號分隔。
1 / \ 2 3 前序：1,2,#,#,3,4,#,#,5,#,# / \ 層序：1,2,3,#,#,4,5,#,#,#,# 4 5
解法一

前序 DFS + 空節點標記

class Codec: def serialize(self, root): out = [] def dfs(node): # 前序：根、左、右；空節點寫 "#" if node is None: out.append("#") return out.append(str(node.val)) dfs(node.left) dfs(node.right) dfs(root) return ",".join(out) def deserialize(self, data): tokens = iter(data.split(",")) def build(): # ★ 用同樣的前序順序讀回來 tok = next(tokens) if tok == "#": return None node = TreeNode(int(tok)) node.left = build() # 左子樹會「剛好」讀完它自己的 token node.right = build() return node return build()
複雜度說明
時間O(n)
空間O(n)
解法二

層序 BFS + 空節點標記

class Codec: def serialize(self, root): if root is None: return "" out, q = [], deque([root]) while q: # 層序；空節點寫 "#" node = q.popleft() if node is None: out.append("#") continue out.append(str(node.val)) q.append(node.left) q.append(node.right) return ",".join(out) def deserialize(self, data): if not data: return None vals = data.split(",") root = TreeNode(int(vals[0])) q, i = deque([root]), 1 while q: node = q.popleft() for side in ("left", "right"): # 依序讀出左、右孩子 if vals[i] != "#": child = TreeNode(int(vals[i])) setattr(node, side, child) q.append(child) i += 1 return root

樹很深（一條鏈，一萬層）時，前序遞迴在 Python 會超過遞迴上限；層序版本沒有這個問題。

複雜度說明
時間O(n)
空間O(n)

二、層序O(n)O(n)不怕深樹

邊界條件檢查清單

  • 空樹 → 前序版是 "#"；層序版是空字串。
  • 負數、多位數 → 要有分隔符號。
  • 深度一萬的鏈 → 遞迴版要調高遞迴上限或改用迭代。

常見追問

如果是 BST？

第 449 題：BST 只存前序就夠了（不用空標記）——因為值的大小就能決定左右。反序列化時帶著上下界遞迴。

只有前序 + 中序能不能還原？

可以（第 105 題），前提是值不重複。但序列化要存兩份，而且重建比較複雜；加空標記的單一遍歷更簡單。
