LeetCode 667

Beautiful Arrangement II
優美的排列 II

Medium · 中等 陣列 數學

Problem

Given two integers n and k, construct a list answer that contains n different positive integers ranging from 1 to n and obeys the following requirement:

  • Suppose this list is answer = [a1, a2, a3, ... , an], then the list [|a1 - a2|, |a2 - a3|, |a3 - a4|, ... , |an-1 - an|] has exactly k distinct integers.

Return the list answer. If there multiple valid answers, return any of them.

中文翻譯

給你兩個整數 n 和 k，構造一個由 1 到 n 組成的排列，使得相鄰兩數之差的絕對值恰好有 k 種不同的值。有多種答案時回傳任意一種。

範例

範例 1 輸入：n = 3, k = 1 輸出：[1,2,3] 範例 2 輸入：n = 3, k = 2 輸出：[1,3,2]

限制條件

  • 1 ≤ k < n ≤ 10⁴

LeetCode 原題

解題思路

【怎麼得到 k 種差值？】 1, k+1, 2, k, 3, k-1, ... 差依序是 k, k-1, k-2, ..., 1 —— 恰好 k 種。 這需要 k+1 個數。 【其他數怎麼放？】 剩下的數放在前面，遞增排列：差都是 1， 1 已經在上面的 k 種裡，不會增加新的差值。 【具體】 前面：1, 2, ..., n-k-1 後面：n-k, n, n-k+1, n-1, ...（一小一大交錯） 銜接處 n-k-1 -> n-k 的差也是 1。
解法

構造

class Solution: def constructArray(self, n: int, k: int) -> List[int]: res = list(range(1, n - k)) # 前面 1..n-k-1 遞增排列，相鄰差都是 1 lo, hi = n - k, n while lo <= hi: # ★ 剩下的 k+1 個數「一小一大」交錯：差為 k, k-1, ..., 1 res.append(lo) lo += 1 if lo <= hi: res.append(hi) hi -= 1 return res

驗證方式：n < 40 的所有 (n, k) 都檢查排列合法且差值種數恰為 k。

複雜度說明
時間O(n)
空間O(1)不計輸出

邊界條件檢查清單

  • k = 1 → 1, 2, ..., n。
  • k = n − 1 → 全部一小一大交錯。

常見追問

構造題的思路

先找一個「恰好產生所需數量」的小結構（這裡是交錯排列），再把剩下的東西用「不增加新東西」的方式放進去。
