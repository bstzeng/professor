Single Element in a Sorted Array
有序陣列中的單一元素

Medium · 中等 陣列 二分搜尋

Problem

You are given a sorted array consisting of only integers where every element appears exactly twice, except for one element which appears exactly once.

Return the single element that appears only once.

Your solution must run in O(log n) time and O(1) space.

中文翻譯

給你一個已排序的整數陣列，其中每個元素都恰好出現兩次，只有一個元素出現一次。找出它。要求 O(log n) 時間、O(1) 空間。

範例

範例 1 輸入：nums = [1,1,2,3,3,4,4,8,8] 輸出：2 範例 2 輸入：nums = [3,3,7,7,10,11,11] 輸出：10

限制條件

  • 1 ≤ nums.length ≤ 10⁵
  • 0 ≤ nums[i] ≤ 10⁵

LeetCode 原題

解題思路

【異或可以做到 O(n)，但要求 O(log n)】 【觀察配對的位置】 [1,1,2,3,3,4,4,8,8] 0 1 2 3 4 5 6 7 8 單一元素 2 之前：配對在 (0,1) —— 從偶數索引開始。 單一元素之後：配對在 (3,4)、(5,6)、(7,8) —— 從奇數索引開始。 【二分】 把 mid 調成偶數，看 nums[mid] == nums[mid+1]： 相等：mid 之前沒被打亂 -> 單一元素在 mid+2 之後 不等：已經錯位 -> 單一元素在 mid 或更左 區間每次縮小一半。
解法

對偶數索引二分

class Solution: def singleNonDuplicate(self, nums: List[int]) -> int: lo, hi = 0, len(nums) - 1 while lo < hi: mid = (lo + hi) // 2 if mid % 2 == 1: mid -= 1 # 讓 mid 對齊成偶數：成對的元素應該在 (偶, 偶+1) if nums[mid] == nums[mid + 1]: lo = mid + 2 # ★ 配對沒被打亂 -> 單一元素在右邊 else: hi = mid # 配對亂了 -> 單一元素在 mid 或左邊 return nums[lo]
複雜度說明
時間O(log n)
空間O(1)

邊界條件檢查清單

  • 只有一個元素 → 直接回傳。
  • 單一元素在頭或尾 → 二分照樣收斂。

常見追問

異或的寫法

也可以寫成：比較 nums[mid] 和 nums[mid ^ 1]。mid 是偶數時 mid^1 = mid+1，奇數時 mid^1 = mid−1——正好是「應該配對的夥伴」。
