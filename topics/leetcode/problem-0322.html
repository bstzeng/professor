LeetCode 322

Coin Change
零錢兌換

Medium · 中等 廣度優先搜尋 陣列 動態規劃

Problem

You are given an integer array coins representing coins of different denominations and an integer amount representing a total amount of money.

Return the fewest number of coins that you need to make up that amount. If that amount of money cannot be made up by any combination of the coins, return -1.

You may assume that you have an infinite number of each kind of coin.

中文翻譯

給你一個代表不同面額硬幣的陣列 coins，以及總金額 amount。

回傳湊出總金額所需的最少硬幣數。如果無法湊出，回傳 -1。

每種硬幣的數量都是無限的。

範例

範例 1 輸入：coins = [1,2,5], amount = 11 輸出：3 說明：11 = 5 + 5 + 1 範例 2 輸入：coins = [2], amount = 3 輸出：-1 範例 3 輸入：coins = [1], amount = 0 輸出：0

限制條件

  • 1 ≤ coins.length ≤ 12
  • 1 ≤ coins[i] ≤ 2³¹ − 1
  • 0 ≤ amount ≤ 10⁴

LeetCode 原題

解題思路

【貪心為什麼不行？】 coins = [1, 3, 4]，amount = 6 貪心：4 + 1 + 1 = 3 枚 最佳：3 + 3 = 2 枚 ✘ （台幣、美元這種面額設計剛好讓貪心成立，但一般情況不成立。） 【完全背包 DP】 dp[x] = 湊出 x 的最少硬幣數 dp[0] = 0 dp[x] = min(dp[x - c] + 1) 對每個 c <= x 「最後一枚是 c」-> 剩下 x - c 用最少的方式湊。 【不可能的標記】 用 amount + 1 當作「無限大」： 就算全用 1 元也只要 amount 枚，所以 amount + 1 不可能是真的答案。 【BFS 觀點】 金額是節點，加一枚硬幣是一條邊， 從 0 走到 amount 的最短路徑 = 最少硬幣數。

錯誤示範

貪心（每次拿最大面額）

class Solution: def coinChange(self, coins: List[int], amount: int) -> int: # ✘ 錯誤示範：每次拿最大的面額 count = 0 for c in sorted(coins, reverse=True): count += amount // c amount %= c return count if amount == 0 else -1

coins = [1, 3, 4]、amount = 6 時回傳 3，正確答案是 2。

解法一

BFS 最短路徑

class Solution: def coinChange(self, coins: List[int], amount: int) -> int: if amount == 0: return 0 seen = {0} frontier = [0] steps = 0 while frontier: # BFS：第幾層 = 用了幾枚 steps += 1 nxt = [] for s in frontier: for c in coins: t = s + c if t == amount: return steps if t < amount and t not in seen: seen.add(t) nxt.append(t) frontier = nxt return -1
複雜度說明
時間O(amount · k)k = 硬幣種類數
空間O(amount)
解法二

完全背包 DP

class Solution: def coinChange(self, coins: List[int], amount: int) -> int: INF = amount + 1 # 不可能的值（最多用 amount 個 1 元） dp = [0] + [INF] * amount # dp[x]：湊出 x 最少要幾枚 for x in range(1, amount + 1): for c in coins: if c <= x: # ★ 最後一枚是 c：剩下的 x - c 用最少的方式湊 dp[x] = min(dp[x], dp[x - c] + 1) return dp[amount] if dp[amount] < INF else -1
複雜度說明
時間O(amount · k)
空間O(amount)

邊界條件檢查清單

  • amount = 0 → 0。
  • 無法湊出 → −1。
  • 硬幣面額大於 amount → 直接跳過。
  • 面額很大（2³¹ − 1）→ c <= x 的判斷避免負索引。

常見追問

追問：有幾種湊法？

第 518 題「零錢兌換 II」：dp[x] += dp[x − c]。 但要注意迴圈順序：外層硬幣、內層金額 → 算「組合數」（1+2 和 2+1 算同一種）； 外層金額、內層硬幣 → 算「排列數」（第 377 題）。
