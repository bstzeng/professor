LeetCode 539

Minimum Time Difference
最小時間差

Medium · 中等 陣列 數學 字串 排序

Problem

Given a list of 24-hour clock time points in "HH:MM" format, return the minimum minutes difference between any two time-points in the list.

中文翻譯

給你一組 24 小時制的時間點 "HH:MM"，回傳任意兩個時間點之間的最小分鐘差。

範例

範例 1 輸入：timePoints = ["23:59","00:00"] 輸出：1 範例 2 輸入：timePoints = ["00:00","23:59","00:00"] 輸出：0

限制條件

  • 2 ≤ timePoints.length ≤ 2 * 10⁴
  • timePoints[i] is in the format "HH:MM".

LeetCode 原題

解題思路

【轉成分鐘 + 排序】 "HH:MM" -> HH*60 + MM，範圍 [0, 1440)。 排序後，最小差一定在相鄰兩個之間…… 【環形！】 時間是一圈：23:59 和 00:00 只差 1 分鐘。 所以還要比較「最早 + 1440 - 最晚」這一對。 【鴿籠原理】 一天只有 1440 個不同的分鐘， 超過 1440 個時間點一定有重複 -> 直接回傳 0。
解法

排序 + 相鄰差 + 跨午夜

class Solution: def findMinDifference(self, timePoints: List[str]) -> int: if len(timePoints) > 1440: return 0 # 鴿籠原理：一天只有 1440 分鐘，一定有重複 mins = sorted(int(t[:2]) * 60 + int(t[3:]) for t in timePoints) res = min(b - a for a, b in zip(mins, mins[1:])) return min(res, mins[0] + 1440 - mins[-1]) # ★ 跨過午夜：最早的 + 24 小時 - 最晚的
複雜度說明
時間O(n log n)
空間O(n)

邊界條件檢查清單

  • 重複時間 → 0。
  • 跨午夜 → 23:59 與 00:00 差 1。

常見追問

O(n) 做法

用長度 1440 的布林陣列標記出現過的分鐘（重複就回傳 0），再依序掃一遍取相鄰差，相當於計數排序。
