Battleships in a Board
甲板上的戰艦

Medium · 中等 深度優先搜尋 陣列 矩陣

Problem

Given an m x n matrix board where each cell is a battleship 'X' or empty '.', return the number of the battleships on board.

Battleships can only be placed horizontally or vertically on board. In other words, they can only be made of the shape 1 x k (1 row, k columns) or k x 1 (k rows, 1 column), where k can be of any size. At least one horizontal or vertical cell separates between two battleships (i.e., there are no adjacent battleships).

Follow up: Could you do it in one-pass, using only O(1) extra memory and without modifying the values board?

中文翻譯

給你一個 m x n 的棋盤，每格是戰艦 'X' 或空格 '.'，回傳戰艦的數量。

戰艦只能橫放或直放（1 x k 或 k x 1），兩艘戰艦之間至少隔一格（不會相鄰）。

進階：能只掃一遍、O(1) 額外空間、而且不修改棋盤嗎？

範例

範例 1 輸入：board = [["X",".",".","X"], [".",".",".","X"], [".",".",".","X"]] 輸出：2 範例 2 輸入：board = [["."]] 輸出：0

限制條件

  • 1 ≤ m, n ≤ 200
  • board[i][j] 是 '.' 或 'X'

LeetCode 原題

解題思路

【一般做法：數連通區塊（第 200 題）】 DFS / BFS，但要修改棋盤或用 visited -> 不符合進階要求。 【只數「船頭」】 每艘船都是一條直線，有唯一的「最左上角」那一格： 它的左邊不是 X，上邊也不是 X。 其他格子至少有一個鄰居（左或上）是同一艘船的 X。 所以：數滿足「是 X、左邊不是 X、上邊不是 X」的格子數 = 船數。 因為題目保證船不相鄰，不會有「左邊的 X 屬於另一艘船」的情況。
解法

只數每艘船的頭

class Solution: def countBattleships(self, board: List[List[str]]) -> int: count = 0 for i, row in enumerate(board): for j, c in enumerate(row): # ★ 只數每艘船的「頭」：左邊和上邊都不是 X if (c == "X" and (i == 0 or board[i - 1][j] != "X") and (j == 0 or row[j - 1] != "X")): count += 1 return count
複雜度說明
時間O(mn)
空間O(1)

邊界條件檢查清單

  • 沒有船 → 0。
  • 長度 1 的船 → 自己就是頭。
  • 第一列、第一欄 → 沒有上邊或左邊，視為不是 X。

常見追問

如果船可以相鄰？

那就無法只看局部分辨，必須用 DFS／並查集數連通區塊（而且題目會變得不明確——相鄰的兩艘船看起來就像一艘 L 形的船）。
