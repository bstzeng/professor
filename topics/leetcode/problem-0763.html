LeetCode 763

Partition Labels
劃分字母區間

Medium · 中等 貪心 雜湊表 雙指標 字串

Problem

You are given a string s. We want to partition the string into as many parts as possible so that each letter appears in at most one part. For example, the string "ababcc" can be partitioned into ["abab", "cc"], but partitions such as ["aba", "bcc"] or ["ab", "ab", "cc"] are invalid.

Note that the partition is done so that after concatenating all the parts in order, the resultant string should be s.

Return a list of integers representing the size of these parts.

中文翻譯

給你字串 s，把它劃分成盡可能多的段落，使每個字母最多只出現在一個段落中。

依序回傳每個段落的長度。

範例

範例 1 輸入：s = "ababcbacadefegdehijhklij" 輸出：[9,7,8] 範例 2 輸入：s = "eccbbbbdec" 輸出：[10]

限制條件

  • 1 ≤ s.length ≤ 500
  • s 只含小寫英文字母

LeetCode 原題

解題思路

【一個字母出現的位置必須全在同一段】 段落一旦包含字母 c，就必須延伸到 c 最後出現的位置。 【貪心掃描】 end = 目前段落至少要到的位置。 每讀到一個字母，end = max(end, last[c])。 i == end：段落中所有字母的最後位置都已經包含了， 在這裡切最早，能切出最多段。
解法

最後位置 + 貪心

class Solution: def partitionLabels(self, s: str) -> List[int]: last = {c: i for i, c in enumerate(s)} # 每個字母最後出現的位置 res, start, end = [], 0, 0 for i, c in enumerate(s): end = max(end, last[c]) # 目前這段至少要延伸到這裡 if i == end: # ★ 段內所有字母的最後位置都到齊了：可以切 res.append(end - start + 1) start = i + 1 return res

驗證方式：和「所有能切的位置（左右兩邊沒有共同字母）都切」的方法比對 2000 組。

複雜度說明
時間O(n)字母表大小固定
空間O(1)

邊界條件檢查清單

  • 所有字母都不同 → 每段長度 1。
  • 首尾字母相同 → 整個字串一段。

常見追問

區間合併的角度

每個字母對應一個區間 [第一次, 最後一次]，問題變成合併重疊的區間（第 56 題），合併後每段的長度就是答案。
