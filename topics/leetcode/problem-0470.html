Implement Rand10() Using Rand7()
用 Rand7() 實作 Rand10()

Medium · 中等 數學 拒絕抽樣 機率與統計 隨機化

Problem

Given the API rand7() that generates a uniform random integer in the range [1, 7], write a function rand10() that generates a uniform random integer in the range [1, 10]. You can only call the API rand7(), and you shouldn't call any other API. Please do not use a language's built-in random API.

Follow up:

  • What is the expected value for the number of calls to rand7() function?
  • Could you minimize the number of calls to rand7()?

中文翻譯

給你一個 API rand7()，會均勻產生 [1, 7] 的整數。只用它寫出 rand10()，均勻產生 [1, 10] 的整數。

進階：呼叫 rand7() 的期望次數是多少？能再減少嗎？

範例

範例 輸入：n = 3（呼叫 rand10 三次） 輸出：例如 [3,8,10]

限制條件

  • 1 ≤ n ≤ 10⁵

LeetCode 原題

解題思路

【一次 rand7 只有 7 種結果，不夠 10 種】 (rand7() + rand7()) 不均勻（和的分布是三角形）✘ 【兩次 rand7 組成一個「二位數」】 x = (rand7() - 1) × 7 + rand7() 第一次決定「十位」（0..6），第二次決定「個位」（1..7） -> x 均勻分布在 1..49，每個機率 1/49 ✔ 【拒絕抽樣（rejection sampling）】 49 不是 10 的倍數。 只接受 1..40（每個數字對應 4 個 x），41..49 就重來。 被接受時，1..40 仍然是均勻的 -> (x - 1) % 10 + 1 均勻落在 1..10。 【期望呼叫次數】 每一輪呼叫 2 次，被接受的機率 40/49。 期望輪數 = 49/40 -> 期望呼叫 2 × 49/40 ≈ 2.45 次。 【進一步優化】 被拒絕的 41..49 還有 9 種均勻的結果， 可以再乘上一次 rand7 變成 1..63，取前 60 個…… 把「剩下的隨機性」回收利用，期望次數可以降到約 2.2。
解法

組合成 1..49 + 拒絕抽樣

# The rand7() API is already defined for you. # def rand7(): # @return a random integer in the range 1 to 7 class Solution: def rand10(self) -> int: while True: # ★ 兩次 rand7 組成 1..49 的均勻分布 x = (rand7() - 1) * 7 + rand7() if x <= 40: # 只接受前 40 個（10 的倍數），其餘重來 return (x - 1) % 10 + 1

驗證方式：二十萬次抽樣，每個數字的次數都在期望值 ±5% 以內，平均呼叫 rand7 約 2.45 次。
