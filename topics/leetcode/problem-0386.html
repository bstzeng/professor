LeetCode 386

Lexicographical Numbers
字典序排數

Medium · 中等 深度優先搜尋 字典樹

Problem

Given an integer n, return all the numbers in the range [1, n] sorted in lexicographical order.

You must write an algorithm that runs in O(n) time and uses O(1) extra space.

中文翻譯

給你一個整數 n，回傳 1 到 n 所有整數，依字典序（當成字串比較）排列。

必須 O(n) 時間、O(1) 額外空間。

範例

範例 1 輸入：n = 13 輸出：[1,10,11,12,13,2,3,4,5,6,7,8,9] 範例 2 輸入：n = 2 輸出：[1,2]

限制條件

  • 1 ≤ n ≤ 5 × 10⁴

LeetCode 原題

解題思路

【字典序 = 十叉樹的前序遍歷】 (root) / / ... \ 1 2 9 / | \ 10 11 ... 19 / \ 100 101 ... 前序：1, 10, 100, ..., 101, ..., 11, ..., 2, ... 【O(1) 空間的迭代】 從 x = 1 開始，每一步找「前序的下一個」： 1. 能往下走（x × 10 <= n）-> x = x × 10 2. 不能往下 -> 往右邊的兄弟（x + 1） 但如果 x 的個位是 9（沒有右兄弟），或 x + 1 > n， 就先退回父節點（x // 10），重複檢查，再 + 1。 【範例 n = 13】 1 -> 10（往下） 10 -> 11 -> 12 -> 13（兄弟） 13 + 1 = 14 > 13 -> 退回 1 -> 2（兄弟） 2 -> 20 > 13 不能往下 -> 3 -> ... -> 9
解法一

DFS 前序遍歷

class Solution: def lexicalOrder(self, n: int) -> List[int]: res = [] def dfs(x: int) -> None: # 前序走訪一棵十叉樹 if x > n: return res.append(x) for d in range(10): if x * 10 + d > n: break dfs(x * 10 + d) for first in range(1, 10): dfs(first) return res
複雜度說明
時間O(n)
空間O(log n)遞迴深度 ≤ 5
解法二

迭代找「下一個」

class Solution: def lexicalOrder(self, n: int) -> List[int]: res = [] x = 1 for _ in range(n): res.append(x) if x * 10 <= n: # ★ 優先往下一層走（在後面加 0） x *= 10 else: while x % 10 == 9 or x + 1 > n: # 走不下去：退回上一層 x //= 10 x += 1 # 同一層的下一個 return res
複雜度說明
時間O(n)攤銷；退回父節點的總次數 ≤ n
空間O(1)不計輸出

邊界條件檢查清單

  • n < 10 → 1..n 本身就是字典序。
  • x 的個位是 9 → 沒有右兄弟，要退回上一層。
  • x + 1 > n → 也要退回上一層。
