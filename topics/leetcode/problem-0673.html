Number of Longest Increasing Subsequence
最長遞增子序列的個數

Medium · 中等 樹狀陣列 線段樹 陣列 動態規劃

Problem

Given an integer array nums, return the number of longest increasing subsequences.

Notice that the sequence has to be strictly increasing.

中文翻譯

給你整數陣列 nums，回傳最長嚴格遞增子序列的個數（不同位置的子序列分開計算）。

範例

範例 1 輸入：nums = [1,3,5,4,7] 輸出：2 範例 2 輸入：nums = [2,2,2,2,2] 輸出：5

限制條件

  • 1 ≤ nums.length ≤ 2000
  • -10⁶ ≤ nums[i] ≤ 10⁶
  • 答案保證在 32 位元整數範圍內

LeetCode 原題

解題思路

【第 300 題的 DP】 length[i] = 以 nums[i] 結尾的 LIS 長度 = 1 + max(length[j])，j < i 且 nums[j] < nums[i] 【多記一個 count[i]】 count[i] = 以 nums[i] 結尾、長度為 length[i] 的子序列個數。 對每個 j： length[j] + 1 > length[i] -> 找到更長的，count[i] = count[j] length[j] + 1 == length[i] -> 又一種方法，count[i] += count[j] 【答案】 所有 length[i] == 最大長度 的 count[i] 加總。
解法

LIS DP + 方法數

class Solution: def findNumberOfLIS(self, nums: List[int]) -> int: n = len(nums) length = [1] * n # length[i]：以 i 結尾的 LIS 長度 count = [1] * n # count[i]：達到這個長度的方法數 for i in range(n): for j in range(i): if nums[j] < nums[i]: if length[j] + 1 > length[i]: length[i] = length[j] + 1 count[i] = count[j] # ★ 找到更長的：方法數重新計算 elif length[j] + 1 == length[i]: count[i] += count[j] # 一樣長：方法數累加 best = max(length) return sum(c for l, c in zip(length, count) if l == best)

驗證方式：和枚舉所有子序列的暴力法比對 1500 組。

複雜度說明
時間O(n²)
空間O(n)

邊界條件檢查清單

  • 全部相同 → n（每個單獨的元素都是長度 1 的 LIS）。
  • 嚴格遞增 → 相等不能接。

常見追問

O(n log n)

對每個長度維護「結尾值 → 累積方法數」的有序結構，用二分加前綴和查詢可以做到 O(n log n)，或用樹狀陣列/線段樹（以值為索引，存 (最長長度, 方法數)）。
