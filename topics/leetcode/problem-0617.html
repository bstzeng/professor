LeetCode 617

Merge Two Binary Trees
合併二元樹

Easy · 簡單 樹 深度優先搜尋 廣度優先搜尋 二元樹

Problem

You are given two binary trees root1 and root2.

Imagine that when you put one of them to cover the other, some nodes of the two trees are overlapped while the others are not. You need to merge the two trees into a new binary tree. The merge rule is that if two nodes overlap, then sum node values up as the new value of the merged node. Otherwise, the NOT null node will be used as the node of the new tree.

Return the merged tree.

Note: The merging process must start from the root nodes of both trees.

中文翻譯

給你兩棵二元樹 root1、root2。把它們疊在一起：重疊位置的節點值相加，不重疊的位置則保留存在的那一個節點。

回傳合併後的樹（從兩棵樹的根開始合併）。

範例

範例 1 輸入：root1 = [1,3,2,5], root2 = [2,1,3,null,4,null,7] 輸出：[3,4,5,5,4,null,7] 範例 2 輸入：root1 = [1], root2 = [1,2] 輸出：[2,2]

限制條件

  • 節點數在 [0, 2000] 範圍內
  • -10⁴ ≤ Node.val ≤ 10⁴

LeetCode 原題

解題思路

【同步遞迴】 merge(a, b)： 有一邊是空的 -> 回傳另一邊（整棵子樹直接接上，不用複製） 都不空 -> a.val += b.val，左右分別遞迴 這裡直接修改 root1 並回傳它； 若不想改動輸入，可以每次建新節點。
解法

同步遞迴

class Solution: def mergeTrees(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> Optional[TreeNode]: if not root1 or not root2: return root1 or root2 # ★ 一邊是空的：直接沿用另一邊的整棵子樹 root1.val += root2.val root1.left = self.mergeTrees(root1.left, root2.left) root1.right = self.mergeTrees(root1.right, root2.right) return root1
複雜度說明
時間O(min(m, n))只走訪兩棵樹重疊的部分
空間O(min(h₁, h₂))

邊界條件檢查清單

  • 一棵是空樹 → 回傳另一棵。
  • 形狀完全不同 → 非重疊的部分直接接上。
