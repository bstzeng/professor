Find Mode in Binary Search Tree
二元搜尋樹中的眾數

Easy · 簡單 樹 深度優先搜尋 二元搜尋樹 二元樹

Problem

Given the root of a binary search tree (BST) with duplicates, return all the mode(s) (i.e., the most frequently occurred element) in it.

If the tree has more than one mode, return them in any order.

Assume a BST is defined as follows:

  • The left subtree of a node contains only nodes with keys less than or equal to the node's key.
  • The right subtree of a node contains only nodes with keys greater than or equal to the node's key.
  • Both the left and right subtrees must also be binary search trees.

Follow up: Could you do that without using any extra space? (Assume that the implicit stack space incurred due to recursion does not count).

中文翻譯

給你一棵允許重複值的二元搜尋樹（BST）的根節點，找出所有眾數（出現次數最多的值）。若有多個，以任意順序回傳。

這裡的 BST 定義：左子樹的值都 ≤ 節點值，右子樹的值都 ≥ 節點值。

進階：能不用額外空間嗎？（遞迴的呼叫堆疊不算）

範例

範例 1 輸入：root = [1,null,2,2] 輸出：[2] 範例 2 輸入：root = [0] 輸出：[0]

限制條件

  • 節點數在 [1, 10⁴] 範圍內
  • -10⁵ ≤ Node.val ≤ 10⁵

LeetCode 原題

解題思路

【一般二元樹的做法】 用雜湊表數每個值出現幾次，取最大的。O(n) 空間。 【利用 BST 的性質】 BST 的中序走訪 = 由小到大排好的序列。 排序後，相同的值一定擠在一起 -> 像在排序陣列上數「連續段」： prev：上一個值 run ：目前這一段的長度 best：目前最長的長度 run > best -> 清空答案，只放這個值 run == best -> 加進答案 只用幾個變數，不需要雜湊表。
解法一

雜湊表計數（任何二元樹都適用）

class Solution: def findMode(self, root: Optional[TreeNode]) -> List[int]: cnt = Counter() def dfs(nd): if nd: cnt[nd.val] += 1 dfs(nd.left); dfs(nd.right) dfs(root) best = max(cnt.values()) return [v for v, c in cnt.items() if c == best]
複雜度說明
時間O(n)
空間O(n)
解法二

中序走訪 + 連續段計數

class Solution: def findMode(self, root: Optional[TreeNode]) -> List[int]: res, best = [], 0 prev, run = None, 0 # 中序走訪時「上一個值」與它目前連續出現的次數 def visit(v): nonlocal prev, run, best, res run = run + 1 if v == prev else 1 # ★ BST 中序是有序的，相同值一定相鄰 prev = v if run > best: best, res = run, [v] elif run == best: res.append(v) def inorder(nd): if nd: inorder(nd.left) visit(nd.val) inorder(nd.right) inorder(root) return res
複雜度說明
時間O(n)
空間O(h)只有遞迴堆疊

邊界條件檢查清單

  • 只有一個節點 → 答案就是它。
  • 所有值都不同 → 每個值都是眾數，全部回傳。
  • 更新 best 時要清空舊答案 → 不能只 append。

常見追問

真正的 O(1) 空間？

遞迴堆疊仍是 O(h)。要做到 O(1)，可以用 Morris 中序走訪（第 99 題、第 94 題的進階）：暫時把前驅節點的右指標接回自己，走完再還原。
