LeetCode 220

Contains Duplicate III
存在重複元素 III

Hard · 困難 陣列 分桶排序 有序集合 排序 滑動視窗

Problem

You are given an integer array nums and two integers indexDiff and valueDiff.

Return true if there is a pair of indices (i, j) with i != j, abs(i - j) <= indexDiff and abs(nums[i] - nums[j]) <= valueDiff. Otherwise return false.

中文翻譯

給你一個整數陣列 nums，以及兩個整數 indexDiff、valueDiff。

如果存在一對索引 (i, j)，滿足 i != j、abs(i - j) <= indexDiff、而且 abs(nums[i] - nums[j]) <= valueDiff，回傳 true；否則回傳 false。

範例

範例 1 輸入：nums = [1,2,3,1], indexDiff = 3, valueDiff = 0 輸出：true 說明：(0, 3)：距離 3，值相差 0。 範例 2 輸入：nums = [1,5,9,1,5,9], indexDiff = 2, valueDiff = 3 輸出：false

限制條件

  • 2 ≤ nums.length ≤ 10⁵
  • −10⁹ ≤ nums[i] ≤ 10⁹
  • 1 ≤ indexDiff ≤ nums.length
  • 0 ≤ valueDiff ≤ 10⁹

LeetCode 原題

解題思路

【第 219 題的滑動視窗，但查詢條件變了】 視窗（最近 indexDiff 個元素）裡， 有沒有某個值 y 落在 [x - t, x + t]？ 【方法一：有序結構】 視窗內的值保持排序，二分找「第一個 >= x - t 的值」， 再看它是否 <= x + t。 需要能在 O(log k) 插入和刪除的有序集合。 Python 標準函式庫沒有平衡樹，用 list + insort 的插入是 O(k)。 【方法二：分桶】 把數線切成寬度 w = t + 1 的桶： 桶編號 = x // w - 同一桶內任兩數相差 <= t ✔ - 所以每個桶在視窗裡最多只會有一個數 （有第二個的話早就回傳 true 了） - 相差 <= t 的兩個數，只可能在同一桶或相鄰桶 每個新數字只看 3 個桶 -> O(1) ✔ 【負數】 Python 的 // 是向下取整：-1 // 4 = -1、-4 // 4 = -1、-5 // 4 = -2 ✔ 其他語言（C++/Java 向零取整）要自己處理， 否則 -3 和 3 會被放進同一個桶 0 ✘ 【為什麼桶寬是 t + 1 而不是 t？】 同一桶內最大相差 = 桶寬 − 1，要讓它剛好等於 t -> 桶寬 t + 1。 另外 t = 0 時，桶寬 t 會除以零 ✘
解法一

暴力

class Solution: def containsNearbyAlmostDuplicate(self, nums: List[int], indexDiff: int, valueDiff: int) -> bool: for i in range(len(nums)): for j in range(i + 1, min(i + indexDiff + 1, len(nums))): if abs(nums[i] - nums[j]) <= valueDiff: return True return False
複雜度說明
時間O(n·k)k = indexDiff
空間O(1)
解法二

滑動視窗 + 排序陣列（bisect）

class Solution: def containsNearbyAlmostDuplicate(self, nums: List[int], indexDiff: int, valueDiff: int) -> bool: window = [] # 視窗內的值，保持排序 for i, x in enumerate(nums): j = bisect.bisect_left(window, x - valueDiff) # 第一個 >= x - t 的值 if j < len(window) and window[j] <= x + valueDiff: return True bisect.insort(window, x) if i >= indexDiff: window.pop(bisect.bisect_left(window, nums[i - indexDiff])) return False

查詢是 O(log k)，但 insort 和 pop 在 list 中間插入刪除是 O(k)。在其他語言用 TreeSet / std::set 可以做到 O(n log k)；Python 可以用第三方的 sortedcontainers.SortedList。

複雜度說明
時間O(n·k)（list）用平衡樹可降為 O(n log k)
空間O(k)
解法三

滑動視窗 + 分桶

class Solution: def containsNearbyAlmostDuplicate(self, nums: List[int], indexDiff: int, valueDiff: int) -> bool: w = valueDiff + 1 # ★ 桶寬 t+1：同一桶內任兩數相差 <= t buckets = {} # 桶編號 -> 桶內唯一的值 for i, x in enumerate(nums): b = x // w # Python 的 // 向下取整，負數也正確 if b in buckets: return True if b - 1 in buckets and x - buckets[b - 1] <= valueDiff: return True if b + 1 in buckets and buckets[b + 1] - x <= valueDiff: return True buckets[b] = x if i >= indexDiff: # 維持視窗大小：移除太舊的 del buckets[nums[i - indexDiff] // w] return False
【為什麼刪除時可以直接 del buckets[編號]？】 每個桶最多一個數，而且視窗裡的數互不在同一桶， 所以那個桶裡放的一定就是要移除的 nums[i - indexDiff] ✔
複雜度說明
時間O(n)每個數只看 3 個桶
空間O(min(n, k))

解法對照

解法時間空間備註
一、暴力O(n·k)O(1)超時
二、有序結構O(n log k)*O(k)*需要平衡樹
三、分桶O(n)O(k)最佳 ✔

邊界條件檢查清單

  • valueDiff = 0 → 退化成第 219 題；桶寬 1。
  • 負數 → 必須向下取整分桶（Python 的 // 正確）。
  • 值很大（±10⁹）→ 相減不會溢位（Python）；其他語言要用 64 位元。
  • 同一個桶已經有數 → 直接 true，不需要相減。

常見追問

追問：分桶的想法還能用在哪？

第 164 題「最大間距」：n 個數放進 n+1 個桶，最大間距一定出現在「桶與桶之間」， 不用排序就能 O(n) 求出。分桶是「用值域換時間」的經典技巧。
