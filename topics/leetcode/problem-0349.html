LeetCode 349

Intersection of Two Arrays
兩個陣列的交集

Easy · 簡單 陣列 雜湊表 雙指標 二分搜尋 排序

Problem

Given two integer arrays nums1 and nums2, return an array of their intersection. Each element in the result must be unique and you may return the result in any order.

中文翻譯

給你兩個整數陣列 nums1、nums2，回傳它們的交集。結果中每個元素只出現一次，順序不限。

範例

範例 1 輸入：nums1 = [1,2,2,1], nums2 = [2,2] 輸出：[2] 範例 2 輸入：nums1 = [4,9,5], nums2 = [9,4,9,8,4] 輸出：[9,4]

限制條件

  • 1 ≤ nums1.length, nums2.length ≤ 1000
  • 0 ≤ nums1[i], nums2[i] ≤ 1000

LeetCode 原題

解題思路

【結果要去重 -> 集合】 set(nums1) & set(nums2)，O(n + m)。 【不用雜湊表：排序 + 雙指標】 兩個陣列都排序，指標各自從頭走： 小的那邊前進 相等 -> 加入答案（和上一個不同才加），兩邊都前進
解法一

集合交集

class Solution: def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]: return list(set(nums1) & set(nums2)) # 集合交集
複雜度說明
時間O(n + m)
空間O(n + m)
解法二

排序 + 雙指標

class Solution: def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]: a, b = sorted(nums1), sorted(nums2) i = j = 0 res = [] while i < len(a) and j < len(b): if a[i] < b[j]: i += 1 elif a[i] > b[j]: j += 1 else: if not res or res[-1] != a[i]: # 去重 res.append(a[i]) i += 1 j += 1 return res
複雜度說明
時間O(n log n + m log m)
空間O(1)不計排序與輸出

解法對照

解法時間空間
一、集合O(n + m)O(n + m) ✔
二、排序 + 雙指標O(n log n + m log m)O(1)

邊界條件檢查清單

  • 沒有交集 → 空陣列。
  • 重複元素 → 答案中只出現一次。
