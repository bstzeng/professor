LeetCode 504

Base 7
七進位數

Easy · 簡單 數學 字串

Problem

Given an integer num, return a string of its base 7 representation.

中文翻譯

給你一個整數 num，回傳它的七進位表示字串。

範例

範例 1 輸入：num = 100 輸出："202" 範例 2 輸入：num = -7 輸出："-10"

限制條件

  • -10⁷ ≤ num ≤ 10⁷

LeetCode 原題

解題思路

【進位轉換的標準做法】 n = d_k·7^k + ... + d_1·7 + d_0 n % 7 = d_0（最低位），n // 7 去掉最低位。 反覆做，得到由低到高的每一位，最後反轉。 【負數】 先記下符號，對絕對值轉換，最後補上 "-"。 （Python 對負數的 % 和 // 是向下取整，直接做會出錯。） 【0】 迴圈一次都不會執行，要特判。
解法

反覆除以 7

class Solution: def convertToBase7(self, num: int) -> str: if num == 0: return "0" neg, n = num < 0, abs(num) digits = [] while n: n, r = divmod(n, 7) # ★ 反覆除以 7，餘數就是由低到高的每一位 digits.append(str(r)) return ("-" if neg else "") + "".join(reversed(digits))
複雜度說明
時間O(log₇|n|)
空間O(log₇|n|)

邊界條件檢查清單

  • num = 0 → "0"。
  • 負數 → 先取絕對值。
  • 7 的次方 → 例如 49 = "100"。

常見追問

任意進位

把 7 換成 b 就是任意進位轉換。超過 10 的進位要把餘數對應到字母（第 405 題十六進位）；負進位（第 1017 題）則要調整餘數為非負。

延伸題目

  • 第 405 題 數字轉換為十六進位數
  • 第 168 題 Excel 表列名稱
  • 第 1017 題 負二進位轉換
