LeetCode 387

First Unique Character in a String
字串中的第一個唯一字元

Easy · 簡單 佇列 雜湊表 字串 計數

Problem

Given a string s, find the first non-repeating character in it and return its index. If it does not exist, return -1.

中文翻譯

給你一個字串 s，找出第一個不重複的字元，回傳它的索引；不存在的話回傳 -1。

範例

範例 1 輸入：s = "leetcode" 輸出：0 範例 2 輸入：s = "loveleetcode" 輸出：2 範例 3 輸入：s = "aabb" 輸出：-1

限制條件

  • 1 ≤ s.length ≤ 10⁵
  • s 只包含小寫英文字母

LeetCode 原題

解題思路

【兩趟掃描】 第一趟：數每個字元出現幾次 第二趟：依原本的順序，找第一個次數為 1 的 為什麼不能一趟？讀到某個字元時，還不知道它後面會不會再出現。 【只有 26 種字母的技巧】 對每個字母，用 find 找第一次出現、rfind 找最後一次出現。 兩者相同 -> 只出現一次。 在所有只出現一次的字母中，取位置最小的。 26 × O(n)，但 find / rfind 是 C 實作，實際上很快。
解法一

計數 + 第二趟找

class Solution: def firstUniqChar(self, s: str) -> int: cnt = collections.Counter(s) # 第一趟：計數 for i, ch in enumerate(s): # 第二趟：依原順序找第一個次數為 1 的 if cnt[ch] == 1: return i return -1
複雜度說明
時間O(n)
空間O(1)最多 26 種字元
解法二

find == rfind

class Solution: def firstUniqChar(self, s: str) -> int: # 只看 26 個字母：出現一次的字母中，位置最前面的那個 best = len(s) for ch in "abcdefghijklmnopqrstuvwxyz": i = s.find(ch) if i != -1 and i == s.rfind(ch): # ★ 第一次出現 == 最後一次出現 -> 只出現一次 best = min(best, i) return best if best < len(s) else -1
複雜度說明
時間O(26 · n)
空間O(1)

解法對照

解法時間空間
一、計數O(n)O(1) ✔
二、find / rfindO(26n)O(1)

邊界條件檢查清單

  • 全部重複 → −1。
  • 只有一個字元 → 0。
