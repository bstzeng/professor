LeetCode 83

Remove Duplicates from Sorted List
刪除排序串列中的重複元素

Easy · 簡單 鏈結串列

Problem

Given the head of a sorted linked list, delete all duplicates such that each element appears only once. Return the linked list sorted as well.

中文翻譯

給你一個已排序的鏈結串列，刪掉重複的元素，讓每個值只出現一次。回傳處理後的串列（仍然有序）。

和第 82 題的關鍵差異：頭節點永遠保留

1 -> 1 -> 2 -> 3 -> 3 第 83 題（本題，每個值留一個）： 1 -> 2 -> 3 第 82 題（有重複的全刪）： 2 因為本題「每組保留第一個」，所以： 頭節點【永遠】會被保留（它是它那一組的第一個） -> 不需要 dummy node -> 不需要 prev 指標 程式碼從第 82 題的 14 行降到 7 行。 這是一個很好的對照： 「規格上一個小小的差別（留一個 vs 全刪）」 造成「實作上一整個資料結構（dummy node）的有無」。

範例

範例 1 輸入：head = [1,1,2] 輸出：[1,2] 範例 2 輸入：head = [1,1,2,3,3] 輸出：[1,2,3]

限制條件

  • 串列節點數在 [0, 300] 範圍內
  • −100 ≤ Node.val ≤ 100
  • 串列已依升序排好

LeetCode 原題

先看懂限制在說什麼

  • 已排序 —— 相同的值連續，所以只要和「下一個」比。
  • 可以是空串列 → 回傳 None。while cur and cur.next 自然處理。
  • 結果永遠非空（只要輸入非空）—— 和第 82 題不同。

解題思路

一個指標掃過去，看到「下一個和我一樣」就把它跳過。關鍵是：跳過之後不能前進，因為新的「下一個」可能還是一樣。

解法一

單指標掃描（標準解）

class Solution: def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]: cur = head while cur and cur.next: if cur.val == cur.next.val: cur.next = cur.next.next # 跳過下一個（不前進，可能還有更多重複） else: cur = cur.next return head

為什麼刪掉之後 cur 不能前進？

1 -> 1 -> 1 cur 在第一個 1： cur.val == cur.next.val -> cur.next = 第三個 1 現在是 1 -> 1（第一個和第三個） 如果 cur 前進了： cur 會跳到第三個 1，而串列還是 1 -> 1 ✘ 正確做法（cur 不動）： cur 還在第一個 1 cur.val == cur.next.val -> cur.next = None 現在是 1 ✔ 一句話： 刪除一個節點之後，「下一個」變成了新的節點， 必須重新檢查它。 這和第 27 題（Remove Element）的「從尾巴填坑」是同一個道理 —— 只要「搬進來的東西還沒檢查過」，指標就不能前進。

while cur and cur.next 的兩個條件

cur：處理空串列。cur.next：處理「走到最後一個節點」（沒有下一個可以比）。順序不能換 —— Python 的短路求值保證 cur 是 None 時不會去讀 cur.next。

七行、O(1) 空間、一趟掃完。這是鏈結串列題裡最乾淨的一題。

複雜度說明
時間O(n)每個節點最多看兩次
空間O(1)只用一個指標
解法二

遞迴（三行核心）

class Solution: def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]: if not head or not head.next: return head head.next = self.deleteDuplicates(head.next) # 後面處理好之後，如果新的 next 和自己同值，就把它跳過 return head.next if head.val == head.next.val else head
語意：「先把後面處理乾淨，再看自己要不要被合併掉」 deleteDuplicates([1,1,2]) head = 第一個 1 head.next = deleteDuplicates([1,2]) head = 第二個 1 head.next = deleteDuplicates([2]) = [2] 1 != 2 -> return 第二個 1（也就是 [1,2]） 現在 head.next 是第二個 1 head.val(1) == head.next.val(1) -> return head.next 也就是回傳 [1,2] ✔（第一個 1 被跳過了） 注意這裡「保留的是後面那個」而不是前面那個 —— 但因為值相同，輸出看不出差別。 如果節點帶著其他資料（例如 (值, 標籤)）， 「保留哪一個」就有差別了 —— 那時要改成保留 head 並接上 head.next.next。

只有三行核心邏輯。但它有 O(n) 的遞迴深度 —— n = 300 沒問題，更大就會爆。

複雜度說明
時間O(n)每個節點一層遞迴
空間O(n)遞迴堆疊

邊界條件檢查清單

  • 空串列：[] → []。
  • 單一節點：[1] → [1]。
  • 全部相同：[1,1,1] → [1]。「刪除後 cur 不前進」在這裡至關重要。
  • 沒有重複：[1,2,3] → 原樣。
  • 成對重複：[1,1,2,2,3,3] → [1,2,3]。
  • 結尾有重複：[1,2,2] → [1,2]。最後 cur.next 變成 None，迴圈正確結束。

常見追問

追問一：如果要「有重複的全部刪掉」呢？

第 82 題。需要 dummy node 和 prev 指標，程式碼長一倍。兩題放在一起寫一次，就能清楚感受到「規格差一句話，實作差一個資料結構」。

追問二：如果串列沒有排序呢？

用一個 set 記錄看過的值，遇到看過的就跳過。空間從 O(1) 變成 O(不同值的個數)。「已排序」在這裡的價值就是那個 set。

追問三：Python 的 itertools.groupby 可以用嗎？

如果先把串列轉成 list，可以 —— 但那就失去「原地操作串列」的意義了，而且空間變成 O(n)。串列題的重點通常是「指標操作」而不是「結果對不對」。

追問四：這題為什麼常被當成串列的入門題？

因為它只需要一個指標、一個 if、一個 while —— 但它已經包含了串列操作的核心觀念：

  • 「刪除節點」= 讓前一個節點跳過它
  • 刪除之後指標要不要前進（狀態是否改變）
  • 邊界條件（空串列、最後一個節點）

把這三件事想清楚，第 19、82、203、237 題就都會了。
