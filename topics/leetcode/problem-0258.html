LeetCode 258

Add Digits
各位相加

Easy · 簡單 數學 數論 模擬

Problem

Given an integer num, repeatedly add all its digits until the result has only one digit, and return it.

Follow up: Could you do it without any loop/recursion in O(1) runtime?

中文翻譯

給你一個非負整數 num，反覆把它的各位數字相加，直到結果只剩一位數，回傳這個結果。

進階：能不用迴圈或遞迴，在 O(1) 時間內完成嗎？

範例

範例 1 輸入：num = 38 輸出：2 說明：3 + 8 = 11，1 + 1 = 2 範例 2 輸入：num = 0 輸出：0

限制條件

  • 0 ≤ num ≤ 2³¹ − 1

LeetCode 原題

解題思路

【為什麼數字和和 mod 9 有關？】 10 = 9 + 1 ≡ 1 (mod 9) 100 = 99 + 1 ≡ 1 (mod 9) 所以 abc = 100a + 10b + c ≡ a + b + c (mod 9) 「加總各位數」不會改變 mod 9 的值！ 反覆做下去，最後剩一位數 d（1..9），而 d ≡ num (mod 9)。 【對應關係】 num mod 9 = 1..8 -> 答案就是 1..8 num mod 9 = 0 -> 答案是 9（num > 0 時） num = 0 -> 答案 0 合併寫法：1 + (num - 1) % 9（num > 0） 【這叫做「數根」(digital root)】 小學的「棄九法」驗算乘法也是這個原理： a × b = c => 數根(a) × 數根(b) 的數根 = 數根(c)

解法一

模擬

class Solution: def addDigits(self, num: int) -> int: while num >= 10: num = sum(int(d) for d in str(num)) # 反覆加總各位數 return num
複雜度說明
時間O(log n)數字和很快就變小
空間O(1)
解法二

數根公式

class Solution: def addDigits(self, num: int) -> int: # ★ 數根：10 ≡ 1 (mod 9)，所以「數字和」和原數 mod 9 相同 if num == 0: return 0 return 1 + (num - 1) % 9
複雜度說明
時間O(1)
空間O(1)
