Kth Smallest Element in a BST
二元搜尋樹中第 K 小的元素

Medium · 中等 樹 深度優先搜尋 二元搜尋樹 二元樹

Problem

Given the root of a binary search tree, and an integer k, return the kth smallest value (1-indexed) of all the values of the nodes in the tree.

Follow up: If the BST is modified often (i.e., we can do insert and delete operations) and you need to find the kth smallest frequently, how would you optimize?

中文翻譯

給你一棵二元搜尋樹的根節點 root 和整數 k，回傳樹中第 k 小的值（從 1 開始數）。

進階：如果這棵樹經常被修改（插入、刪除），而且需要頻繁查詢第 k 小，要怎麼優化？

範例

範例 1 輸入：root = [3,1,4,null,2], k = 1 輸出：1 範例 2 輸入：root = [5,3,6,2,4,null,null,1], k = 3 輸出：3

限制條件

  • 節點數為 n
  • 1 ≤ k ≤ n ≤ 10⁴
  • 0 ≤ Node.val ≤ 10⁴

LeetCode 原題

解題思路

【BST 的中序遍歷 = 由小到大排序】 左子樹 < 根 < 右子樹 中序（左 -> 根 -> 右）走出來就是遞增序列。 第 k 個拜訪到的節點 = 第 k 小 ✔ 【提早停止】 不用走完整棵樹，數到 k 就回傳。 用迭代的中序（手動堆疊），時間 O(h + k)： 先往左走到底花 O(h)，之後每 pop 一次就前進一個。 【進階：樹常常變動】 每個節點多存一個「子樹大小」size。 在節點 node： left = 左子樹大小 k <= left -> 答案在左子樹 k == left + 1 -> 就是 node 否則 -> 去右子樹找第 (k - left - 1) 小 每次查詢 O(h)；插入、刪除時沿路更新 size，也是 O(h)。 搭配平衡樹（紅黑樹、AVL）h = O(log n)。 這種樹叫「順序統計樹」(order statistic tree)。
解法一

中序遍歷（產生器，提早停止）

class Solution: def kthSmallest(self, root: Optional[TreeNode], k: int) -> int: def inorder(node): if node: yield from inorder(node.left) yield node.val yield from inorder(node.right) for i, v in enumerate(inorder(root), 1): # 產生器：拿到第 k 個就停 if i == k: return v
複雜度說明
時間O(h + k)
空間O(h)
解法二

迭代中序（手動堆疊）

class Solution: def kthSmallest(self, root: Optional[TreeNode], k: int) -> int: stack = [] node = root while True: while node: # 一路往左，沿途推進堆疊 stack.append(node) node = node.left node = stack.pop() # ★ 中序的下一個（由小到大） k -= 1 if k == 0: return node.val # 第 k 個就停，不必走完整棵樹 node = node.right
【迭代中序的模板】 1. 一路往左，沿途推進堆疊 2. pop 出來 = 下一個最小的 3. 轉到它的右子樹，回到步驟 1
複雜度說明
時間O(h + k)
空間O(h)
解法三

子樹大小（進階問題）

class Solution: def kthSmallest(self, root: Optional[TreeNode], k: int) -> int: size = {} # 節點 -> 子樹大小（樹常常變動時，存在節點上維護） def count(node): if node is None: return 0 size[node] = 1 + count(node.left) + count(node.right) return size[node] count(root) node = root while node: left = size.get(node.left, 0) if k <= left: # 在左子樹 node = node.left elif k == left + 1: # 就是自己 return node.val else: # 在右子樹：扣掉左子樹和自己 k -= left + 1 node = node.right

這裡為了示範，先 O(n) 算出所有子樹大小；實際應用中 size 存在節點上，隨插入刪除維護，每次查詢只要 O(h)。

複雜度說明
時間查詢 O(h)預處理 O(n)
空間O(n)

解法對照

解法時間空間適合
一、遞迴中序O(h + k)O(h)單次查詢
二、迭代中序O(h + k)O(h)單次查詢 ✔
三、子樹大小O(h) / 次O(n)樹常變動、查詢頻繁

邊界條件檢查清單

  • k = 1 → 最左邊的節點。
  • k = n → 最右邊的節點，要走完整棵樹。
  • 樹是一條鏈 → h = n，堆疊深度 n。

常見追問

追問：第 k 大？

反向中序（右 → 根 → 左），或找第 n − k + 1 小。
