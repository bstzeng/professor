LeetCode 344

Reverse String
反轉字串

Easy · 簡單 雙指標 字串

Problem

Write a function that reverses a string. The input string is given as an array of characters s.

You must do this by modifying the input array in-place with O(1) extra memory.

中文翻譯

寫一個函式把字串反轉。輸入是一個字元陣列 s。

必須原地修改輸入陣列，只能用 O(1) 額外空間。

範例

範例 1 輸入：s = ["h","e","l","l","o"] 輸出：["o","l","l","e","h"] 範例 2 輸入：s = ["H","a","n","n","a","h"] 輸出：["h","a","n","n","a","H"]

限制條件

  • 1 ≤ s.length ≤ 10⁵
  • s[i] 是可列印的 ASCII 字元

LeetCode 原題

解題思路

【雙指標】 i 從頭、j 從尾，交換後各往中間走一步，直到相遇。 只需要 n/2 次交換。 【Python 的陷阱】 s = s[::-1] ✘ 只是讓區域變數 s 指向新串列，原本的串列沒變 s[:] = s[::-1] ✔ 切片賦值，把原串列的內容換掉 s.reverse() ✔ 內建的原地反轉 （嚴格來說 s[::-1] 會先建立一個 O(n) 的新串列。）
解法一

雙指標交換

class Solution: def reverseString(self, s: List[str]) -> None: """ Do not return anything, modify s in-place instead. """ i, j = 0, len(s) - 1 while i < j: # ★ 頭尾交換，往中間靠 s[i], s[j] = s[j], s[i] i += 1 j -= 1
複雜度說明
時間O(n)
空間O(1)
解法二

Python 切片賦值

class Solution: def reverseString(self, s: List[str]) -> None: s[:] = s[::-1] # 切片賦值：原地改內容（s = s[::-1] 只是改變區域變數 ✘）
複雜度說明
時間O(n)
空間O(n)暫時的反轉副本

解法對照

解法時間空間
一、雙指標O(n)O(1) ✔
二、切片O(n)O(n)

邊界條件檢查清單

  • 長度 1 → 不變。
  • 奇數長度 → 中間的字元不動。
