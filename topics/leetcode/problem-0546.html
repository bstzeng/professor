LeetCode 546

Remove Boxes
移除盒子

Hard · 困難 記憶化搜尋 陣列 動態規劃

Problem

You are given several boxes with different colors represented by different positive numbers.

You may experience several rounds to remove boxes until there is no box left. Each time you can choose some continuous boxes with the same color (i.e., composed of k boxes, k >= 1), remove them and get k * k points.

Return the maximum points you can get.

中文翻譯

給你一排不同顏色的盒子 boxes（正整數代表顏色）。每一輪可以移除連續且同色的 k 個盒子（k ≥ 1），得到 k × k 分。

重複直到沒有盒子，回傳可以得到的最高總分。

範例

範例 1 輸入：boxes = [1,3,2,2,2,3,4,3,1] 輸出：23 範例 2 輸入：boxes = [1,1,1] 輸出：9 範例 3 輸入：boxes = [1] 輸出：1

限制條件

  • 1 ≤ boxes.length ≤ 100
  • 1 ≤ boxes[i] ≤ 100

LeetCode 原題

解題思路

【為什麼一般區間 DP 不夠？】 dp(l, r) 只看 boxes[l..r] 本身， 但分數取決於「同色的能不能湊在一起再一起消」—— 這可能和區間外的盒子有關。 【多加一維：右邊黏著幾個同色】 dp(l, r, k) = 處理 boxes[l..r]， 而且 boxes[r] 右邊還黏著 k 個同色盒子（之後一定和它一起消）。 【兩種選擇】 1. 現在就把 boxes[r] 連同黏著的 k 個一起消： (k+1)² + dp(l, r-1, 0) 2. 在 l..r-1 中找一個同色的 boxes[i]， 先把中間 i+1..r-1 全部消掉，讓 boxes[i] 和 boxes[r] 接起來： dp(i+1, r-1, 0) + dp(l, i, k+1) 【小最佳化】 先把 r 左邊連續同色的吸進 k，減少重複狀態。
解法

三維區間 DP（記憶化）

class Solution: def removeBoxes(self, boxes: List[int]) -> int: @cache def dp(l, r, k): # boxes[l..r]，而且 boxes[r] 的右邊還「黏著」k 個和 boxes[r] 同色的盒子 if l > r: return 0 while l < r and boxes[r - 1] == boxes[r]: # 把同色的往左吸進來 r -= 1 k += 1 # 選擇一：現在就把 boxes[r] 和黏著的 k 個一起移除 res = dp(l, r - 1, 0) + (k + 1) ** 2 # ★ 選擇二：先清掉中間 (i+1..r-1)，讓 boxes[i] 和 boxes[r] 接在一起 for i in range(l, r): if boxes[i] == boxes[r]: res = max(res, dp(l, i, k + 1) + dp(i + 1, r - 1, 0)) return res return dp(0, len(boxes) - 1, 0)

驗證方式：和窮舉所有消除順序的暴力法比對 400 組。

複雜度說明
時間O(n⁴)狀態 n³、轉移 O(n)
空間O(n³)

邊界條件檢查清單

  • 全同色 → n²。
  • 全部不同色 → n。
