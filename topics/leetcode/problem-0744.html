LeetCode 744

Find Smallest Letter Greater Than Target
尋找比目標字母大的最小字母

Easy · 簡單 陣列 二分搜尋

Problem

You are given an array of characters letters that is sorted in non-decreasing order, and a character target. There are at least two different characters in letters.

Return the smallest character in letters that is lexicographically greater than target. If such a character does not exist, return the first character in letters.

中文翻譯

給你一個非遞減排序的字元陣列 letters（至少有兩種不同字元）和字元 target，回傳陣列中大於 target 的最小字元。

如果不存在，回傳 letters 的第一個字元。

範例

範例 1 輸入：letters = ["c","f","j"], target = "a" 輸出："c" 範例 2 輸入：letters = ["c","f","j"], target = "c" 輸出："f" 範例 3 輸入：letters = ["x","x","y","y"], target = "z" 輸出："x"

限制條件

  • 2 ≤ letters.length ≤ 10⁴
  • letters[i] 是小寫英文字母
  • letters 已依非遞減順序排序
  • letters contains at least two different characters.
  • target 是小寫英文字母

LeetCode 原題

解題思路

【「第一個 > target」= upper bound】 bisect_right(letters, target)。 target 重複出現時，bisect_right 會跳過所有等於它的。 【找不到】 索引等於長度 -> 回傳 letters[0]。 用 i % len 一行處理。
解法

二分（upper bound）

class Solution: def nextGreatestLetter(self, letters: List[str], target: str) -> str: i = bisect.bisect_right(letters, target) # 第一個 > target 的位置 return letters[i % len(letters)] # ★ 找不到就繞回第一個
複雜度說明
時間O(log n)
空間O(1)

邊界條件檢查清單

  • target 比所有字元都大 → letters[0]。
  • 重複字元 → bisect_right 跳過所有相等的。

常見追問

lower bound vs upper bound

bisect_left：第一個 ≥ x 的位置；bisect_right：第一個 > x 的位置。兩者相減就是 x 出現的次數。
