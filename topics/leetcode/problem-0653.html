LeetCode 653

Two Sum IV - Input is a BST
兩數之和 IV - 輸入二元搜尋樹

Easy · 簡單 樹 深度優先搜尋 廣度優先搜尋 二元搜尋樹

Problem

Given the root of a binary search tree and an integer k, return true if there exist two elements in the BST such that their sum is equal to k, or false otherwise.

中文翻譯

給你一棵二元搜尋樹的根節點和整數 k，判斷樹中是否存在兩個不同的節點，它們的值相加等於 k。

範例

範例 1 輸入：root = [5,3,6,2,4,null,7], k = 9 輸出：true 範例 2 輸入：root = [5,3,6,2,4,null,7], k = 28 輸出：false

限制條件

  • 節點數在 [1, 10⁴] 範圍內
  • -10⁴ ≤ Node.val ≤ 10⁴
  • root 保證是合法的二元搜尋樹
  • -10⁵ ≤ k ≤ 10⁵

LeetCode 原題

解題思路

【第 1 題的翻版】 走訪每個節點，查 k - val 是否看過，再把 val 加進集合。 這對任何二元樹都成立。 【利用 BST】 中序走訪得到有序陣列，再用雙指標（第 167 題）。 進階：用兩個迭代器（一個正向中序、一個反向中序）做雙指標， 只需 O(h) 額外空間。
解法

走訪 + 雜湊集合

class Solution: def findTarget(self, root: Optional[TreeNode], k: int) -> bool: seen = set() stack = [root] while stack: nd = stack.pop() if not nd: continue if k - nd.val in seen: return True # ★ 和兩數之和一樣：找之前出現過的互補值 seen.add(nd.val) stack += [nd.left, nd.right] return False
複雜度說明
時間O(n)
空間O(n)

邊界條件檢查清單

  • 同一個節點用兩次 → 不行；先查再加入就自然避免。
  • 只有一個節點 → False。
