LeetCode 231

Power of Two
2 的冪

Easy · 簡單 位元運算 遞迴 數學

Problem

Given an integer n, return true if it is a power of two. Otherwise, return false.

An integer n is a power of two if there exists an integer x such that n == 2x.

Follow up: Could you solve it without loops/recursion?

中文翻譯

給你一個整數 n，判斷它是不是 2 的冪次。

如果存在整數 x 使得 n == 2x，n 就是 2 的冪次。

進階：能不用迴圈或遞迴嗎？

範例

範例 1 輸入：n = 1 輸出：true 說明：2⁰ = 1 範例 2 輸入：n = 16 輸出：true 範例 3 輸入：n = 3 輸出：false

限制條件

  • −2³¹ ≤ n ≤ 2³¹ − 1

LeetCode 原題

解題思路

【2 的冪次在二進位中長什麼樣子？】 1 = 1, 2 = 10, 4 = 100, 8 = 1000 ... 恰好只有【一個】位元是 1。 【n & (n - 1) 清掉最低位的 1】 n = ...1000 n - 1 = ...0111 AND = ...0000 只有一個 1 的數，清掉之後就是 0。 【一定要先檢查 n > 0】 n = 0：0 & (-1) = 0，會被誤判 ✘ 負數：永遠不是 2 的冪次。 【另一個技巧：n & -n】 二補數中 -n = ~n + 1， n & -n 只保留最低位的 1（這個值叫 lowbit，樹狀陣列會用到）。 只有一個 1 的數，lowbit 就是它自己。
解法一

一直除以 2

class Solution: def isPowerOfTwo(self, n: int) -> bool: if n <= 0: return False while n % 2 == 0: # 一直除以 2 n //= 2 return n == 1
複雜度說明
時間O(log n)
空間O(1)
解法二

n & (n − 1)

class Solution: def isPowerOfTwo(self, n: int) -> bool: # ★ 2 的冪次在二進位中只有一個 1；n & (n-1) 會把最低位的 1 清掉 return n > 0 and n & (n - 1) == 0
複雜度說明
時間O(1)
空間O(1)
解法三

n & −n（lowbit）

class Solution: def isPowerOfTwo(self, n: int) -> bool: return n > 0 and n & -n == n # n & -n：只保留最低位的 1
複雜度說明
時間O(1)
空間O(1)
解法四

最大的 2 的冪次能否被 n 整除

class Solution: def isPowerOfTwo(self, n: int) -> bool: # 範圍內最大的 2 的冪次是 2^30；n 是 2 的冪次 <=> n 整除 2^30 return n > 0 and (1 << 30) % n == 0

2³⁰ 的因數只有 2⁰、2¹、…、2³⁰（質因數分解只有 2）。這個技巧對任何質數的冪次都適用（第 326 題的 3 的冪次也能這樣做）。

複雜度說明
時間O(1)
空間O(1)

解法時間備註

邊界條件檢查清單

  • n = 0 → false（位元解法一定要先檢查 n > 0）。
  • n = 1 → true（2⁰）。
  • 負數 → false；−2³¹ 在二補數中只有一個 1，但不是 2 的冪次。
