LeetCode 389

Find the Difference
找不同

Easy · 簡單 位元運算 雜湊表 字串 排序

Problem

You are given two strings s and t.

String t is generated by random shuffling string s and then add one more letter at a random position.

Return the letter that was added to t.

中文翻譯

給你兩個字串 s 和 t。t 是把 s 隨機打亂後，再在隨機位置多加一個字母得到的。

回傳多加的那個字母。

範例

範例 1 輸入：s = "abcd", t = "abcde" 輸出："e" 範例 2 輸入：s = "", t = "y" 輸出："y"

限制條件

  • 0 ≤ s.length ≤ 1000
  • t.length == s.length + 1
  • 只包含小寫英文字母

LeetCode 原題

解題思路

【三種想法，都是「抵銷」】 計數：t 的計數 - s 的計數，剩下的那個。 求和：t 所有字元碼的和 - s 所有字元碼的和 = 多出來的字元碼。 XOR：把 s 和 t 所有字元碼全部 XOR， 成對的 x ^ x = 0 抵銷，只剩多出來的那一個 （第 136 題「只出現一次的數字」的同一招）。
解法一

計數

class Solution: def findTheDifference(self, s: str, t: str) -> str: return next(iter(collections.Counter(t) - collections.Counter(s)))
複雜度說明
時間O(n)
空間O(1)最多 26 種
解法二

字元碼求和

class Solution: def findTheDifference(self, s: str, t: str) -> str: return chr(sum(map(ord, t)) - sum(map(ord, s))) # 字元碼總和的差
複雜度說明
時間O(n)
空間O(1)
解法三

XOR

class Solution: def findTheDifference(self, s: str, t: str) -> str: x = 0 for ch in s + t: # ★ 成對的字元 XOR 後抵銷，只剩多出來的那個 x ^= ord(ch) return chr(x)
複雜度說明
時間O(n)
空間O(1)

解法對照

解法時間空間
一、計數O(n)O(1)
二、求和O(n)O(1)
三、XORO(n)O(1) ✔

邊界條件檢查清單

  • s 是空字串 → t 就是答案。
  • 多出來的字母和已有的重複 → 計數、求和、XOR 都照樣正確。
