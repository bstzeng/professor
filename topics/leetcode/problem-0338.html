LeetCode 338

Counting Bits
位元計數

Easy · 簡單 動態規劃 位元運算

Problem

Given an integer n, return an array ans of length n + 1 such that for each i (0 <= i <= n), ans[i] is the number of 1's in the binary representation of i.

Follow up: It is very easy to come up with a solution with a runtime of O(n log n). Can you do it in linear time O(n) and possibly in a single pass? Can you do it without using any built-in function (i.e., like __builtin_popcount in C++)?

中文翻譯

給你整數 n，回傳長度 n + 1 的陣列 ans，ans[i] 是 i 的二進位表示中 1 的個數（0 ≤ i ≤ n）。

進階：O(n log n) 很容易，能做到 O(n) 嗎？能不用內建的 popcount 函式嗎？

範例

範例 1 輸入：n = 2 輸出：[0,1,1] 範例 2 輸入：n = 5 輸出：[0,1,1,2,1,2] 說明：0, 1, 10, 11, 100, 101

限制條件

  • 0 ≤ n ≤ 10⁵

解題思路

【用前面算過的答案 —— DP】 【方法一：右移一位】 i >> 1 就是把 i 的最低位去掉： i = 1011 (11) i >> 1 = 101 (5) 所以 ans[i] = ans[i >> 1] + (i 的最低位) i >> 1 < i，一定已經算過了。 【方法二：清掉最低位的 1】 i & (i - 1) 會把 i 最低位的 1 變成 0（第 231 題用過）： i = 1100 (12) i & (i-1) = 1000 (8) 所以 ans[i] = ans[i & (i - 1)] + 1 【規律】 偶數 2k：和 k 的 1 個數相同（多一個 0 在後面） 奇數 2k+1：比 k 多一個

解法一

逐一計算

class Solution: def countBits(self, n: int) -> List[int]: return [bin(i).count("1") for i in range(n + 1)]
複雜度說明
時間O(n log n)不計輸出
空間O(1)
解法二

DP：清掉最低位的 1

class Solution: def countBits(self, n: int) -> List[int]: ans = [0] * (n + 1) for i in range(1, n + 1): ans[i] = ans[i & (i - 1)] + 1 # 清掉最低位的 1，少一個 1 return ans
複雜度說明
時間O(n)
空間O(1)不計輸出
解法三

DP：右移一位

class Solution: def countBits(self, n: int) -> List[int]: ans = [0] * (n + 1) for i in range(1, n + 1): # ★ i >> 1 已經算過了；i 比它多的只有最低位 ans[i] = ans[i >> 1] + (i & 1) return ans
複雜度說明
時間O(n)
空間O(1)不計輸出
