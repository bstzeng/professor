Find Bottom Left Tree Value
找樹左下角的值

Medium · 中等 樹 深度優先搜尋 廣度優先搜尋 二元樹

Problem

Given the root of a binary tree, return the leftmost value in the last row of the tree.

中文翻譯

給你二元樹的根節點，回傳最底層中最左邊節點的值。樹至少有一個節點。

範例

範例 1 輸入：root = [2,1,3] 輸出：1 範例 2 輸入：root = [1,2,3,4,null,5,6,null,null,7] 輸出：7

限制條件

  • 節點數在 [1, 10⁴] 範圍內
  • -2³¹ ≤ Node.val ≤ 2³¹ - 1

LeetCode 原題

解題思路

【一般想法】 層序走訪，記錄每一層的第一個節點，最後一層的第一個就是答案。 【更簡潔的技巧：先右後左】 BFS 時每個節點先放右孩子、再放左孩子。 這樣同一層裡是「由右到左」出佇列， 整個走訪的最後一個節點 = 最底層的最左邊。 不用另外記錄層數。 【DFS 也行】 前序走訪（先左後右），第一次到達新的深度時記下值； 最深那一層第一個被記下的就是最左邊。
解法

BFS 先右後左

class Solution: def findBottomLeftValue(self, root: Optional[TreeNode]) -> int: q = deque([root]) while q: nd = q.popleft() # ★ 先右後左：最後一個被取出的節點，就是最底層最左邊的 if nd.right: q.append(nd.right) if nd.left: q.append(nd.left) return nd.val
複雜度說明
時間O(n)
空間O(w)w 為最寬一層的節點數

邊界條件檢查清單

  • 只有根節點 → 根的值。
  • 最底層只有右孩子 → 「最左邊」是那一層最左的節點，不一定是左孩子。
