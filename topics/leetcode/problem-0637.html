Average of Levels in Binary Tree
二元樹的層平均值

Easy · 簡單 樹 深度優先搜尋 廣度優先搜尋 二元樹

Problem

Given the root of a binary tree, return the average value of the nodes on each level in the form of an array. Answers within 10-5 of the actual answer will be accepted.

中文翻譯

給你二元樹的根節點，回傳每一層節點值的平均值組成的陣列（與標準答案相差 10⁻⁵ 以內都算正確）。

範例

範例 1 輸入：root = [3,9,20,null,null,15,7] 輸出：[3.00000,14.50000,11.00000] 範例 2 輸入：root = [3,9,20,15,7] 輸出：[3.00000,14.50000,11.00000]

限制條件

  • 節點數在 [1, 10⁴] 範圍內
  • -2³¹ ≤ Node.val ≤ 2³¹ - 1

LeetCode 原題

解題思路

【層序走訪】 每一層：sum / len，再換到下一層。 【溢位？】 其他語言要注意節點值累加可能超過 32 位元整數， Python 的整數沒有上限。
解法

逐層 BFS

class Solution: def averageOfLevels(self, root: Optional[TreeNode]) -> List[float]: res, level = [], [root] while level: res.append(sum(nd.val for nd in level) / len(level)) # 這一層的平均 level = [c for nd in level for c in (nd.left, nd.right) if c] return res
複雜度說明
時間O(n)
空間O(w)

邊界條件檢查清單

  • 大數值 → 其他語言要用 64 位元累加。
