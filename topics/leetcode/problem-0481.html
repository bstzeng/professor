Magical String
神奇字串

Medium · 中等 雙指標 字串

Problem

A magical string s consists of only '1' and '2' and obeys the following rules:

  • The string s is magical because concatenating the number of contiguous occurrences of characters '1' and '2' generates the string s itself.

The first few elements of s is s = "1221121221221121122……". If we group the consecutive 1's and 2's in s, it will be "1 22 11 2 1 22 1 22 11 2 11 22 ......" and the occurrences of 1's or 2's in each group are "1 2 2 1 1 2 1 2 2 1 2 2 ......". You can see that the occurrence sequence is s itself.

Given an integer n, return the number of 1's in the first n number in the magical string s.

中文翻譯

神奇字串 s 只由 1 和 2 組成，而且「把連續相同的字元分組，每組的長度依序排出來」剛好就是 s 本身。

s = "1221121221221121122……"，分組是 1 22 11 2 1 22 1 22 11 2 11 22……，各組長度 1 2 2 1 1 2 1 2 2 1 2 2…… 正是 s。

回傳 s 前 n 個字元中有幾個 1。

範例

範例 1 輸入：n = 6 輸出：3 說明：前 6 個是 "122112"，有 3 個 1。 範例 2 輸入：n = 1 輸出：1

限制條件

  • 1 ≤ n ≤ 10⁵

LeetCode 原題

解題思路

【字串自己描述自己 -> 一邊讀一邊產生】 s[i] 告訴我們「第 i 組」有幾個字元； 組與組之間 1、2 交替。 從 s = [1, 2, 2] 開始，i = 2（第 2 組還沒生成）： s[2] = 2 -> 下一組是兩個「1」（和上一個 2 相反）-> [1,2,2,1,1] s[3] = 1 -> 下一組是一個「2」 -> [1,2,2,1,1,2] s[4] = 1 -> 下一組是一個「1」 -> ... 【為什麼讀取指標不會追上寫入？】 每一組至少 1 個字元，寫入的速度 >= 讀取的速度。
解法

雙指標：讀取組長、寫入新組

class Solution: def magicalString(self, n: int) -> int: s = [1, 2, 2] i = 2 # ★ s[i] 告訴我們「下一組」要放幾個 while len(s) < n: nxt = 3 - s[-1] # 下一組的數字：1 和 2 交替 s.extend([nxt] * s[i]) i += 1 return s[:n].count(1)

驗證方式：產生前兩萬個字元，確認它的「連續段長度序列」就是它自己。

複雜度說明
時間O(n)
空間O(n)

邊界條件檢查清單

  • n ≤ 3 → 直接從前三個字元算。
  • 產生的長度可能超過 n → 最後只取前 n 個。
