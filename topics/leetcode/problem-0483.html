LeetCode 483

Smallest Good Base
最小好進位

Hard · 困難 數學 二分搜尋

Problem

Given an integer n represented as a string, return the smallest good base of n.

We call k >= 2 a good base of n, if all digits of n base k are 1's.

中文翻譯

給你一個以字串表示的整數 n，回傳它的最小好進位。

如果 n 在 k 進位（k ≥ 2）下每一位都是 1，就說 k 是 n 的好進位。

範例

範例 1 輸入：n = "13" 輸出："3" 說明：13 在 3 進位是 111。 範例 2 輸入：n = "4681" 輸出："8" 說明：4681 在 8 進位是 11111。 範例 3 輸入：n = "1000000000000000000" 輸出："999999999999999999" 說明：在 999999999999999999 進位是 11。

限制條件

  • n 是 [3, 10¹⁸] 之間的整數
  • 沒有前導零

LeetCode 原題

解題思路

【n = 1 + k + k² + ... + k^(m-1)】（m 個 1） 【進位越小，位數越多】 k = 2 時位數最多：m 最多約 log₂ n ≈ 60。 從最大的 m 往下試，第一個找得到整數 k 的就是最小的 k。 【給定 m，k 是多少？】 k^(m-1) < n < (k+1)^(m-1)（二項式展開可以證明） -> k = ⌊n^(1/(m-1))⌋ 只要驗證這個 k 的 1 + k + ... + k^(m-1) 是否剛好等於 n。 （浮點數可能差 1，保險起見也試 k + 1；或對 k 二分搜尋。） 【一定有解】 m = 2："11" = 1 + k -> k = n - 1 永遠成立。
解法

枚舉位數 m，直接算出 k

class Solution: def smallestGoodBase(self, n: str) -> str: num = int(n) # ★ 位數 m 越多，進位制 k 越小 -> 從最多的位數開始試 for m in range(num.bit_length(), 1, -1): # m 個 1：1 + k + k² + ... + k^(m-1) k = int(num ** (1 / (m - 1))) # k 的候選（k^(m-1) < num < (k+1)^(m-1)） for cand in (k, k + 1): # 浮點誤差：試 k 和 k+1 if cand < 2: continue total, p = 0, 1 for _ in range(m): total += p p *= cand if total == num: return str(cand) return str(num - 1) # 兩位 "11"：k = num - 1 一定成立

驗證方式：3 到 3000 全部和「逐一試 k」的暴力法比對；再刻意構造「全 1」的大數。

複雜度說明
時間O(log² n)
空間O(1)

邊界條件檢查清單

  • n = 3 → 2（3 = 11₂）。
  • 只有兩位的解 → n − 1。
  • 浮點誤差 → n 接近 10¹⁸ 時 n^(1/(m−1)) 可能差 1，要驗證相鄰值。
