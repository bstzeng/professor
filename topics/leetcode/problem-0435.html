LeetCode 435

Non-overlapping Intervals
無重疊區間

Medium · 中等 貪心 陣列 動態規劃 排序

Problem

Given an array of intervals intervals where intervals[i] = [starti, endi], return the minimum number of intervals you need to remove to make the rest of the intervals non-overlapping.

Note that intervals which only touch at a point are non-overlapping. For example, [1, 2] and [2, 3] are non-overlapping.

中文翻譯

給你一組區間 intervals，回傳最少要刪掉幾個區間，才能讓剩下的區間互不重疊。

只在端點接觸的區間不算重疊，例如 [1, 2] 和 [2, 3]。

範例

範例 1 輸入：intervals = [[1,2],[2,3],[3,4],[1,3]] 輸出：1 說明：刪掉 [1,3]。 範例 2 輸入：intervals = [[1,2],[1,2],[1,2]] 輸出：2 範例 3 輸入：intervals = [[1,2],[2,3]] 輸出：0

限制條件

  • 1 ≤ intervals.length ≤ 10⁵
  • −5 × 10⁴ ≤ starti < endi ≤ 5 × 10⁴

LeetCode 原題

解題思路

【轉換：最少刪幾個 = 總數 - 最多能保留幾個互不重疊的】 這是經典的「活動選擇問題」。 【貪心：依結束時間排序，能選就選】 為什麼選「最早結束」的？ 假設最佳解的第一個區間不是最早結束的那個 X， 把它換成 X：X 結束得更早，不會和後面的衝突 -> 換完一樣是合法的最佳解。 所以選最早結束的永遠不吃虧。 【依開始時間排序行不行？】 可以，但遇到重疊時要保留「結束較早」的那個（刪掉結束晚的）， 邏輯比較繞。依結束時間排序最直接。 【端點相接不算重疊】 判斷用 s >= end（不是 s > end）。
解法

依結束時間排序的貪心

class Solution: def eraseOverlapIntervals(self, intervals: List[List[int]]) -> int: intervals.sort(key=lambda x: x[1]) # ★ 依「結束時間」排序 keep = 0 end = -float("inf") for s, e in intervals: if s >= end: # 和上一個保留的不重疊：保留 keep += 1 end = e return len(intervals) - keep # 刪掉的 = 總數 - 最多能保留的
複雜度說明
時間O(n log n)
空間O(1)不計排序

邊界條件檢查清單

  • 端點相接（[1,2]、[2,3]）→ 不算重疊。
  • 完全相同的區間 → 只能留一個。
  • 一個區間包住很多小區間 → 貪心會刪掉大的。
