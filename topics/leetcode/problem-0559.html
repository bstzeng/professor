Maximum Depth of N-ary Tree
N 叉樹的最大深度

Easy · 簡單 樹 深度優先搜尋 廣度優先搜尋

Problem

Given a n-ary tree, find its maximum depth.

The maximum depth is the number of nodes along the longest path from the root node down to the farthest leaf node.

Nary-Tree input serialization is represented in their level order traversal, each group of children is separated by the null value (See examples).

中文翻譯

給你一棵 N 叉樹的根節點，回傳它的最大深度：從根到最遠葉子節點經過的節點數。

範例

範例 1 輸入：root = [1,null,3,2,4,null,5,6] 輸出：3 範例 2 輸入：root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14] 輸出：5

限制條件

  • 節點總數在 [0, 10⁴] 範圍內
  • 樹的深度不超過 1000

LeetCode 原題

解題思路

【遞迴】 depth(nd) = 1 + max(depth(c) for c in nd.children) 葉子沒有孩子 -> max 的參數是空的，用 default=0。 【BFS】 一層一層走，數層數。
解法

遞迴

class Solution: def maxDepth(self, root: 'Node') -> int: if not root: return 0 return 1 + max((self.maxDepth(c) for c in root.children), default=0) # 沒有孩子時 max 用 default
複雜度說明
時間O(n)
空間O(h)

邊界條件檢查清單

  • 空樹 → 0。
  • 葉子 → max 的空序列要給 default。
