LeetCode 485

Max Consecutive Ones
最大連續 1 的個數

Easy · 簡單 陣列

Problem

Given a binary array nums, return the maximum number of consecutive 1's in the array.

中文翻譯

給你一個二進位陣列 nums，回傳其中連續 1 的最大個數。

範例

範例 1 輸入：nums = [1,1,0,1,1,1] 輸出：3 範例 2 輸入：nums = [1,0,1,1,0,1] 輸出：2

限制條件

  • 1 ≤ nums.length ≤ 10⁵
  • nums[i] 是 0 或 1

LeetCode 原題

解題思路

【一趟掃描】 cur = 目前這一段連續 1 的長度 遇到 1：cur + 1 遇到 0：cur 歸零 隨時更新最大值。
解法

一趟計數

class Solution: def findMaxConsecutiveOnes(self, nums: List[int]) -> int: best = cur = 0 for x in nums: cur = cur + 1 if x == 1 else 0 # ★ 遇到 0 就歸零 best = max(best, cur) return best
複雜度說明
時間O(n)
空間O(1)

邊界條件檢查清單

  • 全部是 0 → 0。
  • 全部是 1 → n。
