LeetCode 523

Continuous Subarray Sum
連續的子陣列和

Medium · 中等 陣列 雜湊表 數學 前綴和

Problem

Given an integer array nums and an integer k, return true if nums has a good subarray or false otherwise.

A good subarray is a subarray where:

  • its length is at least two, and
  • the sum of the elements of the subarray is a multiple of k.

Note that:

  • A subarray is a contiguous part of the array.
  • An integer x is a multiple of k if there exists an integer n such that x = n * k. 0 is always a multiple of k.

中文翻譯

給你整數陣列 nums 和整數 k，判斷是否存在長度至少為 2 的連續子陣列，其元素總和是 k 的倍數。

（0 也算是 k 的倍數。）

範例

範例 1 輸入：nums = [23,2,4,6,7], k = 6 輸出：true 範例 2 輸入：nums = [23,2,6,4,7], k = 6 輸出：true 範例 3 輸入：nums = [23,2,6,4,7], k = 13 輸出：false

限制條件

  • 1 ≤ nums.length ≤ 10⁵
  • 0 ≤ nums[i] ≤ 10⁹
  • 0 ≤ sum(nums[i]) ≤ 2³¹ - 1
  • 1 ≤ k ≤ 2³¹ - 1

LeetCode 原題

解題思路

【前綴和】 子陣列 nums[i+1..j] 的和 = P[j] - P[i]。 它是 k 的倍數 <=> P[j] ≡ P[i] (mod k)。 【雜湊表記「餘數第一次出現的位置」】 掃到 j 時，若 P[j] mod k 之前出現過（在位置 i）， 且 j - i >= 2，就找到了。 只記第一次出現：讓 i 盡量小，子陣列盡量長。 【空前綴】 first[0] = -1：讓「從頭開始的子陣列」也能被找到。 例如 [2, 4], k=6：P = 2, 6 -> 6%6 = 0，和 first[0] = -1 相距 2。
解法

前綴和餘數 + 雜湊表

class Solution: def checkSubarraySum(self, nums: List[int], k: int) -> bool: first = {0: -1} # 前綴和 mod k -> 第一次出現的位置（空前綴在 -1） s = 0 for i, x in enumerate(nums): s = (s + x) % k if s in first: if i - first[s] >= 2: # ★ 兩個前綴和同餘 -> 中間那段的和是 k 的倍數；長度至少 2 return True else: first[s] = i # 只記第一次：讓子陣列盡量長 return False
複雜度說明
時間O(n)
空間O(min(n, k))

邊界條件檢查清單

  • [0, 0] → True（0 是任何 k 的倍數）。
  • 單一元素是 k 的倍數 → 不算（長度至少 2）。
  • 覆蓋 first → 錯誤：會讓長度變短。
