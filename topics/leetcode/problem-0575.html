LeetCode 575

Distribute Candies
分糖果

Easy · 簡單 陣列 雜湊表

Problem

Alice has n candies, where the ith candy is of type candyType[i]. Alice noticed that she started to gain weight, so she visited a doctor.

The doctor advised Alice to only eat n / 2 of the candies she has (n is always even). Alice likes her candies very much, and she wants to eat the maximum number of different types of candies while still following the doctor's advice.

Given the integer array candyType of length n, return the maximum number of different types of candies she can eat if she only eats n / 2 of them.

中文翻譯

Alice 有 n 顆糖果（n 是偶數），candyType[i] 是第 i 顆的種類。醫生說她只能吃 n / 2 顆。她想吃到最多種類，回傳最多能吃到幾種。

範例

範例 1 輸入：candyType = [1,1,2,2,3,3] 輸出：3 範例 2 輸入：candyType = [1,1,2,3] 輸出：2 範例 3 輸入：candyType = [6,6,6,6] 輸出：1

限制條件

  • n == candyType.length
  • 2 ≤ n ≤ 10⁴
  • n is even.
  • -10⁵ ≤ candyType[i] ≤ 10⁵

LeetCode 原題

解題思路

【兩個上限】 最多吃 n/2 顆 -> 最多 n/2 種。 糖果只有 k 種 -> 最多 k 種。 答案 <= min(k, n/2)。 【一定達得到】 每種先挑一顆：若 k <= n/2，就能吃到全部 k 種； 若 k > n/2，挑 n/2 種各一顆即可。
解法

取兩個上限的最小值

class Solution: def distributeCandies(self, candyType: List[int]) -> int: return min(len(set(candyType)), len(candyType) // 2) # ★ 種類數和可吃數量的較小者
複雜度說明
時間O(n)
空間O(n)

邊界條件檢查清單

  • 全部同一種 → 1。
  • 全部不同 → n/2。

常見追問

上界 + 構造

先找出答案的上界，再構造一個方案證明上界可以達到——這是很多貪心題的證明方式。
