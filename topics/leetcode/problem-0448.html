LeetCode 448

Find All Numbers Disappeared in an Array
找到所有陣列中消失的數字

Easy · 簡單 陣列 雜湊表

Problem

Given an array nums of n integers where nums[i] is in the range [1, n], return an array of all the integers in the range [1, n] that do not appear in nums.

Follow up: Could you do it without extra space and in O(n) runtime? You may assume the returned list does not count as extra space.

中文翻譯

給你一個長度為 n 的陣列，每個數都在 [1, n] 之間，回傳 [1, n] 中所有沒出現在陣列裡的數。

進階：能不用額外空間、O(n) 時間嗎？（輸出不算）

範例

範例 1 輸入：nums = [4,3,2,7,8,2,3,1] 輸出：[5,6] 範例 2 輸入：nums = [1,1] 輸出：[2]

限制條件

  • n == nums.length
  • 1 ≤ n ≤ 10⁵
  • 1 ≤ nums[i] ≤ n

LeetCode 原題

解題思路

【和第 442 題同一招：陣列當雜湊表】 讀到 x，把位置 x-1 的值變成負數，代表「x 出現過」。 最後還是正數的位置 i -> i+1 沒出現過。 【細節】 - 讀值時要用 abs（可能已經被標成負的） - 已經是負的就不要再翻轉（否則會翻回正的）
解法一

集合

class Solution: def findDisappearedNumbers(self, nums: List[int]) -> List[int]: seen = set(nums) return [x for x in range(1, len(nums) + 1) if x not in seen]
複雜度說明
時間O(n)
空間O(n)
解法二

原地正負號標記

class Solution: def findDisappearedNumbers(self, nums: List[int]) -> List[int]: for x in nums: i = abs(x) - 1 if nums[i] > 0: nums[i] = -nums[i] # ★ 標記「值 i+1 出現過」 # 仍然是正數的位置 i，代表值 i+1 從來沒出現 return [i + 1 for i, v in enumerate(nums) if v > 0]
複雜度說明
時間O(n)
空間O(1)不計輸出

解法對照

解法時間空間
一、集合O(n)O(n)
二、原地標記O(n)O(1) ✔

邊界條件檢查清單

  • 沒有消失的數 → 空陣列。
  • 重複很多次 → 只要標記一次。

常見追問

另一種原地做法

把每個數加 n：nums[(x−1) % n] += n。最後 ≤ n 的位置就是沒出現的。好處是不用處理正負號。
