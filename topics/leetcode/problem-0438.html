LeetCode 438

Find All Anagrams in a String
找到字串中所有字母異位詞

Medium · 中等 雜湊表 字串 滑動視窗

Problem

Given two strings s and p, return an array of all the start indices of p's anagrams in s. You may return the answer in any order.

中文翻譯

給你兩個字串 s 和 p，找出 s 中所有是 p 的異位詞的子字串，回傳它們的起始索引。

範例

範例 1 輸入：s = "cbaebabacd", p = "abc" 輸出：[0,6] 說明："cba"、"bac" 範例 2 輸入：s = "abab", p = "ab" 輸出：[0,1,2]

限制條件

  • 1 ≤ s.length, p.length ≤ 3 × 10⁴
  • 只包含小寫英文字母

LeetCode 原題

解題思路

【固定長度的滑動視窗】 異位詞長度一定等於 len(p) -> 視窗長度固定為 k。 每次右邊進一個字元、左邊出一個字元， 比較視窗的字母計數和 p 的計數。 【比較的成本】 直接比較兩個 26 格陣列：每步 O(26)，總共 O(26n)。 更快：維護「有幾種字母的計數不一致」（diff）， 每次只有兩個字母的計數改變 -> O(1) 更新 diff， diff == 0 就是異位詞。
解法一

滑動視窗 + 比較計數陣列

class Solution: def findAnagrams(self, s: str, p: str) -> List[int]: k = len(p) if k > len(s): return [] need = [0] * 26 window = [0] * 26 for ch in p: need[ord(ch) - 97] += 1 res = [] for i, ch in enumerate(s): window[ord(ch) - 97] += 1 # 右邊進一個 if i >= k: window[ord(s[i - k]) - 97] -= 1 # 左邊出一個（視窗固定長度 k） if i >= k - 1 and window == need: # ★ 字母計數相同 = 異位詞 res.append(i - k + 1) return res
複雜度說明
時間O(26 · n)
空間O(1)
解法二

滑動視窗 + 維護不一致的數量

class Solution: def findAnagrams(self, s: str, p: str) -> List[int]: k = len(p) cnt = [0] * 26 # cnt = 視窗計數 - p 的計數 for ch in p: cnt[ord(ch) - 97] -= 1 diff = sum(1 for c in cnt if c) # 有幾個字母的計數不一致 res = [] def change(ch, d): nonlocal diff i = ord(ch) - 97 if cnt[i] == 0: diff += 1 cnt[i] += d if cnt[i] == 0: diff -= 1 for i, ch in enumerate(s): change(ch, 1) if i >= k: change(s[i - k], -1) if i >= k - 1 and diff == 0: # 每一步 O(1) 判斷 res.append(i - k + 1) return res
複雜度說明
時間O(n)
空間O(1)

解法對照

解法時間備註
一、比較陣列O(26n)最直觀 ✔
二、維護 diffO(n)字母表大時更好

邊界條件檢查清單

  • p 比 s 長 → 空陣列。
  • 重疊的答案（"abab"）→ 都要列出。
