LeetCode 475

Heaters
供暖器

Medium · 中等 陣列 雙指標 二分搜尋 排序

Problem

Winter is coming! During the contest, your first job is to design a standard heater with a fixed warm radius to warm all the houses.

Every house can be warmed, as long as the house is within the heater's warm radius range.

Given the positions of houses and heaters on a horizontal line, return the minimum radius standard of heaters so that those heaters could cover all houses.

Notice that all the heaters follow your radius standard, and the warm radius will be the same.

中文翻譯

冬天來了！所有暖爐的供暖半徑都相同，房子只要在某個暖爐的半徑範圍內就能取暖。

給你房子和暖爐在直線上的位置，回傳能讓所有房子都取暖的最小半徑。

範例

範例 1 輸入：houses = [1,2,3], heaters = [2] 輸出：1 範例 2 輸入：houses = [1,2,3,4], heaters = [1,4] 輸出：1 範例 3 輸入：houses = [1,5], heaters = [2] 輸出：3

限制條件

  • 1 ≤ houses.length, heaters.length ≤ 3 × 10⁴
  • 1 ≤ houses[i], heaters[i] ≤ 10⁹

LeetCode 原題

解題思路

【每間房子：需要的半徑 = 到最近暖爐的距離】 所有房子都要照顧到 -> 答案 = 所有房子「到最近暖爐距離」的最大值。 【找最近的暖爐】 暖爐排序後，二分找第一個 >= 房子位置的暖爐， 最近的暖爐是它或它左邊那一個。 【另一種：雙指標】 房子和暖爐都排序，指標一起往右走。O(n log n + m log m)。
解法

暖爐排序 + 二分找最近

class Solution: def findRadius(self, houses: List[int], heaters: List[int]) -> int: heaters.sort() radius = 0 for h in houses: i = bisect.bisect_left(heaters, h) # 第一個 >= h 的暖爐 right = heaters[i] - h if i < len(heaters) else float("inf") left = h - heaters[i - 1] if i > 0 else float("inf") # ★ 每間房子只需要最近的暖爐；半徑要照顧到「最遠的那間房子」 radius = max(radius, min(left, right)) return radius
複雜度說明
時間O((n + m) log m)
空間O(1)不計排序

邊界條件檢查清單

  • 房子在所有暖爐左邊或右邊 → 只有一側有暖爐。
  • 房子和暖爐同位置 → 距離 0。

常見追問

二分答案的做法

也可以對半徑二分，檢查給定半徑能否覆蓋所有房子——但直接算「每間房子到最近暖爐的距離」更簡單。
