LeetCode 228

Summary Ranges
彙總區間

Easy · 簡單 陣列

Problem

You are given a sorted unique integer array nums.

Return the smallest sorted list of ranges that cover all the numbers in the array exactly. Each range [a,b] should be output as "a->b" if a != b, and "a" if a == b.

中文翻譯

給你一個已排序、元素不重複的整數陣列 nums。

回傳數量最少、依序排列的區間列表，剛好涵蓋陣列中所有數字。區間 [a,b] 若 a != b 寫成 "a->b"，若 a == b 寫成 "a"。

範例

範例 1 輸入：nums = [0,1,2,4,5,7] 輸出：["0->2","4->5","7"] 範例 2 輸入：nums = [0,2,3,4,6,8,9] 輸出：["0","2->4","6","8->9"]

限制條件

  • 0 ≤ nums.length ≤ 20
  • −2³¹ ≤ nums[i] ≤ 2³¹ − 1
  • nums 中的值互不相同，且遞增排列

LeetCode 原題

解題思路

【把陣列切成「連續遞增 1」的段落】 [0, 1, 2 | 4, 5 | 7] 斷點出現在 nums[j+1] != nums[j] + 1 的地方。 【雙指標】 i = 一段的起點 j 從 i 開始往後延伸，直到下一個不連續 輸出這一段，然後 i = j + 1 【輸出格式】 i == j -> "a" 否則 -> "a->b" 【溢位（其他語言）】 nums[j] + 1 在 nums[j] = 2³¹ - 1 時會溢位。 Java/C++ 可以改寫成 nums[j+1] - nums[j] == 1（用 long）。Python 不必擔心。
解法

雙指標切段

class Solution: def summaryRanges(self, nums: List[int]) -> List[str]: res = [] i, n = 0, len(nums) while i < n: j = i while j + 1 < n and nums[j + 1] == nums[j] + 1: # ★ 一路延伸連續的段 j += 1 res.append(str(nums[i]) if i == j else f"{nums[i]}->{nums[j]}") i = j + 1 # 下一段從 j+1 開始 return res
複雜度說明
時間O(n)
空間O(1)不計輸出

邊界條件檢查清單

  • 空陣列 → []。
  • 只有一個數 → ["a"]。
  • 負數 → 例如 "-3->-1"，格式照樣。
  • 極值 → 2³¹−1 加 1 在其他語言會溢位。

常見追問

追問：如果陣列沒有排序、可能重複？

先排序去重 O(n log n)；或用雜湊集合，只從「x−1 不在集合裡」的 x 開始往上延伸——這就是第 128 題的做法。
