LeetCode 643

Maximum Average Subarray I
子陣列最大平均數 I

Easy · 簡單 陣列 滑動視窗

Problem

You are given an integer array nums consisting of n elements, and an integer k.

Find a contiguous subarray whose length is equal to k that has the maximum average value and return this value. Any answer with a calculation error less than 10-5 will be accepted.

中文翻譯

給你整數陣列 nums 和整數 k，找出長度恰好為 k 的連續子陣列中最大的平均值。

範例

範例 1 輸入：nums = [1,12,-5,-6,50,3], k = 4 輸出：12.75000 範例 2 輸入：nums = [5], k = 1 輸出：5.00000

限制條件

  • n == nums.length
  • 1 ≤ k ≤ n ≤ 10⁵
  • -10⁴ ≤ nums[i] ≤ 10⁴

LeetCode 原題

解題思路

【長度固定 -> 平均最大 <=> 總和最大】 只要找總和最大的長度 k 子陣列，最後除以 k。 【滑動視窗】 先算前 k 個的和，之後每次右移： 加上新進入的 nums[i]，減掉離開的 nums[i-k]。 O(n)。
解法

固定長度滑動視窗

class Solution: def findMaxAverage(self, nums: List[int], k: int) -> float: s = best = sum(nums[:k]) for i in range(k, len(nums)): s += nums[i] - nums[i - k] # ★ 視窗右移：加入新的、減去離開的 best = max(best, s) return best / k
複雜度說明
時間O(n)
空間O(1)

邊界條件檢查清單

  • k = n → 整個陣列的平均。
  • 全是負數 → best 的初始值要用第一個視窗，不能用 0。
