模組 C｜光碟 · 第 11 課

錯誤更正

這一課的目標

  • 理解光碟錯誤更正碼的必要
  • 理解交錯存放如何對付連續錯誤
  • 認識里德－所羅門碼

錯誤一定會發生

光碟上的凹坑只有零點幾微米，任何一點灰塵、指紋、刮傷或製造瑕疵，都會讓一大串資料讀錯。如果沒有錯誤更正，CD 會不停地爆音與跳針。CD 之所以能「永遠完美」（第 9 課），靠的正是精巧的錯誤更正碼（見〈資訊理論〉）。

多加一點資料

錯誤更正的基本想法是：在原始資料之外，加上一些經過計算的額外資料（冗餘）。接收端檢查資料是否符合預期的數學關係，如果不符合，就能找出錯在哪裡並修正。CD 使用的是里德－所羅門碼：把資料分成一組一組的「碼字」，每個碼字加上幾個檢查符號，最多能修正固定數量的錯誤符號。

刮痕是「連續」的

刮痕與灰塵造成的錯誤，往往是一長串連續的，叫做「叢發錯誤」。如果一個碼字的資料都放在一起，一道刮痕就可能讓它錯太多，無法修正。解決辦法是交錯：把每個碼字的符號打散到光碟上相隔很遠的位置。這樣，一道刮痕只會在許多碼字中各造成一兩個錯誤，每一個都還能修正。

CIRC

CD 的錯誤更正叫做「交叉交錯里德－所羅門碼」（CIRC）：兩層里德－所羅門碼之間再加上交錯。它可以完全修正長約 2.5 毫米的連續錯誤；更長的錯誤無法完全修正時，播放機會用前後的樣本內插，猜出缺失的聲音，大多數人聽不出差別。這也是為什麼 CD 刮傷了常常還能播，但刮得太嚴重就會跳針。

無所不在的錯誤更正

里德－所羅門碼不只用在光碟：QR Code 被遮住一部分仍然能掃、太空探測器從遙遠的太空傳回照片、數位電視、行動網路、硬碟與快閃記憶體，都依賴類似的錯誤更正技術。它是現代數位世界看不見的守護者。

🧭 這一課的重點

光碟凹坑零點幾微米灰塵指紋刮傷瑕疵讓一大串資料讀錯，沒有錯誤更正 CD 不停爆音跳針；錯誤更正在原始資料外加經計算額外資料冗餘接收端檢查數學關係找錯修正，CD 用里德－所羅門碼資料分組碼字每碼字加檢查符號最多修正固定數量錯誤；刮痕灰塵錯誤往往一長串連續為叢發錯誤，碼字放一起一道刮痕錯太多，交錯把每碼字符號打散到相隔很遠位置一道刮痕在許多碼字各造成一兩個錯誤都可修正；CD 交叉交錯里德－所羅門碼 CIRC 兩層 RS 碼加交錯可完全修正長約 2.5 毫米連續錯誤，更長時用前後樣本內插多數人聽不出；QR Code 太空探測器數位電視行動網路硬碟快閃記憶體都依賴類似技術。
