線性思考的陷阱：政策抵抗

這一課的目標

  • 認識線性思考與回饋思考的差別
  • 理解政策抵抗
  • 看見反直覺的例子

線性思考：問題 → 找原因 → 採取行動 → 問題解決。但在系統裡，行動會引發其他人的反應，結果又回頭影響原本的問題——這就是回饋。

政策預期系統的反應
拓寬道路解決塞車車流更順開車更方便 → 更多人開車 → 幾年後又塞（誘發需求）
大量撲滅小型森林火災森林更安全枯枝累積 → 終於發生無法控制的大火
抗生素治療所有感染病人好得更快抗藥菌演化 → 抗生素失效
懸賞捕殺眼鏡蛇蛇變少有人開始養蛇領獎金；懸賞取消後放生，蛇更多（眼鏡蛇效應）

斯特曼（John Sterman）稱這為政策抵抗：系統似乎會抵抗我們的介入，因為我們只看到自己的行動，沒看到系統其他部分的回應。佛睿斯特說，複雜系統的行為常常是「反直覺的」。

🧭 這一課的重點

線性思考忽略回饋，常導致政策抵抗：介入引發的反應抵消、甚至逆轉了原本的效果。

🔄 本課的模型都是教學用的簡化版本，用來說明結構如何產生行為，不是對真實世界的精確預測。
