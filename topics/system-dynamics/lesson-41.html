工具：Vensim、Stella 與 Python

這一課的目標

  • 認識常用的建模工具
  • 會用 Python 寫簡單模型
  • 知道各工具的特色
工具特色
Vensim（PLE 免費版）學術界常用，圖形化介面，有敏感度分析
Stella / iThink最早的圖形化工具，適合教學
AnyLogic可結合系統動力學、代理人、離散事件模擬
Insight Maker免費、網頁版
Python（PySD、手寫）彈性最大，能整合資料分析
# SIR 模型（歐拉法） S, I, R = 0.999, 0.001, 0.0 beta, gamma, dt = 0.4, 1 / 7, 0.1 peak = 0 for step in range(int(200 / dt)): infect = beta * S * I # 流量：感染 recover = gamma * I # 流量：康復 S -= infect * dt I += (infect - recover) * dt R += recover * dt peak = max(peak, I) print(f"高峰 {peak:.1%}，最終感染 {R:.0%}")

不論用什麼工具，結構都一樣：存量 += （流入 − 流出）× Δt。圖形化工具的好處是容易溝通，讓利害關係人一起看懂模型。

🧭 這一課的重點

Vensim、Stella、AnyLogic 等工具與 Python 都能建立系統動力學模型，核心都是存量的累積。

🔄 本課的模型都是教學用的簡化版本，用來說明結構如何產生行為，不是對真實世界的精確預測。
