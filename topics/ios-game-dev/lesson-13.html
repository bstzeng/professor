建立你的第一個SpriteKit專案

這一課的目標

  • 能透過File > New > Project，選擇正確的範本與設定，建立一個SpriteKit專案
  • 認識建立專案時要填寫的關鍵欄位：Team、Organization Identifier、Bundle Identifier等
  • 能用Run按鈕把預設範本跑在iOS模擬器上，並看懂畫面上顯示的內容

環境跟帳號都準備好了，這一課終於要建立這門課實際的 第一個專案。跟著步驟做一遍，之後模組F開始的打磚塊 遊戲專案，也會是同樣的流程。

1. File > New > Project，選擇Game範本

打開Xcode，選單列點選File > New > Project（或是Xcode的歡迎畫面點「Create New Project」）。在跳出的範本選擇畫面，先確認上方分頁停在 iOS，然後在範本列表裡找到並選擇 Game這個範本——它是蘋果官方針對遊戲 開發預先準備好的起始專案，會自動幫你把SpriteKit相關的 基礎架構都建好。

2. 填寫專案設定：Game Technology、語言與識別資訊

選好Game範本後，Xcode會進入一個設定畫面，需要填寫幾個 關鍵欄位：

  • Product Name——專案跟App的名稱， 例如MyFirstGame，之後可以在Info.plist 裡另外設定顯示給使用者看的名稱
  • Team——選擇第11課登入的Apple ID， 也就是免費的個人團隊即可（回顧第12課）
  • Organization Identifier——通常填 反向網域格式，例如com.yourname，配合 Product Name，會自動組成完整的Bundle Identifier（例如com.yourname. MyFirstGame），這是這個App在整個Apple生態系裡 獨一無二的識別碼
  • Game Technology——選擇 SpriteKit（Xcode底下可能還會列出 SceneKit、Metal等其他選項，這門課從頭到尾都只會用到 SpriteKit）
  • Language——選擇Swift

填完之後按Next，選一個要儲存專案的資料夾，Xcode就會 把整個專案的檔案結構建立好（下一課會完整導覽這些檔案）。

3. 按下Run，在模擬器上看到第一個畫面

專案建立好、Xcode視窗打開後，在工具列左上角選擇一個 模擬器機型（例如某一款iPhone），接著點擊左上角的 Run按鈕（三角形圖示，或直接按Cmd+R）。 Xcode會先建置專案，接著自動啟動iOS模擬器，把App安裝 並執行起來。

Game範本預設產生的畫面內容，會依Xcode版本略有不同，但 大致上都會看到一個場景，中央顯示著簡單的文字或圖形 （例如類似「Hello, World!」的提示文字，或是一個會 旋轉、移動的簡單圖形），有些版本點擊畫面還會觸發額外 的效果。重點不在於這個預設畫面長什麼樣子，而是這一 整套「建置、安裝、執行」的流程，之後每一次修改程式碼 要驗證效果，都會重複用到。

打開專案裡的GameScene.swift檔案，會看到 類似這樣的程式碼骨架（實際內容依Xcode版本可能略有 差異，但核心結構相同）：

import SpriteKit class GameScene: SKScene { override func didMove(to view: SKView) { // 場景第一次顯示時，這裡的程式碼會被執行 } }

這正是預設範本用來顯示畫面內容的地方——模組D會完整 說明SKScene與didMove(to:) 這兩個關鍵字究竟是什麼。

檢查你的理解

  1. 說明建立SpriteKit專案時，Game Technology與Language分別該選什麼
  2. 解釋Team、Organization Identifier、Bundle Identifier這幾個欄位各自的用途
  3. 說明按下Run之後，Xcode大致做了哪些事，才讓你在模擬器上看到畫面
