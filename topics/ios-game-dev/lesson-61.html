模組 N｜準備上架：Apple Developer Program · 第 61 課

註冊Apple Developer Program（年費美金99元）

這一課的目標

  • 理解為什麼真機測試跟上架App Store，都需要加入付費的Apple Developer Program
  • 分辨Individual與Organization兩種註冊身份，知道各自適合什麼情況、需要準備什麼
  • 知道年費是每年都要續繳的費用，而不是一次性付款

模組M把廣告收入的部分收尾了，磚塊遊戲已經有了完整的 玩法、也接上了AdMob廣告。從這一課開始，模組N到Q要走 完真正把遊戲送上App Store所需要的整套流程——第一步， 就是把Xcode裡免費的Apple ID，升級成一個具備真機測試與 上架資格的Apple Developer Program會員 身份。

1. 為什麼需要Apple Developer Program

回顧第1課提過的區分：單純寫程式、在模擬器上測試， 免費的Apple ID就夠用。但只要想跨出這一步——把遊戲裝到 自己手上的iPhone實機測試手感、找朋友幫忙做TestFlight 測試，或是最終送審上架——都需要一個已經加入Apple Developer Program的帳號。這是因為模組N後面幾課會談到 的簽章機制，需要蘋果核發的憑證，而核發憑證的前提，就是 你已經是這個付費方案的會員。

2. 到developer.apple.com註冊：流程與費用

註冊入口在developer.apple.com，用你的 Apple ID登入後，找到Enroll（註冊）的頁面開始申請。整個 流程大致包含：確認身份資訊、選擇註冊身份類型（下一節會 說明）、同意開發者合約條款，最後完成付款。費用是 每年美金99元（實際換算成新台幣的金額 會隨匯率與Apple當地定價浮動，這類金額本身也可能隨時間 調整，實際申請前建議直接以developer.apple.com上顯示的 金額為準）。付款完成、審核通過後，帳號就正式具備了 真機測試與上架的資格。

3. 兩種身份：Individual vs Organization

註冊時最重要的一個選擇，是決定用Individual （個人）還是Organization（組織／ 公司）身份申請：

  • Individual：流程最單純，只需要你 本人的身份資訊，App在App Store上會顯示是由你的個人 姓名（Apple ID綁定的法定姓名）開發、發布
  • Organization：App會以公司或組織的 名稱上架，但申請門檻高出不少——需要提供一組 D-U-N-S號碼（一種國際通用的企業識別 編號，用來證明這是一個真實存在、可被查核的法律實體）， 如果你的公司還沒有D-U-N-S號碼，通常需要另外申請， 會拉長整個註冊時間

對這門課的情境——一個人獨立開發、準備上架第一款打磚塊 遊戲——Individual身份幾乎都是比較務實的起點： 流程快、不需要額外的企業文件，之後如果真的成立公司， 蘋果也提供帳號轉移或另外申請Organization身份的路徑， 不算是一個做了就回不了頭的決定。

4. 年費與續會：不是一次性費用

很容易被新手忽略的一點：這筆美金99元的費用是 每年都要續繳的年費，不是繳一次終身有效。如果 會員資格到期沒有續會，已經上架的App會從App Store下架、 無法再被新使用者下載（既有已安裝使用者通常還能繼續 使用，但無法再收到更新），真機測試與新App的提交也都會 受影響。把這筆年費想成是「維持App在架上」的持續成本， 而不是上架那一刻的一次性門票，會更符合實際狀況——這也 是後面模組R談上架後長期經營時，值得放進成本考量的一項 固定支出。

檢查你的理解

  1. 說明為什麼真機測試跟送審上架，都需要加入付費的Apple Developer Program
  2. 比較Individual與Organization兩種註冊身份，各自的門檻與App顯示方式有什麼不同
  3. 解釋為什麼年費是「持續成本」而不是「一次性費用」，沒有續會會發生什麼事
