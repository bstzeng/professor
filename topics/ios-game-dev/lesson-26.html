模組 F｜實作專案①：打磚塊遊戲——基礎架構 · 第 26 課

磚塊陣列排版

這一課的目標

  • 用巢狀迴圈計算並建立一整排整列的磚塊SKSpriteNode
  • 理解如何依磚塊尺寸、列數欄數與間距，算出每一塊磚塊的x、y座標
  • 把每塊磚塊加入場景，並統一設定name屬性，供之後的碰撞偵測使用

球拍跟球都已經在場景裡了，這一課要補上打磚塊遊戲最後 一個核心物件——磚塊陣列。跟前兩課逐一手動建立不同， 磚塊數量多，最自然的做法是用兩層迴圈：外層跑「列」， 內層跑「欄」，依照固定的公式算出每一塊磚塊該放的位置。

1. 規劃磚塊陣列的參數

開始寫迴圈之前，先把會用到的幾個數字定義成常數，方便 之後統一調整整體排版：

let brickRows = 5 let brickColumns = 8 let brickSize = CGSize(width: 40, height: 16) let brickPadding: CGFloat = 6

brickRows、brickColumns決定 磚塊陣列的列數與欄數，brickSize是每一塊 磚塊的大小，brickPadding則是磚塊之間的 間距——這四個數字，就是接下來計算座標時需要用到的全部 材料。

2. 用巢狀迴圈計算座標並建立磚塊

先算出一整排磚塊排起來的總寬度，用來算出讓整排置中的 起始x座標startX；再從畫面上方預留一段 距離，當作第一列的y座標startY。接著用巢狀 迴圈，依序建立每一塊磚塊：

func setupBricks() { let totalRowWidth = CGFloat(brickColumns) * brickSize.width + CGFloat(brickColumns - 1) * brickPadding let startX = frame.midX - totalRowWidth / 2 + brickSize.width / 2 let startY = frame.maxY - 100 for row in 0..<brickRows { for column in 0..<brickColumns { let brick = SKSpriteNode(color: .systemOrange, size: brickSize) brick.name = "brick" let x = startX + CGFloat(column) * (brickSize.width + brickPadding) let y = startY - CGFloat(row) * (brickSize.height + brickPadding) brick.position = CGPoint(x: x, y: y) addChild(brick) } } }

totalRowWidth把8塊磚塊的寬度，加上7個間距 （欄數減一）加總起來，得到一整排磚塊排好之後的總寬度； startX再用frame.midX（場景水平 中心）減去總寬度的一半，並加回半塊磚塊寬——因為 position指的是節點的中心點，不是左邊緣， 所以要補這半塊寬度的偏移，第一塊磚塊的左邊緣才會剛好對齊 整排的起始位置。內層迴圈的x、y 計算，則是從起始位置開始，依照欄數、列數各自往右、往下 移動「磚塊尺寸加間距」的整數倍。最後別忘了在 didMove(to:)裡呼叫setupBricks()， 整排磚塊才會真正出現在畫面上。

3. 命名與後續用途

迴圈裡建立的每一塊磚塊，都設定了同樣的 name = "brick"。這在目前階段的直接用途是 方便之後用children(where:)或走訪 children陣列時，快速篩選出「所有磚塊」； 等到模組G加入SKPhysicsBody與碰撞分類後， 判斷「這次碰撞的另一方是不是磚塊」會改用效能更好的 physics category，但一致的命名習慣，仍然是能一眼看懂 場景結構的基本功。
