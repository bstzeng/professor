Xcode、Swift、SpriteKit：三個名詞分別是什麼

這一課的目標

  • 能清楚分辨Xcode、Swift、SpriteKit分別是「工具」「語言」還是「框架」
  • 理解這三者在開發一款iOS遊戲的過程中，各自扮演的角色與彼此的關係
  • 看懂一段簡單的SpriteKit程式碼裡，哪些部分屬於Swift語言本身、哪些部分來自SpriteKit框架

很多新手第一次查資料，看到「用Xcode、Swift、SpriteKit 開發iOS遊戲」這句話，會下意識把三個名詞當成同一類東西 混在一起用。這其實是後面學習路上一個常見的卡點——分不清 楚哪個問題該去查Swift語言的文件、哪個問題該去查SpriteKit 的文件、哪個又只是Xcode這個應用程式本身的操作問題。這一課 花一整堂把三者的分工講清楚，之後每次卡關都能更快判斷 該往哪個方向找答案。

1. Xcode：寫程式、設計畫面、跑模擬器的「開發環境」

Xcode本身是一個應用程式——你會在Mac上像 開啟其他App一樣把它打開。它的角色是整合開發環境 （IDE）：程式碼編輯器、介面設計工具、除錯器、 模擬器，全部整合在同一個視窗裡。Xcode不是一種程式語言， 也不是遊戲引擎本身——它比較像是承載這一切的工作台。 理論上，你也可以用一般的文字編輯器寫Swift程式碼、再用 指令列工具編譯，但那樣會失去Xcode內建的介面設計器、 即時預覽、中斷點除錯等大量幫你省力的功能，模組C會實際 帶你安裝並操作它。

2. Swift：你實際寫下的程式語言

Swift是蘋果在2014年推出的程式語言，是 目前開發iOS、macOS App的主流語言。當你在Xcode的編輯器裡 打字，寫下「角色往前移動」「分數加一」「碰到磚塊要消失」 這些邏輯時，寫下的每一行程式碼，語法上都屬於Swift這個 語言——變數怎麼宣告、條件判斷怎麼寫、函式怎麼定義，這些 都是Swift語言本身的規則，跟你做的是遊戲還是記帳App無關。 模組B會用整整七課，把Swift語言的核心語法快速上手一遍。

3. SpriteKit：組出2D遊戲畫面用的框架

SpriteKit是蘋果官方提供、專門用來做2D 遊戲的框架（framework），可以把它想成 一個現成寫好的「函式庫」——裡面已經準備好一整套跟遊戲 高度相關的類別，例如代表一個遊戲畫面的SKScene、 代表畫面上任何物件的SKNode、可以顯示圖片 的SKSpriteNode，還有物理引擎、動作系統 等等。如果沒有SpriteKit，要做出畫面更新、物件移動、 碰撞偵測這些遊戲基本功能，得完全從零手刻；有了 SpriteKit，你只需要學會怎麼「使用」這些現成的類別， 模組D會完整介紹它的核心概念。

4. 三者合起來：一段實際的程式碼

把三者放進同一個例子裡看最直接。以下是一段完整、能在 SpriteKit專案裡使用的Swift程式碼，定義了一個遊戲畫面 的最小雛形：

import SpriteKit class GameScene: SKScene { override func didMove(to view: SKView) { backgroundColor = .black } }

逐行拆開來看：import SpriteKit這行本身是 Swift語言「匯入框架」的語法，作用是告訴編譯器「這個 檔案要使用SpriteKit提供的功能」；class GameScene: SKScene也是Swift定義類別、並繼承父類別的語法， 但被繼承的SKScene這個父類別，是SpriteKit 框架提供的，代表「一個遊戲畫面」；override func didMove(to view: SKView)是Swift的函式覆寫語法， 而didMove(to:)這個特定的方法，則是SpriteKit 定義好、會在場景被顯示到畫面上時自動呼叫的時機點。至於 這整段程式碼寫在哪個檔案裡、怎麼按下執行鍵讓它跑進 模擬器看到黑色畫面——那些操作，都屬於Xcode負責的範圍。

一個類比：工地、語言、現成建材

如果把做一款遊戲比喻成蓋一棟小屋，Xcode就像是工地 與工具間，你在裡面動手施工、隨時能檢查進度；Swift是 你跟工人溝通、下指令用的語言，每一個指令都得符合這套 語言的文法；SpriteKit則像是一批已經做好標準規格的 建材——現成的門、窗、樓梯零件，你不需要從鋸木頭開始， 但仍然要用Swift清楚地「說」要怎麼把這些零件組裝起來。

檢查你的理解

  1. 用自己的話說明Xcode、Swift、SpriteKit三者的差別
  2. 在範例的GameScene程式碼裡，指出哪些部分是Swift語言本身的語法，哪些部分是SpriteKit框架提供的
  3. 解釋為什麼理論上「只用Swift、不用SpriteKit」也能做出遊戲，但新手不建議這樣做
