流程控制：條件判斷與迴圈

這一課的目標

  • 熟悉if/else與switch的寫法，理解Swift的switch要求窮盡所有情況
  • 能用for-in搭配範圍運算子、以及while寫出迴圈
  • 理解guard提前跳出的寫法，以及它為什麼在Swift裡特別常見

有了型別、函式這些基礎，這一課要把「程式該怎麼根據條件 走不同的路、或是重複執行某段邏輯」講完——這是流程控制， 幾乎每一段實際的遊戲邏輯都少不了它們。

1. if/else：最基本的條件判斷

let lives = 0 if lives <= 0 { print("遊戲結束") } else if lives == 1 { print("只剩最後一條命，小心！") } else { print("目前生命值：\(lives)") }

跟大多數語言一樣，Swift的if條件不需要額外 的括號包住（有寫也不會錯，只是不是必要），但條件判斷式 後面的花括號是必要的，不能省略。

2. switch：要求窮盡所有情況，支援樣式比對

switch用來根據一個值比對多種可能的情況。 跟C語言系的switch不太一樣的地方是：Swift 的switch要求窮盡（exhaustive） ——所有可能的情況都必須被涵蓋，否則編譯器會直接報錯， 通常會搭配default涵蓋剩下所有情況；而且 Swift的switch預設不會fallthrough （不會像某些語言一樣，比對到一個分支後繼續往下一個 分支執行），每個分支執行完就自動結束，這讓行為更可預測：

enum GameState { case start, playing, paused, gameOver } let state = GameState.paused switch state { case .start: print("顯示開始畫面") case .playing: print("遊戲進行中") case .paused: print("遊戲暫停") case .gameOver: print("顯示結束畫面") }

這裡的state是一個enum（列舉， 代表幾種固定可能值的其中一種），因為switch 列出了GameState所有可能的情況，不需要額外 加default——這正是「窮盡性」在實務上最常見 的用法，之後在模組H設計遊戲狀態機時會再遇到。Swift的 switch也支援比較複雜的樣式比對 （pattern matching），例如直接比對數字範圍， 這裡先留一個印象，之後遇到實例再深入。

3. for-in與範圍運算子：走訪一段範圍或一個集合

for-in迴圈可以走訪一個範圍、或是陣列這類 集合裡的每一個元素：

// 0..<10 代表0到9，不包含10（半開範圍運算子） for row in 0..<10 { print("建立第\(row)排磚塊") } let highScores = [120, 98, 75] for score in highScores { print("歷史分數：\(score)") }

0..<10是半開範圍運算子， 代表從0開始、到10之前結束（不含10本身），一共是10個 數字；如果想要包含結尾，則用三個點的0...10 （閉區間，包含10）。用範圍搭配for-in來建立 固定排數的磚塊陣列，是接下來模組F會實際用到的寫法。

4. while：條件成立就持續執行

var remainingBricks = 5 while remainingBricks > 0 { print("還剩\(remainingBricks)塊磚") remainingBricks -= 1 }

while迴圈會在每次執行前檢查條件，條件成立 就繼續執行迴圈內容，不成立就結束——適合用在「不確定要 重複幾次，但知道什麼時候該停下來」的情境，例如「磚塊 還沒清空之前，持續判斷遊戲是否過關」這類邏輯。

5. guard：提前跳出，Swift特別常見的寫法

guard語句用來表達「條件不成立就提前離開」， 跟寫在函式開頭、先擋掉不符合條件的情況，讓函式主體 可以維持在「條件都已經滿足」的狀態下撰寫，讀起來更 清楚：

func startGame(lives: Int) { guard lives > 0 else { print("生命值必須大於0，無法開始遊戲") return } // 執行到這裡，代表lives一定大於0 print("遊戲開始，生命值：\(lives)") }

跟第5課的guard let是同一個語句的兩種常見 用法：guard let檢查Optional是否有值，這裡 的guard則是檢查一般的布林條件；兩者共同的 精神都是「不符合就提前return，讓後續程式碼 建立在條件已經成立的前提上」。

檢查你的理解

  1. 解釋Swift的switch為什麼要求「窮盡」，以及不寫default但涵蓋所有enum情況時是否合法
  2. 說明0..<10跟0...10的差別
  3. 用自己的話解釋guard的用途，以及它跟一般if/else在寫法習慣上的差異
