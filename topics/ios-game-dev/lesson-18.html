模組 D｜SpriteKit核心概念 · 第 18 課

座標系統：SpriteKit的座標邏輯

這一課的目標

  • 理解SpriteKit預設座標系統的原點在場景左下角，y值愈往上愈大，跟UIKit相反
  • 認識anchorPoint屬性，理解它如何影響position跟節點自身範圍的對應關係
  • 能正確判斷、計算一個節點目前實際顯示在畫面上的位置

前面兩課已經多次用到position屬性，這一課 要正式解釋，這個position裡的數字，究竟對應畫面上的 哪個位置——這是新手最容易搞混、也最值得花一整課釐清 的觀念。

1. 原點在左下角，y軸向上：跟UIKit相反

如果你之前接觸過UIKit（iOS傳統的介面框架），會習慣 「原點在畫面左上角，y值愈往下愈大」的座標邏輯。 SpriteKit預設的座標系統剛好相反： 場景的原點(0, 0)在左下角，x軸往右遞增， y軸則是往上遞增——比較接近數學、物理 課本上熟悉的座標系統。

這件事在實務上很重要：如果想讓一個節點「往上移動」， 代表要增加它的y值；如果之後模組G要 套用物理引擎的重力或速度，正的垂直速度會讓物體往上 飛，負的垂直速度才會讓物體往下掉——這跟很多新手直覺 以為「y愈大愈往下」剛好相反，務必記住這一點。

2. anchorPoint：position對應的是節點的哪個點

知道了場景的座標系統之後，還有一個問題：一個節點的 position，究竟是對應這個節點自身範圍的 哪一點？答案由anchorPoint這個屬性決定。 SKSpriteNode的anchorPoint 預設值是(0.5, 0.5)，意思是節點自身範圍 的正中央會對齊到position指定的座標—— 這也是為什麼前面幾課設定position = CGPoint(x: frame.midX, y: frame.midY)，看到的物件會剛好 置中顯示。

anchorPoint的x、y分量，各自代表「節點自身 寬、高的哪個比例位置」會對齊到position：(0, 0) 代表節點的左下角對齊position，(1, 1)代表 節點的右上角對齊position，以此類推。

let sprite = SKSpriteNode(color: .systemBlue, size: CGSize(width: 60, height: 60)) sprite.anchorPoint = CGPoint(x: 0, y: 0) // 預設是(0.5, 0.5) sprite.position = CGPoint(x: 100, y: 100) addChild(sprite)

把anchorPoint改成(0, 0)之後， position = CGPoint(x: 100, y: 100)代表 的是這個節點的左下角會落在座標 (100, 100)，整個60x60的方塊會往右、往上 延伸；如果保持預設的(0.5, 0.5)，同樣的 position則會讓方塊的中心點落在 (100, 100)，畫面上顯示的位置明顯不同。

小提醒：SKScene本身也有anchorPoint

除了SKSpriteNode，SKScene本身也有一個獨立的 anchorPoint屬性，預設是(0, 0)，決定的 是場景的原點要對齊到SKView畫面的哪個位置——這是另一 層次的設定，跟這一課討論的節點anchorPoint是兩回事， 初學階段先維持場景的預設值即可，不需要特別調整。

  2. 說明anchorPoint的預設值是什麼，把它從(0.5, 0.5)改成(0, 0)之後，position的意義有什麼變化
