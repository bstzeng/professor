建立球拍

這一課的目標

  • 用SKSpriteNode建立球拍，設定顏色、大小與初始位置
  • 把球拍加入場景，並設定name屬性方便之後查找
  • 串接模組E學到的touchesMoved邏輯，讓球拍隨手指左右移動並限制邊界

場景規劃底定，這一課動手做出玩家實際會操作的第一個 物件——球拍。回顧第17課「SKSpriteNode：讓圖片動起來」， 目前這個階段還沒有正式的美術素材（模組J才會處理）， 所以先用一個純色方塊當佔位，把邏輯做對，之後隨時可以 換成真正的圖片。

1. 建立SKSpriteNode球拍

SKSpriteNode(color:size:)可以直接建立一個 不需要圖片、用純色填滿的精靈節點，很適合拿來當開發階段 的佔位物件：

class GameScene: SKScene { private let paddle = SKSpriteNode(color: .white, size: CGSize(width: 100, height: 20)) override func didMove(to view: SKView) { paddle.name = "paddle" paddle.position = CGPoint(x: frame.midX, y: frame.minY + 80) addChild(paddle) } }

paddle.name = "paddle"採用了第23課訂下的 命名規範，之後模組G做碰撞判斷時就能依這個名稱識別出 「撞到的是球拍」。位置用frame.minY + 80 設定，而不是寫死一個數字，是因為frame.minY 代表場景最底部的y座標（回顧第18課的座標系統）——用相對 於場景邊界的偏移量，即使之後場景尺寸調整，球拍離底部的 距離也還是合理的。

2. 加上觸控追蹤移動

接著把第22課推導出的clamp公式接上真正的paddle 節點，覆寫touchesMoved：

override func touchesMoved(_ touches: Set<UITouch>, with event: UIEvent?) { guard let touch = touches.first else { return } let location = touch.location(in: self) let halfWidth = paddle.size.width / 2 let minX = frame.minX + halfWidth let maxX = frame.maxX - halfWidth paddle.position.x = min(max(location.x, minX), maxX) }

這段程式碼跟第22課的版本幾乎一樣，差別只是把佔位用的 變數名稱，換成這一課真正建立出來的paddle 屬性。跑起來之後，手指在畫面下半部左右滑動，球拍就會 跟著移動，而且不管手指滑到多靠近螢幕邊緣，球拍都會 停在剛好貼齊邊界的位置，不會有一半跑到畫面外。

檢查你的理解

  1. 寫出用SKSpriteNode建立一個白色、寬100高20球拍的程式碼
  2. 說明為什麼球拍的y座標用frame.minY加上一個偏移量來設定，而不是寫死一個數字
  3. 解釋這一課的touchesMoved實作，跟模組E第22課教的clamp模式是什麼關係
