粒子特效

這一課的目標

  • 理解SKEmitterNode是什麼，以及它跟一般SKSpriteNode的差別
  • 學會用Xcode內建的Particle Emitter Editor視覺化設計一個粒子特效檔案
  • 能把設計好的.sks粒子檔案載入程式碼，在磚塊消失時觸發一次性的爆發效果

上一課讓磚塊消失的瞬間「聽得到」，這一課要讓它「看得 更明顯」——用一小段粒子爆發效果，強化磚塊被擊中那一刻 的存在感。這在許多遊戲裡都是很常見的手法：一個關鍵事件， 同時觸發聲音跟畫面上的小特效，讓玩家更確定「這件事真的 發生了」。

1. SKEmitterNode：專門用來畫「一群小顆粒」的節點

SKEmitterNode是SKNode的子類別， 專門負責管理大量的小顆粒（particle）——每個顆粒都有各自 隨機化的速度、存活時間、縮放、透明度、顏色變化、旋轉角度 等屬性，全部交給SpriteKit自動計算與渲染，開發者不需要 自己手動建立、更新一大堆節點。這讓它很適合做出火花、 煙霧、爆炸碎片、拖尾這類「一群小東西同時噴發」的效果。

2. 用Xcode內建編輯器設計粒子特效

不需要手動計算這些顆粒參數，Xcode內建了視覺化的粒子 編輯器：選擇File > New > File， 在iOS分類裡選擇SpriteKit Particle File， 接著挑一個內建範本（例如Fuse、Spark、Smoke）當作起點， Xcode會建立一個.sks檔案，並直接開啟編輯器， 畫布上即時預覽特效效果。右側面板可以調整Birth Rate（每秒 產生幾顆粒子）、Lifetime（每顆粒子存活多久）、Speed、 Emission Angle（噴發角度範圍）、Scale、顏色隨時間的變化 （Color Ramp）、使用的貼圖等參數，每次調整畫布都會 立即更新，不需要重新編譯就能反覆試效果。存檔後，把這個 檔案命名成類似BrickBreak.sks。

3. 在磚塊消失的瞬間播放一次爆發

設計好的.sks檔案，可以用SKEmitterNode (fileNamed:)載入成一個節點，加到場景裡：

if let burst = SKEmitterNode(fileNamed: "BrickBreak") { burst.position = brick.position burst.zPosition = 5 addChild(burst) let wait = SKAction.wait(forDuration: 1.0) let remove = SKAction.removeFromParent() burst.run(SKAction.sequence([wait, remove])) }

SKEmitterNode(fileNamed:)用檔名（不含副檔名） 載入剛剛做好的粒子檔案，回傳的是一個Optional，因為檔案 萬一不存在就會是nil，所以用if let 安全解包。把position設成磚塊消失的位置， zPosition設高一點，確保特效畫在磚塊、背景 之上。特別要注意最後這段wait加 removeFromParent()——粒子編輯器裡預設的 Birth Rate通常是持續噴發，就算把它調成短時間內噴完， 既有的顆粒也還需要時間播完各自的存活動畫，所以不能一 加進場景就立刻移除節點，而是等一小段時間、讓噴發與殘留 的顆粒都播放完畢，再把整個emitter節點清掉，避免場景裡 累積一堆不再需要、卻還沒被回收的節點。
