在Xcode安裝並初始化Google Mobile Ads SDK

這一課的目標

  • 能透過Swift Package Manager把Google Mobile Ads SDK加入Xcode專案
  • 能在Info.plist正確加入GADApplicationIdentifier，串起AdMob App ID這項必要設定
  • 能在App啟動流程中正確呼叫SDK的初始化函式

上一課拿到了App ID跟三組Ad Unit ID，這一課要把它們 真正接進Xcode專案——安裝SDK、設定Info.plist、呼叫 初始化函式，這三步做對了，後面第57～59課才能開始 請求跟顯示廣告。

1. 用Swift Package Manager加入SDK

在Xcode選單列點選File > Add Package Dependencies...，在跳出的視窗貼上Google官方 文件提供的Google Mobile Ads SDK套件庫網址（可以在 AdMob官方文件的「開始使用」頁面找到目前對應的網址， Google的Swift Package Manager套件路徑通常以 googleads這個組織名稱開頭）。Xcode解析 完套件資訊後，選擇要加入的目標（target）——也就是 打磚塊遊戲這個App本身，確認加入GoogleMobileAds 這個函式庫產品，等待Xcode下載並解析套件依賴關係即可。

2. Info.plist設定GADApplicationIdentifier

接著要讓SDK知道「現在是哪一個App在請求廣告」——這一步 是必要的，如果漏掉，App在真正發出廣告 請求時會直接當機。打開專案的Info.plist，新增一個字串 型別的key，名稱固定是GADApplicationIdentifier， 值就是第55課在AdMob後台建立App項目時拿到的App ID：

<key>GADApplicationIdentifier</key> <string>ca-app-pub-3940256099942544~1458002511</string>

（上面這組ca-app-pub-3940256099942544~1458002511 是Google官方文件公開提供、專門給開發階段測試用的 App ID，實際上架前務必換成自己在AdMob後台建立的正式 App ID，第60課的檢查清單會再次提醒這一點。）

3. 初始化SDK

套件裝好、Info.plist設定完成後，最後一步是在App啟動 流程的早期，呼叫一次SDK的初始化函式 GADMobileAds.sharedInstance().start(completionHandler: nil)。如果App是用SwiftUI的App協定架構，最自然 的位置是放進App結構的init()裡：

import SwiftUI import GoogleMobileAds @main struct BreakoutApp: App { init() { GADMobileAds.sharedInstance().start(completionHandler: nil) } var body: some Scene { WindowGroup { ContentView() } } }

如果專案還是採用傳統的AppDelegate架構，則放在 application(_:didFinishLaunchingWithOptions:) 裡執行：

import GoogleMobileAds func application(_ application: UIApplication, didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool { GADMobileAds.sharedInstance().start(completionHandler: nil) return true }

兩種寫法的重點是一樣的：start(completionHandler:) 要在App一啟動就盡早呼叫一次，確保後面第57～59課建立 任何一種廣告物件、發出任何一次廣告請求之前，SDK都已經 完成必要的內部初始化程序。

檢查你的理解

  1. 說明用Swift Package Manager加入Google Mobile Ads SDK的步驟
  2. 解釋為什麼Info.plist一定要設定GADApplicationIdentifier，漏掉會發生什麼事
  3. 說明GADMobileAds.sharedInstance().start(completionHandler:)應該在App啟動流程的哪個時機呼叫
