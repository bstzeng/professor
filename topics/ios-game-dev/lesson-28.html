模組 G｜實作專案②：物理引擎與碰撞 · 第 28 課

physics body設定

這一課的目標

  • 理解SKPhysicsBody的角色：讓SpriteKit知道一個節點在物理世界裡該被當成什麼形狀
  • 學會用rectangleOf與circleOfRadius，幫球拍、磚塊、球建立對應形狀的physics body
  • 理解isDynamic與affectedByGravity這兩個屬性，分別決定「誰會被物理引擎推著走」跟「誰受重力影響」

模組F結束時，場景裡已經有球拍、球、排列整齊的磚塊，但 它們目前都只是畫面上「看起來在那裡」的SKSpriteNode， 彼此之間沒有任何物理關係——球不會撞到磚塊，球拍也擋 不住球，一切都只是靜止的圖片。模組G要把SpriteKit內建 的物理引擎接上這些節點，讓它們開始有碰撞、反彈這些 遊戲該有的行為。第一步，就是幫每個需要參與物理互動 的節點，設定一個physicsBody。

1. SKPhysicsBody是什麼

每一個SKSpriteNode都有一個physicsBody 屬性，預設是nil——代表這個節點完全不參與 物理模擬，就只是一張畫在畫面上的圖。只要幫它指派一個 SKPhysicsBody實例，物理引擎才會開始「認得」 這個節點，知道它的形狀、該不該受重力影響、撞到別的 物體時該怎麼反應。

SKPhysicsBody有好幾種初始化方式，對應不同的形狀，這一課 會用到最常見的兩種：

  • SKPhysicsBody(rectangleOf: size)——建立 一個矩形的physics body，適合球拍、磚塊這種方形的圖案
  • SKPhysicsBody(circleOfRadius: radius)—— 建立一個圓形的physics body，適合球這種圓形的圖案

2. 幫球拍與磚塊建立physics body（矩形）

球拍跟每一顆磚塊都是矩形的SKSpriteNode，用 rectangleOf:搭配節點本身的size， 就能讓physics body的大小跟畫面上看到的圖案完全對齊：

paddle.physicsBody = SKPhysicsBody(rectangleOf: paddle.size) for brick in bricks { brick.physicsBody = SKPhysicsBody(rectangleOf: brick.size) }

這裡沿用第26課「磚塊陣列排版」建立好的bricks 陣列，用迴圈幫每一顆磚塊都接上對應大小的physics body。

3. 幫球建立physics body（圓形）

球是圓形的圖案，用矩形physics body雖然也能動，但轉角 處的碰撞判定會不太自然，所以改用circleOfRadius:， 半徑通常取球的寬度除以2：

ball.physicsBody = SKPhysicsBody(circleOfRadius: ball.size.width / 2)

4. isDynamic：誰該被物理引擎推著走

isDynamic是一個布林值，預設是true， 代表這個physics body會受到力、碰撞、重力的影響而移動、 旋轉——也就是「動態」的物體。但這款打磚塊遊戲裡，球拍 跟磚塊的位置都是由我們自己的程式碼直接控制（球拍靠 觸控移動、磚塊本來就該固定不動），不應該被物理引擎的 碰撞力道推著跑，所以要把它們的isDynamic 設成false：

paddle.physicsBody?.isDynamic = false for brick in bricks { brick.physicsBody?.isDynamic = false }

設成false之後，這些physics body會變成 「靜態」的——它們依然會參與碰撞判定（球撞上去還是會 彈開），但不會因為被撞而自己移動或旋轉，就像遊戲裡 一堵不會被推倒的牆。球則相反，需要真的能被彈來彈去， 所以維持預設的true即可（也可以顯式寫出來， 讓意圖更清楚）：

ball.physicsBody?.isDynamic = true

5. affectedByGravity：這款遊戲不需要真實重力

affectedByGravity同樣預設是true， 代表這個physics body會被場景的重力往下拉，這對模擬 「真實世界物理」的遊戲（例如角色會往下掉的平台遊戲） 很有用。但打磚塊是一款球在畫面裡各方向彈射的遊戲，如果 球一直被重力往下拉，很快就會全部往螢幕底部集中，完全 不是想要的效果，所以要把球的affectedByGravity 關掉：

ball.physicsBody?.affectedByGravity = false

球拍跟磚塊因為isDynamic已經設成 false，本來就不會受任何力（包含重力） 影響位置，所以不需要額外設定affectedByGravity。

檢查你的理解

  1. 說明為什麼球拍跟磚塊要用rectangleOf:，球要用circleOfRadius:
  2. 解釋isDynamic設成false對球拍跟磚塊分別代表什麼
  3. 說明為什麼這款打磚塊遊戲要把球的affectedByGravity關掉
