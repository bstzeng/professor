重力、速度與反彈

這一課的目標

  • 理解scene.physicsWorld.gravity怎麼控制整個物理世界的重力，以及為什麼這款遊戲要設成.zero
  • 學會用velocity屬性給球一個初始速度，讓它開始朝某個方向移動
  • 理解restitution、friction、linearDamping這幾個屬性，怎麼影響球的反彈與速度衰減

上一課幫球拍、球、磚塊都接上了physics body，但這時候 場景其實還是靜止的——physics body只是定義了形狀跟基本 屬性，球並不會自己動起來。這一課要處理兩件事：先把 整個物理世界的重力關掉（打磚塊不需要真實重力）， 再給球一個初始的方向與速度，讓它真正開始在畫面裡彈射。

1. physicsWorld.gravity：整個場景的重力

每個SKScene都有一個physicsWorld屬性，代表 整個場景共用的物理世界設定，其中gravity是 一個CGVector，預設值是CGVector(dx: 0, dy: -9.8)——模擬地球重力，讓所有isDynamic = true且affectedByGravity = true的 物體持續往下掉。上一課已經把球的affectedByGravity 關掉了，但更直接的做法，是乾脆把整個場景的重力歸零， 通常放在didMove(to:)裡設定：

override func didMove(to view: SKView) { physicsWorld.gravity = CGVector(dx: 0, dy: 0) // 或寫成 physicsWorld.gravity = .zero }

重力歸零之後，球才會照著我們給它的速度，沿直線方向 移動，只有撞到東西時才會改變方向——這正是打磚塊需要 的「由上往下看」的彈射手感，而不是被地心引力拉著往 螢幕底部掉。

2. 用velocity給球一個初始速度

physics body的velocity是一個CGVector， 代表這個物體目前每秒鐘在x、y方向各移動多少點（point）。 只要幫球設定一個非零的velocity，球就會開始朝那個方向 持續移動——這是牛頓第一運動定律的直接體現：沒有外力 （這裡重力已歸零）介入時，物體會維持等速直線運動， 直到撞到別的東西為止：

ball.physicsBody?.velocity = CGVector(dx: 140, dy: -220)

這裡的dx: 140, dy: -220代表球每秒鐘往右 移動140點、往下移動220點——由於SpriteKit的y軸預設是 向上為正（回顧第18課座標系統），負的dy 代表朝畫面下方發射，符合「開始畫面按下開始後，球從 中間往下朝球拍方向射出」的直覺。

3. restitution：讓球維持穩定的反彈力道

restitution（恢復係數，也就是彈性）是一個 0到1之間的CGFloat，預設值是0.2，代表物體 碰撞後保留多少比例的速度：0代表完全不反彈（撞上去就 黏住不動），1代表完全彈性碰撞（碰撞前後速度大小不變， 理論上可以一直彈下去不會變慢）。打磚塊遊戲希望球撞到 牆壁、球拍、磚塊之後，還能維持差不多的速度繼續彈射， 所以要把restitution設得接近1：

ball.physicsBody?.restitution = 1.0

4. friction與linearDamping：避免球逐漸慢下來

除了restitution，還有兩個屬性會讓球在沒有明顯察覺的 情況下越彈越慢：

  • friction——兩個物體表面互相接觸、滑動 時的摩擦力，預設值0.2，數值越高，接觸時速度損耗 越明顯
  • linearDamping——類似空氣阻力，即使沒有 碰到任何東西，也會讓物體的線性速度隨時間慢慢衰減， 預設值0.1

對打磚塊的球來說，這兩者都不是想要的效果——球應該只有 撞到東西時速度才改變方向，其餘時間都該保持等速直線 移動，所以通常都設成0：

ball.physicsBody?.friction = 0 ball.physicsBody?.linearDamping = 0

把這一課用到的物理屬性整理起來，球的完整設定大致是：

func setupBallPhysics() { ball.physicsBody = SKPhysicsBody(circleOfRadius: ball.size.width / 2) ball.physicsBody?.isDynamic = true ball.physicsBody?.affectedByGravity = false ball.physicsBody?.restitution = 1.0 ball.physicsBody?.friction = 0 ball.physicsBody?.linearDamping = 0 ball.physicsBody?.velocity = CGVector(dx: 140, dy: -220) }
