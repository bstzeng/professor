分數系統

這一課的目標

  • 加入一個score變數，追蹤玩家目前的分數
  • 學會用SKLabelNode把分數顯示在畫面上，並放在畫面上方適當的位置
  • 讓每次磚塊被消滅時，同步更新分數與畫面上的文字

模組G結束時，球已經能撞掉磚塊，但玩家看不到任何「表現 如何」的回饋——磚塊一顆一顆消失，卻沒有分數、沒有進度 感。模組H要處理的正是這種遊戲邏輯與狀態管理，第一課 從最直覺的分數系統開始：加一個變數記錄分數，再用畫面 上的文字把它顯示出來。

1. 宣告score變數

在GameScene類別裡加入一個儲存分數的屬性， 初始值設為0：

class GameScene: SKScene, SKPhysicsContactDelegate { var score = 0 // ... }

2. 用SKLabelNode顯示分數

SKLabelNode是SpriteKit裡專門用來顯示文字的 節點，跟SKSpriteNode一樣可以設定位置、大小、加入場景 節點樹。建立一個顯示分數的label，放在畫面上方：

let scoreLabel = SKLabelNode(fontNamed: "Helvetica-Bold") override func didMove(to view: SKView) { // 其餘physics設定... scoreLabel.text = "分數：0" scoreLabel.fontSize = 24 scoreLabel.fontColor = .white scoreLabel.position = CGPoint(x: frame.midX, y: frame.maxY - 50) scoreLabel.zPosition = 10 addChild(scoreLabel) }

fontNamed:指定字型名稱；text是 目前顯示的字串；position用 frame.midX取畫面水平置中， frame.maxY - 50則是從畫面最上方往下留一點 邊距，讓文字不會貼在螢幕邊緣；zPosition 設得比較高（例如10），確保分數文字畫在球、磚塊這些 節點的上層，不會被擋住。

3. 磚塊被消滅時更新分數

分數該在什麼時候增加？答案就是第32課 didBegin(_:)裡磚塊被移除的那一刻——在呼叫 removeFromParent()的同時，把分數加上去、 並更新label的文字：

func didBegin(_ contact: SKPhysicsContact) { let bodyA = contact.bodyA let bodyB = contact.bodyB let brickBody: SKPhysicsBody if bodyA.categoryBitMask == PhysicsCategory.brick { brickBody = bodyA } else if bodyB.categoryBitMask == PhysicsCategory.brick { brickBody = bodyB } else { return } brickBody.node?.removeFromParent() score += 10 scoreLabel.text = "分數：\(score)" }

每消滅一顆磚塊得10分，可以依照磚塊的顏色、行數等等 設計不同的分數（例如越上排的磚塊分數越高），但核心 邏輯都一樣：修改score之後，記得同步更新 scoreLabel.text——這兩件事沒有自動綁定， 漏了其中一步，畫面就不會反映真正的分數。

檢查你的理解

  1. 說明SKLabelNode跟SKSpriteNode的差異，以及各自常見的用途
  2. 解釋scoreLabel.position為什麼用frame.midX跟frame.maxY - 50
  3. 說明為什麼修改score之後，一定要記得同步更新scoreLabel.text
