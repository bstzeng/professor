模組 B｜地端LLM基礎：安裝與執行Ollama · 第 6 課

拉取並執行你的第一個地端模型

這一課的目標

  • 學會用ollama pull把一個模型下載到自己的電腦上
  • 學會用ollama run啟動互動式對話，實際跟地端模型對話
  • 知道怎麼結束一場互動式對話、回到一般的終端機畫面

上一課裝好了Ollama本身，但電腦上還沒有任何一個模型可以 用——Ollama只是負責執行模型的工具，模型檔案本身要另外 下載。這一課要把第一個模型拉下來，並且直接在終端機裡 跟它對話一次，實際感受一下地端LLM運作起來是什麼樣子。

1. ollama pull：把模型下載到本機

Ollama維護了一個公開的模型庫，收錄了許多開放權重的 LLM，可以用ollama pull加上模型名稱下載。 這一課先用llama3.2這個體積相對小、適合 一般電腦入門的模型示範：

ollama pull llama3.2

執行之後，終端機會顯示下載進度，類似下面這樣（實際 呈現的層數與百分比會依模型而不同）：

pulling manifest pulling dde5aa3fc5ff... 100% ▕████████████████▏ 2.0 GB pulling 966de95ca8a6... 100% ▕████████████████▏ 1.4 KB verifying sha256 digest writing manifest success

看到success，代表模型的權重檔案已經完整 下載到本機，之後不需要再重新下載，就能直接執行。

2. ollama run：啟動互動式對話

模型下載好之後，用ollama run加上模型名稱， 就能直接在終端機裡跟它開始對話：

ollama run llama3.2

終端機會出現一個等待輸入的提示符號，這時候直接打字、 按下Enter，就能把訊息送給模型：

>>> Send a message (/? for help)

輸入一句問題，例如「用一句話說明什麼是地端LLM」，模型 會直接在終端機裡把回覆的文字逐步印出來——這整個過程 完全在你自己的電腦上運算，沒有任何內容被傳送到外部 伺服器。

小提醒：ollama run 沒下載過的模型會自動先pull

如果直接對一個還沒下載過的模型執行ollama run， Ollama會自動先把它pull下來，再進入互動模式，不會 報錯要求你先手動pull。這一課特意把兩個步驟分開講， 是為了讓你清楚知道「下載模型」跟「執行模型」其實是 兩件不同的事。

3. 結束對話與基本操作

對話結束後，在提示符號下輸入/bye，就能 離開互動模式、回到一般的終端機畫面：

>>> /bye

另外，輸入/?可以看到目前這個互動模式支援 的其他內建指令，例如切換模型、查看目前的對話設定等。
