模組 B｜地端LLM基礎：安裝與執行Ollama · 第 8 課

Ollama常用CLI指令

這一課的目標

  • 學會用ollama list查看目前電腦上已經下載的模型
  • 學會用ollama rm刪除模型、用ollama ps查看目前正在執行的模型與記憶體佔用
  • 學會用ollama show查看一個模型的詳細參數設定

前面兩課學會了拉模型、跑模型、挑選合適的模型等級， 隨著下載的模型越來越多，會需要一些管理上的指令—— 知道自己電腦上到底裝了哪些模型、誰正在佔用記憶體、 該刪掉哪些不再需要的版本。這一課整理四個最常用到 的管理指令。

1. ollama list：查看已下載的模型

想知道目前電腦上已經下載了哪些模型，執行：

ollama list

會列出一張表格，包含模型名稱、模型ID、檔案大小、以及 最後修改時間，類似下面這樣：

NAME ID SIZE MODIFIED llama3.2:latest a80c4f17acd5 2.0 GB 3 days ago

這是確認「我到底裝了什麼」最直接的方式，特別是在下載 過好幾個不同大小、不同量化版本的模型之後。

2. ollama rm：刪除不需要的模型

模型檔案通常有數GB以上，如果某個模型已經不再需要， 可以用ollama rm加上模型名稱刪除，釋放 硬碟空間：

ollama rm llama3.2

刪除後，這個模型就不在ollama list的清單裡 了，如果之後又想用，需要重新ollama pull 下載一次。

3. ollama ps：查看目前執行中的模型

Ollama在你第一次使用某個模型時，會把它載入記憶體，並且 在一段閒置時間之後才會自動卸載，不是每次對話都要重新 載入一次。想知道目前有哪些模型正佔用記憶體、佔用了多少， 執行：

ollama ps

輸出類似下面這樣：

NAME ID SIZE PROCESSOR UNTIL llama3.2:latest a80c4f17acd5 3.5 GB 100% GPU 4 minutes from now

PROCESSOR這一欄會顯示模型目前是用CPU還是 GPU運算（如果電腦有支援的獨立顯卡，Ollama會優先使用 它），UNTIL則顯示這個模型還會在記憶體裡 保留多久，超過這段閒置時間沒有新的請求，就會自動被 卸載，釋放記憶體給其他用途。

4. ollama show：查看模型詳細資訊

想知道某個模型的參數量、量化等級、支援的上下文長度等 詳細資訊，執行ollama show加上模型名稱：

ollama show llama3.2

輸出會列出這個模型的架構資訊（例如參數量、量化等級、 上下文長度），以及它預設使用的提示詞範本（template） 跟授權條款（license）等內容——這在你想確認「我現在 跑的到底是哪個版本、上下文長度夠不夠用」時特別實用， 後面模組談Prompt設計時也會再用到這裡看到的資訊。

檢查你的理解

  1. 寫出查看已下載模型清單、以及刪除一個模型分別要用的指令
  2. 說明ollama ps裡的UNTIL欄位代表什麼意思
  3. 說明ollama show能看到哪些資訊，什麼情況下你會需要用到它
