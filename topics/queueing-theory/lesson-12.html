用程式產生隨機到達

這一課的目標

  • 知道如何產生指數亂數
  • 會寫簡單的到達產生器
  • 理解逆變換法

要模擬排隊，第一步是產生隨機的到達時刻。電腦內建的亂數 U 介於 0 和 1 之間，用逆變換法可以把它變成指數分布：

\[T = -\frac{\ln(1-U)}{\lambda}\]
import random, math def arrivals(lam, minutes): t, out = 0.0, [] while True: t += -math.log(1 - random.random()) / lam # 下一個間隔 if t > minutes: return out out.append(t) print(len(arrivals(2, 60))) # 大約 120

Excel 也能做：在儲存格輸入 =-LN(1-RAND())/2 就是平均 0.5 分鐘的間隔，往下累加就是到達時刻。本主題的互動模擬都是這樣產生客人的。

有了到達與服務時間的產生器，再加上「事件依時間先後處理」的邏輯，就是第 45 課的離散事件模擬。

🧭 這一課的重點

用逆變換 T = −ln(1−U)/λ 可以產生指數間隔，累加就得到卜瓦松到達時刻。
