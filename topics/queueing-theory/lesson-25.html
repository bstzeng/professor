爾朗 C 公式：客服中心要排幾個人

這一課的目標

  • 認識話務量與爾朗 C
  • 會用服務水準決定人數
  • 用互動做人力規劃

話務量 \(A = \lambda/\mu\)（單位：爾朗）＝平均同時需要的服務人數。爾朗 C 公式給出「來電需要等待」的機率：

\[C(c, A) = \frac{\dfrac{A^c}{c!}\dfrac{c}{c-A}}{\displaystyle\sum_{k=0}^{c-1}\frac{A^k}{k!} + \frac{A^c}{c!}\frac{c}{c-A}},\qquad W_q = \frac{C(c,A)}{c\mu - \lambda}\]

客服業常用服務水準，例如「80% 的來電在 20 秒內接起」：

\[SL = 1 - C(c,A)\, e^{-(c\mu-\lambda)t}\]

實務上還要加上「排班係數」：休息、教育訓練、請假等，實際排班人數通常要再多 20～35%。

🧭 這一課的重點

爾朗 C 公式計算等待機率與平均等待，可用來找出達到服務水準所需的最少人數。
