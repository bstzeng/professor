離散事件模擬

這一課的目標

  • 了解離散事件模擬的原理
  • 會寫簡單的模擬程式
  • 知道模擬的注意事項

真實系統常有時變到達、多種顧客、複雜路線、班表，公式無法處理。這時就用離散事件模擬：維護一個「事件清單」，依時間順序處理每個事件（到達、服務完成），並記錄統計。

import heapq, random, math exp = lambda m: -math.log(1 - random.random()) * m def mm1(lam, mu, n=100000): t_free, waits, t = 0.0, [], 0.0 for _ in range(n): t += exp(1 / lam) # 下一位到達 start = max(t, t_free) # 櫃台空了才開始 waits.append(start - t) t_free = start + exp(1 / mu) # 服務完成時刻 return sum(waits) / n print(mm1(0.8, 1.0)) # 理論值 4.0

注意事項：

  • 暖機期：模擬從空的系統開始，前段資料要丟掉。
  • 重複與信賴區間：跑很多次，報告平均值與信賴區間，不能只跑一次。
  • 驗證：先用有公式的簡單情況檢查程式正確。

常用工具有 Python 的 SimPy、商用的 Arena、AnyLogic、Simio。

🧭 這一課的重點

離散事件模擬依時間處理事件、累積統計，能處理公式無法處理的複雜系統；要注意暖機、重複與驗證。
