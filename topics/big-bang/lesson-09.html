度規張量：怎麼測量彎曲時空裡的距離

這一課的目標

  • 從畢氏定理出發，推廣出描述任意（包括彎曲）時空中距離的一般公式 ds² = gμνdxμdxν
  • 認識平坦閔考斯基時空的度規，理解它跟一般彎曲度規的差異在哪裡
  • 理解度規張量是廣義相對論裡最核心的物件——曲率、測地線、場方程式，最終都是從它建構出來的

第 8 課用球面三角形建立了「內在曲率可以純靠測量偵測到」的直覺，但一直沒有給出一套精確的 數學工具來執行這個測量。這一課要介紹廣義相對論裡最核心的數學物件—— 度規張量（metric tensor），它正是回答「在這個空間（或時空）裡，兩個相鄰的點 之間到底相距多遠」這個問題的工具。

1. 起點：畢氏定理

在平坦的二維平面上，用直角座標 (x, y) 描述位置，兩個無窮接近的點之間，座標差 (dx, dy) 對應的實際距離 ds，由畢氏定理給出：

ds² = dx² + dy²

推廣到三維空間，加上 z 座標：ds² = dx² + dy² + dz²。這個公式看起來理所當然，但它其實隱含了 一個特定的假設——空間是平坦的，而且我們用的是「筆直」的直角座標系。如果換一種座標系， 即使空間仍然平坦，公式的形式也會改變。

2. 換個座標系，公式長相就不一樣：極座標的例子

考慮同一個平坦的二維平面，但改用極座標 (r, θ) 描述位置（r 是到原點的距離，θ 是角度）。 座標的微小變化 (dr, dθ) 對應的實際距離，這次要用：

ds² = dr² + r² dθ²

注意 dθ 前面的係數是 r²，會隨著位置（距離原點多遠）改變——但這個空間本身仍然完完全全是 平坦的，跟直角座標描述的是同一個平面！這是這一課最重要的觀念之一：度規的係數不是常數， 不代表空間一定是彎曲的——那有可能只是選了一種「彎曲」的座標系（極座標的座標線本身 是同心圓跟放射線，不是筆直的網格）去描述一個平坦的空間。要真正判斷空間是否彎曲，需要一個 跟座標選擇無關的判準，這是第 11 課曲率張量要處理的問題；這一課先把「怎麼用度規計算距離」 這個工具本身建立起來。

3. 一般公式：度規張量 gμν

把上面的想法推廣到任意維度、任意座標系（包括真正彎曲的空間），距離公式的一般形式寫成：

ds² = gμν dxμ dxν

這裡用了愛因斯坦求和約定的簡寫：只要同一個指標（這裡是 μ 跟 ν）分別以 上標、下標各出現一次，就代表對這個指標所有可能的值（例如四維時空中 μ, ν 各自跑遍 0, 1, 2, 3）自動求和，不用另外寫求和符號 Σ。完整寫開來（以四維時空為例）就是：

ds² = Σμ=03 Σν=03 gμν dxμ dxν

gμν 是一個對稱的（gμν = gνμ）矩陣，稱為度規張量， 它的分量可以隨時空中的位置而改變。給定 gμν，你就能算出這個時空裡任何兩個無窮接近 的點之間的間隔 ds——這個指標記號跟求和約定的完整、正式規則，第 10 課的數學工具箱會補完； 這一課先把它當作一個直觀夠用的簡寫。

4. 平坦時空的度規：閔考斯基度規

狹義相對論描述的平坦時空（沒有重力、沒有加速度的時空），用直角時空座標 (t, x, y, z) 時，度規張量取一個特別簡單的常數形式，稱為閔考斯基度規 ημν （這裡採用 c=1 的自然單位，也就是用光走的距離當作時間的單位）：

ημν = diag(−1, +1, +1, +1)

對應的間隔公式：

ds² = −dt² + dx² + dy² + dz²

跟畢氏定理最大的不同是時間項前面帶了一個負號——這正是狹義相對論「時空」 （而不是純粹的四維歐幾里得空間）的正負號特徵（signature）。這個負號帶來了物理上重要的區分： ds² < 0 的間隔稱為類時（timelike），代表兩個事件之間可以有一個有質量的 物體以低於光速的速度連接（例如同一個粒子世界線上先後發生的兩個事件）；ds² > 0 稱為 類空（spacelike），代表兩個事件之間任何物理訊號都來不及連接； ds² = 0 稱為類光（null/lightlike），正是光線行進的路徑。

閔考斯基度規之所以特別重要，是因為它扮演彎曲時空理論裡的「基準」：如果一個時空的度規在某個 點附近能被適當選取的座標系轉換成 ημν 的形式（至少在該點的一階近似），這正好呼應 第 7 課等效原理的說法——局部而言，任何彎曲時空看起來都「近似平坦」，就像球面上足夠小的區域 看起來近似一個平面一樣。

5. 度規如何編碼真正的幾何／曲率資訊

一般而言，gμν 的分量會隨時空位置改變，而且這種改變原則上有兩種完全不同的來源： 一種只是「選了一組彎曲的座標系」（像前面極座標的例子，空間其實還是平的）；另一種才是空間 本身真正具有內在曲率。第 11 課會給出能明確區分這兩種情形的工具（黎曼曲率張量：對真正平坦的 空間，不管用什麼座標系，這個張量算出來都恆為零；對真正彎曲的空間，它不為零）。這一課的重點 是先熟悉：不管度規背後代表的是哪一種情形，gμν 都是唯一需要知道、就能算出任意兩點 間隔的物件——它是整個廣義相對論數學結構的地基。

這一課最重要的一句話

度規張量 gμν 是廣義相對論裡「萬物的起點」：它定義了距離跟時間間隔怎麼算，接下來 第 11 課的曲率、測地線，都是從 gμν 透過微分運算構造出來的量；第 13 課的愛因斯坦場 方程式，本質上就是一個決定 gμν 該怎麼被物質、能量所彎曲的方程式。學會怎麼讀懂 一個度規，就等於掌握了一把打開整個模組 C（弗里德曼方程式）大門的鑰匙。

檢查你的理解

  1. 寫出用度規張量表示時空間隔的一般公式，並說明公式裡每個符號代表什麼。
  2. 為什麼平坦空間換成極座標描述後，度規係數會隨位置改變？這是否代表空間變彎曲了？
  3. 閔考斯基度規 ημν = diag(−1,+1,+1,+1) 裡的負號，在物理上區分出哪三種類型的時空間隔？
