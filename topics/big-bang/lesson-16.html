模組 C｜FRW度規與弗里德曼方程式完整推導 · 第 16 課

完整推導弗里德曼方程式（一）：把FRW度規代入場方程式

這一課的目標

  • 理解從度規計算克里斯多福符號的一般方法，並知道FRW度規非零的克里斯多福符號有哪些
  • 記住並理解FRW度規的芮奇張量與芮奇純量結果：R₀₀ = −3(ä/a)，R = 6[ä/a + (ȧ/a)² + k/a²]
  • 把完美流體的應力-能量張量跟這些幾何量放進愛因斯坦方程式的00分量，為第17課的化簡做好準備

第 15 課寫出了 FRW 度規的精確形式。這一課開始執行模組 B 建立的完整程序：從度規張量 gμν 出發，算出克里斯多福符號 Γ、芮奇張量 Rμν、芮奇純量 R， 組成愛因斯坦張量 Gμν，再讓它等於完美流體的應力-能量張量 8πG·Tμν。 這是整套廣義相對論工具箱在具體問題上的第一次完整實戰——過程涉及不少代數，這一課先把 「怎麼算」跟「算出什麼」講清楚，第 17 課再完成最後的化簡，正式導出弗里德曼方程式。

1. 計算克里斯多福符號的一般方法

模組 B 第 11 課定義過克里斯多福符號的一般公式：

Γλμν = (1/2) gλσ(∂μgσν + ∂νgσμ − ∂σgμν)

方法很機械：把 FRW 度規的十個獨立分量 gμν（g00=−1，grr=a²/(1−kr²)， gθθ=a²r²，gφφ=a²r²sin²θ，其餘非對角項為零）逐一對每個座標 (t, r, θ, φ) 微分，代入上面的公式，逐一算出每個 Γλμν。這個計算本身 不涉及任何新概念——純粹是代數，只是分量很多。因為 FRW 度規高度對稱（只有對角分量非零， 且只依賴 t 跟 r、θ），大部分的 Γ 分量會直接等於零，真正非零的只有一小部分，主要可以分成 兩類：

FRW度規非零的克里斯多福符號（略去繁瑣的中間代數，只列結果）

混合時間-空間項，描述「空間度規隨時間膨脹」帶來的效應，例如 Γ0rr = a ȧ/(1−kr²)，Γr0r = Γθ0θ = Γφ0φ = ȧ/a——這一類全部正比於 ȧ/a，是尺度因子變化率跟空間度規 耦合的直接體現。

純空間項，跟第 15 課三維空間本身的曲率有關，例如 Γrθθ = −r(1−kr²)，Γθrθ = 1/r，以及涉及 sinθ、cosθ 的角度項——這一類完全來自方括號內三維空間度規的幾何，跟 k 有關， 但不牽涉時間微分。

2. FRW度規的芮奇張量與芮奇純量

有了克里斯多福符號，下一步是代入模組 B 第 11 課定義的芮奇張量公式（黎曼張量的縮並）。 因為 FRW 度規的對稱性，芮奇張量也高度簡化：非對角分量全部為零，而且由於空間的均向性， 三個空間對角分量 Rrr、Rθθ、Rφφ（各自除以對應的 grr、gθθ、gφφ）彼此相等——這正是均向性在數學上的具體 表現：任何一個純量或張量的空間分量，都不能偏好某個方向。計算結果是：

R₀₀ = −3 (ä/a)

空間分量合併整理後，芮奇純量（芮奇張量對度規的完全縮並，R = gμνRμν） 等於：

R = 6 [ ä/a + (ȧ/a)² + k/a² ]

（這裡 ȧ ≡ da/dt，ä ≡ d²a/dt² 分別是尺度因子的一階、二階時間導數。）值得注意 R₀₀ 只跟 ä/a（加速度）有關，跟 ȧ 或 k 都無關——時間方向的曲率完全由膨脹的「加速」或 「減速」決定；而芮奇純量 R 則同時包含加速度項、膨脹率平方項、跟空間曲率項，是整個 時空彎曲程度的總和度量。

3. 回顧完美流體的應力-能量張量

模組 B 第 12 課推導過，宇宙學裡把物質內容近似成一個各向同性的完美流體 （perfect fluid）——這正是宇宙學原理要求的：物質的能量密度 ρ 跟壓力 p 必須在空間中 均勻、在各方向上均向，不能有黏滯或熱傳導這類會破壞均向性的效應。在共動觀測者的靜止座標系 （也就是 FRW 座標系）裡，完美流體的應力-能量張量是對角的：

T00 = −ρ,   Tij = p δij

時間分量給出負的能量密度（正負號的慣例來自度規簽名 (−,+,+,+)），三個空間分量全部等於 壓力 p，這正是均向性要求的結果：壓力在各方向必須完全相同，不能有任何方向性的應力。

4. 設立00分量的愛因斯坦方程式

愛因斯坦張量的定義是 Gμν = Rμν − (1/2) R gμν。 取 μν = 00 分量，代入前面算出的 R₀₀、R，以及 g₀₀ = −1：

G₀₀ = R₀₀ − (1/2) R g₀₀ = −3(ä/a) − (1/2) {6[ä/a + (ȧ/a)² + k/a²]} (−1)

這個式子還沒化簡——右邊還有 ä/a 這一項同時出現在兩處，看起來需要進一步整理才能得到 乾淨的結果。把它跟愛因斯坦方程式的 00 分量 G₀₀ = 8πG T₀₀ 放在一起（其中 T₀₀ = g₀₀T00 = (−1)(−ρ) = ρ），就得到：

−3(ä/a) − (1/2) {6[ä/a + (ȧ/a)² + k/a²]} (−1) = 8πG ρ

這正是下一課要展開的起點——把左邊的代數化簡到底，會發現 ä/a 那一項精確抵消，只剩下 一個乾淨、只跟 ȧ/a 跟 k/a² 有關的方程式，也就是第一弗里德曼方程式。這個「ä/a 剛好 消失」不是巧合，而是愛因斯坦張量構造（減去 (1/2)Rgμν 這一項）的必然結果—— 這個構造原本就是為了讓 Gμν 滿足比安基恆等式、確保跟能量守恆一致而設計的。

檢查你的理解

  2. 寫出FRW度規的芮奇純量結果 R = 6[ä/a + (ȧ/a)² + k/a²]，並說出其中每一項的來源（時間曲率、空間曲率）
  3. 解釋為什麼完美流體的空間應力分量 Ti_j 必須正比於 δi_j——這跟均向性有什麼關係
