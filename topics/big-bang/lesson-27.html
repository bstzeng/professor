模組 E｜大霹靂核合成：早期宇宙的核子物理 · 第 27 課

完整推導氘瓶頸：為什麼核合成要等到特定溫度才開始

這一課的目標

  • 指出一個表面上的矛盾：氘束縛能2.2 MeV，為什麼核合成要等到約0.1 MeV才開始
  • 推導光子質子比 η 如何透過「光致分解」的平衡條件，把氘形成的溫度大幅延後
  • 理解這個延遲如何跟第26課的中子衰變效應接軌，共同決定最終元素豐度

第26課推導出弱交互作用在 T≈0.8 MeV 凍結，留下 n/p≈1/6 的比例。照理說，接下來只要溫度 繼續下降到氘的束縛能 2.2 MeV 以下，質子跟中子就該開始結合成氘（p+n→D+γ），核合成的第一步 就此展開。但精確計算（也是觀測）顯示：核合成真正大規模啟動，要等到溫度降到大約 0.07–0.1 MeV 才發生——比氘束縛能整整低了一個數量級以上。這個延遲不是巧合，而是宇宙裡 光子數量遠遠超過重子（質子、中子）數量這個事實所造成的，稱為氘瓶頸 （deuterium bottleneck）。這一課要把這個延遲完整推導出來。

1. 氘作為核合成的第一塊積木

氦-4（以及更重的少量元素）沒辦法由質子跟中子一步直接結合而成——實際反應鏈幾乎都要先經過氘：

p + n → D + γ　　（氘的束縛能 BD ≈ 2.2 MeV）

之後才能透過 D+D、D+p、D+n 等反應逐步組裝成氦-3、氚、最終氦-4。因為幾乎所有通往氦的路徑 都要經過氘，氘形成的難易程度，直接決定了整個核合成鏈什麼時候能開始——這正是「瓶頸」這個 名字的由來。

2. 天真的估計：為什麼會錯

一個直覺的猜測是：只要熱能 T 降到 BD≈2.2 MeV 以下，光子的平均能量就不足以拆散 剛形成的氘核，氘應該能穩定累積。但這個猜測忽略了一件事：光子的能量並不是全部整整齊齊地等於 平均能量 T——黑體輻射的光子能量分布是連續的，遵守普朗克分布，存在一條向高能量延伸的 指數尾巴。即使平均光子能量遠低於 2.2 MeV，光子總數裡，能量高於 2.2 MeV 的那一部分 （雖然佔比很小）依然存在。

真正決定勝負的，不是「有沒有」高能光子，而是「高能光子的數量夠不夠多」——這就要看 光子總數跟重子（質子＋中子）總數的相對比例。

3. 光子質子比 η：一個天文數字

觀測（以及第28課要驗證的核合成豐度、第34課CMB功率頻譜）都指向宇宙裡光子數目跟重子數目 的比例是：

η ≡ nbaryon / nγ ≈ 6×10⁻¹⁰

反過來說，η−1≈1.7×10⁹——平均每一個重子，對應著大約17億個光子。這是一個極端懸殊 的比例，也是後面整個推導的核心數字。

4. 類 Saha 方程式：平衡條件的完整推導

要精確判斷氘什麼時候能「存活」，需要比較氘的形成率跟光致分解率 （γ+D→p+n，光子把氘拆散的逆反應）。在熱平衡下，氘、質子、中子、光子的數密度滿足類似 Saha 方程式的關係（統計力學對平衡態粒子數密度的標準結果）：

nD/(npnn) ∝ exp(BD/T)　（束縛態相對自由態的波茲曼增強）

把這個平衡比例，跟「光子數量遠超重子數量」這個事實放在一起看：氘能不能累積，取決於 「形成氘的反應」相對「光致分解氘的反應」誰佔上風。光致分解率正比於「有能力拆散氘的高能光子 的數密度」，而這部分光子數密度（能量 >BD 的普朗克分布尾端）相對於總光子數密度， 本身就帶有一個波茲曼壓低因子 exp(−BD/T)。氘能夠淨累積的條件，需要「總光子數量 乘上這個壓低因子」不再超過重子數量——也就是說，平衡被打破、氘開始淨累積的條件， 大致可以寫成：

氘瓶頸的平衡條件（量級推導）

η−1 · exp(−BD/T) ≲ 1

等價地寫成 η·exp(BD/T) ≳ 1。直覺意義：即使單一光子拆散氘的機率因為波茲曼因子 exp(−BD/T) 而變得很小，但只要「總光子數 / 重子數」這個巨大的 η−1 因子還沒被壓低因子完全抵消，光子總數依然多到能持續把新形成的氘拆光——氘就無法累積。 只有當溫度低到讓 exp(−BD/T) 這個壓低因子小到足以壓過 η−1≈1.7×10⁹ 這麼大的數量級劣勢，光致分解才會真正停止追上形成速率。

5. 解出瓶頸溫度

對平衡條件 η−1exp(−BD/T)≈1 取對數，解出瓶頸溫度 Tbottleneck：

BD/Tbottleneck ≈ ln(η−1) ≈ ln(1.7×10⁹) ≈ 21.3

Tbottleneck ≈ BD/21.3 ≈ 2.2/21.3 MeV ≈ 0.10 MeV

這正是觀測與精確數值計算得到的量級：T≈0.07–0.1 MeV，比氘的束縛能 2.2 MeV 低了超過20倍。 對數因子 ln(η−1) 是整個延遲的關鍵——因為 η 是一個天文數字，它的自然對數雖然 「只有」大約21，但這已經足以把瓶頸溫度壓低到束縛能的二十分之一左右。這就是為什麼氘瓶頸 延遲得如此顯著：不是因為某個反應特別慢，而是光子數量的絕對優勢，需要溫度降到極低才能 被指數壓低因子克服。

6. 延遲的後果：跟第26課接軌

瓶頸溫度 T≈0.1 MeV，用第25課的溫度—時間公式換算，對應宇宙年齡大約 t≈100–200 秒。 這代表從第26課的弱交互作用凍結（t≈1秒）到核合成真正啟動（t≈200秒），中間有幾分鐘的空窗期—— 正是這段時間裡，部分自由中子透過 β 衰變流失，把 n/p 比從凍結時的約1/6進一步壓低到 核合成啟動時的約1/7（第26課已推導）。氘瓶頸的存在，不只是解釋「核合成什麼時候開始」， 它也是「中子衰變效應為什麼重要」的物理原因：正是這段延遲，給了中子衰變足夠的時間發揮作用。

這一課的關鍵洞見

氘瓶頸的核心是一個對數效應：η 這個天文數字量級的比例，透過 ln(η−1) 只需要 「稀釋」大約21個單位的 BD/T，就能把瓶頸溫度壓到束縛能的二十分之一左右。 這種「指數壓低因子對抗天文數字比例」的推理模式，在下一模組討論復合時期（第30課）時 會再次出現——氫的電離能13.6 eV跟復合實際發生的溫度（約0.3 eV）之間，同樣有著幾乎一模一樣的 η 對數延遲邏輯。

  2. 說明光子質子比 η 在氘瓶頸的平衡條件 η−1exp(−BD/T)≈1 中扮演的角色。
