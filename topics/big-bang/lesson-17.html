完整推導弗里德曼方程式（二）：加速度方程式與流體方程式

這一課的目標

  • 完成第16課的代數，正式導出第一弗里德曼方程式：(ȧ/a)² = (8πG/3)ρ − k/a²
  • 用空間分量的愛因斯坦方程式，推導第二弗里德曼方程式（加速度方程式）：ä/a = −(4πG/3)(ρ+3p)
  • 從能量守恆推導流體方程式，並理解三個方程式之間「只有兩個獨立」的關係

第 16 課把 FRW 度規代入愛因斯坦方程式的 00 分量，得到一個還沒化簡的式子。這一課先完成 那個代數，接著處理空間分量、能量守恆，把宇宙學裡最重要的三個方程式一次推導完整。

1. 化簡00分量：第一弗里德曼方程式

回到第 16 課留下的方程式：

−3(ä/a) − (1/2) {6[ä/a + (ȧ/a)² + k/a²]} (−1) = 8πG ρ

把 −(1/2)(−1) = +(1/2) 乘進大括號：

−3(ä/a) + 3[ ä/a + (ȧ/a)² + k/a² ] = 8πG ρ

−3(ä/a) + 3(ä/a) + 3(ȧ/a)² + 3k/a² = 8πG ρ

兩個 ä/a 項如第 16 課預告的那樣精確抵消，只剩下：

3(ȧ/a)² + 3k/a² = 8πG ρ

兩邊除以 3，得到第一弗里德曼方程式：

(ȧ/a)² = (8πG/3) ρ − k/a²

這是宇宙學裡最重要的方程式：左邊的 ȧ/a（常記作 H，哈伯參數，模組 A 第 2 課的哈伯常數 H₀ 就是它今天的值）描述宇宙的膨脹速率，右邊完全由物質的能量密度 ρ 跟空間曲率 k 決定 ——宇宙膨脹得多快，是由它裡面裝了多少「東西」跟空間本身彎不彎曲，共同決定的。

2. 空間分量與第二弗里德曼方程式

用完全相同的方法（第16課的程序），但這次取愛因斯坦方程式的空間（ij）分量。因為均向性， 三個空間對角分量給出同一個獨立方程式，整理後可以寫成：

2(ä/a) + (ȧ/a)² + k/a² = −8πG p

這個式子仍然同時含有 ä/a 跟 (ȧ/a)²、k/a² 三項，還不夠乾淨。但注意：(ȧ/a)² + k/a² 這個 組合，正好是第一弗里德曼方程式的左邊，等於 (8πG/3)ρ。把這個結果代進去替換：

2(ä/a) + (8πG/3) ρ = −8πG p

2(ä/a) = −8πG p − (8πG/3) ρ = −8πG (p + ρ/3)

兩邊除以 2，並把括號內的分數通分：

ä/a = −(4πG/3) (ρ + 3p)

這是第二弗里德曼方程式，也稱為加速度方程式或雷查杜里方程式 （Raychaudhuri equation 的宇宙學特例）。注意它跟第一弗里德曼方程式的關鍵差異：第一方程式 描述膨脹率（ȧ/a 的平方，一階效應），第二方程式描述膨脹率的變化 （ä/a，二階效應）——換句話說，第一方程式回答「宇宙現在膨脹多快」，第二方程式回答 「這個膨脹速率本身正在加速還是減速」。

3. 驚人的物理意義：一般物質讓宇宙減速

關鍵觀察

能量密度永遠 ρ > 0（物質、輻射都帶正能量），而一般物質（例如氣體、輻射、塵埃）的 壓力也滿足 p ≥ 0。這代表 (ρ + 3p) > 0，因此 ä/a = −(4πG/3)(ρ+3p) < 0——加速度方程式 預測，只要宇宙裡裝的是「正常」物質，宇宙的膨脹一定會減速！這符合直覺： 物質之間互相吸引的重力，應該會拖慢宇宙膨脹的腳步，就像把一顆球往上拋，地球重力會讓它 持續減速一樣。

這個結論在二十世紀大半時間裡都被認為是理所當然的——整部宇宙學史，直到 1998 年超新星 觀測（模組 J 第 58 課會詳細介紹）才發現，宇宙的膨脹其實正在加速， 意味著必然存在某種 p < −ρ/3 的成分（負壓力！），才能讓 (ρ+3p) 變成負值，使 ä/a > 0。 這正是暗能量之謎的數學根源——第二弗里德曼方程式雖然在這一課只是個推導結果，它卻是 後面整個暗能量章節的方程式基礎。

4. 從能量守恆推導流體方程式

除了愛因斯坦方程式的兩個獨立分量，宇宙學裡還有第三個常用的方程式，來自局部能量-動量守恆 ∇μTμν = 0（模組 B 已說明，這個守恆律是愛因斯坦方程式透過比安基恆等式 自動保證的）。取其時間分量，並用熱力學的方式理解它最直接：考慮一塊跟著宇宙膨脹的 共動體積 V = a³（取單位共動體積），裡面的總能量是 E = ρ a³。宇宙膨脹是絕熱過程 （沒有熱量從外面流入——因為宇宙學原理下沒有「外面」），熱力學第一定律 dE = −p dV 給出：

能量隨時間的變化率：

dE/dt = d(ρa³)/dt = ρ̇ a³ + 3ρ a²ȧ

體積隨時間的變化率：

dV/dt = 3a²ȧ

代入 dE/dt = −p dV/dt：

ρ̇ a³ + 3ρ a²ȧ = −3p a²ȧ

兩邊除以 a³：

ρ̇ + 3(ȧ/a)(ρ + p) = 0

這正是流體方程式（連續方程式），它就是 ∇μTμ0 = 0 在 FRW 背景下的具體結果。物理意義很直接：ρ̇ 是能量密度的變化率，右邊 3(ȧ/a)ρ 這一項 描述純粹因為體積膨脹造成的密度稀釋，而 3(ȧ/a)p 這一項則描述壓力對外做功造成的額外能量 流失——這一項會在第 20 課討論輻射的密度為什麼比物質稀釋得更快時，扮演關鍵角色。

5. 三個方程式，只有兩個獨立

第一弗里德曼方程式、第二弗里德曼方程式、流體方程式，看起來是三個獨立的結果，但其實 彼此之間有代數關聯：把第一弗里德曼方程式 (ȧ/a)² = (8πG/3)ρ − k/a² 兩邊對時間微分， 再代入第二弗里德曼方程式消去 ä，整理後可以精確得到流體方程式 ρ̇+3(ȧ/a)(ρ+p)=0。 這代表這三個方程式中，任何兩個都能推出第三個——它們並非三條互相獨立的物理定律， 而是愛因斯坦方程式（本質上只提供兩個獨立分量：00 分量跟 ij 分量）加上比安基恆等式 自動保證的能量守恆，三者共同的產物。實際應用時，通常挑選第一弗里德曼方程式 加上流體方程式這一組（兩個一階方程式，比含二階導數的加速度方程式更方便 直接求解），第 21、22 課求解尺度因子時用的正是這一組。

檢查你的理解

  1. 完整寫出第一弗里德曼方程式跟第二弗里德曼方程式（加速度方程式）
  2. 解釋為什麼 ρ>0 且 p≥0 時，第二弗里德曼方程式預測宇宙膨脹一定減速；這對後來發現的宇宙加速膨脹意味著什麼
  3. 說明為什麼流體方程式不是獨立於前兩個方程式的第三條物理定律
