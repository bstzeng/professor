模組 B｜廣義相對論工具箱：從等效原理到愛因斯坦場方程式 · 第 12 課

應力-能量張量：物質怎麼告訴時空要怎麼彎曲

這一課的目標

  • 理解應力-能量張量 Tμν 如何描述物質、能量在時空中每一點的密度與流動
  • 推導宇宙學裡最關鍵的特例——完美流體的應力-能量張量——並理解每一項的物理意義
  • 在流體靜止座標系中，求出 Tμν 的分量分別對應能量密度 ρ 跟壓力 p，為模組 C 的推導做準備

第 11 課建立了描述時空幾何、曲率的一整套工具（度規、克里斯多福符號、黎曼張量、里奇張量）。 但廣義相對論的核心主張是：物質與能量決定時空要怎麼彎曲。這一課要建立描述 「物質與能量」這一側的數學語言——應力-能量張量，物理學家約翰·惠勒（John Wheeler）用一句 名言精準總結了廣義相對論的精神：「時空告訴物質如何運動；物質告訴時空如何彎曲」（"Spacetime tells matter how to move; matter tells spacetime how to curve."）第 11 課完成了前半句， 這一課要開始建立後半句所需要的工具。

1. 應力-能量張量：每一點的能量、動量密度與流動

應力-能量張量 Tμν 是一個對稱的二階張量，它在時空中每一點的分量， 完整描述了該處能量與動量的密度，以及它們如何流動、傳遞。具體來說，各分量的物理意義是：

分量物理意義
T00能量密度
T0i（i = 1,2,3）動量密度（等於能量流的通量，兩者由對稱性相等）
Tij（i, j = 1,2,3）應力：第 i 方向動量在第 j 方向的流動——對角項是壓力，非對角項是剪應力

任何形式的物質或能量——固體、氣體、輻射、電磁場——都有各自對應的 Tμν，這正是廣義 相對論場方程式（第 13 課）右手邊「物質、能量」那一側的完整數學表示。

2. 宇宙學裡最重要的特例：完美流體

宇宙學處理的對象——星系的平均分布、輻射、後面模組會談到的暗物質暗能量——在夠大的尺度上， 都能極好地用一種理想化模型描述：完美流體（perfect fluid）。這是一種沒有黏滯性、 沒有熱傳導、內部沒有剪應力的流體，完全由兩個純量描述：能量密度 ρ 跟壓力 p，加上流體整體的 運動狀態——用四維速度 uμ 描述（流體微觀元素在時空中運動的切向量， 歸一化滿足 gμνuμuν = −1，這裡沿用第 9 課 (−,+,+,+) 號差的 閔考斯基慣例）。完美流體的應力-能量張量寫成：

Tμν = (ρ + p) uμuν + p gμν

這正是整個模組 C 推導弗里德曼方程式時，要代入愛因斯坦場方程式右手邊的具體形式。這一課 剩下的篇幅，要在流體自身的靜止座標系中，把這個抽象公式的分量具體算出來，看看它到底 長什麼樣子。

3. 在流體靜止座標系中求出分量

在流體自身的靜止座標系裡，流體元素沒有空間運動，四維速度只有時間分量： uμ = (1, 0, 0, 0)。用度規 g00 = −1（第 9 課的閔考斯基度規）把它降指標： u0 = g00u0 = −1，ui = 0。把這些代入完美流體公式：

時間-時間分量：

T00 = (ρ+p)u0u0 + p g00 = (ρ+p)(−1)(−1) + p(−1) = (ρ+p) − p = ρ

空間-空間分量（對角項，i = j）：

Tij = (ρ+p)uiuj + p gij = 0 + p δij = p δij

混合分量（時間-空間，i ≠ 0）：

T0i = (ρ+p)u0ui + p g0i = 0 + 0 = 0

混合分量為零，正對應「靜止流體沒有淨動量流動」的物理直覺。把 T00 = ρ 用度規升成 混合指標形式（用第 10 課的升降指標工具，g00 = −1）：

T00 = g00T00 = (−1)(ρ) = −ρ

Tij = p · δij

這正是完美流體應力-能量張量最常被引用的形式：混合指標寫法下，Tμν 是一個對角矩陣，四個對角元素依序是 (−ρ, p, p, p)。這個負號的出現，純粹是 (−,+,+,+) 號差 約定跟指標升降規則共同作用的結果，不代表能量密度真的是負的——它只是這套記號慣例下的一個 特徵，讀相關文獻時要能認出並且不被誤導。

4. 這個工具接下來會怎麼用

完美流體的 Tμν（或 Tμν）之所以重要，是因為模組 C 推導弗里德曼 方程式時，會把它直接代入第 13 課即將完整寫出的愛因斯坦場方程式右手邊——宇宙中的物質、輻射 整體上被當作一團完美流體，用它的能量密度 ρ 跟壓力 p 描述。不同成分（輻射、一般物質、暗能量） 之間唯一的區別，會歸結成 ρ 跟 p 之間的關係（稱為物態方程式，模組 D 會處理），而應力-能量張量 的形式本身則保持不變。此外，應力-能量守恆律 ∇μTμν = 0（要求局部能量與 動量守恆，用到第 11 課的協變微分）在模組 C 推導流體方程式時也會派上用場，這裡先記住它的存在 即可，不需要現在展開。

檢查你的理解

  1. 說明應力-能量張量 Tμν 的各分量（T₀₀、T₀ᵢ、Tᵢⱼ）分別代表什麼物理量。
  2. 寫出完美流體的應力-能量張量公式 Tμν = (ρ+p)uμuν + pgμν，並說明公式中每個符號的意義。
  3. 在流體靜止座標系中，推導出 T00 = −ρ 與 Tij = pδij 這兩個結果，並說明為什麼混合的時間-空間分量會是零。
