奧伯斯悖論：為什麼夜晚的天空是黑的

這一課的目標

  • 推導奧伯斯悖論：為什麼「無限、靜態、均勻佈滿恆星」的宇宙模型會預測夜空應該全面明亮
  • 理解這個預測跟實際觀測（夜空是黑的）之間的矛盾，以及歷史上曾出現過的各種解釋嘗試
  • 理解現代公認的解答——宇宙的年齡有限——並體會這是宇宙「並非無限、靜態、永恆」的第一個純觀測線索

這門課要從一個聽起來有點荒謬的問題開始：為什麼夜晚的天空是黑的？ 這問題聽起來太理所當然了——太陽下山之後，當然是黑的。但如果你認真把「宇宙長什麼樣子」 這個假設寫清楚，會發現這個看似天真的問題，其實直接指向宇宙不可能是無限、靜態、永恆存在的。 這是十九世紀天文學家海因里希·奧伯斯（Heinrich Olbers）在 1823 年正式提出、後世稱為 奧伯斯悖論（Olbers' Paradox）的著名論證，也是這整門課的第一塊拼圖。

1. 一個看似合理的宇宙模型

在愛因斯坦之前，直覺上最「自然」的宇宙圖像大概是這樣的：宇宙是無限大的， 已經存在了無限長的時間（永恆、靜態，沒有開始也沒有結束），而且恆星 均勻分布在整個空間中，平均密度到處一樣。這個圖像在牛頓的時代看起來幾乎是唯一 合理的選項——畢竟一個「有邊界」的宇宙立刻會被問「邊界外面是什麼」，而一個「有開始」的宇宙 會被問「開始之前發生了什麼」，兩者都顯得不自然。奧伯斯悖論要問的是：如果宇宙真的長這樣， 我們今天晚上抬頭看到的天空，應該是什麼樣子？

2. 核心論證：每一條視線終將擊中一顆恆星

想像從地球上任何一個方向望出去，畫一條視線。在無限大、恆星均勻分布的宇宙裡，這條視線會 持續往前延伸，經過越來越多、越來越遠的恆星。只要視線夠長（而宇宙又真的無限大），這條視線 終究會擊中某一顆恆星的表面——就像在一片無限延伸、種滿樹的森林裡，不管往哪個 方向看，視線最終一定會被某一棵樹擋住，不可能有一條視線可以「看穿」整片森林望向空隙。

如果每一條視線最終都會落在某顆恆星的表面上，那麼整個天空——不管你往哪裡看——理論上應該 呈現出跟恆星表面差不多的亮度。太陽只是一顆普通恆星，這代表整個夜空應該跟正午的天空一樣明亮， 甚至更亮。但這跟我們的日常經驗完全相反：夜空絕大部分是黑的，只有零星的光點。

3. 定量推導：為什麼距離的平方反比「救不了」這個悖論

也許你會想：越遠的恆星看起來越暗（光度隨距離平方反比衰減），這樣不就能讓天空整體變暗嗎？ 讓我們把這個直覺算清楚。假設恆星在空間中均勻分布，數密度為 n（每單位體積的恆星數）， 每顆恆星的平均光度為 L。考慮以觀測者為中心、半徑 r、厚度 dr 的一層薄殼：

薄殼內的恆星數目：

dN = n · 4πr² dr

單顆恆星在距離 r 處造成的視亮度（光通量，遵守平方反比定律）：

f(r) = L / (4πr²)

這層薄殼貢獻的總光通量：

dF = dN · f(r) = n · 4πr² dr · L/(4πr²) = nL dr

關鍵就在這裡：距離平方反比定律（每顆恆星變暗）跟薄殼內恆星數目隨 r² 增加，兩者剛好完全抵消， 使得每一層薄殼貢獻的光通量 nL dr 跟距離 r 完全無關——不管這層殼有多遠，貢獻都一樣多。 把所有薄殼加總（對 r 從 0 積分到宇宙的最大範圍 R）：

F總 = ∫₀R nL dr = nLR

如果宇宙真的無限大（R → ∞），F總 也隨之發散到無限大——這正是奧伯斯悖論的定量核心： 在無限、靜態、均勻的宇宙裡，夜空亮度的積分不收斂。（更精確的處理會考慮恆星之間互相遮蔽， 結論會改成「天空亮度趨近於恆星表面的平均亮度」，而不是真的無限大，但無論哪種說法， 結論都跟「夜空是黑的」直接矛盾。）

4. 歷史上的各種嘗試解釋，以及它們為什麼不夠

在找到正確答案之前，天文學家提出過幾種解釋，但都無法真正解決問題：

  • 星際物質吸收光線：如果宇宙中瀰漫著會吸收星光的塵埃或氣體，遠方的光就會被擋掉。 但這個解釋有個致命問題——如果宇宙真的永恆存在，這些吸收光線的物質早就應該被星光加熱到跟恆星 一樣的溫度，然後自己也開始發光，回到原本的問題。
  • 宇宙不是均勻的，恆星只佔一小部分空間：即使恆星分布有結構、有空隙，只要平均 數密度不為零、宇宙又真的無限大，同樣的積分論證依然會發散，只是收斂得慢一點。

5. 現代解答：宇宙的年齡有限

真正解開這個悖論的關鍵，在於推翻最初的假設之一：宇宙不是永恆靜態存在的， 它有一個有限的年齡（現在已知大約 138 億年）。光速是有限的（c ≈ 3×10⁸ 公尺/秒），所以在宇宙 存在的這 138 億年裡，光線最多也只能走了大約 138 億光年那麼遠。換句話說，我們能接收到的星光， 全部來自一個以地球為中心、半徑大約是 c 乘上宇宙年齡 T 的有限範圍——這正是 「可觀測宇宙」概念的起點。

回到第 3 節的積分：因為宇宙年齡有限，積分的上限 R 不再是無限大，而是被 R ≈ cT 這個有限值截斷。 F總 = nLR 因此是一個有限的數值，不會發散——這就是為什麼夜空絕大部分 是黑暗的：對於絕大多數方向而言，視線路徑上「終將」擊中的那顆恆星，它的光根本還沒有足夠時間 抵達地球。（現代宇宙學的完整圖像還包含宇宙膨脹造成的紅移與早期宇宙不透明等因素，這些會在後面 的模組陸續補上；但光是「宇宙年齡有限」這一點，就已經足以解開奧伯斯悖論的核心矛盾。）

這一課的關鍵洞見

奧伯斯悖論表面上是一道關於天空亮度的簡單推理題，但它的真正份量在於：它是一個 純粹靠觀測（夜空是黑的）就能推翻「宇宙無限、靜態、永恆」這個古典圖像的論證， 而且早在愛因斯坦提出廣義相對論、哈伯發現星系遠離之前近一個世紀就已經被提出。它替接下來 整門課要講的故事——宇宙有一個開始、一直在演化——先埋下了第一條線索。

檢查你的理解

  1. 用自己的話陳述奧伯斯悖論：它從哪些假設出發，又推導出什麼跟觀測矛盾的結論？
  2. 為什麼「恆星越遠越暗」這個距離平方反比效應，不足以解決悖論？（提示：薄殼論證中兩個 r² 因子的抵消）
  3. 解釋「宇宙年齡有限」如何讓第 3 節的積分收斂，從而解開悖論。
