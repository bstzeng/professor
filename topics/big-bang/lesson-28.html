模組 E｜大霹靂核合成：早期宇宙的核子物理 · 第 28 課

氦、鋰的豐度預測與觀測驗證

這一課的目標

  • 推導氦-4質量豐度公式 Yp≈2(n/p)/(1+n/p)，並代入第26、27課的 n/p≈1/7 得到預測值
  • 認識氘、氦-3、鋰-7的豐度預測，理解氘豐度作為重子密度探針的角色
  • 理解為什麼「四種輕元素豐度同時吻合觀測」是大霹靂理論最有力的證據之一

第27課推導出氘瓶頸在 T≈0.1 MeV（t≈100–200秒）被打破。一旦瓶頸解除，核合成鏈會在 接下來短短幾分鐘內迅速跑完——這一課要算出這場「宇宙級核反應」最終留下的元素比例， 並看看這些純粹從理論推出來的數字，怎麼跟七十多年後精密望遠鏡量到的觀測值相互印證。

1. 瓶頸解除後：反應鏈迅速跑完

氘瓶頸一被打破，接下來的反應鏈幾乎是瞬間完成（相對於宇宙年齡的尺度而言）：

p + n → D + γ
D + D → ³He + n，　D + D → T + p
³He + n → T + p，　D + ³He → ⁴He + p，　D + T → ⁴He + n

整條鏈的終點絕大部分停在氦-4——因為氦-4的束縛能（約28.3 MeV）遠高於 氘、氦-3、氚等中間產物，是這個質量範圍裡最穩定的核種。而且核合成沒有時間、也沒有足夠的 反應通道去跨越質量數5跟8的「穩定核種空缺」（沒有穩定的質量數5、8原子核），所以反應鏈 基本上就停在氦-4，只留下極微量沒被完全處理掉的氘、氦-3，以及更微量的鋰-7。

2. 推導氦-4質量豐度公式

核合成啟動時，宇宙裡的中子跟質子數量比是 n/p≈1/7（第26、27課）。因為幾乎所有能配對的中子 最終都會被鎖進氦-4（每個氦-4核用掉2個中子＋2個質子），可以用「中子守恆」的邏輯，直接推導 最終氦豐度：

假設宇宙中每有 p 個質子，就有 n 個中子（n/p≈1/7）。因為氦-4需要等量的中子跟質子（各2個）， 限制反應能進行到底的是數量較少的中子——幾乎所有中子最終都會變成氦-4的一部分。 設核合成前中子總數為 Nn，質子總數為 Np：

形成的氦-4核數目 ≈ Nn/2　（每個氦-4用掉2個中子）

對應用掉的質子數目 ≈ Nn/2　（同樣用掉2個質子）

剩下未被使用、維持自由質子（氫核）的數目 ≈ Np − Nn/2

氦-4的質量豐度 Yp 定義為氦質量佔重子總質量的比例。因為氦-4核質量 近似等於4個核子質量（2質子＋2中子），而核子總數（質子＋中子）近似守恆，質量豐度可以直接用 核子數計算：

Yp = (氦-4的核子總數) / (所有核子總數) = (4 × Nn/2) / (Nn+Np) = 2Nn / (Nn+Np)

分子分母同除以 Np，用 n/p ≡ Nn/Np 表示：

Yp ≈ 2(n/p) / (1 + n/p)

3. 代入數字：Yp≈25%

把第26、27課推導出的核合成啟動時比值 n/p≈1/7 代入：

Yp ≈ 2×(1/7) / (1+1/7) = (2/7) / (8/7) = 2/8 = 0.25

Yp ≈ 25%（質量比）

也就是說，理論預測宇宙中大約四分之一的重子質量，會以氦-4的形式存在，其餘四分之三是氫 （未反應的自由質子）。這是一個純粹從弱交互作用凍結溫度、氘瓶頸物理推導出來的數字， 跟太陽、地球的化學組成完全無關。

4. 跟觀測比對：老、貧金屬星系的氦豐度

要驗證這個預測，天文學家會去測量宇宙中最原始的天體——那些幾乎沒有被恆星 核合成「污染」過的、金屬（天文學上泛指比氦重的元素）含量極低的星系與電離氫區——因為 後來每一代恆星的核融合都會持續製造更多氦，只有最原初、最貧金屬的系統才能反映大霹靂本身 留下的原初豐度。觀測結果與理論預測高度吻合：

輕元素大霹靂核合成預測觀測值（原初豐度）備註
氫（¹H）≈ 75%（質量）≈ 75%未反應的自由質子，佔絕大多數
氦-4（⁴He）Yp ≈ 25%（質量）≈ 24–25%本課推導的核心結果，與觀測吻合度極高
氘（D）D/H ≈ 2.5–3×10⁻⁵（數目比）≈ 2.5×10⁻⁵對重子密度 η 極其敏感，是最精確的 η 探針
氦-3（³He）³He/H ≈ 1×10⁻⁵量級吻合反應鏈中間產物，未完全反應掉的殘留
鋰-7（⁷Li）⁷Li/H ≈ 4–5×10⁻¹⁰觀測值略低（「鋰問題」）四種元素中唯一有明顯張力的個案，仍是活躍研究議題

5. 氘：對重子密度最敏感的探針

氦-4的豐度公式 Yp≈2(n/p)/(1+n/p) 對重子密度 η 並不敏感——因為 n/p 主要由弱交互作用 凍結溫度決定，跟 η 關係較弱。但氘的最終殘留量恰好相反：氘瓶頸解除的確切時刻本身就由 η 決定 （第27課），而瓶頸解除得越晚，氘被進一步反應掉（D+D、D+p等）的機會就越多，殘留的氘就越少。 這代表氘/氫比值是一個對 η（進而對宇宙重子密度）異常敏感的探針——精確測量 原初氘豐度，是獨立於CMB（第34課會看到另一種測 η 的方法）決定宇宙重子密度的重要途徑， 兩種完全不同的方法互相印證，是宇宙學裡「交叉驗證」的經典範例。

6. 為什麼四種元素同時吻合是強力證據

這一課的關鍵洞見

大霹靂核合成理論只有一個自由參數：重子光子比 η（第27課引入）。 用同一個 η 值，理論能同時預測氫、氘、氦-3/4、鋰-7四種完全不同元素的豐度， 而且橫跨的豐度數量級相差極大（從氦的25%到鋰的十億分之幾）——這種「一個參數解釋四個 獨立觀測量」的預測能力，是科學理論中極少見的強力驗證。如果大霹靂模型是錯的，沒有理由 期待調一個參數就能同時讓四個豐度都對得上。這正是為什麼大霹靂核合成，跟哈伯膨脹 （模組A）、宇宙微波背景輻射（模組F）並列為支持大霹靂理論的三大支柱之一。

檢查你的理解

  1. 從「幾乎所有中子最終都變成氦-4」這個假設出發，推導氦-4質量豐度公式 Yp≈2(n/p)/(1+n/p)。
  2. 把 n/p≈1/7 代入，驗證 Yp≈25% 這個結果。
  3. 解釋為什麼「四種輕元素豐度用同一個 η 值同時吻合觀測」比只驗證單一元素豐度更有說服力。
