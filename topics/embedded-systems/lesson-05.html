C 語言的位元操作

這一課的目標

  • 熟悉位元運算子
  • 學會設定、清除、切換與檢查位元
  • 了解位元欄位與遮罩

位元運算子

運算子意義例子（a = 0b1100, b = 0b1010）
&ANDa & b = 0b1000
|ORa | b = 0b1110
^XORa ^ b = 0b0110
~NOT（取反）~a 把每個位元反轉
<<左移1 << 3 = 0b1000
>>右移a >> 2 = 0b0011

四個基本動作

  • 設定第 n 位：reg |= (1u << n);
  • 清除第 n 位：reg &= ~(1u << n);
  • 切換第 n 位：reg ^= (1u << n);
  • 檢查第 n 位：if (reg & (1u << n)) { ... }

多位元欄位

許多暫存器的設定是好幾個位元一組。例如某個 2 位元的欄位在第 4～5 位，要把它設成 0b10：

reg = (reg & ~(0x3u << 4)) | (0x2u << 4);

先用遮罩把那兩位清掉，再放入新的值。

固定寬度的整數

不同的平台上 int 的大小可能不同（8 位元的 AVR 上 int 是 16 位元）。嵌入式程式應該使用 <stdint.h> 的 uint8_t、int16_t、uint32_t 等型別，明確地指定大小。另外要小心：

  • 有號數的右移：行為依實作而定，位元操作盡量用無號數。
  • 1 << 31：如果 1 是有號的 int，可能造成未定義行為，要寫成 1u << 31。
  • 整數提升：uint8_t 參與運算時會先被提升為 int，~ 運算的結果可能和預期不同。

位元組順序

多位元組的數值在記憶體中有兩種存法：小端序（低位元組在前，Cortex-M 通常是這樣）與大端序（高位元組在前，網路協定常用）。在不同的系統之間交換資料時（第 13 課～第 16 課），一定要確認位元組順序。

🧭 這一課的重點

位元運算子有 & | ^ ~ << >>；設定第 n 位 reg |= (1u << n)、清除 reg &= ~(1u << n)、切換 ^=、檢查 reg & (1u << n)；多位元欄位先用遮罩清掉再放入新值；用 stdint.h 的 uint8_t uint32_t 等固定寬度型別，注意有號右移依實作而定、1 << 31 可能未定義應寫 1u、uint8_t 運算時的整數提升；小端序低位元組在前（Cortex-M 通常），大端序高位元組在前（網路協定），交換資料要確認順序。

🔌 本課以 ARM Cortex-M 等常見的 32 位元微控制器為主要例子；暫存器名稱與細節依晶片與廠商而異，實作時請以晶片的資料手冊與參考手冊為準。
