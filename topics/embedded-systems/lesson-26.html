整門課回顧

模組核心
基礎MCU 架構、交叉編譯、記憶體映射暫存器、volatile、位元操作
週邊GPIO、去彈跳、中斷、計時器、PWM、ADC、DAC
通訊UART、I²C、SPI、CAN、USB、BLE 與物聯網
系統狀態機、RTOS 與優先權反轉、低功耗、看門狗、安全的 OTA
實務除錯工具、資安、實作案例

學習路徑建議

  1. 用 Arduino 或 MicroPython 做出幾個小作品，建立信心。
  2. 換到 STM32、ESP32 或 RP2040，學會讀參考手冊、直接操作暫存器。
  3. 買一台便宜的邏輯分析儀，親眼看 UART、I²C、SPI 的波形。
  4. 學 FreeRTOS 或 Zephyr，寫一個多任務的專案。
  5. 學基本的電子學與電路板設計（見〈電子學〉、〈數位邏輯〉）。
  6. 做一個完整的產品：電池、外殼、無線、更新。

未來趨勢

  • RISC-V：開放的指令集架構，越來越多 MCU 採用。
  • 邊緣 AI（TinyML）：在 MCU 上直接執行小型的神經網路，例如語音喚醒詞、異常振動偵測，資料不必上傳雲端（見〈深度學習〉）。
  • Rust：用記憶體安全的語言開發嵌入式系統，減少緩衝區溢位等錯誤。
  • Matter 等統一標準：讓不同品牌的智慧家居互通。
  • 資安法規：安全從一開始就要設計進去（第 24 課）。
  • 能量採集：用太陽能、振動或無線電波發電，打造不需要換電池的裝置。

嵌入式系統是軟體與硬體交會的地方：寫下的每一行程式，都會讓真實世界中的某個東西動起來。延伸：〈機器人與自主系統〉、〈作業系統開發〉、〈手機感測器〉。

🧭 這一課的重點

整門課涵蓋基礎（架構交叉編譯暫存器 volatile 位元操作）、週邊（GPIO 去彈跳中斷計時器 PWM ADC DAC）、通訊（UART I²C SPI CAN USB BLE）、系統（狀態機 RTOS 低功耗看門狗 OTA）、實務（除錯資安案例）；學習路徑為 Arduino 或 MicroPython 入門、換 STM32 ESP32 RP2040 讀參考手冊、邏輯分析儀看波形、學 RTOS、學電子學與電路板、做完整產品；趨勢有 RISC-V、TinyML 邊緣 AI、Rust、Matter、資安法規、能量採集。

🔌 本課以 ARM Cortex-M 等常見的 32 位元微控制器為主要例子；暫存器名稱與細節依晶片與廠商而異，實作時請以晶片的資料手冊與參考手冊為準。
