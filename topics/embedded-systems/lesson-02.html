微控制器的架構

這一課的目標

  • 認識 MCU 的主要組成
  • 理解哈佛架構與匯流排
  • 了解常見的 MCU 家族

晶片裡有什麼

  • CPU 核心：例如 ARM Cortex-M0／M3／M4／M7、RISC-V、8 位元的 AVR。
  • Flash：存放程式與常數，斷電不會消失。
  • SRAM：存放變數與堆疊，斷電就消失。
  • 時脈系統：內部 RC 振盪器或外部石英晶體，經過 PLL 倍頻成系統時脈（數 MHz 到數百 MHz）。
  • 週邊：GPIO、計時器、ADC、UART、I²C、SPI、USB、DMA……
  • 中斷控制器（Cortex-M 的 NVIC）（第 8 課）。

匯流排與哈佛架構

許多 MCU 採用哈佛架構（或修改的哈佛架構）：指令和資料走不同的匯流排，CPU 可以同時抓指令與讀寫資料（見〈計算機結構〉）。週邊掛在較慢的週邊匯流排上，透過匯流排橋接與 CPU 溝通。

DMA

DMA（直接記憶體存取）讓週邊與記憶體之間直接搬資料，不需要 CPU 一個位元組一個位元組地搬：例如 ADC 連續取樣的結果自動存進陣列、UART 收到的資料自動放進緩衝區。CPU 可以同時做別的事，或去睡覺。

常見的家族

家族特色
AVR（ATmega328P）8 位元，Arduino Uno 的核心，簡單易學
STM32ST 的 ARM Cortex-M 系列，型號極多，工業界常用
ESP32內建 Wi-Fi 與藍牙，物聯網的熱門選擇
RP2040樹莓派基金會推出的雙核 Cortex-M0+，有獨特的可程式 I/O
Nordic nRF52／nRF54低功耗藍牙裝置常用

台灣也有許多 MCU 廠商（例如新唐、盛群），產品廣泛用在家電、電腦週邊與工業控制。

怎麼選 MCU

依需求決定：需要多少腳位與哪些週邊？運算量多大（要不要浮點運算單元）？記憶體夠不夠？功耗預算？價格與供貨？開發工具與社群資源？2021 年前後的全球晶片短缺，讓「買得到」也成為重要的考量。

🧭 這一課的重點

MCU 包含 CPU 核心（Cortex-M、RISC-V、AVR）、存程式的 Flash、存變數堆疊的 SRAM、內部 RC 或外部晶體經 PLL 倍頻的時脈、週邊與中斷控制器 NVIC；多採哈佛架構指令資料分開匯流排，週邊掛在較慢匯流排；DMA 讓週邊與記憶體直接搬資料；常見家族 AVR（Arduino Uno）、STM32、ESP32（Wi-Fi 藍牙）、RP2040、Nordic nRF，台灣有新唐盛群；選型看腳位週邊、運算、記憶體、功耗、價格供貨與工具社群。

🔌 本課以 ARM Cortex-M 等常見的 32 位元微控制器為主要例子；暫存器名稱與細節依晶片與廠商而異，實作時請以晶片的資料手冊與參考手冊為準。
