二〇二〇年：C 型肝炎病毒

這一課的目標

  • 了解 C 型肝炎病毒的發現過程
  • 認識三位得主的不同貢獻
  • 了解 C 型肝炎從發現到治癒的歷程

1. 得獎者與官方獎項理由

項目內容
得獎者哈維．阿爾特、麥可．霍頓、查爾斯．賴斯
獎項理由發現 C 型肝炎病毒
領域病毒學／傳染病

2. 那到底是什麼

1970 年代，A 型與 B 型肝炎病毒都已被發現，輸血用的血液也開始篩檢 B 型肝炎。但阿爾特發現，輸血後仍有許多人罹患肝炎，稱為「非 A 非 B 型肝炎」，並證明它可以傳染給黑猩猩。

霍頓花了多年，用當時新穎的分子選殖方法，在 1989 年找出這個病毒的遺傳序列，命名為 C 型肝炎病毒。賴斯則在 1997 年證明，單獨這個病毒就足以引起肝炎，完成了最後一塊拼圖。

3. 在此之前的困境

  • 病毒無法在實驗室培養，傳統方法找不到它
  • 慢性 C 型肝炎會在數十年間悄悄造成肝硬化與肝癌，感染者常不自知

4. 從發現到獲獎的時間差

時間事件
1970 年代阿爾特描述非 A 非 B 型肝炎
1989霍頓團隊找出病毒序列
1997賴斯證明病毒單獨足以致病
2020獲獎，時間差約三十年

霍頓的團隊還有其他成員；他曾在 2013 年因加拿大蓋爾德納獎未納入同事而拒絕領獎，顯示「最多三人」的問題在其他獎項中同樣存在。

5. 今天的影響

  • 血液篩檢讓輸血後感染 C 型肝炎幾乎消失
  • 2010 年代問世的口服直接抗病毒藥物，可治癒九成五以上的患者
  • 世界衛生組織以「2030 年消除病毒性肝炎公共衛生威脅」為目標
