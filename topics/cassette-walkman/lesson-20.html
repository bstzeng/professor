CD 的挑戰

這一課的目標

  • 了解 CD 的發明與優點
  • 理解 CD 如何取代卡帶與黑膠
  • 認識數位音樂的基本概念

Sony 與飛利浦

1970 年代後期，飛利浦與 Sony 各自研究用雷射讀取的數位音樂光碟，後來決定合作制定共同的標準。1982 年，CD（Compact Disc）在日本上市，第一批上市的專輯中包括比利．喬的《52nd Street》。關於 CD 為什麼是 74 分鐘，有一個流傳很廣的說法：Sony 的高層希望一片 CD 能完整收錄貝多芬的第九號交響曲（見〈古典音樂史〉）——不過這個說法的真實性仍有爭議。

CD 的優點

  • 沒有嘶聲：數位錄音沒有磁帶的背景雜訊，安靜的段落真的安靜（第 7 課）。
  • 不會磨損：雷射讀取，不接觸碟片，聽一千次都一樣。
  • 隨機選曲：直接跳到任何一首歌，不用快轉倒帶。
  • 容量與音質：44.1 kHz 取樣、16 位元，頻率響應涵蓋人耳的聽覺範圍（見本系列的「磁碟片、光碟與 MP3」）。

取代

CD 一開始很貴，播放機也貴。但隨著價格下降，1980 年代後期到 1990 年代，CD 先後超越了黑膠與卡帶的銷量，成為音樂的主流。唱片公司把舊專輯重新發行成 CD，賺進了大筆的利潤——很多人把自己的黑膠與卡帶收藏，又用 CD 重買了一次。

卡帶沒有立刻消失

但卡帶並沒有立刻消失：CD 早期不能錄音，隨身 CD 機一走路就會跳針（直到加入防震記憶），汽車裡也多是卡帶座（第 14 課）。所以在 1990 年代，很多人的做法是「買 CD、錄成卡帶帶出門聽」。卡帶在隨身與錄音的領域，又撐了十年。

數位的意義

CD 把音樂變成了數字。這帶來了完美的音質與完美的複製（第 9 課），也為後來的 MP3 與網路音樂（第 22 課）鋪好了路：一旦音樂是數字，它就可以被壓縮、傳送、儲存在任何電腦裡。

🧭 這一課的重點
