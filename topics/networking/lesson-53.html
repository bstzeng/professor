Docker核心概念：映像檔、容器、Dockerfile

這一課的目標

  • 理解映像檔（Image）是唯讀、分層的應用程式範本，容器（Container）是由映像檔啟動的執行實例
  • 理解Dockerfile是描述「如何建置出一個映像檔」的純文字腳本
  • 能讀懂並解釋一份簡單Dockerfile裡FROM、COPY、RUN、WORKDIR、EXPOSE、CMD等指令的作用

第52課建立了容器的技術原理：namespace做隔離、cgroup 做資源限制，讓容器不必背著一整套作業系統核心，也能 做到「感覺獨立」的執行環境。而Docker正是 目前最主流、採用率最高的容器技術實作——它把上一課 的底層機制包裝成一套好用的工具鏈，讓開發者不需要直接 操作namespace、cgroup這些底層細節，就能建立、執行、 分享容器。這一課要建立Docker最核心的三個概念：映像檔、 容器、Dockerfile。

1. 映像檔（Image）：唯讀、分層的應用程式範本

映像檔（Image）是一份唯讀的範本，裡面 打包了執行一個應用程式所需要的所有東西：應用程式的 程式碼本身、需要的執行環境（例如Node.js或Python的 直譯器）、程式依賴的系統函式庫，以及相關的設定檔。 映像檔在建置時，會由一連串的層（layer） 堆疊而成——建置過程中的每一個步驟，通常會對應到一層， 而Docker會聰明地快取每一層的結果：如果重新建置時， 某一層的內容跟上次完全沒變（例如安裝依賴套件那一層）， 就能直接重複使用快取，不必重跑一次；不同映像檔之間， 如果共用相同的底層（例如都是從同一個基礎映像檔開始）， 也能共用、重複利用同一份層，節省磁碟空間與建置時間。

2. 容器（Container）：從映像檔啟動的執行實例

容器（Container）則是映像檔實際被啟動、 執行起來之後的實例（可能正在執行中，也可能已經停止）。 這個關係很像程式設計裡「類別」與「物件實例」的關係， 或是更貼近直覺地說——像是一個程式檔案跟它被執行起來 之後、變成一個個行程（process）的關係：同一份 映像檔，可以同時啟動出好幾個各自獨立、互不干擾的 容器，每個容器都有自己的檔案系統、行程空間、 網路環境（正是第52課namespace提供的隔離視角），但它們 用的都是同一份底層映像檔的內容，不需要重複複製一整份。

3. Dockerfile：描述「怎麼建置出映像檔」的腳本

映像檔不是憑空出現的，通常是根據一份Dockerfile 建置出來的——Dockerfile是一份純文字的腳本， 用一系列固定的關鍵字指令，一步一步描述要怎麼組裝出 這個映像檔。最基本、最常用到的幾個指令：

指令作用
FROM指定要以哪一個既有映像檔作為基礎起點，例如 FROM node:20 表示從官方的Node.js映像檔開始建置
WORKDIR設定接下來指令執行時所在的工作目錄，如果目錄不存在會自動建立
COPY把建置情境（build context，通常是專案資料夾）裡的檔案，複製進映像檔裡
RUN在建置映像檔的過程中執行一段指令，最常見的用途是安裝套件、依賴
EXPOSE用文件性質標註這個容器預期會監聽哪個連接埠，本身不會真的開放連線（實際對外開放靠 docker run -p）
CMD指定容器啟動時，預設要執行的指令

4. 完整範例：一個簡單的Node.js網頁應用程式

以下是一份完整、可運作的Dockerfile範例，用來建置一個 簡單的Node.js網頁應用程式的映像檔：

FROM node:20-alpine WORKDIR /app COPY package.json package-lock.json ./ RUN npm install COPY . . EXPOSE 3000 CMD ["node", "server.js"]

逐行拆解：FROM node:20-alpine選擇一個已經 內建Node.js 20版本、且體積精簡的Alpine Linux作為基礎 映像檔；WORKDIR /app把後續指令的工作目錄 設在容器裡的/app；接著先只複製 package.json與package-lock.json 這兩個描述依賴套件清單的檔案，並執行RUN npm install安裝依賴——刻意把這一步拆開、放在複製 全部程式碼之前，是為了讓Docker的層快取發揮作用：只要 依賴套件清單沒有變動，重新建置時就能直接沿用快取， 跳過重新安裝套件這個通常最花時間的步驟；然後 COPY . .把專案剩下的程式碼複製進映像檔； EXPOSE 3000標註這個應用程式預期監聽3000 埠；最後CMD ["node", "server.js"]指定容器 啟動時，預設要執行node server.js這個指令 來啟動應用程式。

檢查你的理解

  1. 能說出Dockerfile、映像檔、容器三者之間的關係
  2. 能舉出至少四個Dockerfile指令，並說明各自的作用
  3. 能解釋為什麼把「複製依賴清單並安裝依賴」放在「複製全部程式碼」之前，有助於善用層快取
