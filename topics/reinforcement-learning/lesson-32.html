n 步回報與資格跡

這一課的目標

  • 理解 n 步回報
  • 理解 λ 回報與資格跡的直覺
  • 理解偏差與變異的取捨

一步太短，整局太長

TD(0) 只看一步就自舉；蒙地卡羅看到最後。何不看 \(n\) 步？

\[G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1}R_{t+n} + \gamma^nV(S_{t+n})\]
  • \(n = 1\)：TD(0)。
  • \(n = \infty\)：蒙地卡羅。
  • 中間的 \(n\)：用 \(n\) 步的真實獎勵，再用估計補上剩下的。

實驗上，最好的 \(n\) 常常在中間（例如 3～10），因為它在偏差（自舉帶來的）與變異（真實回報帶來的）之間取得平衡。

λ 回報

與其選一個 \(n\)，不如把所有的 \(n\) 步回報都用上，按 \(\lambda^{n-1}\) 的權重平均：

\[G_t^\lambda = (1 - \lambda)\sum_{n=1}^{\infty}\lambda^{n-1}G_t^{(n)}\]

\(\lambda = 0\) 是 TD(0)，\(\lambda = 1\) 是蒙地卡羅。\(\lambda\) 是一個連續的旋鈕。

資格跡：往回看的實作

計算 \(G_t^\lambda\) 需要等到未來，不方便。資格跡（eligibility trace）是一個等價的「往回看」做法：

  • 每個狀態有一個「資格」\(e(s)\)：剛經過時設為 1（或加 1），之後每一步乘上 \(\gamma\lambda\) 衰減。
  • 每一步算出 TD 誤差 \(\delta\) 後，所有狀態都更新：\(V(s) \leftarrow V(s) + \alpha\,\delta\,e(s)\)。
  • 最近經過的狀態資格高，分到較多的功勞（或責任）；很久以前經過的，分到較少。

這是一個優雅的時間信用分配機制（第 5 課）：好事發生時，不只最後一步，最近的一連串步驟都會被強化，強度隨時間衰減。TD-Gammon 使用的就是 TD(λ)。

🔍 大腦的痕跡

神經科學家推測，突觸上也存在類似資格跡的機制：一個突觸活躍後留下一段時間的「標記」，之後如果多巴胺訊號（TD 誤差）到來，被標記的突觸才會被加強。

🧭 這一課的重點

n 步回報 G^(n) 用 n 步真實獎勵再以估計補上，n=1 是 TD(0)、n=∞ 是蒙地卡羅，最好的 n 常在中間以平衡偏差與變異。λ 回報把所有 n 步回報以 λ^{n−1} 權重平均，λ=0 是 TD(0)、λ=1 是蒙地卡羅。資格跡是等價的往回看實作：經過的狀態資格設為 1 後每步乘 γλ 衰減，每步以 TD 誤差乘資格更新所有狀態，最近經過的分到較多功勞，是優雅的時間信用分配，TD-Gammon 用的是 TD(λ)。突觸上可能存在類似資格跡的標記機制。

🎰 本課的推導以直覺與主要步驟為主，省略部分數學嚴格性；互動模擬為教學用的小型版本，每次執行的隨機結果都會略有不同。

檢查你的理解

  1. n 步回報在 n = 1 和 n = ∞ 時，分別等於什麼？
  2. 為什麼最好的 n 常常在中間？
  3. 用資格跡說明：一件好事發生時，功勞是怎麼分給之前的步驟的？
