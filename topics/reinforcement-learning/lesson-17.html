回報與折扣因子

這一課的目標

  • 定義回報
  • 理解折扣因子 γ 的意義
  • 推導回報的遞迴關係

回報

代理人要最大化的不是某一步的獎勵，而是從現在開始所有未來獎勵的總和，叫做回報（return）：

\[G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2R_{t+3} + \cdots = \sum_{k=0}^{\infty}\gamma^kR_{t+k+1}\]

為什麼要打折

  • 數學上：如果任務沒有終點（例如永遠運作的機器人），不打折的總和可能是無限大。只要 \(\gamma < 1\) 且獎勵有界，\(G_t \le R_{\max}/(1-\gamma)\)，一定是有限的。
  • 不確定性：未來越遠越難預測，越不可靠。
  • 經濟學上：今天的 100 元比明年的 100 元有價值（利率）。
  • 行為上：人和動物都偏好即時的獎勵。

γ 的意義

\(\gamma\)代理人「有效視野」約 \(1/(1-\gamma)\) 步
0短視：只在乎下一步的獎勵（就是吃角子老虎）1
0.9在乎未來約 10 步10
0.99在乎未來約 100 步100
1遠見：所有未來同等重要（只適合有終點的任務）∞

例如 \(\gamma = 0.9\)：10 步後的獎勵，權重是 \(0.9^{10}\approx0.35\)；50 步後只剩 \(0.9^{50}\approx0.005\)。

完整推導：遞迴關係

\[G_t = R_{t+1} + \gamma\left(R_{t+2} + \gamma R_{t+3} + \cdots\right) = R_{t+1} + \gamma G_{t+1}\]

「現在的回報 = 下一步的獎勵 + 打折後的下一個回報」。這個簡單的式子，是下一課貝爾曼方程式的種子，也是整個強化學習的骨幹。

🔍 等比級數

如果每一步的獎勵都是 1，\(G = 1 + \gamma + \gamma^2 + \cdots = 1/(1-\gamma)\)。\(\gamma = 0.99\) 時是 100。這就是「有效視野」的由來。

🧭 這一課的重點

回報 G_t 是從現在開始所有未來獎勵的折扣總和 Σγ^k R_{t+k+1}。打折的理由：數學上 γ<1 時無終點任務的總和有限（不超過 R_max/(1−γ)）、未來不確定、經濟上的利率、行為上偏好即時獎勵。γ=0 是短視的吃角子老虎，0.9 約看 10 步，0.99 約看 100 步，γ=1 只適合有終點的任務；有效視野約 1/(1−γ)。推導遞迴關係 G_t=R_{t+1}+γG_{t+1}，是貝爾曼方程式的種子。

🎰 本課的推導以直覺與主要步驟為主，省略部分數學嚴格性；互動模擬為教學用的小型版本，每次執行的隨機結果都會略有不同。

檢查你的理解

  1. 為什麼沒有終點的任務一定要用 γ < 1？
  2. γ = 0.95 時，有效視野大約是幾步？
  3. 推導 G_t = R_{t+1} + γG_{t+1}。
