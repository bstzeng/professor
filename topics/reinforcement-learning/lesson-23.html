策略改進定理

這一課的目標

  • 理解策略改進的做法
  • 證明策略改進定理
  • 理解改進停止時就是最優

一個簡單的想法

評估完一個策略 \(\pi\) 之後，我們知道了 \(v_\pi\)。在某個狀態 \(s\)，如果改做另一個動作 \(a\)（之後仍照 \(\pi\) 走），會不會比較好？只要比較 \(q_\pi(s,a)\) 和 \(v_\pi(s)\)。

更進一步：在每一個狀態，都改選 \(q_\pi\) 最大的動作，得到新的策略

\[\pi'(s) = \arg\max_a q_\pi(s,a)\]

這叫做貪婪改進。

完整證明：策略改進定理

若對所有 \(s\) 都有 \(q_\pi(s, \pi'(s)) \ge v_\pi(s)\)，則 \(v_{\pi'}(s) \ge v_\pi(s)\)。證明：反覆展開——

\[\begin{aligned} v_\pi(s) &\le q_\pi(s, \pi'(s)) = \mathbb{E}\left[R_{t+1} + \gamma v_\pi(S_{t+1}) \mid S_t = s, A_t = \pi'(s)\right]\\ &\le \mathbb{E}_{\pi'}\left[R_{t+1} + \gamma q_\pi(S_{t+1}, \pi'(S_{t+1})) \mid S_t = s\right]\\ &= \mathbb{E}_{\pi'}\left[R_{t+1} + \gamma R_{t+2} + \gamma^2v_\pi(S_{t+2}) \mid S_t = s\right]\\ &\le \cdots \le \mathbb{E}_{\pi'}\left[R_{t+1} + \gamma R_{t+2} + \gamma^2R_{t+3} + \cdots \mid S_t = s\right] = v_{\pi'}(s) \end{aligned}\]

每一步都把「接下來照 \(\pi\)」換成「接下來照 \(\pi'\)」，價值只會增加。貪婪改進滿足定理的條件（因為取了最大值），所以新策略一定不會比舊的差。

停止時就是最優

如果貪婪改進後策略沒有改變，代表 \(v_\pi(s) = \max_a q_\pi(s,a)\) 對所有狀態成立——這正是貝爾曼最優方程式！所以這時的 \(\pi\) 就是最優策略。

🔍 一個小小的魔法

評估「隨機亂走」的策略，再做一次貪婪改進，在格子世界這樣的小問題中，常常就已經得到一個相當不錯的策略。只要知道「在這個策略下，每個地方有多好」，往價值高的方向走，就已經是很大的改進。

🧭 這一課的重點

評估完 π 後，在每個狀態改選 q_π 最大的動作得到新策略 π'，這是貪婪改進。策略改進定理：若所有 s 都有 q_π(s,π'(s))≥v_π(s)，則 v_π'≥v_π；證明是反覆展開，每一步把接下來照 π 換成照 π'，價值只增不減。貪婪改進滿足條件，新策略不會更差。若改進後策略不變，則 v_π=max q_π，正是貝爾曼最優方程式，所以就是最優策略。小問題中評估隨機策略再改進一次常常就已不錯。
