向量空間與子空間

這一課的目標

  • 理解向量空間的概念
  • 判斷一個集合是不是子空間
  • 認識 ℝ³ 的所有子空間

向量空間是一個可以做加法和純量乘法、而且運算結果不會跑出去的集合。\(\mathbb{R}^n\) 是最基本的例子。它裡面的「小向量空間」叫做子空間。

子空間的判斷

一個集合 S 是子空間，只要檢查：

  1. 零向量在裡面（所以一定過原點）。
  2. S 裡任兩個向量相加還在 S 裡。
  3. S 裡的向量乘任何數還在 S 裡。
集合是子空間嗎？原因
平面 x + y + z = 0是過原點的平面
平面 x + y + z = 1不是不過原點：(0,0,0) 不在裡面
第一象限 {x ≥ 0, y ≥ 0}不是乘 −1 就跑出去了
兩條軸的聯集不是(1,0) + (0,1) = (1,1) 不在軸上
某些向量的張成永遠是線性組合的線性組合還是線性組合

ℝ³ 的子空間全家福

  • 只有原點 {0}（0 維）
  • 過原點的直線（1 維）
  • 過原點的平面（2 維）
  • 整個 ℝ³（3 維）

沒有別的了。子空間永遠是「平的」、過原點、向兩端無限延伸。

為什麼要「過原點」？

第 9 課說過，方程組的解集合是「特解 + 某個集合」。Ax = 0 的解集合是子空間（過原點），Ax = b 的解集合是把它平移出去，叫做仿射子空間。區分這兩者，是理解方程組結構的關鍵。

🧭 這一課的重點

向量空間是對加法與純量乘法封閉的集合；子空間是其中包含零向量、對加法與伸縮封閉的子集合。過原點的直線、平面是子空間，不過原點的平面、象限、兩軸聯集都不是。張成永遠是子空間。ℝ³ 的子空間只有原點、過原點直線、過原點平面與 ℝ³ 本身。Ax = b 的解集合是子空間的平移（仿射子空間）。
