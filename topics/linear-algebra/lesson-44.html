主成分分析（PCA）

這一課的目標

  • 理解 PCA 的目標
  • 知道 PCA 就是共變異數矩陣的特徵分解（或資料矩陣的 SVD）
  • 會解讀「解釋變異比例」

一份資料有很多個特徵（維度），但它們常常互相相關，資料其實集中在某個低維的子空間附近。主成分分析（PCA）找出資料變化最大的幾個方向，用它們當新的座標軸。

步驟

  1. 每個特徵減去平均值（中心化）。
  2. 計算共變異數矩陣 \(C = \tfrac{1}{n-1}X^{\mathsf T}X\)（對稱半正定）。
  3. 求 C 的特徵值與特徵向量（或直接對 X 做 SVD）。
  4. 按特徵值由大到小排序：第一個特徵向量是第一主成分，特徵值是沿著它的變異數。
  5. 保留前 k 個主成分，把資料投影上去。
\[\text{前 k 個主成分解釋的變異比例} = \frac{\lambda_1 + \cdots + \lambda_k}{\lambda_1 + \cdots + \lambda_n}\]

應用

領域PCA 做什麼
人臉辨識「特徵臉」（eigenfaces，1991）：人臉影像的前幾十個主成分，每張臉都用這些「標準臉」的組合表示
基因體學數萬個基因的表現量降到二維，常能看出族群或癌症亞型的分群；歐洲人的基因 PCA 圖甚至和地圖很像
金融利率曲線的變動，前三個主成分（水準、斜率、曲率）就能解釋九成以上
視覺化把高維資料投影到 2D 或 3D 來看
前處理去除共線性、降低雜訊，再交給其他模型

PCA 的限制

  • 只找線性的方向；資料若在彎曲的曲面上，要用核 PCA、t-SNE、UMAP 等非線性方法。
  • 對特徵的單位很敏感：通常要先標準化。
  • 「變化大」不一定等於「重要」：分類時有用的方向可能變異很小。

🧭 這一課的重點

PCA 先中心化資料，再對共變異數矩陣做特徵分解（或對資料矩陣做 SVD）。特徵向量依特徵值排序為主成分，特徵值是沿該方向的變異數，前 k 個特徵值的比例是解釋變異比例。應用包括特徵臉、基因體分群、利率曲線分析與視覺化；限制是只找線性方向、對單位敏感、變異大不必然重要。
