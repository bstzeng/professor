API 與程式交易

這一課的目標

  • 了解券商 API 的用途
  • 認識程式交易的優勢與風險
  • 理解散戶與專業機構的速度差距

許多券商提供交易 API，讓投資人用程式自動下單：例如價格突破某個價位就買進、每天固定時間買入定額。程式的好處是不會猶豫、不會漏看，而且可以同時盯很多檔股票。

但是，散戶的程式交易仍然走公共網路、經過券商前台，延遲在毫秒到數十毫秒之間。專業的高頻交易者則把機器放在交易所旁邊、用特製硬體，延遲在微秒等級——差了一千倍以上。

程式交易的風險

程式會忠實執行你寫的邏輯——包括錯誤。一個迴圈寫錯，可能在幾秒內送出成千上萬筆委託。所以券商會對 API 設下速率與額度限制，交易所也有異常委託的監控。第 43 課的騎士資本事件，就是程式錯誤的極端案例。

🧭 這一課的重點

券商 API 讓投資人以程式自動下單，優點是不猶豫、不漏看並能同時監控多檔；但散戶程式仍走公網與券商前台，延遲毫秒等級，專業共置則達微秒等級。程式會忠實執行錯誤，因此有速率與額度限制。

📈 本課程說明交易系統如何運作，不是投資建議。延遲與規模數字多為公開資料或量級估算，實際數值依券商、網路與系統版本而不同；交易規則以證交所、櫃買中心與主管機關最新公告為準。
