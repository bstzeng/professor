飯後兩小時：身體裡發生了什麼事

這一課的目標

  • 用一頓飯串起消化、內分泌、循環與神經系統
  • 理解飯後血糖與胰島素變化的時間順序
  • 認識飽足感的形成機制

這一課，我們用一碗牛肉麵當例子：麵條（澱粉）、牛肉（蛋白質）、湯裡的油（脂肪），跟著它們走一遍，看看各器官怎麼接力處理。

1. 時間軸

2. 三大營養素各走各的路

營養素消化吸收後去哪裡最後的命運
麵條的澱粉唾液澱粉酶 → 胰澱粉酶 → 刷狀緣酵素 → 葡萄糖肝門靜脈 → 肝臟一部分直接供能；多的存成肝醣，再多的轉成脂肪
牛肉的蛋白質胃蛋白酶 → 胰蛋白酶 → 胺基酸肝門靜脈 → 肝臟合成身體的蛋白質；多的胺基酸脫去氮（變尿素）後當燃料
湯裡的油膽汁乳化 → 胰脂肪酶 → 脂肪酸乳糜管 → 淋巴 → 血液送到脂肪組織儲存，或給肌肉使用

3. 各器官的分工

  • 神經系統：副交感神經主導「休息與消化」，促進消化液分泌與腸道蠕動
  • 循環系統：大量血液流向消化道，心輸出量略為上升
  • 胰臟：外分泌出消化酶，內分泌出胰島素
  • 肝臟：第一站處理所有吸收進來的養分，調節要放多少進入全身
  • 腎臟：處理蛋白質代謝後增加的尿素
  • 肌肉與脂肪組織：在胰島素的指示下吸收葡萄糖與脂肪

4. 飽足感怎麼來的

「吃飽了」不是單一訊號，而是多個訊號加總，送到下視丘：

訊號來源作用
胃被撐開胃壁的牽張感受器 → 迷走神經短期飽足
CCK、GLP-1、PYY小腸細胞偵測到脂肪與蛋白質後分泌延緩胃排空、產生飽足感
飢餓素（ghrelin）下降胃分泌，空腹時高、進食後下降減少飢餓感
瘦素（leptin）脂肪組織，反映長期能量儲存長期調節食慾與體重

這些訊號從開始吃到完全作用，大約需要 15～20 分鐘。所以吃太快容易吃過量——等飽足感抵達時，已經多吃了好幾口。近年備受關注的減重藥物，就是模仿 GLP-1 的作用。

生活連結

同樣份量的餐點，先吃蔬菜和蛋白質、最後才吃澱粉，飯後血糖的上升幅度通常會比較平緩。原因是纖維、蛋白質和脂肪會延緩胃排空，讓葡萄糖比較慢地進入小腸被吸收。
