雜訊與雜訊指數

這一課的目標

  • 理解熱雜訊的來源
  • 理解雜訊指數
  • 學會用 Friis 雜訊公式分析接收機

熱雜訊

任何溫度高於絕對零度的電阻，內部電子的隨機熱運動都會產生雜訊。在頻寬 B 內的熱雜訊功率是

\[N = kTB\]

k 是波茲曼常數（見〈統計物理〉）。在室溫（290 K），每 1 Hz 頻寬的雜訊約 −174 dBm。1 MHz 頻寬就是 −174 + 60 = −114 dBm；20 MHz 的 Wi-Fi 通道約 −101 dBm。

訊雜比決定一切

接收機能不能正確解調，取決於訊雜比（SNR）：訊號比雜訊強多少。夏農定理告訴我們，通道容量 C = B log2(1 + SNR)：頻寬越寬、訊雜比越高，能傳的資料越多（見〈資訊理論〉、〈數位通訊〉）。所以接收靈敏度 ≈ 雜訊底線 + 雜訊指數 + 需要的訊雜比。

雜訊指數

每一個放大器、混頻器都會額外加入自己的雜訊，讓訊雜比變差。雜訊指數（NF）衡量訊雜比變差了多少 dB：理想的元件 NF = 0 dB；手機接收機的低雜訊放大器約 1 dB 左右。

第一級最重要

Friis 雜訊公式（又是弗里斯）說明：串接的接收機，整體的雜訊指數主要由第一級決定；第一級的增益夠高，後面各級的雜訊影響就會被「除掉」。所以接收機的第一個元件是低雜訊放大器（LNA，第 18 課），而且要放得離天線越近越好——天線與 LNA 之間的每一 dB 纜線損耗，都直接加到雜訊指數上。衛星碟形天線焦點上的 LNB，就是把低雜訊放大器直接裝在天線上。

其他的雜訊與干擾

  • 天空雜訊：銀河、太陽與大氣也會輻射雜訊；大爆炸留下的宇宙微波背景輻射，最早就是在 1964 年被當作天線的「多餘雜訊」而發現的（見〈大霹靂〉）。
  • 人為雜訊：馬達、開關電源、LED 燈的驅動器、其他無線設備（第 24 課）。
  • 相位雜訊：振盪器的頻率不夠純淨，影響高階調變（第 19 課）。

🧭 這一課的重點

電阻內電子熱運動產生熱雜訊 N = kTB，室溫每 Hz 約 −174 dBm，1 MHz 為 −114 dBm、20 MHz Wi-Fi 約 −101 dBm；能否解調取決於訊雜比，夏農定理 C = B log2(1+SNR)，接收靈敏度 ≈ 雜訊底線 + 雜訊指數 + 需要的 SNR；雜訊指數衡量訊雜比變差多少 dB，手機 LNA 約 1 dB；Friis 雜訊公式顯示整體雜訊指數主要由第一級決定，故第一級為 LNA 且要靠近天線，纜線損耗直接加到雜訊指數，衛星碟的 LNB 即裝在天線上；其他雜訊有天空雜訊（1964 年宇宙微波背景輻射以多餘雜訊發現）、人為雜訊、振盪器相位雜訊。
