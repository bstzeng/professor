Linux ELF 與 macOS Mach-O 的對照

這一課的目標

  • 對照 PE、ELF、Mach-O 的關鍵差異
  • 理解三者共通的載入劇本
  • 建立跨平台的遷移能力

前兩個模組主要以 Windows PE 為例，但你已經見過 Linux 的 ELF（第 3 課）。這一課把三大系統擺在一起對照，你會發現它們是「同一齣戲、不同演員」。

1. 三者對照

WindowsLinuxmacOS
格式PEELFMach-O
開頭MZ7F ELFFE ED FA CE 等
動態庫.dll.so.dylib
載入器（系統載入器）ld.sodyld
啟動CreateProcessexecve（類似）
叫作業系統透過 DLLsyscall 直接叫透過 dylib

2. 劇本其實一樣

名字都不同，但每個系統做的事完全對得上：讀檔頭 → 配記憶體與 ASLR → 載入動態庫、接好函式 → 跑進入點與啟動碼 → 執行 → 結束回收。你在模組 K 學的那條時間線（第 9 課），在三個系統上都成立。

3. 遷移能力

這正是這門課想給你的：理解一個系統的執行檔原理後，換到另一個系統只需要對應名詞，不必從頭學。底層的概念（分頁、動態連結、進入點、系統呼叫）是共通的，這也是電腦科學裡「原理重於細節」的體現。

動手試試

如果你能用到 Linux 或 Mac，用 file 指令看各種執行檔會顯示 ELF 或 Mach-O；再用 readelf（Linux）或 otool（Mac）看它的檔頭與依賴的動態庫。

🔧 本課用最小範例與觀察工具，說明執行檔的結構與載入原理，屬於系統知識與資安基礎；不含惡意程式技術。手工打造的極小執行檔常被防毒軟體視為可疑，請只在自己的環境、用自己的檔案練習。
