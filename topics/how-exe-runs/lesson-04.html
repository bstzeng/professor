PE 格式總覽：MZ 檔頭、DOS stub 與 PE 簽章

這一課的目標

  • 讀懂 PE 檔案的開頭結構
  • 理解 MZ 檔頭與 DOS stub 的由來
  • 知道 PE、ELF、Mach-O 的對應關係

Windows 的執行檔格式叫 PE（Portable Executable）。打開任何一個 .exe，開頭都是同樣的招牌。

1. MZ 檔頭：向 DOS 致敬

每個 PE 檔開頭是 4D 5A（「MZ」，魔術數字），這是 1980 年代 DOS 執行檔的標誌，取自微軟工程師 Mark Zbikowski 的姓名縮寫。為了相容，現代 exe 還保留著它。

2. DOS stub

MZ 檔頭後面跟著一小段 DOS stub：一段能在古老 DOS 上執行的迷你程式，作用只是印出「This program cannot be run in DOS mode」。所以如果你在 DOS 跑現代 exe，會看到這句話，而不是當機。

3. PE 簽章

真正的 PE 內容從哪開始？位置寫在檔案的 0x3C。跳過去會看到 50 45 00 00（「PE\0\0」），這才是現代執行檔的正身，後面接著檔頭與區段表。

4. 三大系統的對應

系統執行檔格式開頭
WindowsPEMZ（4D 5A）
LinuxELF7F ELF（第 3 課）
macOSMach-OFE ED FA CE 之類

三者細節不同，但都要回答同樣的問題：程式從哪開始跑、載到記憶體哪、要借哪些函式庫。接下來幾課就沿著這幾個問題，拆解 PE 的各個部分。

動手試試

用 Hex 檢視器打開任何一個 .exe，開頭一定是 4D 5A（MZ）。往後找找看 “This program cannot be run in DOS mode” 這句話，它就是 DOS stub。

🔧 本課用最小範例與觀察工具，說明執行檔的結構與載入原理，屬於系統知識與資安基礎；不含惡意程式技術。手工打造的極小執行檔常被防毒軟體視為可疑，請只在自己的環境、用自己的檔案練習。
