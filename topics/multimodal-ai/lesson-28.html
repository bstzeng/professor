模組 F｜視覺語言模型 · 第 28 課

LLM 怎麼「看圖」

這一課的目標

  • 理解視覺語言模型的基本架構
  • 知道三個零件的分工
  • 了解訓練的兩個階段

最常見的做法是把三個零件接起來：

  1. 視覺編碼器：通常是預訓練好的 ViT（例如 CLIP、SigLIP），把圖片變成一串 patch 向量。
  2. 投影層：一個小的線性層或 MLP，把視覺向量轉成 LLM 的 embedding 維度。
  3. LLM：把這些「視覺 token」和文字 token 排在一起，照常逐字生成回答。

兩階段訓練

  • 對齊階段：凍結編碼器和 LLM，只訓練投影層，用大量「圖片＋說明」讓兩邊說同一種語言。
  • 指令微調：用「圖片＋問題＋回答」資料微調，讓模型學會依指令看圖回答。

另一條路是原生多模態：從預訓練開始就把圖片、文字（甚至聲音）的 token 混在一起訓練，例如 GPT-4o、Gemini 系列宣稱的做法。

🧭 這一課的重點

視覺語言模型常由視覺編碼器（如 CLIP ViT）、投影層和 LLM 組成，圖片變成視覺 token 與文字一起送入 LLM。訓練先對齊投影層、再做指令微調；原生多模態模型則從預訓練就混合各種 token。

🎨 本課的互動工具在瀏覽器裡即時計算，使用的是教學用的小例子；CLIP 相似度等數值為示意。各模型與產品的推出年份以發表或公開時間為準，功能與授權條款變動很快，使用前請查詢官方最新說明。
