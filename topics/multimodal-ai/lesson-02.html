生成模型的四大家族

這一課的目標

  • 認識四種生成模型的基本想法
  • 比較它們的優缺點
  • 知道為什麼擴散模型成為主流

「生成」的本質是：從訓練資料學出一個機率分布，再從裡面抽樣出新的東西。分類模型只要學「這張是不是貓」，生成模型要學「貓的照片長什麼樣」，難得多。

家族一句話優點缺點
GAN生成器和判別器對抗生成快（一步）、銳利訓練不穩定、多樣性差
VAE壓縮到潛空間再解碼訓練穩定、有潛空間圖片偏模糊
Flow一連串可逆變換能算精確機率架構受限
Diffusion學會一步步去除雜訊品質與多樣性最好、穩定生成要很多步、較慢
自回歸一個 token 一個 token 生成和 LLM 共用架構影像 token 很多、慢

2021～2022 年起，擴散模型在圖片生成全面超越 GAN；現在的 Midjourney、Stable Diffusion、Flux、DALL·E 3、Sora 都以擴散（或相近的 flow matching）為核心。VAE 也沒消失——它成了擴散模型裡負責壓縮的零件。

🧭 這一課的重點

生成模型要學出資料的機率分布並從中抽樣。GAN 快而銳利但難訓練，VAE 穩定但模糊，Flow 可算精確機率，擴散模型品質與多樣性最好而成為主流；自回歸則是 LLM 式的另一條路。
