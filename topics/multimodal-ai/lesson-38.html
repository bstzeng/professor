音訊 token 化：Neural codec

這一課的目標

  • 理解 neural codec 的作用
  • 知道殘差向量量化
  • 了解它如何連結 LLM 與聲音

LLM 擅長處理離散的 token。要讓它生成聲音，就需要一個能把聲音變成 token、再變回聲音的工具：neural codec（Google 的 SoundStream 2021、Meta 的 EnCodec 2022 等）。

殘差向量量化（RVQ）

編碼器每約 13 毫秒輸出一個向量，用一本「碼本」找最接近的一項，記下編號；剩下的誤差再用第二本碼本、第三本……逐層逼近。第一層抓大致的聲音，後面幾層補細節。這些編號就是聲音 token。

有了聲音 token，生成語音或音樂就變成「預測下一個 token」——和 LLM 完全一樣的問題。AudioLM（2022）、VALL-E（2023）、MusicGen（2023）以及許多即時語音對話模型都走這條路。

🧭 這一課的重點

Neural codec（如 SoundStream、EnCodec）把波形壓縮成離散 token 再還原，用殘差向量量化逐層逼近。聲音變成 token 後，生成語音與音樂就成了預測下一個 token 的問題，可用 LLM 的方法處理。
