模組 A｜基礎 · 第 4 課

從 C 程式到機器碼

這一課的目標

  • 理解程式轉換成機器碼的過程
  • 讀懂簡單的組合語言
  • 理解迴圈與條件判斷如何變成分支

四個步驟

原始碼 → 編譯器產生組合語言 → 組譯器產生機器碼（目的檔）→ 連結器把多個目的檔與函式庫合併成執行檔 → 作業系統載入執行。編譯器的內部見〈編譯器〉，執行檔的格式見〈執行檔是怎麼跑起來的〉。

一個例子

// C int sum = 0; for (int i = 0; i < n; i++) sum += a[i]; # RISC-V 組合語言（a0 = 陣列位址, a1 = n） li t0, 0 # sum = 0 li t1, 0 # i = 0 loop: bge t1, a1, done # if i >= n 跳出 slli t2, t1, 2 # t2 = i * 4（每個 int 4 位元組） add t2, a0, t2 # t2 = &a[i] lw t3, 0(t2) # t3 = a[i] add t0, t0, t3 # sum += a[i] addi t1, t1, 1 # i++ j loop done:

觀察

  • 迴圈變成分支：for 迴圈變成一個條件分支（bge）加一個無條件跳躍（j）。
  • 陣列存取要算位址：a[i] 的位址 = 陣列起點 + i × 4。
  • 變數住在暫存器：sum、i 都放在暫存器 t0、t1 中，比記憶體快得多。

一個簡單的迴圈，每一輪要執行 7 條指令，其中有 1 次記憶體載入、2 次分支或跳躍。這些指令怎麼被處理器快速執行，就是接下來幾個模組的主題。

🧭 這一課的重點

原始碼經編譯器、組譯器、連結器變成執行檔再由作業系統載入；C 的 for 迴圈在 RISC-V 中變成條件分支 bge 與跳躍 j，陣列存取要計算起點加 i 乘 4 的位址，變數住在暫存器中。

🖥️ 本課的數字多為教學用的簡化例子；互動元件是示意模型，實際的設計與計算請以專業文件與標準為準。

檢查你的理解

  1. 說出原始碼變成執行檔的四個步驟。
  2. 範例中，for 迴圈被翻譯成哪些指令？
  3. 為什麼 a[i] 的位址要乘以 4？
