RISC-V 入門

這一課的目標

  • 認識 RISC-V 的特色
  • 了解 RISC-V 的模組化設計
  • 理解開放 ISA 的意義

開放與免授權費

RISC-V 在 2010 年誕生於柏克萊，是一套開放、免授權費的指令集。任何公司都可以設計 RISC-V 處理器，不必向任何人付費——這和需要授權的 ARM、只有少數公司能做的 x86 大不相同。

模組化

擴充內容
RV32I / RV64I基本整數指令（約 40 條），32 或 64 位元
M整數乘除法
A原子操作（多核心同步用）
F / D單精度 / 雙精度浮點數
C16 位元壓縮指令，縮小程式碼
V向量運算

微控制器可以只實作基本指令；伺服器處理器則加上所有的擴充。這種「按需選配」的設計，讓 RISC-V 從小晶片到超級電腦都適用。

32 個暫存器

RISC-V 有 32 個整數暫存器 x0～x31，其中 x0 永遠等於 0——寫入無效，讀出永遠是 0。這個小設計讓許多指令可以組合出新功能，例如「把 x5 複製到 x6」可以寫成 add x6, x5, x0。

現況

RISC-V 已經大量用在微控制器、儲存控制器、AI 加速器中，也開始出現在手機與伺服器的研發中。它也是教學用的熱門 ISA，本課程的範例都使用 RISC-V。

🧭 這一課的重點

RISC-V 2010 年誕生於柏克萊，開放免授權費；採模組化設計，基本整數指令約 40 條，加上乘除 M、原子 A、浮點 F/D、壓縮 C、向量 V 等擴充；32 個暫存器中 x0 永遠為 0；廣泛用於微控制器與加速器，也是熱門教學 ISA。
