整地與基礎

這一課的目標

  • 認識基礎的種類
  • 了解開挖與基礎施工
  • 知道業主要看什麼

基礎把整棟房子的重量傳到地盤。選用哪一種，由結構技師依鑽探結果與建物規模決定：

  • 獨立基腳：每根柱子下方一個擴大的基腳，常見於地盤較好的低樓層住宅
  • 筏式基礎：整片厚底板，分散荷重，適合地盤較弱或有地下室
  • 樁基礎：把荷重傳到深處的堅硬地層，用於軟弱地盤

施工順序大致是：整地 → 開挖 → 打底（PC 混凝土墊層）→ 綁鋼筋、組模板 → 勘驗 → 澆置混凝土 → 養護 → 回填。開挖時若遇到地下水、舊基礎或與鑽探不符的地層，要立即請技師評估。

業主要看的

澆置混凝土之前，請建築師或監造確認鋼筋的數量、間距、保護層厚度符合圖說，並拍照留存。基礎被埋起來之後，就再也看不到了。

🧭 這一課的重點

基礎依鑽探與規模選用獨立基腳、筏式基礎或樁基礎；施工依整地、開挖、墊層、鋼筋模板、勘驗、澆置、養護、回填進行；遇異常地層請技師評估，澆置前確認鋼筋並拍照。

🏡 本課介紹自地自建的流程與觀念。土地使用、建築、農舍、危老等規定依縣市與最新法令而不同，實際案件請向建築師、技師與縣市政府主管機關確認；工具中的數字都是示範，請換成你自己的條件與報價。
