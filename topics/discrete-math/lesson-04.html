量詞：所有與存在

這一課的目標

  • 理解述詞與量詞
  • 會否定含量詞的敘述
  • 理解多個量詞的順序很重要

「x > 3」不是命題，因為 x 未定。這種含變數的敘述叫述詞 P(x)。加上量詞，就變成命題：

符號讀法何時為真如何證偽
\(\forall x\, P(x)\)對所有 x，P(x)每一個 x 都滿足找到一個反例
\(\exists x\, P(x)\)存在 x 使 P(x)至少一個 x 滿足證明每一個 x 都不滿足

否定：∀ 和 ∃ 互換

\[\neg\forall x\,P(x) \equiv \exists x\,\neg P(x),\qquad \neg\exists x\,P(x) \equiv \forall x\,\neg P(x)\]

「不是所有天鵝都是白的」= 「存在一隻天鵝不是白的」。這是德摩根定律的推廣：∀ 像是很多個 ∧，∃ 像是很多個 ∨。

量詞的順序

  • \(\forall x\,\exists y\,(y > x)\)：對每個數，都有比它大的數。（真）
  • \(\exists y\,\forall x\,(y > x)\)：有一個數比所有數都大。（假）

只是交換順序，意思就完全不同。「每個人都有一個喜歡的人」和「有一個人被所有人喜歡」也是同樣的差別。

數學中的例子

極限的定義就是三層量詞：

\[\lim_{x\to a}f(x) = L \iff \forall\varepsilon>0\;\exists\delta>0\;\forall x\,\big(0<|x-a|<\delta \to |f(x)-L|<\varepsilon\big)\]

微積分的 ε-δ 定義讓很多人頭痛，其實主要困難就是量詞的順序與否定。

資料庫查詢

SQL 的 EXISTS、NOT EXISTS 就是 ∃ 與 ¬∃。「找出修了所有必修課的學生」這種 ∀ 查詢，通常要寫成「不存在一門必修課是他沒修的」——正是量詞的否定。

🧭 這一課的重點

述詞 P(x) 加上量詞成為命題：∀x P(x) 要每個 x 都滿足，一個反例即可推翻；∃x P(x) 只需一個 x 滿足。否定時 ∀ 與 ∃ 互換、述詞取否定。多個量詞的順序會改變意義，例如 ∀x∃y 與 ∃y∀x。極限的 ε-δ 定義與 SQL 的 EXISTS 都是量詞的應用。

  1. 否定「每個學生都至少修了一門數學課」。
  2. ∀x ∃y (x + y = 0) 在實數中是真的嗎？∃y ∀x (x + y = 0) 呢？
  3. 為什麼推翻 ∀ 敘述只需要一個反例？
