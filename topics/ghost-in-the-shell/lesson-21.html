Solid State Society

這一課的目標

  • 掌握 Solid State Society 的情節
  • 理解作品探討的社會問題
  • 認識素子離開又回來的轉折

基本資料

2006 年的長篇電視電影，設定在 2nd GIG 的兩年後（2034 年）。素子已經離開九課，九課由陀古沙擔任現場指揮，規模也擴大了。

情節

  1. 一連串難民軍人的自殺事件，指向一個名為「傀儡廻」（Puppeteer）的超級駭客。
  2. 九課調查發現，有大量的受虐兒童被從家中帶走、下落不明。
  3. 真相：一群政府高層與財界人士推動一個計畫，把受虐的孩子從問題家庭中帶走，送到獨居、臥床的老人名下扶養，用電子腦系統讓老人們「養育」這些孩子，未來培養成國家的菁英——名為「Solid State」。
  4. 這些老人，有的本身是被社會遺忘的人，他們的意識被系統串連在一起。
  5. 素子在追查中重新出現，最後回到九課。

爭議的問題

  • 少子高齡化：日本社會的真實危機。孩子越來越少，老人越來越多，誰來照顧誰？
  • 受虐兒童：國家該不該介入問題家庭？可以用什麼手段？
  • 為了「善」的目的而違法：計畫的推動者真心認為自己在拯救孩子，但他們剝奪了孩子與家人的選擇。
  • 作品沒有簡單地把計畫寫成邪惡：被帶走的孩子確實從虐待中被救出——但這樣的「拯救」是對的嗎？

素子的回歸

素子離開九課的兩年，在網路中獨自行動。她發現，自己追查的方向和九課重疊；最後她選擇回到九課——不是因為需要組織，而是她認識到，自己作為一個 Ghost，仍然需要與他人的連結。

「Solid State」

Solid State 原本是「固態」的意思，例如固態硬碟。在作品中，它暗示一種「凍結」的社會：老人的意識與孩子的未來，被系統固定下來，社會失去了流動與變化。

🧭 這一課的重點

Solid State Society 是 2006 年的長篇電視電影，設定 2034 年，素子已離開九課，陀古沙擔任現場指揮。難民軍人自殺事件指向超級駭客傀儡廻，九課發現大量受虐兒童被帶走，真相是政府高層與財界把受虐孩子送到獨居臥床老人名下，以電子腦系統讓老人養育並培養成菁英，名為 Solid State，素子在追查中重新出現並回到九課。作品探討少子高齡化、國家介入問題家庭的手段、以善為目的的違法，以及這種拯救是否正確。素子離開兩年後認識到作為 Ghost 仍需要與他人的連結。Solid State 暗示被系統凍結、失去流動的社會。
