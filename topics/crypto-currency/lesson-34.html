The DAO 事件與以太坊分叉

這一課的目標

  • 知道 The DAO 事件經過
  • 理解重入攻擊
  • 認識以太坊經典的由來

2016 年，「The DAO」是一個以智慧合約運作的去中心化投資基金，募集了約當時全部以太幣的 14%。6 月，有人利用合約漏洞轉走約 360 萬枚 ETH。

重入攻擊

合約的提款函式先轉帳、後更新餘額。攻擊者的合約在收到轉帳的瞬間，又再次呼叫提款——此時餘額還沒被扣掉，於是可以反覆提款。

// 有漏洞的寫法（概念） function withdraw() { send(msg.sender, balance[msg.sender]); // ① 先轉帳 → 攻擊者在這裡再次呼叫 withdraw balance[msg.sender] = 0; // ② 才歸零（太晚了） } // 正確順序：先把餘額歸零，再轉帳

2016 年 7 月，以太坊社群決定硬分叉，把被盜的資金退回。反對者認為「程式即法律」不該被人為推翻，繼續使用原本的鏈，成為以太坊經典（ETC）。

🧭 這一課的重點

The DAO 的重入漏洞導致巨額資金被盜，以太坊以硬分叉回復，反對者留在原鏈形成以太坊經典。
