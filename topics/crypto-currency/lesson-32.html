智慧合約

這一課的目標

  • 理解智慧合約是什麼
  • 讀懂一個簡單的合約
  • 知道合約的特性與風險

「智慧合約」一詞由尼克．薩博在 1990 年代提出，比喻是自動販賣機：投錢、按按鈕，規則保證你一定拿到商品，不需要店員。

// Solidity：一個極簡的存錢筒合約 contract PiggyBank { address public owner = msg.sender; // 部署者就是主人 receive() external payable {} // 任何人都可以存錢進來 function withdraw() external { require(msg.sender == owner, "not owner"); // 只有主人能領 payable(owner).transfer(address(this).balance); } }
特性好處風險
公開透明任何人都能檢查程式碼漏洞也被所有人看見
不可修改部署後規則不會被偷偷改有錯也不能直接修正
自動執行不需要信任對方「程式即法律」：漏洞被利用也照樣執行

🧭 這一課的重點

智慧合約是部署在區塊鏈上、自動執行的程式；它公開、不可修改，但任何漏洞也同樣不可挽回。
