平均場理論與朗道理論

這一課的目標

  • 理解平均場近似
  • 推出自洽方程式
  • 認識朗道自由能展開

伊辛模型難解，是因為每個自旋都受鄰居影響，鄰居又受它們的鄰居影響。平均場近似把所有鄰居換成它們的平均值 m，每個自旋只感受到一個有效磁場 zJm（z 是鄰居數），得到自洽方程式：

\[m = \tanh\!\left(\frac{zJm}{k_BT}\right),\qquad T_c^{MF} = \frac{zJ}{k_B}\]

T 高於 Tc 只有 m = 0 的解；低於 Tc 出現 ±m 兩個解——相變自然出現了。對二維正方格子（z = 4），平均場給出 Tc = 4，真實值是 2.269：平均場高估了，因為它忽略了漲落。

朗道用同樣的精神，在 Tc 附近把自由能展開成序參量的冪級數：

\[F(m) = F_0 + a(T - T_c)\,m^2 + b\,m^4 + \cdots\]

T 低於 Tc 時 m² 的係數變負，最低點從 m = 0 移開——和金茲堡—朗道超導理論的「酒瓶底」完全一樣。

🧭 這一課的重點

平均場理論用平均值取代鄰居，得到自洽方程式與相變；朗道理論把自由能展開成序參量的冪級數。
