模組 C｜載子 · 第 17 課

產生與復合

這一課的目標

  • 說明三種復合機制
  • 推導 SRH 復合率
  • 理解少數載子壽命

熱平衡時產生率等於復合率。偏離平衡時（照光、注入），淨復合率 \(U = R - G\) 讓系統回到平衡。

SRH 復合

矽是間接能隙，主要經由能隙中的缺陷能階 \(E_t\)（金屬雜質、空位）兩步完成。肖克萊－里德－霍爾（SRH）推導出：

\[ U_{SRH} = \frac{np - n_i^2}{\tau_p(n + n_1) + \tau_n(p + p_1)},\quad n_1 = n_ie^{(E_t-E_i)/kT},\; p_1 = n_ie^{(E_i-E_t)/kT} \]

\(\tau_{n,p} = 1/(\sigma v_{th}N_t)\)。兩個重要結論：

  • 陷阱能階越接近能隙中央（\(E_t\approx E_i\)），復合越有效。所以金、鐵等在中央附近有能階的雜質是「殺手」。
  • 低注入的 n 型材料中：\(U \approx \Delta p/\tau_p\)。少數載子壽命 \(\tau_p\) 從奈秒到毫秒，取決於材料純度；功率元件有時故意摻金或電子照射來縮短壽命以加快開關（第 50 課）。

其他機制

輻射復合 \(U = B(np - n_i^2)\) 在直接能隙材料主導；歐傑復合 \(U \propto (C_nn + C_pp)(np-n_i^2)\) 在高濃度（重摻雜射極、高注入、雷射）時主導。表面也有懸鍵造成的表面復合，以表面復合速度描述——太陽能電池要做表面鈍化（第 46 課）。

當 \(np < n_i^2\)（例如逆偏的空乏區），\(U < 0\)，代表淨產生：這是逆偏接面漏電流的主要來源之一（第 23 課）。

🧭 這一課的重點

偏離平衡時淨復合率使系統恢復平衡。矽以 SRH 復合為主：U = (np − ni²)/[τp(n + n1) + τn(p + p1)]，陷阱越近能隙中央越有效，低注入 n 型時 U ≈ Δp/τp。輻射復合在直接能隙材料主導，歐傑復合在高濃度主導，另有表面復合；np < ni² 時為淨產生，造成逆偏漏電。

🔬 本課程以矽為主要例子，常數取室溫（300 K）的常用值：Eg ≈ 1.12 eV、ni ≈ 1.0×1010 cm−3、kT/q ≈ 25.9 mV。互動工具使用教科書等級的解析模型，用來建立直覺與量級，不能取代 TCAD 或 SPICE 模型。
