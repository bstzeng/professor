MOS 電容

這一課的目標

  • 說明 MOS 電容的三種狀態
  • 推導空乏電荷與表面電位的關係
  • 定義強反轉條件

金屬（閘極）—氧化層—半導體構成一個電容。p 型基板時：

  • 累積：負閘壓把電洞吸到表面，像一般平行板電容，\(C = C_{ox} = \varepsilon_{ox}/t_{ox}\)。
  • 空乏：正閘壓把電洞推開，留下負的受體離子。空乏寬度 \(W_d = \sqrt{2\varepsilon_s\psi_s/qN_a}\)，空乏電荷 \(Q_d = -qN_aW_d = -\sqrt{2\varepsilon_sqN_a\psi_s}\)。
  • 反轉：表面電位大到表面電子比電洞多。強反轉定義為表面電子濃度等於基板電洞濃度：\(\psi_s = 2\phi_F\)，\(\phi_F = (kT/q)\ln(N_a/n_i)\)。之後空乏寬度停止增加（最大值 \(W_{dm}\)），額外的閘極電荷都由反轉層電子提供。

閘極電壓分配在氧化層與半導體上：

\[ V_G = V_{FB} + \psi_s - \frac{Q_s}{C_{ox}} \]

表面總電荷 \(Q_s\) 的精確式（不用空乏近似）可由泊松方程式在垂直方向積分一次得到：

\[ Q_s = \mp\sqrt{2\varepsilon_skTN_a}\left[\left(e^{-\beta\psi_s}+\beta\psi_s-1\right) + \frac{n_i^2}{N_a^2}\left(e^{\beta\psi_s}-\beta\psi_s-1\right)\right]^{1/2},\quad \beta = \frac{q}{kT} \]

第一項是電洞（累積）與空乏電荷，第二項是電子（反轉），在 \(\psi_s > 2\phi_F\) 後指數成長。下一課的互動工具就是用這個式子算的。

🧭 這一課的重點

MOS 電容在 p 型基板上依閘壓分為累積（C ≈ Cox）、空乏（Qd = −√(2εsqNaψs)）與反轉；強反轉定義為 ψs = 2φF，此後空乏寬度停止增加，額外電荷由反轉電子提供。閘壓分配為 VG = VFB + ψs − Qs/Cox，Qs 的精確式由泊松方程式積分得到，包含電洞、空乏與指數成長的電子項。

🔬 本課程以矽為主要例子，常數取室溫（300 K）的常用值：Eg ≈ 1.12 eV、ni ≈ 1.0×1010 cm−3、kT/q ≈ 25.9 mV。互動工具使用教科書等級的解析模型，用來建立直覺與量級，不能取代 TCAD 或 SPICE 模型。
