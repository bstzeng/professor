光偵測器與影像感測器

這一課的目標

  • 說明光二極體與 PIN、APD 的原理
  • 理解 CMOS 影像感測器的像素結構
  • 認識影像感測器的雜訊來源
元件原理特點
光二極體逆偏 PN 接面收集光產生的載子簡單、線性
PIN 光二極體中間加一層本質層，空乏區寬收集效率高、電容小、速度快，光通訊接收器
雪崩光二極體（APD）在接近崩潰的高電場中倍增高增益，但有額外雜訊
單光子雪崩二極體（SPAD）偏壓超過崩潰電壓，一個光子就能觸發雪崩光達（LiDAR）、手機測距

量子效率 \(\eta\) 是每個入射光子產生的電子數，響應度 \(R = \eta q\lambda/hc\)（A/W）。

CMOS 影像感測器

每個像素是一個埋入式光二極體（pinned photodiode）加上幾顆電晶體：

  1. 曝光時，光電子累積在 n 型區（表面有 p⁺ 層「釘住」電位、隔開介面缺陷，大幅降低暗電流）。
  2. 轉移閘把電荷完全轉移到浮動擴散區（一個小電容）。
  3. 源極隨耦器把電荷轉成電壓讀出。
  4. 相關雙取樣：讀一次重置值、一次訊號值，相減消除重置雜訊（kTC 雜訊）。
  • 背照式（BSI）：把晶圓翻過來，光從背面進入，不被金屬線擋住。
  • 堆疊式：像素層與邏輯電路層分別製作再接合，現在手機的高階感測器多採用。
  • 雜訊來源：暗電流（空乏區產生電流，第 23 課）、光子散粒雜訊（\(\sqrt{N}\)）、讀出雜訊、固定圖樣雜訊。

🧭 這一課的重點

光偵測器包括逆偏光二極體、寬本質層的 PIN、利用雪崩倍增的 APD 與單光子觸發的 SPAD，響應度 R = ηqλ/hc。CMOS 影像感測器像素以埋入式光二極體累積電子、轉移閘轉移電荷、源極隨耦器讀出，並以相關雙取樣消除重置雜訊；背照式與堆疊式提升性能，雜訊來自暗電流、散粒雜訊與讀出雜訊。

🔬 本課程以矽為主要例子，常數取室溫（300 K）的常用值：Eg ≈ 1.12 eV、ni ≈ 1.0×1010 cm−3、kT/q ≈ 25.9 mV。互動工具使用教科書等級的解析模型，用來建立直覺與量級，不能取代 TCAD 或 SPICE 模型。
