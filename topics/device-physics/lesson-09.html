電洞

這一課的目標

  • 說明電洞的概念
  • 推導電洞的電荷與有效質量符號
  • 理解電洞是準粒子

價帶幾乎全滿時，與其追蹤 \(10^{22}\) 個電子，不如追蹤少數幾個空位。全滿能帶的總電流為零：

\[ \mathbf J_{\text{滿}} = -q\sum_{\text{all}}\mathbf v_k = 0 \Rightarrow \mathbf J = -q\sum_{\text{佔據}}\mathbf v_k = +q\sum_{\text{空位}}\mathbf v_k \]

所以空位帶來的電流，就像一個帶 \(+q\) 的粒子以空位處的速度移動。

  • 價帶頂的曲率是負的（\(d^2E/dk^2<0\)），那裡的電子有效質量為負。缺少一個負質量、負電荷的電子，等效於一個正質量、正電荷的粒子：電洞。
  • 電洞的能量往下為正：在能帶圖上，電洞「往上浮」，就像氣泡。
  • 電洞的有效質量通常比電子大，遷移率較小（矽 \(\mu_p\approx 450\)、\(\mu_n\approx 1400\ \text{cm}^2/\text{V·s}\)），這是 PMOS 要做得比 NMOS 寬的原因。

霍爾效應可以直接證明電洞的存在：p 型半導體的霍爾電壓符號與 n 型相反，如同載子帶正電。

🧭 這一課的重點

價帶幾乎全滿時，追蹤空位比追蹤所有電子方便。全滿能帶總電流為零，因此空位造成的電流等效於帶 +q 的粒子；價帶頂電子有效質量為負，缺少它等效於正質量正電荷的電洞。電洞在能帶圖上往上浮，遷移率通常較小，霍爾效應可證明其存在。

🔬 本課程以矽為主要例子，常數取室溫（300 K）的常用值：Eg ≈ 1.12 eV、ni ≈ 1.0×1010 cm−3、kT/q ≈ 25.9 mV。互動工具使用教科書等級的解析模型，用來建立直覺與量級，不能取代 TCAD 或 SPICE 模型。
