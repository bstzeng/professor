動手一：看複數乘法在轉什麼

這一課的目標

  • 會用程式操作複數
  • 驗證乘法的幾何法則
  • 建立實際的手感

本模組的三課都提供可直接執行的程式。 Python 內建支援複數，不需要安裝任何東西。

1. 基本操作

import cmath

z = 3 + 4j          # Python 用 j 表示虛數單位
print(z.real)       # 3.0
print(z.imag)       # 4.0
print(abs(z))       # 5.0        模
print(cmath.phase(z))            # 輻角（弧度）
print(z.conjugate())             # 共軛

注意 Python 用 j（和工程界一致）， 而且必須寫成 4j 不能寫 j。

2. 驗證「長度相乘、角度相加」

import cmath, math

a = 2 * cmath.exp(1j * math.radians(30))   # 長度 2，角度 30 度
b = 3 * cmath.exp(1j * math.radians(45))   # 長度 3，角度 45 度
c = a * b

print(abs(a), abs(b), abs(c))
# 2.0 3.0 6.0            → 2 乘 3 等於 6，長度相乘

print(math.degrees(cmath.phase(c)))
# 75.0                   → 30 加 45 等於 75，角度相加

模組 C 的核心法則，兩行就驗證完了。

3. 驗證 i 的四次循環

z = 1j
for n in range(1, 6):
    p = z ** n
    print(n, round(p.real, 10), round(p.imag, 10))

# 1  0.0   1.0     → i      上
# 2 -1.0   0.0     → -1     左
# 3 -0.0  -1.0     → -i     下
# 4  1.0  -0.0     → 1      回到原點
# 5  0.0   1.0     → i      重新開始

（round 是為了消掉浮點運算的微小誤差， 否則會看到 6.1e-17 之類的數字。這是正常現象。）

4. 畫出來

import matplotlib.pyplot as plt
import cmath, math

base = 1 + 0.3j
pts = [base ** n for n in range(12)]      # 連續乘同一個複數

plt.figure(figsize=(5, 5))
plt.plot([p.real for p in pts], [p.imag for p in pts], "o-")
plt.axhline(0, lw=0.5); plt.axvline(0, lw=0.5)
plt.gca().set_aspect("equal")
plt.title("repeated multiplication")
plt.show()

執行後你會看到一條向外旋開的螺線。 因為 \( |1 + 0.3i| \) 略大於 \( 1 \)，每乘一次就轉一點、放大一點。

把 base 換成 0.9 + 0.3j（模小於 1）， 會得到向內收縮的螺線。

這正是模組 I 的穩定性判準： 模大於一發散、小於一收斂。你剛剛親手畫出了那個判準。

本課重點

  • Python 內建複數，虛數單位寫作 j
  • abs 取模、cmath.phase 取輻角
  • 可直接驗證長度相乘、角度相加
  • 連續乘同一複數會畫出螺線，模的大小決定收斂或發散

檢查你的理解

  1. 用程式驗證兩個複數相乘的模與輻角
  2. 印出 \( i \) 的前八次方
  3. 改變 base 的模，觀察螺線的方向
