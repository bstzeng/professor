動手二：用旋轉疊出一個方波

這一課的目標

  • 以程式重現傅立葉疊加
  • 觀察吉布斯現象
  • 理解疊加的實際效果

模組 G 說「任何訊號都是一堆旋轉疊起來的」。本課驗證它。

1. 疊加方波

import numpy as np
import matplotlib.pyplot as plt

t = np.linspace(0, 2 * np.pi, 2000)

def square_approx(t, terms):
    s = np.zeros_like(t)
    for k in range(terms):
        n = 2 * k + 1                # 只取奇數倍頻
        s += np.sin(n * t) / n
    return s * 4 / np.pi

for terms in (1, 3, 10, 50):
    plt.plot(t, square_approx(t, terms), label=f"{terms} terms")

plt.legend(); plt.grid(alpha=0.3)
plt.title("building a square wave")
plt.show()

執行後你會看到四條曲線：一條純正弦波， 然後愈來愈方，到五十項時已經非常接近方波。

2. 觀察吉布斯現象

把項數加到很大（例如兩百項），注意轉角處： 那裡永遠有一個小小的過衝，而且高度不會隨項數增加而降低， 只會變得愈來愈窄。

這就是吉布斯現象。它是用連續函數逼近不連續跳躍時 必然出現的特徵，不是程式或計算的錯誤。

實務上它會造成數位訊號處理中的振鈴假影， 設計濾波器時必須考慮。

3. 用複數指數版本

上面用的是 \( \sin \)。換成模組 G 講的複數形式： 

import numpy as np

t = np.linspace(0, 2 * np.pi, 2000)

def square_complex(t, terms):
    s = np.zeros_like(t, dtype=complex)
    for k in range(terms):
        n = 2 * k + 1
        # 一對共軛的旋轉：正頻率與負頻率
        s += (np.exp(1j * n * t) - np.exp(-1j * n * t)) / (2j * n)
    return (s * 4 / np.pi).real     # 虛部應該接近 0

結果與前一版完全相同。這驗證了模組 G 的說法： 一條實數的正弦波，就是一對反向旋轉的箭頭之和。

4. 反過來：從訊號找出頻率

import numpy as np

fs = 1000                                  # 取樣率
t = np.arange(0, 1, 1 / fs)
sig = 3 * np.sin(2 * np.pi * 50 * t) + 1 * np.sin(2 * np.pi * 120 * t)

spec = np.fft.rfft(sig)                    # 結果是複數陣列
freq = np.fft.rfftfreq(len(t), 1 / fs)

peaks = np.argsort(np.abs(spec))[-2:]
print(sorted(freq[peaks]))                 # 約 [50.0, 120.0]

混在一起的訊號被拆回原本的兩個頻率。

注意 np.fft.rfft 回傳的是複數陣列—— 模是強度、輻角是相位，正如模組 G 所說。

本課重點

  • 方波可由奇數倍頻的正弦波依 1/n 權重疊出
  • 轉角處的過衝是吉布斯現象，不是錯誤
  • 複數指數版本與三角版本結果完全相同
  • FFT 的輸出是複數陣列：模是強度、輻角是相位
