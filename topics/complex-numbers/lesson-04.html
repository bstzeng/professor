模組 A｜序幕：為什麼你想像不出來 · 第 4 課

課程地圖與閱讀路徑

這一課的目標

  • 取得完整的課程地圖
  • 知道各模組之間的依賴關係
  • 依自己的需求選擇路徑

本課程共十四個模組、四十六課，分為五個區塊。

1. 模組地圖

2. 依賴關係

C 與 D 是全課程的地基，後面所有模組都依賴它們。 其餘的應用模組（F 到 I）彼此獨立，可以只挑有興趣的看。

  • A → B → C → D → E → 任選 F、G、H、I
  • J、K、L、M、N 可在讀完 D 之後任何時間讀

3. 依需求的建議路徑

你的目的建議路徑
只想弄懂「它到底是什麼」A → B → C → D → N
要修電路學或訊號C → D → E → F → G
要修控制系統C → D → I → 再修拉普拉斯課程
對物理有興趣C → D → E → H
想動手驗證C → D → L
純粹想解開心結A → B → C → K

4. 與另一門課的關係

本站另有一門拉普拉斯轉換課程。兩門課的關係是：

  • 本課程告訴你複數在描述旋轉
  • 那門課告訴你怎麼用旋轉去拆解任何訊號

建議先讀完本課程的模組 D，再進入那門課會順很多。 本課程的模組 G 就是那門課的入口。

模組 A 重點回顧

  • 「虛數」是反對者取的名字，記錄困惑而非性質
  • 電力、通訊、音訊、影像、控制全部依賴複數
  • 本課程從問題與幾何出發，把定義放在後面
  • 模組 C 與 D 是地基，應用模組可依興趣選讀

檢查你的理解

  1. 說出課程的五個區塊與各自的模組
  2. 指出哪兩個模組是全課程的地基
  3. 依自己的需求選出一條路徑
