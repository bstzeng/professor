動手三：畫出曼德博集合

這一課的目標

  • 以程式生成曼德博集合
  • 理解著色的意義
  • 總結本模組

最後一個練習，把模組 I 的碎形畫出來。

1. 完整程式

import numpy as np
import matplotlib.pyplot as plt

W, H, MAX_ITER = 800, 600, 200

# 建立複數平面上的一片網格
re = np.linspace(-2.2, 0.8, W)
im = np.linspace(-1.2, 1.2, H)
C = re[None, :] + 1j * im[:, None]

Z = np.zeros_like(C)
escape = np.zeros(C.shape, dtype=int)
alive = np.ones(C.shape, dtype=bool)

for n in range(MAX_ITER):
    Z[alive] = Z[alive] ** 2 + C[alive]      # 核心那一行
    gone = alive & (np.abs(Z) > 2)           # 跑掉的
    escape[gone] = n
    alive &= ~gone

escape[alive] = MAX_ITER                     # 沒跑掉的算集合內

plt.figure(figsize=(9, 7))
plt.imshow(escape, extent=(-2.2, 0.8, -1.2, 1.2), cmap="twilight_shifted")
plt.axis("off")
plt.show()

2. 逐行說明

程式片段在做什麼
建立 C把每個像素對應到平面上的一個複數 \( c \)
Z ** 2 + C整張圖同時做一次迭代
abs(Z) 大於 2判斷是否已經確定跑掉
escape 陣列記錄「第幾步跑掉」，作為顏色
alive 遮罩已跑掉的不再計算，加速運算

3. 可以玩的地方

  • 縮小範圍放大細節：把 re 與 im 改成邊界附近的一小塊，例如 \( -0.75 \) 附近
  • 增加迭代次數：放大之後 200 次不夠，改成 1000 會看到更多結構
  • 改變公式：把 Z ** 2 改成 Z ** 3， 會得到形狀完全不同的碎形
  • 固定 C，改變起點：那會得到另一族圖形（朱利亞集合）

放大邊界時，你會不斷看到與整體相似的小副本。 無論放大多少倍，結構都不會用完。

4. 這個練習的意義

整段程式的數學內容只有一行：Z = Z ** 2 + C。 一個平方、一個加法。

這是複數結構豐富性最直接的證據。

同樣的公式在實數線上做，得到的只是一段乏味的區間。 複雜度來自多出來的那個維度，以及乘法會旋轉—— 也就是本課程從模組 C 開始一直在講的那件事。

模組 L 重點回顧

  • Python 內建複數，可直接驗證模與輻角的運算法則
  • 連續乘同一複數畫出螺線，模的大小決定收斂或發散
  • 方波可由旋轉疊加而成，FFT 的輸出是複數
  • 曼德博集合的核心只有一行：平方加常數

檢查你的理解

  1. 執行程式並放大邊界的某個區域
  2. 說明著色代表什麼
  3. 解釋為什麼同樣公式在實數上不會產生碎形
