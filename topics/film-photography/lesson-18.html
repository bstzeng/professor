X 光底片

這一課的目標

  • 了解 X 光攝影的發現
  • 理解 X 光底片與增感屏
  • 了解醫療影像的數位化

妻子的手

1895 年 11 月，德國物理學家倫琴在實驗中發現了一種看不見、能穿透物體的射線，他稱之為 X 射線。幾週後，他拍下了妻子的手掌：骨骼與戒指清楚可見，皮肉則幾乎透明。據說他的妻子看到照片時說：「我看到了自己的死亡。」這張照片震驚了世界，倫琴在 1901 年獲得第一屆諾貝爾物理獎（見〈醫學影像〉）。

照相底片的新用途

X 光本身看不見，必須用照相底片記錄：X 光穿過身體，骨骼吸收較多、軟組織吸收較少，在底片上形成明暗不同的影像。骨骼擋住 X 光，底片上對應的區域曝光少、沖洗後是白色的；所以 X 光片看起來是「白骨黑底」——它其實是一張負片。

增感屏

鹵化銀對 X 光的吸收效率很低，需要很大的劑量才能曝光。解決方法是增感屏：在底片前後放上塗有螢光物質的板子，螢光物質吸收 X 光後發出可見光，再讓底片感光。這大幅降低了病人需要接受的輻射劑量。醫用 X 光底片也常在兩面都塗上乳劑，進一步提高效率。

早期的危險

X 光剛被發現時，人們並不了解它的危險：鞋店用 X 光機讓顧客看腳在鞋子裡的樣子，許多早期的研究者與醫師因為長期暴露而罹患皮膚潰瘍與癌症。後來才逐步建立了輻射防護的觀念與規範（見〈核物理〉）。

數位化

1980 年代起，醫院逐步改用電腦放射攝影（用可重複使用的影像板）與數位放射攝影（直接用電子感測器），影像存在醫院的影像儲傳系統（PACS）中，醫師在螢幕上看片。過去醫院裡堆積如山的 X 光片袋、病人自己抱著大片子轉診的景象，已經很少見了。數位化也讓 AI 能協助判讀影像。

🧭 這一課的重點

1895 年 11 月倫琴發現看不見能穿透物體的 X 射線，幾週後拍妻子手掌骨骼戒指清楚皮肉幾乎透明，據說妻子說我看到了自己的死亡，1901 年獲首屆諾貝爾物理獎；X 光需用照相底片記錄，骨骼吸收多對應區曝光少沖洗後白色，白骨黑底其實是負片；鹵化銀吸收 X 光效率低，增感屏塗螢光物質吸收 X 光發可見光使底片感光大幅降低劑量，醫用底片兩面塗乳劑；早期不了解危險，鞋店用 X 光機看腳，研究者醫師長期暴露罹皮膚潰瘍癌症，後建立輻射防護；1980 年代起改用電腦放射攝影影像板與數位放射攝影電子感測器，存入 PACS 螢幕看片，堆積的片袋與病人抱大片子轉診少見，數位化讓 AI 協助判讀。
