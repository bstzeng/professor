模組 B｜第一類：對話式AI工作台 · 第 5 課

ChatGPT／Claude／Gemini：三家通用助理的定位差異

這一課的目標

  • 了解三家主流助理各自的生態定位與整合優勢
  • 知道模型能力排名為什麼不該是唯一的選擇依據
  • 建立「以工作流為單位」而不是「以模型為單位」的選擇習慣

第一類AI工作流，是你每天都在用的那個：對話視窗。它常被 當成「還不算工作流」的入門玩具，但事實上，加上專案、記憶、 檔案與連接器之後，它已經是很多人手上唯一真正在運作的 AI流程。這個模組把它當成一個正式的類別來看。

1. 三家的定位差異

產品生態上的位置特別適合的場景
ChatGPT使用者最多、外掛與GPTs生態最廣、通用性強什麼都要一點的日常助手、自訂小工具分享
Claude長文件處理與寫作／程式碼見長，Artifacts 與 MCP 生態長文分析、寫作、程式相關工作、可連接內部工具
Gemini與 Google Workspace（Gmail、Docs、Drive）深度整合本來就重度使用 Google 生態的個人與團隊

這張表刻意不比「誰比較聰明」。旗艦模型的能力差距在多數 日常任務上已經小到難以察覺，而且每隔幾個月就互相超車一次； 真正穩定影響你工作效率的，是它能不能碰到你的資料、 能不能塞進你既有的流程。

2. 為什麼「哪家最聰明」不是好問題

排行榜上的分數多半來自標準化測驗，跟你的真實任務相關性 有限。更務實的評估方式是：拿你自己最常做的五個任務，各準備 三個真實例子，在候選工具上各跑一次，看哪一個的輸出你要改 得最少。這套做法在模組 M 會被正式化成「評測集」——你會發現， 個人選工具跟企業選模型，方法其實是同一套，只是規模不同。

3. 訂閱制、API 與兩者的差別

同一家公司通常有兩種賣法：訂閱制的對話產品 （月費、有使用量上限、附帶介面與功能）與 API （按 token 計費、沒有介面、給程式呼叫）。這門課後面談到的 自動化平台與程式框架，用的幾乎都是 API 這一側。搞混這兩者 是新手最常見的成本誤判——訂閱制的「無限用」不等於你可以 拿同一個帳號去跑自動化流程。

時效性提醒

這一課提到的產品定位每隔幾個月就會變動一次：功能會互相 抄襲、價格會調整、模型會換代。請把它讀成「這三家目前的 生態差異大致長這樣」，而不是永久成立的結論。判讀方法 （看整合、看資料可及性、用自己的任務測）才是要記住的部分。

檢查你的理解

  1. 說明為什麼「整合能力」通常比「模型分數」更影響實際效率
  2. 描述用自己的真實任務評估工具的具體做法
  3. 解釋訂閱制產品與API計費的差別，以及混淆會造成什麼後果
