六個情境拆解：從需求到完整工作流

這一課的目標

  • 看到完整的工作流設計如何組合工具、模式與治理
  • 從六個情境中找出跟自己最接近的一個
  • 學會用同一套結構描述任何工作流

這一課把整門課的東西用六個情境串起來。每個情境都用同一 套結構描述：觸發 → 流程與模式 → 人工介入 → 量測指標。

1. 客服信件分流與草稿

觸發：新信件進入客服信箱。流程：規則過濾廣告 → Routing 分成退貨／技術／客訴／其他 → 依類別檢索知識庫（RAG）產生草稿 → 程式檢查（有無引用、是否承諾金額）。人工介入：客訴類 與涉及金額的一律人工；其他類人工按送出。 指標：草稿採用率、平均回覆時間、轉人工率。

2. 行銷內容產線

觸發：每週企劃會後建立主題清單。流程： Orchestrator 依主題產出多個角度 → 平行產生草稿與配圖候選 → Evaluator 檢查品牌用語與事實標記。人工介入：選角度、最終定稿。 指標：每篇產出時間、退稿率、發布後成效。

3. 研發：從 issue 到 PR

觸發：issue 被貼上特定標籤。流程：編碼代理讀取程式碼庫 → 實作 → 跑測試（Agent 迴圈）→ 開 PR。 人工介入：PR 審查與合併。指標：一次通過率、審查耗時、 回退率。

4. 財務：發票與費用審核

觸發：新發票上傳。流程：OCR 擷取欄位 → 結構化輸出 → 程式驗證（金額加總、統編格式、重複偵測） → 比對採購紀錄。人工介入：金額超過門檻、驗證失敗、 找不到對應採購單。指標：自動通過率、錯誤攔截率、 每張處理成本。

5. 招募：履歷初篩

觸發：新履歷投遞。流程：擷取結構化資訊 → 對照職缺 必要條件（程式判斷，不是模型判斷）→ 產生摘要與提問建議。人工介入：所有淘汰決定都由 人做。指標：篩選一致性、面試轉換率。

這個情境的特別提醒

招募涉及就業機會，屬於高風險應用：許多地區對自動化決策 有明確的告知、解釋與人工複核要求，也需要注意偏誤。 正確做法是讓AI整理資訊、不做淘汰決定， 並保留完整紀錄。

6. 個人知識管理

觸發：稍後閱讀清單或筆記庫更新。流程：抓取內容 → 摘要與標籤 → 找出與既有筆記的關聯 → 每週彙整一份回顧。 人工介入：決定收藏什麼、寫下自己的判斷。 指標：一週後你還記得幾條、回顧時實際用到幾條。

檢查你的理解

  1. 挑出跟你最接近的情境，用同一套結構描述你的版本
  2. 說明為什麼招募情境的淘汰決定必須由人做
  3. 找出六個情境中共同出現的兩個設計模式
