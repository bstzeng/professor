模組 B｜從文字到向量 · 第 7 課

Embedding

這一課的目標

  • 理解 embedding 的作用
  • 知道 embedding 矩陣的大小
  • 認識輸出端的 unembedding

Token ID 只是一個編號，本身沒有意義。模型的第一步是查表：用 ID 去 embedding 矩陣中取出對應的一列，得到一個長度為 d 的向量（d 稱為隱藏維度，例如 Llama 3 8B 是 4096）。

項目Llama 3 8B 的數字
詞彙表大小128,256
隱藏維度 d4,096
Embedding 矩陣128,256 × 4,096 ≈ 5.25 億個參數
每個 token 的向量4,096 個數字

訓練之後，意義相近的 token 在這個高維空間中會靠得比較近。接下來的每一層 Transformer，都是在一步一步地改寫這些向量，把上下文的資訊加進去。

模型的最後一步則相反：把最後一層的向量乘上一個「unembedding」（輸出投影）矩陣，得到詞彙表中每個 token 的分數（logits），再由此抽出下一個 token（第 25 課）。這一步在 decode 時每個 token 都要做一次，詞彙表越大，這一步越花時間。

🧭 這一課的重點

Embedding 以 token ID 查表取得 d 維向量（Llama 3 8B 為 4096 維），各層逐步改寫向量；最後由 unembedding 投影成詞彙表大小的 logits。

⚡ 文中的硬體規格取自廠商公開資料（稠密運算、未計稀疏加速），速度與記憶體計算都是理論估算，實際數字會因軟體實作、批次與排程而不同。
