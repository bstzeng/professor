互連

這一課的目標

  • 認識 GPU 之間的互連
  • 理解頻寬對平行策略的影響
  • 了解叢集網路的角色

多卡平行的效率取決於卡與卡之間的通訊速度。

互連範圍頻寬（數量級）
PCIe 5.0 x16GPU 與 CPU、一般擴充約 64 GB/s 單向
NVLink（H100）同一台機器內的 GPU900 GB/s（雙向合計）
NVLink（Blackwell）機器內，及 NVL72 機櫃內 72 張卡1.8 TB/s
InfiniBand／RoCE機器之間每張卡 400～800 Gb/s（50～100 GB/s）

可以看到機器內與機器間的頻寬差了一個數量級。這就是為什麼張量平行留在機器內，跨機器時改用通訊量較小的管線平行或資料平行。

NVSwitch 讓同一台機器內的 8 張 GPU 兩兩以全速互連。Blackwell 世代的 NVL72 把 72 張 GPU 以 NVLink 連成一個大型的共享網域，讓超大 MoE 模型的專家平行能在高速網路中進行。AMD 的 Infinity Fabric、Google TPU 的 ICI 也扮演類似的角色。

對推論來說，互連還有一個重要用途：在分離部署中傳送 KV Cache，以及在多台機器之間共享 prefix cache。這些都需要 RDMA（遠端直接記憶體存取），讓資料不經過 CPU 直接在 GPU 記憶體之間搬運。

🧭 這一課的重點

機器內 NVLink 每卡約 900 GB/s，機器間 InfiniBand 每卡約 50～100 GB/s，差一個數量級；因此 TP 留在機器內，跨機用 PP、DP；RDMA 支援 KV Cache 傳輸。

⚡ 文中的硬體規格取自廠商公開資料（稠密運算、未計稀疏加速），速度與記憶體計算都是理論估算，實際數字會因軟體實作、批次與排程而不同。
