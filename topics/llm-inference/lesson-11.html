模組 C｜注意力與 KV Cache · 第 11 課

因果遮罩

這一課的目標

  • 理解因果遮罩的作用
  • 理解它與自回歸生成的關係
  • 比較雙向與單向模型

生成式 LLM 在訓練時被要求「看前面的字，預測下一個字」。為了不讓模型「偷看答案」，注意力被加上了因果遮罩（causal mask）：每個 token 只能注意自己和它前面的 token。

在注意力分數矩陣中，這等於把右上三角的部分設為負無限大，softmax 之後權重為 0（上一課的互動中灰色的格子）。

因果遮罩帶來一個對推論極為重要的性質：前面 token 的計算結果，不會因為後面加了新的 token 而改變。第 5 個 token 的 K 和 V，無論後面接了什麼，都是一樣的。

這就是 KV Cache 能夠成立的前提——算過的 K、V 可以存起來重複使用（下一課）。

雙向（例如 BERT）單向／因果（例如 GPT、Llama）
每個 token 看得到前後所有 token只有前面的 token
擅長理解、分類、搜尋向量生成文字
能否快取加一個字，所有 token 都要重算前面的結果可以快取

🧭 這一課的重點

因果遮罩讓每個 token 只能注意前面的 token；因此前面 token 的 K、V 不會因後面新增 token 而改變，這是 KV Cache 成立的前提。

⚡ 文中的硬體規格取自廠商公開資料（稠密運算、未計稀疏加速），速度與記憶體計算都是理論估算，實際數字會因軟體實作、批次與排程而不同。
