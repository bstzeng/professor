GPU 的結構

這一課的目標

  • 認識 GPU 的基本組成
  • 理解 Tensor Core 的角色
  • 理解為什麼 GPU 適合矩陣運算

GPU 是為大量平行計算設計的處理器。以 NVIDIA H100 SXM 為例：

元件數量作用
SM（串流多處理器）132 個GPU 的基本運算單位，每個有自己的排程器、暫存器與共享記憶體
CUDA Core每 SM 128 個一般的浮點與整數運算
Tensor Core每 SM 4 個專門做小矩陣乘加，提供絕大部分的 AI 算力
HBM380 GB主記憶體，堆疊在晶片旁
L2 快取50 MB所有 SM 共用

Tensor Core 是 AI 推論的主角：它在一個時脈內完成一個小矩陣塊的乘加（例如 BF16 的 16×16 區塊），速度比 CUDA Core 快一個數量級以上。989 TFLOPS 的 BF16 算力幾乎全部來自 Tensor Core。

程式透過 kernel 在 GPU 上執行：一個 kernel 被分成成千上萬個執行緒區塊，分配到各個 SM 上。推論引擎的效能很大一部分取決於 kernel 寫得好不好——FlashAttention、各種量化 GEMM、融合（fusion）多個運算以減少記憶體讀寫，都是 kernel 層級的最佳化。

另一個常見的瓶頸是 kernel 啟動開銷：decode 每一步要啟動數百個小 kernel，每個都有幾微秒的開銷。CUDA Graphs 把整個 decode 步驟錄製起來一次重播，可以明顯降低小 batch 時的延遲。

🧭 這一課的重點

GPU 由上百個 SM 組成，Tensor Core 提供幾乎全部 AI 算力；程式以 kernel 執行，kernel 品質與融合決定效能；CUDA Graphs 降低 decode 的 kernel 啟動開銷。

⚡ 文中的硬體規格取自廠商公開資料（稠密運算、未計稀疏加速），速度與記憶體計算都是理論估算，實際數字會因軟體實作、批次與排程而不同。
