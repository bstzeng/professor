PagedAttention 與 vLLM

這一課的目標

  • 理解 KV Cache 的碎片化問題
  • 理解 PagedAttention 的做法
  • 認識 vLLM

早期系統為每個請求預先配置一塊連續的 KV Cache 空間，大小按最大長度預留。但大多數請求遠遠用不到最大長度，加上不同大小的空間來來去去造成碎片，研究發現六到八成的 KV Cache 記憶體被浪費。

2023 年，UC Berkeley 團隊在 SOSP 發表 PagedAttention，靈感直接來自作業系統的虛擬記憶體：

作業系統PagedAttention
程序請求
虛擬頁面邏輯 KV 區塊（例如每 16 個 token 一塊）
實體頁框GPU 記憶體中的實體區塊
頁表區塊表
寫入時複製多個請求共用相同前綴的區塊
  • 按需配置：每生成 16 個 token 才配置一個新區塊，浪費最多只有最後一塊
  • 不需連續：區塊可以散落在記憶體任何地方，注意力 kernel 透過區塊表找到它們
  • 可以共用：平行抽樣多個回答、或多個請求有相同的系統提示時，共用的部分只存一份

同一團隊開源的 vLLM 以 PagedAttention 為核心，把記憶體浪費降到 4% 以下，吞吐量比當時的系統高出 2～4 倍，迅速成為最廣泛使用的開源推論引擎之一。SGLang、TensorRT-LLM 等其他框架也都採用了類似的分頁管理。

🧭 這一課的重點

連續預留 KV Cache 造成大量浪費與碎片；PagedAttention 借用虛擬記憶體的分頁概念，按需配置不連續的區塊並允許共用，vLLM 以此大幅提升吞吐量。

⚡ 文中的硬體規格取自廠商公開資料（稠密運算、未計稀疏加速），速度與記憶體計算都是理論估算，實際數字會因軟體實作、批次與排程而不同。
