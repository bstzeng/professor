天鵝座 X-1

這一課的目標

  • 了解 X 光天文學的開始
  • 理解如何從雙星軌道推算質量
  • 了解霍金與索恩的賭注

X 光天文學

地球的大氣擋住了 X 射線，所以 X 光天文學必須上太空。1964 年，一枚探空火箭在天鵝座的方向發現了一個強烈的 X 光源：天鵝座 X-1。1970 年發射的烏呼魯衛星，是第一顆 X 光天文衛星，發現了數百個 X 光源，以及天鵝座 X-1 的快速閃爍——意味著發光的區域非常小。

從伴星推算質量

1971～1972 年，天文學家找到了 X 光源位置上的一顆藍超巨星，它每 5.6 天繞著一個看不見的伴星轉一圈——正是米歇爾在 1783 年提出的方法（第 2 課）。從可見星的速度變化，可以算出質量函數：

\[f(M) = \frac{M_X^3\sin^3i}{(M_X + M_*)^2} = \frac{PK^3}{2\pi G}\]

其中 \(P\) 是週期、\(K\) 是可見星視線速度的振幅、\(i\) 是軌道的傾角。這個式子給出看不見的天體質量的下限。天鵝座 X-1 的不可見天體，質量遠超過中子星的上限。今天的最佳估計約為 21 倍太陽質量。

賭注

1975 年，霍金與索恩打賭：霍金賭天鵝座 X-1 不是黑洞。霍金後來解釋，這是一份「保險」：如果他一生研究的黑洞不存在，至少他贏了賭注。1990 年，證據已經壓倒性，霍金認輸，按照約定送給索恩一年份的雜誌訂閱。

X 光雙星

今天已知銀河系中約二十多個以動力學方法確認的黑洞 X 光雙星，以及更多的候選者。2022 年起，蓋亞衛星的資料還找到了幾個安靜的黑洞——它們的伴星距離夠遠，沒有物質被吸走，所以不發 X 光，只從伴星的運動被找到。

🧭 這一課的重點

X 光天文學須上太空，1964 年火箭發現天鵝座 X-1，1970 年烏呼魯衛星發現它快速閃爍、發光區很小；1971～1972 年找到每 5.6 天繞看不見伴星的藍超巨星，由質量函數 f(M)=PK³/(2πG) 得到質量下限，遠超中子星上限，今估約 21 倍太陽質量；1975 年霍金賭它不是黑洞作為保險，1990 年認輸；銀河系約有二十多個動力學確認的黑洞 X 光雙星，2022 年起蓋亞資料也找到了安靜的黑洞。
