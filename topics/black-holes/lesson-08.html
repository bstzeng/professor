模組 B｜廣義相對論中的黑洞 · 第 8 課

光子球與最內穩定圓軌道

這一課的目標

  • 理解有效位能的方法
  • 推導光子球的位置
  • 理解 ISCO 與吸積盤

有效位能

在史瓦西時空中，一個質點的徑向運動可以寫成類似一維的能量方程式（\(G = c = 1\)，\(L\) 是單位質量的角動量）：

\[\left(\frac{dr}{d\tau}\right)^2 = E^2 - V_{\text{eff}}(r),\qquad V_{\text{eff}} = \left(1 - \frac{2M}{r}\right)\left(1 + \frac{L^2}{r^2}\right)\]

展開後，和牛頓力學相比多了一項 \(-2ML^2/r^3\)：在近處，它壓過了離心位障。

最內穩定圓軌道（ISCO）

令 \(dV_{\text{eff}}/dr = 0\)，圓軌道的半徑滿足 \(Mr^2 - L^2r + 3ML^2 = 0\)。只有判別式 \(L^4 - 12M^2L^2\ge 0\)，也就是 \(L\ge 2\sqrt3M\) 時才有解。臨界的情況：

\[r_{\text{ISCO}} = 6M = 3r_s\]

比這更近，沒有穩定的圓軌道：任何一點擾動，物體就會螺旋掉進黑洞。這決定了吸積盤的內緣，也決定了吸積的能量效率（第 20 課）。

光子球

光沒有質量，有效位能變成 \(V = (1 - 2M/r)L^2/r^2\)。對 \(r\) 微分求極大：

\[\frac{d}{dr}\left[\frac{1}{r^2} - \frac{2M}{r^3}\right] = 0\;\Longrightarrow\; r = 3M = 1.5\,r_s\]

在這個半徑，光可以繞著黑洞轉圈——但這是不穩定的，就像一顆球停在山頂上。理論上，站在光子球上往前看，你會看到自己的後腦勺。

陰影

從遠處射來的光，衝擊參數小於 \(b_c = 3\sqrt3M\approx 5.2M\) 就會被捕獲。所以從遠處看，黑洞會在明亮的背景（例如吸積盤的光）前面，投下一個半徑約 \(5.2M\)、約為視界 2.6 倍大的陰影。事件視界望遠鏡拍到的，就是它（模組 F）。

🧭 這一課的重點

史瓦西時空中質點的徑向運動可寫成 (dr/dτ)²=E²−V_eff，V_eff=(1−2M/r)(1+L²/r²)，比牛頓多一項 −2ML²/r³ 使近處離心位障消失；圓軌道需 L≥2√3M，臨界為 ISCO r=6M=3r_s，更近處沒有穩定圓軌道，決定吸積盤內緣；光的位能極大在 r=3M 的光子球，光可不穩定地繞圈；衝擊參數小於 3√3M 的光被捕獲，黑洞投下約視界 2.6 倍的陰影。
