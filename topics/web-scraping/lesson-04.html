CSS 選擇器完整教學：標籤、class、id、組合選擇器

學習目標

  • 完整掌握CSS選擇器的核心語法：標籤、class、id、屬性選擇器
  • 學會用組合選擇器（後代、直接子代）精準鎖定目標
  • 能在BeautifulSoup的 .select() 方法裡直接套用同一套語法

CSS選擇器是爬蟲最常用的定位語言——不只 DevTools裡用得到，BeautifulSoup的 .select() 方法、Selenium的 find_element(By.CSS_SELECTOR, ...) 用的都是同一套語法，學一次到處通用。 這一課下面有練習區，可以直接打字測試， 邊看邊練。

1. 基本選擇器

  • 標籤選擇器——p 選出所有 <p> 標籤。
  • class選擇器——.price （句點開頭）選出所有 class 包含 price 的元素。
  • id選擇器——#header （井字號開頭）選出 id 為 header 的唯一 元素。
  • 屬性選擇器—— [data-id="102"] 選出 data-id屬性剛好等於102的元素。

3. 組合選擇器：描述節點之間的關係

  • 後代選擇器（空白）—— .sp-product .sp-price 選出所有 .sp-product元素裡面（不論 隔幾層）的 .sp-price。
  • 直接子代選擇器（>）—— .sp-product > h3 只選 .sp-product的直接子節點 裡是 h3 的，不會選到孫節點以下的h3。
  • 多個class同時符合（不加空白）—— .sp-product.sp-featured（中間沒有 空白）選出同一個元素同時擁有這兩個 class的情況——注意這跟「後代選擇器」的空白 差一個字元，意思完全不同，很容易打錯。
  • 逗號並列（or邏輯）—— h2, h3 選出所有h2或h3。

用上面的練習區試試看 .sp-product .sp-product-title （後代）跟 .sp-product.sp-featured （同一元素多class）這兩種寫法，比較選到的 結果有什麼不同。

4. 對應到 BeautifulSoup 的寫法

from bs4 import BeautifulSoup soup = BeautifulSoup(html, "html.parser") # 這一整套CSS選擇器語法，直接丟進 .select() 就能用 products = soup.select(".sp-product") titles = soup.select(".sp-product .sp-product-title") featured = soup.select(".sp-product.sp-featured") one = soup.select_one('[data-id="102"]') # 只拿第一個符合的

這正是這一課值得學紮實的原因：同一套CSS選擇器 語法，DevTools練熟了，直接原封不動搬進 soup.select()就能用，不需要另外 學一套BeautifulSoup專屬的查詢語法。

檢查你的理解

  1. 能寫出標籤、class、id、屬性四種基本選擇器
  2. 能說明後代選擇器（空白）跟直接子代選擇器（>）的差異
  3. 能說明「.a .b」跟「.a.b」這兩種寫法的意思差異
  4. 能說出CSS選擇器怎麼直接套用在BeautifulSoup的.select()裡
