模組 B｜JavaScript 語法基礎：給 Python 工程師的對照式入門 · 第 12 課

條件、迴圈與常用內建方法：對照 Python 慣用寫法

學習目標

  • 掌握JS的if/else語法與布林判斷
  • 認識for、for...of、while三種迴圈，知道分別對照Python的哪種寫法
  • 認識字串常用方法，處理爬蟲常遇到的文字清理需求

模組B最後一堂實質內容課，把條件判斷跟迴圈這兩塊 基本拼圖補上——這部分JS跟Python的邏輯幾乎相同， 主要差異在語法細節。

1. 條件判斷：if / else

if/else 語法，注意條件要用小括號包起來 

      

      

        主要差異：JS的條件要用小括號( )
        包起來，程式區塊用大括號{ }而不是
        縮排；elif在JS裡寫成
        else if（兩個字，中間有空格）。
      


      
2. 三種迴圈寫法

      

        

          for、for...of 的差異，for...of 是最常對照Python for的寫法
          
        

        
        

      

      

        

          寫爬蟲相關的JS程式碼時，for...of
          是最常用、最接近Python for item in list
          直覺的寫法。傳統的for語法在需要
          同時用到索引位置時比較方便；另外還有
          for...in（走訪物件的鍵，跟
          for...of拼字很像但用途不同，
          容易混淆，實務上比較少用，看到時知道它在
          走訪物件鍵值即可）。
        

      


      
3. 字串常用方法：清理爬到的文字

      

        爬蟲抓下來的文字，經常帶有多餘空白、換行、
        貨幣符號，需要清理。這些方法讀懂JS程式碼裡
        怎麼處理文字很有幫助：
      

      

        

          字串清理常用方法
          
        

        
        

      

      

        
    
          
  • .trim()——對照 Python .strip()。
    • 
          
  • .replace(a, b)——對照
            .replace(a, b)，用法幾乎一樣。
    • 
          
  • .includes(x)——對照
            Python的 x in string。
    • 
          
  • .split(sep)——對照
            .split(sep)，用法幾乎一樣。
    • 
          
  • 正規表示式（regex）語法JS跟Python的核心
            規則高度相似，/pattern/flags
            這種寫法是JS特有的「正規表示式字面量」，
            對照Python要先re.compile(pattern)
            才能使用。
    •
