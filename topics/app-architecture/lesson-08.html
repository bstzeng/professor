MVP、MVVM 與資料繫結

這一課的目標

  • 理解 MVVM 與資料繫結
  • 比較 MVC、MVP、MVVM
  • 知道 ViewModel 的可測試性
模式中間層特點
MVCController控制器處理輸入；視圖可直接讀模型
MVPPresenterPresenter 透過介面「命令」被動的視圖
MVVMViewModel視圖透過繫結自動同步，ViewModel 不知道視圖存在
// ViewModel：純資料與命令 class EditorVM { title = observable("未命名"); isDirty = observable(false); save = command(async () => { await doc.save(); this.isDirty.set(false); }); } // View（宣告式）：<Label text={vm.title} /> <Button onClick={vm.save} disabled={!vm.isDirty} />

🧭 這一課的重點

MVVM 透過資料繫結讓視圖自動更新；ViewModel 不依賴視圖，容易測試。

🧰 本課以通用的軟體架構說明概念，程式碼為教學用的簡化片段（以 TypeScript 為主），重點在設計思路而非特定框架的完整寫法。
