自動儲存與當機復原

這一課的目標

  • 學會安全的存檔流程
  • 認識自動儲存的設計
  • 知道當機復原的機制
async function safeSave(path: string, bytes: Uint8Array) { const tmp = path + ".tmp"; await fs.writeFile(tmp, bytes); await fsync(tmp); // 確保真的寫進磁碟，不只停在快取 await fs.rename(tmp, path); // 原子取代 }
  • 自動儲存：定時或閒置時，在背景把文件存到復原資料夾，不覆蓋使用者的檔案。
  • 當機偵測：啟動時放一個「執行中」標記，正常結束時刪除；下次啟動若標記還在，就知道上次當掉了。
  • 版本歷史：有些軟體保留多個自動版本，讓使用者回到過去。

為什麼寫入不一定立刻到磁碟？見 〈作業系統是怎麼寫出來的〉第 37 課 的頁快取。

🧭 這一課的重點

安全存檔＝寫暫存檔、fsync、原子改名；自動儲存與當機標記讓意外不至於丟失工作。
