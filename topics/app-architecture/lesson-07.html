MVC：模型、視圖、控制器

這一課的目標

  • 理解 MVC 的三個角色
  • 知道 MVC 解決的問題
  • 認識 MVC 的變形
class CounterModel { // Model：資料與規則 count = 0; listeners: (() => void)[] = []; increment() { this.count++; this.listeners.forEach(f => f()); } } class CounterView { // View：只負責顯示 render(m: CounterModel) { label.text = `次數：${m.count}`; } } button.onClick = () => model.increment(); // Controller：把操作轉成模型呼叫

MVC 最大的價值：同一份資料可以有多個畫面，而且資料規則不會散落在按鈕事件裡。實務上很多框架把 View 和 Controller 合併，例如 iOS 的 ViewController。

🧭 這一課的重點

MVC 把資料（Model）、顯示（View）、操作（Controller）分開，讓同一份資料能驅動多個畫面。

🧰 本課以通用的軟體架構說明概念，程式碼為教學用的簡化片段（以 TypeScript 為主），重點在設計思路而非特定框架的完整寫法。
