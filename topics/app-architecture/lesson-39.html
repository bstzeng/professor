拆解一個繪圖軟體

這一課的目標

  • 理解圖層合成
  • 認識非破壞性編輯
  • 知道大型影像的記憶體管理
  • 圖塊（Tile）：大圖切成小塊，只載入、只重算需要的塊；記憶體不夠時換到暫存磁碟。
  • 非破壞性：調整圖層、智慧型物件、遮色片都只存參數，原始像素保留。
  • 歷史紀錄：像素操作的復原成本高，常只保存被修改的圖塊（第 14 課）。
  • GPU 加速：濾鏡與合成交給 GPU，介面保持流暢。
  • 外掛濾鏡：透過外掛 API 接收像素資料（第 20 課）。

🧭 這一課的重點

繪圖軟體用圖塊管理大影像、用非破壞性圖層保留可編輯性，並把重運算交給 GPU 與背景執行緒。

🧰 本課以通用的軟體架構說明概念，程式碼為教學用的簡化片段（以 TypeScript 為主），重點在設計思路而非特定框架的完整寫法。

  2. 為什麼要把影像切成圖塊？
  3. 繪圖軟體的復原為什麼特別耗記憶體？
