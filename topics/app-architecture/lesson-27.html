網路層

這一課的目標

  • 理解網路層的責任
  • 認識重試與指數退避
  • 知道錯誤如何呈現給使用者
async function request<T>(path: string, tries = 3): Promise<T> { for (let i = 0; i < tries; i++) { try { const res = await fetch(BASE + path, { signal: AbortSignal.timeout(10_000), headers: auth() }); if (res.status >= 500) throw new RetryableError(); if (!res.ok) throw new ApiError(res.status); return await res.json(); } catch (e) { if (!(e instanceof RetryableError) || i === tries - 1) throw e; await sleep(2 ** i * 500 + Math.random() * 200); // 指數退避＋隨機抖動 } } throw new Error("unreachable"); }
  • 逾時：每個請求都要有上限，不能無限等。
  • 只重試安全的錯誤：伺服器錯誤可以重試；「餘額不足」重試也沒用。
  • 冪等：送錢、下單這類操作要帶唯一請求 ID，重試時伺服器才不會重複執行。

網路通訊本身的原理見 〈網路〉。

🧭 這一課的重點

網路層集中處理憑證、逾時、重試與錯誤轉換，讓上層看到有意義的結果。

🧰 本課以通用的軟體架構說明概念，程式碼為教學用的簡化片段（以 TypeScript 為主），重點在設計思路而非特定框架的完整寫法。
