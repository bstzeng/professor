指令系統與快捷鍵

這一課的目標

  • 理解指令登錄表
  • 認識快捷鍵對應
  • 知道「可用條件」
registry.register({ id: "editor.toggleBold", title: "切換粗體", when: ctx => ctx.editorFocused && !ctx.readOnly, // 可用條件 run: ctx => ctx.editor.toggleMark("bold"), }); keymap.bind("Ctrl+B", "editor.toggleBold");

把所有功能變成有 ID 的指令後，選單、工具列、快捷鍵、命令面板、巨集、外掛都只是「呼叫指令」的不同入口。這也讓「最近使用的指令」「鍵盤快捷鍵自訂」幾乎不用額外工作。

🧭 這一課的重點

把每個功能登錄成具名指令，各種入口共用同一套實作，快捷鍵只是對應表。

🧰 本課以通用的軟體架構說明概念，程式碼為教學用的簡化片段（以 TypeScript 為主），重點在設計思路而非特定框架的完整寫法。

檢查你的理解

  1. 指令登錄表的好處是什麼？
  2. 「可用條件」用來做什麼？
  3. 快捷鍵自訂在這個架構下怎麼實現？
