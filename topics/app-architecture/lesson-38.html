語言伺服器協定（LSP）

自動完成、跳到定義、錯誤提示這些「懂程式語言」的功能，由獨立的語言伺服器提供，編輯器透過標準協定與它溝通。這樣一個 Python 語言伺服器就能同時服務 VS Code、Vim、Emacs 等多種編輯器。

編輯器 → 語言伺服器： { "method": "textDocument/completion", "params": { "position": { "line": 12, "character": 8 } } } 語言伺服器 → 編輯器： { "result": [ { "label": "print" }, { "label": "property" } ] }

🧭 這一課的重點

文字編輯器＝高效緩衝區＋命令＋虛擬化畫面＋外掛＋語言伺服器。
