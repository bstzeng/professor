模組 D｜擴充與設定 · 第 23 課

主題與外觀

這一課的目標

  • 理解設計代幣（Design Token）
  • 知道主題如何切換
  • 認識高對比與無障礙主題
// 元件只使用語意化的名稱，不寫死顏色 const light = { "bg": "#ffffff", "text": "#1f2328", "accent": "#0969da", "danger": "#cf222e" }; const dark = { "bg": "#0d1117", "text": "#e6edf3", "accent": "#4493f8", "danger": "#f85149" }; button.style.background = theme["accent"]; // 換主題時只換對應表

這種語意化的顏色、間距、字體大小叫做設計代幣。設計師在工具裡維護代幣，程式和設計稿共用同一份。

  • 跟隨系統：監聽作業系統的深色模式切換事件。
  • 高對比主題：同一套代幣換一組對比更高的值。
  • 外掛主題：主題本身也可以是外掛（只提供代幣值）。

🧭 這一課的重點

主題靠語意化的設計代幣實現：元件只說「強調色」，主題決定強調色是什麼。

🧰 本課以通用的軟體架構說明概念，程式碼為教學用的簡化片段（以 TypeScript 為主），重點在設計思路而非特定框架的完整寫法。

  2. 為什麼元件不應該寫死顏色？
