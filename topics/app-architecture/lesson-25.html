本機資料庫

這一課的目標

  • 理解應用程式為什麼需要資料庫
  • 認識 SQLite
  • 知道索引與資料庫遷移

相簿、郵件、聊天記錄、瀏覽器歷史——需要搜尋、排序、部分更新的資料，用一個大 JSON 檔很快就撐不住。SQLite 是一個嵌入式資料庫，整個資料庫就是一個檔案，幾乎每支手機、每個瀏覽器裡都有。

CREATE TABLE message ( id INTEGER PRIMARY KEY, chat_id INTEGER NOT NULL, sent_at INTEGER NOT NULL, body TEXT ); CREATE INDEX idx_chat_time ON message(chat_id, sent_at); -- 依對話與時間快速查詢 SELECT body FROM message WHERE chat_id = ? ORDER BY sent_at DESC LIMIT 50;
  • 索引：像書的目錄，讓查詢不必掃描整張表。
  • 交易：一組修改要嘛全部成功、要嘛全部不做，不會只寫一半。
  • 遷移：新版本需要新欄位時，用編號的遷移腳本逐步升級資料庫結構。

🧭 這一課的重點

需要查詢與部分更新的本機資料，用 SQLite 這類嵌入式資料庫；記得索引、交易與遷移。

🧰 本課以通用的軟體架構說明概念，程式碼為教學用的簡化片段（以 TypeScript 為主），重點在設計思路而非特定框架的完整寫法。
