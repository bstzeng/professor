文件模型

這一課的目標

  • 理解文件模型的角色
  • 區分模型與排版結果
  • 認識結構化文件

使用者看到的是排好版的頁面，程式裡存的卻是一棵結構樹：章節、段落、表格、帶樣式的文字片段（Run）。排版（換行、分頁）是根據模型和視窗寬度計算出來的結果。

interface Run { text: string; bold?: boolean; italic?: boolean; } interface Paragraph { style: string; runs: Run[]; } interface Document { paragraphs: Paragraph[]; styles: Record<string, Style>; }

所有編輯操作都是對這棵樹的修改，這讓復原、協同編輯、存檔都有了共同的基礎。

🧭 這一課的重點

文件模型是軟體的核心資料結構；畫面上的排版是由模型計算出來的，不是模型本身。

🧰 本課以通用的軟體架構說明概念，程式碼為教學用的簡化片段（以 TypeScript 為主），重點在設計思路而非特定框架的完整寫法。
