單向資料流

這一課的目標

  • 理解單向資料流
  • 認識 Redux／Elm 架構
  • 知道它的優缺點
type Action = { type: "add"; text: string } | { type: "toggle"; id: number }; function reducer(state: Todo[], a: Action): Todo[] { // 純函式：舊狀態＋動作 → 新狀態 switch (a.type) { case "add": return [...state, { id: Date.now(), text: a.text, done: false }]; case "toggle": return state.map(t => t.id === a.id ? { ...t, done: !t.done } : t); } }
  • 優點：狀態變化可追蹤、可重播；除錯工具能「時光倒流」。
  • 優點：天然支援復原（保存舊狀態即可，見 第 14 課）。
  • 缺點：簡單功能也要寫動作與更新函式，樣板程式碼較多。

🧭 這一課的重點

單向資料流讓狀態只能透過動作改變，畫面是狀態的函數；可預測、可重播。

🧰 本課以通用的軟體架構說明概念，程式碼為教學用的簡化片段（以 TypeScript 為主），重點在設計思路而非特定框架的完整寫法。
