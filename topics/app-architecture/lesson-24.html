腳本與巨集

這一課的目標

  • 認識腳本與巨集的用途
  • 理解物件模型 API
  • 知道巨集的安全風險

Excel 的 VBA、Photoshop 的動作與腳本、Office 的 JavaScript 增益集，都讓使用者自動化重複工作。架構上需要提供一套物件模型 API，讓腳本能以程式方式操作文件。

// 腳本：把所有圖層名稱加上前綴（概念 API） for (const layer of app.activeDocument.layers) { layer.name = "v2_" + layer.name; }
  • 錄製巨集：使用者操作時記錄指令序列（命令模式再次出現，第 14 課），再轉成腳本。
  • 安全：文件內嵌的巨集是常見的惡意程式管道，預設應停用並提示使用者。
  • 沙盒：腳本只能透過 API 操作文件，不能任意存取檔案系統。

🧭 這一課的重點

腳本與巨集透過物件模型 API 操作文件；要預設停用文件內嵌巨集並限制權限。

🧰 本課以通用的軟體架構說明概念，程式碼為教學用的簡化片段（以 TypeScript 為主），重點在設計思路而非特定框架的完整寫法。
