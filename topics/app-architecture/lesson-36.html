當機回報與記錄檔

這一課的目標

  • 理解當機回報的流程
  • 認識符號檔
  • 學會設計有用的記錄檔
log.info("doc.open", { sizeKB: 1830, format: "docx", ms: 412 }); log.warn("font.missing", { family: "思源黑體" }); log.error("save.failed", { code: "EACCES" }); // 不記錄檔案內容與完整路徑
  • 分級：除錯、資訊、警告、錯誤；發行版通常只記錄資訊以上。
  • 結構化：用鍵值而不是自由文字，方便搜尋與統計。
  • 輪替：限制檔案大小與數量，避免塞滿硬碟。
  • 隱私：不記錄使用者內容與敏感資料（第 30 課）。

🧭 這一課的重點

當機回報＋符號檔讓開發者看到真實的錯誤位置；結構化、分級的記錄檔幫助診斷。

🧰 本課以通用的軟體架構說明概念，程式碼為教學用的簡化片段（以 TypeScript 為主），重點在設計思路而非特定框架的完整寫法。
