外掛系統

這一課的目標

  • 理解外掛架構
  • 認識擴充點與外掛 API
  • 知道外掛的隔離與版本相容
// 外掛的進入點（VS Code 風格） export function activate(ctx: ExtensionContext) { ctx.subscriptions.push( commands.registerCommand("myExt.wordCount", () => { const text = window.activeTextEditor?.document.getText() ?? ""; window.showInformationMessage(`字數：${text.length}`); }) ); }
  • 擴充點：主程式事先設計好「哪裡可以加東西」。
  • 延遲啟用：外掛宣告觸發條件（開啟某種檔案時才載入），避免拖慢啟動。
  • 隔離：放到獨立行程或沙盒，外掛當掉或卡住不影響主程式。
  • API 版本：外掛宣告需要的 API 版本，主程式保持向下相容。

🧭 這一課的重點

外掛系統＝穩定的 API＋擴充點＋隔離；設計得好，社群就能替你擴充軟體。

🧰 本課以通用的軟體架構說明概念，程式碼為教學用的簡化片段（以 TypeScript 為主），重點在設計思路而非特定框架的完整寫法。
