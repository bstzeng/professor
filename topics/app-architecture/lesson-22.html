設定檔

這一課的目標

  • 理解設定的分層
  • 認識設定的儲存與驗證
  • 知道設定變更的通知
const config = new LayeredConfig([workspace, user, defaults]); config.get("editor.tabSize"); // 由上往下找 config.onDidChange("editor.tabSize", v => editor.setTabSize(v)); // 即時套用
  • 結構描述（Schema）：定義每個設定的型別、預設值與說明，用來產生設定畫面與驗證。
  • 儲存位置：使用者設定放在作業系統規定的位置（例如應用程式支援資料夾），不要寫進安裝目錄。
  • 遷移：設定名稱改了，要把舊設定自動轉換。

🧭 這一課的重點

設定由預設、使用者、專案層層覆蓋；用結構描述驗證並自動產生設定畫面。

🧰 本課以通用的軟體架構說明概念，程式碼為教學用的簡化片段（以 TypeScript 為主），重點在設計思路而非特定框架的完整寫法。
