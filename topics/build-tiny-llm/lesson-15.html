Token embedding 與位置 embedding

這一課的目標

  • 理解 embedding 查表
  • 理解為什麼需要位置資訊
  • 看懂模型開頭的程式

nn.Embedding(V, d) 是一張 V 列、d 行的表。token id 是 2214，就取出第 2214 列——一個 d 維向量。這些數字一開始是隨機的，訓練時跟著其他參數一起學。

注意力本身不知道順序，所以再加一張位置 embedding 表：第 0 個位置一個向量、第 1 個位置一個向量……把兩者相加，就是送進 Transformer 的輸入。

def forward(self, idx, targets=None, caches=None, start=0): B, T = idx.shape x = self.tok_emb(idx) if self.pos_emb is not None: x = x + self.pos_emb(torch.arange(start, start + T, device=idx.device)) x = self.drop(x)

這是 GPT-2 的做法（學出來的絕對位置）。缺點是只能處理訓練時看過的長度（我們是 80）。第 35 課會換成現代 LLM 用的 RoPE。

🧭 這一課的重點

Token embedding 是一張 V×d 的表，用 token id 查出向量；位置 embedding 另一張表提供順序資訊，兩者相加後送進 Transformer。GPT-2 用學出來的絕對位置。

🛠️ 本課程的 Python 範例都在一台 4 核心 CPU、沒有 GPU 的電腦上實際執行過，頁面上的「執行結果」就是當時的輸出；你的數字會因硬體、PyTorch 版本與隨機性而略有不同。語料來自開源的 chinese-poetry 專案（MIT 授權）。
