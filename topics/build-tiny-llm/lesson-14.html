為什麼 bigram 不夠

這一課的目標

  • 理解 n-gram 的限制
  • 知道為什麼不能直接加大 n
  • 理解神經網路語言模型的優勢

直覺的改進是看前兩個字（trigram）、前三個字……統稱 n-gram。但表格大小是 \(V^n\)：

模型看前面幾個字表格格數（V＝6,758）
bigram1約 4,600 萬
trigram2約 3,100 億
4-gram3約 2 京

而且大多數格子在資料裡從沒出現過（bigram 就只有 0.87% 的格子出現過），根本估計不出機率。

神經網路的解法

  • 共享知識：「春風」和「秋風」的 embedding 相近，學到一個，另一個也受益。表格做不到這一點。
  • 參數不隨 n 爆炸：Transformer 看 80 個字還是 1000 個字，參數量幾乎一樣（只多了位置 embedding）。
  • 注意力：直接決定要看前文的哪幾個字，而不是死記每一種組合。

接下來的模組，我們就一步一步把 bigram 升級成 Transformer。

🧭 這一課的重點

n-gram 的表格大小是 V^n，看前 3 個字就要 2 京格，而且大多數組合從沒出現過。神經網路透過 embedding 共享知識、參數不隨上下文長度爆炸，並用注意力選擇要看哪些字。

🛠️ 本課程的 Python 範例都在一台 4 核心 CPU、沒有 GPU 的電腦上實際執行過，頁面上的「執行結果」就是當時的輸出；你的數字會因硬體、PyTorch 版本與隨機性而略有不同。語料來自開源的 chinese-poetry 專案（MIT 授權）。

  2. 「春風」和「秋風」的例子說明神經網路的什麼優勢？
  3. Transformer 看更長的上下文，參數會暴增嗎？
