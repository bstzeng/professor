單頭 self-attention

這一課的目標

  • 一步步算出注意力
  • 理解 Q、K、V 的計算
  • 看懂分數、softmax、加權平均

每個 token 的向量 x 乘上三個矩陣，得到 Query、Key、Value。用 Q 和所有 K 做內積得到分數，除以 √d，softmax 變成權重，再用權重加總 V。

🐍 s07_attention.py　下載　執行：python s07_attention.py

# -*- coding: utf-8 -*- """第 16～18 課：單頭自注意力，一步一步算。""" import torch import torch.nn.functional as F torch.manual_seed(0) B, T, C, hd = 1, 4, 8, 4 # 1 段文字、4 個 token、每個 8 維；注意力頭 4 維 x = torch.randn(B, T, C) Wq, Wk, Wv = (torch.randn(C, hd) * 0.4 for _ in range(3)) q, k, v = x @ Wq, x @ Wk, x @ Wv # (1, 4, 4) scores = q @ k.transpose(-2, -1) / hd ** 0.5 # (1, 4, 4)：每個 token 對每個 token 的分數 print("分數（未遮罩）：\n", scores[0].round(decimals=2)) mask = torch.tril(torch.ones(T, T)).bool() scores = scores.masked_fill(~mask, float("-inf")) print("\n因果遮罩後：\n", scores[0].round(decimals=2)) w = F.softmax(scores, dim=-1) print("\nsoftmax 權重（每一列加起來 ＝ 1）：\n", w[0].round(decimals=2)) out = w @ v print("\n輸出形狀：", tuple(out.shape), " 第 1 個 token 的輸出 ＝ 它自己的 v：", torch.allclose(out[0, 0], v[0, 0])) # 多頭：把 C 維切成 H 個頭，各自做注意力 H = 2 qh = q.repeat(1, 1, H).view(B, T, H, hd).transpose(1, 2) # (B, H, T, hd) print("\n多頭的形狀 (B, H, T, hd)：", tuple(qh.shape))

▶ 執行結果（實際執行的輸出）

分數（未遮罩）： tensor([[ 0.9800, 0.3600, -0.6200, 0.8500], [-1.5600, -0.1600, -1.0400, 0.3300], [-0.2400, -0.4500, 0.1600, -0.5900], [-1.8400, -0.1800, -1.7400, 0.5800]]) 因果遮罩後： tensor([[ 0.9800, -inf, -inf, -inf], [-1.5600, -0.1600, -inf, -inf], [-0.2400, -0.4500, 0.1600, -inf], [-1.8400, -0.1800, -1.7400, 0.5800]]) softmax 權重（每一列加起來 ＝ 1）： tensor([[1.0000, 0.0000, 0.0000, 0.0000], [0.2000, 0.8000, 0.0000, 0.0000], [0.3000, 0.2500, 0.4500, 0.0000], [0.0500, 0.2800, 0.0600, 0.6100]]) 輸出形狀： (1, 4, 4) 第 1 個 token 的輸出 ＝ 它自己的 v： True 多頭的形狀 (B, H, T, hd)： (1, 2, 4, 4)

整個注意力只有三個矩陣乘法和一個 softmax，全部可以平行計算——這就是 Transformer 在 GPU 上這麼快的原因。

🧭 這一課的重點

單頭注意力把 x 乘上 W_Q、W_K、W_V 得到 Q、K、V，計算 QKᵀ/√d 的分數、softmax 成權重，再加權平均 V。全部是矩陣運算，可以平行計算。

🛠️ 本課程的 Python 範例都在一台 4 核心 CPU、沒有 GPU 的電腦上實際執行過，頁面上的「執行結果」就是當時的輸出；你的數字會因硬體、PyTorch 版本與隨機性而略有不同。語料來自開源的 chinese-poetry 專案（MIT 授權）。
