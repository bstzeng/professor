混合精度與梯度累積

這一課的目標

  • 理解混合精度訓練
  • 理解梯度累積
  • 知道這兩招什麼時候用

混合精度

矩陣乘法用 16 位元（bfloat16）算，速度可以快 2 倍以上、記憶體減半；但權重和優化器狀態仍保留 32 位元，以免累積誤差。PyTorch 用 torch.autocast 自動處理：

amp = torch.autocast(device_type=device if device != "mps" else "cpu", dtype=torch.bfloat16, enabled=args.amp)

在 GPU 上加 --amp 就會啟用。bfloat16 的數值範圍和 FP32 一樣大，不像 FP16 需要額外做損失縮放（見〈LLM 模型全解〉第 50 課）。在 CPU 上效果有限，我們的實測沒有使用。

梯度累積

for _ in range(args.accum): # 梯度累積 x, y = get_batch("train") with amp: _, loss = model(x, y) (loss / args.accum).backward()

記憶體只夠放 8 段文字，但想要 32 段的效果？設定 --batch 8 --accum 4：連續算 4 次梯度（每次除以 4）累加起來，再更新一次參數，數學上等同一次 32 段的 batch。代價是一步要花 4 倍時間。

🧭 這一課的重點

混合精度用 bfloat16 做矩陣運算、FP32 保存權重，GPU 上更快更省記憶體。梯度累積把多個小 batch 的梯度加起來再更新，等同大 batch，用時間換記憶體。

🛠️ 本課程的 Python 範例都在一台 4 核心 CPU、沒有 GPU 的電腦上實際執行過，頁面上的「執行結果」就是當時的輸出；你的數字會因硬體、PyTorch 版本與隨機性而略有不同。語料來自開源的 chinese-poetry 專案（MIT 授權）。

  2. --batch 8 --accum 4 等效於多大的 batch？
  3. 梯度累積的代價是什麼？
