從你的小 GPT 到 GPT-4：差了什麼

這一課的目標

  • 比較本課程模型與大型 LLM
  • 知道還沒做的步驟
  • 規劃接下來的學習
本課程大型 LLM（約略）
參數300 萬數十億到數兆
訓練資料162 萬字數兆到數十兆 token
訓練算力一台 CPU、約 20 分鐘上萬張 GPU、數週到數月
Tokenizer字元級BPE，10 萬以上
上下文80數萬到百萬
對齊LoRA 指令微調SFT ＋ RLHF／DPO ＋ 安全訓練
推論KV cache量化、批次、推測解碼、分散式部署

但核心的程式碼和原理是一樣的：tokenizer、embedding、注意力、殘差、預測下一個 token、交叉熵、AdamW、抽樣。你已經親手寫過每一個零件了。

接下來

  • 把模型放大、在 GPU 上訓練更久，看品質怎麼變。
  • 把語料換成你自己的（例如金庸小說、宋詞、你的部落格），注意長度和清理。
  • 改用 BPE tokenizer 訓練一般中文文章。
  • 讀 nanoGPT、Llama 的原始碼。
  • 〈LLM 模型全解〉：RLHF、DPO、量化、MoE。
  • 〈一次 LLM 推論到底發生什麼〉：推論系統的工程。

下載全部範例

build-tiny-llm-examples.zip：所有程式碼（不含資料與訓練好的模型）。先執行 python prepare_data.py，再 python train.py。

🧭 這一課的重點

本課程的模型與大型 LLM 在參數、資料、算力、tokenizer、上下文、對齊與推論工程上差了好幾個數量級，但核心原理與程式碼相同。接下來可以放大模型、換語料、改用 BPE、閱讀 nanoGPT 與 Llama。

🛠️ 本課程的 Python 範例都在一台 4 核心 CPU、沒有 GPU 的電腦上實際執行過，頁面上的「執行結果」就是當時的輸出；你的數字會因硬體、PyTorch 版本與隨機性而略有不同。語料來自開源的 chinese-poetry 專案（MIT 授權）。
