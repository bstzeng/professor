RoPE：旋轉位置編碼

這一課的目標

  • 理解 RoPE 的想法
  • 看懂 rope 函式
  • 知道 RoPE 的優點

2021 年蘇劍林等人提出 RoPE。做法：把向量每兩個維度當成平面上的一個點，依照 token 的位置旋轉一個角度。不同的維度組用不同的轉速（從快到慢）。

def rope(x, pos): """旋轉位置編碼：把每兩個維度當成一個平面，依位置旋轉不同角度。x: (B, H, T, D)""" d = x.shape[-1] freq = 1.0 / (10000 ** (torch.arange(0, d, 2, device=x.device).float() / d)) ang = pos[:, None].float() * freq[None, :] # (T, D/2) cos, sin = ang.cos(), ang.sin() x1, x2 = x[..., 0::2], x[..., 1::2] out = torch.stack([x1 * cos - x2 * sin, x1 * sin + x2 * cos], dim=-1) return out.flatten(-2)

關鍵性質：位置 m 的 Q 和位置 n 的 K 都旋轉之後，它們的內積只跟 m − n 有關。模型自然學到「相對位置」，而且不需要位置 embedding 表。

在 CausalSelfAttention.forward 裡，只對 Q、K 套用 RoPE（V 不用）：

pos = torch.arange(start, start + T, device=x.device) q, k = rope(q, pos), rope(k, pos)

搭配 YaRN 等方法調整轉速，RoPE 模型可以延伸到比訓練時更長的上下文（見〈LLM 模型全解〉第 69 課）。

🧭 這一課的重點

RoPE 把 Q、K 每兩個維度依位置旋轉不同角度，旋轉後的內積只取決於相對距離，不需要位置 embedding 表，還能延伸上下文。Llama、Qwen 等都使用。
