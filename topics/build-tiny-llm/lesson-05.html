準備語料：下載、清理、切分

這一課的目標

  • 統計語料的基本數字
  • 知道字的分布非常不平均
  • 了解訓練集與驗證集的切分

訓練前先看看資料：有多少首詩、多少個不同的字、哪些字最常見。

🐍 s03_data.py　下載　執行：python s03_data.py

# -*- coding: utf-8 -*- """第 5 課：看看語料長什麼樣。""" from collections import Counter poems = open("data/tang.txt", encoding="utf-8").read().split("\n") poems = [p for p in poems if p] text = "".join(poems) print("詩的數量：", len(poems)) print("總字數：", len(text)) print("不同的字：", len(set(text))) kind = Counter() for p in poems: n = len(p.replace("，", "").replace("。", "")) kind[{20: "五言絕句", 28: "七言絕句", 40: "五言律詩", 56: "七言律詩"}[n]] += 1 for k, v in kind.most_common(): print(" %s：%d 首" % (k, v)) cnt = Counter(c for c in text if c not in "，。") print("最常見的 20 個字：", "".join(c for c, _ in cnt.most_common(20))) once = sum(1 for c, v in cnt.items() if v == 1) print("只出現一次的字：%d 個（例如：%s）" % (once, "".join([c for c, v in cnt.items() if v == 1][:10])))

▶ 執行結果（實際執行的輸出）

詩的數量： 36595 總字數： 1620259 不同的字： 6754 五言律詩：14333 首 七言絕句：10484 首 七言律詩：7850 首 五言絕句：3928 首 最常見的 20 個字： 不人山風一無日雲來花春水月有何上時中天年 只出現一次的字：1040 個（例如：蒐殖譟嶪侁煠闓絜跱簋）

觀察

  • 約 6,750 個不同的字，但前幾百個常用字就佔了大部分。這種「少數很常見、多數很罕見」的分布叫長尾分布。
  • 有一千多個字只出現一次——模型幾乎不可能學會它們。
  • 五言律詩最多，五言絕句最少。模型寫出來的詩，也會偏向資料裡比較多的體裁。

切分

我們把整份文字的前 95% 當訓練集、後 5% 當驗證集。驗證集模型從沒看過，用來檢查它是真的學會寫詩，還是只是背下訓練資料。

# ---- 資料：整份文字轉成一長串 token id，前 95% 訓練、後 5% 驗證 ---- text = open(args.data, encoding="utf-8").read() if os.path.exists("tokenizer.json"): tok = CharTokenizer.load("tokenizer.json") else: tok = CharTokenizer.train(text) tok.save("tokenizer.json") data = torch.tensor(tok.encode(text), dtype=torch.long) n = int(len(data) * 0.95) train_data, val_data = data[:n], data[n:]

🧭 這一課的重點

語料約 3.6 萬首、162 萬字、6,750 個不同的字，字頻是長尾分布。前 95% 當訓練集、後 5% 當驗證集，用來檢查模型是否真的學會而不是背誦。
