載入開源小模型

這一課的目標

  • 知道 Hugging Face 的角色
  • 看懂載入模型與 tokenizer 的程式
  • 了解微調開源模型需要的資源

我們的唐詩模型只看過 162 萬字。開源模型（Llama、Qwen、Gemma、Mistral 等）用數兆 token 預訓練過，懂得多得多。實務上幾乎都是拿開源模型來微調，而不是從零訓練。

Hugging Face 是最大的開源模型平台，用 transformers 套件兩行就能載入：

from transformers import AutoModelForCausalLM, AutoTokenizer tok = AutoTokenizer.from_pretrained("Qwen/Qwen2.5-0.5B-Instruct") model = AutoModelForCausalLM.from_pretrained("Qwen/Qwen2.5-0.5B-Instruct")

載入的模型和我們的 GPT 本質相同：model(input_ids) 輸出 logits，.generate() 逐字生成。0.5B 的模型約 1 GB，筆電也跑得動；7B 以上的模型通常需要 GPU 或量化。

模型大小推論（16 位元）LoRA 微調（約略）
0.5B約 1 GBCPU 可行但慢；任何 GPU
7B～8B約 16 GB24 GB GPU，或用 QLoRA 壓到約 10 GB
70B約 140 GB多張 GPU，或 QLoRA 約 48 GB

本課程的測試環境無法連線到 Hugging Face，所以下面第 40 課附的 hf_qwen_lora.py 沒有附上執行結果。我們改在自己的唐詩模型上，從零實作 LoRA 並完整跑過——原理完全相同。

🧭 這一課的重點

實務上多半拿開源模型微調而非從零訓練。transformers 套件兩行就能從 Hugging Face 載入模型與 tokenizer，用法和我們的 GPT 相同；模型越大需要的 GPU 記憶體越多。

🛠️ 本課程的 Python 範例都在一台 4 核心 CPU、沒有 GPU 的電腦上實際執行過，頁面上的「執行結果」就是當時的輸出；你的數字會因硬體、PyTorch 版本與隨機性而略有不同。語料來自開源的 chinese-poetry 專案（MIT 授權）。
