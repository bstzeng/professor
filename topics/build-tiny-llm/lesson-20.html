殘差與 LayerNorm

這一課的目標

  • 理解殘差連接在 Transformer 中的寫法
  • 理解 LayerNorm
  • 知道 Pre-LN 與 Post-LN 的差別

殘差連接：x = x + attn(x)，讓資訊和梯度可以繞過子層直接傳遞。整個模型可以想成一條「殘差流」，每一層都在上面加一點修正。

LayerNorm：把每個 token 的向量調整成平均 0、標準差 1，再乘上可學的縮放。讓每一層的輸入保持穩定。

Pre-LN 與 Post-LN

Post-LN（原始 Transformer）Pre-LN（GPT-2 之後）
寫法x = LN(x + f(x))x = x + f(LN(x))
訓練穩定度深了容易不穩、需要仔細 warmup穩定，現在的主流

Pre-LN 讓殘差流保持「乾淨」，梯度可以毫無阻礙地從最後一層流回第一層。所以最後還要在輸出前再做一次 LayerNorm（ln_f）。

🧭 這一課的重點

殘差連接 x = x + f(x) 讓資訊與梯度直通，形成殘差流；LayerNorm 穩定每層輸入。現代模型用 Pre-LN（先正規化再進子層），比原始的 Post-LN 穩定，輸出前再加一次 ln_f。
