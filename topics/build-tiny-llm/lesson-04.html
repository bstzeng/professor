nn.Module 與訓練迴圈

這一課的目標

  • 會寫一個 nn.Module
  • 記住訓練迴圈的五個步驟
  • 知道 optimizer 在做什麼

PyTorch 的模型都繼承 nn.Module：在 __init__ 裡建立參數和子模組，在 forward 裡寫計算。我們先用最簡單的直線練習。

🐍 s02_module.py　下載　執行：python s02_module.py

# -*- coding: utf-8 -*- """第 4 課：nn.Module 與訓練迴圈——用梯度下降找出 y = 2x + 1。""" import torch import torch.nn as nn torch.manual_seed(0) x = torch.linspace(-3, 3, 100).unsqueeze(1) # 100 個點，形狀 (100, 1) y = 2 * x + 1 + 0.3 * torch.randn_like(x) # 加一點雜訊 class Line(nn.Module): def __init__(self): super().__init__() self.lin = nn.Linear(1, 1) # 裡面有 weight 和 bias 兩個參數 def forward(self, x): return self.lin(x) model = Line() opt = torch.optim.SGD(model.parameters(), lr=0.1) for step in range(101): pred = model(x) # 1. 前向 loss = ((pred - y) ** 2).mean() # 2. 算損失（MSE） opt.zero_grad() # 3. 清掉舊梯度 loss.backward() # 4. 反向傳播 opt.step() # 5. 更新參數 if step % 20 == 0: print("step %3d loss %.4f w=%.3f b=%.3f" % (step, loss.item(), model.lin.weight.item(), model.lin.bias.item()))

▶ 執行結果（實際執行的輸出）

step 0 loss 16.5048 w=1.128 b=0.238 step 20 loss 0.0946 w=2.000 b=1.002 step 40 loss 0.0945 w=2.000 b=1.011 step 60 loss 0.0945 w=2.000 b=1.011 step 80 loss 0.0945 w=2.000 b=1.011 step 100 loss 0.0945 w=2.000 b=1.011

訓練迴圈五步驟

  1. 前向：pred = model(x)
  2. 損失：loss = ...
  3. 清梯度：opt.zero_grad()（PyTorch 的梯度預設會累加）
  4. 反向：loss.backward()
  5. 更新：opt.step()

20 步之後 w 和 b 就很接近 2 和 1 了。我們的 GPT 只是把「一條直線」換成「300 萬個參數的 Transformer」、把 MSE 換成交叉熵，迴圈完全一樣。

🧭 這一課的重點

模型繼承 nn.Module，在 forward 寫計算。訓練迴圈是前向、算損失、清梯度、反向、更新五步。從一條直線到 GPT，迴圈都一樣。

🛠️ 本課程的 Python 範例都在一台 4 核心 CPU、沒有 GPU 的電腦上實際執行過，頁面上的「執行結果」就是當時的輸出；你的數字會因硬體、PyTorch 版本與隨機性而略有不同。語料來自開源的 chinese-poetry 專案（MIT 授權）。
