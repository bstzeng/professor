字元級 tokenizer

這一課的目標

  • 理解 tokenizer 的工作
  • 實作字元級 tokenizer
  • 知道 encode 與 decode

神經網路只吃數字。Tokenizer 負責把文字切成一個個 token，再對應成整數 id（encode），以及反過來（decode）。最簡單的做法：每個字就是一個 token。

class CharTokenizer: """每個字一個 token。""" def __init__(self, chars): self.itos = list(chars) self.stoi = {c: i for i, c in enumerate(self.itos)} @classmethod def train(cls, text): chars = sorted(set(text) | set(SPECIAL)) return cls(chars)

🐍 s04_char_tok.py　下載　執行：python s04_char_tok.py

# -*- coding: utf-8 -*- """第 6 課：字元級 tokenizer。""" from tokenizer import CharTokenizer text = open("data/tang.txt", encoding="utf-8").read() tok = CharTokenizer.train(text) print("詞彙量：", tok.vocab_size) s = "床前明月光，疑是地上霜。" ids = tok.encode(s) print("編碼：", ids) print("解碼：", tok.decode(ids)) print("換行符號的 id：", tok.encode("\n")) print("詞彙表最前面 10 個：", repr("".join(tok.itos[:10])))

▶ 執行結果（實際執行的輸出）

詞彙量： 6758 編碼： [1390, 395, 2127, 2214, 292, 6757, 3449, 2137, 805, 10, 6167, 2] 解碼： 床前明月光，疑是地上霜。 換行符號的 id： [0] 詞彙表最前面 10 個： '\n 。〔〕一丁七丈三'

詞彙表依字的 Unicode 順序排列，所以換行（\n）是 0 號。我們把換行當成「一首詩結束」的記號：模型生成到換行，就代表這首詩寫完了。

中文很適合字元級

英文只有 26 個字母，用字母當 token 序列會太長；中文一個字本身就有意義，常用字也只有幾千個，字元級 tokenizer 對唐詩來說很合理。

🧭 這一課的重點

Tokenizer 把文字切成 token 並對應成整數。字元級 tokenizer 讓每個字一個 token，詞彙量約 6,758；換行代表一首詩結束。中文因為單字有意義，很適合字元級。
