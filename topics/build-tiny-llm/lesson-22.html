堆疊成 GPT

這一課的目標

  • 看懂 GPT 類別
  • 理解權重綁定
  • 理解初始化與損失計算
class GPT(nn.Module): def __init__(self, cfg): super().__init__() self.cfg = cfg self.tok_emb = nn.Embedding(cfg.vocab_size, cfg.n_embd) self.pos_emb = None if cfg.modern else nn.Embedding(cfg.block_size, cfg.n_embd) self.drop = nn.Dropout(cfg.dropout) self.blocks = nn.ModuleList([Block(cfg) for _ in range(cfg.n_layer)]) self.ln_f = RMSNorm(cfg.n_embd) if cfg.modern else nn.LayerNorm(cfg.n_embd) self.head = nn.Linear(cfg.n_embd, cfg.vocab_size, bias=False) self.head.weight = self.tok_emb.weight # 權重綁定：輸入和輸出共用同一張 embedding 表 self.apply(self._init)

（這裡節錄建構子，完整程式見第 24 課。）

三個細節

  • 輸出層：最後的 head 把 d 維向量轉成 V 個 logits，就是對整個詞彙表的分數。
  • 權重綁定：輸出層和 token embedding 共用同一張表。輸入時「字 → 向量」、輸出時「向量 → 每個字的分數」，用同一組權重很合理，還能省下 V×d 個參數（我們省了 130 萬）。
  • 初始化：所有權重用標準差 0.02 的常態分布，偏差設 0，這是 GPT-2 的設定。
logits = self.head(self.ln_f(x)) loss = None if targets is not None: loss = F.cross_entropy(logits.view(-1, logits.size(-1)), targets.view(-1)) return logits, loss

損失就是對每個位置的 logits 做交叉熵，PyTorch 一行搞定。

🧭 這一課的重點

GPT 由 token／位置 embedding、N 個 Block、最後的 LayerNorm 與輸出層組成。輸出層和 token embedding 權重綁定以節省參數，權重以標準差 0.02 初始化，損失是每個位置的交叉熵。
