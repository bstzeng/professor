範例下載與指令速查

⬇️ 下載全部範例（zip）。需要 Python 3.9 以上與 PyTorch。

建議執行順序

python prepare_data.py # 下載語料（約 30 MB），產生 data/tang.txt python train.py # 訓練（4 核心 CPU 約 20 分鐘，GPU 幾分鐘） python sample.py --prompt 春 # 寫詩 python chat.py # 互動 python train.py --modern --out ckpt_modern.pt # Llama 風格 python s13_instruct_data.py # 產生指令資料 python lora.py # LoRA 微調 python s14_eval.py # 評估

train.py 常用參數

參數預設說明
--steps2000訓練步數
--batch／--accum32／1批次大小與梯度累積
--block80上下文長度
--n_layer／--n_head／--n_embd4／4／192模型大小
--lr／--warmup1e-3／100學習率與 warmup 步數
--modern關Llama 風格
--resume關從存檔繼續
--amp關混合精度（GPU）
