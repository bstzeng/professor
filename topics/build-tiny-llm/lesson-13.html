抽樣生成第一段文字

這一課的目標

  • 理解自回歸生成
  • 會從機率分布抽樣
  • 觀察 bigram 生成的品質

生成的方法：給一個開頭的字，從它那一列的機率抽樣出下一個字，再用新的字繼續抽，直到抽到換行。每一步都把自己的輸出當成下一步的輸入，叫做自回歸生成——GPT 也是這樣生成的。

def sample(start, n=60): idx = tok.stoi[start] out = start for _ in range(n): idx = torch.multinomial(raw[idx], 1).item() if tok.itos[idx] == "\n": break out += tok.itos[idx] return out

▶ 執行結果

生成： 春闈。 月窗早晚歲道升高，忍開戶喧。還用，心亦遷。夢江帆隨人。欲把七旬時，廉船過。振俗事可追呼兒，琴。愛毀穴蟻斜漢月，捫蘿去，鶴， 山形勝難狀古般。詩名。吟新事，葉颯然歸寧憂。早晚笛雪裏有酒杯，古同陶，橘下，人骨亦扁舟輕財貨，八埏。秦客自笑妖星列晚，當合

每兩個相鄰的字都還算通順（「月明」「山遠」「早晚」），但整句毫無意義，也不知道五言七言、什麼時候該斷句。因為它只記得前一個字。

注意這裡用的是 torch.multinomial 按機率抽樣，而不是每次都選機率最高的字。如果每次都選最高，「月」後面永遠是「，」，很快就會陷入重複。第 32 課會詳細討論。

🧭 這一課的重點

自回歸生成每次依機率抽出下一個字，再把它當作下一步的輸入，GPT 也是這樣。Bigram 只記得前一個字，所以相鄰兩字通順，整句卻沒有意義也沒有格式。

🛠️ 本課程的 Python 範例都在一台 4 核心 CPU、沒有 GPU 的電腦上實際執行過，頁面上的「執行結果」就是當時的輸出；你的數字會因硬體、PyTorch 版本與隨機性而略有不同。語料來自開源的 chinese-poetry 專案（MIT 授權）。
