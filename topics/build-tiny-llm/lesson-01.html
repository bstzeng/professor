模組 A｜準備 · 第 1 課

這門課要做出什麼

這一課的目標

  • 知道整門課的目標與流程
  • 看到最後做出來的成果
  • 了解需要的背景知識

這門課要從零開始，用 Python 和 PyTorch 一行一行寫出一個 GPT，讓它讀完 3.6 萬首唐詩之後學會寫詩。整個模型約 300 萬個參數，一般筆電的 CPU 就能訓練，不需要 GPU。

這是本課程訓練好的模型寫的詩（給它一個開頭的字，它自己接下去）：

▶ 執行結果

春風多少思，夢客到東樓。孤鶴人何在，湘洲日夜深。 春深似野園，微急是孤舟。家有花枝在，年少月中空。庭前歸不可，月月楚風吹。 春風塵際節，風暮雨中天。暖色蕭蕭斷，寒霞萬里中。

它當然不懂詩的意思，常常前後不連貫，但已經學會了五言、七言的格式、對仗的節奏和唐詩常用的字詞。這些全部都是從資料裡「猜下一個字」學出來的，沒有人教它任何規則。

你需要的背景

  • 會基本的 Python（變數、函式、迴圈、類別）。
  • 知道神經網路、梯度下降、注意力機制的概念——不熟的話可以先看 〈神經網路與深度學習〉。
  • 不需要 GPU；有 NVIDIA 顯示卡或 Apple M 系列晶片會快很多。

🧭 這一課的重點

這門課從零寫一個約 300 萬參數的 GPT，用 3.6 萬首唐詩在 CPU 上訓練，讓它學會寫詩，最後再用 LoRA 微調讓它聽懂指令。每一步都附可執行的程式與實際輸出。

🛠️ 本課程的 Python 範例都在一台 4 核心 CPU、沒有 GPU 的電腦上實際執行過，頁面上的「執行結果」就是當時的輸出；你的數字會因硬體、PyTorch 版本與隨機性而略有不同。語料來自開源的 chinese-poetry 專案（MIT 授權）。

檢查你的理解

  1. 這門課的模型用什麼資料訓練？
  2. 模型大約有多少參數？需要 GPU 嗎？
  3. 模型學會寫詩靠的是什麼訓練目標？
