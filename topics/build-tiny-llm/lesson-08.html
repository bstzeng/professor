中文的 BPE 會遇到什麼

這一課的目標

  • 看懂位元組層級 BPE 在中文上的行為
  • 理解壓縮率
  • 知道為什麼中文常比英文花更多 token

用唐詩訓練 400 次合併，看看前幾次合併了什麼：

🐍 s05_bpe.py　下載　執行：python s05_bpe.py

# -*- coding: utf-8 -*- """第 7、8 課：從零實作 BPE，看它在中文上學到什麼。""" import time from tokenizer import BPETokenizer, show poems = open("data/tang.txt", encoding="utf-8").read().split("\n")[:1500] sample = "\n".join(poems) t = time.time() tok = BPETokenizer.train(sample, 400, verbose=12) print("訓練 400 次合併花了 %.0f 秒" % (time.time() - t)) s = "白日依山盡，黃河入海流。欲窮千里目，更上一層樓。" ids = tok.encode(s) print("\n「%s」" % s) print("UTF-8 位元組數：", len(s.encode("utf-8")), " 字數：", len(s), " BPE token 數：", len(ids)) print("切法：", " | ".join(show(tok.vocab[i]) for i in ids)) test = "\n".join(open("data/tang.txt", encoding="utf-8").read().split("\n")[30000:30200]) n_ids = len(tok.encode(test)) print("\n在沒看過的 200 首詩上：位元組 %d → BPE token %d（字數 %d）" % (len(test.encode("utf-8")), n_ids, len(test)))

觀察

  • 中文字在 UTF-8 裡通常是 3 個位元組。最早的合併常是把常見的「前兩個位元組」黏起來（顯示成 ‹e5 a4›），因為很多中文字共用同樣的開頭位元組。
  • 標點「，」「。」很快就成為完整的 token；接著還會出現跨字的組合，例如「，」加上下一個字的第一個位元組——BPE 只看頻率，不管字的邊界。
  • 常見字（山、月、日）最後變成一個 token；罕見字還是 2～3 個 token。
  • 在沒看過的詩上，BPE 用的 token 數約是字數的 1.5 倍，比字元級還多——因為我們只合併了 400 次，連常用字都還沒完全學完。

真實的 LLM

GPT-4 等模型的詞彙表有 10 萬到 20 萬個 token，常用中文字大多是一個 token，但在詞彙表以英文為主的模型上，同樣意思的中文常比英文花更多 token，費用和速度都受影響（見〈LLM 模型全解〉）。

🧭 這一課的重點

位元組層級 BPE 會先合併中文字常見的位元組開頭，常用字最後變成單一 token、罕見字仍拆開。合併次數太少時，中文 token 數甚至比字數還多；真實模型用 10 萬以上的詞彙表。
