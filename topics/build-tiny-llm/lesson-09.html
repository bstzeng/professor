特殊 token 與編碼、解碼

這一課的目標

  • 知道特殊 token 的用途
  • 理解我們用換行代表一首詩結束
  • 處理不在詞彙表裡的字

除了一般的字，tokenizer 通常還有幾個特殊 token：

特殊 token例子用途
文件結束<|endoftext|>（GPT-2）分隔不同文件，生成到這裡就停
對話角色<|im_start|>user標出誰在說話（chat template）
填充<pad>把不同長度的序列補成一樣長

我們的設計很簡單：

SPECIAL = ["\n", "〔", "〕", " "] # 換行＝一首詩結束；〔〕與空白給第 39 課的指令格式用
  • 換行：一首詩結束，同時也代表下一首詩的開始。所以生成時，我們會在提示前面先加一個換行，告訴模型「這是一首新詩的開頭」；生成到下一個換行就停。
  • 〔 〕和空白：先保留，第 39 課做指令微調時，用來寫「〔七言絕句 春〕」這種指令。

沒看過的字

字元級 tokenizer 遇到詞彙表沒有的字（例如「咖啡」）就無法編碼。chat.py 的做法是先把這些字濾掉。BPE 則沒有這個問題，最壞就拆成位元組——這是 BPE 成為主流的重要原因。

🧭 這一課的重點

特殊 token 用來標記文件結束、對話角色、填充。我們用換行代表一首詩結束，並預留〔〕給指令格式。字元級 tokenizer 無法處理沒看過的字，BPE 則可以拆成位元組。
