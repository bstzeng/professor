模組 E｜訓練 · 第 31 課

實驗：改層數、寬度、上下文長度

這一課的目標

  • 學會設計對照實驗
  • 觀察模型大小對損失的影響
  • 理解上下文長度的重要

🐍 s09_experiments.py　下載　執行：python s09_experiments.py

# -*- coding: utf-8 -*- """第 31 課：改層數、寬度、上下文長度，各訓練 300 步，比較驗證損失。""" import re import subprocess import sys RUNS = [("基準：2 層、128 維、上下文 80", []), ("加深：4 層", ["--n_layer", "4"]), ("加寬：256 維", ["--n_embd", "256"]), ("上下文縮短為 16", ["--block", "16"])] for name, extra in RUNS: cmd = [sys.executable, "train.py", "--steps", "300", "--eval_every", "299", "--n_layer", "2", "--n_embd", "128", "--out", "exp.pt", "--warmup", "30"] + extra out = subprocess.run(cmd, capture_output=True, text=True).stdout last = [l for l in out.splitlines() if l.startswith("step")][-1] params = re.search(r"參數 ([\d.]+)M", out).group(1) print("%-22s 參數 %sM → 驗證損失 %s" % (name, params, re.search(r"val loss ([\d.]+)", last).group(1)))

從結果學到

  • 在相同步數下，加深或加寬通常讓損失更低，但每一步也更慢。
  • 上下文縮短到 16：模型連一句七言都看不完整，損失明顯變差——它不知道自己寫到第幾句。
  • 只訓練 300 步的結論不一定能推廣到長時間訓練。真實的研究會用縮放定律，在小模型上做實驗、預測大模型的表現。

動手試試

  • 把 dropout 改成 0，看驗證損失會不會變差。
  • 把學習率改成 3e-3 或 3e-4。
  • 不加 warmup（--warmup 0）會怎樣？

🧭 這一課的重點

對照實驗一次只改一個變因。加深、加寬通常降低損失但更慢；上下文太短，模型看不到整首詩的結構，損失明顯變差。短時間實驗的結論要小心推廣。

🛠️ 本課程的 Python 範例都在一台 4 核心 CPU、沒有 GPU 的電腦上實際執行過，頁面上的「執行結果」就是當時的輸出；你的數字會因硬體、PyTorch 版本與隨機性而略有不同。語料來自開源的 chinese-poetry 專案（MIT 授權）。
