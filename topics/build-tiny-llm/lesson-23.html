數參數：我的模型有多大

這一課的目標

  • 會計算 GPT 的參數量
  • 知道小模型裡 embedding 佔比很高
  • 把參數量換算成記憶體

🐍 s08_params.py　下載　執行：python s08_params.py

# -*- coding: utf-8 -*- """第 23 課：數一數模型有多少參數。""" from gpt import GPT, GPTConfig from tokenizer import CharTokenizer tok = CharTokenizer.load("tokenizer.json") cfg = GPTConfig(vocab_size=tok.vocab_size, block_size=80) m = GPT(cfg) parts = {} for name, p in m.named_parameters(): key = "embedding（字）" if name.startswith("tok_emb") else "embedding（位置）" if name.startswith("pos_emb") else \ "注意力" if ".attn." in name else "MLP" if ".mlp." in name else "LayerNorm" parts[key] = parts.get(key, 0) + p.numel() for k, v in parts.items(): print("%-16s %9d" % (k, v)) print("%-16s %9d （輸出層和字 embedding 共用權重，所以不另外計算）" % ("合計", m.num_params())) d, L, V = cfg.n_embd, cfg.n_layer, cfg.vocab_size est = V * d + cfg.block_size * d + L * (12 * d * d + 13 * d) + 2 * d print("公式 V·d ＋ T·d ＋ L·(12d² ＋ 13d) ＋ 2d ＝", est)

▶ 執行結果（實際執行的輸出）

embedding（字） 1297536 embedding（位置） 15360 LayerNorm 3456 注意力 592896 MLP 1183488 合計 3092736 （輸出層和字 embedding 共用權重，所以不另外計算） 公式 V·d ＋ T·d ＋ L·(12d² ＋ 13d) ＋ 2d ＝ 3092736

公式算出來和程式數出來完全一樣。注意 embedding 佔了約四成——小模型的詞彙表相對很「貴」。大模型則相反，Llama 3 8B 的 embedding 只佔約一成三。

更多大型模型的參數計算（GQA、MoE 等），見〈LLM 模型全解〉第 14～21 課。

🧭 這一課的重點

GPT 的參數量約 V·d + T·d + L·(12d² + 13d)，本課程模型約 309 萬，embedding 佔四成。訓練時每個參數約需 16 bytes（FP32 權重、梯度與 Adam 狀態）。

🛠️ 本課程的 Python 範例都在一台 4 核心 CPU、沒有 GPU 的電腦上實際執行過，頁面上的「執行結果」就是當時的輸出；你的數字會因硬體、PyTorch 版本與隨機性而略有不同。語料來自開源的 chinese-poetry 專案（MIT 授權）。
