組成一個 Block

這一課的目標

  • 看懂 Block 的完整程式
  • 理解 Block 的輸入輸出形狀相同
  • 知道為什麼可以一直疊

把前面的零件組起來，一個 Block 的 forward 只有兩行：

class Block(nn.Module): def __init__(self, cfg): super().__init__() Norm = RMSNorm if cfg.modern else nn.LayerNorm self.ln1, self.attn = Norm(cfg.n_embd), CausalSelfAttention(cfg) self.ln2, self.mlp = Norm(cfg.n_embd), MLP(cfg) def forward(self, x, cache=None, start=0): x = x + self.attn(self.ln1(x), cache, start) # 殘差連接 x = x + self.mlp(self.ln2(x)) return x

Block 的輸入和輸出形狀都是 (B, T, d)，所以可以像積木一樣疊起來。GPT-2 small 疊 12 層、GPT-3 疊 96 層、我們疊 4 層。

一層 Block 的參數

注意力 4d²、FFN 8d²，再加上偏差和兩個 LayerNorm，約 \(12d^2 + 13d\)。我們 d = 192，一層約 44 萬個參數。

🧭 這一課的重點

一個 Block 就是 x = x + attn(ln1(x)) 和 x = x + mlp(ln2(x)) 兩行。輸入輸出形狀相同，所以可以一直疊；一層約 12d² 個參數。

🛠️ 本課程的 Python 範例都在一台 4 核心 CPU、沒有 GPU 的電腦上實際執行過，頁面上的「執行結果」就是當時的輸出；你的數字會因硬體、PyTorch 版本與隨機性而略有不同。語料來自開源的 chinese-poetry 專案（MIT 授權）。
