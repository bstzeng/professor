遷移學習

這一課的目標

  • 理解遷移學習的想法
  • 分辨特徵擷取與微調
  • 連結到 LLM 的預訓練與微調

從零訓練一個大模型需要大量資料和算力。遷移學習：先拿在大資料集（例如 ImageNet）上訓練好的模型，再用少量自己的資料調整到新任務。

兩種做法

做法怎麼做適合
特徵擷取凍結預訓練的層，只重新訓練最後的分類層資料很少（幾百張）
微調（fine-tune）用較小的學習率，連前面的層一起調整資料中等、任務差異較大

為什麼可行？前面的層學到的是邊緣、紋理、形狀這類通用特徵，對大多數影像任務都有用；只有最後幾層比較專門。

import torchvision model = torchvision.models.resnet50(weights='DEFAULT') # 下載 ImageNet 預訓練權重 for p in model.parameters(): p.requires_grad = False # 凍結 model.fc = torch.nn.Linear(2048, 5) # 換成 5 類的新分類層 # 接著只訓練 model.fc 即可

LLM 的版本

LLM 就是遷移學習的極致：先用數兆 token 預訓練出通用的「基礎模型」，再用指令資料微調（SFT）、偏好資料對齊（RLHF），甚至用 LoRA 只調一小部分參數。詳見〈LLM 模型全解〉。

🧭 這一課的重點

遷移學習拿大資料集預訓練好的模型，換上新的輸出層，再凍結訓練或用小學習率微調。前面的層學的是通用特徵，所以少量資料也能有好結果；LLM 的預訓練加微調正是同樣的想法。
