反向傳播一步步算

這一課的目標

  • 理解前向與反向傳播
  • 能手算一個小網路的梯度
  • 知道自動微分在做什麼

1986 年 Rumelhart、Hinton、Williams 在《自然》期刊發表論文，展示反向傳播可以有效訓練多層網路，讓神經網路研究重新熱起來。（類似的想法更早就有人提出。）

手算一個例子

網路：h = ReLU(w1·x)，ŷ = w2·h，L = (ŷ − y)² 設 x = 2, y = 10, w1 = 1.5, w2 = 2 前向：h = ReLU(3) = 3 ŷ = 6 L = (6−10)² = 16 反向： ∂L/∂ŷ = 2(ŷ − y) = −8 ∂L/∂w2 = ∂L/∂ŷ · h = −8 × 3 = −24 ∂L/∂h = ∂L/∂ŷ · w2 = −8 × 2 = −16 ∂L/∂w1 = ∂L/∂h · ReLU'· x = −16 × 1 × 2 = −32 更新（η = 0.01）：w2 = 2 + 0.24 = 2.24，w1 = 1.5 + 0.32 = 1.82 再算一次：h = 3.64，ŷ = 8.15，L = 3.4 ← 損失從 16 降到 3.4

注意 ∂L/∂h 算一次，就同時用來算 w1 的梯度——反向傳播的效率來自重複使用中間結果，總計算量大約只是前向的兩倍。

自動微分

PyTorch 在前向計算時記錄每個運算（計算圖），呼叫 loss.backward() 時自動沿著圖反向套用連鎖律。所以我們只要寫前向，梯度不用自己推。

🧭 這一課的重點

反向傳播從損失開始，用連鎖律一層層往回算出每個參數的梯度，並重複使用中間結果，成本只是前向的約兩倍。PyTorch 的自動微分會記錄計算圖、自動完成這件事。

🧠 本課的互動工具都在瀏覽器裡即時計算；資料是教學用的小例子，詞向量、注意力等數值為示意，真實模型的維度從數百到數萬維。歷史年份以原始論文發表年份為準。

檢查你的理解

  1. 反向傳播為什麼比「每個參數各自數值微分」快得多？
  2. 在範例中，∂L/∂h 被用來算什麼？
  3. loss.backward() 做了什麼？
