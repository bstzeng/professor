One-hot 的問題

這一課的目標

  • 知道 one-hot 編碼
  • 理解它的缺點
  • 了解「分散式表示」的想法

電腦只懂數字。最直接的表示法：詞彙表有 5 萬個字，每個字是一個 5 萬維的向量，只有自己的位置是 1、其他都是 0，叫做 one-hot。

貓 = [0, 0, 1, 0, 0, …, 0] 狗 = [0, 0, 0, 1, 0, …, 0] 汽車 = [0, 0, 0, 0, 1, …, 0]

問題

  • 太大：詞彙量多少，向量就多長，而且幾乎全是 0。
  • 沒有意義：任兩個字的內積都是 0。「貓」和「狗」的距離，跟「貓」和「汽車」一樣遠。

分散式表示

語言學家 Firth 在 1957 年說：「看一個字的鄰居，就知道它的意思。」「貓」和「狗」常出現在相似的句子裡（「我家的＿＿很可愛」「帶＿＿去看獸醫」），所以它們應該有相似的表示。

做法：用一個短得多的稠密向量（例如 300 維）表示每個字，每一維都是實數，意思相近的字向量相近。這種向量叫做 embedding（嵌入）。

🧭 這一課的重點

One-hot 用一個只有一個 1 的超長向量表示字，既浪費又無法表達字的相似度。分散式表示用短的稠密向量，讓常出現在相似上下文的字有相近的向量，這就是 embedding。

🧠 本課的互動工具都在瀏覽器裡即時計算；資料是教學用的小例子，詞向量、注意力等數值為示意，真實模型的維度從數百到數萬維。歷史年份以原始論文發表年份為準。
