Batch Norm 與 Layer Norm

這一課的目標

  • 理解正規化層的作用
  • 分辨 Batch Norm 與 Layer Norm
  • 知道 Transformer 用哪一種

訓練時前面層的參數一直在變，後面層收到的輸入分布也跟著變，難以學習。正規化層把每一層的輸入調整成平均 0、標準差 1，再用兩個可學的參數 γ、β 縮放與平移。

Batch Norm（2015）

對每個特徵，用整個批次算平均和標準差。讓 CNN 可以用更大的學習率、訓練快很多。缺點：依賴批次大小，批次太小時統計不準；推論時要改用訓練中累積的平均值。

Layer Norm（2016）

對每一筆資料自己，在所有特徵上算平均和標準差，不受批次影響，也適合長度不一的序列。Transformer 用的是 Layer Norm。

Batch NormLayer NormRMSNorm
統計範圍同一特徵、跨批次同一筆資料、跨特徵同 Layer Norm，但只除以均方根
常用在CNNTransformer、RNNLlama 等新 LLM

RMSNorm 省略減去平均的步驟，計算更快、效果相當，是現代 LLM 的常見選擇。

🧭 這一課的重點

正規化層把每層輸入調成平均 0、標準差 1 再縮放，讓訓練更穩更快。Batch Norm 跨批次統計，常用於 CNN；Layer Norm 對每筆資料自己統計，是 Transformer 的選擇；新 LLM 多用 RMSNorm。

🧠 本課的互動工具都在瀏覽器裡即時計算；資料是教學用的小例子，詞向量、注意力等數值為示意，真實模型的維度從數百到數萬維。歷史年份以原始論文發表年份為準。
