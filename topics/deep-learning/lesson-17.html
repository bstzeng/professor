實作：手寫數字辨識（MNIST）

這一課的目標

  • 認識 MNIST 資料集
  • 看懂一個完整的 MLP 訓練程式
  • 知道一般能達到多少準確率

MNIST 有 7 萬張 28×28 的手寫數字灰階圖（6 萬張訓練、1 萬張測試），1998 年由 LeCun 等人整理，是深度學習入門的經典題目。

一個完整的 PyTorch 程式

import torch, torch.nn as nn from torchvision import datasets, transforms tf = transforms.ToTensor() train = datasets.MNIST('data', train=True, download=True, transform=tf) test = datasets.MNIST('data', train=False, download=True, transform=tf) loader = torch.utils.data.DataLoader(train, batch_size=64, shuffle=True) model = nn.Sequential( nn.Flatten(), # 28×28 → 784 nn.Linear(784, 128), nn.ReLU(), nn.Linear(128, 10)) # 10 個 logits opt = torch.optim.Adam(model.parameters(), lr=1e-3) loss_fn = nn.CrossEntropyLoss() # 內含 softmax for epoch in range(5): for x, y in loader: loss = loss_fn(model(x), y) opt.zero_grad() # 清掉上一次的梯度 loss.backward() # 反向傳播 opt.step() # 更新參數 with torch.no_grad(): xs, ys = test.data.float() / 255, test.targets acc = (model(xs).argmax(1) == ys).float().mean() print(f'測試準確率 {acc:.1%}')

這個約 10 萬個參數的網路，訓練幾分鐘就能達到約 97～98% 的測試準確率。用 CNN（模組 E）可以到 99% 以上。

訓練迴圈的四個步驟

  1. 前向：model(x) 算出預測。
  2. 算損失：和答案比較。
  3. 反向：loss.backward() 自動算出所有梯度。
  4. 更新：opt.step() 依梯度調整參數。

不管是 10 萬參數的 MNIST 網路還是數千億參數的 LLM，訓練迴圈都是這四步。〈親手訓練一個小 LLM〉會從這裡出發一路寫到 GPT。

🧭 這一課的重點

MNIST 是 7 萬張手寫數字圖片，一個兩層的 MLP 就能達到約 98% 準確率。訓練迴圈永遠是前向、算損失、反向傳播、更新參數四步，LLM 也一樣。

🧠 本課的互動工具都在瀏覽器裡即時計算；資料是教學用的小例子，詞向量、注意力等數值為示意，真實模型的維度從數百到數萬維。歷史年份以原始論文發表年份為準。
