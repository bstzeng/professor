矩陣乘法的直覺

這一課的目標

  • 會算小矩陣的乘法
  • 理解一層神經網路就是一次矩陣乘法
  • 知道形狀要怎麼對齊

矩陣乘法 \(C = AB\)：C 的第 i 列第 j 行，就是 A 的第 i 列和 B 的第 j 行做內積。

A = [[1, 2], B = [[5, 6], [3, 4]] [7, 8]] C[0][0] = 1×5 + 2×7 = 19 C[0][1] = 1×6 + 2×8 = 22 C[1][0] = 3×5 + 4×7 = 43 C[1][1] = 3×6 + 4×8 = 50

形狀規則

(m × n) 乘 (n × p) 得到 (m × p)。中間的 n 必須相同，就像接水管要口徑相同。寫神經網路時，十個錯誤有八個是形狀對不上。

一層神經網路 ＝ 一次矩陣乘法

一層有 4 個輸入、3 個神經元，每個神經元有 4 個權重，排成 3×4 的矩陣 W。輸入 x 是 4 維向量：\(y = Wx + b\) 一次算出 3 個神經元的輸出。一次丟進 32 筆資料，就是 (32×4) 乘 (4×3)，一口氣算完。

為什麼 GPU 這麼重要

矩陣乘法裡每個內積都可以獨立平行計算。GPU 有上萬個小核心，正好適合；訓練 LLM 的運算量有九成以上是矩陣乘法。

🧭 這一課的重點

矩陣乘法是一次算很多個內積，(m×n)(n×p) → (m×p)。一層神經網路就是 y = Wx + b；批次輸入時也是一次矩陣乘法，這正是 GPU 擅長的事。
