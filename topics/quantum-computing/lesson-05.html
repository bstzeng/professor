疊加：不是「同時在兩個地方」

這一課的目標

  • 掌握疊加態的正確理解
  • 認識常見的錯誤比喻
  • 會讀懂狀態的寫法

疊加是量子力學最常被誤解的概念。本課先把錯的說法拿掉。

1. 那些不太對的說法

常見說法問題
「同時是 0 和 1」暗示它有兩個確定的值，但它一個確定的值都沒有
「在兩個地方」暗示有兩個實體，實際上只有一個系統
「我們只是不知道它是哪一個」這是最嚴重的誤解，見下

第三個為什麼特別嚴重

「它其實是 0 或 1，只是我們不知道」——這叫做古典的無知， 就像蓋著的骰子。

但疊加不是這樣，而且這件事已經被實驗證實了。 如果只是無知，就不會有干涉現象； 而干涉是實際觀察得到的。

（驗證這件事的實驗，正是二〇二二年諾貝爾物理獎的內容—— 模組 O 會處理。）

2. 比較好的理解

疊加是一種新的狀態，它本身就是一個確定的狀態—— 只是這個狀態不對應到「0」或「1」的任何一個。

用一個比喻：一個指向東北的箭頭。

  • 它不是「同時指東又指北」
  • 它也不是「其實指東或指北，只是我們不知道」
  • 它就是指東北——那是一個完全確定的方向
  • 只是如果你堅持問「它是東還是北」，你會得到隨機的答案

本站複數課程講過：一個複數是平面上的箭頭。 量子態也是一種箭頭，只是活在一個更高維的空間裡。

3. 寫法

物理上用這個記號寫狀態：

\[ \lvert \psi \rangle = \alpha \lvert 0 \rangle + \beta \lvert 1 \rangle \]

符號意思
\( \lvert 0 \rangle \)、\( \lvert 1 \rangle \)兩個基本狀態，相當於古典的 0 與 1
\( \alpha, \beta \)複數，稱為機率幅
\( \lvert \psi \rangle \)整體的狀態

（那個角括號記號只是一個習慣寫法，用來提醒「這是一個量子態」， 不必被它嚇到。你可以把它想成一個向量。）

4. 唯一的限制

\[ \lvert \alpha \rvert^2 + \lvert \beta \rvert^2 = 1 \]

因為 \( \lvert \alpha \rvert^2 \) 是測到 0 的機率、 \( \lvert \beta \rvert^2 \) 是測到 1 的機率，兩者必須加起來等於一。

注意這個限制是對模平方，不是對機率幅本身。 機率幅可以是負的、可以是複數——而那正是干涉能發生的原因。

例：\( \alpha = \beta = \frac{1}{\sqrt{2}} \) 是一個合法的疊加態， 測量時各有一半機率得到 0 或 1。 但 \( \alpha = \frac{1}{\sqrt{2}} \)、\( \beta = -\frac{1}{\sqrt{2}} \) 也是——測量結果的機率完全一樣，但它是不同的狀態。 下一課說明這個差別為什麼重要。

本課重點

  • 疊加不是「同時是兩個值」，也不是「我們不知道是哪個」
  • 它是一個確定的狀態，只是不對應到任何一個基本值
  • \( \lvert\psi\rangle = \alpha\lvert0\rangle + \beta\lvert1\rangle \)，\( \alpha, \beta \) 是複數
  • 機率幅可以是負數或複數，這是干涉能發生的原因

  2. 用箭頭比喻解釋疊加
  3. 說明為什麼機率幅可以是負的很重要
