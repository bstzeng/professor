結構化輸出

這一課的目標

  • 理解結構化輸出的必要性
  • 用 schema 定義輸出
  • 在程式中驗證輸出

當輸出要交給程式處理時，「請只輸出 JSON」這種請求偶爾會失敗：多一句「好的，以下是結果」、少一個欄位、型別不對。對程式來說，偶爾失敗就是會壞掉。

可靠的做法是使用 API 的結構化輸出功能：提供一個 JSON Schema，模型產生的內容被限制在合法範圍內，保證符合格式。提示仍然重要——它決定欄位的內容好不好，schema 決定形式對不對。

🐍 Python 範例（離線可執行，已實際執行）　在程式中驗證模型輸出的格式

import json # 模型可能回傳的三種輸出（第一種是沒有約束時常見的情況） outputs = [ '好的！以下是擷取結果：{"name": "王小美", "plan": "企業", "demo": "要"}', '{"name": "王小美", "plan": "enterprise"}', '{"name": "王小美", "plan": "enterprise", "demo": true}', ] schema = {"name": str, "plan": ["free", "pro", "enterprise"], "demo": bool} def check(raw): try: data = json.loads(raw) except json.JSONDecodeError: return "不是合法 JSON" errs = [] for key, rule in schema.items(): if key not in data: errs.append("缺少 " + key) elif isinstance(rule, list) and data[key] not in rule: errs.append(key + " 必須是 " + "/".join(rule)) elif isinstance(rule, type) and not isinstance(data[key], rule): errs.append(key + " 型別應為 " + rule.__name__) return "通過" if not errs else "；".join(errs) for raw in outputs: print(check(raw).ljust(24), raw[:40])

☁️ Claude API 範例（需要 pip install anthropic 與 API 金鑰）　用 schema 保證輸出格式

from typing import Literal from pydantic import BaseModel import anthropic class Lead(BaseModel): name: str plan: Literal["free", "pro", "enterprise"] demo: bool client = anthropic.Anthropic() r = client.messages.parse( model="claude-opus-5-5", max_tokens=16000, messages=[{"role": "user", "content": "擷取資料：我是王小美，想試用企業方案，可以安排展示嗎？"}], output_format=Lead, # 以 Pydantic 類別定義 schema，SDK 會驗證並回傳物件 ) print(r.parsed_output)

結構化輸出也有限制：某些 schema 寫法（例如數值範圍）不支援，內容是否「合理」仍要用程式檢查。

🧭 這一課的重點

程式要讀取的輸出不能只靠「請輸出 JSON」，因為偶爾會多出文字、缺欄位或型別錯誤。使用結構化輸出提供 JSON Schema 可保證格式，提示則決定欄位內容的品質；仍要用程式驗證內容是否合理。

✍️ 提示工程的最佳做法會隨模型世代改變；本課以目前主流模型（特別是 Claude）的實際行為為例，原則大多通用。Python 範例中標示「已執行」的為離線程式，輸出是實際結果；呼叫 API 的範例需要金鑰，模型名稱與參數以官方文件為準。
