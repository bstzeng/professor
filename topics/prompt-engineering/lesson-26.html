Level 2｜Context：模型該看到什麼 · 第 26 課

多模態上下文

這一課的目標

  • 了解如何在提示中使用圖片與 PDF
  • 寫出針對圖片的清楚指令
  • 處理表格資料

現代模型可以直接讀圖片與 PDF。提示的原則和文字相同——說清楚要做什麼——但有幾個特別的地方：

  • 圖片放在問題之前：先給圖，再問問題。
  • 說明要看哪裡：「看右上角的表格」「比較第二張和第三張圖的差異」。
  • 先描述再分析：要求模型先描述看到的內容，再進行判斷，可以減少看錯造成的錯誤推論。
  • 多張圖要標號：「圖 1：……」「圖 2：……」，方便模型引用。

  • 先描述、再判斷
  • 給出明確的判斷選項，包括「無法判斷」

表格資料（例如 CSV）可以直接以文字形式放入，並說明欄位意義。如果需要精確計算，讓模型寫程式或使用計算工具，比讓它「看表心算」可靠得多。

🧭 這一課的重點

多模態提示原則與文字相同但要注意：圖片放在問題前、說明要看哪裡、先描述再分析以減少看錯、多張圖要標號。表格可用文字放入並說明欄位；需要精確計算時讓模型寫程式或用工具，比心算可靠。

✍️ 提示工程的最佳做法會隨模型世代改變；本課以目前主流模型（特別是 Claude）的實際行為為例，原則大多通用。Python 範例中標示「已執行」的為離線程式，輸出是實際結果；呼叫 API 的範例需要金鑰，模型名稱與參數以官方文件為準。
