X 光繞射與布拉格定律

這一課的目標

  • 理解布拉格定律
  • 了解 X 光繞射的歷史與應用
  • 學會從繞射圖推測晶體結構

勞厄的想法

1912 年，德國物理學家勞厄想到：如果 X 光是波長很短的電磁波，而晶體中的原子間距約為 10−10 公尺，那麼晶體就像一個天然的三維繞射光柵。他的同事做了實驗，果然在底片上看到規則排列的亮點。這一舉證明了兩件事：X 光是波，晶體中的原子確實規則排列。勞厄獲得 1914 年諾貝爾物理獎。

布拉格父子

1913 年，英國的布拉格父子（威廉．亨利．布拉格與威廉．勞倫斯．布拉格）提出了更直觀的解釋：把 X 光的繞射看成在一層一層的原子平面上的「反射」。

\[2d\sin\theta = n\lambda\]

從相鄰兩層平面反射的光，光程差是 2d sin θ。只有當它是波長的整數倍，兩道光才相長干涉。他們用這個方法解出了氯化鈉與鑽石的結構——第一次「看見」原子的排列。父子兩人同獲 1915 年諾貝爾物理獎；兒子勞倫斯當年 25 歲，至今仍是最年輕的諾貝爾物理獎得主。

從繞射圖到結構

粉末繞射把樣品磨成細粉，各種方向的晶粒都有，所以每一組晶面都會在特定的 2θ 產生一個繞射峰。峰的位置給出晶面間距（進而得到晶格常數與晶格類型），峰的強度反映晶胞中原子的種類與位置，峰的寬度可以估計晶粒的大小。每一種晶體都有獨特的「指紋」，資料庫中收錄了數十萬種，可以用來鑑定未知的物質（見〈分析化學〉）。

改變世界的繞射圖

  • DNA 雙螺旋（1953）：羅莎琳．富蘭克林拍攝的「51 號照片」的 X 形圖案，讓華生與克里克推斷出螺旋結構（見〈遺傳與 DNA〉）。
  • 蛋白質結構：1958 年肯德魯解出肌紅蛋白，至今蛋白質資料庫中大部分的結構都來自 X 光晶體學。
  • 藥物：霍奇金解出盤尼西林、維生素 B₁₂ 與胰島素的結構（1964 年諾貝爾化學獎）。

今天，同步輻射光源提供比實驗室強上億倍的 X 光（台灣新竹有國家同步輻射研究中心的台灣光子源）；電子與中子也能做繞射，各有所長：中子對輕原子（如氫）與磁結構特別敏感。

🧭 這一課的重點

1912 年勞厄想到晶體原子間距約 10^−10 公尺如三維繞射光柵，實驗看到規則亮點證明 X 光是波且原子規則排列，1914 年諾貝爾獎；1913 年布拉格父子把繞射看成原子平面的反射，2d sin θ = nλ，光程差為波長整數倍時相長干涉，解出氯化鈉與鑽石結構，1915 年同獲諾貝爾獎，勞倫斯 25 歲至今最年輕物理獎得主；粉末繞射各方向晶粒皆有，峰位置給晶面間距與晶格、強度反映原子種類位置、寬度估晶粒大小，資料庫數十萬種指紋可鑑定物質；1953 年富蘭克林 51 號照片 X 形圖案助華生克里克推斷 DNA 雙螺旋、1958 年肯德魯解出肌紅蛋白、霍奇金解盤尼西林維生素 B12 胰島素 1964 年諾貝爾化學獎；同步輻射強上億倍台灣新竹台灣光子源，電子與中子也能繞射，中子對氫與磁結構敏感。
