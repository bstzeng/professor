Face ID

這一課的目標

  • 理解結構光的原理
  • 了解 3D 臉部辨識的流程
  • 理解它與 2D 臉部辨識的差別

把圖案投在臉上

2017 年，蘋果在 iPhone X 推出 Face ID。它的核心是結構光：點陣投影器把三萬多個看不見的紅外光點投射到臉上；紅外線相機拍下這些光點。因為臉是立體的，光點落在鼻子、眼窩、臉頰上的位置會偏移——從偏移的程度，就能算出臉上每一點的深度，建立臉部的三維模型。這和第 12 課的飛時測距是不同的方法，但目的都是得到深度。

流程

  1. 泛光照明器發出均勻的紅外光，讓紅外線相機在黑暗中也能看到臉。
  2. 點陣投影器投出光點，取得深度圖。
  3. 專用的神經網路把紅外影像與深度圖轉換成數學表示，和註冊時的資料比對。
  4. 注意力偵測：檢查眼睛是否張開、正在看手機——避免在你睡著時被別人拿去解鎖。
  5. 比對的資料存在手機中受保護的安全晶片區域，不上傳到雲端。

為什麼比 2D 安全

只用一般前鏡頭拍照比對的 2D 臉部辨識，可能被一張照片、一段影片騙過。3D 的結構光能分辨平面的照片與立體的臉，也在紅外線下看不到螢幕上播放的影像。蘋果公布的數據是：隨機的另一個人能解鎖的機率約為百萬分之一（指紋約五萬分之一）；但雙胞胎、相貌相似的兄弟姊妹、13 歲以下的兒童，誤判的機率較高。

戴口罩、陽光直射、角度太偏時，辨識可能失敗——這是臉部辨識的實際限制。

🧭 這一課的重點

2017 年 iPhone X 推出 Face ID 核心是結構光點陣投影器投三萬多個紅外光點到臉上紅外線相機拍下，臉是立體的光點在鼻子眼窩臉頰位置偏移從偏移算出深度建三維模型；流程泛光照明器讓暗處也看得到、點陣取得深度圖、專用神經網路比對、注意力偵測眼睛張開正在看、資料存在安全晶片不上傳；2D 臉部辨識可能被照片影片騙過，3D 結構光分辨平面與立體，蘋果公布隨機他人解鎖約百萬分之一指紋約五萬分之一，雙胞胎兄弟姊妹 13 歲以下誤判較高；口罩陽光角度偏可能失敗。

📱 互動模擬為教學用的簡化模型；各廠牌手機使用的感測器與演算法不盡相同，規格會隨機型改變。
