狀態空間

這一課的目標

  • 理解狀態的概念
  • 理解狀態空間表示法
  • 理解它與古典方法的差別

系統的「狀態」

狀態是一組數字，只要知道它們（加上未來的輸入），就能完全預測系統未來的行為。例如一台車在直線上的狀態是「位置」與「速度」；一個倒單擺的狀態是「桿子的角度、角速度、底座的位置、底座的速度」。

狀態空間表示法

把系統寫成一組一階微分方程式，用矩陣表示：

dx／dt = A x + B u（狀態怎麼變化）
y = C x（我們量到什麼）

x 是狀態向量，u 是輸入，y 是輸出；A、B、C 是矩陣。A 的特徵值就是系統的極點（見第 16 課、〈線性代數〉）。

為什麼用狀態空間

  • 多輸入多輸出：飛機有很多個控制面、很多個感測器，彼此互相影響——古典的轉移函數方法處理起來很麻煩，狀態空間用矩陣就能自然地處理。
  • 內部的資訊：不只看輸入與輸出，還能看到系統內部的每一個狀態。
  • 電腦計算：矩陣運算非常適合電腦。
  • 現代控制理論的基礎：最佳控制、卡爾曼濾波、模型預測控制都建立在狀態空間上。

可控性與可觀性

  • 可控性：能不能透過輸入，把系統帶到任何想要的狀態？
  • 可觀性：能不能從量測到的輸出，推算出所有內部的狀態？

如果某個狀態既控制不到、又量不到，而它又不穩定——那就沒有任何控制器救得了。1960 年前後，卡爾曼等人建立了這些概念，開啟了「現代控制理論」。量不到的狀態，可以用觀測器（例如卡爾曼濾波器）從量得到的資訊估算出來（見〈手機裡的感測器〉的感測器融合）。

🧭 這一課的重點

狀態是一組數字知道它們加未來輸入就能完全預測系統行為，車是位置與速度、倒單擺是角度角速度底座位置速度；狀態空間 dx/dt = Ax + Bu、y = Cx，A 的特徵值就是極點；用狀態空間因為多輸入多輸出飛機多控制面感測器、能看內部狀態、矩陣適合電腦、是最佳控制卡爾曼濾波 MPC 基礎；可控性能否透過輸入帶到任何狀態、可觀性能否從輸出推算所有狀態，既控制不到又量不到且不穩定就救不了，1960 年前後卡爾曼建立開啟現代控制理論，量不到的狀態用觀測器如卡爾曼濾波器估算。
