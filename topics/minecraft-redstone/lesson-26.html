程式計數器與控制單元

這一課的目標

  • 理解程式計數器
  • 理解控制單元的工作
  • 理解微指令的概念

程式計數器

程式計數器（PC）是一個特別的暫存器，存放著下一條要執行的指令的位址。它本質上是一個計數器（第 22 課）：每執行完一條指令，就加 1。遇到跳躍指令時，它被直接改寫成新的位址。

控制單元

控制單元是 CPU 的指揮。它讀取指令的運算碼，用解碼器判斷是哪一種指令，然後在正確的時脈節拍，送出一連串的控制訊號：

  • 讓哪一個暫存器把資料放到匯流排上。
  • 讓 ALU 做哪一種運算（設定多工器的選擇訊號）。
  • 讓哪一個暫存器接收結果。
  • 程式計數器要加 1，還是載入跳躍的位址。

例如 ADD 指令，控制單元可能分成幾個步驟：（1）把 A、B 送進 ALU；（2）設定 ALU 為加法；（3）把結果存回 A；（4）更新旗標；（5）PC 加 1。

匯流排

CPU 的各個部分，透過一組共用的線路——匯流排——傳遞資料。同一時間只能有一個部分把資料放上匯流排，就像一條單線道。控制單元負責安排誰在什麼時候使用它。

在紅石 CPU 中，控制單元往往是最複雜的部分：一大片解碼器、多工器與時序電路，決定每一條指令的每一個步驟。

🧭 這一課的重點

程式計數器 PC 是存放下一條指令位址的特別暫存器，本質是計數器，每條指令後加 1，跳躍時被改寫成新位址；控制單元是 CPU 的指揮，讀取運算碼用解碼器判斷指令，在正確時脈節拍送出控制訊號：哪個暫存器把資料放上匯流排、ALU 做哪種運算、哪個暫存器接收結果、PC 加 1 或載入跳躍位址，如 ADD 分成送入 ALU、設定加法、存回 A、更新旗標、PC 加 1；各部分透過共用的匯流排傳資料，同時只能一個部分使用像單線道；紅石 CPU 中控制單元往往最複雜。
