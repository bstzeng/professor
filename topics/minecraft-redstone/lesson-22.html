計數器與暫存器

這一課的目標

  • 理解二進位計數器
  • 理解暫存器與移位暫存器
  • 了解它們在 CPU 中的角色

計數器

把幾個 T 正反器串起來：第一個接時脈，第二個接第一個的輸出，依此類推。第一個每個脈衝翻轉一次，第二個每兩個脈衝翻轉一次，第三個每四個……把它們的輸出合起來讀，正好是 0、1、2、3、……的二進位數！

脈衝數Q2Q1Q0
0000
1001
2010
3011
4100

計數器的用途：計時、數有幾個物品通過、以及 CPU 中的程式計數器（第 26 課）。

暫存器

暫存器是一組 D 正反器，在 CPU 內部暫時存放資料：要相加的兩個數、計算的結果、下一條指令的位址。它是電腦中最快的記憶體，但數量很少（一般的 CPU 只有幾十個）。

移位暫存器

把 D 正反器串成一列，每一個的輸出接到下一個的輸入：每個時脈，資料就往旁邊移一格。它可以把一次一個位元進來的串列資料，轉換成同時並排的並列資料（或者反過來）。USB、序列埠的傳輸，都用到這個原理。

在 Minecraft 中，玩家用移位暫存器做出跑馬燈、密碼鎖（依序輸入正確的按鈕組合）、甚至音樂盒（用音符方塊依序播放）。

🧭 這一課的重點

把 T 正反器串起來，第一個接時脈、後面接前一個的輸出，第一個每脈衝翻轉、第二個每兩個、第三個每四個，合起來讀正好是二進位的 0、1、2、3，用於計時、計數物品與程式計數器；暫存器是一組 D 正反器在 CPU 內暫存資料，是最快的記憶體但只有幾十個；移位暫存器把 D 正反器串成一列每個時脈資料移一格，可把串列資料轉成並列，USB 與序列埠用到，Minecraft 玩家用來做跑馬燈、密碼鎖、音樂盒。

🟥 本課程以 Minecraft Java 版的紅石機制為主（基岩版有些許不同）；互動元件是簡化的模擬。
