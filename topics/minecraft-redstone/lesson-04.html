中繼器與比較器

這一課的目標

  • 理解中繼器的功能
  • 理解比較器的兩種模式
  • 認識它們在電路中的用途

中繼器

紅石中繼器在 2011 年加入遊戲，有四個功能：

  1. 補強：把任何強度大於 0 的訊號，補回 15。
  2. 延遲：可以設定 1～4 個紅石刻（0.1～0.4 秒）的延遲。
  3. 單向：訊號只能從後方進、前方出，可以防止訊號倒流。
  4. 鎖定：如果另一個中繼器從側面對它充能，它會被鎖住，保持目前的輸出不變——這可以用來做記憶（第 20 課）。

比較器

紅石比較器在 2013 年的「紅石更新」中加入。它有後方一個輸入、兩側的側面輸入，以及兩種模式：

  • 比較模式：如果後方的訊號強度 ≥ 側面的強度，就輸出後方的強度；否則輸出 0。
  • 減法模式：輸出 = 後方強度 − 側面強度（最小為 0）。

比較器還能「讀取」容器的內容：放在箱子、熔爐、漏斗旁邊，它會依照容器有多滿，輸出 0～15 的訊號。這讓玩家能做出自動倉庫、物品分類機。

類比計算

比較器能處理 0～15 的訊號強度，所以可以做「類比」的計算：比較大小、相減。有些玩家利用它，做出了用一條線傳送 16 種數值的「十六進位」電路，比二進位更省空間。

🧭 這一課的重點

紅石中繼器 2011 年加入，四個功能：把大於 0 的訊號補回 15、設定 1～4 個紅石刻延遲、只能從後進前出防止倒流、被側面中繼器充能時鎖住保持輸出可做記憶；比較器 2013 年紅石更新加入，比較模式後方 ≥ 側面就輸出後方強度否則 0，減法模式輸出後方減側面，還能依箱子熔爐漏斗多滿輸出 0～15 做自動倉庫與分類機；比較器能做比較與相減的類比計算，有玩家做出一條線傳 16 種數值的十六進位電路。

🟥 本課程以 Minecraft Java 版的紅石機制為主（基岩版有些許不同）；互動元件是簡化的模擬。
