人在迴路

這一課的目標

  • 依風險分級設計核准機制
  • 讓被拒絕的動作回饋給模型
  • 在自主與安全之間取得平衡

代理越自主，越需要在關鍵時刻讓人介入。人在迴路（human-in-the-loop）的做法是：依動作的風險分級，決定要不要先問人。

風險例子做法
低讀檔、搜尋自動放行
中修改檔案第一次問，之後同類動作放行
高（不可逆）刪除、付款、寄信、推送到正式環境每次都問

被拒絕時，也要回傳一個 tool_result（例如「使用者拒絕了這個動作」，標記 is_error），讓模型知道並調整計畫，而不是假裝沒發生。

Claude Code 的權限模式正是這個概念：預設模式改檔與執行指令前會詢問；也可以切成「自動接受修改」或「只規劃不動手」（plan 模式）。Codex 也有類似的核准等級。太多詢問讓人疲勞、太少則有風險，要依任務調整。

🐍 Python 範例（離線版）　下載 g40_approval.py　需同資料夾的 mockllm.py

讀檔自動放行，寫檔與刪檔詢問後允許，寄信被拒絕——模型收到拒絕訊息後調整回覆。

# -*- coding: utf-8 -*- """第 40 課：人在迴路（human-in-the-loop）——危險動作執行前先問人。 依風險分級：讀取＝自動放行；寫入＝問一次；不可逆（刪除、付款、寄信）＝每次都問。""" import json from mockllm import MockClient, text, tool_use RISK = {"read_file": "low", "write_file": "medium", "delete_file": "high", "send_email": "high"} FS = {"draft.md": "草稿", "old.log": "舊紀錄"} approved_once = set() def ask_human(name, args, answers): """真實程式用 input()；這裡用預先準備的答案模擬使用者的選擇。""" ans = answers.pop(0) print(" 🙋 代理想執行 %s(%s)，允許嗎？[y/n] → %s" % (name, json.dumps(args, ensure_ascii=False), ans)) return ans == "y" def gate(name, args, answers): r = RISK[name] if r == "low" or (r == "medium" and name in approved_once): return True ok = ask_human(name, args, answers) if ok and r == "medium": approved_once.add(name) return ok IMPL = {"read_file": lambda path: FS[path], "write_file": lambda path, text: FS.__setitem__(path, text) or "ok", "delete_file": lambda path: FS.pop(path) and "deleted", "send_email": lambda to, body: "sent"} PLAN = [tool_use("read_file", {"path": "draft.md"}), tool_use("write_file", {"path": "draft.md", "text": "定稿"}), tool_use("delete_file", {"path": "old.log"}), tool_use("send_email", {"to": "boss@co.com", "body": "定稿完成"})] client = MockClient(lambda ctx: PLAN[ctx.turn] if ctx.turn < len(PLAN) else text("處理完畢（被拒絕的動作已略過）。")) tools = [{"name": n, "description": n, "input_schema": {"type": "object"}} for n in RISK] msgs, answers = [{"role": "user", "content": "把草稿定稿、清掉舊紀錄，然後寄信給老闆"}], ["y", "y", "n"] while True: r = client.messages.create(model="mock", max_tokens=500, tools=tools, messages=msgs) msgs.append({"role": "assistant", "content": r.content}) if r.stop_reason != "tool_use": break b = r.content[0] if gate(b.name, b.input, answers): res = {"type": "tool_result", "tool_use_id": b.id, "content": str(IMPL[b.name](**b.input))} print(" ✓ 執行 %s（風險：%s）" % (b.name, RISK[b.name])) else: # 被拒絕也要回 tool_result，讓模型知道並調整 res = {"type": "tool_result", "tool_use_id": b.id, "content": "使用者拒絕了這個動作", "is_error": True} print(" ✗ 使用者拒絕 %s" % b.name) msgs.append({"role": "user", "content": [res]}) print(r.content[0].text, "目前檔案：", FS)

▶ 執行結果（這是實際執行的輸出）

✓ 執行 read_file（風險：low） 🙋 代理想執行 write_file({"path": "draft.md", "text": "定稿"})，允許嗎？[y/n] → y ✓ 執行 write_file（風險：medium） 🙋 代理想執行 delete_file({"path": "old.log"})，允許嗎？[y/n] → y ✓ 執行 delete_file（風險：high） 🙋 代理想執行 send_email({"to": "boss@co.com", "body": "定稿完成"})，允許嗎？[y/n] → n ✗ 使用者拒絕 send_email 處理完畢（被拒絕的動作已略過）。 目前檔案： {'draft.md': '定稿'}
☁️ Claude API 版（換成真的 Claude，點我展開）

需要 pip install anthropic 並設定環境變數 ANTHROPIC_API_KEY；會實際呼叫 API 並計費。下載 g40_approval.py

# -*- coding: utf-8 -*- """第 40 課（Claude API 版）：在工具迴圈中加入核准關卡。被拒絕時一樣要回 tool_result（is_error），Claude 才知道要調整。""" import anthropic client = anthropic.Anthropic() RISK = {"read_file": "low", "delete_file": "high"} tools = [{"name": "read_file", "description": "讀取檔案", "input_schema": { "type": "object", "properties": {"path": {"type": "string"}}, "required": ["path"]}}, {"name": "delete_file", "description": "刪除檔案（不可復原）", "input_schema": { "type": "object", "properties": {"path": {"type": "string"}}, "required": ["path"]}}] def execute(name, args): return "（示範）已執行 %s %s" % (name, args) messages = [{"role": "user", "content": "看一下 old.log 的內容，如果沒用就刪掉。"}] while True: r = client.messages.create(model="claude-opus-5-5", max_tokens=16000, tools=tools, messages=messages) messages.append({"role": "assistant", "content": r.content}) if r.stop_reason != "tool_use": break results = [] for b in r.content: if b.type != "tool_use": continue if RISK[b.name] == "high" and input("允許執行 %s %s？[y/N] " % (b.name, b.input)).strip().lower() != "y": results.append({"type": "tool_result", "tool_use_id": b.id, "content": "使用者拒絕了這個動作", "is_error": True}) else: results.append({"type": "tool_result", "tool_use_id": b.id, "content": execute(b.name, b.input)}) messages.append({"role": "user", "content": results}) print(next(b.text for b in r.content if b.type == "text"))

🧭 這一課的重點

人在迴路依風險分級：讀取自動放行、修改可詢問一次、不可逆動作每次都問；被拒絕時也要回傳 tool_result 讓模型調整。Claude Code 與 Codex 的權限模式就是此概念，詢問太多或太少都要依任務權衡。

🤖 本課的 Python 範例分兩版：離線版用一個模仿 Anthropic SDK 介面的「假 LLM」（mockllm.py），不需 API 金鑰即可執行，頁面上的輸出就是實際執行的結果；Claude API 版使用官方 anthropic 套件，需要 API 金鑰、會產生費用。API 細節（模型名稱、beta 功能）會隨時間更新，以官方文件為準。
