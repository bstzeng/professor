呼叫 LLM API：訊息與角色

這一課的目標

  • 認識 Messages API 的基本結構
  • 理解 API 是無狀態的
  • 學會維護多輪對話歷史

使用 Claude 這類模型時，你的程式會呼叫一個 API。最核心的參數有三個：model（用哪個模型）、max_tokens（這次最多輸出多少）、messages（對話內容）。另外常用 system（系統提示）設定角色與規則。

角色誰說的例子
system開發者（你）「你是客服助理，用繁體中文回答。」
user使用者，或工具結果「我的訂單到哪了？」
assistant模型「我幫你查一下。」

最重要的觀念：API 是無狀態的。伺服器不會幫你記住對話——每次呼叫，你都要把整段歷史重新送過去。模型「記得」你的名字，只是因為那句話還在你送去的 messages 裡。

這件事對代理影響深遠：代理每跑一輪，歷史就變長一點，下一次要送的內容就更多。第 20 課起我們會處理這個問題。

🐍 Python 範例（離線版）　下載 a03_messages.py　需同資料夾的 mockllm.py

維護一個 history 清單，每輪把使用者訊息和模型回應都加進去。最後示範：如果不送歷史，模型就真的「忘了」。

# -*- coding: utf-8 -*- """第 3 課：呼叫 LLM API 的基本形狀——system、messages、角色交替。 API 是「無狀態」的：每次呼叫都要把整段對話重新送過去。""" from mockllm import MockClient, text def policy(ctx): # 假模型：能「記得」名字，只因為整段歷史每次都被送進來 for m in ctx.messages: if m["role"] == "user" and "我叫" in m["content"]: name = m["content"].split("我叫")[1].strip("。 ") if "名字" in ctx.user_text(): return text("你叫%s。（我是從你送來的對話歷史裡讀到的）" % name) if "名字" in ctx.user_text(): return text("我不知道你的名字——這次送來的訊息裡沒有提到。") return text("你好！（system 要我：%s）" % ctx.system) client = MockClient(policy) system = "用繁體中文、一句話回答。" history = [] def send(msg): history.append({"role": "user", "content": msg}) r = client.messages.create(model="mock", max_tokens=300, system=system, messages=history) history.append({"role": "assistant", "content": r.content}) print("使用者：%s\n模型　：%s (送出 %d tokens)" % (msg, r.content[0].text, r.usage.input_tokens)) send("嗨，我叫小安。") send("我的名字是什麼？") print("\n歷史共有 %d 則訊息，角色依序：%s" % (len(history), [m["role"] for m in history])) # 如果「忘了」把歷史送回去，模型就真的不知道： r = client.messages.create(model="mock", max_tokens=300, system=system, messages=[{"role": "user", "content": "我的名字是什麼？"}]) print("不送歷史 →", r.content[0].text)

▶ 執行結果（這是實際執行的輸出）

使用者：嗨，我叫小安。 模型　：你好！（system 要我：用繁體中文、一句話回答。） (送出 38 tokens) 使用者：我的名字是什麼？ 模型　：你叫小安。（我是從你送來的對話歷史裡讀到的） (送出 92 tokens) 歷史共有 4 則訊息，角色依序：['user', 'assistant', 'user', 'assistant'] 不送歷史 → 我不知道你的名字——這次送來的訊息裡沒有提到。
☁️ Claude API 版（換成真的 Claude，點我展開）

需要 pip install anthropic 並設定環境變數 ANTHROPIC_API_KEY；會實際呼叫 API 並計費。下載 a03_messages.py

# -*- coding: utf-8 -*- """第 3 課（Claude API 版）：system + 多輪 messages。API 無狀態，每次送完整歷史。""" import anthropic client = anthropic.Anthropic() MODEL = "claude-opus-5-5" system = "用繁體中文、一句話回答。" history = [] def send(msg): history.append({"role": "user", "content": msg}) r = client.messages.create(model=MODEL, max_tokens=16000, system=system, messages=history) history.append({"role": "assistant", "content": r.content}) reply = next(b.text for b in r.content if b.type == "text") print("使用者：%s\n Claude：%s (input=%d, output=%d tokens)" % (msg, reply, r.usage.input_tokens, r.usage.output_tokens)) send("嗨，我叫小安。") send("我的名字是什麼？")

回應的 content 是一個區塊清單，每個區塊有 type：text（文字）、tool_use（要求使用工具）、thinking（思考）等。代理程式的工作，就是讀懂這些區塊並做出反應。

🧭 這一課的重點

Messages API 的核心是 model、max_tokens、messages，加上 system 設定角色；角色有 system、user、assistant。API 無狀態，每次都要送完整歷史，所以代理的歷史會越來越長。回應是由 text、tool_use、thinking 等區塊組成的清單。

🤖 本課的 Python 範例分兩版：離線版用一個模仿 Anthropic SDK 介面的「假 LLM」（mockllm.py），不需 API 金鑰即可執行，頁面上的輸出就是實際執行的結果；Claude API 版使用官方 anthropic 套件，需要 API 金鑰、會產生費用。API 細節（模型名稱、beta 功能）會隨時間更新，以官方文件為準。
