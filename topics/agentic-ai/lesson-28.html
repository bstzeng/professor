讀寫檔案

這一課的目標

  • 設計檔案操作工具
  • 用 str_replace 做精確修改
  • 防止路徑穿越攻擊

程式代理最常用的工具就是檔案操作。常見的設計是三四個動作：view（看檔案或目錄，附行號）、create（建立或覆寫）、str_replace（取代一段文字）、insert（在某行後插入）。

為什麼修改用 str_replace 而不是「整份重寫」或「改第 N 行」？

  • 整份重寫：大檔案很浪費 token，也容易不小心改到別處。
  • 依行號修改：模型讀檔後行號可能已經變了，容易對錯行。
  • str_replace：指定「把這段原文換成那段」，而且要求原文剛好出現一次——出現 0 次或多次都報錯，請模型多帶一點上下文。精確又安全。

路徑穿越

模型給的路徑是不可信的。../../etc/passwd 或絕對路徑都可能讀到專案外的檔案。正確做法：把路徑解析成絕對路徑（resolve），再確認它仍在專案根目錄之內。

Claude API 有 Anthropic 定義的文字編輯工具（不需要寫 schema，模型已經熟悉用法），你只要實作上述動作。

🐍 Python 範例（離線版）　下載 e28_files.py　需同資料夾的 mockllm.py

實作三個檔案工具，示範 str_replace 遇到多處相符時拒絕，以及擋下 ../ 路徑穿越。

# -*- coding: utf-8 -*- """第 28 課：檔案工具——view / create / str_replace，全部限制在專案根目錄內（防止 ../ 路徑穿越）。""" import os import tempfile from pathlib import Path ROOT = Path(tempfile.mkdtemp(prefix="agent_ws_")).resolve() def safe(path): p = (ROOT / path).resolve() if not p.is_relative_to(ROOT): raise PermissionError("拒絕：%s 在專案目錄之外" % path) return p def view(path): p = safe(path) if p.is_dir(): return "\n".join(sorted(x.name for x in p.iterdir())) return "\n".join("%4d %s" % (i, l) for i, l in enumerate(p.read_text(encoding="utf-8").splitlines(), 1)) def create(path, file_text): p = safe(path) p.parent.mkdir(parents=True, exist_ok=True) p.write_text(file_text, encoding="utf-8") return "已建立 %s（%d 行）" % (path, file_text.count("\n") + 1) def str_replace(path, old_str, new_str): """只取代『剛好出現一次』的字串——出現 0 次或多次都報錯，避免改錯地方。""" p = safe(path) s = p.read_text(encoding="utf-8") n = s.count(old_str) if n != 1: raise ValueError("old_str 出現 %d 次，必須剛好 1 次；請提供更多上下文" % n) p.write_text(s.replace(old_str, new_str), encoding="utf-8") return "已修改 %s" % path print(create("app/config.py", "DEBUG = True\nPORT = 8000\nHOST = 'localhost'")) print(view("app/config.py")) print(str_replace("app/config.py", "DEBUG = True", "DEBUG = False")) for call in [lambda: str_replace("app/config.py", "=", ":"), lambda: view("../../etc/passwd")]: try: call() except Exception as e: print("✗", type(e).__name__, e) print(view("app/config.py"))

▶ 執行結果（這是實際執行的輸出）

已建立 app/config.py（3 行） 1 DEBUG = True 2 PORT = 8000 3 HOST = 'localhost' 已修改 app/config.py ✗ ValueError old_str 出現 3 次，必須剛好 1 次；請提供更多上下文 ✗ PermissionError 拒絕：../../etc/passwd 在專案目錄之外 1 DEBUG = False 2 PORT = 8000 3 HOST = 'localhost'
☁️ Claude API 版（換成真的 Claude，點我展開）

需要 pip install anthropic 並設定環境變數 ANTHROPIC_API_KEY；會實際呼叫 API 並計費。下載 e28_files.py

# -*- coding: utf-8 -*- """第 28 課（Claude API 版）：Anthropic 定義的文字編輯工具（text_editor_20250728）。 不用寫 input_schema——Claude 已經知道怎麼用；你負責實作 view / create / str_replace / insert。""" import tempfile from pathlib import Path import anthropic client = anthropic.Anthropic() ROOT = Path(tempfile.mkdtemp()).resolve() (ROOT / "config.py").write_text("DEBUG = True\nPORT = 8000\n", encoding="utf-8") def safe(path): p = (ROOT / path.lstrip("/")).resolve() if not p.is_relative_to(ROOT): raise PermissionError("路徑在專案目錄之外") return p def editor(inp): cmd, p = inp["command"], safe(inp["path"]) if cmd == "view": return p.read_text(encoding="utf-8") if p.is_file() else "\n".join(x.name for x in p.iterdir()) if cmd == "create": p.write_text(inp["file_text"], encoding="utf-8") return "已建立" if cmd == "str_replace": s = p.read_text(encoding="utf-8") if s.count(inp["old_str"]) != 1: raise ValueError("old_str 必須剛好出現一次") p.write_text(s.replace(inp["old_str"], inp["new_str"]), encoding="utf-8") return "已修改" if cmd == "insert": lines = p.read_text(encoding="utf-8").split("\n") lines.insert(inp["insert_line"], inp["insert_text"]) p.write_text("\n".join(lines), encoding="utf-8") return "已插入" raise ValueError("未知指令 " + cmd) tools = [{"type": "text_editor_20250728", "name": "str_replace_based_edit_tool"}] messages = [{"role": "user", "content": "把 /config.py 的 DEBUG 關掉，並把 PORT 改成 8080。"}] while True: r = client.messages.create(model="claude-opus-5-5", max_tokens=16000, tools=tools, messages=messages) messages.append({"role": "assistant", "content": r.content}) if r.stop_reason != "tool_use": break results = [] for b in r.content: if b.type == "tool_use": try: results.append({"type": "tool_result", "tool_use_id": b.id, "content": editor(b.input)}) except Exception as e: results.append({"type": "tool_result", "tool_use_id": b.id, "content": str(e), "is_error": True}) messages.append({"role": "user", "content": results}) print((ROOT / "config.py").read_text(encoding="utf-8"))

🧭 這一課的重點

檔案工具常見 view、create、str_replace、insert；修改用 str_replace 並要求原文剛好出現一次，比整份重寫或依行號修改更精確安全。所有路徑都要解析後確認仍在專案根目錄內，以防路徑穿越。

🤖 本課的 Python 範例分兩版：離線版用一個模仿 Anthropic SDK 介面的「假 LLM」（mockllm.py），不需 API 金鑰即可執行，頁面上的輸出就是實際執行的結果；Claude API 版使用官方 anthropic 套件，需要 API 金鑰、會產生費用。API 細節（模型名稱、beta 功能）會隨時間更新，以官方文件為準。
