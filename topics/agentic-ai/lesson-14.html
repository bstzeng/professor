思考：讓模型先想再答

這一課的目標

  • 理解「先思考」為什麼能提升正確率
  • 認識 thinking 區塊
  • 用 effort 控制思考深度與成本

「球棒和球共 110 元，球棒比球貴 100 元，球多少錢？」直覺答案是 10 元，但正確答案是 5 元。人需要停下來想一想，模型也是。

現代的 LLM 可以在回答前先產生一段思考（回應中的 thinking 區塊）：拆解問題、列出步驟、自我檢查。對代理來說更重要的是工具之間的思考：看到工具結果後，先想清楚它代表什麼、下一步該做什麼，再行動。

在 Claude 最新的模型上，思考是自適應（adaptive）的：模型自己判斷需要想多少。你用 effort（low、medium、high、xhigh、max）控制整體的深度與 token 花費。簡單任務用 low 省錢，困難的程式與長時程任務用 high 以上。

思考也要付費

思考的 token 算在輸出裡，要付費、也會增加延遲。思考內容預設不回傳（只回傳空白的 thinking 區塊）；需要看時可設定 display 為 summarized，取得可讀的摘要。

🐍 Python 範例（離線版）　下載 c14_thinking.py　需同資料夾的 mockllm.py

假模型示範：不思考時直覺答錯，思考時拆步驟答對。Claude API 版比較 low 與 high 兩種 effort。

# -*- coding: utf-8 -*- """第 14 課：先想再答。回應裡多了一種 thinking 區塊；代理在每次呼叫工具之前也可以先想。 這個假模型示範：不想 → 直覺答錯；先想 → 拆步驟答對。""" from mockllm import MockClient, text, thinking Q = "球棒和球共 110 元，球棒比球貴 100 元，球多少錢？" def policy(ctx): if ctx.extra.get("thinking"): return [thinking("設球 x 元，球棒 x+100。x + (x+100) = 110 → 2x = 10 → x = 5。驗算：5 + 105 = 110 ✓"), text("球 5 元。")] return text("球 10 元。") # 直覺答案（錯） client = MockClient(policy) for think in (False, True): kw = {"thinking": {"type": "adaptive"}} if think else {} r = client.messages.create(model="mock", max_tokens=2000, messages=[{"role": "user", "content": Q}], **kw) print("思考%s：" % ("開" if think else "關")) for b in r.content: print(" [%s] %s" % (b.type, b.thinking if b.type == "thinking" else b.text)) print(" output tokens = %d（思考也要算錢）" % r.usage.output_tokens)

▶ 執行結果（這是實際執行的輸出）

思考關： [text] 球 10 元。 output tokens = 11（思考也要算錢） 思考開： [thinking] 設球 x 元，球棒 x+100。x + (x+100) = 110 → 2x = 10 → x = 5。驗算：5 + 105 = 110 ✓ [text] 球 5 元。 output tokens = 46（思考也要算錢）
☁️ Claude API 版（換成真的 Claude，點我展開）

需要 pip install anthropic 並設定環境變數 ANTHROPIC_API_KEY；會實際呼叫 API 並計費。下載 c14_thinking.py

# -*- coding: utf-8 -*- """第 14 課（Claude API 版）：adaptive thinking 與 effort。 Claude Opus 5.5 的思考一律開啟（由模型自行決定想多少），用 output_config.effort 控制深度； display="summarized" 會回傳可讀的思考摘要（預設是 omitted，thinking 文字為空）。""" import anthropic client = anthropic.Anthropic() Q = "球棒和球共 110 元，球棒比球貴 100 元，球多少錢？" for effort in ("low", "high"): r = client.messages.create( model="claude-opus-5-5", max_tokens=16000, thinking={"type": "adaptive", "display": "summarized"}, output_config={"effort": effort}, messages=[{"role": "user", "content": Q}], ) print("== effort=%s output_tokens=%d" % (effort, r.usage.output_tokens)) for b in r.content: if b.type == "thinking": print("[思考摘要]", b.thinking[:200]) elif b.type == "text": print("[回答]", b.text)

🧭 這一課的重點

讓模型先思考能提升正確率，對代理尤其重要的是工具之間的思考。新的 Claude 模型採自適應思考，用 effort 控制深度與花費；思考 token 計入輸出要付費，預設不回傳全文。

🤖 本課的 Python 範例分兩版：離線版用一個模仿 Anthropic SDK 介面的「假 LLM」（mockllm.py），不需 API 金鑰即可執行，頁面上的輸出就是實際執行的結果；Claude API 版使用官方 anthropic 套件，需要 API 金鑰、會產生費用。API 細節（模型名稱、beta 功能）會隨時間更新，以官方文件為準。
