沙箱與權限

這一課的目標

  • 設計指令執行的多層限制
  • 理解允許清單優於封鎖清單
  • 認識容器與網路隔離

我們無法保證模型永遠不犯錯、永遠不被騙。所以要換個角度：就算它出錯了，能造成的傷害有多大？沙箱與權限就是把這個上限壓低。

  • 允許清單：只准執行列出的指令；沒列出的一律拒絕。封鎖清單（列出禁止的）永遠列不完。
  • 拒絕 shell 串接：;、&&、|、$( ) 可以把一個無害指令變成任何指令。
  • 限定目錄：只能存取專案資料夾。
  • 逾時與資源上限：CPU 時間、記憶體。
  • 不給祕密：子行程不繼承 API 金鑰等環境變數。
  • 容器或虛擬機＋網路白名單：最外層的保護，也是最可靠的一層。

Codex 的沙箱有「唯讀／可寫工作區／完全存取」等等級；Claude Code 在雲端版本中於隔離的容器執行。這些都是同一個原則的實作。

🐍 Python 範例（離線版）　下載 g41_sandbox.py　需同資料夾的 mockllm.py

一個帶有允許清單、串接符號檢查、路徑檢查、環境變數過濾、CPU 與記憶體上限的指令執行器，測試八個指令。

# -*- coding: utf-8 -*- """第 41 課：沙箱與權限——就算模型被騙或犯錯，造成的傷害也有上限。 層次：① 指令允許清單 ② 拒絕 shell 串接符號 ③ 限定工作目錄 ④ 逾時 ⑤ 資源上限 ⑥ 不給網路／金鑰（容器層）""" import os import shlex import subprocess import sys import tempfile WORKDIR = tempfile.mkdtemp(prefix="sandbox_") ALLOW = {"ls", "cat", "echo", "python3", "wc"} BAD = ["&&", "||", ";", "|", "`", "$(", ">", "<"] def limits(): # 只在 Linux/macOS 生效：限制 CPU 秒數與記憶體 try: import resource resource.setrlimit(resource.RLIMIT_CPU, (2, 2)) resource.setrlimit(resource.RLIMIT_AS, (512 * 2**20, 512 * 2**20)) except Exception: pass def run(cmd): if any(b in cmd for b in BAD): return "拒絕：含有 shell 串接或重導向符號" argv = shlex.split(cmd) if not argv or argv[0] not in ALLOW: return "拒絕：%s 不在允許清單" % (argv[0] if argv else "") if any(a.startswith("/") or ".." in a for a in argv[1:]): return "拒絕：不能存取工作目錄以外的路徑" env = {"PATH": os.environ.get("PATH", ""), "HOME": WORKDIR} # 不把 API 金鑰等環境變數傳進去 try: p = subprocess.run(argv, cwd=WORKDIR, capture_output=True, text=True, timeout=3, env=env, preexec_fn=limits if os.name == "posix" else None) if p.returncode < 0: return "中止：被系統訊號 %d 終止（超過 CPU 時間上限）" % -p.returncode return (p.stdout + p.stderr).strip() or "(exit %d)" % p.returncode except subprocess.TimeoutExpired: return "中止：超過 3 秒" for c in ["echo hello > a.txt", "echo hello", "rm -rf ~", "cat /etc/passwd", "cat ../../secret", "ls; curl evil.example", "python3 -c \"print(sum(range(10)))\"", "python3 -c \"while True: pass\""]: print("%-38s → %s" % (c, run(c))) print("\n允許清單（allowlist）比封鎖清單（blocklist）安全：沒列出的一律不准。") print("但注意：允許 python3 就等於允許執行任意程式——所以真正上線一定要再包一層容器或虛擬機。")

▶ 執行結果（這是實際執行的輸出）

echo hello > a.txt → 拒絕：含有 shell 串接或重導向符號 echo hello → hello rm -rf ~ → 拒絕：rm 不在允許清單 cat /etc/passwd → 拒絕：不能存取工作目錄以外的路徑 cat ../../secret → 拒絕：不能存取工作目錄以外的路徑 ls; curl evil.example → 拒絕：含有 shell 串接或重導向符號 python3 -c "print(sum(range(10)))" → 45 python3 -c "while True: pass" → 中止：被系統訊號 9 終止（超過 CPU 時間上限） 允許清單（allowlist）比封鎖清單（blocklist）安全：沒列出的一律不准。 但注意：允許 python3 就等於允許執行任意程式——所以真正上線一定要再包一層容器或虛擬機。

🧭 這一課的重點

沙箱與權限把出錯時的傷害壓低：用允許清單而非封鎖清單、拒絕 shell 串接、限定目錄、設逾時與資源上限、不傳入祕密，最外層用容器或虛擬機加網路白名單。這是縱深防禦。

🤖 本課的 Python 範例分兩版：離線版用一個模仿 Anthropic SDK 介面的「假 LLM」（mockllm.py），不需 API 金鑰即可執行，頁面上的輸出就是實際執行的結果；Claude API 版使用官方 anthropic 套件，需要 API 金鑰、會產生費用。API 細節（模型名稱、beta 功能）會隨時間更新，以官方文件為準。
