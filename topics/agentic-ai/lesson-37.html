多代理的代價與陷阱

這一課的目標

  • 估算多代理的 token 與成本
  • 認識多代理常見的失敗
  • 判斷任務是否適合多代理

多代理聽起來很厲害，但代價實在。Anthropic 分享研究系統的經驗時提到：代理通常比一般聊天多用約 4 倍 token，多代理系統更可達約 15 倍。效果確實更好，但只有在任務價值夠高時才划算。

陷阱說明
token 倍增每個代理都要讀背景、自己探索
協調失誤子任務重疊、遺漏，或彼此結論矛盾
資訊遺失摘要時丟掉了關鍵細節
除錯困難出錯時要追蹤好幾個代理的軌跡
緊密相依的任務多個代理同時改同一段程式，容易互相衝突

判斷原則：子任務彼此獨立、可平行、資訊量大（研究、大量檔案審查）適合多代理；步驟緊密相依、需要共享大量上下文（例如一起改同一個功能的程式碼）通常單一代理更好。

🐍 Python 範例（離線版）　下載 f37_costs.py　需同資料夾的 mockllm.py

同一個任務，比較單一代理與「一個協調者＋六個工作者」的 token 與成本。

# -*- coding: utf-8 -*- """第 37 課：多代理的代價——token 用量會倍增，協調也會出錯。先算清楚再決定。""" PRICE = {"claude-opus-5-5": (4.0, 20.0), "claude-sonnet-5-5": (2.0, 10.0), "claude-haiku-4-5": (1.0, 5.0)} # 美元／百萬 tokens def cost(model, inp, out): pi, po = PRICE[model] return (inp * pi + out * po) / 1e6 def agent_run(model, turns, base_ctx, growth, out_per_turn): """一個代理跑 turns 輪：每輪重送整段上下文，上下文每輪增加 growth。""" inp = sum(base_ctx + growth * t for t in range(turns)) return cost(model, inp, out_per_turn * turns), inp + out_per_turn * turns single, st = agent_run("claude-opus-5-5", 30, 8000, 3000, 800) print("單一代理（Opus 5.5，30 輪）：%7.2f 美元，%9d tokens" % (single, st)) orch, ot = agent_run("claude-opus-5-5", 10, 8000, 2000, 800) # 每個工作者都要重新讀背景資料、自己探索，所以各自的上下文也會長大 workers = [agent_run("claude-sonnet-5-5", 20, 8000, 3000, 800) for _ in range(6)] multi = orch + sum(c for c, _ in workers) mt = ot + sum(t for _, t in workers) print("多代理（Opus 協調 + 6 個 Sonnet 工作者）：%5.2f 美元，%9d tokens" % (multi, mt)) print("\ntoken 是單一代理的 %.1f 倍；工作者改用較便宜的模型，成本只是 %.1f 倍。值得嗎？看任務：" % (mt / st, multi / single)) for k, v in [("✓ 適合", "可平行、彼此獨立、資訊量大（研究、大量檔案審查）"), ("✗ 不適合", "步驟緊密相依、需要共享大量上下文（例如：多人同時改同一段程式碼）")]: print(" %s：%s" % (k, v))

▶ 執行結果（這是實際執行的輸出）

單一代理（Opus 5.5，30 輪）： 6.66 美元， 1569000 tokens 多代理（Opus 協調 + 6 個 Sonnet 工作者）：10.56 美元， 4654000 tokens token 是單一代理的 3.0 倍；工作者改用較便宜的模型，成本只是 1.6 倍。值得嗎？看任務： ✓ 適合：可平行、彼此獨立、資訊量大（研究、大量檔案審查） ✗ 不適合：步驟緊密相依、需要共享大量上下文（例如：多人同時改同一段程式碼）

🧭 這一課的重點

多代理的代價包括 token 倍增、協調失誤、摘要遺失資訊與除錯困難；Anthropic 經驗是代理約為聊天的 4 倍 token、多代理約 15 倍。子任務獨立、可平行、資訊量大時才適合，步驟緊密相依的任務用單一代理較好。

🤖 本課的 Python 範例分兩版：離線版用一個模仿 Anthropic SDK 介面的「假 LLM」（mockllm.py），不需 API 金鑰即可執行，頁面上的輸出就是實際執行的結果；Claude API 版使用官方 anthropic 套件，需要 API 金鑰、會產生費用。API 細節（模型名稱、beta 功能）會隨時間更新，以官方文件為準。
