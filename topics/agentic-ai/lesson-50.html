模組 H｜實務與未來 · 第 50 課

代理的極限與常見失敗

這一課的目標

  • 辨識代理常見的失敗模式
  • 從軌跡中自動偵測問題
  • 為每種失敗準備對策

代理很強大，但會以特定的方式失敗。認得這些模式，就能及早偵測、事先預防：

失敗模式樣子對策
重複迴圈同樣的動作、同樣的錯誤一再發生重複偵測、步數上限（第 19 課）
幻想工具或參數呼叫不存在的工具、編造檔名清楚的工具清單、參數驗證（第 12 課）
無根據的結論沒讀到資料卻給出具體數字要求引用來源、檢查軌跡
過早宣告完成說修好了，其實沒跑測試要求外部驗證（第 18 課）
偏離任務越做越多、改了不該改的清楚的範圍、權限限制
上下文腐化任務太長，忘了最初的要求待辦清單、摘要、子代理（第 17、21、33 課）
過度信任外部內容被注入、採信錯誤資料縱深防禦（第 41、42 課）

代理的可靠度常被忽略的一點：每一步的成功率乘起來。每步 95% 正確、做 20 步，全部正確的機率只有約 36%。所以長任務一定要有中途驗證，而不是只在最後檢查。

\[0.95^{20} \approx 0.36\]

🐍 Python 範例（離線版）　下載 h50_failures.py　需同資料夾的 mockllm.py

掃描一段有問題的代理軌跡，自動找出重複迴圈、幻想工具與無根據的結論。

# -*- coding: utf-8 -*- """第 50 課：代理常見的失敗模式，以及每一種的偵測方法（用規則掃描一段代理軌跡）。""" import json from collections import Counter TRACE = [ # 一段（虛構的）有問題的代理軌跡 {"tool": "search", "args": {"q": "Q3 營收"}, "result": "找到 3 筆"}, {"tool": "read", "args": {"path": "q3.csv"}, "result": "錯誤：檔案不存在"}, {"tool": "read", "args": {"path": "q3.csv"}, "result": "錯誤：檔案不存在"}, {"tool": "read", "args": {"path": "q3.csv"}, "result": "錯誤：檔案不存在"}, {"tool": "get_revenue_magic", "args": {}, "result": "錯誤：沒有這個工具"}, {"tool": "final", "args": {"text": "Q3 營收為 1.2 億元，成長 30%。"}, "result": ""}, ] def detect(trace): issues = [] calls = Counter(json.dumps([s["tool"], s["args"]], sort_keys=True) for s in trace) for k, n in calls.items(): if n >= 3: issues.append("重複迴圈：%s 被呼叫了 %d 次（同樣的參數、同樣的錯誤）" % (k, n)) for s in trace: if "沒有這個工具" in s["result"]: issues.append("幻想工具：呼叫了不存在的 %s" % s["tool"]) ok_data = any(s["tool"] == "read" and "錯誤" not in s["result"] for s in trace) final = trace[-1]["args"].get("text", "") if any(ch.isdigit() for ch in final) and not ok_data: issues.append("無根據的結論：最終答案有具體數字，但從未成功讀到任何資料") return issues for i in detect(TRACE): print("⚠", i) print(""" 其他常見失敗： · 過早宣告完成（說修好了，其實沒跑測試） → 要求用外部驗證（測試、檢查清單） · 偏離任務（越做越多、改了不該改的檔案） → 清楚的範圍說明＋權限限制 · 上下文腐化（對話太長、忘了最初的要求） → 待辦清單、摘要、子代理 · 對工具結果過度信任（被注入、資料錯誤） → 交叉驗證、標記不可信資料""")

▶ 執行結果（這是實際執行的輸出）

⚠ 重複迴圈：["read", {"path": "q3.csv"}] 被呼叫了 3 次（同樣的參數、同樣的錯誤） ⚠ 幻想工具：呼叫了不存在的 get_revenue_magic ⚠ 無根據的結論：最終答案有具體數字，但從未成功讀到任何資料 其他常見失敗： · 過早宣告完成（說修好了，其實沒跑測試） → 要求用外部驗證（測試、檢查清單） · 偏離任務（越做越多、改了不該改的檔案） → 清楚的範圍說明＋權限限制 · 上下文腐化（對話太長、忘了最初的要求） → 待辦清單、摘要、子代理 · 對工具結果過度信任（被注入、資料錯誤） → 交叉驗證、標記不可信資料

🧭 這一課的重點

代理常見失敗有重複迴圈、幻想工具、無根據結論、過早宣告完成、偏離任務、上下文腐化與過度信任外部內容，各有對策。每步成功率會連乘（95% 做 20 步約剩 36%），長任務必須中途驗證。

🤖 本課的 Python 範例分兩版：離線版用一個模仿 Anthropic SDK 介面的「假 LLM」（mockllm.py），不需 API 金鑰即可執行，頁面上的輸出就是實際執行的結果；Claude API 版使用官方 anthropic 套件，需要 API 金鑰、會產生費用。API 細節（模型名稱、beta 功能）會隨時間更新，以官方文件為準。
