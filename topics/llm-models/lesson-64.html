1. 標準 HF repo

Qwen2.5-7B-Instruct/ ├── config.json 架構規格 ├── generation_config.json 預設生成參數 ├── model-00001-of-00004.safetensors 權重分片 1 ├── model-00002-of-00004.safetensors 權重分片 2 ├── model-00003-of-00004.safetensors 權重分片 3 ├── model-00004-of-00004.safetensors 權重分片 4 ├── model.safetensors.index.json 哪個張量在哪一片 ├── tokenizer.json 詞表與合併規則 ├── tokenizer_config.json 特殊 token 與 chat template ├── vocab.json / merges.txt 舊式 tokenizer 檔（有些模型有） ├── special_tokens_map.json 特殊 token 對照 ├── README.md Model card └── LICENSE

2. 分片與 index

權重被切成每片約 4–5 GB，原因是：

  • 方便斷點續傳（下載中斷不用重來）
  • 某些檔案系統對單檔大小有限制
  • 可以平行下載

index.json 長這樣：

{ "metadata": { "total_size": 15231233024 }, "weight_map": { "model.embed_tokens.weight": "model-00001-of-00004.safetensors", "model.layers.0.self_attn.q_proj.weight": "model-00001-of-00004.safetensors", ... "lm_head.weight": "model-00004-of-00004.safetensors" } }

total_size 很實用：除以 2 就是 BF16 模型的參數量（第 21 課）。

3. GGUF repo 的樣子

Qwen2.5-7B-Instruct-GGUF/ ├── Qwen2.5-7B-Instruct-Q2_K.gguf 2.8 GB ├── Qwen2.5-7B-Instruct-Q3_K_M.gguf 3.8 GB ├── Qwen2.5-7B-Instruct-Q4_K_M.gguf 4.7 GB ← 通常選這個 ├── Qwen2.5-7B-Instruct-Q5_K_M.gguf 5.4 GB ├── Qwen2.5-7B-Instruct-Q6_K.gguf 6.3 GB ├── Qwen2.5-7B-Instruct-Q8_0.gguf 8.1 GB ├── Qwen2.5-7B-Instruct-f16.gguf 15.2 GB └── README.md

只要下載一個檔案。這是 GGUF repo 與標準 repo 最大的操作差異——標準 repo 要下載全部，GGUF repo 只挑一個。

超過 50 GB 的 GGUF 有時會被切成多片 （-00001-of-00003.gguf）， 這種就要全部下載，llama.cpp 會自動合併。

4. 只下載需要的檔案

pip install huggingface_hub # 只抓一個 GGUF 檔 huggingface-cli download bartowski/Qwen2.5-7B-Instruct-GGUF \ Qwen2.5-7B-Instruct-Q4_K_M.gguf --local-dir ./models # 標準 repo 排除不需要的 huggingface-cli download Qwen/Qwen2.5-7B-Instruct \ --exclude "*.pth" "*.bin" --local-dir ./models/qwen # 只看 config，不下載權重 huggingface-cli download Qwen/Qwen2.5-7B-Instruct config.json --local-dir .

很多 repo 同時放 .safetensors 與舊的 .bin， 不排除的話會下載兩倍的量。

5. 幾個容易忽略的檔案

檔案為何重要
generation_config.json裡面的 eos_token_id 可能是個陣列（多個結束 token）， 設錯模型會停不下來
tokenizer_config.jsonchat template 在這裡，第 34 課的所有問題都源自它
config.json 的 rope_scaling有這個欄位代表 context 是靠外推撐出來的（第 69 課）
*.py（自訂程式碼）需要 trust_remote_code=True， 等於執行陌生程式碼，要先看過內容

最後一項是安全問題：trust_remote_code=True 會執行 repo 裡的 Python 檔案。新架構的模型常常需要它， 但務必先看一眼那些檔案在做什麼。
