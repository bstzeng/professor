模組 I｜MoE：AxB 到底什麼意思 · 第 46 課

讀懂 8x7B：Mixtral 為何是 47B 而不是 56B

這一課的目標

  • 完整拆解 8x7B 這個記號
  • 算出 Mixtral 的總參數與活躍參數
  • 知道為何它既不是 56B 也不是 7B

1. 這個記號的意思

8 x 7B │ └── 每個「專家分支」大約對應一個 7B 模型的規模 └────── 8 個專家

直覺會算成 8 × 7 = 56B。錯的。 實際是 46.7B。差了 9B 左右， 原因是注意力層與嵌入層是共享的，不會複製八份。

2. Mixtral 8x7B 的規格

d_model4,096
層數32
注意力頭 / KV 頭32 / 8（GQA）
專家 FFN 中間層14,336
專家數 / top-k8 / 2
詞表32,000

3. 逐項計算

【每層】 注意力 = 4096 × 128 × (2×32 + 2×8) = 41,943,040 ← 共享，只有一份 單一專家 = 3 × 4096 × 14336 = 176,160,768 八個專家 = 8 × 176,160,768 = 1,409,286,144 路由器 = 4096 × 8 = 32,768 兩個 norm = 8,192 ──────────────────────────────────────────────────── 每層總計 = 1,451,270,144 【全模型】 32 層 = 32 × 1,451,270,144 = 46,440,644,608 嵌入層 = 32000 × 4096 = 131,072,000 lm_head = 32000 × 4096 = 131,072,000 final norm = 4,096 ──────────────────────────────────────────────────── 總參數 = 46,702,792,704 ≈ 46.70 B

官方數字：46.7 B。吻合。

4. 活躍參數

處理一個 token 時，只有 2 個專家被啟動：

【每層（活躍）】 注意力 = 41,943,040 兩個專家 = 2 × 176,160,768 = 352,321,536 路由器 + norm = 40,960 ──────────────────────────────────────────────────── 每層 = 394,305,536 【全模型（活躍）】 32 層 = 12,617,777,152 嵌入 + lm_head + norm = 262,148,096 ──────────────────────────────────────────────────── 活躍參數 = 12,879,925,248 ≈ 12.88 B

官方數字：12.9 B。吻合。

5. 這代表什麼

指標Mixtral 8x7B相當於
記憶體需求46.7 B一個 47B dense 模型
推論速度12.9 B 活躍一個 13B dense 模型
實際能力—介於兩者之間，接近 30–40B dense
BF16 檔案大小 ≈ 46.7e9 × 2 bytes = 93 GB Q4_K_M 量化後 ≈ 46.7e9 × 4.85 / 8 = 28 GB

所以想在家跑 Mixtral 8x7B， 你需要的是接近 30 GB 的記憶體（不是 8 GB）， 但跑起來的速度像 13B（不是像 47B）。 這就是 MoE 對個人使用者的真實意義。

6. 通用公式

總參數 = L × [ 注意力 + E × 單一專家 + 路由器 + norm ] + 詞表 活躍參數 = L × [ 注意力 + k × 單一專家 + 路由器 + norm ] + 詞表 其中 E = 專家總數，k = top-k
