模組 J｜數值精度與量化原理 · 第 51 課

量化的本質：壓到 4 bit 失去了什麼

這一課的目標

  • 掌握量化的基本數學
  • 理解分組量化與縮放因子
  • 知道誤差從哪裡來

1. 基本做法

量化就是把一組浮點數映射到有限個整數，再記住換算方式。

【對稱量化】 scale = max(|w|) / (2^(bits−1) − 1) q = round(w / scale) 整數，範圍 [−7, 7]（4-bit） w' = q × scale 還原 【非對稱量化】 scale = (max − min) / (2^bits − 1) zero = round(−min / scale) q = round(w / scale) + zero 範圍 [0, 15] w' = (q − zero) × scale

非對稱多存一個零點，但能更貼合不對稱的分布。 4-bit 量化幾乎都用非對稱。

2. 手算一個例子

假設一組權重：[0.12, −0.45, 0.88, −0.03, 0.31]，量化到 4-bit 對稱。

max(|w|) = 0.88 scale = 0.88 / 7 = 0.1257 w → w/scale → round → 還原 → 誤差 0.12 → 0.955 → 1 → 0.1257 → +0.0057 −0.45 → −3.580 → −4 → −0.5029 → −0.0529 0.88 → 7.000 → 7 → 0.8800 → 0.0000 −0.03 → −0.239 → 0 → 0.0000 → +0.0300 0.31 → 2.466 → 2 → 0.2514 → −0.0586

觀察兩件事：最大值沒有誤差（它定義了 scale）， 而小數值的相對誤差很大（−0.03 直接被歸零）。

3. 離群值的災難

如果這組裡有一個 8.0：

scale = 8.0 / 7 = 1.143 原本的 0.12、−0.45、0.31 全部 round 成 0 → 整組除了離群值以外全部歸零

這是量化最大的敵人。而 LLM 的啟動值裡 確實存在少數維度的數值遠大於其他（離群特徵）。 AWQ、GPTQ、imatrix 這些方法要解的，本質上都是這個問題。

4. 分組量化

解法是：不要整個矩陣共用一個 scale，而是切成小組。

group size每組權重數額外開銷品質
per-tensor整個矩陣幾乎為零差
per-channel一整列／行低中
128128中好（常用預設）
3232高最好

開銷是實際的。以 group size 128、每組存一個 FP16 scale 與一個 zero 為例：

每 128 個權重： 128 × 4 bit = 512 bit （權重本身） + 16 bit（scale）+ 16 bit（zero）= 32 bit 實際 bpw = (512 + 32) / 128 = 4.25 bit

所以「4-bit 量化」實際上是 4.25 bpw 或更多。 這解釋了為什麼 Q4_K_M 的實際 bpw 是 4.8 而不是 4.0—— 還有其他保護機制（第 56 課）。

5. 權重量化 vs 啟動值量化

只量化權重（W4A16）權重與啟動值都量化（W8A8）
省記憶體✓✓
省計算✗（要解回 FP16 計算）✓（整數乘法）
難度低高（啟動值離群更嚴重）
本機常見GGUF、GPTQ、AWQ 都是較少見

你在 HF 上看到的量化模型幾乎都是只量化權重。 因為單次推論的瓶頸是記憶體頻寬不是算力（第 22 課）， 省記憶體就等於加速。
