Base model 為什麼不能直接用

這一課的目標

  • 理解 base model 的實際行為
  • 知道什麼時候該用 base 版
  • 掌握 few-shot 提示的由來

1. Base model 在做什麼

它只學過一件事：續寫。給它一段文字， 它輸出統計上最像接下來會出現的內容。 它沒有「回答問題」的概念，也沒有「對話」的概念。

輸入：法國的首都是哪裡？ Base 模型可能輸出： 德國的首都是哪裡？ 義大利的首都是哪裡？ 請在下方作答。 ────────── 第二題（5 分）... 因為在網路語料裡，一個問句後面常常接的是更多問句。

2. 它也沒有「停止」的概念

Base model 會一直寫下去，直到你設的長度上限。 它不知道什麼時候該閉嘴，因為訓練資料裡沒有「回答結束」這個訊號。 Instruct 模型則被教會在適當時機輸出 EOS token。

3. Few-shot：用格式誘導

既然它只會續寫，那就給它一個明顯的模式讓它接下去：

Q: 法國的首都是哪裡？ A: 巴黎 Q: 日本的首都是哪裡？ A: 東京 Q: 澳洲的首都是哪裡？ A:

這就是 GPT-3 論文展示的 few-shot learning。 它不是「學習」，而是用格式把續寫引導到你要的方向。 在 base model 上，這幾乎是唯一可行的用法。

4. 那為什麼還要發 base 版

用途為何要 base
自己做微調Instruct 版已經被調成特定風格，從 base 開始才乾淨
領域續訓要灌入新知識時，base 沒有對話格式的包袱
研究研究預訓練本身的性質，不能被後訓練污染
文字補全類應用程式碼補全、寫作接龍，續寫本來就是需求
評測基線測預訓練品質，不受後訓練影響

5. 常見的誤用

  • 下載 base 版當聊天機器人：會得到一堆不知所云的續寫， 然後以為模型很爛
  • 對 base 版套用 chat template：它沒學過那些特殊 token，行為會很奇怪
  • 拿 base 版跑對話評測：分數當然低，但那不是它的用途

辨識方法很簡單：名字裡沒有 Instruct／Chat／it 的就是 base 版。 Qwen2.5-7B 是 base，Qwen2.5-7B-Instruct 才是能聊天的那個。

6. 中間地帶

近年出現一些「半成品」：只做了 SFT 沒做偏好優化的版本， 或是官方明確標示 -SFT、-Base-Chat 的模型。 它們會聽指令，但語氣生硬、拒答邏輯不完整。 通常是給人繼續做 DPO 用的中繼站。

重點回顧

  • Base model 只會續寫，沒有回答與停止的概念
  • Few-shot 是用格式誘導續寫，不是真的學習
  • Base 版的用途是微調、續訓、研究與補全
  • 名字裡沒有 Instruct／Chat／it 的就是 base
