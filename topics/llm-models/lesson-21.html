模組 D｜參數量是怎麼決定的 · 第 21 課

實作：從 config.json 反推任何模型的參數量

這一課的目標

  • 寫出一段可執行的參數量計算
  • 用它驗證真實模型
  • 學會處理各種架構例外

1. 完整腳本

把第 14 課的公式寫成程式。這段程式在本課實際跑過， 對 Llama 2 7B 與 Llama 3 8B 的結果與官方公布數字完全一致。

def count_params(c): d = c["hidden_size"] L = c["num_hidden_layers"] h = c["num_attention_heads"] kv = c.get("num_key_value_heads", h) # 沒寫就是 MHA hd = c.get("head_dim") or d // h # 沒寫就用 d/h ff = c["intermediate_size"] V = c["vocab_size"] tied = c.get("tie_word_embeddings", False) attn = d * hd * (2*h + 2*kv) # Wq Wk Wv Wo mlp = 3 * d * ff # SwiGLU 三矩陣 per_layer = attn + mlp + 2*d # 加兩個 RMSNorm total = L * per_layer total += V * d # 嵌入層 total += d # final norm if not tied: total += V * d # lm_head return total

2. 執行結果

Llama-2-7B: total=6,738,415,616 (6.74B) attn=67,108,864 mlp=135,266,304 per_layer=202,383,360 Llama-3-8B: total=8,030,261,248 (8.03B) attn=41,943,040 mlp=176,160,768 per_layer=218,112,000

官方數字分別是 6.74B 與 8.03B。誤差為零。

3. 直接抓線上 config

import json, urllib.request def fetch_config(repo): url = f"https://huggingface.co/{repo}/raw/main/config.json" with urllib.request.urlopen(url) as r: return json.load(r) c = fetch_config("Qwen/Qwen2.5-7B") print(f"{count_params(c)/1e9:.2f} B")

gated repo（需要同意授權的，例如 Llama 系列）會回 401， 這時改用 huggingface_hub 帶 token，或直接在網頁上看 config.json。

4. 需要處理的例外

例外徵兆怎麼改
有 biasattention_bias: true加上 hd*(h+2*kv) + d

5. 更省事的做法

如果只是想知道數字，不必自己算：

# 方法一：看 HF 網頁右側的 "Model size" 欄位（由 safetensors 標頭自動統計） # 方法二：讀 safetensors index，不下載權重 import json, urllib.request url = "https://huggingface.co/Qwen/Qwen2.5-7B/raw/main/model.safetensors.index.json" idx = json.load(urllib.request.urlopen(url)) print(idx["metadata"]["total_size"] / 2 / 1e9, "B params (BF16)") # 方法三：本機已下載時 from safetensors import safe_open # 逐一累加每個張量的元素數

但自己算一次有意義：它會逼你看懂 config 的每個欄位， 而那些欄位正是後面判斷記憶體需求、KV cache、量化行為的依據。

6. 模組 D 總結

  • 參數量是四個旋鈕的結果，不是可以直接指定的數字
  • 公式：L × (d·hd·(2h+2kv) + 3·d·ff + 2d) + V·d × (1 或 2) + d
  • d_model 平方成長，是最強的槓桿
  • 尺寸慣例主要由顯卡容量決定
