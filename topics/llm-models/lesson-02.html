模組 A｜導論：一個模型從無到有 · 第 2 課

訓練四階段全景：從一張顯卡到一個 checkpoint

這一課的目標

  • 掌握模型誕生的四個階段
  • 知道每個階段的成本量級差多少
  • 理解為什麼你看到的模型幾乎都是別人第二手加工的

1. 四個階段

階段做什麼資料量成本量級誰做得起
預訓練在數兆 token 上學「下一個字是什麼」1–20T tokens百萬至數千萬美元大公司／國家級實驗室
中期訓練延長 context、補強特定領域、續訓百億至千億 tokens數萬至數十萬美元中型團隊
後訓練SFT、RLHF／DPO、推理能力訓練數萬至數百萬筆樣本數千至數十萬美元小團隊可做
量化／再製壓成 4-bit、合併、做 LoRA校準資料數百筆幾美元至數百美元個人

注意這個成本階梯：每往下一階，便宜大約兩個數量級。 這就是為什麼 Hugging Face 上有幾十萬個模型， 但真正從零預訓練出來的基座模型只有幾十個。

2. 預訓練產出什麼

預訓練的目標函數極其單純：給定前面的 token，預測下一個 token。 沒有人工標註，語料本身就是答案（self-supervised）。 訓練幾兆個 token 之後，模型學會的是語言的統計結構—— 文法、事實、程式語法、推理模式，全部隱含在權重裡。

產出叫做 base model（基座模型）。 它會接話，但不會聽指令。你問它「法國的首都是哪裡？」， 它可能回你「法國的首都是哪裡？德國的首都是哪裡？義大利的……」—— 因為在網路語料裡，問題後面接的常常是更多問題。

3. 後訓練把它變成助理

後訓練是一連串手術：

  1. SFT：餵幾萬到幾十萬筆「指令－回應」對，教它回答的格式
  2. 偏好優化：用 RLHF 或 DPO，教它「哪種回答比較好」
  3. 推理訓練（近幾年）：用可驗證的任務（數學、程式）做強化學習，練出長思考鏈

產出就是你看到的 -Instruct、-Chat、-Thinking 版本。 模組 G 會逐一拆解。

4. 量化與再製：社群的那一層

官方發的通常是 BF16 權重，一個 70B 模型 140 GB，一般人跑不動。 於是社群做兩件事：

  • 量化：壓成 4-bit，140 GB 變成約 40 GB，消費級硬體跑得動
  • 再製：微調、合併、移除拒答行為，產生各種衍生版本

所以你在 HF 上搜一個模型，會看到官方一個 repo、 底下掛著幾十個 -GGUF、-AWQ、-abliterated 的社群 repo。 這不是混亂，是這個生態的正常結構。

5. 一張圖式的總結

網路文字 (15T tokens) │ 預訓練：數千張 GPU × 數週，數百萬美元 ▼ Base Model ────────────────► 學術研究、續訓的起點 │ SFT + 偏好優化 + 推理訓練 ▼ Instruct Model ──────────────► 官方發佈的可用版本（BF16） │ 社群量化 / 微調 / 合併 ▼ GGUF Q4_K_M / AWQ / LoRA ──► 你實際下載的那個檔案

重點回顧

  • 四階段：預訓練 → 中期訓練 → 後訓練 → 量化再製，成本每階差兩個數量級
  • 預訓練只做一件事：預測下一個 token
  • Base model 會接話不會聽話，後訓練才讓它變成助理
  • 你下載的多半是第三手：官方權重經過社群量化

檢查你的理解

  1. 說出四個階段與各自的成本量級
  2. 解釋 base model 為何不能直接當助理用
  3. 說明為什麼 HF 上同一個模型會有幾十個 repo
