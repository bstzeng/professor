3. K-quant 的混合精度

K-quant 的核心想法：不是所有層都用同一個位元數。 敏感的層保留更高精度。

以 Q4_K_M 為例（概念示意）： attention.wv → Q6_K ← 對品質影響大，給高位元 ffn_down → Q6_K ← 同上 其餘注意力與 FFN → Q4_K embedding / output → 通常 Q6_K 或更高

所以 _S、_M、_L 的差別就是 「有多少層被提升到高位元」：

後綴意思相對品質相對大小
_S（Small）提升的層最少較低最小
_M（Medium）中等平衡中
_L（Large）提升的層最多較高最大

這也解釋了為什麼 Q4_K_M 的實際 bpw 是 4.8 而不是 4.0。

5. 選擇流程

  1. 算出可用記憶體（顯存 − 2 GB 給 KV cache 與系統）
  2. 從 Q4_K_M 開始試
  3. 還有餘裕 → 往上到 Q5_K_M 或 Q6_K
  4. 不夠 → 往下到 Q4_K_S，再不夠考慮 IQ4_XS
  5. 要到 Q3 以下 → 先考慮換小一號的模型

再重複一次第 53 課的原則： 同樣記憶體下，大模型的 Q4 通常優於小模型的 Q8。
