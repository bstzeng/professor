殘差、RMSNorm 與 SwiGLU

這一課的目標

  • 理解殘差連接為何是深層網路的前提
  • 知道 RMSNorm 相對 LayerNorm 省了什麼
  • 掌握 pre-norm 與 post-norm 的差別

1. 殘差連接

每個子層的輸出不是直接往下傳，而是加回輸入：

x = x + Attention(Norm(x)) x = x + FFN(Norm(x))

那個 x + 就是殘差（residual）。它解決的是梯度消失： 反向傳播時，梯度有一條「直達車」可以不經過任何權重矩陣 直接回到前面的層。沒有它，超過十幾層的網路根本訓不起來。

另一個視角是殘差流（residual stream）： 把 x 看成一條貫穿所有層的匯流排，每一層讀取它、算出一點東西、寫回去。 這是目前理解 Transformer 內部運作最有用的心智模型。

2. LayerNorm 與 RMSNorm

正規化的目的是讓每層的輸入分布穩定，避免數值飄掉。

LayerNorm: y = (x − μ) / σ × γ + β 需要算平均與標準差，有兩組參數 RMSNorm: y = x / RMS(x) × γ 只算均方根，只有一組參數 RMS(x) = √( Σxᵢ² / n )
LayerNormRMSNorm
參數γ 與 β，共 2×d_model只有 γ，d_model
運算要先算平均再減不需要減平均
速度基準快約 10–20%
效果基準實測幾乎相同

結論很簡單：去掉平均項不影響效果，卻省時間， 所以現在的模型幾乎全用 RMSNorm。 參數上它微不足道——8B 模型的所有 norm 加起來不到 30 萬參數。

3. Pre-norm 與 post-norm

Post-norm（原始 Transformer）: x = Norm(x + Sublayer(x)) Pre-norm（現代標準） : x = x + Sublayer(Norm(x))

差別看起來很小，影響很大。Pre-norm 保留了一條完全沒有被正規化干擾的殘差通道， 訓練穩定得多，不需要複雜的 warmup 調參。 代價是最終輸出的尺度會隨層數累積，所以模型最後還要再接一個 final norm。

4. SwiGLU

啟動函數的演進：

函數形式特點
ReLUmax(0, x)簡單，但負區間梯度為零
GELUx · Φ(x)平滑，GPT 系列常用
SiLU／Swishx · sigmoid(x)平滑且負區間不全死
SwiGLUSiLU(xW_gate) ⊙ (xW_up)閘控機制，效果最好

SwiGLU 的關鍵是那個「閘」：一條路徑決定要不要讓資訊通過， 另一條路徑決定通過的是什麼內容，兩者相乘。 這讓網路能做出條件式的判斷，而不只是固定的非線性壓縮。

代價就是第 12 課提到的：多一個矩陣，所以要把 d_ff 乘 2/3 來補。 論文的結論是即使參數持平，SwiGLU 仍然勝出。

5. 完整的一層長這樣

def block(x): x = x + attention(rmsnorm(x)) # 跨 token 交換資訊 x = x + swiglu_ffn(rmsnorm(x)) # 逐 token 處理 return x # 疊 32 次，最後再一個 rmsnorm + lm_head

整個 Llama 架構就這麼多。剩下的差異都在超參數： 幾層、多寬、幾個頭。下一課我們把它的參數精確算出來。
