支持向量機

這一課的目標

  • 理解最大間隔的概念
  • 理解支持向量與 C 參數
  • 理解核技巧

最寬的街道

能把兩類分開的直線可能有無數條，哪一條最好？支持向量機（SVM）的答案：選擇離兩邊最近的點最遠的那一條——在兩類之間開出一條最寬的街道，邊界就在街道的正中間。間隔越寬，對新資料的容錯能力越好。

支持向量

決定街道位置的，只有剛好落在街邊的那幾個點，叫做支持向量。其他的點即使移動或刪除，邊界都不變。這讓 SVM 對遠離邊界的資料不敏感。

軟間隔與 C

真實的資料常常有重疊或雜訊，無法完美分開。軟間隔 SVM 允許一些點越界，但要付出代價。參數 C 控制這個取捨：C 大，盡量不犯錯，街道窄（容易過擬合）；C 小，容忍一些錯誤，街道寬（較平滑）。C 的作用和正則化相反（第 8 課）。

核技巧

資料無法用直線分開怎麼辦（例如一類在圓心、另一類圍成一圈）？把資料映射到更高維的空間，在那裡也許就能用平面分開了——例如加入 x² + y² 這個新維度，圓心的點在「下面」、外圈的點在「上面」。

妙的是，SVM 的計算只需要樣本之間的內積。核函數直接計算出高維空間中的內積，完全不需要真的把資料映射過去——這就是核技巧。常用的 RBF（高斯）核甚至相當於映射到無限維的空間。參數 γ 控制每個點的影響範圍：γ 大，邊界很曲折（容易過擬合）。

SVM 的地位

SVM 由瓦普尼克等人在 1960～1990 年代發展，在 2000 年代是最熱門、效果最好的分類器之一，在手寫辨識、文字分類、生物資訊中廣泛使用，背後有漂亮的統計學習理論支持。深度學習興起後，它在影像與語音上被取代，但在中小型、高維的資料上仍然是很強的工具。缺點是資料量很大時（數十萬筆以上）訓練很慢，而且需要仔細地調 C 與 γ、標準化特徵（第 21 課）。

🧭 這一課的重點

SVM 選擇離兩邊最近點最遠的分界，在兩類間開出最寬的街道使容錯最好；只有落在街邊的支持向量決定邊界；軟間隔允許越界付代價，C 大少犯錯街窄易過擬合、C 小較寬平滑，作用與正則化相反；無法線性分開時映射到高維，如加 x²+y² 分開圓心與外圈，計算只需內積，核函數直接算高維內積即核技巧，RBF 核相當於無限維，γ 大邊界曲折；瓦普尼克等 1960～1990 年代發展，2000 年代最熱門，深度學習後影像語音被取代，中小型高維資料仍強，缺點大資料慢需調 C γ 與標準化。
