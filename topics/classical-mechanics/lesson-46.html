泊松括號

這一課的目標

  • 定義泊松括號
  • 用泊松括號寫運動方程與守恆律
  • 理解它與量子力學對易子的對應

定義

對相空間中任意兩個函數 \(f(q,p)\) 與 \(g(q,p)\)，定義泊松括號（1809）：

\[\{f, g\} = \sum_i\left(\frac{\partial f}{\partial q_i}\frac{\partial g}{\partial p_i} - \frac{\partial f}{\partial p_i}\frac{\partial g}{\partial q_i}\right)\]

完整推導：任何量的時間演化

物理量 \(f(q,p)\) 沿著軌跡的變化率，用連鎖律加上哈密頓方程式：

\[\frac{df}{dt} = \sum_i\left(\frac{\partial f}{\partial q_i}\dot q_i + \frac{\partial f}{\partial p_i}\dot p_i\right) = \sum_i\left(\frac{\partial f}{\partial q_i}\frac{\partial H}{\partial p_i} - \frac{\partial f}{\partial p_i}\frac{\partial H}{\partial q_i}\right) = \{f, H\}\]

任何物理量的變化率，都是它和哈密頓量的泊松括號。哈密頓量是「時間演化的生成者」。

  • 取 \(f = q\)：\(\dot q = \{q, H\} = \partial H/\partial p\)。
  • 取 \(f = p\)：\(\dot p = \{p, H\} = -\partial H/\partial q\)。哈密頓方程式只是特例。
  • 守恆律：\(f\) 守恆 ⟺ \(\{f, H\} = 0\)。

基本泊松括號

\[\{q_i, p_j\} = \delta_{ij}, \qquad \{q_i, q_j\} = 0, \qquad \{p_i, p_j\} = 0\]

對角動量的分量，可以算出 \(\{L_x, L_y\} = L_z\)（以及循環排列）。角動量的三個分量彼此的括號不為零——這在量子力學中會變成「不能同時精確測量 \(L_x\) 和 \(L_y\)」。

狄拉克的發現

1925 年，23 歲的研究生狄拉克讀到海森堡的矩陣力學論文，論文中的量 \(qp - pq\) 不等於零。某個星期天散步時，他突然想到：這個結構很像泊松括號！他翻遍教科書（星期天圖書館沒開，他等到星期一早上）確認了泊松括號的定義，然後寫下了量子化的規則：

\[\{f, g\} \;\longrightarrow\; \frac{1}{i\hbar}[\hat f, \hat g], \qquad [\hat q, \hat p] = i\hbar\]
古典力學量子力學
相空間中的函數 \(f(q,p)\)算符 \(\hat f\)
泊松括號 \(\{f, g\}\)對易子 \([\hat f, \hat g]/i\hbar\)
\(df/dt = \{f, H\}\)海森堡方程 \(d\hat f/dt = [\hat f, \hat H]/i\hbar\)
\(\{q, p\} = 1\)\([\hat q, \hat p] = i\hbar\) → 測不準原理

整個量子力學的代數結構，就藏在一百年前的古典力學裡。古典力學是 \(\hbar\to0\) 的極限。見〈量子力學〉。

🧭 這一課的重點

泊松括號 {f,g}=Σ(∂f/∂q ∂g/∂p−∂f/∂p ∂g/∂q)。以連鎖律與哈密頓方程得 df/dt={f,H}，哈密頓量生成時間演化，哈密頓方程是 f=q、p 的特例，守恆即 {f,H}=0。基本括號 {q_i,p_j}=δ_ij，角動量 {L_x,L_y}=L_z。1925 年狄拉克發現海森堡的 qp−pq 與泊松括號結構相同，寫下量子化規則 {f,g}→[f,g]/iħ、[q,p]=iħ，古典函數對應算符、泊松括號對應對易子、運動方程對應海森堡方程，古典力學是 ħ→0 的極限。
