諾特定理

這一課的目標

  • 理解循環座標與守恆量
  • 推導諾特定理的力學形式
  • 從時間對稱推導能量守恆

循環座標

上一課的行星問題中，\(\mathcal L\) 不含 \(\theta\)。歐拉—拉格朗日方程立刻給出

\[\frac{\partial\mathcal L}{\partial\theta} = 0 \;\Longrightarrow\; \frac{d}{dt}\frac{\partial\mathcal L}{\partial\dot\theta} = 0 \;\Longrightarrow\; p_\theta \equiv \frac{\partial\mathcal L}{\partial\dot\theta} = \text{常數}\]

不出現在拉格朗日量中的座標叫循環座標，它對應的廣義動量 \(p_q = \partial\mathcal L/\partial\dot q\) 守恆。\(\mathcal L\) 不含 \(\theta\)，意思是把系統整個轉一個角度，\(\mathcal L\) 不變——這是一種對稱性。

完整推導：諾特定理（力學版）

設座標做一個連續的小變換 \(q_i \to q_i + \epsilon K_i(q)\)，而且 \(\mathcal L\) 不變：\(\delta\mathcal L = 0\)。

\[0 = \delta\mathcal L = \sum_i\left(\frac{\partial\mathcal L}{\partial q_i}\epsilon K_i + \frac{\partial\mathcal L}{\partial\dot q_i}\epsilon\dot K_i\right)\]

用運動方程把 \(\partial\mathcal L/\partial q_i\) 換成 \(\frac{d}{dt}\partial\mathcal L/\partial\dot q_i\)：

\[0 = \epsilon\sum_i\left(\frac{d}{dt}\frac{\partial\mathcal L}{\partial\dot q_i}K_i + \frac{\partial\mathcal L}{\partial\dot q_i}\frac{dK_i}{dt}\right) = \epsilon\frac{d}{dt}\left(\sum_i p_i K_i\right)\]

所以 \(Q = \sum_i p_iK_i\) 守恆。每一個連續對稱性，都給出一個守恆量。

對稱性變換 \(K\)守恆量 \(Q\)
空間平移所有粒子沿 x 移動：\(K_i = 1\)總動量 \(\sum p_x\)
繞 z 軸旋轉\(\delta x = -y\epsilon,\ \delta y = x\epsilon\)角動量 \(L_z = \sum(xp_y - yp_x)\)

完整推導：能量守恆

時間對稱要另外處理。如果 \(\mathcal L\) 不顯含時間，計算它的全微分：

\[\frac{d\mathcal L}{dt} = \sum_i\left(\frac{\partial\mathcal L}{\partial q_i}\dot q_i + \frac{\partial\mathcal L}{\partial\dot q_i}\ddot q_i\right) = \sum_i\frac{d}{dt}\left(\frac{\partial\mathcal L}{\partial\dot q_i}\dot q_i\right)\]
\[\Longrightarrow\; \frac{d}{dt}\left(\sum_i p_i\dot q_i - \mathcal L\right) = 0\]

守恆量 \(H = \sum p_i\dot q_i - \mathcal L\)。對一般的系統（\(T\) 是速度的二次式），\(\sum p_i\dot q_i = 2T\)，所以 \(H = 2T - (T - V) = T + V\)——總能量。這個 \(H\) 就是下一個模組的主角：哈密頓量。

艾米・諾特

艾米・諾特（Emmy Noether）在 1915 年應希爾伯特與克萊因之邀到哥廷根大學，幫忙解決廣義相對論中能量守恆的問題。因為她是女性，學校拒絕給她正式職位，她的課要掛在希爾伯特的名下。希爾伯特在教授會議上抗議：「我不認為候選人的性別是反對她的理由。我們這裡是大學，不是澡堂。」

她 1918 年發表的定理，成為現代物理的基石：粒子物理中的電荷守恆來自規範對稱，所有基本交互作用都由對稱性決定。愛因斯坦稱她為「自女性開始接受高等教育以來，最重要的創造性數學天才」。

🧭 這一課的重點

拉格朗日量不含的循環座標，其廣義動量 p=∂L/∂q̇ 守恆，這對應系統在該變換下的對稱性。諾特定理推導：設小變換 q→q+εK 使 L 不變，以運動方程替換 ∂L/∂q，得 d/dt(Σp_iK_i)=0，每個連續對稱給出一個守恆量：空間平移對應動量、旋轉對應角動量。L 不顯含時間時，全微分得 H=Σp_iq̇_i−L 守恆，一般等於 T+V，即能量，也是哈密頓量。艾米・諾特 1915 年到哥廷根卻因性別無法獲正式職位，希爾伯特抗議「這裡是大學，不是澡堂」；她的定理成為現代物理基石。
