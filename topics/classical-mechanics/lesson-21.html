模組 D｜振動與波 · 第 21 課

耦合振子與正規模態

這一課的目標

  • 推導兩個耦合振子的運動方程式
  • 理解正規模態
  • 理解拍頻與能量交換

兩個單擺連一根彈簧

兩個相同的單擺（或兩個接在牆上的質量），中間用一根彈簧 \(k'\) 連起來。各自的運動方程：

\[m\ddot x_1 = -kx_1 - k'(x_1 - x_2), \qquad m\ddot x_2 = -kx_2 - k'(x_2 - x_1)\]

兩個方程互相耦合：\(x_1\) 的運動取決於 \(x_2\)，反之亦然。

完整推導：換座標

把兩式相加、相減，定義 \(q_1 = x_1 + x_2\)、\(q_2 = x_1 - x_2\)：

\[\ddot q_1 = -\frac{k}{m}q_1, \qquad \ddot q_2 = -\frac{k + 2k'}{m}q_2\]

耦合消失了！\(q_1\) 和 \(q_2\) 各自做獨立的簡諧運動。它們叫做正規模態：

模態運動頻率
同相模態 \(q_1\)兩個一起往同一邊擺，中間的彈簧不伸縮\(\omega_1 = \sqrt{k/m}\)
反相模態 \(q_2\)兩個往相反方向擺，中間的彈簧被拉扯\(\omega_2 = \sqrt{(k+2k')/m}\)

在線性代數的語言裡，這就是把運動方程寫成矩陣 \(\ddot{\vec x} = -K\vec x\)，然後找 \(K\) 的特徵向量（模態形狀）與特徵值（頻率平方）——見〈線性代數〉。

拍頻：能量來回交換

如果一開始只拉動第一個擺、第二個靜止，運動是兩個模態的疊加。當耦合很弱（\(k'\ll k\)）時，兩個頻率很接近：

\[x_1 = A\cos\left(\tfrac{\omega_2-\omega_1}{2}t\right)\cos\left(\tfrac{\omega_1+\omega_2}{2}t\right), \quad x_2 = A\sin\left(\tfrac{\omega_2-\omega_1}{2}t\right)\sin\left(\tfrac{\omega_1+\omega_2}{2}t\right)\]

第一個擺慢慢停下、第二個慢慢擺起來，然後再換回來——能量在兩者之間來回流動，交換的週期由頻率差決定。調音師聽兩根弦的「嗡嗡聲」（拍頻）來判斷音準，用的是同一個原理。

N 個振子

N 個質量用彈簧串成一排，就有 N 個正規模態。任何複雜的運動，都是這些模態的疊加。這個想法延伸到：分子的振動光譜、晶體的聲子、建築的模態分析——以及下一課，連續的弦。

🧭 這一課的重點

兩個單擺以彈簧耦合，運動方程互相依賴；相加相減換成 q₁=x₁+x₂、q₂=x₁−x₂ 後耦合消失，得到兩個正規模態：同相模態頻率 √(k/m)、中間彈簧不伸縮，反相模態頻率 √((k+2k')/m)。這等於找矩陣的特徵向量與特徵值。只拉一個擺時，兩個接近的頻率疊加產生拍頻，能量在兩擺間來回流動，調音也用拍頻。N 個振子有 N 個模態，延伸到分子光譜、聲子與建築模態分析。

🪐 本課的推導以物理直覺為主，省略部分數學嚴格性；數值為教學用的近似值。只想看概念的讀者，可以跳過推導，直接看圖、互動與「重點」。
