模組 H｜哈密頓力學 · 第 47 課

正則變換與哈密頓—雅可比方程式

這一課的目標

  • 理解正則變換的概念
  • 理解作用—角變數
  • 認識哈密頓—雅可比方程式與量子力學的關係

換座標的自由

在拉格朗日力學中，我們可以換任意的廣義座標 \(q\)。在哈密頓力學中，自由更大：可以把 \(q\) 和 \(p\) 混在一起換成新的 \((Q, P)\)，只要新變數仍然滿足哈密頓方程式的形式。這種變換叫正則變換。

判斷條件很簡潔：新變數的基本泊松括號仍然是 \(\{Q, P\} = 1\)。正則變換保持相空間體積（劉維爾定理）與泊松括號不變。

終極目標

如果能找到一個正則變換，讓新的哈密頓量 \(K\) 只和新動量 \(P\) 有關，那麼

\[\dot P = -\frac{\partial K}{\partial Q} = 0, \qquad \dot Q = \frac{\partial K}{\partial P} = \omega(P) = \text{常數}\]

\(P\) 是常數，\(Q\) 等速增加——問題解完了！所有的難度都轉移到「找出那個變換」。

例子：作用—角變數

彈簧振子 \(H = p^2/2m + \tfrac12m\omega^2q^2\)。做變換 \(q = \sqrt{2J/m\omega}\sin\theta\)、\(p = \sqrt{2Jm\omega}\cos\theta\)（可驗證 \(\{\theta, J\} = 1\)），代入得

\[H = \omega J \;\Longrightarrow\; \dot J = 0, \quad \dot\theta = \omega\]

\(\theta\) 是相空間圓上的角度，\(J\) 叫作用量變數，等於相空間軌跡所圍面積除以 \(2\pi\)：

\[J = \frac{1}{2\pi}\oint p\,dq\]

作用量變數有一個重要性質：如果系統的參數非常緩慢地改變（例如慢慢縮短單擺的繩子），\(J\) 幾乎不變——這叫絕熱不變量。

從古典到量子：舊量子論

1913～1916 年，波耳與索末菲提出量子化條件：\(\oint p\,dq = nh\)——作用量變數只能是 \(\hbar\) 的整數倍。對振子，這給出 \(E = \omega J = n\hbar\omega\)（只差了零點能 \(\tfrac12\hbar\omega\)）；對氫原子，它給出波耳的能階。為什麼偏偏是作用量變數被量子化？愛因斯坦指出：因為只有絕熱不變量，才能在緩慢變化下保持「整數」不變。

哈密頓—雅可比方程式

找那個神奇變換的方程式，是一個關於「生成函數」\(S(q, t)\) 的偏微分方程：

\[\frac{\partial S}{\partial t} + H\left(q, \frac{\partial S}{\partial q}\right) = 0\]

\(S\) 正是沿真實路徑計算的作用量。哈密頓最初是在研究光學時想到這套方法的：等 \(S\) 面就像光的波前，粒子軌跡就像垂直於波前的光線。

1926 年，薛丁格正是從這個類比出發：如果古典力學是「幾何光學」，那一定有一個「波動光學」版本的力學。把 \(\psi = e^{iS/\hbar}\) 代入，就通往了薛丁格方程式。

🧭 這一課的重點

哈密頓力學允許把 q 與 p 混合換成新的 (Q,P)，只要保持哈密頓方程形式，即 {Q,P}=1，這是正則變換，保持相空間體積與泊松括號。若新哈密頓量只依賴 P，則 P 守恆、Q 等速增加，問題解完。彈簧振子以作用—角變數換成 H=ωJ，J=(1/2π)∮p dq 是軌跡面積，也是參數緩變時不變的絕熱不變量。波耳—索末菲量子化 ∮p dq=nh 給出 E=nħω 與波耳能階，愛因斯坦指出只有絕熱不變量能保持整數。哈密頓—雅可比方程 ∂S/∂t+H(q,∂S/∂q)=0 中 S 是作用量，等 S 面像波前、軌跡像光線，薛丁格由此類比得到薛丁格方程式。
