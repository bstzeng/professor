模組 G｜拉格朗日力學 · 第 39 課

最小作用量原理

這一課的目標

  • 理解作用量的定義
  • 從作用量原理推導牛頓第二定律
  • 理解這個原理的哲學意義

作用量

對一個力學系統，定義拉格朗日量 \(\mathcal L = T - V\)，以及作用量：

\[S = \int_{t_1}^{t_2}\mathcal L(q, \dot q, t)\,dt\]

哈密頓原理（1834）：系統從時刻 \(t_1\) 的位置走到 \(t_2\) 的位置，在所有可能的路徑中，真實的路徑讓 \(S\) 取駐值（通常是最小值）。

用上一課的變分法（把 \(x\) 換成 \(t\)、\(y\) 換成 \(q\)），立刻得到

\[\frac{d}{dt}\frac{\partial\mathcal L}{\partial\dot q} - \frac{\partial\mathcal L}{\partial q} = 0\]

完整推導：還原牛頓定律

一維粒子：\(\mathcal L = \tfrac12 m\dot x^2 - V(x)\)。

  • \(\partial\mathcal L/\partial\dot x = m\dot x\)（就是動量！）
  • \(\partial\mathcal L/\partial x = -V'(x) = F\)（就是力！）
\[\frac{d}{dt}(m\dot x) - F = 0 \;\Longrightarrow\; m\ddot x = F\]

牛頓第二定律從一個最佳化原理中跑了出來。這也回答了上一課的疑問：如果用 \(T + V\)，會得到 \(m\ddot x = -F\)，方向錯了。減號是必要的。

一個更古老的想法

1662 年，費馬提出光學的「最短時間原理」：光從一點到另一點，走的是花最少時間的路徑。由此可以推出反射定律和折射定律（光在水中較慢，所以入水時會彎折，在水中少走一點）。1744 年，莫佩爾蒂把類似的想法推廣到力學，認為這證明了上帝的智慧與經濟。

它是目的論嗎

最小作用量原理聽起來像是粒子「知道」終點、「選擇」了最好的路徑。這曾引發長期的哲學爭論。但數學上，它和牛頓定律完全等價：每一刻局部地遵守 \(F = ma\)，整體上就會讓作用量取駐值。

真正的解釋要等到量子力學：費曼的路徑積分說，粒子同時「走」所有的路徑，每條路徑貢獻一個相位 \(e^{iS/\hbar}\)。偏離駐值的路徑相位快速變化、互相抵消；只有駐值附近的路徑相位一致、互相加強。古典路徑，就是所有量子路徑干涉後倖存下來的那一條。

🔍 費曼的高中老師

費曼在《費曼物理學講義》中回憶，他高中時物理老師巴德告訴他最小作用量原理，他被深深吸引，「從此以後，這個原理對我來說一直很有趣」。這堂課後來成了講義第二卷第 19 章。

🧭 這一課的重點

拉格朗日量 L=T−V，作用量 S=∫L dt；哈密頓原理指出真實路徑讓 S 取駐值，用變分法得歐拉—拉格朗日方程式。一維粒子 ∂L/∂ẋ=mẋ 是動量、∂L/∂x=−V'=F 是力，代入即得 mẍ=F，若用 T+V 方向會錯。更早有費馬的光學最短時間原理推出反射折射定律，莫佩爾蒂推廣到力學。它看似目的論但與牛頓定律數學上等價；量子力學的路徑積分解釋：各路徑貢獻相位 e^{iS/ħ}，只有駐值附近的路徑相長干涉而倖存成為古典路徑。
