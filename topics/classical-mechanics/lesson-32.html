轉動慣量與平行軸定理

這一課的目標

  • 理解轉動慣量的定義
  • 計算幾種常見形狀的轉動慣量
  • 推導平行軸定理

轉動的動能

剛體繞固定軸以角速度 \(\omega\) 轉動，距軸 \(r_i\) 的質點速度 \(v_i = \omega r_i\)，總動能

\[K = \sum\tfrac12 m_i(\omega r_i)^2 = \tfrac12 I\omega^2, \qquad I = \sum m_i r_i^2 = \int r^2\,dm\]

\(I\) 叫做轉動慣量：它是轉動的「質量」，代表物體多難被轉動。關鍵是 \(r^2\)：同樣的質量，離軸越遠，貢獻越大。轉動的第二定律是 \(\tau = I\alpha\)，角動量 \(L = I\omega\)。

完整推導：均勻細桿繞中心

長 \(L\)、質量 \(M\)，線密度 \(\lambda = M/L\)：

\[I = \int_{-L/2}^{L/2} x^2\lambda\,dx = \lambda\frac{x^3}{3}\Big|_{-L/2}^{L/2} = \frac{1}{12}ML^2\]

常見形狀

形狀轉軸轉動慣量
細環（或薄圓筒）中心軸\(MR^2\)
實心圓盤（或圓柱）中心軸\(\tfrac12 MR^2\)
實心球直徑\(\tfrac25 MR^2\)
薄球殼直徑\(\tfrac23 MR^2\)
細桿中心\(\tfrac{1}{12}ML^2\)
細桿一端\(\tfrac13 ML^2\)

斜面滾動比賽

讓圓環、圓盤、實心球從同一個斜面同時滾下（不打滑）。能量守恆：\(Mgh = \tfrac12Mv^2 + \tfrac12I\omega^2\)，加上 \(v = \omega R\)。令 \(I = \beta MR^2\)：

\[v = \sqrt{\frac{2gh}{1 + \beta}}\]

結果和質量、半徑都無關，只看形狀：實心球（\(\beta = 0.4\)）最快，圓盤（0.5）第二，圓環（1）最慢。因為圓環的質量全在外圈，更多能量被拿去轉動。

完整推導：平行軸定理

已知繞質心軸的 \(I_{\text{cm}}\)，求繞一條平行、相距 \(d\) 的軸的 \(I\)。設每個質點相對質心的位置為 \(\vec r_i'\)，則到新軸的距離向量為 \(\vec r_i' + \vec d\)（只看垂直於軸的分量）：

\[I = \sum m_i|\vec r_i' + \vec d|^2 = \underbrace{\sum m_i r_i'^2}_{I_{\text{cm}}} + 2\vec d\cdot\underbrace{\sum m_i\vec r_i'}_{=0} + Md^2\]
\[I = I_{\text{cm}} + Md^2\]

中間項為零，因為相對於質心的質量加權位置總和就是零（質心的定義）。驗證：細桿繞一端 \(= \tfrac{1}{12}ML^2 + M(L/2)^2 = \tfrac13ML^2\)。✓

🧭 這一課的重點

剛體轉動動能 ½Iω²，轉動慣量 I=∫r²dm 是轉動的質量，離軸越遠貢獻越大，τ=Iα、L=Iω。均勻細桿繞中心積分得 ML²/12。常見形狀：細環 MR²、圓盤 ½MR²、實心球 ⅖MR²、薄球殼 ⅔MR²、細桿一端 ⅓ML²。斜面滾動不打滑時 v=√(2gh/(1+β))，與質量半徑無關，實心球最快、圓環最慢。平行軸定理 I=I_cm+Md²，中間項因質心定義為零，可驗證細桿繞一端為 ⅓ML²。

🪐 本課的推導以物理直覺為主，省略部分數學嚴格性；數值為教學用的近似值。只想看概念的讀者，可以跳過推導，直接看圖、互動與「重點」。
