動量守恆與碰撞

這一課的目標

  • 從第三定律推導動量守恆
  • 完整推導一維彈性碰撞
  • 理解衝量

動量

\(\vec p = m\vec v\)。牛頓原本寫的第二定律就是 \(\vec F = d\vec p/dt\)：力是動量的變化率。

完整推導：動量守恆

兩個物體互相作用，第三定律說 \(\vec F_{12} = -\vec F_{21}\)。所以

\[\frac{d\vec p_1}{dt} + \frac{d\vec p_2}{dt} = \vec F_{21} + \vec F_{12} = 0 \;\Longrightarrow\; \vec p_1 + \vec p_2 = \text{常數}\]

推廣到任意多個物體：內力兩兩抵消，沒有外力時，系統的總動量守恆。不論內部發生什麼——碰撞、爆炸、黏在一起——總動量都不變。

衝量

\[\vec J = \int \vec F\,dt = \Delta\vec p\]

同樣的動量變化，作用時間越長，力就越小。安全氣囊、跳遠的沙坑、接球時手往後收，都是在延長作用時間來減小衝擊力。

碰撞的分類

類型動量動能例子
彈性碰撞守恆守恆撞球（近似）、氣體分子
非彈性碰撞守恆減少大部分真實碰撞
完全非彈性碰撞守恆減少最多黏在一起：子彈射入木塊

完整推導：一維彈性碰撞

\(m_1\) 以 \(u_1\) 撞向靜止的 \(m_2\)。動量與動能守恆：

\[m_1u_1 = m_1v_1 + m_2v_2, \qquad \tfrac12m_1u_1^2 = \tfrac12m_1v_1^2 + \tfrac12m_2v_2^2\]

把兩式改寫為 \(m_1(u_1 - v_1) = m_2v_2\) 與 \(m_1(u_1^2 - v_1^2) = m_2v_2^2\)，相除得 \(u_1 + v_1 = v_2\)（相對速度反向）。代回解出

\[v_1 = \frac{m_1 - m_2}{m_1 + m_2}u_1, \qquad v_2 = \frac{2m_1}{m_1 + m_2}u_1\]
情況結果
\(m_1 = m_2\)交換速度：撞球的「定桿」，母球停住、子球以原速前進
\(m_1 \ll m_2\)幾乎原速彈回：球撞牆
\(m_1 \gg m_2\)大的幾乎不受影響，小的以約 \(2u_1\) 飛出：保齡球撞瓶

完全非彈性碰撞：彈道擺

子彈 \(m\) 射入懸掛的木塊 \(M\)，一起擺高 \(h\)。碰撞瞬間動量守恆：\(mv = (m+M)V\)；之後擺動時能量守恆：\(V = \sqrt{2gh}\)。所以

\[v = \frac{m+M}{m}\sqrt{2gh}\]

這是 1742 年羅賓斯發明的測子彈速度方法。注意兩個階段要用不同的守恆律：碰撞時動能不守恆，擺動時動量不守恆（繩子有外力）。

🧭 這一課的重點

動量 p=mv，牛頓原式為 F=dp/dt。由第三定律內力兩兩抵消，沒有外力時系統總動量守恆。衝量 J=∫F dt=Δp，延長作用時間可減小衝擊力，如安全氣囊。碰撞分彈性（動能守恆）、非彈性、完全非彈性（黏在一起）。一維彈性碰撞解得 v₁=(m₁−m₂)u₁/(m₁+m₂)、v₂=2m₁u₁/(m₁+m₂)，等質量交換速度。彈道擺先用動量守恆再用能量守恆，v=(m+M)√(2gh)/m。
