紋理映射

這一課的目標

  • 理解 UV 座標
  • 理解紋理取樣與濾波
  • 認識各種紋理貼圖

UV 座標

紋理映射把一張 2D 圖片貼到 3D 表面上，就像包禮物。每個頂點帶有一組 UV 座標（0～1），指出它對應圖片上的哪個位置；三角形內部的 UV 由重心座標插值（第 12 課）。把 3D 模型的表面「攤平」成 2D 的過程叫做 UV 展開，就像把地球儀攤成世界地圖，一定會有接縫與變形。

取樣與濾波

像素中心對應到的 UV 位置，很少剛好落在紋理的某個像素（texel）上：

  • 最近鄰：直接取最近的 texel，放大時呈現方塊狀（像素風遊戲故意這樣做）。
  • 雙線性濾波：取周圍 4 個 texel 加權平均，放大時平滑。

各種貼圖

貼圖用途
顏色（albedo）表面的基本顏色
法線表面細節的凹凸（第 16 課）
粗糙度、金屬度PBR 材質參數（第 20 課）
環境遮蔽（AO）縫隙與角落的陰暗
發光自己會發光的部分
環境貼圖反射周圍的景物

一個遊戲角色常同時使用五、六張貼圖。紋理是 GPU 記憶體最大的用戶之一，所以會使用專門的壓縮格式（如 BC、ASTC），讓 GPU 可以直接讀取壓縮的資料。

🧭 這一課的重點

紋理映射以頂點的 UV 座標把 2D 圖片貼到 3D 表面，內部由重心座標插值，UV 展開必有接縫與變形；取樣有最近鄰（方塊狀）與雙線性濾波（平滑）；常見貼圖有顏色、法線、粗糙度金屬度、AO、發光、環境貼圖；紋理使用 BC、ASTC 等 GPU 壓縮格式。
