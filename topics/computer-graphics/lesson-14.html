GPU 渲染管線

這一課的目標

  • 認識 GPU 渲染管線的各階段

著色器

2001 年前後，GPU 開始支援可程式化著色器：開發者可以用小程式（GLSL、HLSL）自訂頂點與像素的處理方式。這讓水面、皮膚、毛髮、卡通風格等效果成為可能。後來的「計算著色器」更讓 GPU 用於圖形以外的通用計算，最終促成了 AI 的爆發（見〈GPU 與平行運算〉）。

圖形 API

API說明
OpenGL / OpenGL ES跨平台的老牌標準
Direct3D微軟 Windows 與 Xbox
Vulkan新一代低階、跨平台的 API
Metal蘋果
WebGL / WebGPU瀏覽器中的 3D 圖形

新一代的 API（Vulkan、Direct3D 12、Metal）把更多控制權交給開發者，減少驅動程式的負擔，但也讓程式變得更複雜。

🧭 這一課的重點

GPU 管線依序為輸入組裝、頂點著色器、選用的曲面細分與幾何著色器、裁剪與光柵化、片段著色器、輸出合併；2001 年前後出現可程式化著色器（GLSL、HLSL），計算著色器促成 GPU 通用計算與 AI；圖形 API 有 OpenGL、Direct3D、Vulkan、Metal、WebGL 與 WebGPU。
