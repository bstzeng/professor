Layout 是什麼：一疊透明投影片

這一課的目標

  • 理解 layout 是「多層的平面幾何圖」
  • 知道 layout 和光罩、製程步驟的對應關係
  • 認識 GDSII／OASIS 檔案格式

晶片是用類似「照相」的方式一層一層做出來的：在晶圓上塗感光材料、用光透過光罩曝光、再蝕刻或沉積材料。每一個步驟需要一張圖案，告訴機器「這一層哪裡要留、哪裡要去掉」。Layout 就是這些圖案的總和。

1. 一疊投影片

想像一疊透明投影片，每一張畫著不同顏色的方塊與線條：綠色代表電晶體所在的區域，紅色代表閘極，藍色代表導線……把它們疊在一起從上往下看，就是 layout 工具裡看到的彩色畫面。

2. 常見的層

層代表什麼類比
Well（井）基板中摻雜不同型態的大區域，PMOS 要放在 N-well 裡地基的分區
Active／Diffusion要製作電晶體源極、汲極與通道的區域房子的地板
Poly（多晶矽閘極）跨過 Active 的線條，就是電晶體的閘極開關
Contact從電晶體往上連到第一層金屬的小洞樓梯
Metal 1、2、3…一層層的金屬導線不同樓層的走廊
Via連接相鄰兩層金屬的小洞樓層之間的樓梯

先進製程中，閘極多半已改用金屬閘極，但 layout 上仍習慣稱這一層為 poly 或 gate。

3. 最終檔案：GDSII

整顆晶片的 layout 最後存成 GDSII（或更新的 OASIS）格式：裡面沒有「電晶體」「導線」這些概念，只有「第幾層、座標在哪的多邊形」。一顆大型晶片的 GDSII 檔案可以大到數十、數百 GB。晶圓廠拿到這份檔案，再轉換成一張張光罩。

所以「設計一顆晶片」最終就是在回答一個問題：這幾十層圖案，每一個多邊形要畫在哪裡？接下來的課程，會一步步告訴你這些多邊形是怎麼被決定的。

產業現場

早期的晶片真的是用手畫的：1970 年代的工程師在大張的描圖紙上畫出每一層，再用紅色膠膜（rubylith）刻出圖案，縮小拍照成光罩。Intel 4004 只有約 2,300 個電晶體，今天一顆手機晶片的數量是它的上千萬倍。
