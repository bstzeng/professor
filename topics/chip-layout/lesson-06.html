畫一個反相器：NMOS＋PMOS、電源軌與 N-well

這一課的目標

  • 看懂 CMOS 反相器的 layout
  • 理解電源軌、共用閘極、輸出節點在 layout 上的位置
  • 連結電路圖與 layout

反相器（NOT 閘）只有兩顆電晶體：一顆 PMOS 接電源（VDD）、一顆 NMOS 接地（GND），兩者的閘極接在一起當輸入，汲極接在一起當輸出（《電子電路完整課程》第 41 課）。輸入為 0 時 PMOS 導通、輸出被拉到 1；輸入為 1 時 NMOS 導通、輸出被拉到 0。

2. 逐一對照

電路圖上的東西在 layout 上
VDD 與 GND上下兩條水平的 Metal 1 粗線（電源軌）
PMOS上半部：N-well 裡的一塊 Active，被 poly 跨過
NMOS下半部：P 基板上的一塊 Active，被同一條 poly 跨過
輸入 A那條垂直的 poly，同時是兩顆電晶體的閘極
輸出 Y一段 Metal 1，把兩顆電晶體的汲極連在一起

注意這個安排的巧妙之處：一條垂直的 poly 同時當兩顆電晶體的閘極，不需要額外連線；PMOS 放上面靠近 VDD、NMOS 放下面靠近 GND，源極直接往上或往下接到電源軌，線最短。

3. 為什麼 PMOS 常常畫得比較寬

在傳統平面製程中，電洞（PMOS 的載子）的遷移率比電子低，同樣尺寸的 PMOS 電流比較小。為了讓輸出「拉高」和「拉低」一樣快，PMOS 常會畫得比 NMOS 寬。

想親手開關各層、看看它們怎麼疊出一顆反相器，可以打開本主題的互動 layout 觀察器（在主題頁的參考資料區）。

產業現場

學校的 VLSI 課程幾乎都從「親手畫一個反相器」開始：在 layout 工具裡畫出各層、跑 DRC 與 LVS 檢查，再用模擬確認它能正確反相。這是很多 layout 工程師的第一份作品。
