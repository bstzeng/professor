可測試性設計（DFT）：掃描鏈與內建自我測試

這一課的目標

  • 理解製造缺陷與測試的目的
  • 理解掃描鏈與 ATPG 的原理
  • 認識記憶體內建自我測試（MBIST）

即使設計完全正確，製造過程中的微粒、缺陷也會讓一部分晶片壞掉。每一顆晶片出廠前都要經過測試，把壞的篩掉。問題是：晶片內部的數十億個節點，外面根本碰不到。可測試性設計（Design for Testability，DFT）就是在設計時預先加入讓測試變容易的電路。

1. 掃描鏈

最核心的 DFT 技術是掃描鏈：把一般的正反器換成可以切換模式的掃描正反器，在測試模式下把所有正反器串成一條（或數百條）長長的移位暫存器。這樣測試機就能控制每一個正反器的值，並觀察每一個正反器的結果——把一個難以測試的序向電路，變成容易測試的組合邏輯。

2. ATPG：自動產生測試圖樣

ATPG（Automatic Test Pattern Generation）工具會根據故障模型自動產生測試資料。最基本的模型是「某條線卡在 0 或 1」（stuck-at），另外還有檢查速度是否正常的轉換延遲故障等。工具的目標是用最少的測試圖樣，達到極高的故障涵蓋率。

3. 記憶體內建自我測試

記憶體陣列太大又太規則，不適合用掃描鏈測試。通常會加入 MBIST 電路：晶片自己產生一連串讀寫圖樣，檢查每一個位元是否正常，找到壞位元後再用備用的列或行修復（第 38 課）。

4. DFT 對 layout 的影響

  • 掃描正反器比一般正反器大一點，DFT 電路會增加一些面積
  • 掃描鏈需要依正反器位置重新排序，縮短線長（第 23 課）
  • 測試模式下大量正反器同時切換，功耗與 IR drop 可能比正常運作時更嚴重
  • JTAG 介面讓測試機與除錯工具能存取晶片內部

產業現場

晶片測試分成晶圓階段（用探針卡直接接觸每一顆 die）與封裝後的最終測試。台灣的京元電子等測試廠，是全球半導體測試產業的重要成員。
