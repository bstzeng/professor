模組 H｜類比與客製化 layout · 第 36 課

類比電路為什麼要手工畫：匹配、對稱與共質心

這一課的目標

  • 理解類比 layout 與數位 layout 的根本差異
  • 理解元件匹配的重要性
  • 認識共質心、交錯排列與 dummy 元件等技巧

晶片中除了數位邏輯，還有許多類比電路：電源管理、類比數位轉換器（ADC）、鎖相迴路（PLL）、射頻收發器、高速介面的收發電路等。它們處理的是連續變化的電壓與電流，對微小的差異極為敏感，所以 layout 大多仍由類比 layout 工程師手工完成。

1. 數位 vs 類比 layout

數位類比
關心的事邏輯正確、時序、面積精確的電壓電流、匹配、雜訊、寄生效應
方法標準元件＋自動擺放繞線大多手工擺放與繞線
元件數數百萬到數十億數十到數千
驗證STA、DRC、LVS再加上含寄生效應的電路後模擬

2. 匹配：類比電路的核心

許多類比電路（例如差動放大器，《電子電路完整課程》第 46 課）依靠兩顆元件完全相同才能正常工作。但製程在晶圓上有漸變，溫度也有梯度，放在不同位置的兩顆電晶體會有系統性差異。所以類比 layout 的重點，是讓需要匹配的元件「經歷相同的環境」。

3. 常用技巧

技巧做法目的
共質心排列把 A、B 各拆成數份，交錯排成對稱的圖案抵消線性的製程與溫度梯度
交錯排列ABAB 交替讓兩者平均分布
Dummy 元件在陣列外圍加一圈不使用的元件讓每顆元件的邊緣環境一致
同方向擺放匹配的元件朝同一個方向避免方向造成的差異
對稱繞線兩條差動訊號線走相同長度與路徑寄生效應相同

4. 寄生效應與後模擬

類比電路對導線的電阻與電容非常敏感。完成 layout 後，要萃取寄生參數（第 29 課），放回電路中重新模擬（後模擬），確認效能仍符合規格；不符合就要修改 layout 再跑一輪。類比 layout 常是電路設計者與 layout 工程師密切合作、反覆迭代的過程。

近年也有越來越多自動化工具嘗試產生類比 layout，但在高效能電路上，人工經驗仍然非常重要。

產業現場

類比 layout 工程師在台灣 IC 設計業中是專業而搶手的職位，許多人從技術人員或相關科系入行，透過多年的專案累積經驗。好的類比 layout 工程師往往能讓同一個電路的效能明顯提升。
