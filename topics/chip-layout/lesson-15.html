RTL 設計：用 Verilog 描述硬體

這一課的目標

  • 理解 RTL（暫存器傳輸層級）的意思
  • 分辨軟體程式與硬體描述語言的根本差異
  • 認識可合成的 Verilog 基本寫法

RTL（Register Transfer Level）描述的是：資料在每一個時脈週期，如何從一組暫存器（正反器）經過組合邏輯，傳到下一組暫存器。最常用的語言是 Verilog／SystemVerilog 與 VHDL。

1. 程式與電路的根本差異

軟體（C、Python）硬體描述（Verilog）
描述的是一步一步的指令同時存在的電路結構
執行CPU 依序執行所有電路同時在運作
a + b執行一次加法放一個實體的加法器
迴圈重複執行通常代表複製很多份電路
變數記憶體中的值一條線或一組正反器

2. 兩種基本寫法

// 組合邏輯：輸出隨時跟著輸入變 assign y = (a & b) | c; // 序向邏輯：在時脈上升緣更新 always @(posedge clk) begin if (reset) count <= 0; else count <= count + 1; end

第一段會被合成成幾個邏輯閘；第二段會變成一組正反器加上一個加法器——一個計數器。

3. 可合成的子集

Verilog 原本也用來寫測試與模擬，其中有些語法（例如 #10 這種延遲、檔案讀寫、某些迴圈寫法）在真實電路中沒有對應物，不能被合成。設計者必須遵守可合成的寫法與團隊的程式規範，否則可能出現「模擬時對、做成電路卻錯」的情況。

4. 好的 RTL 決定好的 layout

RTL 寫法直接影響後端：過深的組合邏輯會讓時序難以收斂，龐大的多工器會讓繞線擁擠。有經驗的 RTL 設計者會「想著 layout 寫程式碼」，例如適當地切割管線、避免不必要的大扇出。

產業現場

AI 產生 Verilog 是近年熱門的研究方向，大型語言模型已能寫出簡單的模組；但在正確性、時序與可驗證性上仍有很大挑戰，目前主要作為工程師的輔助工具。
