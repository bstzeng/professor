NAND、NOR 與串並聯：從電路圖到 layout

這一課的目標

  • 理解 CMOS 邏輯閘上下兩半的互補結構
  • 在 layout 上辨認串聯與並聯的電晶體
  • 理解共用擴散區如何節省面積

反相器是一上一下兩顆電晶體。更複雜的邏輯閘，則是由多顆電晶體串聯或並聯組成（《電子電路完整課程》第 50 課）。

1. CMOS 的互補原則

邏輯閘上半部 PMOS（拉高網路）下半部 NMOS（拉低網路）
NAND2兩顆並聯兩顆串聯
NOR2兩顆串聯兩顆並聯

規則是：上下兩半互為「對偶」——一邊串聯，另一邊就並聯。這保證任何輸入組合下，輸出只會被其中一邊連到 VDD 或 GND，不會兩邊同時導通而短路。

2. NAND2 的 layout

在 layout 上，串聯的電晶體就是在同一塊 Active 上畫兩條 poly，中間那段擴散區同時是第一顆的汲極與第二顆的源極，連 contact 都不用打——這叫共用擴散區。並聯則是兩顆電晶體的源極接在一起、汲極接在一起，需要用金屬把它們連起來。

3. 為什麼 NAND 比 NOR 常用

串聯的電晶體越多，電流越小、速度越慢。NOR 閘的串聯部分在 PMOS 上，而 PMOS 本來就比較弱，兩者相加讓 NOR 在傳統製程中特別慢。所以實際設計中，NAND 通常比 NOR 更受青睞，而串聯超過三、四顆的邏輯閘也很少見，會改用多個小閘組合。

4. 歐拉路徑：讓 poly 排整齊

畫複雜的閘時，工程師希望 NMOS 和 PMOS 的 poly 順序一致，讓每一條 poly 能直直地從上貫穿到下，同時讓擴散區盡量連續不中斷。找這個排列順序的方法，在教科書中稱為歐拉路徑法。

產業現場

一個標準元件庫裡常有上千種元件，其中很多是 AOI、OAI 這類「一次做完 AND＋OR＋反相」的複合閘，因為把邏輯合併成一個閘，常比串好幾個小閘更省面積、更快。
