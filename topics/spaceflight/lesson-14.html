軌道六要素：用六個數字描述一條軌道

這一課的目標

  • 認識軌道六要素的幾何意義
  • 知道狀態向量與六要素如何互換
  • 理解為什麼需要兩種表示法

1. 為什麼需要六個數字

第 7 課說過：二體問題化簡後有六個自由度 （相對位置三個、相對速度三個）。 所以描述一條軌道剛好需要六個獨立參數。

最直接的六個數字就是狀態向量： (x, y, z, vx, vy, vz)。 但這組數字有一個缺點：它們每一刻都在變。

軌道六要素的設計目標是： 讓其中五個永遠不變，只有一個隨時間變化。

2. 六個要素

符號名稱決定什麼會變嗎
a半長軸軌道大小（與能量、週期）不變
e離心率軌道形狀（多扁）不變
i傾角軌道平面相對參考面的傾斜不變
Ω升交點赤經軌道平面繞參考軸轉了多少不變
ω近拱點幅角橢圓在軌道平面內的朝向不變
ν真近點角太空船此刻在軌道的哪裡一直在變

前五個定義「這是哪一條軌道」，第六個定義「現在在哪」。 這就是六要素比狀態向量好用的地方： 只要不點火，你只需要更新一個數字。

3. 三個角度的層次關係

i、Ω、ω 是三次連續旋轉，順序不能換：

從參考座標系出發，做三次旋轉： 1. 繞 Z 軸轉 Ω → 把 X 軸轉到升交點方向 2. 繞新的 X 軸轉 i → 把平面傾斜成軌道平面 3. 繞新的 Z 軸轉 ω → 把 X 軸轉到近拱點方向 現在座標系的 X 軸指向近拱點， 太空船的位置就是 (r·cos ν, r·sin ν, 0)。

升交點是軌道由南往北穿過參考平面的那個點。 春分點（vernal equinox）是參考方向， 它是天球上一個固定的方向， 不隨地球自轉改變——這一點很重要， 因為 Ω 是慣性座標系裡的量，不是地理經度。

軌道aei特色

兩個值得注意的數字：

  • 98.2°（太陽同步）大於 90°，意思是軌道是逆行的——衛星繞行方向與地球自轉相反。這是為了讓 J2 造成的進動方向正確（第 11 課）。
  • 63.4°（Molniya）不是隨便選的。在這個傾角，J2 造成的近地點進動剛好為零，所以遠地點可以永遠固定在北半球上空。這個角度的來源是 5·cos²i − 1 = 0。

5. 從狀態向量算出六要素

輸入：r 向量、v 向量（在慣性座標系中） 1. r = |r|, v = |v| 2. h = r × v 角動量向量 3. n = ẑ × h 節線向量（指向升交點） 4. e = [(v² − μ/r)r − (r·v)v] / μ 離心率向量 5. ε = v²/2 − μ/r 6. a = −μ/(2ε) 7. e = |e| 8. i = acos(h_z / |h|) 9. Ω = acos(n_x / |n|) 若 n_y < 0 則 Ω = 360° − Ω 10. ω = acos(n·e / (|n||e|)) 若 e_z < 0 則 ω = 360° − ω 11. ν = acos(e·r / (|e| r)) 若 r·v < 0 則 ν = 360° − ν

後面四步的「若…則」是象限判斷。 acos 的值域只有 0 到 180 度， 所以必須用另一個量的正負號來決定落在哪一半。 這是實作時最容易出錯的地方。

6. 反過來：從六要素算出狀態向量

1. p = a(1 − e²) 2. r = p / (1 + e·cos ν) 3. 在軌道平面座標系（近拱點方向為 X） r_pqw = [ r·cos ν, r·sin ν, 0 ] v_pqw = √(μ/p) · [ −sin ν, e + cos ν, 0 ] 4. 旋轉回慣性系（三次旋轉的合成矩陣） r_ijk = R3(−Ω) · R1(−i) · R3(−ω) · r_pqw v_ijk = R3(−Ω) · R1(−i) · R3(−ω) · v_pqw

第 3 步那個 vpqw 的形式值得記住—— 它把速度直接寫成 ν 的函數， 完全不需要微分。 它的推導只用到軌道方程與角動量守恆。

7. 兩種表示法各自的用途

場合用哪一種原因
數值積分狀態向量微分方程直接作用在 r、v 上
長期軌道預報六要素只有一個量在變，誤差不會累積到形狀上
描述與編目六要素人類看得懂，可以直接比較兩條軌道
機動規劃兩者都用用要素規劃、用向量執行
會合與近距操作相對座標兩條軌道幾乎相同，差值才是重點（第 76 課）

最後一列是一個重要的第三種表示法。 當兩艘太空船相距只有幾公里、 而軌道半徑是七千公里時， 用六要素表示會遇到嚴重的數值精度問題—— 兩組幾乎相同的大數字相減。 所以會合計算改用以目標為原點的局部座標系。

8. 一個實際的邊界情況

六要素在某些軌道上會退化：

情況問題處理方式
圓軌道（e = 0）沒有近拱點，ω 無定義改用緯度幅角 u = ω + ν
赤道軌道（i = 0）沒有升交點，Ω 無定義改用近拱點經度 ϖ = Ω + ω
圓 + 赤道兩者都無定義改用真經度 l = Ω + ω + ν

GEO 衛星同時滿足兩個退化條件， 所以實務上都用「真經度」或「星下點經度」來描述， 而不是 Ω 與 ω。

這類退化不是物理問題，是座標選擇的問題。 軌道本身完全正常，只是我們選的六個數字裡 有些失去了意義。 現代軌道軟體常改用等效要素（equinoctial elements） 來避開所有奇異點。
