再入的物理：11 km/s 的熱與 Allen–Eggers 解

這一課的目標

  • 推導 Allen–Eggers 彈道再入解
  • 算出峰值減速度與它發生的高度
  • 理解「鈍頭」為何能降低熱負荷

1. 要處理多少能量

指揮艙 5,560 kg，再入速度 10,982 m/s 動能 = ½ × 5,560 × 10,982² = 3.353 × 10¹¹ J 每公斤 = ½ × 10,982² = 60.3 MJ/kg 對照（第 1 課的表） TNT 爆炸 4.6 MJ/kg 汽油燃燒 46 MJ/kg → 指揮艙的動能相當於它自身質量的 13 倍 TNT，或 1.3 倍的汽油完全燃燒。 這些能量必須在約 10 分鐘內全部消散掉。

2. Allen–Eggers 的假設

1953 年 H. Julian Allen 與 A. J. Eggers 的分析 假設 1. 指數大氣：ρ = ρ₀ e^(−h/H) 2. 飛行路徑角 γ 在減速段近似為常數（陡峭再入） 3. 忽略重力（減速度遠大於 g） 4. 忽略升力（純彈道） 5. 彈道係數 B = m/(C_d·A) 為常數 運動方程 m·dV/dt = −½ρV²·C_d·A 換成以高度為自變數（dh = V sin γ dt，注意 γ < 0） dV/dh = ½ρ₀ e^(−h/H) V C_d A / (m·sin|γ|) 分離變數並積分
解 ┌──────────────────────────────────────────────┐ │ V(h) = V_E · exp( −ρ₀H e^(−h/H) / (2B sin|γ|) ) │ └──────────────────────────────────────────────┘ 其中 B = m/(C_d A) 是彈道係數（單位 kg/m²） V_E 是進入介面的速度

3. 峰值減速度

對 V(h) 求減速度並找極值 減速度 a = V·dV/dh · sin|γ| ... （鏈鎖律） 令 da/dh = 0，可得峰值發生在 ┌────────────────────────────────────┐ │ V_peak = V_E / e （e = 2.71828） │ └────────────────────────────────────┘ 這是一個非常漂亮的結果： 峰值減速度永遠發生在「速度降到入口速度的 1/e」時， 與彈道係數、進入角、大氣密度全部無關。 對阿波羅：V_peak = 10,982/2.71828 = 4,040 m/s 峰值減速度的大小 ┌────────────────────────────────────┐ │ a_max = V_E² · sin|γ| / (2·e·H) │ └────────────────────────────────────┘ 同樣與彈道係數無關！ 代入 V_E = 10,982 m/s γ = 6.5°，sin γ = 0.11320 H = 7,160 m a_max = (10,982² × 0.11320)/(2 × 2.71828 × 7,160) = 1.36524e7 / 38,926 = 350.7 m/s² = 35.8 g

4. 峰值發生的高度

h_peak = H · ln( ρ₀H / (B·sin|γ|) ) 彈道係數（指揮艙） m = 5,560 kg 底部直徑 3.91 m → A = π(3.91/2)² = 12.01 m² C_d ≈ 1.3（鈍體） B = 5,560/(1.3 × 12.01) = 356.2 kg/m² 代入 h_peak = 7,160 × ln(1.225 × 7,160/(356.2 × 0.11320)) = 7,160 × ln(8,771/40.32) = 7,160 × ln(217.5) = 7,160 × 5.382 = 38,535 m ≈ 38.5 公里 峰值減速度發生在約 38 公里高度。 這與實際觀測的阿波羅再入「最亮」的時段吻合 —— 那正是能量耗散最快的時候。

注意 B 只影響「在哪裡」減速最猛， 不影響「有多猛」。 彈道係數越小（越輕、越大、阻力越大）， 減速發生在越高的地方—— 而那正是降低熱負荷的關鍵。

5. 為什麼是鈍頭

1951 年 Allen 的洞見，是整個載人再入技術的起點。

直覺（錯的） 「要減少空氣阻力造成的加熱，所以做成尖的、流線的。」 Allen 的洞見（對的） 不是要減少總加熱，是要讓熱進到「空氣」而不是「載具」。 機制 尖銳外型 激波緊貼表面（附體激波） 高溫氣體直接接觸載具 邊界層薄 → 對流熱傳極強 → 大部分熱進入載具 鈍頭外型 激波脫體，在載具前方形成一道弓形激波 激波與載具之間有一層「激波層」 高溫氣體大部分沿著激波層流向側面被帶走 → 只有一小部分熱進入載具 而且鈍頭的阻力大 → 彈道係數小 → 在高空就減速 → 峰值加熱發生在密度低處 → 熱流更小
量化：熱流的 Sutton–Graves 關係 q̇ = k · √(ρ/R_n) · V³ k = 1.7415e-4（SI 單位） R_n = 鼻端（熱盾）的曲率半徑 三個關鍵依賴 q̇ ∝ V³ ← 速度的三次方！ q̇ ∝ √ρ ← 在高空減速有利 q̇ ∝ 1/√R_n ← 曲率半徑越大，熱流越小 最後一項就是「鈍頭」的直接好處。 阿波羅指揮艙 熱盾的曲率半徑約 4.7 公尺（幾乎是一個扁球面） 在峰值時 ρ ≈ 5.63e-3 kg/m³，V ≈ 4,040 m/s q̇ = 1.7415e-4 × √(5.63e-3/4.7) × 4,040³ = 1.7415e-4 × 0.03461 × 6.594e10 = 3.97 MW/m² 註：這是用峰值減速時刻的速度算的。 實際的峰值熱流發生得更早（速度更高、密度較低的時刻）， 阿波羅的實測峰值熱流約 3–5 MW/m²。

如果做成尖頭， R_n 降到 0.1 公尺， 熱流會變成 √(4.7/0.1) = 6.9 倍—— 而且激波附體讓更高比例的熱進入載具。 任何已知的材料都撐不住。

6. 熱流 vs 總熱量

熱流 q̇（W/m²）總熱量 Q（J/m²）
決定表面最高溫度燒蝕層厚度
依賴V³、√ρ、1/√R_n對時間積分
鈍頭大幅降低略增（飛行時間變長）
高空減速大幅降低略增
升力式再入降低增加（時間更長）
這是一個真實的取捨 升力式再入（第 82 課）把峰值過載從 36 g 降到 6.5 g， 峰值熱流也降低了。 但它把再入時間從約 3 分鐘拉長到約 10 分鐘， → 總熱量增加 → 熱盾必須更厚 阿波羅的熱盾底部厚 7 公分、重約 640 公斤（第 33 課）。 純彈道再入的熱盾可以薄一些， 但那樣太空人會死於過載。 又一次：Δv 或質量不是唯一的成本。

7. 從月球回來 vs 從低軌道回來

速度只差 41%，但熱流差 2.8 倍。 V³ 這個指數，就是為什麼從月球回來 比從太空站回來難得多。

而從火星回來會更快（12–14 km/s）， 熱流再高 60–130%。 這是載人火星任務的一個真實技術門檻。
