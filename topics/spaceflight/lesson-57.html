影響球：什麼時候「歸月球管」

這一課的目標

  • 區分「引力相等點」與「影響球」
  • 理解為何後者才是正確的分界
  • 看懂座標切換的實際操作與誤差

1. 兩個都叫「分界」的地方

引力相等點（equigravisphere） μ_E/(D−x)² = μ_M/x² → x = D·√μ_M/(√μ_E + √μ_M) = 384,400 × √4902.8/(√398600 + √4902.8) = 384,400 × 70.02/(631.35 + 70.02) = 384,400 × 0.09983 = 38,376 km （距月心） 影響球（Laplace sphere of influence） r_SOI = D·(m_M/m_E)^(2/5) = 384,400 × 0.0123^0.4 = 66,183 km （距月心） 兩者差了 1.7 倍。

更奇怪的是：在影響球邊界上， 地球的引力還是月球的 3.5 倍。

在 r = 66,183 km（距月心）處 距地心 = 384,400 − 66,183 = 318,217 km g_地球 = 398,600/318,217² = 3.936e-6 km/s² g_月球 = 4,902.8/66,183² = 1.119e-6 km/s² 比值 = 3.52 地球的引力大得多， 但我們卻說「這裡開始歸月球管」。

2. 為什麼影響球才是對的

關鍵在於：我們關心的不是絕對引力， 而是「相對運動」由誰主導。

在月心座標系中，太空船的運動方程 加速度 = 月球的引力（主項） + 地球對太空船的引力 − 地球對月球的引力 ← 這一項！ 最後兩項合起來叫「潮汐項」或「攝動項」。 因為地球同時拉著太空船與月球， 兩者的差才是真正造成相對運動偏離的部分。 地球對太空船 g = 3.936e-6 地球對月球 g = 398,600/384,400² = 2.698e-6 差 = 1.238e-6 ← 這才是攝動量 對照月球的主項 1.119e-6 兩者同量級 → 所以這裡確實是分界。

這就是 Laplace 定義的內涵。 他比較的是兩個「攝動比」：

以地球為主天體時： 攝動比 = (月球的攝動) / (地球的主力) 以月球為主天體時： 攝動比 = (地球的攝動) / (月球的主力) 在影響球邊界上，這兩個比值相等。 → 換座標系不會讓近似變得更差， 但再往裡面走就會變得更好。

3. 幾個天體的影響球

天體相對誰SOI 半徑佔軌道半徑
月球地球66,200 km17.2%
地球太陽924,000 km0.62%
火星太陽577,000 km0.25%
木星太陽48,200,000 km6.2%
水星太陽112,000 km0.19%

月球那一列特別大（17.2%）， 因為地月質量比不像其他行星對太陽那麼懸殊。 這也是為什麼地月系統的 patched conic 近似 比行星際的差—— 「切換區」佔了整段路程太大的比例。

對照 地球的 SOI 只佔它到太陽距離的 0.62% → 行星際任務中，「在地球影響球內」的那一段 幾乎可以視為一個點，patched conic 誤差很小 月球的 SOI 佔地月距離的 17.2% → 「切換」發生在一個很大的區域裡， 而在那個區域裡兩個天體的影響都不可忽略 這是第 48 課說「patched conic 對月球任務誤差較大」 的根本原因。

4. 切換的實際操作

在影響球邊界上 已知（地心座標） r_地心, v_地心（太空船） r_月, v_月（從星曆查） 轉換 r_月心 = r_地心 − r_月 v_月心 = v_地心 − v_月 然後用 μ_M 重新計算軌道要素（第 14 課） h = r_月心 × v_月心 ε = v_月心²/2 − μ_M/r_月心 a = −μ_M/(2ε) ← 會是負的（雙曲線） e = √(1 + 2εh²/μ_M²) r_p = a(1 − e) v∞ = √(2ε)
阿波羅的典型數值 在影響球邊界 |v_地心| ≈ 0.36 km/s（已經爬得很慢了） |v_月| = 1.022 km/s（月球公轉） 向量相減之後 |v_月心| ≈ 1.15 km/s 用月球的 μ 算 ε = 1.15²/2 − 4902.8/66183 = 0.6613 − 0.0741 = 0.5872 km²/s² ε > 0 → 雙曲線 ✔ v∞ = √(2 × 0.5872) = 1.084 km/s 咦？第 51 課用的是 v∞ = 0.9 km/s。 差異來自： 這裡用的是「在 SOI 邊界的速度」當作 v∞ 的近似， 但 v∞ 嚴格說是「無窮遠處」的速度。 在有限距離上，還要扣掉已經被月球加速的部分。 更精確地說 v∞ = √(v² − 2μ_M/r) = √(1.15² − 2×4902.8/66183) = √(1.3225 − 0.1482) = 1.084 km/s 實際任務的 v∞ 落在 0.8–1.1 km/s 之間， 依到達幾何而異。本課後續採用 0.9 km/s。

5. 誤差有多大

近似造成的誤差
在邊界「突然」切換速度向量有數 m/s 的不連續
忽略地球在月球影響球內的攝動近月點偏差數百公里
忽略月球在地球段的攝動到達時刻偏差數小時
忽略太陽累積數十公里
影響球假設為球形實際上是一個略扁的曲面
總誤差：近月點高度可能差數百到數千公里 對照目標精度：數十公里 → patched conic 只能當「初始猜測」 真實任務的流程（第 48 課提過） 1. patched conic 給初始猜測 2. 完整數值積分 + 差分修正迭代 3. 飛行中用四次 MCC 吸收剩餘誤差（第 54 課） 換句話說： patched conic 的誤差最終是由「中途修正」買單的， 而那筆帳只有幾 m/s —— 完全可以接受。

6. 一個觀念上的釐清

影響球不是一道牆。 太空船穿過它時什麼事都沒發生—— 重力是連續的，運動是平滑的。

影響球只是一個計算上的約定。 它標示的是「從這裡開始， 用月心二體模型比用地心二體模型更準」。

類比 這就像「熱帶」與「溫帶」的分界線。 實際上氣候是連續變化的， 但在某條緯度以北，用「溫帶模型」描述會比較準。 沒有人會在跨越北回歸線時感覺到什麼。

但這個約定有實際後果。 阿波羅的導航在通過影響球時， AGC 會切換到月心座標系運作， 地面的定軌軟體也會換一套參考系。 那是一個真實的軟體事件， 儘管物理上什麼都沒發生。
