模組 B｜軌道力學（一）：從牛頓到圓錐曲線 · 第 10 課

能量守恆與 vis-viva 的推導

這一課的目標

  • 從運動方程推導出能量守恆
  • 導出 vis-viva 公式
  • 理解為何「軌道能量只跟半長軸有關」

1. 推導：把運動方程點乘速度

運動方程 r̈ = −μ/r³ · r 兩邊與 v（= ṙ）做內積 ṙ · r̈ = −μ/r³ · (r · ṙ) 左邊：注意 d(v·v)/dt = 2 v·v̇，所以 ṙ · r̈ = ½ d(v²)/dt 右邊：注意 r² = r·r，微分得 2r·ṙ = 2(r · ṙ) 所以 r · ṙ = r·ṙ −μ/r³ · (r·ṙ) = −μ·ṙ/r² = d(μ/r)/dt 合併 ½ d(v²)/dt − d(μ/r)/dt = 0 d/dt [ v²/2 − μ/r ] = 0 ┌──────────────────────────┐ │ ε ≡ v²/2 − μ/r = 常數 │ └──────────────────────────┘

ε 叫比機械能（specific orbital energy）， 單位 km²/s²。 它是動能項與位能項的和，而且沿著軌道永遠不變。

位能項寫成 −μ/r，是因為我們把無窮遠處定為零位能。 所以束縛軌道的 ε 一定是負的， 逃逸軌道的 ε 一定是正的或零。

2. 把 ε 跟半長軸連起來

在近地點，r 與 v 垂直，而且 r = a(1 − e)：

在近地點 ε = v_p²/2 − μ/r_p 用 h = r_p·v_p 代換 v_p ε = h²/(2r_p²) − μ/r_p 代入 h² = μ·p = μ·a(1−e²) 與 r_p = a(1−e) ε = μa(1−e²)/(2a²(1−e)²) − μ/(a(1−e)) = μ(1+e)(1−e)/(2a(1−e)²) − μ/(a(1−e)) = μ(1+e)/(2a(1−e)) − μ/(a(1−e)) = μ[(1+e) − 2] / (2a(1−e)) = μ(e−1)/(2a(1−e)) = −μ/(2a) ┌──────────────────┐ │ ε = −μ/(2a) │ └──────────────────┘

這是軌道力學裡最重要的結論之一： 軌道能量只取決於半長軸，跟離心率完全無關。

一條又扁又長的橢圓，和一個半徑等於它半長軸的圓， 能量完全相同，週期也完全相同。 這一點會在霍曼轉移（第 16 課）與會合（第 76 課）不斷被使用。

3. Vis-viva 公式

把兩個式子合併——這就是整門課用得最多的一行：

v²/2 − μ/r = −μ/(2a) ┌────────────────────────────┐ │ v² = μ (2/r − 1/a) │ │ │ │ v = √( μ (2/r − 1/a) ) │ └────────────────────────────┘

「vis viva」是拉丁文「活力」的意思， 是萊布尼茲對動能的舊稱。

這條公式的威力在於： 只要知道現在的距離 r 和軌道的半長軸 a， 就能立刻算出速度。 不需要知道離心率、不需要知道在軌道的哪個位置、 不需要知道時間。

4. 三個立即的特例

圓軌道：r = a v = √(μ(2/r − 1/r)) = √(μ/r) ✔ 第 2 課的公式 拋物線逃逸：a = ∞，1/a = 0 v = √(2μ/r) ✔ 逃逸速度 雙曲線：a < 0（負的！） v = √(μ(2/r + 1/|a|)) > √(2μ/r) ✔ 超過逃逸速度

雙曲線的半長軸是負數，這一開始很怪， 但它讓 vis-viva 對所有軌道型態統一成立。 第 13 課會解釋這個負號的幾何意義。

5. 用 vis-viva 算 TLI

先預覽第 50 課的計算，感受一下這條公式的用法。

目標：從 185 km 圓軌道，飛到 406,563 km 的遠地點 停泊軌道速度 r = 6378 + 185 = 6,563 km v_circ = √(398600/6563) = 7.7932 km/s 轉移軌道的半長軸 a = (r_p + r_a)/2 = (6563 + 406563)/2 = 206,563 km 轉移軌道在近地點的速度 v_p = √(398600 × (2/6563 − 1/206563)) = √(398600 × (3.04739e-4 − 4.84116e-6)) = √(398600 × 2.99898e-4) = √119.539 = 10.9334 km/s 所需 Δv 10.9334 − 7.7932 = 3.1402 km/s

兩行 vis-viva 就得到了阿波羅最關鍵的那個數字。 實際任務的 TLI Δv 約 3.05–3.20 km/s， 差異來自有限推力、目標點的變化與餘裕， 但量級完全正確。

6. 能量圖：一個很有用的視覺化

這張圖一眼說明了三件事：

  • ε < 0：能量線與位能曲線相交，太空船被困在交點以內 → 橢圓。
  • ε = 0：能量線與位能曲線在無窮遠處相切 → 拋物線，到無窮遠時速度剛好為零。
  • ε > 0：永遠不相交 → 雙曲線，到無窮遠仍有剩餘速度 v∞ = √(2ε)。

v∞ = √(2ε) 這個量叫「雙曲線超速」， 它是行星際任務最核心的參數， 第 93 課算火星任務時會大量使用 （那裡會用它的平方，寫成 C3 = v∞²= 2ε）。

7. 為什麼這條公式這麼好用

比較一下要算軌道速度有哪些方法：

方法需要知道難度
數值積分運動方程初始狀態、積分器需要電腦
解克卜勒方程求位置再微分六要素、時間、迭代求根繁瑣
vis-vivar 和 a，兩個數字一行

代價是 vis-viva 只給你速度大小， 不給方向、不給時間、不給位置。 但對於算 Δv 來說，這剛好就是我們要的全部—— 因為 Δv 發生在近地點或遠地點， 那裡的速度方向本來就是確定的（垂直於半徑）。

這就是為什麼幾乎所有任務規劃的第一輪估算 都只用 vis-viva 和霍曼轉移。
