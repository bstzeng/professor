動手算：去火星要多少 C3 與 Δv

這一課的目標

  • 從頭算出火星任務的完整 Δv 帳
  • 比較各種抵達方案
  • 把它與阿波羅的帳並排

1. 常數

μ_S = 1.32712440018e11 km³/s² μ_E = 398,600.4418 km³/s² μ_Ma = 42,828.37 km³/s² AU = 1.495979e8 km R_E = 6,378.137 km R_Ma = 3,396.2 km 地球軌道 1.000 AU 火星軌道 1.524 AU（平均） 停泊軌道 185 km → r_p = 6,563.1 km

2. 第一步：日心轉移橢圓

a = (1.000 + 1.524)/2 × AU = 1.2618 × 1.495979e8 = 1.88767e8 km 地球公轉速度 v_E = √(μ_S/AU) = √(1.32712e11/1.495979e8) = √887.12 = 29.785 km/s 轉移橢圓在近日點（地球軌道）的速度 v_p = √(μ_S(2/r_E − 1/a)) = √(1.32712e11 × (2/1.495979e8 − 1/1.88767e8)) = √(1.32712e11 × (1.336915e-8 − 5.29752e-9)) = √(1.32712e11 × 8.07163e-9) = √1071.19 = 32.729 km/s

3. 第二步：離開地球的 v∞ 與 C3

v∞ = v_p − v_E = 32.729 − 29.785 = 2.944 km/s C3 = v∞² = 8.67 km²/s² ┌──────────────────────┐ │ C3 = 8.67 km²/s² │ └──────────────────────┘ 這是火星任務最常被引用的數字。 發射載具的規格書都用 C3 當橫軸（第 13 課）。

4. 第三步：從 LEO 出發的 Δv

在 185 km 停泊軌道 v_circ = √(398,600.44/6,563.1) = √60.7335 = 7.7932 km/s 需要的近地點速度（雙曲線 vis-viva） v_p = √(v∞² + 2μ_E/r_p) = √(8.67 + 2 × 398,600.44/6,563.1) = √(8.67 + 121.467) = √130.137 = 11.408 km/s ┌────────────────────────────────┐ │ Δv = 11.408 − 7.793 = 3.615 │ └────────────────────────────────┘ 對照 剛好逃逸地球：3.228 km/s 去火星： 3.615 km/s 多付 0.387 km/s（12%），就從「剛好逃逸」 變成「能飛到火星」。 這是 Oberth 效應（第 21 課）最實際的展現。

5. 第四步：抵達火星

轉移橢圓在遠日點（火星軌道）的速度 v_a = √(μ_S(2/r_Ma − 1/a)) = √(1.32712e11 × (2/(1.524 × 1.495979e8) − 1/1.88767e8)) = √(1.32712e11 × (8.77155e-9 − 5.29752e-9)) = √(1.32712e11 × 3.47403e-9) = √461.06 = 21.472 km/s 火星公轉速度 v_Ma = √(μ_S/(1.524 AU)) = √(1.32712e11/2.27987e8) = √582.10 = 24.127 km/s 相對火星的 v∞ v∞ = 24.127 − 21.472 = 2.655 km/s 太空船比火星慢 —— 火星從後面追上它（第 91 課）。

6. 三種抵達方案

方案 A：進入 400 km 圓軌道（純推進） r_p = 3,396.2 + 400 = 3,796.2 km v_hyp = √(2.655² + 2 × 42,828.37/3,796.2) = √(7.049 + 22.562) = √29.611 = 5.442 km/s v_circ = √(42,828.37/3,796.2) = √11.2812 = 3.359 km/s Δv = 5.442 − 3.359 = 2.083 km/s 方案 B：進入 400 × 33,000 km 橢圓捕獲軌道 r_a = 3,396.2 + 33,000 = 36,396.2 km a = (3,796.2 + 36,396.2)/2 = 20,096.2 km v_p = √(42,828.37 × (2/3,796.2 − 1/20,096.2)) = √(42,828.37 × (5.26842e-4 − 4.97607e-5)) = √(42,828.37 × 4.77081e-4) = √20.4326 = 4.520 km/s Δv = 5.442 − 4.520 = 0.922 km/s 比方案 A 省 1.16 km/s（56%） 方案 C：直接進入大氣（EDL，第 96 課） Δv = 0 進入速度（在 125 km 高度） v = √(2.655² + 2 × 42,828.37/3,521.2) = √(7.049 + 24.327) = √31.376 = 5.601 km/s
為什麼方案 B 這麼省 同樣的 Oberth 效應（第 21 課）： 在近火點，太空船的速度最快（5.44 km/s）。 在那裡減速 0.92 km/s，就足以把能量從正變負（捕獲）。 但要再從橢圓降到圓軌道， 必須在速度已經變慢之後再減速 —— 效率低得多。 現代的做法：先進入橢圓（0.92 km/s）， 再用 aerobraking（每圈輕微掠過大氣層頂） 花幾個月慢慢把遠火點降下來。 aerobraking 的 Δv 成本接近零， 代價是幾個月的時間與持續的操作風險。 火星全球探勘者號、奧德賽號、MRO 都用了這個技術。

關鍵的不對稱 去火星便宜（因為有大氣減速） 離開火星貴（因為重力比月球大 2.3 倍、 而且要克服大氣阻力） 火星表面的逃逸速度 5.03 km/s 月球表面的逃逸速度 2.38 km/s 來回總帳只差 1.5 km/s， 但質量比的差距是指數的： 用 ve = 3.5 km/s 月球：e^(9.0/3.5) = e^2.571 = 13.1 火星：e^(10.5/3.5) = e^3.0 = 20.1 質量比差 53%。 再加上任務時間 978 天 vs 8 天所需的消耗品， 載人火星任務的實際質量需求是登月的十倍以上。

9. 一個關鍵的緩解手段：就地資源利用

In-Situ Resource Utilization（ISRU） 火星大氣 95% 是 CO₂。 用電解與 Sabatier 反應可以製造氧氣與甲烷： 2 H₂O → 2 H₂ + O₂ （電解，水來自地下冰） CO₂ + 4 H₂ → CH₄ + 2 H₂O （Sabatier 反應） 甲烷 + 液氧 = 一組可用的推進劑（Isp 約 370 s，第 25 課） 效果 回程所需的 6.2 km/s 的推進劑， 不必從地球帶過去。 質量影響 帶回程推進劑：起飛質量 ∝ e^(10.5/ve) 就地製造： 起飛質量 ∝ e^(4.3/ve) 用 ve = 3.5：20.1 vs 3.4 → 質量需求減少約 83% 這就是為什麼所有嚴肅的載人火星任務規劃 都把 ISRU 當成前提，而不是選項。 毅力號上的 MOXIE 實驗（2021–2023） 已經在火星上實際製造出氧氣（每小時約 6–10 克）， 驗證了原理。
