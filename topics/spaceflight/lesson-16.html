霍曼轉移：兩圈之間最省的走法

這一課的目標

  • 推導霍曼轉移的兩次 Δv 公式
  • 理解為什麼需要兩次點火
  • 知道霍曼在什麼條件下不是最省的

1. 問題設定

從半徑 r₁ 的圓軌道，轉移到同一平面上半徑 r₂ 的圓軌道。 用最少的 Δv 怎麼做？

德國工程師 Walter Hohmann 在 1925 年給出答案： 用一條與兩個圓都相切的橢圓。

轉移橢圓的近拱點在 r₁，遠拱點在 r₂， 所以它的半長軸是：

a_t = (r₁ + r₂)/2

2. 推導

起點圓軌道速度 v₁ = √(μ/r₁) 轉移橢圓在 r₁ 處的速度（vis-viva） v_p = √(μ(2/r₁ − 1/a_t)) 第一次點火 Δv₁ = v_p − v₁ = √(μ(2/r₁ − 1/a_t)) − √(μ/r₁) 轉移橢圓在 r₂ 處的速度 v_a = √(μ(2/r₂ − 1/a_t)) 目標圓軌道速度 v₂ = √(μ/r₂) 第二次點火 Δv₂ = v₂ − v_a 總計 Δv = Δv₁ + Δv₂

也可以寫成只用比值 R = r₂/r₁ 的緊湊形式：

Δv/v₁ = √(2R/(1+R)) − 1 + (1/√R)(1 − √(2/(1+R)))

3. 為什麼一定要兩次

回到第 6 課的陷阱一：任何封閉軌道都會回到出發點。

第一次點火之後，太空船進入一條橢圓， 它的近拱點還在 r₁。 如果不做第二次點火，它會盪到 r₂ 然後掉回 r₁， 週而復始。

第二次點火的作用是「把近拱點抬到 r₂」， 也就是把橢圓圓化。 這件事只能在遠拱點做—— 在其他任何位置點火，都無法只改變近拱點而不改變遠拱點。

4. 動手算一次：LEO → GEO

r₁ = 6,563 km（185 km 高度） r₂ = 42,164 km（地球同步） v₁ = √(398600/6563) = 7.7932 km/s v₂ = √(398600/42164) = 3.0747 km/s a_t = (6563 + 42164)/2 = 24,363.6 km v_p = √(398600 × (2/6563 − 1/24363.6)) = √(398600 × (3.04739e-4 − 4.10450e-5)) = √(398600 × 2.63694e-4) = √105.108 = 10.2521 km/s Δv₁ = 10.2521 − 7.7932 = 2.4590 km/s v_a = √(398600 × (2/42164 − 1/24363.6)) = √(398600 × (4.74338e-5 − 4.10450e-5)) = √(398600 × 6.38884e-6) = √2.5466 = 1.5958 km/s Δv₂ = 3.0747 − 1.5958 = 1.4788 km/s 總計 Δv = 3.9378 km/s 飛行時間 = T/2 = π√(a_t³/μ) = π√(24363.6³/398600) = π√(36,283,000) = π × 6,023.6 = 18,923 s = 5.26 小時

這就是每一顆同步衛星都要付的代價。 3.94 km/s，加上入軌的 9.4，總共約 13.3 km/s—— 比去月球（9.4 + 3.14 + 0.9 = 13.4）只少一點點。

5. 兩個觀察

觀察一：Δv₁ 比 Δv₂ 大，但這不總是成立

R = r₂/r₁ = 6.42 Δv₁ = 2.459 （62%） Δv₂ = 1.479 （38%） 當 R 很小（例如 1.1，小幅抬高軌道） 兩次 Δv 幾乎相等 當 R 很大（例如 60，去月球距離） Δv₁ 佔絕大部分，Δv₂ 變得很小

後者正是 TLI 的情況：去月球的 Δv 幾乎全在第一腳。 而「第二腳」則變成了 LOI， 只是那時中心天體已經換成月球了（第 60 課）。

觀察二：Δv 有一個上限

當 R → ∞（轉移到無窮遠） Δv₁ → √(2μ/r₁) − √(μ/r₁) = (√2 − 1)·v₁ = 0.4142 · v₁ Δv₂ → 0 總 Δv → 0.4142 × 7.7932 = 3.228 km/s

這就是逃逸的 Δv（第 2 課）。 霍曼轉移的 Δv 隨 R 增加而單調上升， 但永遠不會超過逃逸所需的值。

所以「去月球比逃離地球還便宜」不是巧合， 而是因為月球還在有限距離上。

6. 霍曼不是永遠最省：雙橢圓轉移

當 R 很大時，有一個反直覺的替代方案： 先飛得比目標更遠，再回來。

雙橢圓轉移（bi-elliptic） 1. 從 r₁ 加速到一條遠拱點在 r* 的橢圓（r* > r₂） 2. 在 r* 加速，把近拱點抬到 r₂ 3. 在 r₂ 減速圓化 為什麼可能更省？ 因為在 r* 處速度很慢，改變近拱點的成本很低（Oberth 效應的反面）
R = r₂/r₁哪個省
R < 11.94霍曼永遠較省
11.94 < R < 15.58看 r* 選多遠，可能雙橢圓較省
R > 15.58雙橢圓較省（若 r* 夠大）
LEO → GEO 的例子（R = 6.42，霍曼應該較省） 霍曼：3.938 km/s，5.3 小時 雙橢圓（r* = 500,000 km） Δv₁ = 3.156，Δv₂ = 0.208，Δv₃ = 1.101（減速） 總計 4.466 km/s 霍曼確實較省，而且快非常多。 ✔

雙橢圓的代價是時間。 飛到 50 萬公里再回來要好幾個月。 所以它在載人任務上幾乎不用， 但在深空探測器與某些軌道調整上偶爾有價值。

7. 霍曼的三個前提

課本上的霍曼轉移假設了三件事， 每一件在真實任務裡都會被打破：

假設現實影響處理
脈衝式點火（瞬間）點火要幾分鐘Δv 需求增加 1–5%有限推力修正（第 65 課）
兩軌道共面通常有夾角需要額外 Δv合併機動（第 22 課）
目標一直在那裡目標在移動要算相位Lambert（第 20 課）

第三項是去月球和去火星時最重要的。 你不是要飛到「月球現在的位置」， 而是要飛到「三天後月球會在的位置」。 第 51 課與第 92 課會處理這件事。
