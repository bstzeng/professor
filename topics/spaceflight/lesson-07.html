模組 B｜軌道力學（一）：從牛頓到圓錐曲線 · 第 7 課

二體問題：從 F = ma 寫出運動方程

這一課的目標

  • 把萬有引力定律寫成向量微分方程
  • 看清楚二體問題的完整形式
  • 知道這組方程為什麼可以解、三體為什麼不行

1. 出發點：兩條定律

牛頓第二定律 F = m·a 萬有引力定律 F = G·m₁·m₂ / r² （大小） 向量形式：從 m₁ 指向 m₂ 的力 F₁₂ = G·m₁·m₂ / |r₂ − r₁|³ · (r₂ − r₁) 注意分母是三次方，因為 (r₂ − r₁) 還帶了一個長度

整個軌道力學就是從這兩行推出來的。 沒有別的物理輸入。

2. 寫出兩個天體的運動方程

設有兩個質點，質量 m₁ 與 m₂， 在某個慣性座標系中的位置向量是 R₁ 與 R₂。

令 r = R₂ − R₁ （從 1 指向 2 的向量） r = |r| （距離） 對 m₁ 寫牛頓第二定律 m₁ · R̈₁ = G·m₁·m₂/r³ · r ……(1) 對 m₂ 寫牛頓第二定律 m₂ · R̈₂ = −G·m₁·m₂/r³ · r ……(2) （負號：m₂ 受到的力指向 m₁，方向相反）

兩個質點各有三個座標分量， 所以這是六個二階常微分方程， 需要十二個初始條件（位置三個 + 速度三個，各兩個天體）。

3. 第一次化簡：質心等速運動

把 (1) 與 (2) 直接相加：

m₁·R̈₁ + m₂·R̈₂ = 0 定義質心 Rc = (m₁R₁ + m₂R₂)/(m₁+m₂) 則 (m₁+m₂)·R̈c = 0 → R̈c = 0 → 質心以等速直線運動（或靜止）

這是一個重大的簡化。 我們可以把座標原點放在質心上， 它就是一個慣性參考系，而且六個自由度裡有三個 （質心的位置）變成了平凡解。

4. 第二次化簡：只看相對位置

真正關心的其實不是「地球在哪、太空船在哪」， 而是「太空船相對地球在哪」。 把 (2)/m₂ 減去 (1)/m₁：

R̈₂ − R̈₁ = −G·m₁/r³ · r − G·m₂/r³ · r 左邊 = r̈ r̈ = −G(m₁ + m₂)/r³ · r 定義 μ ≡ G(m₁ + m₂) ┌────────────────────────┐ │ r̈ = −μ/r³ · r │ ← 二體問題的核心方程 └────────────────────────┘

十二個自由度變成六個 （相對位置三個 + 相對速度三個）， 而且方程的形式極簡： 加速度的方向永遠指向中心，大小與距離平方成反比。

5. 這個方程的三個關鍵性質

性質一：中心力

加速度 r̈ 永遠平行於 r（只是反向）。 這種力叫中心力。 第 9 課會證明：中心力必然導致角動量守恆， 而角動量守恆必然導致軌道是平面的。

性質二：保守力

重力可以寫成一個位能函數的梯度：

U(r) = −μ/r ∇U = μ/r³ · r r̈ = −∇U → 力只與位置有關，與路徑無關 → 總能量守恆（第 10 課）

性質三：平方反比

這一點最特殊。 平方反比力有一個額外的守恆量 （Laplace–Runge–Lenz 向量，第 11 課）， 而這個額外守恆量正是軌道封閉且不進動的原因。

如果重力是 1/r2.1 而不是 1/r²， 行星軌道就會是一朵緩慢旋轉的花瓣形，而不是固定的橢圓。 水星近日點的微小進動，正是廣義相對論修正的著名證據。

6. 為什麼二體能解、三體不能

二體問題有十個運動積分（守恆量）：

守恆量個數來源
質心位置與速度6動量守恆
角動量向量 h3中心力
總能量 E1保守力

十二個自由度減去十個守恆量，剩下兩個， 再用一次時間積分就解完了。 這是一個剛好夠用的巧合。

三體問題 自由度 18（三個天體各六個） 守恆量 仍然只有 10（動量 6 + 角動量 3 + 能量 1） 剩下 8 個自由度沒有守恆量可以消掉 → 沒有一般的解析解（Poincaré, 1890） → 只能數值積分，或在特殊條件下求近似解

這個事實有兩個重大後果，貫穿整門課：

  • patched conic 方法（第 57 課）：把地月旅程切成「只受地球影響」與「只受月球影響」兩段，每段都是可解的二體問題。這是阿波羅實際使用的近似方法。
  • 數值積分（第 23 課）：真實的任務規劃必須把太陽、月球、地球扁率全部放進去，用 RK4 之類的方法逐步推進。

7. 一個容易忽略的細節：μ 到底是誰的

嚴格來說 μ = G(m₁ + m₂) 太空船繞地球 m₁ = 地球 5.97e24 kg m₂ = 太空船 1e4 kg m₂/m₁ = 1.7e-21 → 完全可以忽略 μ ≈ G·M_earth = 398,600 km³/s² ✔ 月球繞地球 m_moon/m_earth = 0.0123 → 1.23%，不能忽略 若要精確計算地月系統，μ = G(M_E + M_M) 太空船繞月球 μ ≈ G·M_moon = 4,902.8 km³/s² ✔

這門課只要處理太空船，所以永遠用中心天體的 μ 就好。 但看到月球軌道週期時要記得， 那個 27.32 天用的是地月合併的 μ。
