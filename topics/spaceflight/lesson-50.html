模組 H｜TLI：算出飛向月球的那一腳 · 第 50 課

動手算：TLI 需要多少 Δv

這一課的目標

  • 把 TLI 的 Δv 從頭算到尾
  • 檢查每一個假設
  • 與真實任務數據對照並解釋差異

1. 已知條件

地球重力參數 μ = 398,600.4418 km³/s² 地球半徑 R = 6,378.137 km 停泊軌道高度 h = 185 km 目標遠地點 r_a = 406,563 km 為什麼是 406,563 而不是月球的平均距離 384,400？ 因為軌道要設計成「在月球前方一點」與月球相遇， 而且月球軌道是橢圓（遠地點 405,500 km）， 阿波羅任務刻意選擇在月球接近遠地點時到達。 第 51 課會說明這個瞄準。

2. 步驟一：停泊軌道速度

r_p = 6,378.137 + 185 = 6,563.137 km v_c = √(μ/r_p) = √(398600.4418 / 6563.137) = √60.73331 = 7.79316 km/s

3. 步驟二：轉移軌道的半長軸

a = (r_p + r_a) / 2 = (6,563.137 + 406,563) / 2 = 413,126.137 / 2 = 206,563.07 km

4. 步驟三：轉移軌道在近地點的速度

v_p = √( μ (2/r_p − 1/a) ) 計算括號內 2/r_p = 2 / 6,563.137 = 3.047332 × 10⁻⁴ 1/a = 1 / 206,563.07 = 4.841146 × 10⁻⁶ 差 = 2.998920 × 10⁻⁴ 乘上 μ 398,600.4418 × 2.998920e-4 = 119.53864 開根號 v_p = 10.93338 km/s

5. 步驟四：Δv

┌─────────────────────────────────────┐ │ Δv = v_p − v_c │ │ = 10.93338 − 7.79316 │ │ = 3.14022 km/s │ └─────────────────────────────────────┘

3.14 km/s。這就是離開地球去月球的價格。

6. 順便算出來的其他量

離心率 e = (r_a − r_p)/(r_a + r_p) = (406563 − 6563.137)/(406563 + 6563.137) = 400,000 / 413,126 = 0.96822 比能量 ε = −μ/(2a) = −398600.4418/(2 × 206563.07) = −0.96481 km²/s² 特徵能量 C3 = 2ε = −1.9296 km²/s² （負的，如第 49 課所說） 轉移軌道週期 T = 2π√(a³/μ) = 2π√(8.8137e15/398600) = 2π√(2.2112e10) = 2π × 148,701 = 934,320 s = 259.5 小時 到遠地點是半圈 = 129.8 小時 = 5.41 天 遠地點速度（用 h = r_p·v_p = r_a·v_a） h = 6,563.137 × 10.93338 = 71,756 km²/s v_a = 71,756 / 406,563 = 0.17650 km/s 在遠地點只有 176 公尺/秒 —— 比高鐵還慢。

7. 但阿波羅只飛了 73 小時

半圈要 129.8 小時， 阿波羅 11 號卻在約 73 小時後就抵達月球。為什麼？

兩個原因 原因一：在到達遠地點之前就遇上月球 遠地點在 406,563 km，月球在 384,400 km。 太空船飛到 384,400 km 時，還沒到遠地點。 用克卜勒方程（第 18 課）算： r = a(1 − e·cos E) cos E = (1 − r/a)/e = (1 − 384400/206563)/0.96822 = −0.88919 E = 2.6664 rad M = E − e·sin E = 2.6664 − 0.96822 × 0.45884 = 2.2234 rad n = 2π/T = 2π/934,308 = 6.72496e-6 rad/s t = M/n = 330,615 s = 91.8 小時 單靠這個原因，飛行時間就從 129.8 降到 91.8 小時。 原因二：月球的引力把最後一段「拉」快了 進入影響球（距月心 66,200 km，即距地心約 318,200 km） 的時刻，用同樣的方法算出是飛行後 56.2 小時。 之後太空船不再減速 —— 月球的引力接手並開始加速它， 而且月球本身也正朝著會合點移動。 這一段無法用地心二體解處理（那正是 patched conic 要換座標系的原因）。實際任務中， 從影響球邊界到近月點約需 16–18 小時。 56 + 17 ≈ 73 小時 ✔

這是 patched conic 方法的一次完整示範： 第一段用地心橢圓算到影響球邊界， 第二段用月心雙曲線算剩下的路。

8. 與真實任務對照

任務TLI Δv（實測）本課計算差異
阿波羅 8 號3.043 km/s3.140−3.1%
阿波羅 11 號約 3.15 km/s3.140+0.3%
阿波羅 15 號約 3.05 km/s3.140−2.9%
差異的來源 1. 每次任務的目標遠地點不同 取決於該次的著陸點、飛行時間與自由返回需求 2. 有限推力損失 理論假設瞬間改變速度，實際點火 347 秒。 期間太空船移動了約 20 度的真近點角， 後半段的推力不再與最佳方向完全一致。 → 實際需要的推進劑略多於理想值 3. 月球軌道是橢圓 近地點 363,300 km，遠地點 405,500 km 到達時月球的實際距離每次不同 4. 太陽攝動 在 40 萬公里處，太陽的攝動已經不可忽略 結論：本課的計算在 ±3% 以內重現了真實數據。 這對理解原理完全足夠， 對真的要飛則需要第 23 課的數值積分。

9. 這個數字的意義

3.14 km/s 在整個 Δv 預算裡的位置（第 3 課） 地表 → LEO 9.4 （51%） TLI 3.14 （17%） ← 這一課 動力下降 2.0 （11%） 月面上升 1.85 （10%） TEI 1.00 （5%） LOI 0.95 （5%） 它需要多少推進劑（第 28 課） 作用在約 147 噸上，用 J-2（ve = 4.129） 質量比 = e^(3.14/4.129) = 2.139 推進劑 = 147 × (1 − 1/2.139) = 78.3 噸 換句話說：78 噸液氫液氧，換 3.14 km/s。
