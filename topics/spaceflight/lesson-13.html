圓、橢圓、拋物線、雙曲線：四種軌道與判別

這一課的目標

  • 整理四種圓錐曲線的判別方式
  • 理解雙曲線的負半長軸與漸近線
  • 學會雙曲線超速 v∞ 與 C3 的用法

1. 一張總表

形狀eεa特徵
圓0−μ/(2r)= r速度恆定
橢圓0 < e < 1< 0> 0封閉、週期性
拋物線= 1= 0= ∞臨界逃逸
雙曲線> 1> 0< 0逃逸且有剩餘速度

所有四種都滿足同一條軌道方程與同一條 vis-viva 公式。 它們不是四種不同的東西，是同一族曲線的四個區間。

2. 橢圓：實務上最常用的

基本關係 r_p = a(1 − e) 近拱點 r_a = a(1 + e) 遠拱點 a = (r_p + r_a)/2 半長軸 e = (r_a − r_p)/(r_a + r_p) b = a√(1 − e²) 半短軸 p = a(1 − e²) 半通徑 c = a·e 焦點到中心的距離 速度 v_p = √(μ/a · (1+e)/(1−e)) v_a = √(μ/a · (1−e)/(1+e)) v_p/v_a = (1+e)/(1−e) = r_a/r_p

「近拱點／遠拱點」是通用說法。 繞地球叫近地點／遠地點（perigee/apogee）， 繞月球叫近月點／遠月點（perilune/apolune）， 繞太陽叫近日點／遠日點（perihelion/aphelion）。

3. 雙曲線：那個負的半長軸

雙曲線的 a < 0 一開始很不直觀。 但它讓所有公式統一，而且有明確的幾何意義。

雙曲線的關係（注意 a < 0，所以常寫 |a|） r_p = a(1 − e) 仍然成立（a 負、(1−e) 負，乘積為正 ✔） v∞ = √(μ/|a|) 無窮遠處的剩餘速度 ε = μ/(2|a|) = v∞²/2 正能量 C3 ≡ v∞² = 2ε = μ/|a| 特徵能量 漸近線與近拱點方向的夾角 cos = −1/e 偏折角 sin(δ/2) = 1/e

a 的幾何意義：雙曲線也有兩支， |a| 是「焦點到近拱點」與「兩支頂點中點」之間的距離。 負號來自於焦點落在曲線凹面的另一側。

實務上不必糾結幾何，只要記得： 雙曲線用 |a| 和 v∞ 來描述，而 vis-viva 照樣成立。

4. C3：行星際任務的通用語言

C3 ≡ v∞² = 2ε （單位 km²/s²） C3 < 0 束縛軌道（橢圓） C3 = 0 剛好逃逸（拋物線） C3 > 0 逃逸有剩餘（雙曲線） 從高度 h 的圓軌道出發，達到某個 C3 所需的 Δv v_需要 = √(C3 + 2μ/r) Δv = √(C3 + 2μ/r) − √(μ/r)

為什麼用 C3 而不用 v∞？ 因為 C3 與能量成正比， 而發射載具的性能曲線（酬載質量 vs 能量） 用 C3 當橫軸是線性的、好內插。 所有發射服務的規格書都是用 C3 標示的。

月球那一列的 C3 是負的—— 去月球根本不需要逃逸地球。 這一點常被誤解，第 49 課會展開。

5. 偏折角：重力助推的來源

雙曲線經過天體時，速度大小不變（能量守恆）， 但方向被轉了 δ 角。

sin(δ/2) = 1/e 且 e = 1 + r_p·v∞²/μ 所以 sin(δ/2) = 1 / (1 + r_p·v∞²/μ) 觀察 r_p 越小（飛越得越近）→ e 越小 → δ 越大 v∞ 越小（來得越慢） → e 越小 → δ 越大
範例：航海家二號飛越木星 μ_J = 1.267e8 km³/s² r_p ≈ 721,700 km（約 10 個木星半徑） v∞ ≈ 9.0 km/s e = 1 + 721700 × 81 / 1.267e8 = 1 + 0.4613 = 1.4613 sin(δ/2) = 1/1.4613 = 0.6844 δ/2 = 43.2° → δ = 86.4° 速度方向被轉了將近 90 度。

在木星參考系裡，速度大小完全沒變—— 進來 9 km/s，出去還是 9 km/s。 但在太陽參考系裡， 因為木星自己在動，這個轉向會讓太空船 「偷」到木星的一部分公轉動量。 第 94 課會把這件事算清楚。

6. 判斷一條軌道的實用流程

輸入：某時刻的 r 向量與 v 向量 1. r = |r|, v = |v| 2. ε = v²/2 − μ/r 3. 若 ε < 0 → 橢圓；ε = 0 → 拋物線；ε > 0 → 雙曲線 4. a = −μ/(2ε) （雙曲線會得到負值，正常） 5. h = r × v, h = |h| 6. e = √(1 + 2εh²/μ²) 7. r_p = a(1 − e) 8. 若是橢圓：T = 2π√(a³/μ), r_a = a(1+e) 若是雙曲線：v∞ = √(2ε), C3 = 2ε, δ = 2·asin(1/e)

這八行涵蓋了所有二體軌道的判別。 阿波羅導航電腦裡處理軌道的程式， 核心就是這幾個公式的定點數版本。

7. 一個常見的混淆

「阿波羅有沒有逃離地球引力？」

沒有。 TLI 之後的軌道是一條 e ≈ 0.97 的高離心率橢圓， C3 是負的。太空船從頭到尾都被地球束縛著。

它只是飛得夠遠，遠到在遠地點附近 月球的引力變得比地球更重要（第 57 課的影響球）。 如果月球那時不在，太空船會沿著橢圓盪回來—— 這正是自由返回軌道（第 52 課）的物理基礎， 也是阿波羅 13 號能活著回來的原因。
