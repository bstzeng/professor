地火霍曼轉移：為什麼是 259 天

這一課的目標

  • 算出地火霍曼轉移的時間與 Δv
  • 理解為何一定要「提前出發」
  • 看懂快速轉移的取捨

1. 霍曼轉移橢圓

地球軌道 r₁ = 1.000 AU 火星軌道 r₂ = 1.524 AU（用平均值；實際軌道 e = 0.093） 轉移橢圓 a = (r₁ + r₂)/2 = (1.000 + 1.524)/2 = 1.2618 AU 近日點 = 1.000 AU（地球） 遠日點 = 1.524 AU（火星） e = (1.524 − 1.000)/(1.524 + 1.000) = 0.2076 轉移時間（克卜勒第三定律，第 12 課） T = a^(3/2) 年 = 1.2618^1.5 = 1.4174 年 半圈 = 0.7087 年 = 258.9 天 ┌──────────────────────────┐ │ 地火霍曼轉移 = 259 天 │ └──────────────────────────┘

2. Δv：兩次點火

單位換算 1 AU = 1.495979e8 km μ_S = 1.32712e11 km³/s² 地球公轉速度 v_E = √(μ_S/AU) = 29.785 km/s 火星公轉速度 v_M = √(μ_S/(1.524 AU)) = 24.129 km/s 離開（在轉移橢圓的近日點） v_p = √(μ_S(2/r₁ − 1/a)) = √(1.32712e11 × (2/1.496e8 − 1/(1.2618 × 1.496e8))) = √(1.32712e11 × (1.33691e-8 − 5.29679e-9)) = √(1.32712e11 × 8.07231e-9) = √1071.28 = 32.730 km/s 相對地球需要的 v∞ Δv₁ = 32.730 − 29.785 = 2.945 km/s C3 = 2.945² = 8.67 km²/s² 抵達（在轉移橢圓的遠日點） v_a = √(μ_S(2/r₂ − 1/a)) = √(1.32712e11 × (8.77157e-9 − 5.29679e-9)) = √(1.32712e11 × 3.47478e-9) = √461.16 = 21.475 km/s 火星的公轉速度 24.129 km/s 相對火星的 v∞ Δv₂ = 24.129 − 21.475 = 2.654 km/s

注意：太空船抵達時比火星慢。 火星從後面追上它。 所以相對火星的速度方向， 大致與火星的公轉方向相反—— 太空船是被火星「撞上」的。

3. 從 LEO 出發的完整 Δv

離開地球（用第 90 課的公式） Δv_離開 = √(v∞² + 2μ_E/r_p) − √(μ_E/r_p) = √(8.671 + 121.468) − 7.7932 = √130.139 − 7.7932 = 11.408 − 7.793 = 3.615 km/s 抵達火星（三種選擇） (a) 進入 400 km 圓軌道 v_hyp = √(2.654² + 2 × 42828/3796.2) = √29.585 = 5.439 v_circ = √(42828/3796.2) = 3.359 Δv = 2.080 km/s (b) 進入 400 × 33,000 km 橢圓捕獲軌道 a = 20,096 km v_p = √(42828 × (2/3796.2 − 1/20096)) = 4.520 Δv = 5.439 − 4.520 = 0.919 km/s (c) 直接進入大氣（EDL，第 96 課） Δv = 0（大氣免費） (b) 比 (a) 省 1.16 km/s —— 這就是為什麼 幾乎所有火星軌道器都先進入高離心率軌道， 再用氣動煞車（aerobraking）慢慢圓化。

4. 為什麼一定要「提前出發」

太空船飛 259 天到達 1.524 AU 問題：那時候火星在哪裡？ 火星公轉週期 1.8808 年 = 686.98 天 角速度 = 360/686.98 = 0.5240 度/天 259 天內火星移動 = 259 × 0.5240 = 135.7 度 而太空船走的是半圈 = 180 度 所以出發時，火星必須在 180 − 135.7 = 44.3 度「前方」 ┌──────────────────────────────────┐ │ 出發時的相位角 = 44.3 度 │ └──────────────────────────────────┘ 也就是：從太陽看，火星必須在地球「前面」44.3 度。

5. 快速轉移的取捨

霍曼轉移是「最省 Δv」，但不是「最快」。 想更快 → 用一條更「扁」的橢圓（更高的能量） → 在到達火星軌道之前就切過去，不等到遠日點 代價：到達時速度更高 → 相對火星的 v∞ 更大 → 抵達更貴

為什麼載人任務想要更快 輻射暴露（第 58 課）與 ∝ 時間 消耗品與 ∝ 時間 心理與生理影響 ∝ 時間 系統故障機率 ∝ 時間 但快速轉移同時讓 EDL 變難（進入速度更高） → 熱防護更重 → 酬載更少 這是載人火星任務設計的核心矛盾。

6. 回程：一個常被忽略的問題

去程 259 天。回程呢？ 回程也是 259 天（對稱的霍曼轉移）。 但出發時機不是「想走就走」—— 必須等到地球與火星的相位再次正確。 回程的相位條件 太空船從火星出發，走 180 度，飛 259 天 地球在這 259 天內移動 259 × 0.9856 = 255.3 度 出發時，地球必須在火星「後方」 180 − 255.3 = −75.3 度 即地球在火星前方 75.3 度 ... 需要繞一圈調整 實際計算：從抵達火星到「可以出發回家」， 必須在火星停留約 460 天。 ┌──────────────────────────────────────┐ │ 合會（conjunction）型任務 │ │ 去 259 + 停 460 + 回 259 = 978 天 │ │ 約 2.7 年 │ └──────────────────────────────────────┘ 另一種：衝（opposition）型任務 縮短在火星的停留到約 30–60 天 但去程或回程必須走一條「繞過金星」的軌道 總時間約 640 天，Δv 大幅增加（約多 4–6 km/s） 多數載人火星任務規劃選擇合會型 —— 因為 Δv 是硬性的，而時間可以靠工程解決。

Δv 只差兩倍，但任務時間差 122 倍。 這就是為什麼載人火星任務的主要挑戰 不在軌道力學，而在生命維持、輻射防護與可靠度。
