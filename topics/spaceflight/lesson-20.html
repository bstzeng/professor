Lambert 問題：給兩點與飛行時間，求那條軌道

這一課的目標

  • 理解 Lambert 問題的形式與它為何無所不在
  • 認識 Lambert 定理這個關鍵簡化
  • 知道求解流程與多解的問題

1. 問題的形式

已知 r₁：出發點的位置向量 r₂：到達點的位置向量 Δt：兩點之間的飛行時間 方向：順行還是逆行（繞短弧還是長弧） 求 v₁：出發時需要的速度向量 v₂：到達時的速度向量

這是一個邊值問題（boundary value problem）， 跟第 19 課的傳播（初值問題）方向相反。

2. 為什麼這個問題無所不在

應用r₁r₂Δt
TLI 設計地球停泊軌道上的點火點三天後月球的位置73 小時
火星轉移發射時地球的位置到達時火星的位置約 200–300 天
軌道會合追趕者現在的位置目標未來的位置規劃的會合時間
攔截攔截器位置目標未來位置攔截時間
軌道決定第一次觀測第二次觀測兩次觀測間隔
回程設計離開月球的位置再入點約 60–70 小時

幾乎所有「從 A 飛到 B」的問題， 最後都是一個 Lambert 問題。 霍曼轉移（第 16 課）只是 Lambert 的一個特例—— 兩點恰好相隔 180 度、Δt 恰好是半個週期。

3. Lambert 定理：那個關鍵的簡化

Lambert 在 1761 年證明了一件很不直觀的事：

┌──────────────────────────────────────────────┐ │ 轉移時間 Δt 只取決於三個量： │ │ a（半長軸） │ │ r₁ + r₂（兩個半徑之和） │ │ c（兩點之間的弦長） │ │ │ │ 與軌道的離心率、方向、形狀細節全部無關。 │ └──────────────────────────────────────────────┘

這個定理把一個六維問題壓成了一維問題。 我們只需要找到正確的 a（或某個等價的單一參數）， 其他一切都能推導出來。

它的具體形式（Lagrange 表示式，橢圓情況）：

√(μ/a³) · Δt = (α − sin α) − (β − sin β) 其中 sin²(α/2) = s/(2a) sin²(β/2) = (s − c)/(2a) s = (r₁ + r₂ + c)/2 半周長 c = |r₂ − r₁| 弦長

給定 a，右邊可以直接算出來。 所以問題變成：調整 a，讓 Δt 等於指定值。 一維求根，用牛頓法或二分法都行。

4. Δt 與 a 的關係曲線

幾個重要的性質：

  • a 有下限：amin = s/2。小於這個值的橢圓根本連不到那兩點。這條軌道叫「最小能量轉移」。
  • 短弧與長弧是兩條不同的曲線：同樣的 a，走短弧比走長弧快。
  • Δt 隨 a 單調變化（在各自分支上），所以求根一定收斂到唯一解。
  • a → ∞ 時：短弧 Δt → 某個下限（拋物線轉移，最快的可能）；長弧 Δt → 另一個值。
最小能量轉移的性質 a_min = s/2 Δt_min-energy = √(a_min³/μ) · [π − β_m + sin β_m] （短弧） 注意：「最小能量」不等於「最小 Δv」！ 最小能量指的是轉移軌道本身的能量最低， 但 Δv 還要看它與出發／到達軌道速度的差。

5. 多圈解：一個實際的複雜性

如果 Δt 很長，太空船可以在途中繞好幾圈再到達。

繞 N 圈的 Lambert 方程 √(μ/a³)·Δt = 2πN + (α − sin α) − (β − sin β) 對每一個 N，短弧與長弧各有解 → 總解數 = 2(N_max + 1) 而且對 N ≥ 1，每個分支上 Δt(a) 不再單調， 同一個 Δt 可能對應兩個 a → 求根需要先找出極值點，再在各單調區間內分別求解

多圈解在低推力任務與某些會合設計中很重要。 對阿波羅這種直接轉移的任務，只需要 N = 0。

6. 實務上的求解方法

方法迭代變數特性
Lagrange / Lancastera 或 x經典，橢圓與雙曲線要分開處理
通用變數（Bate–Mueller–White）z = χ²/a一套程式處理所有型態
Gooding特殊參數化收斂極快，三次迭代達機器精度
Izzox（Householder 法）現代標準，穩健且支援多圈

通用變數版本的核心（用第 19 課的 Stumpff 函數）：

A = sin(Δθ)·√(r₁r₂/(1 − cos Δθ)) （順行取正） 給定試探值 z： y(z) = r₁ + r₂ + A(z·S(z) − 1)/√C(z) χ = √(y/C(z)) Δt(z) = (χ³·S(z) + A·√y) / √μ 對 z 用牛頓法求根，使 Δt(z) = Δt_指定 收斂後 f = 1 − y/r₁ g = A·√(y/μ) ġ = 1 − y/r₂ v₁ = (r₂ − f·r₁)/g v₂ = (ġ·r₂ − r₁)/g

z 的正負號自動決定軌道型態： z > 0 是橢圓，z < 0 是雙曲線，z = 0 是拋物線。 這就是通用變數的價值——不必事先知道答案是哪一類。

7. 一個必須注意的退化情況

當 Δθ 恰好等於 180 度時， Lambert 問題沒有唯一解。

原因是：兩個點與中心天體三點共線， 無法決定軌道平面的方向—— 繞任何一個包含這條線的平面都可以。

在公式裡的表現 A = sin(Δθ)·√(...) → sin(180°) = 0 → A = 0 g = A·√(y/μ) = 0 v₁ = (r₂ − f·r₁)/g → 除以零

實務上這叫「180 度轉移奇異」。 處理方式是把 Δθ 稍微偏離 180 度 （例如設計成 179.5 度）， 或另外指定軌道平面。

這個奇異點在火星任務裡特別麻煩， 因為理想的霍曼轉移剛好就是 180 度（第 91 課）。 所以真實的火星任務從來不用精確的 180 度轉移， 而是稍微偏離一點——這個偏離也順便避開了 第 92 課會看到的另一個問題。

最後一列是 Lambert 最壯觀的應用。 一張 porkchop plot 背後是幾萬次 Lambert 求解—— 每一個像素一次，掃遍所有可能的出發與到達日期組合。 這在 1960 年代需要大型主機跑很久， 現在筆電上幾秒鐘就能算完。
