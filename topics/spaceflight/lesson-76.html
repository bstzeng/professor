會合的幾何：追趕、相位與 CW 方程

這一課的目標

  • 理解相對運動的反直覺性質
  • 推導 Clohessy–Wiltshire 方程
  • 看懂相位追趕的基本策略

1. 那個反直覺的規則

第 6 課提過：要追上前面的目標，必須先減速。 現在把它算清楚。

在圓軌道上往前加速 Δv → 半長軸增加 → 週期變長 → 一圈之後你落後了 用第 12 課的公式 T = 2π√(a³/μ) dT/T = (3/2)(da/a) 用 vis-viva 求 da v² = μ(2/r − 1/a) 在 r 不變的瞬間微分：2v·dv = μ·da/a² → da = 2v·a²·dv/μ 對圓軌道 v² = μ/a，所以 μ = v²a → da = 2v·a²·dv/(v²a) = 2a·dv/v da/a = 2·dv/v 代回 dT/T = (3/2) × 2 × dv/v = 3·dv/v ┌──────────────────────┐ │ dT/T = 3 · dv/v │ └──────────────────────┘
數值例子（月球 110 km 圓軌道） v = 1.6291 km/s T = 118.75 分 = 7,125 秒 往前加速 1 m/s dT/T = 3 × 1/1629 = 1.842e-3 dT = 7125 × 1.842e-3 = 13.1 秒 一圈之後，你比原本晚 13.1 秒到達同一點。 在 1.629 km/s 下，13.1 秒 = 21.3 公里。 → 往前加速 1 m/s，一圈之後落後 21.3 公里。

所以追趕的正確方法是減速： 降低軌道 → 週期變短 → 每圈都追近一點。

2. 相對座標系

第 14 課提過：用六要素描述兩條幾乎相同的軌道 會有嚴重的數值精度問題。 正確的做法是建立一個以目標為原點的局部座標系。

Hill 座標系（也叫 LVLH：Local Vertical, Local Horizontal） 原點：目標（CSM） x 軸：徑向，從月心指向目標（向外為正） y 軸：沿軌道方向（目標的速度方向） z 軸：垂直於軌道面 注意：這個座標系以角速度 n = √(μ/a³) 旋轉。 所以在它裡面寫運動方程時， 必須加上離心力與科氏力項。

3. 推導 Clohessy–Wiltshire 方程

在旋轉座標系中的運動方程 a_慣性 = a_相對 + 2Ω × v_相對 + Ω × (Ω × r) 科氏項 離心項 追蹤者的絕對加速度（重力） a = −μ·R/|R|³，其中 R = R_目標 + r 線性化：假設 |r| ≪ |R_目標| 展開到一階 −μ(R_t + r)/|R_t + r|³ ≈ −μR_t/R_t³ + (μ/R_t³)(3(r·x̂)x̂ − r) 把所有項整理，並用 n² = μ/R_t³ ┌───────────────────────────────┐ │ ẍ − 2n·ẏ − 3n²x = 0 │ │ ÿ + 2n·ẋ = 0 │ │ z̈ + n²z = 0 │ └───────────────────────────────┘ 這就是 Clohessy–Wiltshire 方程（1960 年） 也叫 Hill 方程（Hill 在 1878 年研究月球運動時就得到了類似的形式）

三個重要的觀察：

  • z 方向完全解耦，而且是簡諧運動（週期 = 軌道週期）。這對應軌道面的偏離——它不會累積，只會來回振盪。
  • x 與 y 耦合，透過科氏項。這就是「加速影響高度、高度影響相位」的數學形式。
  • y 方程沒有 y 項，只有 ẋ。這代表沿軌道方向沒有回復力——任何徑向的擾動都會造成沿軌道方向的永久漂移。

4. 解

給定初始狀態 (x₀, y₀, z₀, ẋ₀, ẏ₀, ż₀) x(t) = (4 − 3cos nt)x₀ + (sin nt / n)ẋ₀ + (2/n)(1 − cos nt)ẏ₀ y(t) = 6(sin nt − nt)x₀ + y₀ − (2/n)(1 − cos nt)ẋ₀ + (1/n)(4 sin nt − 3nt)ẏ₀ z(t) = z₀ cos nt + (ż₀/n) sin nt
關鍵的一項：y 方程裡的 −6nt·x₀ 這是一個「隨時間線性成長」的項。 意思：如果追蹤者的高度與目標差 x₀（徑向偏移）， 那麼它每一圈會在沿軌道方向漂移 Δy（每圈） = −6n·x₀·T = −6n·x₀·(2π/n) = −12π·x₀ ┌────────────────────────────────┐ │ 每圈的相位漂移 = −12π × 高度差 │ └────────────────────────────────┘ 高度差 1 公里 → 每圈漂移 37.7 公里 負號：追蹤者比目標低（x₀ < 0）→ Δy > 0 → 往前追上 ✔

這條 12π 的關係是整個會合策略的核心。 它把「高度差」直接換算成「每圈追近多少」。

5. 阿波羅的數值

上升後 LM 在 17 × 83 km 橢圓，平均高度約 50 km CSM 在 110 km 圓軌道 平均高度差 x₀ ≈ −60 km 每圈的相位追趕 = 12π × 60 = 2,262 公里 沿 CSM 軌道一整圈的長度 = 2π × 1847.4 = 11,608 公里 → 每圈追近 2,262/11,608 = 19.5% 的一圈 如果上升時 LM 落後 CSM 半圈（5,804 公里）， 需要 5,804/2,262 = 2.6 圈才能追上。 實際做法 任務規劃讓 LM 在「CSM 即將通過頭頂前」起飛， 使得上升後 LM 落後 CSM 約 550 公里（約 17 度）。 → 只需要不到一圈就能追上 這就是第 70 課「每一圈只有一個短暫起飛時機」的 另一層意義：不只要平面對，相位也要對。

6. 兩種會合策略

共橢圓（阿波羅）直接上升（Direct）
圈數約 1.5 圈（3 小時）約 0.5 圈（1 小時）
機動次數4–5 次2 次
Δv約 60 m/s約 100 m/s
對誤差的容忍高（每次機動都能修正）低
可觀測性好（有時間用雷達與六分儀確認）差
使用阿波羅 11–16 號阿波羅 17 號、後期蘇聯任務

阿波羅 17 號改用直接會合， 因為前六次任務已經證明上升導引的精度足夠， 而縮短會合時間可以減少疲勞與消耗品使用。

現代的自動會合（如 Progress、Dragon、神舟） 則走向另一個方向：「快速會合」—— 用精確的相位規劃讓對接在 3–6 小時內完成， 甚至可以在發射後兩圈內完成。

7. CW 方程的限制

假設何時失效
目標在圓軌道目標軌道有明顯離心率時
相對距離 ≪ 軌道半徑相距數百公里以上時
無攝動月球 mascon（第 63 課）、地球 J2
無推力連續推力的會合
阿波羅的情況 相對距離最大約 550 公里 軌道半徑 1,847 公里 比值 = 0.30 —— 已經不算「遠小於」 所以 CW 方程只用來做「粗略規劃與直覺理解」， 實際的機動參數用完整的二體 Lambert 求解（第 20 課）。 CW 的價值在於： 它給出了「多少高度差換多少相位追趕」這個定量直覺， 而那是規劃整個序列的基礎。
