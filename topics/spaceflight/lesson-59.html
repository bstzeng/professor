模組 J｜LOI：進入月球軌道 · 第 59 課

到了月球為什麼不會自己被抓住

這一課的目標

  • 理解為何接近天體不會自動被捕獲
  • 看懂能量守恆如何禁止「自然捕獲」
  • 知道三體效應提供的例外

1. 一個必然的結論

太空船從很遠的地方（影響球外）飛向月球。 它相對月球的比能量是：

ε = v²/2 − μ_M/r 在影響球邊界（r = 66,183 km） v ≈ 1.15 km/s ε = 0.661 − 0.074 = 0.587 km²/s² > 0 ε > 0 → 雙曲線（第 13 課） 而 ε 是守恆的（第 10 課）。 在近月點（r = 1,847 km） ε 仍然是 0.587 v = √(2(ε + μ_M/r)) = √(2(0.587 + 2.654)) = 2.546 km/s 仍然大於該處的逃逸速度 √(2μ_M/r) = 2.304 km/s → 太空船一定會飛走。

這不是「可能」，是「必然」。 在純二體問題中， 從無窮遠來的東西一定回到無窮遠去。 沒有任何幾何安排能改變這件事。

2. 為什麼必須點火

要被捕獲，必須讓 ε < 0 而 ε = v²/2 − μ_M/r r 是幾何決定的（你飛得多近） → 只能改變 v 減速 → 降低 v → 降低 ε 需要減多少 在近月點 r_p = 1,847.4 km 現在的速度 v_hyp = 2.5885 km/s 目標圓軌道速度 v_c = 1.6291 km/s Δv = 0.9594 km/s（若直接圓化） 這就是 LOI。

3. 為什麼在近月點做

第 21 課的 Oberth 效應：在最快的地方改變能量最有效。

比較：在不同高度執行捕獲 在近月點 110 km（v_hyp = 2.589） 圓化到 110 km：Δv = 2.589 − 1.629 = 0.959 km/s 在 1,000 km（r = 2,737.4 km） v_hyp = √(1.394 + 2×4902.8/2737.4) = √4.975 = 2.2304 v_c = √(4902.8/2737.4) = 1.3383 Δv = 2.2304 − 1.3383 = 0.8921 km/s 咦？在高處反而省？ 但這樣得到的是 1,000 km 的軌道，不是 110 km 的。 要再降到 110 km 還需要一次霍曼轉移： a = (2737.4 + 1847.4)/2 = 2292.4 在 1,000 km 減速：0.1369 在 110 km 減速： 0.1511 合計 0.8921 + 0.1369 + 0.1511 = 1.1801 km/s 比直接在近月點捕獲（0.9594）貴 0.22 km/s。 ✔ Oberth 效應成立

4. 例外：三體效應下的「彈道捕獲」

上面的結論只在純二體下成立。 在三體問題裡，有一個奇特的例外。

彈道捕獲（ballistic capture）/ 弱穩定邊界轉移 想法 不從地球直接飛向月球， 而是先飛到約 150 萬公里外（接近地球影響球邊緣）， 在那裡太陽的攝動變得重要。 利用太陽的攝動緩慢改變軌道， 然後以極低的相對速度「飄」進月球的引力範圍。 在弱穩定邊界（weak stability boundary）附近， 太空船可以進入一個暫時被月球束縛的狀態， 而不需要（或只需要極少）減速。 代價 飛行時間：3–4 個月（而不是 3 天） 軌道不穩定：捕獲是暫時的，仍需小量點火穩定 節省 約 0.2–0.3 km/s 實例 日本的飛天號（Hiten, 1991）是第一個實際驗證的 後續多個月球探測器（如 GRAIL, CAPSTONE）使用類似技術

對載人任務完全不適用。 三到四個月的飛行需要的消耗品遠超過省下的推進劑價值。 但對無人探測器，這是一個實用的技術。

5. 另一個例外：氣動捕獲

如果目標天體有大氣（火星、金星、泰坦）， 可以用大氣阻力來減速捕獲。 aerocapture：一次通過大氣就把 ε 降到負值 aerobraking：多次淺層通過，逐步降低遠拱點 節省的 Δv 可達 1 km/s 以上（第 96 課） 月球沒有大氣 → 這條路不存在。 這也是第 15 課那張 Δv 地圖裡 「火星表面比月球表面便宜」的原因。

6. 捕獲的能量圖

LOI 後的能量（圓化到 110 km） ε = v_c²/2 − μ_M/r = 1.6291²/2 − 4902.8/1847.4 = 1.327 − 2.654 = −1.327 km²/s² ε < 0 ✔ 被捕獲 對應的半長軸 a = −μ_M/(2ε) = 4902.8/2.654 = 1,847.4 km = r（因為是圓軌道）✔

7. 一個對稱性：TEI 是 LOI 的鏡像

LOI：把 ε 從 +0.587 降到 −1.327 （減速 0.96 km/s） TEI：把 ε 從 −1.327 升回 正值 （加速約 1.0 km/s） 兩者幾乎對稱，而且都在近月點做（Oberth 效應）。 為什麼 TEI 略貴一些： TEI 不只要逃離月球，還要 「以正確的方向與速度離開，好讓地心軌道通往地球」 第 80 課會算。 一個有趣的推論 如果任務只是「飛掠月球然後回來」（如阿波羅 8 號的替代方案， 或阿波羅 13 號實際做的）， 就完全不需要 LOI 與 TEI —— 省下約 2 km/s。 阿波羅 13 號正是因為這個， 才能在幾乎沒有推進能力的情況下回到地球。
