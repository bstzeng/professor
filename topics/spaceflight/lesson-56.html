被動熱控：那個每小時三圈的翻滾

這一課的目標

  • 算出不旋轉時的溫度差有多大
  • 理解被動熱控的原理
  • 看懂它與姿態控制、導航的衝突

1. 如果不轉會怎樣

太空中的熱平衡（第 36 課） 只有輻射，沒有傳導與對流 面向太陽的一側 吸收 = α · S · A （S = 1,361 W/m² 太陽常數） 輻射 = ε · σ · T⁴ · A 平衡時 α·S = ε·σ·T⁴ T = (α·S / (ε·σ))^(1/4) 若 α/ε = 1（灰體） T = (1361 / 5.67e-8)^0.25 = (2.4004e10)^0.25 = 394 K = 121 °C 背向太陽的一側 只有輻射出去，沒有吸收（宇宙背景 3 K 可忽略） → 溫度持續下降，趨近於絕對零度 實際上會被艙內熱源與結構傳導拉住， 但仍可降到 −100 °C 以下。

同一艘太空船的兩側相差超過 200 °C。 後果：

問題後果
推進劑貯箱受熱不均一側沸騰增壓，一側可能凝固
結構熱應力彎曲變形，影響光學對準與對接
電子設備超溫元件失效
散熱器受熱朝陽的散熱器不但排不出熱，還會吸熱
低溫側的潤滑與密封橡膠變硬、潤滑劑凝固
冷卻液管路可能凍結

2. 解法：慢慢轉

Passive Thermal Control（PTC） 俗稱「BBQ Roll」—— 像烤肉架上的肉一樣慢慢轉 阿波羅的設定 繞太空船的縱軸（X 軸）旋轉 轉速約每小時 3 圈 = 每 20 分鐘 1 圈 = 0.3 度/秒 縱軸指向垂直於太陽方向 → 每一面依序接受日照與陰影
為什麼是 3 rev/hr 太慢 → 每一面在日照下停留太久，仍會過熱 太快 → RCS 推進劑消耗增加、影響導航觀測 估算：熱時間常數 太空船外殼的熱容量與輻射散熱率決定它的響應時間。 對阿波羅的量級，特徵時間約數十分鐘。 轉一圈 20 分鐘，與這個時間常數相當 → 溫度波動被平均掉大部分 實測：PTC 下的表面溫度變化控制在 ±10 °C 以內 （不轉時是 ±200 °C）

3. 「被動」的意思

關鍵在於：一旦轉起來，就不需要繼續消耗推進劑。

建立 PTC 的程序 1. 用 RCS 把太空船轉到正確的姿態 2. 用 RCS 施加旋轉，達到 0.3°/s 3. 停止 RCS 之後角動量守恆，它會一直轉下去。 需要的推進劑 太空船繞 X 軸的轉動慣量約 30,000 kg·m² 角速度 0.3°/s = 5.24e-3 rad/s 角動量 L = 157 kg·m²/s RCS 力偶臂約 2 公尺，兩具推進器各 445 N 力矩 = 2 × 445 × 2 = 1,780 N·m → 需要 157/1780 = 0.088 秒的點火 推進劑消耗：可忽略不計。 維持的成本 理想情況：零 實際上會有微小的擾動： 重力梯度力矩 太陽輻射壓 推進劑晃動 排氣 所以每隔幾小時要用 RCS 微調一次， 但整趟任務的 PTC 推進劑消耗仍然很小。

這是一個典型的「用物理定律代替持續控制」的設計。 角動量守恆免費提供了穩定性。

4. 一個穩定性問題：中間軸定理

剛體繞三個主慣性軸的旋轉 繞最大慣性軸：穩定 ✔ 繞最小慣性軸：穩定 ✔ 繞中間慣性軸：不穩定 ✘（會翻滾） 這叫「中間軸定理」或「網球拍定理」 更麻煩的是「能量耗散」 如果太空船內部有任何能量耗散機制 （推進劑晃動、結構阻尼）， 那麼只有「繞最大慣性軸」的旋轉是真正穩定的。 繞最小慣性軸的旋轉會緩慢演化成繞最大慣性軸 —— 這叫「翻滾不穩定」（flat spin）。 阿波羅的情況 CSM + LM 組合體是細長的 → 縱軸（X 軸）是「最小慣性軸」 所以 PTC 旋轉在有能量耗散時並非長期穩定！ 處理方式 AGC 的姿態控制程式持續監視， 當偏差超過閾值時用 RCS 修正。 這是為什麼 PTC 仍然需要偶爾的主動介入。

1958 年的探險者一號衛星就栽在這上面。 它被設計成繞最小慣性軸自旋， 結果因為天線的能量耗散， 幾個小時後就翻滾成繞最大慣性軸的姿態。 這是人類第一次在實際飛行中遇到這個現象。

5. PTC 與其他任務活動的衝突

活動衝突處理
光學導航（第 55 課）轉動中無法對準恆星暫停 PTC，量完再恢復
高增益天線通訊天線要指向地球天線有萬向架，可以邊轉邊追蹤
SPS 點火必須停止旋轉並對準點火前停止 PTC
太陽能（若有）阿波羅沒用太陽能，無此問題—
睡眠旋轉造成窗外景色不斷變化拉上遮光簾
每一次「停止 PTC → 做事 → 重建 PTC」 都要消耗 RCS 推進劑與時間（約 20–30 分鐘） 所以任務規劃會把需要停止 PTC 的活動 盡量集中在同一個時段做完。 這是任務時間線設計的一個實際約束。

6. 阿波羅 13 號：PTC 的極端考驗

爆炸後，指揮艙完全關機（第 37 課） → 沒有加熱器 → 沒有冷卻液循環 完全依賴 PTC 來避免任何一側過冷或過熱。 問題 組合體的構型改變了（大家都在 LM 裡）， 質量分布不同，PTC 的建立變得困難。 而且 LM 的 RCS 從來沒有被設計來控制 「LM + CSM + 損壞的 SM」這個組合體的姿態。 太空人必須手動摸索出可行的操作方式。 結果 指揮艙內部溫度降到約 4 °C 牆壁大量結露（第 36 課） 但關鍵系統沒有凍壞 —— 再入時全部正常啟動 這在事後被認為是相當幸運的。
