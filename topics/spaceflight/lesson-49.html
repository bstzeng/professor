模組 H｜TLI：算出飛向月球的那一腳 · 第 49 課

逃逸速度與「差一點逃逸」的軌道

這一課的目標

  • 釐清「去月球要不要達到逃逸速度」
  • 理解 C3 為負代表什麼
  • 看懂「差一點逃逸」的軌道有什麼特別

1. 一個常見的誤解

「要離開地球去月球，必須達到第二宇宙速度 11.2 km/s。」

這句話是錯的。 而且錯的方式很有啟發性。

2. 算一次就清楚

在 185 km 高度 圓軌道速度 v_c = √(398600/6563) = 7.7932 km/s 逃逸速度 v_esc = √(2×398600/6563) = 11.0212 km/s TLI 之後的速度 v_TLI = 10.9334 km/s v_TLI < v_esc 差距 = 11.0212 − 10.9334 = 0.0878 km/s 只差 88 公尺/秒，不到 1%。

阿波羅從來沒有逃離地球引力。 它在一條被地球束縛的橢圓軌道上， 只是這條橢圓的遠地點剛好超過月球的距離。

3. 用能量看得更清楚

比能量 ε = v²/2 − μ/r TLI 之後 ε = 10.9334²/2 − 398600/6563 = 59.770 − 60.735 = −0.965 km²/s² ε < 0 → 束縛軌道（橢圓）✔ 特徵能量 C3 = 2ε = −1.93 km²/s² 對照第 13 課的表： C3 < 0 → 橢圓 C3 = 0 → 拋物線（剛好逃逸） C3 > 0 → 雙曲線

所以去月球的 C3 是負的。 這個數字在任務規劃的語言裡有明確意義： 發射載具不必具備「逃逸能力」， 只要具備「接近逃逸的能力」。

4. 為什麼只差 1% 的速度，卻差這麼多

量化這個敏感度 a = 1 / (2/r_p − v_p²/μ) r_a = 2a − r_p v_p = 10.9000 → r_a = 293,500 km （到不了月球） v_p = 10.9200 → r_a = 352,500 km v_p = 10.9334 → r_a = 407,100 km ← 阿波羅 v_p = 10.9500 → r_a = 503,200 km v_p = 11.0000 → r_a = 1,702,600 km v_p = 11.0210 → r_a = ∞ 從 10.9334 到 10.9500（只差 17 m/s） 遠地點就從 40.7 萬公里變成 50.3 萬公里。

這是 TLI 精度要求的來源。 點火誤差 1 m/s，遠地點就偏差約 4,750 公里； 10 m/s 的誤差就是 53,000 公里。 而月球的影響球只有 66,200 公里—— 所以 TLI 的速度誤差必須控制在數 m/s 以內， 剩下的靠中途修正（第 54 課）。

5. 那為什麼不乾脆逃逸

多花 88 m/s 就能逃逸，看起來很便宜。 但那樣做完全沒有好處： 1. 逃逸軌道是雙曲線，太空船會一去不返 —— 除非月球把它抓住，但那需要精確的瞄準 2. 失去自由返回能力（第 52 課） —— 橢圓軌道會自己盪回來，雙曲線不會 3. 到達月球時的相對速度更高 → LOI 需要的 Δv 更大 第 3 點可以算出來： v_TLI = 10.933 → 到達月球時 v∞ ≈ 0.9 km/s → LOI 0.84 km/s v_TLI = 11.100 → 到達月球時 v∞ ≈ 1.5 km/s → LOI 約 1.25 km/s 多花 167 m/s 在 TLI，要在 LOI 多付 410 m/s。 而且 LOI 是用 Isp 較低的 SPS 做的，代價更大。

「剛好夠用」在這裡不只是省錢，而是最佳解。

為什麼火星必須逃逸 月球在地球的影響球「裡面」（384,400 < 924,000 km 的地球 SOI） → 可以用地球束縛軌道抵達 火星在太陽的軌道上，完全在地球影響球之外 → 必須先脫離地球，成為一個獨立繞太陽的物體 → 必須逃逸 這是「月球任務」與「行星際任務」最根本的分野。

這個分野也反映在導航上。 月球任務的參考系是地心（然後切換到月心）； 行星際任務的參考系是日心。 第 90 課會處理這個切換。

7. 一個歷史註記

1959 年的蘇聯探測器 Luna 1 原本要撞擊月球，但因為 TLI 時序誤差， 它從月球旁邊約 6,000 公里處飛過。

它的速度超過了逃逸速度， 所以成為人類第一個進入日心軌道的人造物體。 蘇聯當時把它重新命名為「第一顆人造行星」。

這說明了兩件事： 第 4 節那個敏感度是真實的工程風險； 而「差一點」與「剛好超過」逃逸速度， 會導致完全不同的命運。
