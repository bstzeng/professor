克卜勒三定律：從推導結果反讀回去

這一課的目標

  • 把克卜勒三定律對應回二體解
  • 推導第三定律，並用它做實際計算
  • 理解「經驗定律」與「推導結果」的差別

1. 三定律的原始陳述

定律陳述年份
第一行星沿橢圓軌道運行，太陽位於一個焦點上1609
第二連接行星與太陽的線段在相同時間掃過相同面積1609
第三公轉週期的平方正比於半長軸的立方1619

克卜勒是從第谷·布拉赫留下的觀測資料裡硬湊出來的。 他先試了圓形（誤差 8 角秒，他認為第谷的資料不會錯這麼多）， 再試蛋形，最後才試出橢圓。 整個過程花了將近二十年，沒有任何物理理論指引。

2. 第一定律 = 軌道方程

第 11 課解出的：

r = (h²/μ) / (1 + e·cos θ)

當 0 < e < 1 時，這條曲線就是以原點為一個焦點的橢圓。 原點放的是中心天體。第一定律成立。

但推導同時告訴我們克卜勒不知道的事： e ≥ 1 的情況也是合法的解。 克卜勒只看行星，行星都是束縛軌道， 所以他從來沒見過拋物線或雙曲線。 第一顆被確認的雙曲線軌道天體（1I/'Oumuamua） 要等到 2017 年才被發現。

3. 第二定律 = 角動量守恆

第 9 課已經證明：dA/dt = h/2 = 常數。

值得再強調一次：第二定律不需要平方反比。 任何中心力都會給出等面積定律。 所以第二定律其實是三條裡「最弱」的一條—— 它只告訴我們力指向太陽，沒有告訴我們力的大小怎麼變。

4. 第三定律：推導

用第二定律：一整圈掃過的面積就是橢圓面積 πab， 花的時間是週期 T。

πab = (h/2) · T → T = 2πab/h 橢圓的關係 b = a√(1 − e²) p = a(1 − e²) = h²/μ → h = √(μ·a(1−e²)) 代入 T = 2π · a · a√(1−e²) / √(μ·a(1−e²)) = 2π · a²√(1−e²) / (√μ · √a · √(1−e²)) = 2π · a² / (√μ · √a) = 2π · a^(3/2) / √μ ┌────────────────────────┐ │ T = 2π √(a³/μ) │ │ T² = 4π²a³/μ │ └────────────────────────┘

注意 (1−e²) 在推導中完全抵消了。 這就是為什麼週期只跟半長軸有關、跟離心率無關—— 跟第 10 課能量只跟 a 有關是同一件事的兩面。

5. 第三定律的三個用法

用法一：算週期

ISS（400 km 圓軌道，a = 6,778 km） T = 2π√(6778³/398600) = 2π√(781,153) = 2π × 883.8 = 5,553 s = 92.5 分 GPS（半同步軌道，a = 26,560 km） T = 2π√(26560³/398600) = 2π√(47,001,000) = 2π × 6,856 = 43,077 s = 11 小時 58 分 地球同步（T = 86,164 s = 一恆星日） a = (μT²/4π²)^(1/3) = (398600 × 86164²/39.478)^(1/3) = (7.4965e13)^(1/3) = 42,164 km 高度 = 42164 − 6378 = 35,786 km ✔

用法二：算轉移軌道的飛行時間

阿波羅 TLI 轉移軌道 a = 206,563 km T = 2π√(206563³/398600) = 2π√(2.21167e10) = 2π × 148,717 = 934,410 s 飛到遠地點是半圈 = T/2 = 467,205 s = 129.8 小時 = 5.41 天

但阿波羅實際只飛了約 73 小時（約 3 天）就到月球。 為什麼差這麼多？

兩個原因：

  • 月球不在遠地點。阿波羅的轉移軌道遠地點設計得比月球距離遠一些，所以在到達遠地點之前就遇上月球了——只飛了那條橢圓的一部分。
  • 月球的引力把它拉過去。進入影響球之後就不再是繞地球的橢圓了。

這是 patched conic 近似的典型限制， 第 51 課會用 Lambert 問題處理得更精確。

用法三：稱量天體

量一顆衛星的軌道，就能算出主星的 μ μ = 4π²a³/T² 伽利略 1610 年看到木星的四顆衛星， 量出它們的週期與距離，就能算出木星的 μ。 木衛四（Callisto） a = 1,882,700 km，T = 16.689 天 = 1,441,930 s μ = 4π² × (1.8827e6)³ / (1.44193e6)² = 39.478 × 6.6725e18 / 2.0792e12 = 1.2670e8 km³/s² ✔ 與現代值相符

這是天文學裡測質量的唯一通用方法。 沒有衛星的天體（例如金星，在探測器之前） 的質量就非常難確定。

6. 克卜勒不知道的兩件事

第一：第三定律其實不精確。 完整的形式是：

T² = 4π²a³ / [G(M + m)] 對行星繞太陽：m/M 最大的是木星，約 1/1047 → 木星的週期比「純克卜勒」預測短約 0.05% 對月球繞地球：m/M = 1/81.3 → 差異 1.2%，用第 8 課算過，這個必須修正

克卜勒的資料精度看不出行星的這個偏差。 牛頓的推導卻自然帶出了它。

第二：三定律只對二體成立。 行星彼此之間的攝動會造成偏差， 而這些偏差正是 1846 年海王星被算出來 而非看出來的原因——天王星的軌道偏離了預測， 偏離量指向一顆尚未發現的行星。

7. 從經驗定律到推導結果的意義

克卜勒的三定律是描述：它們說行星怎麼動。 牛頓的推導是解釋：它們說行星為什麼這樣動。

差別在於預測能力。 克卜勒定律只能用在已經觀測過的系統上； 牛頓的方程可以告訴你 一個從來沒有人飛過的軌道會長什麼樣。

阿波羅計畫每一次點火的時機與大小， 都是從第 7 到 11 課那組方程算出來的， 在真的點火之前就已經知道結果。 這是「解釋」相對於「描述」的實際價值。
