從時間反推位置：軌道傳播

這一課的目標

  • 把前面的零件組成完整的軌道傳播器
  • 認識 Lagrange f 與 g 函數
  • 知道解析傳播與數值積分各自的適用範圍

1. 傳播問題的完整敘述

輸入 t₀ 時刻的狀態向量 r₀, v₀ 時間增量 Δt 輸出 t₀ + Δt 時刻的狀態向量 r, v

這是軌道力學最基本的計算。 導航、會合、任務規劃、碰撞預警——全部建立在它上面。

2. 標準流程（經由六要素）

1. 由 r₀, v₀ 算出 a, e, i, Ω, ω, ν₀ （第 14 課） 2. 由 ν₀ 算 E₀： tan(E₀/2) = √((1−e)/(1+e)) · tan(ν₀/2) 3. 由 E₀ 算 M₀ = E₀ − e·sin E₀ （克卜勒方程，正向） 4. M = M₀ + n·Δt，其中 n = √(μ/a³) 5. 解克卜勒方程得 E （牛頓法，第 18 課） 6. 由 E 算 ν 與 r 7. 由 (a,e,i,Ω,ω,ν) 組回 r, v （第 14 課）

七個步驟，中間只有第 5 步需要迭代。

但這個流程有兩個缺點： 要做兩次座標轉換（很多三角函數）， 而且在退化軌道（e≈0 或 i≈0）會出問題（第 14 課）。

3. 更好的方法：Lagrange f 與 g 函數

關鍵洞見：新的位置向量一定落在軌道平面上， 所以它必定是 r₀ 與 v₀ 的線性組合。

┌──────────────────────┐ │ r = f·r₀ + g·v₀ │ │ v = ḟ·r₀ + ġ·v₀ │ └──────────────────────┘ f、g、ḟ、ġ 是四個純量函數。 它們完全繞過了六要素與座標轉換。

用偏近點角的改變量 ΔE = E − E₀ 表示：

f = 1 − (a/r₀)(1 − cos ΔE) g = Δt − √(a³/μ)(ΔE − sin ΔE) ḟ = −√(μa)·sin ΔE / (r·r₀) ġ = 1 − (a/r)(1 − cos ΔE) 一個有用的檢查：f·ġ − ḟ·g = 1 恆成立 （這是 Wronskian 行列式，來自狀態轉移矩陣的保辛性質）

那個恆等式在實作時極有價值。 寫完程式後算一次 f·ġ − ḟ·g， 如果不等於 1（誤差在 10⁻¹² 以內），就是有 bug。

4. 通用變數：一個程式處理所有軌道型態

上面的公式只對橢圓成立。 雙曲線要換成 cosh、sinh，拋物線又是另一套。 寫三套程式很容易出錯。

Sundman 與 Battin 發展出的通用變數 （universal variable）解決了這個問題。

引入變數 χ，滿足 dχ/dt = √μ / r 以及 Stumpff 函數 C(z) = (1 − cos√z)/z 若 z > 0 = (cosh√(−z) − 1)/(−z) 若 z < 0 = 1/2 若 z = 0 S(z) = (√z − sin√z)/√z³ 若 z > 0 = (sinh√(−z) − √(−z))/√(−z)³ 若 z < 0 = 1/6 若 z = 0 其中 z = χ²/a （橢圓時正，雙曲線時負，拋物線時零） 通用克卜勒方程 √μ·Δt = (r₀·v₀/√μ)χ²C(z) + (1 − r₀/a)χ³S(z) + r₀χ 同樣用牛頓法對 χ 求解。

Stumpff 函數在 z = 0 附近要用級數展開， 因為公式裡有 0/0。實作時這是最容易出錯的地方。

C(z) = 1/2 − z/24 + z²/720 − z³/40320 + ... S(z) = 1/6 − z/120 + z²/5040 − z³/362880 + ... 當 |z| < 0.1 時改用級數。

5. 解析傳播的極限

上面的方法有一個共同前提：純二體。 真實世界不是。

攝動相對主要重力的量級累積效應
地球 J2（扁率）約 10-3LEO 每天進動數度
更高階重力項10-6公里級／天
月球引力（對 LEO）10-7GEO 上顯著
太陽引力（對 LEO）10-7GEO 上顯著
大氣阻力（400 km）10-7–10-5高度持續下降
太陽輻射壓10-8高面質比衛星顯著
廣義相對論10-9GPS 授時必須修正
J2 造成的一階長期變化（可以解析算出） dΩ/dt = −(3/2)·J2·(R/p)²·n·cos i dω/dt = (3/4)·J2·(R/p)²·n·(5cos²i − 1) J2 = 1.08263e-3（地球） 範例：ISS（a = 6778 km, e ≈ 0, i = 51.6°） n = √(398600/6778³) = 1.1314e-3 rad/s (R/p)² = (6378/6778)² = 0.8857 dΩ/dt = −1.5 × 1.08263e-3 × 0.8857 × 1.1314e-3 × cos(51.6°) = −1.0128e-6 rad/s = −5.01 度/天 實際觀測值約 −5.0 度/天 ✔

J2 的效應大到可以用解析公式處理， 所以有一整類「半解析」方法： 用二體解當主體，再疊加攝動的解析修正。 這對衛星編目與長期預報很實用。

6. 什麼時候必須改用數值積分

情況方法理由
快速估算、教學純二體解析一行公式
衛星編目、幾天預報半解析（二體 + J2）夠準、夠快
地月轉移數值積分兩個天體同時作用，patched conic 不夠準
行星際任務數值積分 + 高精度星曆誤差累積數億公里
低推力軌道數值積分推力持續作用，沒有「脈衝」可言
碰撞預警數值積分 + 協方差傳播需要不確定度，不只是位置

阿波羅實際使用的是混合方式。 地面的任務控制中心用大型電腦做完整的數值積分， 算出精確的點火參數再上傳； 太空船上的 AGC 只做二體解析計算， 用來在失去通訊時維持基本導航能力 （這個備援能力在阿波羅 13 號派上了用場，第 88 課）。

7. 一個實際的誤差示範

若用純二體傳播 ISS 軌道七天，只更新 M 七天後 Ω 實際已經退行 35 度 → 位置誤差約 6778 × sin(35°) = 3,887 km 用二體 + J2 一階修正 → 誤差降到約 10 公里量級 用完整數值積分（含大氣模型） → 誤差降到百公尺量級，但取決於大氣密度預報的品質

最後一句很重要。 LEO 軌道預報的精度上限不是數學，是大氣密度。 太陽活動會讓熱層密度變化好幾倍， 而太陽活動本身無法精確預報。 這就是為什麼 LEO 衛星的長期軌道預報 永遠有不可消除的不確定性。
