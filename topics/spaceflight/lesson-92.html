發射窗口：26 個月一次與 porkchop plot

這一課的目標

  • 算出 26 個月這個數字
  • 看懂 porkchop plot 怎麼產生與怎麼讀
  • 理解窗口的實際寬度

1. 會合週期

地球與火星的相對位置有週期性。 地球角速度 ω_E = 360/365.256 = 0.98561 度/天 火星角速度 ω_M = 360/686.980 = 0.52403 度/天 相對角速度 = 0.98561 − 0.52403 = 0.46158 度/天 回到同樣的相對位置需要 360/0.46158 = 779.9 天 ┌────────────────────────────────────┐ │ 會合週期 = 779.9 天 = 2.135 年 │ │ = 25.6 個月 │ └────────────────────────────────────┘ 用週期表示的通式 1/T_syn = |1/T₁ − 1/T₂| 1/T_syn = |1/365.256 − 1/686.980| = |2.7378e-3 − 1.4556e-3| = 1.2822e-3 T_syn = 779.9 天 ✔

為什麼外行星的會合週期反而短 木星走得很慢（12 年一圈）， 所以地球每繞一圈多一點就能「追上」它。 T_syn → 365 天（當外行星週期 → ∞） 火星的會合週期特別長（26 個月）， 是因為它的週期（1.88 年）與地球（1 年） 「不夠懸殊也不夠接近」。 這是巧合，但它是載人火星任務時程規劃的核心約束。

2. 為什麼每次窗口都不一樣

火星軌道的離心率 e = 0.0934（第 90 課） 近日點 1.381 AU 遠日點 1.666 AU 如果「會合」發生在火星的近日點附近 → 轉移距離短，Δv 低，飛行時間短 如果發生在遠日點附近 → 轉移距離長，Δv 高 而會合週期（779.9 天）與火星週期（687.0 天）不成整數比 → 每一次會合發生在火星軌道的不同位置 → 大約每 15–17 年才回到類似的條件
發射窗口最小 C3（典型）相對難度
有利年份（火星近日點附近）約 8–11 km²/s²容易
平均年份約 12–16中等
不利年份（火星遠日點附近）約 18–22困難

C3 從 8 變成 20，對發射載具的酬載影響很大。 同一枚火箭在有利年份可以送 3 噸到火星， 在不利年份可能只剩 1.8 噸。

3. Porkchop plot：怎麼產生

演算法 for 每一個出發日期 t_dep: for 每一個到達日期 t_arr: 1. 從星曆查出 t_dep 時地球的位置 r₁ 與速度 v₁_planet 2. 從星曆查出 t_arr 時火星的位置 r₂ 與速度 v₂_planet 3. Δt = t_arr − t_dep 4. 解 Lambert(r₁, r₂, Δt, μ_Sun) → v₁, v₂ （第 20 課） 5. C3 = |v₁ − v₁_planet|² 6. v∞_抵達 = |v₂ − v₂_planet| 存成兩個二維陣列 畫出 C3 與 v∞ 的等高線圖，疊在同一張圖上。 橫軸：出發日期 縱軸：到達日期（或飛行時間） 「porkchop」這個名字來自等高線圍出的形狀 —— 它看起來像一塊豬排。

4. 怎麼讀這張圖

選擇發射日期的實際流程 1. 畫出 C3 等高線（受限於發射載具的能力） 例如：Falcon Heavy 送 4 噸的 C3 上限約 15 2. 畫出抵達 v∞ 等高線（受限於 EDL 或 MOI 的能力） 例如：EDL 系統能承受的最大進入速度對應 v∞ < 3.5 3. 兩者的交集 = 可用區域 4. 在可用區域內選擇 考慮：發射場的每日窗口、 抵達時火星的季節（沙塵暴）、 抵達時的通訊幾何（會不會被太陽擋住）、 著陸點的當地時間 5. 最終選出一個「發射週期」（launch period）， 通常持續 2–4 週，每天有一個 20–120 分鐘的窗口。

5. 兩支「豬排」

Porkchop 圖通常有兩個分離的低 C3 區域 第一類（type I）：轉移角 < 180 度 飛行時間較短（150–250 天） 通常 C3 較高 第二類（type II）：轉移角 > 180 度 飛行時間較長（250–350 天） 通常抵達 v∞ 較低 兩者中間有一條「脊」—— 那正是第 20 課的 180 度奇異點！ 在轉移角恰好 180 度時，Lambert 問題沒有唯一解， C3 在數值上會發散。 所以真實的火星任務從來不用精確的 180 度轉移 —— 它們都落在 type I 或 type II 的其中一邊。

6. 錯過窗口的代價

錯過一次 = 等 26 個月 實際成本 持續的團隊人事費用（每年數千萬到上億美元） 硬體的儲存與維護（有些元件會老化） 可能需要重新認證某些系統 科學儀器的校正失效 團隊流失 歷史案例 ExoMars 2020 因為降落傘測試失敗延到 2022， 又因為地緣政治因素再度延期 —— 目前規劃 2028。 這個任務已經延了三個窗口、超過六年。 這個壓力有時會導致不好的決定 —— 火星極地著陸者（1999）與火星氣候軌道器（1999） 的失敗，事後檢討都提到了 「為了趕上窗口而壓縮測試」。

7. 一個補充：低推力任務的窗口

離子推進的任務（如黎明號 Dawn、 BepiColombo）不使用脈衝式霍曼轉移。 它們持續推進數年，軌道是一條緩慢外旋的螺線。 好處 Isp 3,000 秒（第 25 課）→ 推進劑需求極低 發射窗口寬鬆很多（可以用推進來調整相位） 代價 飛行時間極長（黎明號花了 4 年到灶神星） 需要大量電力（太陽能板或核電） 推力極小，無法在深重力井中作業 對載人任務不適用（時間太長）， 但對貨物運輸與科學探測器越來越常見。
