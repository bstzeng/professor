3. 建議的工具

課文裡所有算式都寫成可直接輸入計算機的形式。 如果想自己重算，最方便的是任何能執行下列風格程式碼的環境：

import math mu_earth = 398600.4418 # km^3/s^2 R_earth = 6378.137 # km def v_circ(r): return math.sqrt(mu_earth / r) def v_vis_viva(r, a): return math.sqrt(mu_earth * (2.0/r - 1.0/a)) r_park = R_earth + 185 a_tli = (r_park + 406563) / 2.0 print(v_circ(r_park)) # 7.7932 print(v_vis_viva(r_park, a_tli)) # 10.9333 print(v_vis_viva(r_park, a_tli) - v_circ(r_park)) # 3.1401 ← TLI

整門課最核心的計算就是上面這幾行。 後面 95 課大部分是在解釋： 這幾個數字該從哪裡來、為什麼這樣取、以及算出來之後要做什麼。

注意所有重力常數都寫成 μ = GM 而不是分開的 G 與 M。 原因是 μ 的測量精度遠高於 G 或 M 各自的精度—— 我們能從衛星軌道非常準確地測出 μ， 但 G 本身是物理學裡測得最不準的基本常數之一。

5. 數字的來源分級

這門課的數字分成三類，課文中會標明：

類別例子可信度
物理常數μ、半徑、AU高，可直接引用
任務紀錄各次點火的時間與持續秒數、質量來自公開任務報告，但不同來源略有出入
本課推算各段 Δv、推進劑用量、損失估計用理想化模型算出的量級

第三類要特別小心。 本課用的是二體 patched conic 模型， 它會系統性地低估實際需求，因為它忽略了： 太陽的攝動、地球扁率、月球重力異常、 有限推力（點火需要幾分鐘而不是瞬間）、 以及任務規劃保留的餘裕。

典型的誤差幅度 本課算出的 TLI Δv 3.14 km/s 阿波羅實際 TLI Δv 約 3.05–3.20 km/s（依任務而異） 誤差 約 ±3% 本課算出的 LOI Δv 0.84 km/s 阿波羅實際 LOI-1 Δv 約 0.89–0.92 km/s 誤差 約 −7%（低估）

幾個百分比的誤差對理解原理完全足夠， 但對真的要飛的任務是致命的。 真實任務規劃用的是高精度星曆、完整重力場模型 與數值積分（第 23 課會說明為什麼）。

6. 閱讀建議

  • 模組 B、C 是地基。後面所有計算都建立在 vis-viva 與霍曼轉移上。如果只能仔細讀兩個模組，就是這兩個。
  • 模組 D 是轉換器。它把 Δv 換成質量，這是所有硬體規格的來源。
  • 模組 G 到 N 是主線。按順序讀，它是一趟完整的旅程。
  • 模組 P 是延伸。它會反覆使用前面的工具，但參考系換成太陽。
  • 第 99 課是查詢用。公式與名詞總表，隨時可以回頭翻。
