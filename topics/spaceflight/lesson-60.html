模組 J｜LOI：進入月球軌道 · 第 60 課

動手算：LOI 需要多少 Δv

這一課的目標

  • 從頭算出 LOI 的 Δv
  • 理解為何分成 LOI-1 與 LOI-2
  • 與實測數據對照並解釋差異

1. 起點：到達時相對月球的速度

第 57 課算過，在影響球邊界 |v_月心| ≈ 1.15 km/s 對應的 v∞ = √(v² − 2μ_M/r) = √(1.15² − 2×4902.8/66183) = √(1.3225 − 0.1482) = 1.084 km/s 實際任務的 v∞ 在 0.8–1.2 km/s 之間， 取決於到達幾何與飛行時間。 本課用 v∞ = 1.18 km/s（由阿波羅 11 號的實測 LOI Δv 反推）。

2. 近月點的速度

目標近月點 r_p = 1,737.4 + 110 = 1,847.4 km 用 vis-viva 的雙曲線形式（第 13 課） v_hyp = √(v∞² + 2μ_M/r_p) = √(1.18² + 2 × 4902.8/1847.4) = √(1.3924 + 5.3078) = √6.7002 = 2.5885 km/s 對照該處的圓軌道速度 v_c = √(μ_M/r_p) = √(4902.8/1847.4) = √2.6539 = 1.6291 km/s 超出 0.9594 km/s。

3. LOI-1：進入橢圓而非圓

阿波羅並沒有一次就圓化。 LOI-1 進入的是一條 110 × 315 公里的橢圓。

目標橢圓 r_p = 1,847.4 km（110 km 高） r_a = 2,052.4 km（315 km 高） a = 1,949.9 km 橢圓在近月點的速度 v_pe = √(μ_M(2/r_p − 1/a)) = √(4902.8 × (1.08256e-3 − 5.12847e-4)) = √(4902.8 × 5.69716e-4) = √2.79322 = 1.6713 km/s ┌────────────────────────────────────┐ │ LOI-1 Δv = 2.5885 − 1.6713 │ │ = 0.9172 km/s │ └────────────────────────────────────┘ 阿波羅 11 號實測：0.9175 km/s ✔

（這個吻合是因為我們用實測值反推了 v∞。 真正的驗證在下一節。）

4. 為什麼不一次圓化

理由說明
降低單次點火的風險LOI-1 是 SPS 的第一次長時間點火（357 秒），若中途失敗，橢圓軌道仍可控
保留中止能力橢圓軌道的遠月點較高，若要中止返回，TEI 的時機選擇更多
先量測再圓化LOI-1 之後有兩圈時間讓地面精確定軌，再算 LOI-2 的參數
月球重力異常第 63 課：直接進入低圓軌道會因為 mascon 而快速變形
總 Δv 幾乎相同分兩次只多花約 0.002 km/s
驗算「分兩次幾乎不多花」 一次圓化：Δv = 2.5885 − 1.6291 = 0.9594 km/s 分兩次： LOI-1（進入 110×315 橢圓）= 0.9172 LOI-2（在近月點圓化） = 1.6713 − 1.6291 = 0.0423 合計 = 0.9595 km/s 差異 0.0001 km/s —— 完全可以忽略。 為什麼？因為兩次點火都在同一個位置（近月點）， 只是分成兩段做。Oberth 效應完全相同。 阿波羅 11 號 LOI-2 實測：0.0479 km/s （略高，因為同時做了微小的平面修正）

5. 現在真正驗證一次

上面用實測值反推 v∞ 是循環論證。 現在反過來，從獨立的物理量推出 v∞。

獨立推導 v∞ 在影響球邊界（距月心 66,183 km，距地心 318,217 km） 地心座標中的太空船速度（用第 50 課的轉移軌道） a = 206,563 km, μ_E = 398,600 v = √(398600 × (2/318217 − 1/206563)) = √(398600 × (6.28502e-6 − 4.84115e-6)) = √(398600 × 1.44387e-6) = √0.575525 = 0.7586 km/s 月球的公轉速度 v_月 = 1.022 km/s（近似圓軌道） 兩者的向量差取決於夾角 θ |v_月心| = √(0.7586² + 1.022² − 2 × 0.7586 × 1.022 × cos θ) θ = 60°： |v| = 0.9191 km/s θ = 75°： |v| = 1.1039 θ = 82°： |v| = 1.1850 θ = 90°： |v| = 1.2728 θ = 105°： |v| = 1.4217 對應的 v∞ = √(|v|² − 2μ_M/66183) = √(|v|² − 0.1482) 以及 LOI-1 = √(v∞² + 5.3078) − 1.6713 θ = 60°： v∞ = 0.8346 → LOI-1 = 0.779 km/s θ = 75°： v∞ = 1.0346 → LOI-1 = 0.854 θ = 82°： v∞ = 1.1207 → LOI-1 = 0.891 θ = 90°： v∞ = 1.2132 → LOI-1 = 0.933 θ = 105°： v∞ = 1.3686 → LOI-1 = 1.008 實測 0.9175 落在 θ ≈ 88° 附近。 ✔ 也就是說：太空船抵達時的速度方向 與月球公轉方向大致垂直。這符合幾何直覺 —— 太空船幾乎「徑向」向外飛，而月球「橫向」掃過來。

這個交叉檢驗確認了整套計算的自洽性。

6. LOI 的執行細節

項目阿波羅 11 號
點火時刻任務時間 75:49:50
持續時間357.5 秒（近 6 分鐘）
Δv917.5 m/s
引擎SPS（91.2 kN）
點火前質量約 44,000 kg
消耗推進劑約 12,300 kg
位置月球背面，無通訊
結果軌道110.4 × 314.1 km
有限推力損失 理想脈衝：瞬間改變速度 實際：357.5 秒，期間太空船在軌道上移動 近月點附近的角速度 ω = v/r = 2.5885/1847.4 = 1.4011e-3 rad/s = 0.0803 度/秒 357.5 秒 → 移動 28.7 度的真近點角 在這 28.7 度中，速度方向一直在轉， 而推力方向必須跟著調整（或接受餘弦損失）。 典型損失：1–2%，約 10–18 m/s 這被算在第 15 課的餘裕欄裡。

7. 那六分鐘

LOI 發生在月球背面。 從點火開始到重新出現在月球前緣， 地面完全沒有任何訊號。

阿波羅 11 號的情況 75:41:23 失去訊號（進入月球背面） 75:49:50 LOI-1 點火（地面不知道有沒有成功） 75:55:48 點火結束 76:15:29 重新獲得訊號 約 34 分鐘的等待。 如果 LOI 沒點著 太空船會沿雙曲線飛過月球 重新出現的時間會比預期早約 6 分鐘 所以任務控制中心準備了兩個時間： 「成功則在 76:15:29 出現」 「失敗則在 76:09:xx 出現」 訊號出現的時刻本身就告訴了他們答案 —— 在聽到任何語音之前。

這是一個漂亮的工程細節： 用一個純幾何的事實作為最快的狀態指示器。

檢查你的理解

  1. 從 v∞ 算出近月點的雙曲線速度與 LOI-1 的 Δv
  2. 驗證分兩次點火與一次圓化的總 Δv 幾乎相同
  3. 用獨立的幾何推導交叉檢驗 v∞ 的合理範圍
