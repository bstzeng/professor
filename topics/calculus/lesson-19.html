微積分基本定理

這一課的目標

  • 理解微積分基本定理
  • 學會用反導數計算積分
  • 體會這個定理的威力

兩個看似無關的問題

切線的斜率（微分）與曲線下的面積（積分），看起來是兩個完全不同的幾何問題。牛頓的老師巴羅已經隱約察覺它們有關；牛頓與萊布尼茲則把這個關係變成了一套系統的方法。

第一部分：面積函數的導數

定義 A(x) = 從 a 到 x 的面積。當 x 增加一點點 dx，面積增加一個高 f(x)、寬 dx 的窄條，所以：

\[\frac{d}{dx}\int_a^x f(t)\,dt=f(x)\]

面積的增長速度，就是曲線的高度。

第二部分：用反導數算積分

\[\int_a^b f(x)\,dx=F(b)-F(a),\qquad F'=f\]

只要找到一個函數 F，它的導數是 f（反導數），積分就等於 F 在兩個端點的差。不必再加無限多個長方形！

例子

∫ x² dx 從 0 到 2：x³/3 的導數是 x²，所以答案 = 8/3 − 0 = 8/3。上一課的模擬中，用一百個長方形慢慢逼近的數，在這裡一行就算出來了。

直覺上：如果你知道車子每一刻的位置（F），那麼從 a 到 b 時刻走了多遠，只要看終點減起點——不必把每一刻的速度（f）加起來。

這個定理把微分與積分連成一體，讓無數原本無法計算的問題變得可以計算。它是科學革命的數學引擎。

🧭 這一課的重點

切線斜率與曲線下面積看似不同，巴羅已察覺有關，牛頓與萊布尼茲變成系統方法；第一部分定義 A(x) 為 a 到 x 的面積，x 增加 dx 面積增加高 f(x) 寬 dx 的窄條所以 A′(x)＝f(x)，面積的增長速度就是曲線高度；第二部分 ∫_a^b f dx＝F(b)−F(a) 其中 F′＝f 是反導數，不必加無限多長方形；∫ x² 從 0 到 2，x³/3 導數是 x² 所以 8/3；直覺是知道每刻位置看終點減起點不必把速度加起來；這定理把微分與積分連成一體，是科學革命的數學引擎。
