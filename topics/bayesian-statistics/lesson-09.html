卜瓦松—伽瑪模型

這一課的目標

  • 推導卜瓦松—伽瑪的後驗
  • 理解它在計數資料中的應用
  • 理解小樣本時先驗的作用

計數資料

每小時有幾通電話、每年有幾次地震、每個晶片有幾個缺陷、某個偵測器每天看到幾個事件。這類「在固定時間或空間中發生了幾次」的資料，常用卜瓦松分布描述，參數是發生率 \(\lambda\)：

\[p(k\,|\,\lambda) = \frac{\lambda^ke^{-\lambda}}{k!}\]

共軛先驗：伽瑪分布

\[p(\lambda) = \text{Gamma}(\lambda\,|\,\alpha, \beta) \propto \lambda^{\alpha-1}e^{-\beta\lambda}\]

推導

觀察了 \(n\) 個時段，總共 \(K = \sum k_i\) 次事件：

\[p(\lambda|\text{資料}) \propto \lambda^{K}e^{-n\lambda}\cdot\lambda^{\alpha-1}e^{-\beta\lambda} = \lambda^{\alpha+K-1}e^{-(\beta+n)\lambda}\]
\[\text{後驗} = \text{Gamma}(\alpha + K,\; \beta + n)\]

同樣簡單：事件數加到 α，觀察的時段數加到 β。\(\alpha\) 與 \(\beta\) 可以理解為「想像中已在 β 個時段中看到 α 次事件」。後驗平均 \((\alpha + K)/(\beta + n)\)。

小樣本的威力

一家新開的餐廳，第一週有 0 次食物中毒的投訴。用頻率派的最大似然估計，發生率是 0——但這顯然太樂觀。貝氏方法用同類餐廳的資料作為先驗，給出一個合理的、大於 0 的估計，並且隨著資料增加，逐漸「相信」這家餐廳自己的紀錄。

同樣的想法用在：保險公司為新客戶定保費、估計罕見疾病的發生率、以及第 26 課的階層模型。

連續量測常態（變異數已知）常態精確度相加

🧭 這一課的重點

計數資料用卜瓦松分布描述發生率 λ，共軛先驗是伽瑪分布，n 個時段共 K 次事件的後驗為 Gamma(α+K, β+n)，事件數加到 α、時段數加到 β；小樣本時最大似然可能給出 0 這種過度樂觀的估計，貝氏以同類資料作先驗給出合理估計，用於保險、罕見疾病與階層模型。
