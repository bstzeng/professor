Log4Shell

這一課的目標

  • 了解Log4Shell的背景與經過
  • 理解調查認定的原因
  • 認識事故之後的改進
項目內容
時間2021 年 12 月
事件Log4Shell 漏洞
受害對象使用 Java 日誌程式庫 Log4j 的大量系統
手法在日誌中寫入特定字串即可遠端執行程式
影響全球數以億計的系統可能受影響

背景

Log4j 是 Java 世界中非常普遍的日誌記錄程式庫，被包在無數的軟體與產品中。

經過

  1. 研究者發現：只要讓系統把一段特定格式的字串寫進日誌，Log4j 就會去遠端下載並執行程式。
  2. 攻擊者可以把這段字串放在聊天訊息、帳號名稱、網頁標頭中——幾乎任何會被記錄的地方。
  3. 漏洞公開後幾小時內就出現大規模的攻擊。
  4. 許多組織甚至不知道自己的系統裡有沒有使用 Log4j。

原因

  • 一個方便但危險的功能被預設開啟。
  • 軟體依賴層層嵌套，組織缺乏元件清單。

後續改進

  • 推動軟體物料清單（SBOM），讓組織知道自己用了哪些元件。
  • 加強開源軟體的安全與快速修補。

一句話教訓

你無法修補你不知道自己擁有的東西。
