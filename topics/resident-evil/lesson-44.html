模組 K｜六代：四條戰線 · 第 44 課

四個劇本的結構與 C 病毒

這一課的目標

  • 掌握六代四條劇本的結構與交會方式
  • 認識 C 病毒的成分與產物
  • 理解六代在設計上的核心問題

《惡靈古堡 6》二〇一二年推出，它的野心是同時做出三種不同的惡靈古堡——結果是系列評價最兩極的一作。

1. 四條劇本

劇本主角取向
里昂篇里昂・S・甘迺迪 ／ 海倫娜・哈潑喪屍、封閉空間、偏向傳統恐怖
克里斯篇克里斯・雷德菲爾 ／ 皮爾斯・尼凡斯軍事射擊、掩體、大場面
傑克篇傑克・穆勒 ／ 雪莉・柏金逃亡與追逐，近戰比重高
艾妲篇艾妲・王潛行與解謎，補完前三條線的空白

四條線在幾個時間點交會——同一場爆炸、同一棟建築、同一個敵人，會從不同角度被演出兩次甚至三次。玩家在交會點還可以與正在玩另一條線的線上玩家短暫合作。

2. C 病毒

六代的病毒由卡菈・拉德梅斯製作，成分是 G 病毒＋T-Veronica，並加入了從傑克・穆勒（威斯克之子）身上取得的資料。

產物特徵
喪屍C 病毒也能製造傳統喪屍，但這些喪屍會奔跑、會使用武器
J'avo保有智能、能組織作戰。受傷的部位會當場變異成鐮刀、甲殼或翅膀
蛹（Chrysalid）J'avo 重傷後結繭，羽化成完全不同的高階型態

J'avo 是設定上最進步的一步：打傷它反而讓它變強，這在遊戲性上製造了「要一次解決，不要打半套」的壓力。

3. 六代的問題

野心與失焦

六代想同時滿足三群人：想要恐怖的、想要射擊的、想要動作的。它的解法是各做一條線。

問題有兩層：

  • 每一條線都不夠好——里昂篇的恐怖比不上一代，克里斯篇的射擊比不上同期的軍事射擊遊戲
  • 系統要同時服務三種玩法，結果誰都不合身——翻滾、趴射、近戰連段、快速反應事件全部塞在一起，操作複雜卻不精準

再加上大量不可跳過的過場與 QTE，六代成為系列「動作化」路線的終點站——不是因為它走到了目的地，而是因為它撞牆了。

4. 它做對的地方

  • 四線交錯的敘事結構在當年是有企圖心的實驗
  • 傑克與雪莉這一對是系列中寫得相當好的新角色組合
  • 戰鬥系統本身在熟練後有相當高的上限（傭兵模式評價良好）
  • 克里斯篇對「指揮官的責任」這個主題有認真處理

  1. 列出六代四條劇本的主角與各自的取向
  2. 說明 C 病毒的成分與 J'avo 最特別的能力
  3. 說明六代「想同時滿足三群人」造成的兩個問題
