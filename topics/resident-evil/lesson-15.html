模組總結：0 代在時間線上的位置

這一課的目標

  • 整理 0 代為整個系列補完的設定
  • 理解這一代在評價上的爭議點
  • 知道遊玩順序上的建議

0 代是系列裡定位最特別的一作：它是最後製作的古典式惡靈古堡（2002 年，四代之前），講的卻是最早發生的故事。

1. 它補完了什麼

  • Bravo 小隊的下落——一代開場時他們已經死得差不多了，0 代說明了過程
  • T 病毒的真正發明者——馬可斯，而不是後來接手的柏金
  • 威斯克與柏金的年輕時代——兩人一起執行過謀殺，這對理解他們後來的關係很重要
  • 麗貝卡的角色厚度——她在一代裡戲份不多，0 代給了她一整段故事

2. 爭議在哪裡

優點缺點
搭檔切換帶來新的謎題設計兩人分頭管理道具非常繁瑣
列車與培訓所的場景美術是系列高峰取消道具箱，導致玩家要記住東西丟在哪
補完了關鍵的前史比利在後續作品中幾乎沒有再出現，角色被浪費
馬可斯是設定上很有意思的反派「水蛭復活」的設定被不少人認為太超自然

一個公允的評價

0 代常被排在系列中段的位置，原因不是它做錯了什麼，而是它做的是別人已經做過的事：在一代重製版（同年推出）把古典惡靈古堡的表現力推到頂點之後，0 代的固定鏡頭與坦克操作顯得像是慣性延續。

但如果你在意這個系列的設定，0 代提供的資訊密度非常高——特別是它讓你看見保護傘內部的人際關係，而不只是它的產品。

3. 遊玩順序建議

如果是第一次接觸，建議先玩一代（重製版）再玩 0 代。0 代的許多情感重量來自「你已經知道洋館裡會發生什麼」，而它的結尾鏡頭也只有在你認得那棟洋館時才成立。

  1. 列出 0 代為系列補完的至少三項設定
  2. 說明 0 代取消道具箱造成的實際問題
  3. 解釋為什麼建議先玩一代再玩 0 代
