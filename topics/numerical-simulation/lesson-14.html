一維波動方程式

這一課的目標

  • 把波動方程式離散化
  • 推導 CFL 條件
  • 認識數值色散

難度：★★★

結果

\[u_i^{n+1} = 2u_i^n - u_i^{n-1} + C^2\left(u_{i+1}^n - 2u_i^n + u_{i-1}^n\right),\qquad C = \frac{c\,\Delta t}{\Delta x} \le 1\]

一步一步推導

🐍 wave1d.py　下載　執行：python wave1d.py

固定模擬到 t = 0.6（脈衝已分成兩半並在牆反射），C ≤ 1 時最大值約 0.5；C 超過 1 一點點就爆掉。

# 第 14 課：一維波動方程式 u_tt = c² u_xx，跳蛙法；CFL 數 C = c dt/dx import numpy as np def run(C, N=200, T=0.6): steps = round(T / (C / N)) # dt = C·dx/c，c = 1；固定模擬到 t = T x = np.linspace(0, 1, N + 1) u0 = np.exp(-200 * (x - 0.5) ** 2) # 一個鼓起的脈衝 u_prev = u0.copy() u = u0.copy() u[1:-1] = u0[1:-1] + 0.5 * C**2 * (u0[2:] - 2 * u0[1:-1] + u0[:-2]) # 初速為 0 的第一步 for _ in range(steps): un = np.zeros_like(u) un[1:-1] = 2 * u[1:-1] - u_prev[1:-1] + C**2 * (u[2:] - 2 * u[1:-1] + u[:-2]) u_prev, u = u, un return np.max(np.abs(u)) for C in [0.5, 0.9, 1.0, 1.02, 1.1]: print(f"C = {C:4.2f} -> t = 0.6 時 max|u| = {run(C):.3e}")

▶ 執行結果（實際執行的輸出）

C = 0.50 -> t = 0.6 時 max|u| = 4.995e-01 C = 0.90 -> t = 0.6 時 max|u| = 4.995e-01 C = 1.00 -> t = 0.6 時 max|u| = 4.999e-01 C = 1.02 -> t = 0.6 時 max|u| = 5.904e+03 C = 1.10 -> t = 0.6 時 max|u| = 2.324e+25

常見錯誤

  • 第一步用 u⁻¹ = u⁰：初速度不為 0 時會錯。程式用泰勒展開處理初速為 0 的第一步。
  • 二維、三維時的條件更嚴：C ≤ 1/√d（第 33 課用 0.5）。
  • 以為 C 愈接近 1 愈好就把它設成 1.0：多維、變係數時沒有「剛好精確」，留一點餘裕。

🧭 這一課的重點

波動方程式跳蛙法 u^{n+1} = 2uⁿ − u^{n−1} + C²δ²uⁿ。放大因子滿足 G² − 2(1−2C²s²)G + 1 = 0，C ≤ 1 時 |G| = 1，C > 1 時爆掉（CFL 條件：數值傳播速度 Δx/Δt 不能比 c 慢）；一維 C = 1 剛好精確。
