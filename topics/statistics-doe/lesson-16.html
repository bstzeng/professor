指數與 Gamma 分布

這一課的目標

  • 推導指數分布的性質與無記憶性
  • 掌握 Gamma 函數與 Gamma 分布
  • 看出卡方分布只是 Gamma 的特例

1. 指數分布

密度與 CDF：

\[ f(x) = \lambda e^{-\lambda x}, \quad F(x) = 1 - e^{-\lambda x}, \qquad x \geq 0 \]

它描述卜瓦松過程中兩次事件之間的等待時間。

推導這個連結：設事件依速率 \( \lambda \) 的卜瓦松過程發生。 「等待時間 \( T \) 超過 \( t \)」等價於「\( [0,t] \) 內一次都沒發生」：

\[ P(T > t) = P(N(t) = 0) = \frac{(\lambda t)^0 e^{-\lambda t}}{0!} = e^{-\lambda t} \]

故 \( F(t) = 1 - e^{-\lambda t} \)，微分即得密度。

2. MGF 與動差

\[ M(t) = \int_0^{\infty} e^{tx}\lambda e^{-\lambda x}dx = \lambda\int_0^{\infty}e^{-(\lambda - t)x}dx = \frac{\lambda}{\lambda - t}, \qquad t < \lambda \]

注意 MGF 只在 \( t<\lambda \) 存在——這是重尾分布的一個訊號。

\[ M'(t) = \frac{\lambda}{(\lambda-t)^2} \;\Rightarrow\; E[X] = \frac{1}{\lambda} \] \[ M''(t) = \frac{2\lambda}{(\lambda-t)^3} \;\Rightarrow\; E[X^2] = \frac{2}{\lambda^2}, \qquad \operatorname{Var}(X) = \frac{2}{\lambda^2} - \frac{1}{\lambda^2} = \frac{1}{\lambda^2} \]

平均與標準差相等，都是 \( 1/\lambda \)。

3. 無記憶性

\[ P(X > s+t \mid X > s) = \frac{P(X>s+t)}{P(X>s)} = \frac{e^{-\lambda(s+t)}}{e^{-\lambda s}} = e^{-\lambda t} = P(X>t) \]

指數分布是唯一具有無記憶性的連續分布 （幾何分布是唯一的離散版本）。

實務意義：指數分布假設「不會老化」。 電子元件的隨機失效大致符合， 但機械磨損完全不符合—— 已經跑了十萬公里的軸承，剩餘壽命當然比新品短。 後者要用 Weibull 分布之類允許失效率隨時間變化的模型。

4. Gamma 函數

\[ \Gamma(\alpha) = \int_0^{\infty} x^{\alpha-1}e^{-x}\,dx, \qquad \alpha > 0 \]

關鍵性質一：遞迴。用分部積分，取 \( u = x^{\alpha} \)、\( dv = e^{-x}dx \)：

\[ \Gamma(\alpha+1) = \int_0^\infty x^{\alpha}e^{-x}dx = \Big[-x^{\alpha}e^{-x}\Big]_0^{\infty} + \alpha\int_0^{\infty}x^{\alpha-1}e^{-x}dx = 0 + \alpha\Gamma(\alpha) \]

關鍵性質二：\( \Gamma(1) = \int_0^\infty e^{-x}dx = 1 \)。結合遞迴得

\[ \Gamma(n) = (n-1)! \quad \text{對正整數 } n \]

關鍵性質三：\( \Gamma(1/2) = \sqrt{\pi} \)。推導：令 \( x = u^2/2 \)，

\[ \Gamma(1/2) = \int_0^\infty x^{-1/2}e^{-x}dx = \int_0^{\infty}\frac{\sqrt{2}}{u}e^{-u^2/2}\,u\,du = \sqrt{2}\int_0^{\infty}e^{-u^2/2}du = \sqrt{2}\cdot\frac{\sqrt{2\pi}}{2} = \sqrt{\pi} \]

最後一步用了上一課的高斯積分（取一半，因為只積正半軸）。 這個結果在推導卡方分布時會直接用到。

5. Gamma 分布

\[ f(x) = \frac{\beta^{\alpha}}{\Gamma(\alpha)}x^{\alpha-1}e^{-\beta x}, \qquad x>0,\ \alpha>0,\ \beta>0 \]

\( \alpha \) 稱為形狀參數，\( \beta \) 稱為率參數。 （另一種常見的參數化用尺度 \( \theta = 1/\beta \)，本課程統一用率參數。）

MGF：

\[ M(t) = \int_0^\infty e^{tx}\frac{\beta^\alpha}{\Gamma(\alpha)}x^{\alpha-1}e^{-\beta x}dx = \frac{\beta^\alpha}{\Gamma(\alpha)}\int_0^{\infty}x^{\alpha-1}e^{-(\beta-t)x}dx \]

右邊的積分是 \( \text{Gamma}(\alpha, \beta-t) \) 密度的正規化常數的倒數， 等於 \( \Gamma(\alpha)/(\beta-t)^{\alpha} \)。故

\[ \boxed{\;M(t) = \left(\frac{\beta}{\beta-t}\right)^{\alpha}, \qquad t<\beta\;} \]

由此

\[ E[X] = \frac{\alpha}{\beta}, \qquad \operatorname{Var}(X) = \frac{\alpha}{\beta^2} \]

6. 可加性

若 \( X_i \sim \text{Gamma}(\alpha_i, \beta) \) 獨立（率參數必須相同），則

\[ M_{\sum X_i}(t) = \prod\left(\frac{\beta}{\beta-t}\right)^{\alpha_i} = \left(\frac{\beta}{\beta-t}\right)^{\sum\alpha_i} \]

故 \( \sum X_i \sim \text{Gamma}(\sum\alpha_i, \beta) \)。 形狀參數相加，率參數不變。

7. 家族關係

分布是 Gamma 的哪個特例備註
指數 \( (\lambda) \)\( \alpha=1,\ \beta=\lambda \)第一次事件的等待時間
Erlang \( (k,\lambda) \)\( \alpha=k \) 為正整數第 \( k \) 次事件的等待時間
卡方 \( \chi^2(k) \)\( \alpha = k/2,\ \beta = 1/2 \)下一個模組的主角

最後一列是這一課的重點。 把 \( \alpha=k/2, \beta=1/2 \) 代入 Gamma 的 MGF：

\[ M(t) = \left(\frac{1/2}{1/2-t}\right)^{k/2} = (1-2t)^{-k/2} \]

記住這個式子。模組 E 一開始就要用它來 辨認出「n 個獨立標準常態的平方和」是什麼分布。
