模組 L｜簡單線性迴歸 · 第 52 課

估計量的性質與誤差變異數

這一課的目標

  • 證明 β̂ 的不偏性
  • 推導 Var(β̂₁) 與 Var(β̂₀)
  • 推導 MSE 為 σ² 的不偏估計

1. 把 β̂₁ 寫成 Y 的線性組合

這是所有推導的關鍵一步。先注意一個恆等式：

\[ S_{xy} = \sum(x_i-\bar x)(Y_i - \bar Y) = \sum(x_i-\bar x)Y_i - \bar Y\underbrace{\sum(x_i-\bar x)}_{=0} = \sum(x_i-\bar x)Y_i \]

因此

\[ \hat\beta_1 = \frac{\sum(x_i-\bar x)Y_i}{S_{xx}} = \sum_{i=1}^{n} c_i Y_i, \qquad c_i = \frac{x_i-\bar x}{S_{xx}} \]

\( \hat\beta_1 \) 是 \( Y_i \) 的線性組合，權重 \( c_i \) 是固定的常數 （因為 \( x_i \) 視為固定）。

三個有用的性質：

\[ \sum c_i = 0, \qquad \sum c_ix_i = 1, \qquad \sum c_i^2 = \frac{1}{S_{xx}} \]

驗證第二式：\( \sum c_ix_i = \frac{\sum(x_i-\bar x)x_i}{S_{xx}} = \frac{S_{xx}}{S_{xx}}=1 \)。
驗證第三式：\( \sum c_i^2 = \frac{\sum(x_i-\bar x)^2}{S_{xx}^2} = \frac{S_{xx}}{S_{xx}^2}=\frac{1}{S_{xx}} \)。

2. 不偏性

\[ E[\hat\beta_1] = \sum c_iE[Y_i] = \sum c_i(\beta_0+\beta_1x_i) = \beta_0\underbrace{\sum c_i}_{=0} + \beta_1\underbrace{\sum c_ix_i}_{=1} = \beta_1 \]

只用到 \( E[\varepsilon_i]=0 \)—— 不需要獨立、不需要變異數齊一、不需要常態。

對截距：

\[ E[\hat\beta_0] = E[\bar Y] - \bar x E[\hat\beta_1] = (\beta_0+\beta_1\bar x) - \bar x\beta_1 = \beta_0 \]

3. 變異數

由獨立性與變異數齊一（模組 C 的公式）：

\[ \operatorname{Var}(\hat\beta_1) = \sum c_i^2\operatorname{Var}(Y_i) = \sigma^2\sum c_i^2 = \boxed{\frac{\sigma^2}{S_{xx}}} \]

這個結果對實驗設計極為重要。

\[ S_{xx} = \sum(x_i-\bar x)^2 \]

要把斜率估得準，就要讓 \( x \) 值分散開來。 所有 \( x \) 擠在一起（\( S_{xx} \) 小）時， 斜率的不確定性極大——就像用很短的槓桿去定一條直線的方向。

極端情況：若只在兩個 \( x \) 值上取點， 把一半的觀測放在最小值、一半放在最大值， \( S_{xx} \) 達到最大，斜率估得最準。 這正是模組 Q 的二水準因子設計為何只取兩個水準的理論根據。

代價是完全無法檢查線性假設—— 兩點必定連成直線。所以實務上會加中心點（模組 S）。

截距的變異數：由 \( \hat\beta_0 = \bar Y - \hat\beta_1\bar x \)，

\[ \operatorname{Var}(\hat\beta_0) = \operatorname{Var}(\bar Y) + \bar x^2\operatorname{Var}(\hat\beta_1) - 2\bar x\operatorname{Cov}(\bar Y,\hat\beta_1) \]

可以證明 \( \operatorname{Cov}(\bar Y, \hat\beta_1) = 0 \)：

\[ \operatorname{Cov}\left(\frac{1}{n}\sum Y_i,\ \sum c_jY_j\right) = \frac{\sigma^2}{n}\sum c_i = 0 \]

故

\[ \operatorname{Var}(\hat\beta_0) = \frac{\sigma^2}{n}+\bar x^2\frac{\sigma^2}{S_{xx}} = \sigma^2\left(\frac{1}{n}+\frac{\bar x^2}{S_{xx}}\right) \]

注意 \( \bar x \) 離 0 愈遠，截距估得愈不準—— 因為要把直線延伸很長一段才碰到 \( y \) 軸。

4. 分布

加上常態假設，\( \hat\beta_1 \) 是常態變數的線性組合，故

\[ \hat\beta_1 \sim N\!\left(\beta_1,\ \frac{\sigma^2}{S_{xx}}\right), \qquad \hat\beta_0\sim N\!\left(\beta_0,\ \sigma^2\left(\frac{1}{n}+\frac{\bar x^2}{S_{xx}}\right)\right) \]

5. 誤差變異數的估計

定義殘差平方和

\[ SSE = \sum_{i=1}^n (y_i-\hat y_i)^2 = \sum e_i^2 \]

定理：

\[ E[SSE] = (n-2)\sigma^2 \;\Longrightarrow\; \hat\sigma^2 = MSE = \frac{SSE}{n-2} \text{ 是 } \sigma^2 \text{ 的不偏估計} \]

推導：先做代數變形。

\[ e_i = y_i - \hat\beta_0 - \hat\beta_1x_i = y_i - (\bar y - \hat\beta_1\bar x) - \hat\beta_1 x_i = (y_i-\bar y) - \hat\beta_1(x_i-\bar x) \]

平方求和：

\[ SSE = \sum(y_i-\bar y)^2 - 2\hat\beta_1\sum(x_i-\bar x)(y_i-\bar y) + \hat\beta_1^2\sum(x_i-\bar x)^2 \] \[ = S_{yy} - 2\hat\beta_1 S_{xy} + \hat\beta_1^2 S_{xx} \]

代入 \( \hat\beta_1 = S_{xy}/S_{xx} \)，後兩項合併：

\[ -2\frac{S_{xy}^2}{S_{xx}} + \frac{S_{xy}^2}{S_{xx}} = -\frac{S_{xy}^2}{S_{xx}} = -\hat\beta_1 S_{xy} \] \[ \boxed{\;SSE = S_{yy} - \hat\beta_1 S_{xy}\;} \]

這是計算 \( SSE \) 最方便的公式。

取期望值。先算 \( E[S_{yy}] \)：由模組 E 的恆等式套用在 \( Y \) 上，

\[ E[S_{yy}] = E\left[\sum(Y_i-\bar Y)^2\right] = \sum\operatorname{Var}(Y_i) - n\operatorname{Var}(\bar Y) + \sum(E[Y_i]-\overline{E[Y]})^2 \]

其中前兩項給出 \( n\sigma^2 - \sigma^2 = (n-1)\sigma^2 \)， 第三項是「真值的離差平方和」\( = \beta_1^2 S_{xx} \)。故

\[ E[S_{yy}] = (n-1)\sigma^2 + \beta_1^2S_{xx} \]

再算 \( E[\hat\beta_1 S_{xy}] = E[\hat\beta_1^2 S_{xx}] = S_{xx}E[\hat\beta_1^2] \)：

\[ E[\hat\beta_1^2] = \operatorname{Var}(\hat\beta_1)+\big(E[\hat\beta_1]\big)^2 = \frac{\sigma^2}{S_{xx}}+\beta_1^2 \] \[ \Longrightarrow E[\hat\beta_1 S_{xy}] = \sigma^2 + \beta_1^2 S_{xx} \]

相減：

\[ E[SSE] = (n-1)\sigma^2 + \beta_1^2S_{xx} - \sigma^2 - \beta_1^2S_{xx} = (n-2)\sigma^2 \quad ✓ \]

為什麼是 \( n-2 \)？ 因為估計了兩個參數（\( \beta_0 \) 與 \( \beta_1 \)）， 殘差滿足兩條線性限制。

與模組 E 的規則完全一致：自由度 = 觀測數 − 估計的參數數。 單樣本時估一個平均，得 \( n-1 \)； 迴歸估兩個係數，得 \( n-2 \)。

6. 承接前例

續用溫度與強度的資料。先算 \( S_{yy} \)：

\[ S_{yy} = (-14.333)^2+(-7.333)^2+(-5.333)^2+(3.667)^2+(8.667)^2+(14.667)^2 \] \[ = 205.44+53.77+28.44+13.44+75.11+215.11 = 591.33 \] \[ SSE = 591.33 - 0.5771\times 1010 = 591.33 - 582.86 = 8.47 \] \[ MSE = \frac{8.47}{4} = 2.118, \qquad \hat\sigma = 1.455 \]

標準誤：

\[ SE(\hat\beta_1) = \sqrt{\frac{2.118}{1750}} = \sqrt{0.0012103} = 0.03479 \]

斜率估計 \( 0.5771 \pm \) 標準誤 \( 0.0348 \)—— 相對精度很高，因為溫度範圍夠寬（\( S_{xx} \) 大）。
