模組 F｜估計理論 · 第 23 課

點估計、不偏性與均方誤差分解

這一課的目標

  • 掌握不偏性、一致性的定義
  • 推導 MSE = 變異數 + 偏誤²
  • 理解偏誤與變異數的取捨

1. 什麼是估計量

估計量是一個只由樣本算出來的統計量 \( \hat{\theta} = T(X_1,\dots,X_n) \)， 用來猜測未知參數 \( \theta \)。

同一個參數可以有很多估計量。例如估計母體中心，可以用 樣本平均、樣本中位數、去頭尾平均、甚至「永遠回答 0」。 我們需要一套標準來比較它們。

2. 偏誤與不偏性

\[ \operatorname{Bias}(\hat\theta) = E[\hat\theta] - \theta \]

若 \( \operatorname{Bias} = 0 \)（對所有可能的 \( \theta \) 都成立）， 稱 \( \hat\theta \) 為不偏估計量。

估計量目標參數是否不偏
\( \bar{X} \)\( \mu \)是
\( S^2 \)（除以 \( n-1 \)）\( \sigma^2 \)是
\( \frac{1}{n}\sum(X_i-\bar X)^2 \)\( \sigma^2 \)否，低估
\( S \)（樣本標準差）\( \sigma \)否，低估

最後一列很多人不知道：\( S \) 不是 \( \sigma \) 的不偏估計。

因為 \( E[S^2]=\sigma^2 \) 但 \( E[S] \neq \sqrt{E[S^2]} \)—— 由詹森不等式，凹函數 \( \sqrt{\cdot} \) 使得 \( E[\sqrt{S^2}] < \sqrt{E[S^2]} \)。

不偏性在非線性變換下不會保持。 這是不偏性作為判準的一個結構性弱點。

3. 均方誤差

不偏只看平均位置，沒看散布。 一個「平均而言正確但每次都錯很多」的估計量並不好用。 更全面的判準是均方誤差：

\[ \operatorname{MSE}(\hat\theta) = E\big[(\hat\theta - \theta)^2\big] \]

4. 分解定理

\[ \boxed{\;\operatorname{MSE}(\hat\theta) = \operatorname{Var}(\hat\theta) + \big[\operatorname{Bias}(\hat\theta)\big]^2\;} \]

推導：令 \( b = E[\hat\theta] \)。在括號中插入 \( \pm b \)：

\[ E[(\hat\theta-\theta)^2] = E\big[((\hat\theta - b) + (b-\theta))^2\big] \] \[ = E[(\hat\theta-b)^2] + 2(b-\theta)E[\hat\theta - b] + (b-\theta)^2 \]

中間項為零，因為 \( E[\hat\theta - b] = E[\hat\theta] - b = 0 \) （\( b-\theta \) 是常數可提出）。剩下：

\[ = \operatorname{Var}(\hat\theta) + \operatorname{Bias}^2 \]

結構與模組 E 的平方和恆等式完全相同—— 都是「總誤差 = 隨機的部分 + 系統的部分」。 這個分解在整門課會出現很多次。

5. 偏誤與變異數的取捨

不偏不一定最好。 有時候接受一點偏誤，可以換到大幅降低的變異數， 總體 MSE 反而更小。

一個具體例子

設 \( X_i \sim N(\mu,\sigma^2) \)。考慮估計 \( \sigma^2 \) 的一族估計量：

\[ \hat\sigma^2_c = c\sum_{i=1}^{n}(X_i - \bar X)^2 \]

令 \( Q = \sum(X_i-\bar X)^2 \)。由模組 E，\( Q/\sigma^2 \sim \chi^2(n-1) \)，故

\[ E[Q] = (n-1)\sigma^2, \qquad \operatorname{Var}(Q) = 2(n-1)\sigma^4 \]

因此

\[ \operatorname{MSE}(\hat\sigma_c^2) = c^2\cdot 2(n-1)\sigma^4 + \big[c(n-1)\sigma^2 - \sigma^2\big]^2 = \sigma^4\Big[2(n-1)c^2 + \big(c(n-1)-1\big)^2\Big] \]

對 \( c \) 微分求極小：

\[ \frac{d}{dc} = \sigma^4\Big[4(n-1)c + 2(n-1)\big(c(n-1)-1\big)\Big] = 0 \] \[ 2c + c(n-1) - 1 = 0 \;\Longrightarrow\; c = \frac{1}{n+1} \]
選擇\( c \)性質
不偏估計 \( S^2 \)\( 1/(n-1) \)偏誤為 0
最大概似估計\( 1/n \)略微低估
最小 MSE\( 1/(n+1) \)低估更多，但總誤差最小

三者都合理，判準不同答案就不同。 實務上仍以 \( S^2 \) 為標準， 因為不偏性讓它在變異數分析中可以直接相加（模組 N）， 而且差異隨 \( n \) 增大迅速消失。

6. 一致性

\( \hat\theta_n \) 稱為一致的，若對任何 \( \varepsilon>0 \)：

\[ P\big(|\hat\theta_n - \theta| > \varepsilon\big) \longrightarrow 0 \quad \text{當 } n\to\infty \]

一個實用的充分條件：若 \( \operatorname{MSE}(\hat\theta_n)\to 0 \)， 則 \( \hat\theta_n \) 一致。

證明用 Chebyshev 不等式：

\[ P(|\hat\theta_n - \theta| > \varepsilon) \leq \frac{E[(\hat\theta_n-\theta)^2]}{\varepsilon^2} = \frac{\operatorname{MSE}}{\varepsilon^2} \longrightarrow 0 \]

例如 \( \bar{X} \)：\( \operatorname{MSE} = \operatorname{Var} = \sigma^2/n \to 0 \)，所以一致。 這其實就是大數法則。

不偏與一致是兩件不同的事：

  • 不偏但不一致：\( \hat\mu = X_1 \)（只用第一個觀測值）。平均是對的，但永遠不會變準。
  • 有偏但一致：\( \frac{1}{n}\sum(X_i-\bar X)^2 \)。有偏誤，但偏誤與變異數都趨於 0。

一致性是更基本的要求—— 一個連「資料愈多愈準」都做不到的估計量沒有價值。

7. 有效性

在所有不偏估計量中，變異數最小的稱為 最小變異不偏估計量。 「變異數能小到什麼程度」有一個理論下界， 這就是本模組第 4 課要推導的 Cramér–Rao 不等式。
