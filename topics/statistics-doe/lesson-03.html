模組 A｜序幕：為什麼需要統計學 · 第 3 課

課程地圖：從抽樣分布到實驗設計

這一課的目標

  • 掌握全課程的邏輯順序
  • 理解為什麼 DOE 需要前面所有的鋪陳
  • 知道自己需要哪些前置知識

1. 一條主線

很多人把統計學、假設檢定、實驗設計當成三門課。 它們其實是同一條推導鏈的三段。

機率 → 隨機變數的分布 → 統計量的分布 → 用分布做判斷（檢定） → 用線性模型描述多個因子 → 反過來設計資料的產生方式（實驗設計）

關鍵的轉折在最後一步。前面所有內容都是 「給定資料，能推論出什麼」； 實驗設計問的是相反的問題： 「我想推論出某件事，資料該怎麼產生」。

這就是為什麼 DOE 必須放在最後。 你要先知道 F 檢定的變異數怎麼算， 才會明白為什麼因子設計比「一次改一個因子」有效率。

2. 五個部分

部分模組回答什麼問題
一、機率與分布A 至 D隨機變數的行為可以怎麼描述
二、抽樣分布與估計E 至 F統計量本身的分布是什麼
三、假設檢定G 至 K怎麼用分布做出可檢驗的判斷
四、線性模型L 至 N多個因子同時作用時怎麼分析
五、實驗設計O 至 T資料該怎麼產生才問得出因果

3. 三個關鍵節點

八十多課裡有三課是承重牆，其他內容都掛在上面：

節點在哪裡為什麼關鍵
三大抽樣分布的推導模組 Et、卡方、F 三個分布是後面所有檢定的工具，不推導就只能背公式
奈曼—皮爾森引理模組 H它說明了為什麼檢定要長成那個樣子，而不是別的樣子
平方和的正交分解模組 L 至 N迴歸、變異數分析、因子設計三者的共同骨架

如果時間有限，這三處請務必自己動筆推一次。 其餘內容都可以在需要時回頭查， 但這三處不推過，後面會變成純粹的公式記憶。

4. 前置知識

需要什麼用在哪裡
微分最大概似估計、最小平方法求極值
積分與重積分連續分布的期望值、機率密度的推導
變數變換與 Jacobiant 分布與 F 分布密度的推導
矩陣乘法與反矩陣多元迴歸的矩陣形式
特徵值與特徵向量反應曲面法的標準點分析

如果對複數與轉換不熟，本站的 複數到底在做什麼 與 拉普拉斯轉換 可以先看。 後者尤其相關——動差生成函數其實就是機率密度的拉普拉斯轉換， 模組 C 會說明這件事。

5. 這門課不做什麼

  • 不使用測度論。所有機率都以初等的方式定義，該說明的極限與收斂會用文字交代清楚。
  • 不教軟體操作。所有例子都用手可以算完的數字，讓你看到每一步。
  • 不涵蓋時間序列、存活分析、多變量分析等專門領域。
  • 貝氏統計只在兩處點到（貝氏定理與貝氏因子），不獨立成模組。

模組 A 重點回顧

  • 統計學的核心問題是分辨系統性差異與隨機變異
  • 參數是固定的未知常數，統計量是有分布的隨機變數
  • 偏誤的樣本再大也救不回來，增加 n 只縮小隨機誤差
  • 三個承重牆是抽樣分布、奈曼—皮爾森引理、平方和分解

檢查你的理解

  1. 說出五個部分各自回答什麼問題
  2. 解釋為什麼實驗設計必須放在最後
  3. 指出三個必須自己推導一次的關鍵節點
