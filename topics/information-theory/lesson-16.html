通道容量與通道編碼定理

這一課的目標

  • 定義通道容量
  • 計算二元對稱通道的容量
  • 理解通道編碼定理

通道容量

一個通道每次使用，最多能傳多少資訊？調整輸入的分布 \(P(x)\)，讓互資訊最大：

\[C = \max_{P(x)}I(X; Y)\]

二元對稱通道

翻轉機率 \(p\)。不管送什麼，收到時的不確定性都是 \(H(Y|X) = H_2(p)\)（第 3 課的二元熵）。輸入均勻時 \(H(Y) = 1\) 最大，所以

\[C = 1 - H_2(p)\]

\(p = 0\)：\(C = 1\)，完美。\(p = 0.5\)：\(C = 0\)，收到的完全是隨機的。\(p = 0.11\)：\(C \approx 0.5\)。

通道編碼定理

通道編碼定理（夏農，1948）

只要傳送的速率 \(R < C\)，就存在一種編碼，讓錯誤率任意接近零。如果 \(R > C\)，錯誤率就不可能任意小。

這推翻了「可靠與速度不能兼得」的直覺。翻轉機率 11% 的通道，用適當的編碼，可以用一半的速度幾乎完全沒有錯誤地傳送——而不是像重複碼那樣，速度要趨近零。

怎麼證明：隨機編碼

夏農的證明極為巧妙：他沒有構造任何具體的編碼，而是證明「隨機選一個很長的編碼，平均來說就很好」。直覺：把很長的一段訊息（\(n\) 位元）編成很長的碼字。雜訊會把碼字「推」到附近的一團區域（大約 \(2^{nH_2(p)}\) 個可能的結果）。只要碼字的數量 \(2^{nR}\) 不多到讓這些團彼此重疊，就能分辨。全部的空間有 \(2^n\) 個點，所以最多能放 \(2^{n(1 - H_2(p))}\) 個碼字——\(R < 1 - H_2(p) = C\)。

證明告訴我們好的編碼存在，卻沒說怎麼找。接下來半個世紀，工程師一直在追趕這個極限（模組 D）。

🧭 這一課的重點

通道容量 C 是調整輸入分布時互資訊的最大值；二元對稱通道 C=1−H₂(p)，p=0.11 時約 0.5；通道編碼定理說速率低於 C 就存在使錯誤率任意接近零的編碼，高於 C 則不可能，推翻了可靠與速度不能兼得；夏農以隨機編碼證明，碼字被雜訊推成約 2^{nH₂(p)} 的一團，不重疊時最多放 2^{n(1−H₂(p))} 個碼字，但證明沒說怎麼找。
