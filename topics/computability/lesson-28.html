停機問題

給定任意一個程式 P 和一個輸入 x，判斷 P 在輸入 x 時，最後會停下來，還是會永遠執行下去。

這個問題非常實際。如果能解決它，我們就能自動偵測所有的無窮迴圈 bug，編譯器可以在程式執行前就警告「這段程式碼永遠不會結束」。

有些程式很容易判斷：

while (true) { } // 顯然永遠不停 for i in 1..10: print(i) // 顯然會停

但有些程式極其困難：

n = 輸入 while n != 1: if n 是偶數: n = n / 2 else: n = 3n + 1

這段程式對每一個輸入都會停嗎？這就是考拉茲猜想（第 39 課），至今沒有人能證明。還有更多這樣的程式，它們會不會停，等價於數學上的未解難題。

一個自然的想法是：「直接執行它，看它會不會停。」問題是，如果它跑了一億步還沒停，你無法知道它是「快要停了」還是「永遠不會停」。等待無法給出「不會停」的答案。

圖靈證明了：不存在一個萬能的程式能對所有 (P, x) 正確回答這個問題。下一課，我們一步步看這個證明。

🧭 這一課的重點

停機問題問任意程式 P 在輸入 x 時會停還是永遠執行；解決它就能自動偵測無窮迴圈；有些程式容易判斷，有些如考拉茲程式等價於未解數學難題；直接執行無法給出不會停的答案，圖靈證明不存在萬能的判斷程式。

🧮 互動模擬為教學用的簡化版本；圖靈機、λ 演算等模擬器都設有步數上限，以免瀏覽器卡住——這個「上限」本身就呼應了停機問題：我們無法事先知道一個程式會不會停。
