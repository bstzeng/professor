連續 token 與離散 token

這一課的目標

  • 推導 VQ-VAE 的三項損失
  • 理解直通估計（straight-through）
  • 計算離散 token 的資訊量

把圖片變成 token 有兩條路：連續（patch 投影成實數向量，前幾課的做法）與離散（每個位置變成 codebook 裡的一個編號，像文字一樣）。離散 token 讓 LLM 可以用「預測下一個 token」的方式生成圖片和聲音。

VQ-VAE

編碼器輸出 \(z_e(x)\)；codebook \(\{e_k\}_{k=1}^{K}\)。量化取最近的碼字：

\[k^{*} = \arg\min_{k} \lVert z_e(x) - e_k \rVert_2, \qquad z_q(x) = e_{k^{*}}\]

解碼器用 \(z_q\) 重建 \(\hat x\)。損失有三項（\(\operatorname{sg}\) 表示 stop-gradient，前向照常計算、反向不傳梯度）：

\[\mathcal{L} = \underbrace{\lVert x - \hat x \rVert^2}_{\text{重建}} + \underbrace{\lVert \operatorname{sg}[z_e] - e_{k^*} \rVert^2}_{\text{codebook：碼字靠向編碼}} + \beta\,\underbrace{\lVert z_e - \operatorname{sg}[e_{k^*}] \rVert^2}_{\text{commitment：編碼靠向碼字}}\]

直通估計

\(\arg\min\) 不可微，梯度無法從 \(z_q\) 傳回編碼器。直通估計的做法是在前向時用 \(z_q\)，反向時假裝 \(\partial z_q / \partial z_e = I\)：

\[z_q^{\text{ST}} = z_e + \operatorname{sg}[z_q - z_e] \;\;\Rightarrow\;\; \text{前向值} = z_q,\quad \frac{\partial z_q^{\text{ST}}}{\partial z_e} = I\]

於是重建損失的梯度 \(\partial \mathcal{L}/\partial z_q\) 直接複製給 \(z_e\)。第二項負責更新碼字（實務上也常用指數移動平均），第三項（\(\beta\) 常取 0.25）防止編碼器輸出漂得離碼字太遠。

一個離散 token 有多少資訊？

codebook 大小 \(K\) 時，每個 token 最多 \(\log_2 K\) 位元。例如 Chameleon 的圖片分詞器把 512×512 的圖編成 1,024 個 token、codebook 8,192（13 位元），整張圖最多 \(1024 \times 13 \approx 13{,}300\) 位元——約 1.7 KB。這解釋了離散 token 為什麼常常「丟細節」：資訊量被硬性限制住了。

聲音常用殘差向量量化（RVQ）：第一層量化後的殘差 \(r_1 = z - z_q^{(1)}\) 再交給第二層量化，依此類推，\(Q\) 層就有 \(Q\log_2 K\) 位元（第 19 課）。

🧭 這一課的重點

離散 token 讓 LLM 能用預測下一個 token 的方式生成圖片和聲音。VQ-VAE 取最近碼字 z_q = e_{k*}，損失 = 重建 + ‖sg[z_e] − e‖²（更新碼字）+ β‖z_e − sg[e]‖²（commitment）。argmin 不可微，用直通估計 z_e + sg[z_q − z_e]，前向值為 z_q、反向梯度直接傳給 z_e。每個 token 最多 log₂K 位元，例如 1,024 個 token × 13 位元約 1.7 KB，所以離散 token 會丟細節；聲音常用殘差向量量化 RVQ。
