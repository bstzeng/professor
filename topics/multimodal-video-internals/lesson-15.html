第一階段：對齊預訓練

這一課的目標

  • 理解凍結與梯度流動
  • 推導只有投影層收到梯度
  • 知道對齊階段的資料與規模

LLaVA 式訓練的第一階段，凍結視覺編碼器 \(f_\phi\) 與 LLM \(p_\theta\)，只訓練投影層 \(g_\psi\)。資料是簡單的圖片說明（LLaVA-1.5 用約 55.8 萬筆）。

推導：梯度只流到投影層

令 \(H_v = g_\psi(f_\phi(x_v))\)。損失 \(\mathcal{L}(\theta, \psi)\) 對 \(\psi\) 的梯度由鏈鎖律為

\[\frac{\partial \mathcal{L}}{\partial \psi} = \frac{\partial \mathcal{L}}{\partial H_v}\cdot\frac{\partial H_v}{\partial \psi}, \qquad \frac{\partial \mathcal{L}}{\partial H_v} = \sum_{i} m_i \frac{\partial\left[-\log p_\theta(x_i\mid H_v, x_{

第二個因子要穿過整個 LLM 做反向傳播（所以仍需要 LLM 的啟動值），但因為 \(\theta, \phi\) 被凍結，只有 \(\psi\) 會被更新。直覺上，這一階段是在學一本「視覺特徵 → LLM 詞嵌入空間」的翻譯字典，讓 LLM 讀得懂視覺 token。

為什麼要先對齊

如果一開始就同時更新 LLM，隨機初始化的投影層會送進一堆「看不懂的向量」，LLM 為了降低損失可能學會忽略視覺 token，甚至破壞原本的語言能力。先把投影層對齊，第二階段再解凍 LLM，訓練更穩定。

參數量的直覺：兩層 MLP 投影（1024 → 4096 → 4096）約 2,100 萬個參數，只占 7B 模型的 0.3%，所以第一階段很便宜。

🧭 這一課的重點

第一階段凍結視覺編碼器與 LLM，只訓練投影層，資料是簡單圖片說明（LLaVA-1.5 約 55.8 萬筆）。由鏈鎖律 ∂L/∂ψ = (∂L/∂H_v)(∂H_v/∂ψ)，梯度要穿過 LLM 反傳但只有 ψ 被更新，等於學一本視覺特徵到詞嵌入空間的翻譯字典。先對齊能避免 LLM 學會忽略視覺 token 或破壞語言能力；兩層 MLP 投影約 2,100 萬參數，只占 7B 的 0.3%。
