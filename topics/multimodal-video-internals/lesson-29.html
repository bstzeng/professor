模組 E｜影片生成的核心 · 第 29 課

文字怎麼注入

這一課的目標

  • 比較三種文字條件化方式
  • 從貝氏公式推導 classifier-free guidance
  • 證明 CFG 在速度場上同樣成立

文字編碼器

影片模型需要把提示詞變成一串向量。常見的選擇：T5 系列的編碼器（例如 T5-XXL、Wan 使用多語言的 umT5）、CLIP 的文字編碼器，或直接用多模態 LLM 當編碼器——HunyuanVideo 用 decoder-only 的 MLLM，並因為它是單向（因果）注意力，額外加一個雙向的 token refiner 改善特徵。

三種注入方式

方式做法成本
交叉注意力影片 token 當 Q，文字 token 當 K、V\(O(N M d)\)
MMDiT／聯合注意力文字與影片 token 串接，用各自的權重投影後做一次自注意力\(O((N+M)^2 d)\)
雙串流 → 單串流前幾層各自處理（雙串流），後幾層串接共用權重（單串流）介於兩者之間

MMDiT（SD3 提出）讓文字也能「看到」影像並被更新，圖文互動更充分；HunyuanVideo 採用「雙串流到單串流」的混合設計。

推導：classifier-free guidance

希望樣本更符合條件 \(c\)，可以從「加強版」的分布取樣 \(\tilde p(x\mid c) \propto p(x)\,p(c\mid x)^{w}\)。取對數梯度（分數）並用貝氏公式 \(\log p(c\mid x) = \log p(x\mid c) - \log p(x) + \text{const}\)：

\[\nabla_x \log \tilde p(x\mid c) = \nabla_x\log p(x) + w\big(\nabla_x \log p(x\mid c) - \nabla_x \log p(x)\big)\]

不需要另外訓練分類器：同一個模型訓練時以一定機率（例如 10%）把提示詞換成空字串，就同時學會了有條件與無條件兩種預測。由 \(\epsilon_\theta = -\sigma_t \nabla\log p_t\)，在噪音預測上就是

\[\tilde\epsilon = \epsilon_\theta(x, \varnothing) + w\big(\epsilon_\theta(x, c) - \epsilon_\theta(x, \varnothing)\big)\]

在速度場上也成立

用第 25 課的慣例（\(x_t = t x_1 + (1-t)x_0\)，\(x_0\) 是噪音）。Tweedie 公式給出 \(\mathbb{E}[x_0\mid x_t] = -(1-t)\,\nabla\log p_t(x_t)\)，再由 \(\mathbb{E}[x_1\mid x_t] = \big(x_t - (1-t)\mathbb{E}[x_0\mid x_t]\big)/t\)：

\[v(x,t) = \mathbb{E}[x_1 - x_0\mid x_t = x] = \frac{x - \mathbb{E}[x_0\mid x]}{t} = \frac{x + (1-t)\,\nabla_x\log p_t(x)}{t}\]

\(v\) 是分數的仿射函數，係數只依賴 \(t\)。所以對分數做的線性組合可以直接搬到速度上：\(\tilde v = v_\theta(x,\varnothing) + w\big(v_\theta(x,c) - v_\theta(x,\varnothing)\big)\)。代價是每一步要算兩次（有條件與無條件），推論成本加倍（第 37 課）。

🧭 這一課的重點

文字編碼器可用 T5（Wan 用 umT5）、CLIP 或 MLLM（HunyuanVideo 加雙向 refiner）。注入方式：交叉注意力 O(NMd)、MMDiT 聯合注意力 O((N+M)²d)、雙串流到單串流混合。CFG 從 p(x)p(c|x)^w 出發，以貝氏公式得分數 ∇log p(x) + w(∇log p(x|c) − ∇log p(x))，訓練時隨機丟掉提示詞即可同時學兩種預測。Tweedie 公式給出 v = (x + (1−t)∇log p_t)/t，速度是分數的仿射函數，所以 CFG 可直接用在速度上，代價是每步算兩次。
