投影層路線：LLaVA

這一課的目標

  • 拆解 LLaVA 的資料流
  • 推導只對回答計算損失的訓練目標
  • 計算 LLaVA 的視覺 token 數

LLaVA 的資料流：圖片 \(x_v\) → 凍結的 CLIP ViT-L/14 → 倒數第二層的 patch 特徵 \(Z_v \in \mathbb{R}^{N_v \times d_v}\) → 投影 \(H_v = g(Z_v) \in \mathbb{R}^{N_v \times d}\) → 接在文字嵌入前面送進 LLM。

LLaVA-1 的 \(g\) 是一個線性層 \(H_v = Z_v W\)；LLaVA-1.5 改成兩層 MLP（中間 GELU），效果明顯更好。輸入 336×336、patch 14，所以 \(N_v = (336/14)^2 = 24^2 = 576\)。
