自注意力與交叉注意力

這一課的目標

  • 完整推導縮放點積注意力
  • 推導為什麼要除以 √d
  • 區分自注意力與交叉注意力

定義

給定查詢 \(Q \in \mathbb{R}^{N \times d_k}\)、鍵 \(K \in \mathbb{R}^{M \times d_k}\)、值 \(V \in \mathbb{R}^{M \times d_v}\)：

\[\operatorname{Attn}(Q,K,V) = \operatorname{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right) V, \qquad \operatorname{softmax}(z)_j = \frac{e^{z_j}}{\sum_{l} e^{z_l}}\]

第 \(i\) 個輸出是 \(V\) 各列的加權平均，權重 \(a_{ij} = \operatorname{softmax}_j(q_i \cdot k_j / \sqrt{d_k})\)，且 \(\sum_j a_{ij} = 1\)。

推導：為什麼除以 √d

假設 \(q, k\) 的各分量獨立、平均 0、變異數 1。內積 \(s = \sum_{i=1}^{d_k} q_i k_i\) 的平均是 0，變異數為

\[\operatorname{Var}(s) = \sum_{i=1}^{d_k} \operatorname{Var}(q_i k_i) = \sum_{i=1}^{d_k} \mathbb{E}[q_i^2]\,\mathbb{E}[k_i^2] = d_k\]

（第一個等號用到各項獨立；第二個等號因為 \(\mathbb{E}[q_i k_i]=0\)，所以 \(\operatorname{Var}(q_ik_i)=\mathbb{E}[q_i^2k_i^2]=\mathbb{E}[q_i^2]\mathbb{E}[k_i^2]\)。）當 \(d_k = 128\)，內積的標準差約 11，softmax 會變得極端尖銳、梯度接近 0。除以 \(\sqrt{d_k}\) 後變異數回到 1。

自注意力 vs. 交叉注意力

Q 來自K、V 來自成本
自注意力序列 X同一個序列 X\(O(N^2 d)\)
交叉注意力序列 X（例如文字）另一個序列 Y（例如圖片特徵）\(O(NMd)\)

多模態模型兩種都用：LLaVA 把圖片 token 接進文字序列做自注意力；Flamingo 讓文字用交叉注意力去「查詢」圖片；影片生成模型常用交叉注意力把文字提示注入（第 29 課）。

def attention(Q, K, V, mask=None): s = Q @ K.T / sqrt(Q.shape[-1]) # (N, M) 相似度 if mask is not None: s = s.masked_fill(~mask, -inf) # 因果遮罩：看不到未來 a = softmax(s, dim=-1) # 每一列加總為 1 return a @ V # (N, d_v)

🧭 這一課的重點

縮放點積注意力 softmax(QK^T/√d_k)V：輸出是 V 的加權平均。若 q、k 分量獨立、平均 0、變異數 1，內積變異數為 d_k，所以要除以 √d_k 讓變異數回到 1，避免 softmax 過度尖銳。自注意力的 Q、K、V 來自同一序列，成本 O(N²d)；交叉注意力的 K、V 來自另一序列，成本 O(NMd)。
