即時語音對話

這一課的目標

  • 比較串接式與端到端語音對話
  • 推導延遲預算
  • 理解全雙工的雙串流設計

串接式管線的延遲

傳統語音助理是「語音辨識 → LLM → 語音合成」三段串接。使用者說完到聽見回應的延遲是

\[T = T_{\text{VAD}} + T_{\text{ASR}} + T_{\text{LLM, 首 token}} + T_{\text{TTS, 首段音訊}} + T_{\text{網路}}\]

例如：判斷說完需要 300 毫秒靜音 ＋ 辨識 150 ＋ LLM 首 token 300 ＋ TTS 首段 150 ＋ 網路 100 ≈ 1 秒。而人類對話中換人說話的間隔大約只有 200 毫秒，所以串接式系統總讓人覺得「慢半拍」，而且聽不到語氣、無法被打斷。

端到端與全雙工

Kyutai 在 2024 年發表的 Moshi 是開放的全雙工模型代表：它同時建模兩條音訊串流（使用者與模型自己），每一步都在「聽」也可以「說」，不需要判斷對方是否說完。它的 codec 是 12.5 Hz（每幀 80 毫秒），聲學 token 再延遲一幀，理論延遲

\[80\ \text{ms（一幀）} + 80\ \text{ms（聲學延遲）} = 160\ \text{ms}\]

實測約 200 毫秒，接近人類。Moshi 還會在輸出聲音的同時預測對應的文字 token（「內心獨白」），用文字的語言能力來穩定語音內容。

雙串流的序列

每個時間步 \(s\) 的輸入包含：模型自己的文字 token、模型的 \(Q\) 個聲學 token、使用者的 \(Q\) 個聲學 token。模型預測下一步自己的文字與聲學 token，使用者的串流則只當條件。這讓「插話」「附和（嗯嗯）」「被打斷就停下」都變成模型自然學到的行為。

🧭 這一課的重點

串接式語音助理延遲 = VAD + ASR + LLM 首 token + TTS 首段 + 網路，常達約 1 秒，而人類換人說話間隔約 200 毫秒，且串接式聽不到語氣、無法被打斷。Moshi（2024）全雙工同時建模使用者與模型兩條音訊串流，codec 12.5 Hz，理論延遲 80+80 = 160 毫秒、實測約 200 毫秒，並同時預測文字內心獨白來穩定內容；插話、附和、被打斷就停都成為自然學到的行為。
