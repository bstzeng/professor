輸出也能多模態

這一課的目標

  • 比較 LLM 生成圖片的兩種方式
  • 推導自回歸＋擴散的聯合損失
  • 理解語音輸出的 codec token

能「看」圖之後，下一步是「畫」圖和「說」話。輸出端有兩大類做法：

一、離散 token ＋ 解碼器

LLM 輸出圖片或音訊的離散 token，再交給 VQ 解碼器或音訊 codec 解碼器還原。優點是只要一個交叉熵損失；缺點是第 5 課說的資訊上限，以及要逐 token 生成（一張圖上千步）。

二、LLM ＋ 擴散

讓同一個 Transformer 對文字做自回歸、對圖片的連續潛向量做擴散（例如 Transfusion 一類的做法）。總損失是兩者加權：

其中 \(\mathcal{L}_{\text{diff}}\) 是 flow matching 損失（第 25 課完整推導）。注意力遮罩是混合的：文字部分用因果遮罩，同一張圖內部的 patch 彼此雙向可見。另一種較鬆的耦合是讓 LLM 輸出一組「條件向量」，交給獨立的擴散模型畫圖。

語音輸出

語音通常用多層 RVQ 的 codec token（第 19 課）。每個時間步有 \(Q\) 層 codebook，若全部攤平成一列，序列會變長 \(Q\) 倍。常見的「延遲模式」讓第 \(q\) 層比第 1 層晚 \(q-1\) 步輸出，於是每一步並行預測 \(Q\) 個 token，同時保留層與層之間的依賴。

NAVER 的 HyperCLOVA X 8B Omni（2026）是開放模型中的一個例子：單一的 decoder-only Transformer 處理交錯的文字、聲音、視覺序列，輸入由編碼器提供連續嵌入，輸出則交給各模態專屬的解碼器。

🧭 這一課的重點

多模態輸出兩大類：離散 token＋解碼器（一個交叉熵損失，但有資訊上限且需逐 token 生成）、LLM＋擴散（如 Transfusion 類做法，L = L_LM + λL_diff，文字用因果遮罩、同一張圖內 patch 雙向可見）。語音用多層 RVQ codec token，延遲模式讓第 q 層晚 q−1 步，每步並行預測 Q 個 token。HyperCLOVA X 8B Omni 是 2026 年開放的 any-to-any 例子。
