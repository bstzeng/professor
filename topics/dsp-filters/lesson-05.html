離散訊號與系統

這一課的目標

  • 認識基本的離散訊號
  • 理解線性與非時變
  • 理解因果與穩定

數列

離散訊號寫成 x[n]，n 是整數的樣本編號。幾個基本的訊號：

  • 單位脈衝 δ[n]：只有 n = 0 時是 1，其他都是 0。
  • 單位步階 u[n]：n ≥ 0 時是 1。
  • 正弦：x[n] = cos(ω n)，ω 是數位頻率（弧度／樣本），ω = 2π f / fs。ω = π 對應奈奎斯特頻率。
  • 複指數：x[n] = ejωn，是分析頻率響應的關鍵（見〈複數〉）。

注意：數位頻率 ω 和 ω + 2π 是同一個訊號——這正是混疊在數學上的樣子（第 3 課）。所以只需要看 0 到 π 的範圍。

系統

系統把輸入數列 x[n] 變成輸出數列 y[n]。我們最關心的是同時具備兩個性質的系統：

  • 線性：輸入相加，輸出也相加；輸入放大兩倍，輸出也放大兩倍（疊加原理）。
  • 非時變：輸入延遲幾個樣本，輸出也只是延遲同樣的樣本，系統的行為不隨時間改變。

同時線性且非時變的系統叫做 LTI 系統。它的威力在於：只要知道它對單位脈衝的反應（第 8 課），就知道它對任何輸入的反應（第 7 課）。

因果與穩定

  • 因果：輸出只取決於現在與過去的輸入，不能偷看未來。即時處理一定要因果；處理錄好的檔案則可以用非因果的濾波器（例如零相位濾波，第 14 課）。
  • 穩定（BIBO）：有界的輸入一定產生有界的輸出。不穩定的濾波器輸出會越來越大，直到溢位（第 11 課）。

🧭 這一課的重點

離散訊號 x[n] 以整數樣本編號，基本訊號有單位脈衝 δ[n]、單位步階 u[n]、正弦 cos(ωn) 其中數位頻率 ω = 2πf/fs 而 π 對應奈奎斯特、複指數 e^jωn；ω 與 ω+2π 是同一訊號即混疊，只需看 0 到 π；線性為疊加原理、非時變為延遲輸入只延遲輸出，兩者兼具為 LTI 系統，知道脈衝響應即知任何輸入的反應；因果系統不看未來，即時處理須因果、錄好的檔案可零相位；BIBO 穩定為有界輸入產生有界輸出。
