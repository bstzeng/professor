卷積

這一課的目標

  • 理解卷積的運算
  • 理解卷積與 LTI 系統的關係
  • 了解卷積的計算量

卷積

LTI 系統的輸出，等於輸入與脈衝響應 h[n] 的卷積：

\[y[n] = \sum_{k} h[k]\, x[n-k] = (h * x)[n]\]

為什麼

任何輸入都可以拆成一連串「放大、延遲過的脈衝」：x[n] = x[0]δ[n] + x[1]δ[n−1] + …。系統對每一個脈衝的反應都是一個放大、延遲過的 h[n]（線性加非時變，第 5 課），把它們全部加起來，就是卷積。

手算的方法

  1. 把 h 翻轉。
  2. 對準位置 n。
  3. 對應的元素相乘。
  4. 全部相加，得到 y[n]。
  5. 滑動到下一個位置，重複。

例：x = [1, 2, 3]，h = [1, 1]（兩點相加）→ y = [1, 3, 5, 3]。輸出的長度是 3 + 2 − 1 = 4。

卷積無所不在

  • FIR 濾波：就是輸入和係數的卷積。
  • 殘響效果：錄下音樂廳的「脈衝響應」（拍一下手或放一個爆破音），把乾淨的錄音和它卷積，聽起來就像在那個音樂廳裡演奏（見〈聲學〉、〈音樂製作〉）。
  • 影像模糊與銳化：二維的卷積（第 24 課）。
  • 卷積神經網路：學習出卷積核來辨識影像特徵（見〈深度學習〉）。
  • 機率：兩個獨立隨機變數的和，它的分布是兩個分布的卷積（見〈機率〉）。

計算量

長度 N 的訊號與長度 M 的濾波器卷積，需要約 N × M 次乘法。當濾波器很長（例如殘響的脈衝響應有數萬點）時，直接計算太慢，改用 FFT 在頻域相乘（卷積定理：時域卷積 = 頻域相乘）會快得多（第 18 課）。

🧭 這一課的重點

LTI 系統輸出等於輸入與脈衝響應的卷積 y[n] = Σ h[k] x[n−k]；因任何輸入可拆成放大延遲的脈衝，各產生放大延遲的 h 再相加；手算為翻轉、對準、相乘、相加、滑動，x=[1,2,3] h=[1,1] 得 [1,3,5,3] 長度 N+M−1；應用有 FIR 濾波、以音樂廳脈衝響應卷積的殘響效果、影像模糊銳化、卷積神經網路、獨立隨機變數之和的分布；N×M 次乘法，濾波器很長時用 FFT 頻域相乘（卷積定理）更快。
