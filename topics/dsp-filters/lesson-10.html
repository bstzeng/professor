轉移函數與頻率響應

這一課的目標

  • 學會從差分方程求轉移函數
  • 理解頻率響應的意義
  • 區分振幅響應與相位響應

轉移函數

對差分方程兩邊取 z 轉換（第 9 課），整理成輸出與輸入之比，就得到轉移函數：

\[H(z) = \frac{Y(z)}{X(z)} = \frac{b_0 + b_1 z^{-1} + \cdots + b_M z^{-M}}{1 + a_1 z^{-1} + \cdots + a_N z^{-N}}\]

例：指數平均 y[n] = α x[n] + (1−α) y[n−1] 的轉移函數是 H(z) = α / (1 − (1−α) z−1)。

頻率響應

把 z 代入單位圓上的點 z = ejω，就得到頻率響應 H(ejω)：它告訴我們頻率 ω 的正弦波通過濾波器後會怎樣。因為 LTI 系統有一個重要的性質：正弦波輸入，輸出還是同頻率的正弦波，只是大小與相位改變了。

  • 振幅響應 |H(ejω)|：放大或衰減多少，常用分貝（dB）表示：−3 dB 約是功率減半，−20 dB 是振幅剩十分之一。
  • 相位響應 ∠H(ejω)：延遲多少。不同頻率的延遲不同，波形就會變形（第 14 課）。

濾波器的類型

類型讓什麼通過用途
低通低頻去除高頻雜訊、抗混疊、平滑
高通高頻去除直流偏移與低頻漂移
帶通某一段頻率選出特定的訊號（收音機選台）
帶阻（陷波）除了某一段之外去除 60 Hz 電源干擾（第 22 課）
全通所有頻率都通過只改變相位，用來修正相位

規格

設計濾波器時要訂出規格：通帶的範圍與允許的漣波、阻帶的範圍與需要的衰減、中間的過渡帶有多寬。過渡帶越窄、衰減越大，需要的濾波器階數（計算量）就越高。

🧭 這一課的重點

對差分方程取 z 轉換得轉移函數 H(z) = Y/X = b 多項式 ÷ (1 + a 多項式)，指數平均為 α/(1−(1−α)z^−1)；代入 z = e^jω 得頻率響應，LTI 系統正弦輸入輸出同頻只改大小與相位；振幅響應常以 dB 表示，−3 dB 約功率減半、−20 dB 振幅剩十分之一，相位響應不同頻率延遲不同使波形變形；濾波器類型有低通、高通、帶通、帶阻陷波、全通；規格包括通帶漣波、阻帶衰減、過渡帶寬，越嚴格階數越高。
