DICOM：X 光、CT 影像怎麼連病歷一起存

這一課的目標

  • 理解 DICOM 把影像與病歷合存
  • 知道醫學影像為何精度較高
  • 連結去識別化的隱私議題

醫院的影像不用一般的 JPG，而是 DICOM 格式。它的特別之處是：影像和完整的檢查資訊放在同一個檔案裡。

1. 影像＋病歷

一個 DICOM 檔除了影像，還帶著病人姓名、生日、病歷號、檢查日期、部位、儀器參數，以及最關鍵的切片位置。這樣影像永遠不會和病人資訊脫節。

2. 為什麼精度更高

一般照片每色 8 位元（256 階），但醫學影像常用 16 位元灰階（上萬階）。因為醫師需要在極細微的灰階差異裡分辨組織（例如 CT 上分辨不同軟組織），精度不夠會漏掉病灶。這也呼應了第 57 課的高動態範圍概念。

3. 疊成 3D

一次 CT 或 MRI 掃描會產生上百張切片，每張是身體的一個橫斷面。因為每個檔都記錄了自己的切片位置，軟體就能把它們疊起來重建成 3D 影像，讓醫師從任何角度觀看。

4. 隱私：去識別化

因為檔案內含病人個資，用於教學、研究、分享的影像必須先去識別化，移除姓名、病歷號等資訊。這和照片的 EXIF 隱私問題（第 23 課）是同一種警覺：檔案裡藏的資訊，往往比你看到的畫面更多。

動手試試

如果你做過 CT 或 MRI，醫院給的光碟裡就是 DICOM 檔，可用免費的 DICOM 檢視器打開，還能看到拍攝參數與一張張切片。
