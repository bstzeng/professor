SVG：用文字描述的向量圖

這一課的目標

  • 區分點陣圖與向量圖
  • 理解 SVG 為什麼是純文字
  • 知道向量圖適合與不適合的場合

前面所有影像格式都是點陣圖：記錄每個像素的顏色，放大就會馬賽克。SVG 走完全不同的路——它記錄的是「怎麼畫」。

1. 存指令而非像素

SVG 用文字寫下「畫一個圓心在這、半徑多少的紅圓」「從這點到那點畫一條線」這類指令，瀏覽器每次顯示時才照著即時畫出來。所以不管放多大都清晰，檔案大小只看圖形多複雜，和解析度無關。

2. SVG 其實是純文字（XML）

打開 SVG 檔會發現它是可讀的文字（一種 XML，第 46 課）。這帶來很多好處：

  • 可以用程式產生（這門課的所有圖解就是這樣做的）。
  • 可以被搜尋引擎讀懂、可以嵌入網頁直接操作。
  • 可以寫動畫、可以用 CSS 改顏色。
  • 檔案通常很小（一個圖示可能只有幾百位元組）。

3. 什麼時候別用 SVG

向量圖不適合存照片：照片沒有簡單的幾何形狀，硬要用向量描述反而更大更慢。所以原則很簡單：標誌、圖示、字型、圖表用向量（SVG）；照片用點陣圖（JPG）。
