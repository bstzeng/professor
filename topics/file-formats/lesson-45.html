docx、xlsx、epub、apk：其實都是 ZIP 包 XML

這一課的目標

  • 理解現代文件格式多半是 ZIP
  • 知道 docx 內部裝了什麼
  • 說出幾個「其實是 ZIP」的格式

這一課有個會讓很多人驚訝的事實：你的 Word、Excel、PowerPoint 檔，其實都是 ZIP 壓縮檔。上一課學會了 ZIP，這一課就能看穿它們。

1. 親手驗證

把一個 報告.docx 複製一份、改名成 報告.zip，用解壓縮軟體打開，你會看到裡面是一堆資料夾與檔案：word/document.xml 是文字內容（用 XML 寫，第 51 課），word/media/ 放內嵌的圖片，還有描述作者、標題的檔案。

2. 一大票格式都是這樣

格式其實是 ZIP 包什麼
docx／xlsx／pptxXML（文字、表格、投影片）＋圖片
epub（電子書）HTML＋CSS＋圖片（就像一個小網站）
apk（Android App）／jar（Java）程式碼＋資源檔（第 45 課、程式類在課程二詳談）
很多遊戲的資源包ZIP 換個副檔名

3. 為什麼這樣設計

  • 免費現成：ZIP 又能打包又能壓縮，不必重新發明。
  • 好維護：內容是 XML 純文字，程式容易讀寫、也方便修復。
  • 省空間：文件裡大量重複的 XML 標籤被 DEFLATE 壓得很小。

這也解釋了一個現象：docx 檔壞掉時，有時用解壓縮軟體還能把裡面的圖片與文字救出來——因為它本質上就是個 ZIP。

動手試試

複製一個 .docx，改副檔名成 .zip，用解壓縮軟體打開，找到 word/document.xml 用記事本開來看——你的文章就在那些 XML 標籤之間。

檢查你的理解

  1. docx 檔案本質上是什麼格式？
  2. docx 解開後，文字內容放在哪個檔案？
  3. 再舉兩個「其實是 ZIP」的格式。
