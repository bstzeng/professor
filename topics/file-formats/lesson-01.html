檔案是什麼：位元組、十六進位與 Hex 檢視器

這一課的目標

  • 說出位元、位元組與十六進位的關係
  • 看懂 Hex 檢視器的三個欄位
  • 理解為什麼工程師習慣用十六進位

硬碟、記憶體裡沒有「照片」或「音樂」這種東西，只有一長串位元組。一個位元組是 8 個位元（0 或 1），可以表示 0 到 255 之間的一個數字。一個檔案，就是把好幾千、好幾百萬個這種數字依序排好。

1. 十六進位：工程師的計數法

十進位（我們平常用的 0～9）在這裡不好用，因為 256 不是 10 的整數次方。改用十六進位（0～9 再加 A～F 代表 10～15）就漂亮了：4 個位元剛好是一位（0～F），一個位元組剛好兩位（00～FF）。所以你會看到位元組都寫成兩個字元，例如 48、FF。

2. Hex 檢視器

打開檔案看原始位元組的工具叫 Hex 檢視器（或十六進位編輯器）。它通常分三欄：

  • 位移：這一列從檔案的第幾個位元組開始（也用十六進位）。
  • 十六進位區：每個位元組的值，一列 16 個。
  • ASCII 區：能對應到可見字元的就顯示出來，不能的用「·」代替。

這門課會一直用這個檢視器，一個位元組一個位元組地拆開各種檔案。常見的免費工具有 HxD（Windows）、Hex Fiend（Mac），或線上的十六進位檢視器。

動手試試

隨便找一個檔案，用 Hex 檢視器打開，看看開頭幾個位元組。等你上完模組 A，就能靠這幾個位元組猜出它是什麼格式。
