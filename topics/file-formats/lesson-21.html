之字形掃描與霍夫曼編碼：把係數打包成位元

這一課的目標

  • 說明之字形掃描的用意
  • 理解 JPG 如何利用連續的 0
  • 連結到前面學過的霍夫曼編碼

量化後每個 8×8 區塊剩下 64 個數字，大多是 0，而且 0 集中在右下（高頻）。JPG 用兩招把它們變成最短的位元流。

1. 之字形掃描

如果照一般順序（一列一列）讀這 64 個數字，0 會分散在各處。JPG 改用之字形順序，沿對角線由左上往右下走。這樣一來，非零的低頻係數集中在前面，後面就是一長串連續的 0。

2. 用「連續幾個 0」代替

面對後段一長串 0，JPG 不逐一記錄，而是用「接下來有幾個 0，然後才是一個非零值」的方式描述（游程編碼的概念，第 7 課），最後再補一個「到此為止，剩下全是 0」的結束記號。

3. 霍夫曼編碼收尾

最後，把這串（含「幾個 0」和數值）用霍夫曼編碼（第 8 課）依出現頻率換成長短不一的位元碼。這就是 JPG 檔案裡 SOS 標記之後那一大段壓縮資料的真面目。

所以整條 JPG 流水線是：YCbCr → 色度抽樣 → 切 8×8 → DCT → 量化 → 之字形 → 游程 → 霍夫曼。看懂這條線，你就懂了世界上最普及的影像格式。
