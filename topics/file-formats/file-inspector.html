互動檔案解剖器：拆解你自己的檔案

這個工具讓你把課堂上學的「用魔術數字辨識格式」實際用在自己的檔案上。檔案只在你的瀏覽器裡讀取，不會上傳到任何伺服器。

選一個你電腦裡的檔案（圖片、聲音、壓縮檔、文件都行）。 檔案完全不會上傳，所有分析都在你的瀏覽器裡進行。

它會告訴你什麼

  • 真實格式：依開頭的魔術數字判斷，而不是看副檔名（第 2 課）。
  • 名不符實的警告：如果副檔名和內容對不上（例如 .jpg 其實是執行檔），會特別提醒（第 62 課）。
  • 十六進位：顯示開頭 64 個位元組，就像一個小型 Hex 檢視器（第 1 課）。

試試看：把一個 .docx 丟進來，它會被辨識成 ZIP（第 45 課）；把一張照片改名成 .txt 再丟進來，它仍會認出真正的格式。
