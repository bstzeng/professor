MP4 結構：box（atom）樹狀結構、moov 與 mdat

這一課的目標

  • 說明 MP4 的 box 結構
  • 區分 moov 與 mdat 的角色
  • 理解「快速啟動」為什麼把 moov 移到前面

MP4 是最通用的影片容器。它由一個個 box（早期叫 atom）組成，又是我們熟悉的區塊結構（第 5 課）——每個 box 前面是長度和名稱。

1. 三個關鍵 box

box角色
ftyp檔案型別：宣告這是哪種 MP4（相容性資訊）
moov目錄（後設資料）：有幾條軌、每條用什麼編碼、每一格畫面在檔案的第幾個位元組
mdat實際的影音資料本體，通常最大

2. box 會巢狀

box 可以包 box：moov 裡有多個 trak（一條影像軌、一條聲音軌），每個 trak 裡又有描述時間與位置的子 box。這種樹狀結構讓 MP4 能容納很複雜的內容。

3. 快速啟動

moov 是播放的「目錄」，播放器必須先讀到它才知道怎麼解碼。問題是製作影片時 moov 常被放在檔尾（因為要全部壓完才知道每格位置）。這樣線上播放就得整支下載完才能開始播。

所以串流用的 MP4 會做快速啟動處理，把 moov 搬到檔案開頭，播放器一拿到目錄就能邊下載邊播（第 43 課會看更進階的分段串流）。

動手試試

用支援的工具（如 MP4Box、FFmpeg 的 faststart）處理一支影片，把 moov 移到前面，比較線上播放的啟動速度差別。
