EXIF：照片裡藏的相機資訊、時間與 GPS 位置

這一課的目標

  • 說出 EXIF 存放哪些資訊
  • 知道 EXIF 藏在 JPG 的哪個標記
  • 理解 EXIF 的隱私風險

相機和手機拍照時，會把一堆拍攝資訊寫進 JPG，稱為 EXIF。它就藏在上一課看到的 APP1 標記裡，而且用的正是 TIFF 的標籤式結構（第 16 課）。

1. EXIF 裡有什麼

類別範例
相機廠牌、型號、鏡頭
拍攝參數光圈、快門、ISO、焦距、有沒有開閃光燈
時間拍攝的年月日時分秒
方向照片該轉正的角度（手機直拍靠這個）
縮圖一張小的預覽圖
GPS 位置經度、緯度，有時還有高度——如果拍照時開了定位

2. 隱私風險

最需要注意的是 GPS。如果你在家裡拍了東西、直接把原圖上傳到論壇或傳給陌生人，對方可能就能從 EXIF 讀出你家的座標。曾有通緝犯因為分享的照片帶有 GPS 而被定位。

  • 多數社群平台（Facebook、Instagram 等）上傳時會自動移除 EXIF，但不是全部，而且用通訊軟體傳「原始檔案」時通常會保留。
  • 手機相機設定裡可以關閉「位置」標記。
  • 分享敏感照片前，可以用「移除 EXIF」的工具或截圖（截圖不含原始 EXIF）。

3. EXIF 也很有用

EXIF 不全是壞事：它讓你事後知道每張照片的拍攝參數（學攝影很有用）、自動把手機直拍的照片轉正、依時間與地點整理相簿。重點是知道它的存在，分享時才能自己決定要不要帶著它。

動手試試

用「檢視內容／檔案資訊」或線上 EXIF 檢視器打開一張自己手機拍的照片，看看裡面記錄了哪些資訊——可能包括你當時的所在地。
