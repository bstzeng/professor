HLS 串流：把影片切成幾秒一段的小檔案

這一課的目標

  • 說明分段串流的運作方式
  • 理解 m3u8 播放清單與 ts 片段的關係
  • 知道自動切換畫質的原理

線上看影片時，其實你下載的不是一個大檔，而是幾百個幾秒鐘的小片段。這套技術叫 HLS（HTTP Live Streaming），YouTube、Netflix、各種直播都用類似做法。

1. 播放清單＋片段

  • .m3u8 播放清單：一個純文字檔，裡面按順序列出「每一小段影片的網址」。
  • .ts 片段：每個約 2～10 秒的影片小檔。

播放器先抓清單，然後一段一段下載、接著播。你快轉時，它就去清單裡找對應時間的那幾段來抓，不必下載整支影片。

2. 自動切換畫質

清單裡通常同時列出好幾種畫質的片段（1080p、720p、480p…）。播放器會偵測你的網速：網路好就抓高畫質那組片段，一變慢就自動換成低畫質，所以影片不會卡住，只是畫質偷偷降了。這叫自適應串流。

3. 為什麼這樣設計

  • 用一般的 HTTP 就能傳（和下載網頁一樣），不需特殊伺服器，還能用 CDN 快取加速。
  • 能無縫切換畫質，適應各種網路。
  • 直播也能做：一邊錄一邊產生新片段、更新清單。

另一套類似技術叫 DASH，原理相同。這也是為什麼線上影片很難「右鍵另存」成單一檔案——它本來就是散成幾百個小片段串流過來的。到這裡，影片模組結束。

動手試試

在電腦瀏覽器用開發者工具的「網路」分頁看一支串流影片，你會看到它不斷下載一小段一小段的檔案（.ts 或類似），而不是一個大檔。
