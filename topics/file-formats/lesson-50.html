PDF：物件、交叉參照表與增量更新

這一課的目標

  • 理解 PDF 的物件結構
  • 說明交叉參照表的作用
  • 知道增量更新的便利與風險

PDF 的設計目標是「在任何裝置上都長得一模一樣」。它把一頁的所有東西——文字、字型、圖片、排版位置——都描述得清清楚楚。

1. 一堆物件

PDF 內容由許多物件組成，每個有編號，分別描述文字區塊、內嵌字型、圖片、頁面等，精確指定「什麼東西畫在頁面的哪個座標、長什麼樣」。這就是它跨裝置一致的原因。

2. 交叉參照表：又是從檔尾讀

PDF 檔尾有一張交叉參照表（xref），記錄每個物件在檔案的第幾個位元組。閱讀器打開 PDF 時，先看檔尾找到 xref，再靠它直接跳到需要的物件——和 ZIP「從檔尾讀」是同樣的智慧（第 44 課）。

3. 增量更新與它的風險

編輯 PDF 時，很多工具不重寫整個檔案，而是把改動附加在檔尾，再更新 xref。好處是快、而且能還原到舊版本。但有個隱私風險：你以為刪掉或塗黑的內容，可能還完整留在檔案較前面的地方，只是沒被顯示。

曾有政府或企業把 PDF 上的機密文字用黑框「遮住」就發布，結果別人把黑框下的文字複製出來——因為文字根本沒被刪掉。要真正移除，得用「清理／扁平化」功能重新輸出（第 63 課）。

動手試試

用 PDF 閱讀器打開一份 PDF，試著用滑鼠把「看起來是圖片」的區域反白，你可能會發現底下其實是可複製的文字——PDF 的內容比看起來多。
