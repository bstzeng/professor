TIFF：多頁、多種壓縮的專業影像格式

這一課的目標

  • 說出 TIFF 的標籤式結構特點
  • 知道 TIFF 可以裝多張影像、多種壓縮
  • 理解 TIFF 與其他格式的關係

TIFF（Tagged Image File Format）常見於掃描器、傳真、印刷與專業攝影。它的設計哲學是「極度有彈性」。

1. 標籤式結構

TIFF 不像 BMP 有固定欄位，而是用一連串標籤描述影像的各種屬性（寬、高、位元深度、壓縮方式、色彩、每個資料區塊在哪裡）。這讓它能容納各種奇特的影像，但也讓規格變得複雜，不同軟體對 TIFF 的支援程度不一。

2. 一個檔多張圖、多種壓縮

  • 多頁：一個 TIFF 可放多張影像，掃描整份文件常用；也常內嵌縮圖。
  • 壓縮可選：可以完全不壓、可用 LZW、ZIP、甚至內嵌 JPEG。同一格式，無損有損都行。

3. 大小端都支援

TIFF 開頭兩個位元組若是 49 49（「II」）代表小端，4D 4D（「MM」）代表大端（第 3 課）。它是少數兩種都支援的格式，讀取時要先看這裡。

許多格式借用了 TIFF 的骨架：Photoshop 的 PSD、大部分相機的 RAW（第 17 課）都用類似的標籤式結構。

動手試試

如果你有掃描軟體，把一份多頁文件掃成單一 TIFF，你會得到「一個檔案、多張影像」——這是 PNG／JPG 做不到的。
