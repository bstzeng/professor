種子檔（.torrent）：用雜湊指紋分享大檔案

這一課的目標

  • 理解種子檔本身不含檔案內容
  • 說明雜湊值如何驗證每一塊資料
  • 知道 P2P 分享的基本原理

種子檔（.torrent）常被誤會成「壓縮的影片」，其實它完全不含檔案內容，只有幾 KB，裝的是一份「怎麼湊出這個檔案」的說明書。

1. 種子檔裡有什麼

它用一種叫 Bencode 的簡單編碼（第 51 課純文字家族的親戚）記錄：目標檔案的檔名、大小、被切成幾塊（例如每塊 256 KB），以及最關鍵的——每一塊的雜湊值（指紋），還有去哪裡找其他分享者的資訊。

2. 雜湊指紋：怎麼確保沒拿到壞資料

雜湊值是把一塊資料算出的一小段「指紋」：資料只要差一個位元組，指紋就完全不同。下載時，你從別人手上一塊一塊拿資料，每拿到一塊就算它的指紋、和種子檔裡的核對：對得上才留下，不對就重抓。所以就算資料來自陌生人，也不怕被混入壞內容。

3. 去中心化分享（P2P）

傳統下載是從一台伺服器抓；種子則是大家互相分享（peer-to-peer）：你下載好的每一塊，也同時上傳給還沒拿到的人。分享的人越多，整體速度越快，也沒有單一伺服器的頻寬瓶頸。

這個「用雜湊驗證每一塊、大家互相湊」的設計非常穩健，也被用在其他地方（例如 Git 的版本控制、區塊鏈都用雜湊串起資料）。（提醒：P2P 技術本身中性，但用它分享受著作權保護的內容仍是侵權。）

動手試試

雜湊的威力可以自己試：用線上工具算一段文字的 SHA 值，再改動其中一個字，你會發現整串指紋完全變了——這就是它能驗證資料完整的原因。
