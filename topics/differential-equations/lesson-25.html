用拉普拉斯轉換解方程

這一課的目標

  • 理解拉普拉斯轉換解初始值問題的流程
  • 處理不連續的輸入與脈衝
  • 理解轉移函數的概念

另一種思路

拉普拉斯轉換把時間的函數 f(t) 變成 s 的函數 F(s)。關鍵的性質是：導數變成乘以 s（再減去初始值）：

\[\mathcal{L}\{y'\} = sY(s) - y(0),\qquad \mathcal{L}\{y''\} = s^2Y(s) - s\,y(0) - y'(0)\]

於是一個常係數的線性微分方程，變成關於 Y(s) 的代數方程式（見〈拉普拉斯轉換〉）。

三個步驟

  1. 轉換：方程式兩邊取拉普拉斯轉換，初始條件自動帶入。
  2. 解代數：解出 Y(s)，通常是一個分式。
  3. 反轉換：用部分分式拆開，查表得到 y(t)。

例：y″ + 3y′ + 2y = 0、y(0) = 1、y′(0) = 0。轉換得 (s² + 3s + 2)Y = s + 3，Y = (s + 3)/((s + 1)(s + 2)) = 2/(s + 1) − 1/(s + 2)，所以 y = 2e−t − e−2t（過阻尼，第 12 課）。注意分母 s² + 3s + 2 就是特徵方程式（第 11 課）。

處理突然的輸入

拉普拉斯轉換特別擅長處理不連續的輸入：開關突然打開（步階函數）、在某個時刻突然敲一下（狄拉克 δ 函數，例如鐵鎚敲擊、瞬間的電流脈衝）。用傳統的方法要分段求解再接起來，用拉普拉斯轉換則一次處理。

轉移函數

初始條件為零時，輸出與輸入的轉換之比 Y(s)/X(s) = H(s) 叫做轉移函數，完整地描述了一個線性系統。例如阻尼振子的 H(s) = 1/(s² + 2ζω0s + ω0²)。H(s) 的極點（分母為零的 s）就是特徵根，決定系統是否穩定、是否振盪（第 16 課）；把 s 換成 jω，就得到頻率響應——第 13 課共振的放大倍數曲線。控制工程與訊號處理大量使用這個工具（見〈控制理論〉、〈數位濾波器與 z 轉換〉）。

限制

拉普拉斯轉換主要適用於常係數線性方程。非線性的系統（第 19 課、第 20 課）通常需要線性化、數值方法或定性分析。

🧭 這一課的重點

拉普拉斯轉換把 f(t) 變 F(s)，導數變乘以 s 減初始值 L{y′} = sY − y(0)、L{y″} = s²Y − sy(0) − y′(0)，常係數線性微分方程變代數方程；步驟為轉換帶入初始條件、解代數得分式、部分分式反轉換查表，y″ + 3y′ + 2y = 0、y(0) = 1、y′(0) = 0 得 Y = 2/(s+1) − 1/(s+2)、y = 2e^−t − e^−2t 過阻尼，分母即特徵方程；擅長步階函數與狄拉克 δ 函數等不連續輸入一次處理；初始條件為零時 Y/X = H(s) 為轉移函數，極點即特徵根決定穩定與振盪，s 換 jω 得頻率響應即共振曲線，控制工程與訊號處理大量使用；主要適用常係數線性方程，非線性需線性化數值或定性分析。
