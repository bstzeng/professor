冪級數解

這一課的目標

  • 理解冪級數解法
  • 認識特殊函數
  • 了解級數解的收斂範圍

用無窮級數表示解

許多重要的方程式（變係數的線性方程）沒有初等函數的解。冪級數法假設解是一個無窮級數 y = Σ anxn，代入方程式，比較 x 的各次方的係數，得到係數之間的遞迴關係，一個一個算出來。

一個簡單的例子

y″ + y = 0。代入 y = Σ anxn，得到 an+2 = −an ÷ ((n+1)(n+2))。從 a0、a1 出發：y = a0(1 − x²/2! + x⁴/4! − …) + a1(x − x³/3! + x⁵/5! − …)——正是 cos x 和 sin x 的泰勒級數（第 11 課）！

特殊函數

物理中常見的變係數方程，它們的級數解被賦予名字，成為特殊函數：

方程式特殊函數出現在
艾里方程 y″ = xy艾里函數光學（彩虹附近的亮度）、量子力學的線性位能
貝索方程貝索函數圓形鼓面的振動、圓柱中的熱傳導、電磁波導（第 24 課）
勒讓德方程勒讓德多項式球對稱的問題：地球重力場、氫原子
埃爾米特方程埃爾米特多項式量子諧振子

在電腦普及之前，這些函數被整理成厚厚的數值表；今天的科學計算函式庫都能直接計算它們（例如 SciPy 的 special 模組）。

收斂的範圍

冪級數只在一定的範圍內收斂。理論告訴我們：在方程式的正常點附近，級數解至少在到最近的奇異點（係數變成無限大的點，可能是複數）的距離內收斂。在奇異點附近（例如貝索方程的 x = 0），需要修正的方法（弗羅貝尼烏斯法），解可能包含 x 的分數次方或對數。

漸近與攝動

另一類近似的方法是攝動法：當方程式中有一個小參數 ε，先解 ε = 0 的簡單問題，再把修正項依 ε 的次方展開。天文學家用它計算行星之間的微小影響——1846 年，勒維耶與亞當斯分析天王星軌道的攝動，預測出海王星的位置，被稱為「筆尖上發現的行星」（見〈太陽系〉）。

🧭 這一課的重點

變係數線性方程常無初等函數解，冪級數法假設 y = Σ an x^n 代入比較係數得遞迴關係；y″ + y = 0 得 a(n+2) = −an/((n+1)(n+2))，解正是 cos x 與 sin x 的泰勒級數；特殊函數有艾里函數（彩虹光學、線性位能）、貝索函數（圓形鼓面、圓柱熱傳、波導）、勒讓德多項式（地球重力場、氫原子）、埃爾米特多項式（量子諧振子），過去整理成數值表今由 SciPy special 計算；在正常點附近級數至少在到最近奇異點距離內收斂，奇異點附近用弗羅貝尼烏斯法；攝動法以小參數 ε 展開修正，1846 年勒維耶與亞當斯以天王星軌道攝動預測海王星，筆尖上發現的行星。
