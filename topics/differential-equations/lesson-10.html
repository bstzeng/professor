模組 B｜數值方法 · 第 10 課

剛性方程

這一課的目標

  • 理解剛性的意義
  • 理解數值穩定性
  • 認識隱式方法

快與慢

有些系統同時包含變化非常快與非常慢的成分：化學反應中，有些反應在微秒內完成、有些要好幾個小時；電路中，有些電容的時間常數是奈秒、有些是秒。這種方程叫做剛性（stiff）方程。

顯式方法的困境

考慮 y′ = −1000(y − cos x)。真解很快地貼近 cos x，之後就平緩地變化。用歐拉法時，如果步長 h 大於 0.002，數值解就會劇烈地振盪、越來越大而發散——即使真解早已變得很平緩，步長仍被那個「已經消失」的快速成分限制住。這叫做數值不穩定：誤差不是慢慢累積，而是每一步被放大。

對 y′ = λy（λ < 0），歐拉法的每一步把誤差乘上 (1 + hλ)。只有當 |1 + hλ| < 1，也就是 h < 2/|λ| 時才穩定。λ 很大時，h 就必須非常小。

隱式方法

後向歐拉法用終點的斜率：

\[y_{n+1} = y_n + h\,f(x_{n+1}, y_{n+1})\]

未知的 yn+1 出現在等號兩邊，每一步都要解一個（可能是非線性的）方程式，計算比較費力。但它對 y′ = λy 的每一步把誤差乘上 1/(1 − hλ)，對任何 λ < 0 和任何 h 都小於 1——無條件穩定。步長可以依照解的平緩程度選擇，而不被快速成分限制。

實務

  • 化學反應動力學（燃燒、大氣化學，見〈化學工程〉）、電路模擬（SPICE）、控制系統，常常是剛性的。
  • 專門的剛性求解器：後向差分公式（BDF，例如 Gear 方法）、隱式龍格－庫塔法；SciPy 的 solve_ivp 可以選擇 method='BDF' 或 'Radau'。
  • 徵兆：一般的求解器（例如 RK45）走得異常地慢、步長變得極小——很可能是剛性問題。

更深的教訓

數值方法不只是「近似」，它本身就是一個動態系統，有自己的穩定性。選錯方法，電腦可能很有自信地給出完全錯誤的答案。理解方程式的性質，是使用數值方法的前提。

🧭 這一課的重點

同時有極快與極慢成分的系統如化學反應微秒與數小時、電路奈秒與秒，稱剛性方程；y′ = −1000(y − cos x) 真解很快貼近 cos x 後平緩，歐拉法 h 大於 0.002 即振盪發散，步長被已消失的快速成分限制即數值不穩定；y′ = λy 歐拉每步誤差乘 (1 + hλ)，需 h < 2/|λ|；後向歐拉 y(n+1) = yn + h f(x(n+1), y(n+1)) 每步需解方程但誤差乘 1/(1 − hλ) 無條件穩定；燃燒大氣化學、SPICE 電路、控制系統常剛性，用 BDF Gear 或隱式 RK，SciPy 可選 BDF 或 Radau，RK45 異常慢步長極小是徵兆；數值方法本身是動態系統有自己的穩定性。
