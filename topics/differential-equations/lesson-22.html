邊界值問題

這一課的目標

  • 區分初始值與邊界值問題
  • 理解特徵值問題與駐波
  • 了解打靶法

兩端的條件

到目前為止的問題，都是給定同一個時刻的條件（初始位置與速度）——初始值問題。但許多問題的條件在兩端：一根兩端固定的弦、兩端溫度固定的金屬棒、兩端支撐的梁。這叫做邊界值問題。

可能無解或無限多解

邊界值問題的行為和初始值問題很不一樣。考慮 y″ + λy = 0、y(0) = 0、y(L) = 0（兩端固定的弦）：

  • 大多數的 λ：只有 y = 0 這個「無聊」的解。
  • 只有特定的 λ = (nπ/L)2（n = 1, 2, 3, …）：存在非零的解 y = sin(nπx/L)。

這些特殊的 λ 叫做特徵值，對應的解叫做特徵函數——這是第 15 課矩陣特徵值的「無限維」版本。

駐波與音高

吉他弦的振動正是如此：兩端固定，只能以特定的形狀振動——基音（n = 1，弦的中間振動最大）、第一泛音（n = 2，中間有一個不動的節點）、第二泛音……頻率依序是基頻的 1、2、3 倍。這些駐波決定了樂器的音高與音色（見〈聲學〉、〈樂理〉）。輕輕地碰弦的正中間，就能「消掉」基音，只聽到高八度的泛音。

量子化

量子力學中，被侷限在盒子裡的粒子，滿足類似的邊界值問題（薛丁格方程式），能量只能取特定的值——能量量子化，和弦只能發出特定的音高是同一個數學（見〈量子力學〉）。

施圖姆－劉維爾理論

19 世紀的施圖姆與劉維爾發展出一般的理論：這類邊界值問題的特徵函數彼此正交，可以用來展開任意的函數——就像用正弦與餘弦展開成傅立葉級數（見〈傅立葉與訊號〉）。這是解偏微分方程（第 23 課、第 24 課）的關鍵工具。

打靶法

數值上解邊界值問題的一個直觀方法：把它當成初始值問題，猜一個初始斜率，往前「射擊」，看看在另一端是否打中目標；沒打中就調整斜率再射，直到命中（用二分法或牛頓法）——就像炮兵調整仰角。另一個方法是有限差分法：把區間切成許多點，把導數換成差分，得到一組聯立的代數方程式（見〈數值模擬〉）。

🧭 這一課的重點

初始值問題給同一時刻條件，邊界值問題條件在兩端如兩端固定的弦、兩端溫度固定的棒、兩端支撐的梁；y″ + λy = 0、y(0) = y(L) = 0 大多數 λ 只有零解，只有 λ = (nπ/L)² 有非零解 sin(nπx/L)，為特徵值與特徵函數，是矩陣特徵值的無限維版本；吉他弦只能以基音、泛音等駐波振動頻率為基頻 1 2 3 倍，碰弦正中消掉基音聽到高八度泛音；盒中粒子滿足類似問題能量量子化；施圖姆－劉維爾理論特徵函數正交可展開任意函數如傅立葉級數，是解偏微分方程的關鍵；打靶法猜初始斜率射擊調整至命中如炮兵，或有限差分法化為聯立代數方程。
