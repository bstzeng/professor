存在與唯一性

這一課的目標

  • 理解存在與唯一性定理
  • 認識解不唯一的例子
  • 理解解可能在有限時間內爆炸

兩個基本的問題

給一個微分方程與初始條件，在動手求解之前，數學家會先問：解存在嗎？如果存在，只有一個嗎？對物理模型來說，這是「決定論」的數學表述：知道現在，能否唯一地決定未來？

皮卡－林德勒夫定理

對 y′ = f(x, y)、y(x0) = y0：如果 f 在初始點附近連續，而且 f 對 y 的變化不太劇烈（例如 ∂f/∂y 也連續，數學上稱為「利普希茨條件」），那麼在初始點附近，解存在而且唯一。證明的方法是「逐次逼近」：從一個猜測出發，反覆代入積分式，證明這個過程會收斂到唯一的解。

解不唯一的例子

y′ = 3y2/3、y(0) = 0。y = 0 顯然是解；但 y = x3 也是解！甚至「先在 0 停留任意久，再沿著 (x − a)3 升起」也都是解。問題出在 y2/3 在 y = 0 處對 y 的導數無限大，違反了定理的條件。這種模型如果描述物理系統，就無法預測未來——說明模型本身可能有問題。

有限時間爆炸

即使解存在且唯一，也不一定能延伸到所有的時間。y′ = y2、y(0) = 1，解是 y = 1/(1 − x)：在 x = 1 時趨於無限大，在有限的時間內爆炸。比較：y′ = y 的解 ex 雖然成長很快，但在任何有限的時間都是有限的。成長率比「線性」還快的非線性方程，就可能在有限時間爆炸——這在燃燒、核反應的失控（見〈化學工程〉的熱失控）等模型中都有對應。第 2 課互動元件的「圓」例子，也顯示解在 y = 0 時走不下去。

為什麼重要

  • 解曲線不會相交（第 2 課）：唯一性的直接結果。
  • 數值方法有意義：如果解不唯一，電腦算出來的是哪一個？
  • 相平面的軌跡不會交叉（第 16 課）：這限制了二維系統可能的行為，例如平面上不可能出現混沌（第 20 課）。

🧭 這一課的重點

求解前先問解是否存在與是否唯一，是決定論的數學表述；皮卡－林德勒夫定理若 f 在初始點附近連續且對 y 滿足利普希茨條件如 ∂f/∂y 連續，則附近解存在唯一，以逐次逼近證明；y′ = 3y^(2/3)、y(0) = 0 有 y = 0 與 y = x³ 等無限多解，因 y^(2/3) 在 0 處導數無限大違反條件，模型無法預測未來；y′ = y²、y(0) = 1 解 1/(1 − x) 在 x = 1 有限時間爆炸，成長比線性快的非線性方程可能爆炸如熱失控；唯一性使解曲線與相平面軌跡不相交、數值方法有意義、平面上不可能混沌。

∂ 本課以直觀與應用為主，證明力求精簡；完整的理論請參考微分方程的教科書。互動元件使用數值方法，結果為近似值。

  2. 舉一個解不唯一的例子，說明為什麼不唯一。
  3. y′ = y² 的解為什麼會在有限時間內爆炸？
