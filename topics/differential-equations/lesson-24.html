波動方程

這一課的目標

  • 理解波動方程的推導
  • 了解達朗貝爾解
  • 比較波動方程與熱方程

振動的弦

一條拉緊的弦，位移 y(x, t)。考慮一小段弦，張力在兩端的垂直分量之差提供它的加速度（牛頓第二定律），得到

\[\frac{\partial^2 y}{\partial t^2} = c^2\,\frac{\partial^2 y}{\partial x^2}\]

c = √(張力 ÷ 線密度) 是波速：弦拉得越緊、越細，波傳得越快，音也越高（見〈波動〉、〈吉他〉）。

達朗貝爾解

1747 年，法國的達朗貝爾發現了一個優雅的通解：

\[y(x,t) = F(x - ct) + G(x + ct)\]

任何形狀 F 以速度 c 向右平移，加上任何形狀 G 向左平移。換句話說：波就是保持形狀地移動。撥動弦的一點，兩個「凸起」分別往兩邊跑去，在兩端反射回來。

駐波

兩端固定時，向左與向右的波互相疊加，形成駐波（第 22 課）：分離變數得到 sin(nπx/L) cos(nπct/L)，每個模態以自己的頻率振動，而且不會衰減（沒有阻尼時）。

熱方程與波動方程

熱方程（第 23 課）波動方程
時間導數一階二階
行為擴散、平滑、衰減傳播、保持形狀、振盪
高頻成分迅速消失保留（以更高的頻率振盪）
時間方向不可逆可逆（倒著播放也是合理的波）
訊號速度「無限快」（任何擾動瞬間影響全部，但極微弱）有限的速度 c

一個時間導數的差異，造成了完全不同的物理。

波動方程無所不在

  • 聲波：空氣的壓力擾動（見〈聲學〉）。
  • 地震波：P 波與 S 波在地球內部傳播，用來定位震源與研究地球內部的構造。
  • 電磁波：馬克士威方程組推導出電場與磁場都滿足波動方程，波速正是光速——光就是電磁波（見〈電磁學〉）。
  • 重力波：時空本身的漣漪（見〈重力波〉）。
  • 海浪與海嘯（非線性與色散使情況更複雜）。

🧭 這一課的重點

拉緊的弦一小段張力兩端垂直分量之差提供加速度得 ∂²y/∂t² = c² ∂²y/∂x²，c = √(張力/線密度) 越緊越細波越快音越高；1747 年達朗貝爾通解 y = F(x − ct) + G(x + ct)，波保持形狀向左右平移，撥弦兩個凸起往兩邊跑再反射；兩端固定疊加成駐波 sin(nπx/L) cos(nπct/L) 無阻尼不衰減；熱方程一階時間導數擴散平滑衰減高頻迅速消失不可逆訊號無限快極微弱，波動方程二階傳播保持形狀振盪保留高頻可逆有限速度 c；應用有聲波、地震 P 波 S 波、馬克士威推導電磁波速為光速、重力波、海浪海嘯。

∂ 本課以直觀與應用為主，證明力求精簡；完整的理論請參考微分方程的教科書。互動元件使用數值方法，結果為近似值。
