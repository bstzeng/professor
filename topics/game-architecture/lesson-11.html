元件式設計

這一課的目標

  • 理解元件式設計
  • 寫出元件介面
  • 知道元件之間怎麼溝通
class Component { public: GameObject* owner; virtual void Update(float dt) {} }; class GameObject { std::vector<Component*> components; public: template<class T> T* Get(); // 找某種元件 void Update(float dt) { for (auto* c : components) c->Update(dt); } }; // 使用： auto* hp = player->Get<Health>(); hp->Damage(10);

元件之間怎麼溝通

  • 直接取得：owner->Get<Rigidbody>()，簡單但產生依賴。
  • 事件：發出訊息，有興趣的元件自己接收（第 15 課）。
  • 共用資料：例如所有元件都讀同一個 Transform。

Unity 的 GameObject、Unreal 的 Actor Component 都是這個思路。

🧭 這一課的重點

元件式設計把行為拆成小元件，物件由元件組合而成，設計師可以自由搭配。

🎮 本課以通用的遊戲引擎架構說明概念，程式碼為教學用的簡化片段（類 C++／C# 虛擬碼），不是特定引擎的實際原始碼；各引擎的實作細節以官方文件為準。
