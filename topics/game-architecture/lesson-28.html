腳本語言

這一課的目標

  • 理解腳本層的角色
  • 認識綁定層
  • 比較常見的腳本方案
-- Lua：企劃也能寫的道具效果 function OnUse(player) player:Heal(50) Audio.Play("potion") end
方案例子特點
嵌入式腳本語言Lua小、快、容易嵌入，常見於自製引擎與模組系統
託管語言C#（Unity、Godot）有型別檢查與工具支援
專用語言GDScript為引擎量身打造
視覺化腳本藍圖（Unreal）拖拉節點，不寫文字程式

🧭 這一課的重點

腳本層讓遊戲邏輯可以快速修改、由非程式人員參與；效能關鍵部分留在引擎原生程式。

🎮 本課以通用的遊戲引擎架構說明概念，程式碼為教學用的簡化片段（類 C++／C# 虛擬碼），不是特定引擎的實際原始碼；各引擎的實作細節以官方文件為準。

  1. 為什麼遊戲邏輯常用腳本語言？
  2. 綁定層做什麼？
  3. 視覺化腳本有什麼優缺點？
