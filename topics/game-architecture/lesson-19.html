2D 繪圖：精靈、圖集、圖層

這一課的目標

  • 認識精靈與圖集
  • 理解圖層與排序
  • 知道瓦片地圖
  • 精靈（Sprite）：一張貼圖上的一塊矩形區域，加上位置、旋轉、縮放。
  • 圖層與排序：背景、地形、角色、特效、UI 各自一層；同一層用 y 座標決定前後（俯視角遊戲）。
  • 瓦片地圖（Tilemap）：用格子拼出關卡，每格只存一個編號，節省記憶體也方便編輯。
  • 攝影機：2D 遊戲也有攝影機，決定畫面看到世界的哪一塊。
// 每畫格：把所有精靈交給批次器 for (auto& s : sprites) batcher.Add(s.texture, s.uvRect, s.transform, s.layer); batcher.Flush(); // 依圖層與貼圖排序，合併成少數幾次繪製

🧭 這一課的重點

2D 畫面由精靈、圖集、圖層與瓦片地圖組成；圖集讓大量精靈能被一次畫完。

🎮 本課以通用的遊戲引擎架構說明概念，程式碼為教學用的簡化片段（類 C++／C# 虛擬碼），不是特定引擎的實際原始碼；各引擎的實作細節以官方文件為準。
