輸入系統

這一課的目標

  • 理解輸入的抽象層
  • 區分輪詢與事件
  • 認識輸入緩衝
// 設定：動作對應到多個實體按鍵 input.Bind("Jump", Key::Space); input.Bind("Jump", Gamepad::A); // 遊戲邏輯：只問動作 if (input.Pressed("Jump") && onGround) Jump();
概念說明
按下／持續／放開同一個鍵在不同畫格有不同意義：剛按下才跳，持續按住才蓄力
輪詢每畫格讀一次所有按鍵狀態（遊戲常用）
事件作業系統送來「某鍵被按下」（文字輸入、UI 常用）
輸入緩衝落地前幾格按下跳躍也算數，手感更好
死區類比搖桿中心附近的小晃動要忽略

🧭 這一課的重點

輸入系統把各種裝置統一成抽象動作，遊戲邏輯只關心「動作」而不是「按鍵」。

🎮 本課以通用的遊戲引擎架構說明概念，程式碼為教學用的簡化片段（類 C++／C# 虛擬碼），不是特定引擎的實際原始碼；各引擎的實作細節以官方文件為準。

  2. 「剛按下」和「持續按住」有什麼不同？
  3. 輸入緩衝如何改善手感？
