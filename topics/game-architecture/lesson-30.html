存檔系統

這一課的目標

  • 理解序列化
  • 知道要存什麼、不存什麼
  • 處理存檔的版本相容
struct SaveData { int version = 3; Vec2 playerPos; int hp; std::vector<std::string> inventory; std::map<std::string, bool> questFlags; }; // 讀到 version 2 的存檔：inventory 欄位不存在 → 給預設值
議題做法
物件之間的參考存 ID 而不是記憶體位址，讀檔後再連回去
版本更新存版本號，讀檔時逐版升級
防止損毀先寫到暫存檔，成功後再取代舊檔
防作弊簽章或加密（單機遊戲通常不必太在意）

檔案格式設計的一般原則，見 〈檔案格式解剖學〉。

🧭 這一課的重點

存檔就是序列化必要狀態；記得處理參考、版本與寫入失敗。

🎮 本課以通用的遊戲引擎架構說明概念，程式碼為教學用的簡化片段（類 C++／C# 虛擬碼），不是特定引擎的實際原始碼；各引擎的實作細節以官方文件為準。

檢查你的理解

  1. 為什麼存檔裡要存 ID 而不是指標？
  2. 版本號有什麼用？
  3. 怎麼避免存檔寫到一半損毀？
