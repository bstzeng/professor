延遲與預測

這一課的目標

  • 理解網路延遲的影響
  • 認識客戶端預測與校正
  • 知道延遲補償
  • 客戶端預測：自己的角色先在本地移動，不等伺服器。
  • 伺服器校正：伺服器回傳權威結果，若不一致，客戶端拉回並重播之後的輸入。
  • 其他玩家插值：別人的位置故意晚一點顯示，在兩個已知位置之間插值（第 8 課）。
  • 延遲補償：射擊判定時，伺服器把時間「倒回」射擊者看到的那一刻。
// 客戶端：送出輸入並立刻套用 Input in = Sample(); in.seq = ++seq; pending.push_back(in); Send(in); Simulate(player, in); // 收到伺服器狀態（已處理到 ackSeq） player = serverState; for (auto& in : pending) if (in.seq > ackSeq) Simulate(player, in); // 重播

🧭 這一課的重點

客戶端預測讓操作立即回應，伺服器校正保證一致；其他玩家則靠插值顯示。
