Unity 的架構

這一課的目標

  • 對照 Unity 的物件模型
  • 理解 MonoBehaviour 生命週期
  • 認識 Unity 的 ECS（DOTS）
public class Player : MonoBehaviour { [SerializeField] float speed = 5f; Rigidbody2D rb; void Awake() { rb = GetComponent<Rigidbody2D>(); } // 取得同物件上的元件 void Update() { /* 讀輸入 */ } void FixedUpdate() { rb.velocity = moveInput * speed; } // 物理 }
本主題概念Unity 對應
元件式設計（第 11 課）GameObject ＋ MonoBehaviour
場景圖（第 14 課）Transform 父子關係
ECS（第 12 課）DOTS：Entities、IComponentData、System
資源管理（第 27 課）Addressables、Asset Bundle
事件（第 15 課）C# event、UnityEvent

🧭 這一課的重點

Unity 是元件式設計的代表；DOTS 則提供資料導向的 ECS 選項。

🎮 本課以通用的遊戲引擎架構說明概念，程式碼為教學用的簡化片段（類 C++／C# 虛擬碼），不是特定引擎的實際原始碼；各引擎的實作細節以官方文件為準。
