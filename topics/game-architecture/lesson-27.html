資源管理

這一課的目標

  • 理解資源管理器的角色
  • 認識參考計數與控制代碼
  • 知道背景載入與串流
Handle<Texture> tex = resources.Load<Texture>("slime.png"); // 已經載入過 → 直接回傳同一份，計數 +1 // 不再使用時 → 計數 -1，歸零才釋放
  • 控制代碼（Handle）：用編號代替指標，資源被重新載入或移動時也不會變成懸空指標。
  • 背景載入：在另一條執行緒讀檔、解壓，完成後才交給主執行緒，避免卡頓。
  • 串流：開放世界只把玩家附近的區塊放在記憶體，走遠了再換。
  • 熱重載：美術存檔後，遊戲裡立刻更新。

🧭 這一課的重點

資源管理器確保同一份資源只載入一次，並負責背景載入、串流與釋放。

🎮 本課以通用的遊戲引擎架構說明概念，程式碼為教學用的簡化片段（類 C++／C# 虛擬碼），不是特定引擎的實際原始碼；各引擎的實作細節以官方文件為準。

  1. 參考計數什麼時候會釋放資源？
  2. 為什麼用控制代碼而不是指標？
  3. 開放世界遊戲怎麼處理龐大的地圖？
