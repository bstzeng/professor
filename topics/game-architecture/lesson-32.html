編輯器與工具鏈

這一課的目標

  • 理解編輯器的角色
  • 認識執行時與編輯時的分別
  • 知道反射系統

商用引擎最大的價值之一是編輯器：拖拉物件、調整數值、即時預覽。編輯器本身就是一個大型應用程式（呼應 〈套裝應用程式的架構〉），它和遊戲共用同一套引擎核心。

反射：讓編輯器看得到欄位

// Unreal 風格：巨集標記，建置工具自動產生描述資料 UPROPERTY(EditAnywhere, Category="Combat") float AttackDamage = 10.f; // Unity 風格：public 或 [SerializeField] 欄位自動出現在檢視器 [SerializeField] float attackDamage = 10f;

C++ 本身沒有反射，引擎用巨集與程式碼產生器補上；有了反射，編輯器、存檔、網路同步都可以自動處理欄位。

  • 編輯時：載入原始資源、顯示輔助線、允許任意修改。
  • 執行時：只包含遊戲需要的部分，工具程式碼被排除在建置之外。

🧭 這一課的重點

編輯器讓內容創作者直接工作；反射系統是連接程式碼與編輯器、存檔、網路的橋樑。

🎮 本課以通用的遊戲引擎架構說明概念，程式碼為教學用的簡化片段（類 C++／C# 虛擬碼），不是特定引擎的實際原始碼；各引擎的實作細節以官方文件為準。

檢查你的理解

  1. 為什麼說引擎的一半是工具？
  2. 反射系統做什麼用？
  3. 編輯時和執行時有什麼差別？
