Godot 的架構

這一課的目標

  • 對照 Godot 的物件模型
  • 理解場景的巢狀組合
  • 認識訊號
# GDScript extends CharacterBody2D signal died @export var speed := 200.0 func _physics_process(delta): velocity = Input.get_vector("left", "right", "up", "down") * speed move_and_slide() func take_damage(n): hp -= n if hp <= 0: died.emit() # 誰在聽？發送者不需要知道
本主題概念Godot 對應
場景圖節點樹
元件子節點（每個節點只有一種功能）
觀察者模式訊號（signal）
固定時間步長_physics_process
預製物件場景（.tscn）可以實例化

🧭 這一課的重點

Godot 用「節點樹＋場景＋訊號」組織一切；功能靠組合子節點而非掛元件。

🎮 本課以通用的遊戲引擎架構說明概念，程式碼為教學用的簡化片段（類 C++／C# 虛擬碼），不是特定引擎的實際原始碼；各引擎的實作細節以官方文件為準。
