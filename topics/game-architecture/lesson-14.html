場景圖與父子座標

這一課的目標

  • 理解場景圖
  • 認識區域座標與世界座標
  • 知道場景圖的其他用途
struct Transform { Vec3 localPos; Quat localRot; Vec3 localScale; Transform* parent; Matrix World() const { Matrix local = Compose(localPos, localRot, localScale); return parent ? parent->World() * local : local; } };

實務上會把世界矩陣快取起來，只有在自己或父節點變動時才重新計算（「髒旗標」）。

其他用途

  • 整組隱藏、刪除、複製：對父節點操作即可。
  • 把武器「綁」在角色的手骨上。
  • UI 版面：按鈕在面板裡、面板在畫面裡。

🧭 這一課的重點

場景圖用父子關係組織物件，子物件的世界座標由父物件推算。

🎮 本課以通用的遊戲引擎架構說明概念，程式碼為教學用的簡化片段（類 C++／C# 虛擬碼），不是特定引擎的實際原始碼；各引擎的實作細節以官方文件為準。
