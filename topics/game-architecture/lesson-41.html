Unreal 的架構

這一課的目標

  • 對照 Unreal 的物件模型
  • 理解 Gameplay Framework
  • 認識藍圖與 C++ 的分工
  • UObject：所有物件的基底，提供反射、垃圾回收、序列化（第 32 課）。
  • Actor：可以放進世界的物件；ActorComponent 提供可重用的功能。
  • 藍圖：視覺化腳本，可以繼承 C++ 類別；常見分工是 C++ 寫系統、藍圖拼玩法。
  • 內建網路複製：欄位標記 Replicated 就會自動從伺服器同步到客戶端。
UCLASS() class AMyCharacter : public ACharacter { GENERATED_BODY() UPROPERTY(Replicated, EditAnywhere) float Health = 100.f; UFUNCTION(Server, Reliable) void ServerFire(); // 客戶端呼叫，在伺服器執行 };

🧭 這一課的重點

Unreal 以 Actor＋Component 為基礎，Gameplay Framework 把規則、控制、身體分開，並內建網路複製。

🎮 本課以通用的遊戲引擎架構說明概念，程式碼為教學用的簡化片段（類 C++／C# 虛擬碼），不是特定引擎的實際原始碼；各引擎的實作細節以官方文件為準。
