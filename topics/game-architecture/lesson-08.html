插值與外推

這一課的目標

  • 理解物理與繪製的不同步
  • 學會用插值讓畫面平滑
  • 知道外推的風險

使用固定時間步長後，畫面時刻通常落在兩次物理更新「之間」。如果直接畫最後一次的位置，高更新率螢幕上會看到一頓一頓的移動。

// alpha = acc / STEP，介於 0～1 Vector2 drawPos = Lerp(prevPos, currPos, alpha); DrawSprite(sprite, drawPos);
方法做法特點
插值在上一次和這一次物理狀態之間取中間值永遠正確，但畫面晚最多一個物理步
外推用目前速度預測下一刻的位置沒有延遲，但碰撞或轉向時會「超出去」再拉回

連線遊戲裡也有同樣的問題：其他玩家的位置只有每秒幾十次的更新，客戶端需要插值才能看起來流暢（第 36 課）。

🧭 這一課的重點

插值讓繪製和物理解耦：物理用固定步，畫面在兩步之間平滑內插。

🎮 本課以通用的遊戲引擎架構說明概念，程式碼為教學用的簡化片段（類 C++／C# 虛擬碼），不是特定引擎的實際原始碼；各引擎的實作細節以官方文件為準。

  2. 插值和外推各有什麼優缺點？
  3. alpha 這個值是怎麼來的？
