效能預算

這一課的目標

  • 理解畫格預算的分配
  • 認識 CPU 與 GPU 的平行
  • 知道常見的效能瓶頸

CPU 與 GPU 同時工作

CPU 準備第 N+1 格的資料時，GPU 正在畫第 N 格。整體速度取決於比較慢的那一方：CPU 瓶頸時降低畫質沒有用，GPU 瓶頸時優化遊戲邏輯也沒有用。

常見瓶頸

  • 繪製呼叫太多（CPU 端）。
  • 像素太多、特效太重（GPU 端）。
  • 記憶體配置與快取未命中（見 第 13 課）。
  • 物理物體太多、尋路太頻繁。

🧭 這一課的重點

每個系統都分到一塊畫格預算；先量測找出是 CPU 還是 GPU 瓶頸，再對症優化。

🎮 本課以通用的遊戲引擎架構說明概念，程式碼為教學用的簡化片段（類 C++／C# 虛擬碼），不是特定引擎的實際原始碼；各引擎的實作細節以官方文件為準。
