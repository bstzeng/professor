定義域、值域與限制條件

這一課的目標

  • 理解 domain 與 range 的推論語意
  • 認識存在、全稱、基數與值限制
  • 會用限制條件描述類別

定義域與值域

\[\text{domain}(P) = C \;:\; P(x,y) \Rightarrow C(x),\qquad \text{range}(P) = D \;:\; P(x,y) \Rightarrow D(y)\]

這是 RDFS／OWL 中最常被誤解的地方：domain 與 range 不是檢查規則，而是推論規則。寫了「作者是」的 domain 是「書」，再寫「托爾金 作者是 某人」，推理機不會報錯，而是推出「托爾金是一本書」。

限制條件

OWL 用屬性限制描述類別的成員必須滿足什麼條件。每個限制本身就是一個（匿名）類別：

限制描述邏輯寫法意思例子
存在限制\(\exists P.C\)至少有一個 P 值屬於 C父母 ≡ 人 ⊓ ∃有子女.人
全稱限制\(\forall P.C\)所有的 P 值都屬於 C（可能一個都沒有）素食者 ⊑ ∀吃.植物
基數限制\({\geq}n\,P,\;{\leq}n\,P,\;{=}n\,P\)P 值的個數人 ⊑ =2 有生物學上的父母
值限制\(\exists P.\{a\}\)P 值包含某個特定個體台灣人 ≡ 人 ⊓ ∃國籍.{台灣}

全稱限制的陷阱

「素食者 ⊑ ∀吃.植物」的意思是：如果素食者吃了東西，那東西一定是植物。一個什麼都不吃的人也滿足這個條件（空真）。所以全稱限制通常要搭配存在限制：素食者 ⊑ ∃吃.植物 ⊓ ∀吃.植物。

from owlready2 import get_ontology, Thing, ObjectProperty onto = get_ontology("http://example.org/food.owl") with onto: class Food(Thing): pass class Plant(Food): pass class Meat(Food): pass class Person(Thing): pass class eats(Person >> Food): pass class has_child(Person >> Person): pass class Parent(Person): equivalent_to = [Person & has_child.some(Person)] # ∃ 存在限制 class Vegetarian(Person): is_a = [eats.some(Plant), eats.only(Plant)] # ∃ 與 ∀ 搭配 class BigFamily(Person): equivalent_to = [Person & has_child.min(3, Person)] # 基數限制

必要條件 vs. 必要且充分條件

is_a（⊑）寫的是必要條件：素食者一定滿足這些條件，但滿足條件的不一定是素食者。equivalent_to（≡）寫的是必要且充分條件：滿足條件的就自動被歸類為父母。這個差別決定了推理機能不能自動分類（下一課）。

🧭 這一課的重點

domain 與 range 是推論規則而非檢查規則：P(x,y) 推出 x 屬於定義域、y 屬於值域。OWL 以屬性限制描述類別：存在限制 ∃P.C、全稱限制 ∀P.C、基數限制、值限制，每個限制都是匿名類別。全稱限制有空真陷阱，常需搭配存在限制。is_a 表必要條件，equivalent_to 表必要且充分條件，後者使推理機能自動分類。
