蒯因〈論有什麼〉：本體論承諾

這一課的目標

  • 理解蒯因的本體論承諾標準
  • 理解「存在就是成為約束變元的值」
  • 把本體論承諾應用到資料模型上

20 世紀分析哲學家蒯因（W. V. O. Quine）在 1948 年的論文〈論有什麼〉（On What There Is）中，把存有論問題轉換成一個可以檢查的邏輯問題。

本體論承諾

蒯因的名言

To be is to be the value of a variable.（存在，就是成為約束變元的值。）

一個理論「承諾」哪些東西存在，不是看它用了哪些名詞，而是看它的命題寫成一階邏輯之後，量詞 ∃ 的變元必須取哪些值才能讓命題為真。

\[\exists x\,(\text{質數}(x) \wedge x > 1000) \;\Rightarrow\; \text{這個理論承諾了數的存在}\]

說「有些狗比貓大」，就承諾了狗和貓存在；說「飛馬不存在」，不必承諾飛馬存在（羅素的摹狀詞理論已經示範了怎麼改寫）。

在資料模型中的本體論承諾

蒯因的標準非常適合拿來審視一個資料模型或 Ontology：你的模型裡，哪些東西可以被當成量詞的值——可以有自己的識別碼、可以被計數、可以被關係連結？

模型寫法本體論承諾
person.marital_status = 'married'只承諾人存在；婚姻只是一個值
Marriage(id, person1, person2, date)承諾婚姻是一種存在物，可以計數、可以有屬性
product.color = 'red'顏色不是存在物
Color(id, name, hex) + 連結顏色是存在物，可以問「有幾種顏色」
from rdflib import Graph g = Graph().parse(data=''' @prefix : <http://example.org/#> . :John :marriedTo :Mary . :m42 a :Marriage ; :partner :Ann, :Bob ; :year 2015 . ''', format="turtle") # 只有被「量化」得到的東西才能被問「有幾個」 q1 = "SELECT (COUNT(?m) AS ?n) WHERE { ?m a <http://example.org/#Marriage> }" print(list(g.query(q1))) # 只數得到被具體化的那一樁婚姻

蒯因的其他遺產

  • 本體論相對性：同樣的資料可以有不同的本體解釋，不存在脫離語言框架的唯一答案。
  • 不可譯性（gavagai 的例子）：語言學家聽到土著指著兔子說 gavagai，無法確定它指「兔子」「兔子的一部分」還是「兔子的時段」——本體對齊（第 49 課）的根本困難。

🧭 這一課的重點

蒯因 1948 年的〈論有什麼〉主張：存在就是成為約束變元的值。理論的本體論承諾取決於量詞所需的變元值，而非所用的名詞。此標準可直接檢查資料模型：可被識別、計數、連結的東西才是模型承諾存在的，例如婚姻做成值或做成實體，承諾不同。蒯因的本體論相對性與 gavagai 不可譯性，預示了本體對齊的根本困難。

🕸️ 本課程的程式範例以 Python 為主（rdflib、owlready2 等），Turtle 與 SPARQL 以字串形式出現在 Python 中；Palantir 相關內容依公開資料整理，產品與財務資訊以撰寫時為準。

檢查你的理解

  1. 「有些書比字典還厚」承諾了哪些東西存在？
  2. 把顏色做成屬性值或獨立實體，本體論承諾有何不同？
  3. gavagai 的例子和本體對齊有什麼關係？
