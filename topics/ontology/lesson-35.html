OWL 2：完整的本體語言

這一課的目標

  • 認識 OWL 2 的主要構造
  • 區分 OWL 2 DL 與 OWL 2 Full
  • 用 Python 建立 OWL 本體

OWL（Web Ontology Language）2004 年成為 W3C 標準，2009 年更新為 OWL 2。它以描述邏輯 SROIQ(D) 為基礎，提供完整的本體建模能力。

主要構造

類別OWL 詞彙描述邏輯
類別運算owl:intersectionOf、unionOf、complementOf⊓、⊔、¬
屬性限制owl:someValuesFrom、allValuesFrom、hasValue∃、∀、∃R.{a}
基數owl:minQualifiedCardinality 等≥n、≤n、=n
類別公理owl:equivalentClass、disjointWith、AllDisjointClasses≡、互斥
屬性特性TransitiveProperty、SymmetricProperty、FunctionalProperty、inverseOfS、I、F
屬性鏈owl:propertyChainAxiomR ∘ S ⊑ T
個體owl:sameAs、differentFrom、AllDifferenta = b、a ≠ b
列舉owl:oneOf{a, b, c}
鍵owl:hasKey以屬性值識別個體

OWL 2 DL vs. OWL 2 Full

  • OWL 2 DL：遵守描述邏輯的限制（例如類別和個體分開、傳遞屬性不能有基數限制），推理可判定。實務上說「OWL」幾乎都是指這個。
  • OWL 2 Full：允許任何 RDF 圖（類別也可以是個體、可以有屬性），表達力最大，但推理不可判定，很少使用。
from owlready2 import (get_ontology, Thing, AllDisjoint, TransitiveProperty, PropertyChain, sync_reasoner) onto = get_ontology("http://example.org/family.owl") with onto: class Person(Thing): pass class Man(Person): pass class Woman(Person): pass AllDisjoint([Man, Woman]) # 互斥 class has_parent(Person >> Person): pass class has_brother(Person >> Man): pass class has_uncle(Person >> Man): pass has_uncle.property_chain.append(PropertyChain([has_parent, has_brother])) # 角色鏈 ann, mary, tom = Woman("Ann"), Woman("Mary"), Man("Tom") ann.has_parent = [mary]; mary.has_brother = [tom] sync_reasoner(infer_property_values=True) print(ann.has_uncle) # [family.Tom] onto.save(file="family.owl", format="rdfxml")

Manchester 語法

Protégé 介面中常看到更接近英文的 Manchester 語法：Parent EquivalentTo: Person and (hasChild some Person)。它和 OWL/XML、函數式語法、Turtle 都是同一個本體的不同寫法。

🧭 這一課的重點

OWL 2 以 SROIQ(D) 為基礎，提供類別運算（交聯補）、屬性限制（some、all、hasValue）、限定基數、等價與互斥公理、屬性特性、角色鏈、sameAs 與 differentFrom、列舉與鍵。OWL 2 DL 遵守描述邏輯限制，推理可判定；OWL 2 Full 允許任意 RDF 但不可判定。owlready2 可宣告互斥、角色鏈並以 HermiT 推理；Protégé 常用 Manchester 語法。

🕸️ 本課程的程式範例以 Python 為主（rdflib、owlready2 等），Turtle 與 SPARQL 以字串形式出現在 Python 中；Palantir 相關內容依公開資料整理，產品與財務資訊以撰寫時為準。
