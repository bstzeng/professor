推理服務：包含、一致性與實例檢查

這一課的目標

  • 認識標準的推理服務
  • 理解各服務之間的轉換
  • 理解 Tableau 演算法的直覺

描述邏輯推理機提供幾種標準服務：

服務問題用途
概念可滿足性C 有可能有成員嗎？找出定義有矛盾的類別（例如 素食者 ⊓ 吃肉的人）
包含C ⊑ D 嗎？自動分類（第 24 課）
一致性整個知識庫有沒有矛盾？品質檢查
實例檢查個體 a 屬於 C 嗎？自動歸類、查詢
分類算出所有具名類別之間的包含階層本體瀏覽與維護

它們可以互相轉換

\[C \sqsubseteq D \iff C \sqcap \neg D \text{ 不可滿足}\]

所以只要能判斷「可滿足性」，其他問題都能解。推理機的核心就是一個可滿足性檢查器。

Tableau 演算法的直覺

要檢查 C 是否可滿足，就試著建構一個 C 的成員：

  1. 先假設存在一個個體 x 屬於 C。
  2. 把 C 拆開：遇到 ⊓ 就把兩邊都加進 x 的標籤；遇到 ⊔ 就分岔，兩種可能都試；遇到 ∃R.D 就造一個新的 R-鄰居 y 屬於 D；遇到 ∀R.D 就把 D 加到所有 R-鄰居。
  3. 如果某個分支出現矛盾（x 同時屬於 A 和 ¬A），這個分支失敗。
  4. 所有分支都失敗 → 不可滿足；有一個分支走完沒有矛盾 → 可滿足（這個分支就是一個模型）。
# 極簡的 ALC tableau（只處理 ⊓、⊔、¬原子、∃、∀），判斷概念是否可滿足 def sat(labels, depth=0): labels = set(labels) for c in list(labels): # 展開交集 if c[0] == "and": return sat(labels - {c} | {c[1], c[2]}, depth) for c in list(labels): # 聯集：分岔 if c[0] == "or": rest = labels - {c} return sat(rest | {c[1]}, depth) or sat(rest | {c[2]}, depth) atoms = {c[1] for c in labels if c[0] == "atom"} if any(c[0] == "not" and c[1] in atoms for c in labels): return False # 衝突：A 與 ¬A for c in labels: # 存在：造一個鄰居 if c[0] == "some": succ = {c[2]} | {d[2] for d in labels if d[0] == "all" and d[1] == c[1]} if not sat(succ, depth + 1): return False return True A = ("atom", "Meat") veg_meat = ("and", ("all", "eats", ("not", "Meat")), ("some", "eats", A)) print(sat({veg_meat})) # False：∀eats.¬Meat ⊓ ∃eats.Meat 不可滿足

常用的推理機

  • HermiT（牛津）：超 tableau 演算法，owlready2 內建。
  • Pellet：支援 SWRL 規則與解釋。
  • FaCT++、Konclude：高效能。
  • ELK：專門處理 OWL 2 EL，數十萬概念的醫學本體幾秒內分類完成。

🧭 這一課的重點

推理機提供概念可滿足性、包含、一致性、實例檢查與分類等服務，它們可互相轉換，例如 C ⊑ D 等價於 C ⊓ ¬D 不可滿足，因此核心是可滿足性檢查。Tableau 演算法試著建構概念的成員：交集加入標籤、聯集分岔、存在造鄰居、全稱傳播，出現 A 與 ¬A 則該分支失敗。常用推理機有 HermiT、Pellet、FaCT++、Konclude 與專攻 EL 的 ELK。

🕸️ 本課程的程式範例以 Python 為主（rdflib、owlready2 等），Turtle 與 SPARQL 以字串形式出現在 Python 中；Palantir 相關內容依公開資料整理，產品與財務資訊以撰寫時為準。
