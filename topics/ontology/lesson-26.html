一階邏輯回顧

這一課的目標

  • 複習一階邏輯的語法
  • 理解模型與滿足的概念
  • 理解一階邏輯為什麼太強

一階謂詞邏輯（FOL）有：

  • 常數：特定的個體，如 托爾金、魔戒。
  • 謂詞：一元謂詞（類別）如 Book(x)；二元謂詞（關係）如 writtenBy(x, y)。
  • 連接詞：¬、∧、∨、→、↔。
  • 量詞：∀（對所有）、∃（存在）。

把本體寫成一階邏輯

本體陳述一階邏輯
小說 ⊑ 書\(\forall x\,(\text{Novel}(x)\rightarrow\text{Book}(x))\)
父母 ≡ 人 ⊓ ∃有子女.人\(\forall x\,(\text{Parent}(x)\leftrightarrow \text{Person}(x)\wedge\exists y\,(\text{hasChild}(x,y)\wedge\text{Person}(y)))\)
位於 是傳遞的\(\forall x\,\forall y\,\forall z\,(\text{in}(x,y)\wedge\text{in}(y,z)\rightarrow\text{in}(x,z))\)
作者是 的定義域是 書\(\forall x\,\forall y\,(\text{writtenBy}(x,y)\rightarrow\text{Book}(x))\)

模型與蘊涵

一個模型（解釋）是一個「可能世界」：指定論域裡有哪些東西、每個謂詞對哪些東西為真。一個知識庫 KB 蘊涵 φ（KB ⊨ φ），意思是：在所有讓 KB 為真的模型中，φ 都為真。推理機做的事，就是判斷蘊涵。

\[\text{KB} \models \varphi \iff \text{每一個滿足 KB 的模型都滿足 } \varphi\]

一階邏輯太強了

一階邏輯的蘊涵問題是不可判定的（丘奇與圖靈，1936）：不存在一個演算法，能對任意的 KB 和 φ 在有限時間內正確回答 KB ⊨ φ。推理機可能永遠跑不完。

所以本體語言採取的策略是：只取一階邏輯中夠用、又可判定的一部分——這就是描述邏輯（下一課）。

# 用 Python 在一個小模型上檢查一階公式是否成立（有限論域時可以窮舉） domain = {"魔戒", "哈比人", "托爾金", "路易斯"} Book = {"魔戒", "哈比人"} Person = {"托爾金", "路易斯"} writtenBy = {("魔戒", "托爾金"), ("哈比人", "托爾金")} # ∀x ∀y (writtenBy(x,y) → Book(x) ∧ Person(y)) ok = all((x in Book and y in Person) for (x, y) in writtenBy) # ∀x (Book(x) → ∃y writtenBy(x,y)) every_book_has_author = all(any((b, y) in writtenBy for y in domain) for b in Book) print(ok, every_book_has_author)

🧭 這一課的重點

一階邏輯有常數、謂詞、連接詞與量詞，本體陳述都可以翻譯成一階公式：subClassOf 是全稱蘊含、存在限制含存在量詞、傳遞性與定義域都是全稱公式。模型是一個可能世界，KB ⊨ φ 指所有滿足 KB 的模型都滿足 φ，推理機即判斷蘊涵。一階邏輯的蘊涵不可判定，因此本體語言只取可判定的片段，也就是描述邏輯。
