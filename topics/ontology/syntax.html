\(C \sqcup D\)C or D聯集第 27 課
\(\neg C\)not C補集第 27 課
\(\exists R.C\)R some C至少有一個 R 指向 C第 23 課
\(\forall R.C\)R only C所有 R 都指向 C第 23 課
\(\geq n\, R.C\)R min n C至少 n 個第 23 課
\(\leq n\, R.C\)R max n C至多 n 個第 23 課
\(\{a, b\}\){a, b}列舉第 35 課

Turtle 速查

寫法意思
@prefix ex: <http://example.org/> .宣告前綴
ex:a ex:p ex:b .一個三元組
ex:a ex:p ex:b ; ex:q ex:c .分號：同主詞，下一個述詞
ex:a ex:p ex:b , ex:c .逗號：同主詞與述詞，下一個受詞
ex:a a ex:C .a = rdf:type
[ ex:p ex:b ]空白節點
"魔戒"@zh-TW帶語言標籤的字串
