類別與個體

這一課的目標

  • 理解類別、個體與 rdf:type
  • 理解類別的外延與內涵
  • 避免類別與個體混淆

Ontology 的兩種基本元素：

  • 類別（Class）：一群具有共同特徵的東西，例如「小說」「作家」「借閱紀錄」。
  • 個體（Individual，也叫實例）：具體的一個東西，例如《魔戒》、托爾金、第 20231105-001 號借閱紀錄。

個體和類別之間的關係叫 rdf:type（「是一個」）：《魔戒》rdf:type 小說。

外延與內涵

  • 外延：類別包含哪些個體——「小說」的外延是所有小說的集合。OWL 的語意就是用集合定義的：類別 = 個體的集合。
  • 內涵：類別的定義或意義——「小說」是「篇幅較長的虛構散文敘事作品」。

兩個類別可以外延相同、內涵不同：「有心臟的動物」與「有腎臟的動物」（在現實中剛好是同一群動物）。OWL 只看外延，所以如果宣告兩者等價，推理機不會反對。

from owlready2 import get_ontology, Thing onto = get_ontology("http://example.org/lib.owl") with onto: class Book(Thing): pass class Novel(Book): pass # Novel ⊑ Book class Author(Thing): pass lotr = Novel("LOTR") # 個體：rdf:type Novel tolkien = Author("Tolkien") print(lotr.is_a) # [lib.Novel] print(list(Novel.instances())) # [lib.LOTR] print(Book in Novel.ancestors()) # True

常見的混淆

情況問題較好的做法
把「台北」做成類別台北是一個具體的城市，不是一群東西台北是「城市」這個類別的個體
把每個產品型號做成類別「iPhone 16」是型號，「我手上這支」才是個體，兩者都有可能需要依用途決定；必要時用「產品型號」與「產品單品」兩個類別
把顏色「紅色」做成類別看用途：要描述「紅色的東西」還是「紅色這種顏色」通常做成「顏色」類別的個體

雙關（punning）

有時候同一個名字需要同時當類別和個體：「金鷹」這個物種是一個類別（包含所有金鷹），但它本身也可以有屬性（保育等級：一級）。OWL 2 允許同一個 IRI 同時當類別和個體使用，稱為 punning，但兩種身分在邏輯上是分開處理的。

🧭 這一課的重點

類別是具共同特徵的一群東西，個體是具體的一個，兩者以 rdf:type 連結。外延是類別包含的個體集合，內涵是其定義，OWL 只看外延。常見錯誤是把具體城市做成類別，或不分產品型號與單品。OWL 2 的 punning 允許同一 IRI 兼作類別與個體，但邏輯上分開處理。

🕸️ 本課程的程式範例以 Python 為主（rdflib、owlready2 等），Turtle 與 SPARQL 以字串形式出現在 Python 中；Palantir 相關內容依公開資料整理，產品與財務資訊以撰寫時為準。
