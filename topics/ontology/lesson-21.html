屬性：物件屬性與資料屬性

這一課的目標

  • 區分物件屬性與資料屬性
  • 認識資料型別
  • 理解註解屬性

OWL 有三種屬性：

屬性連結例子
物件屬性（ObjectProperty）個體 → 個體《魔戒》作者是 托爾金；書架A3 位於 三樓
資料屬性（DatatypeProperty）個體 → 常值（數字、字串、日期）《魔戒》出版年 1954；托爾金 姓名 "J. R. R. Tolkien"
註解屬性（AnnotationProperty）附加說明，不參與推理rdfs:label、rdfs:comment、skos:definition、作者、版本

資料型別

資料屬性的值有型別，多採用 XML Schema 的資料型別：xsd:string、xsd:integer、xsd:decimal、xsd:boolean、xsd:dateTime 等。也可以限制範圍，例如「年齡是 0 到 150 的整數」。

屬性也有階層

屬性可以有子屬性：「母親是」⊑「父母是」⊑「祖先是」。如果安的母親是瑪麗，推理機就會推出安的父母是瑪麗、安的祖先是瑪麗。

\[\text{hasMother} \sqsubseteq \text{hasParent} \sqsubseteq \text{hasAncestor}\]
from owlready2 import get_ontology, Thing, ObjectProperty, DataProperty, FunctionalProperty import datetime onto = get_ontology("http://example.org/lib.owl") with onto: class Book(Thing): pass class Person(Thing): pass class written_by(Book >> Person): pass # 物件屬性 class year(Book >> int, FunctionalProperty): pass # 資料屬性（函數性：只有一個值） class isbn(Book >> str, FunctionalProperty): pass class has_parent(Person >> Person): pass class has_mother(has_parent): pass # 子屬性 lotr = Book("LOTR", year=1954, isbn="978-0-261-10325-2") lotr.written_by = [Person("Tolkien")]

用註解讓人看得懂

每個類別與屬性都應該有人類可讀的標籤（rdfs:label，可以有多種語言，例如 "小說"@zh-TW、"Novel"@en）與定義（skos:definition）。IRI 只是給機器的識別碼；沒有好的註解，本體很快就沒人看得懂。

屬性值是物件還是常值？

「出生地」該填字串 "台北" 還是個體 :台北？若只是顯示用，字串就夠；若要查詢「出生在台灣北部的作家」，就必須是個體，才能沿著「位於」關係走下去。這又是一次本體論承諾的選擇（第 11 課）。

🧭 這一課的重點

OWL 有物件屬性（連結兩個個體）、資料屬性（連結個體與型別化常值，常用 XML Schema 型別）與不參與推理的註解屬性。屬性可以有階層，如 hasMother ⊑ hasParent ⊑ hasAncestor，推理機會沿子屬性推出上層屬性。每個概念都應有多語標籤與定義。屬性值做成常值或個體，取決於是否需要沿著它繼續查詢。

🕸️ 本課程的程式範例以 Python 為主（rdflib、owlready2 等），Turtle 與 SPARQL 以字串形式出現在 Python 中；Palantir 相關內容依公開資料整理，產品與財務資訊以撰寫時為準。
