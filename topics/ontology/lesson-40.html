生物醫學：Gene Ontology、SNOMED CT 與 OBO Foundry

這一課的目標

  • 認識 Gene Ontology 的結構與用途
  • 認識 SNOMED CT 與醫療術語
  • 理解 OBO Foundry 的原則

Gene Ontology（GO）

1998 年，果蠅、酵母菌、小鼠三個模式生物資料庫的研究者發現，彼此描述基因功能的用詞不一致，無法比較。他們建立了 Gene Ontology，用統一的詞彙描述基因產物的功能，分成三個獨立的分支：

分支描述例子
分子功能（MF）分子層次的活性ATP 結合、激酶活性
生物過程（BP）多個分子功能組成的生物程序細胞分裂、DNA 修復
細胞組成（CC）在細胞中的位置細胞核、粒線體膜

GO 有數萬個術語，以 is_a、part_of、regulates 等關係連成有向無環圖。研究者最常用它做富集分析：一群在實驗中表現量改變的基因，是否特別集中在某些功能上？

SNOMED CT

SNOMED CT 是全球最大的臨床醫學術語系統，包含數十萬個概念（疾病、症狀、手術、藥物、身體結構……），以描述邏輯（OWL 2 EL 的子集）定義。例如「細菌性肺炎」被定義為：肺炎 ⊓ ∃致病因子.細菌 ⊓ ∃發現部位.肺結構。推理機據此自動算出它的所有上層類別。

電子病歷系統用 SNOMED CT 編碼，不同醫院的紀錄才能互相理解、做研究與統計。台灣衛福部的電子病歷交換與 FHIR 標準推動也涉及 SNOMED CT、LOINC（檢驗項目）等國際術語。

OBO Foundry

OBO Foundry 是一個生物醫學本體的協作社群，制定共同原則：開放授權、共用 BFO 上層本體、每個術語有唯一的 ID 與文字定義、明確的範圍、不重複造輪子（例如解剖用 Uberon、化學用 ChEBI、疾病用 MONDO）。

# 用 pronto 讀取 Gene Ontology（OBO 格式），找一個術語的所有上層類別 import pronto go = pronto.Ontology("http://purl.obolibrary.org/obo/go/go-basic.obo") term = go["GO:0006281"] # DNA repair（DNA 修復） print(term.name, "|", term.definition) for sup in term.superclasses(distance=None): # 沿 is_a 往上 print(" ⊑", sup.id, sup.name) # 富集分析通常用專門套件（如 goatools），比較某組基因的 GO 註記與背景分布

為什麼生物醫學特別成功

  • 領域知識龐大、精確，而且有共同的科學基礎。
  • 資料整合需求極強：基因、蛋白質、疾病、藥物分散在數千個資料庫。
  • 有長期的公共資金與學術社群支持。

🧭 這一課的重點

Gene Ontology 1998 年由多個模式生物資料庫建立，分為分子功能、生物過程、細胞組成三支，以 is_a、part_of、regulates 連成有向無環圖，常用於基因富集分析。SNOMED CT 是最大的臨床術語系統，以 OWL 2 EL 子集定義數十萬概念並自動分類，是電子病歷互通的基礎。OBO Foundry 制定開放、共用 BFO、唯一 ID、不重複造輪子等原則。生物醫學因知識精確、整合需求強與長期支持而最成功。
