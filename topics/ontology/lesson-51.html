企業知識圖譜

這一課的目標

  • 理解企業知識圖譜的架構
  • 比較 RDF 與屬性圖兩種技術路線
  • 了解從資料到知識圖譜的建構流程

一家中大型企業可能有數百套系統：ERP、CRM、MES、HR、財務……每套系統對「客戶」「產品」「訂單」都有自己的定義。企業知識圖譜用一套共同的本體，把這些資料連成一張圖。

兩條技術路線

RDF 三元組資料庫屬性圖資料庫
代表產品GraphDB、Stardog、Amazon Neptune、Apache JenaNeo4j、TigerGraph、Amazon Neptune、Memgraph
資料模型三元組，IRI 全域識別節點與邊都可帶屬性（鍵值對）
綱要RDFS、OWL、SHACL較鬆散，通常在應用層定義
查詢語言SPARQLCypher、GQL（2024 年 ISO 標準）
推理有，標準化通常沒有，或需外掛
優勢資料整合、標準、互通、推理圖演算法（路徑、社群、中心性）、開發者友善

兩者正在接近：RDF 1.2 的 RDF-star 讓邊也能有屬性；屬性圖陣營也開始重視綱要。很多企業的做法是：用本體定義語意，用最適合的資料庫存放。

建構流程

  1. 本體設計：從能力問題出發（第 46 課）。
  2. 資料對應：把資料庫表格、CSV、API 對應到本體（R2RML、RML；或寫 Python ETL）。
  3. 實體解析：判斷不同系統的「台積電」「TSMC」「台灣積體電路製造股份有限公司」是同一家公司。
  4. 非結構化抽取：從文件、郵件、合約中用 NLP 或 LLM 抽取實體與關係。
  5. 驗證與推理：SHACL 檢查品質，推理補充隱含關係。
  6. 服務：搜尋、推薦、問答、分析、儀表板。
# 把兩個系統的資料（CRM、ERP）對應到同一個本體，並做簡單的實體解析 import pandas as pd from rdflib import Graph, Namespace, Literal, RDF EX = Namespace("http://example.org/kg#") crm = pd.DataFrame({"cust_id": ["C01", "C02"], "name": ["台積電", "鴻海精密"], "tax_id": ["22099131", "04541302"]}) erp = pd.DataFrame({"vendor": ["V9"], "vendor_name": ["台灣積體電路製造股份有限公司"], "vat": ["22099131"]}) g = Graph() def company(tax_id): # 以統一編號作為實體解析的鍵 → 同一個 IRI return EX["org/" + tax_id] for r in crm.itertuples(): c = company(r.tax_id) g.add((c, RDF.type, EX.Organization)); g.add((c, EX.name, Literal(r.name))) g.add((c, EX.crmId, Literal(r.cust_id))) for r in erp.itertuples(): c = company(r.vat) g.add((c, RDF.type, EX.Organization)); g.add((c, EX.legalName, Literal(r.vendor_name))) g.add((c, EX.erpVendorId, Literal(r.vendor))) # 同一家公司既是客戶也是供應商——跨系統才看得到的事實 q = "SELECT ?c ?n WHERE { ?c :crmId ?x ; :erpVendorId ?y ; :name ?n }" print(list(g.query(q, initNs={"": EX})))

實際案例

  • 搜尋與推薦：電商的產品知識圖譜（屬性、相容性、替代品）。
  • 金融：反洗錢與詐欺偵測，追蹤人、帳戶、公司之間的關係網。
  • 製藥：連結基因、疾病、藥物、臨床試驗，找出藥物再利用的機會。
  • 供應鏈：多層供應商的風險傳遞（第 63 課）。

🧭 這一課的重點

企業知識圖譜以共同本體連結散落在 ERP、CRM、MES 等系統的資料。RDF 三元組資料庫以 SPARQL、標準化推理與互通見長；屬性圖資料庫以 Cypher 或 GQL 與圖演算法見長，兩者正互相靠近。建構流程包括本體設計、資料對應、實體解析、非結構化抽取、驗證推理與服務。應用涵蓋搜尋推薦、反洗錢、藥物再利用與供應鏈風險。

🕸️ 本課程的程式範例以 Python 為主（rdflib、owlready2 等），Turtle 與 SPARQL 以字串形式出現在 Python 中；Palantir 相關內容依公開資料整理，產品與財務資訊以撰寫時為準。
