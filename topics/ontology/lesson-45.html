政府與開放資料

這一課的目標

  • 認識 DCAT 與資料目錄
  • 理解政府資料標準化的挑戰
  • 認識台灣的政府開放資料與資料標準

DCAT：描述資料集的詞彙

各國政府都有開放資料平台，但每個平台描述資料集的方式不同。W3C 的 DCAT（Data Catalog Vocabulary）提供共同的詞彙：資料目錄（Catalog）、資料集（Dataset）、發布形式（Distribution）、資料服務，以及標題、主題、發布機關、授權、更新頻率等屬性。歐盟在此基礎上制定 DCAT-AP，讓會員國的資料目錄可以彙整搜尋。

from rdflib import Graph, Namespace, Literal, URIRef, RDF from rdflib.namespace import DCAT, DCTERMS EX = Namespace("http://example.org/data#") g = Graph(); g.bind("dcat", DCAT); g.bind("dct", DCTERMS) ds = EX.AirQuality g.add((ds, RDF.type, DCAT.Dataset)) g.add((ds, DCTERMS.title, Literal("空氣品質監測小時值", lang="zh-TW"))) g.add((ds, DCTERMS.publisher, EX.EnvironmentAgency)) g.add((ds, DCAT.keyword, Literal("PM2.5", lang="zh-TW"))) g.add((ds, DCTERMS.license, URIRef("https://data.gov.tw/license"))) dist = EX.AirQualityCSV g.add((ds, DCAT.distribution, dist)) g.add((dist, RDF.type, DCAT.Distribution)) g.add((dist, DCAT.mediaType, URIRef("https://www.iana.org/assignments/media-types/text/csv"))) print(g.serialize(format="turtle"))

跨機關的語意互通

  • 核心詞彙：歐盟的 Core Person、Core Business、Core Location 等，讓各國的「人」「企業」「地址」能對應。
  • 英國：政府發布統一的資料標準與登記簿（registers）。
  • 美國：NIEM（國家資訊交換模型）讓聯邦、州、地方機關在司法、國安、急難等領域交換資料。

台灣

  • 政府資料開放平臺（data.gov.tw）彙整各機關的開放資料集，並有統一的詮釋資料欄位與政府資料開放授權條款。
  • 資料標準：國家發展委員會等單位推動各領域的資料標準（例如地址、交通、觀光的共通格式），以減少同一資料各機關各自定義的問題。
  • 地理資訊：國土資訊系統（NGIS）與 TGOS 地理圖資雲服務提供門牌地址、行政區等共用的參考資料。
  • 醫療：衛福部推動以 HL7 FHIR 為基礎的醫療資料交換，搭配國際術語標準（第 40 課）。

開放資料的星等提升

台灣的開放資料多以 CSV、JSON 發布（三顆星）。要提升到五顆星，關鍵是：用穩定的 IRI 標識行政區、機關、門牌等共通實體，並連結到 Wikidata 或國際標準代碼。這正是本體與鏈結資料能貢獻的地方。

🧭 這一課的重點

W3C 的 DCAT 以 Catalog、Dataset、Distribution、資料服務等詞彙描述資料集，歐盟延伸為 DCAT-AP 以彙整各國目錄。跨機關互通有歐盟核心詞彙、英國登記簿、美國 NIEM。台灣有政府資料開放平臺與統一授權、各領域資料標準、NGIS 與 TGOS 共用圖資，以及以 FHIR 為基礎的醫療資料交換。提升到五星的關鍵是以穩定 IRI 標識共通實體並連結國際標準。

🕸️ 本課程的程式範例以 Python 為主（rdflib、owlready2 等），Turtle 與 SPARQL 以字串形式出現在 Python 中；Palantir 相關內容依公開資料整理，產品與財務資訊以撰寫時為準。
