模組 B｜哲學起源 · 第 8 課

中世紀的共相之爭與奧坎剃刀

這一課的目標

  • 理解共相問題
  • 區分實在論、唯名論與概念論
  • 理解奧坎剃刀在 Ontology 設計中的意義

波菲利在《導論》的開頭，丟下一個他說「太深奧、這裡不談」的問題：種與屬（例如「人」「動物」）是真實存在的東西，還是只存在於心中？如果存在，是有形的還是無形的？是存在於事物之中，還是與事物分離？這就是共相問題，中世紀哲學爭論了好幾百年。

立場主張代表人物
實在論共相真實存在（柏拉圖式：獨立於事物；亞里斯多德式：存在於事物之中）安瑟倫、阿奎那（溫和實在論）
概念論共相是心中的概念，以事物的相似性為基礎阿伯拉爾
唯名論只有個別事物存在，共相只是名字羅瑟林、奧坎

奧坎剃刀

14 世紀的奧坎的威廉是唯名論的代表。後人用一句話概括他的方法論：如無必要，勿增實體。能用較少的存在物解釋現象，就不要假設更多。

為什麼這和 Ontology 工程有關

建模時，我們不斷面對「要不要把這個東西當成一個獨立的類別或實體」的問題：

  • 「紅色」要做成一個類別（紅色的東西）、一個實例（顏色的一種）、還是一個屬性值？
  • 「婚姻」是兩個人之間的一條關係，還是一個有開始日期、結束日期、地點的實體？
  • 「角色」（學生、員工）是類別，還是人在某段時間扮演的東西？（第 25 課）

奧坎剃刀提醒我們：不要為每個名詞都建一個類別，否則本體會膨脹、難以維護。但反過來，該獨立出來的概念沒有獨立（例如把有自己屬性的「婚姻」壓成一條關係），之後就無法記錄它的開始與結束。這是 Ontology 設計中永恆的取捨。

from rdflib import Graph, Namespace, Literal, RDF EX = Namespace("http://example.org/#") g = Graph() # 寫法一：婚姻是一條關係（簡潔，但無法描述婚姻本身） g.add((EX.John, EX.marriedTo, EX.Mary)) # 寫法二：婚姻是一個實體（「具體化」reification），可以有自己的屬性 g.add((EX.Marriage42, RDF.type, EX.Marriage)) g.add((EX.Marriage42, EX.partner, EX.John)) g.add((EX.Marriage42, EX.partner, EX.Mary)) g.add((EX.Marriage42, EX.startDate, Literal("2015-06-20"))) g.add((EX.Marriage42, EX.place, EX.Taipei))

🧭 這一課的重點

共相問題追問種與屬是否真實存在：實在論認為存在（柏拉圖式或亞里斯多德式），概念論認為是心中概念，唯名論認為只有個別事物、共相只是名字。奧坎剃刀主張如無必要勿增實體。Ontology 設計時常面對同樣的取捨：概念該做成類別、實例、屬性值、關係還是實體；過多會膨脹，過少則無法描述，例如婚姻的具體化。

🕸️ 本課程的程式範例以 Python 為主（rdflib、owlready2 等），Turtle 與 SPARQL 以字串形式出現在 Python 中；Palantir 相關內容依公開資料整理，產品與財務資訊以撰寫時為準。
