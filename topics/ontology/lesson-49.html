本體對齊、合併與版本管理

這一課的目標

  • 理解本體對齊的問題與方法
  • 認識 SKOS 對應關係與 SSSOM
  • 理解本體版本管理的做法

不同組織各自建立的本體，常常描述重疊的領域。要整合資料，就要找出兩邊概念的對應：這叫本體對齊（ontology alignment / matching）。

對齊的困難

  • 名稱不同、意思相同：Car 與 Automobile、「客戶」與「顧客」。
  • 名稱相同、意思不同：兩個系統的「客戶」，一個含潛在客戶，一個只算成交客戶。
  • 粒度不同：一邊有「轎車」「休旅車」，另一邊只有「汽車」。
  • 結構不同：一邊把地址當屬性，另一邊把地址當類別。

對齊的方法

方法依據
字串比對標籤的編輯距離、同義詞（WordNet、UMLS）
結構比對上下層類別、屬性是否相似
實例比對兩個類別的實例重疊多少
邏輯驗證對齊後合併，用推理機檢查是否產生不一致
嵌入與 LLM把標籤與定義轉成向量比較相似度，再請 LLM 判斷（第 53 課）

每年的 OAEI（本體對齊評估倡議）競賽會比較各種對齊系統，在解剖學、疾病、生物多樣性等資料集上的表現。

表達對應關係

關係意思強度
owl:equivalentClass邏輯上完全等價最強，會影響推理
rdfs:subClassOf一邊是另一邊的子類別強
skos:exactMatch可以互換使用不影響 OWL 推理
skos:closeMatch相近，部分情況可互換弱
skos:broadMatch／narrowMatch較廣／較窄弱
skos:relatedMatch相關最弱

生物醫學社群提出 SSSOM（Simple Standard for Sharing Ontological Mappings）：用一張 TSV 表格記錄對應關係，並註明信心分數、對應方法（人工、詞彙比對、LLM）、作者，讓對應本身也可追溯。

# 簡單的詞彙對齊：標籤正規化 + 字串相似度，輸出 SSSOM 風格的表格 from difflib import SequenceMatcher import csv, sys A = {"a:Car": "Automobile", "a:Truck": "Lorry", "a:Customer": "Customer"} B = {"b:Auto": "automobile", "b:Truck": "truck", "b:Client": "client", "b:Buyer": "customer"} def norm(s): return s.lower().replace("_", " ").strip() rows = [] for ia, la in A.items(): best = max(B.items(), key=lambda kv: SequenceMatcher(None, norm(la), norm(kv[1])).ratio()) score = SequenceMatcher(None, norm(la), norm(best[1])).ratio() pred = "skos:exactMatch" if score > 0.95 else "skos:closeMatch" if score > 0.6: rows.append([ia, pred, best[0], "semapv:LexicalMatching", round(score, 2)]) w = csv.writer(sys.stdout, delimiter="\t") w.writerow(["subject_id", "predicate_id", "object_id", "mapping_justification", "confidence"]) w.writerows(rows) # 注意：Truck 與 Lorry 是同義詞，純字串比對找不到——需要同義詞庫或嵌入

版本管理

  • 版本 IRI：owl:versionIRI 讓每個發布版本都有固定的網址，使用者可以釘選特定版本。
  • 不要刪除，要棄用：不再使用的類別標記 owl:deprecated true，並以 obo:IAO_0100001（term replaced by）指向替代者；直接刪除會讓引用它的資料斷掉。
  • 語意差異：比較兩個版本時，除了文字 diff，還要比較推論結果的差異（例如某類別的上層類別變了），ROBOT diff 等工具可以做到。
  • 變更紀錄：每次發布附上新增、修改、棄用的術語清單。

🧭 這一課的重點

本體對齊要找出不同本體間概念的對應，困難在於同義異名、同名異義、粒度與結構差異。方法有字串、結構、實例比對、邏輯驗證與嵌入或 LLM，OAEI 競賽評估各系統。對應可用 owl:equivalentClass、subClassOf 或較寬鬆的 SKOS 對應關係表達，SSSOM 以表格記錄信心與方法。版本管理需使用版本 IRI、以 deprecated 棄用而非刪除、比較推論差異並保留變更紀錄。

🕸️ 本課程的程式範例以 Python 為主（rdflib、owlready2 等），Turtle 與 SPARQL 以字串形式出現在 Python 中；Palantir 相關內容依公開資料整理，產品與財務資訊以撰寫時為準。
