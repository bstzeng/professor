Protégé 與 Python 工具鏈

這一課的目標

  • 認識 Protégé 的主要功能
  • 認識 Python 的本體工具
  • 建立一套可自動化的工作流程

Protégé 是史丹佛大學開發的免費開源本體編輯器（最早可追溯到 1980 年代），是全世界最多人使用的 OWL 工具。

Protégé 的主要畫面

分頁用途
Entities → Classes建立類別階層；在右側用 Manchester 語法寫等價類別、上層類別、互斥
Object / Data Properties建立屬性，勾選傳遞、對稱、函數性，設定定義域與值域
Individuals建立個體與屬性值
Reasoner 選單選擇 HermiT、Pellet、ELK，執行分類；推論出的階層以黃色顯示
DL Query輸入類別運算式，查詢它的子類別與實例
Explanation點一個推論結果的問號，看是哪些公理推出來的（除錯不一致時非常重要）

另有網頁版 WebProtégé，適合多人協作編輯。

Python 工具

套件用途
rdflibRDF 圖的讀寫、SPARQL 查詢、序列化
owlready2把 OWL 類別與個體對應成 Python 物件；內建 HermiT 與 Pellet
owlrl在 rdflib 圖上做 RDFS 與 OWL 2 RL 的規則推理
pySHACLSHACL 驗證
pronto讀取 OBO 格式（生物醫學本體）
SPARQLWrapper查詢遠端 SPARQL 端點
morph-kgc用 RML 對應規則把 CSV、資料庫轉成 RDF
py-horned-owl、ROBOT（Java）大型本體的處理與自動化建置
# owlready2：本體像 Python 物件一樣操作 from owlready2 import get_ontology, sync_reasoner, default_world onto = get_ontology("file://library.owl").load() print(list(onto.classes())) # 所有類別 print(onto.Novel.is_a) # 上層類別與限制 print(onto.search(label="*Tolkien*")) # 依標籤搜尋 with onto: sync_reasoner() # HermiT：一致性檢查 + 分類 print(list(default_world.inconsistent_classes())) # 不可滿足的類別（應為空） # 也可以直接用 SPARQL 查 owlready2 的資料庫 print(list(default_world.sparql("SELECT ?b WHERE { ?b a <http://example.org/lib#Novel> }")))

把本體當成程式碼管理

  • 本體檔（Turtle 較適合 diff）放進 Git。
  • 每次提交時，CI 自動執行：推理機一致性檢查、SHACL 驗證、能力問題測試、命名規則檢查。
  • 用 ROBOT 或腳本自動產生發布版本與文件（例如 Widoco、pyLODE 產生 HTML 說明頁）。
  • OBO 社群的 ODK（Ontology Development Kit）把這套流程包成標準範本。

🧭 這一課的重點

Protégé 是史丹佛開發的免費 OWL 編輯器，提供類別、屬性、個體編輯，推理機分類、DL Query 與推論解釋，另有網頁版協作。Python 工具包括 rdflib、owlready2、owlrl、pySHACL、pronto、SPARQLWrapper、morph-kgc 等。實務上應將本體當成程式碼管理：Git 版控，CI 自動做一致性檢查、SHACL 驗證與能力問題測試，並自動產生發布版本與文件。

🕸️ 本課程的程式範例以 Python 為主（rdflib、owlready2 等），Turtle 與 SPARQL 以字串形式出現在 Python 中；Palantir 相關內容依公開資料整理，產品與財務資訊以撰寫時為準。
