Wikidata 與 DBpedia

這一課的目標

  • 認識 Wikidata 的資料模型
  • 理解限定詞與參考來源
  • 認識 DBpedia 與兩者的差別

Wikidata

Wikidata 2012 年由維基媒體基金會推出，是一個任何人都能編輯的結構化知識庫，存放了一億個以上的項目。它是維基百科各語言版本的資訊框、各種 AI 助理與搜尋引擎的重要資料來源。

資料模型

元素識別碼例子
項目（item）Q 開頭Q892 托爾金、Q15228 魔戒
屬性（property）P 開頭P50 作者、P569 出生日期、P31 是…的實例
陳述項目 + 屬性 + 值Q15228 P50 Q892
限定詞附加在陳述上「開始時間」「結束時間」「排名」
參考來源附加在陳述上「來自哪本書、哪個網站」
排名首選／一般／不建議同一屬性有多個值時，哪個是目前正確的

這個模型比單純的 RDF 三元組豐富：每個陳述都可以有時間、來源與可信度，正好解決了第 25 課提到的時間與出處問題。匯出成 RDF 時，Wikidata 用具體化的方式表示陳述。

P31 與 P279

Wikidata 沒有強制使用 OWL，而是用兩個屬性表示類別結構：P31（是…的實例，對應 rdf:type）與 P279（是…的子類別，對應 rdfs:subClassOf）。因為是群眾協作，階層中常有不一致之處，研究者會用推理與 SHACL／ShEx 工具找出問題。

from SPARQLWrapper import SPARQLWrapper, JSON sp = SPARQLWrapper("https://query.wikidata.org/sparql", agent="ontology-course-demo") # 出生在台灣、職業是作家的人，依出生日期排序（含限定詞的寫法見 p:/ps:/pq:） sp.setQuery(''' SELECT ?p ?pLabel ?birth WHERE { ?p wdt:P31 wd:Q5 ; # 是人類 wdt:P106 wd:Q36180 ; # 職業：作家 wdt:P19/wdt:P17 wd:Q865 ; # 出生地所屬國家：台灣（Q865） wdt:P569 ?birth . SERVICE wikibase:label { bd:serviceParam wikibase:language "zh-tw,zh,en". } } ORDER BY ?birth LIMIT 20''') sp.setReturnFormat(JSON) for b in sp.query().convert()["results"]["bindings"]: print(b["birth"]["value"][:10], b["pLabel"]["value"])

DBpedia

DBpedia（2007 年起，萊比錫大學與柏林自由大學等）用程式從維基百科的資訊框自動抽取結構化資料，並建立 DBpedia 本體。它是 LOD 雲的中心節點之一。

WikidataDBpedia
資料來源人工直接編輯（加上機器人）從維基百科自動抽取
語言單一知識庫、多語標籤依維基百科語言版本分開抽取
出處每個陳述可附參考來源來自維基百科頁面
更新即時定期重新抽取

🧭 這一課的重點

Wikidata 2012 年推出，是可協作編輯的結構化知識庫，項目以 Q、屬性以 P 編號，陳述可附限定詞、參考來源與排名，解決時間與出處問題，類別結構以 P31（實例）與 P279（子類別）表示。可透過 SPARQL 端點查詢。DBpedia 自 2007 年從維基百科資訊框自動抽取資料並建立本體，是 LOD 雲中心節點；兩者在資料來源、多語處理、出處與更新方式上不同。

🕸️ 本課程的程式範例以 Python 為主（rdflib、owlready2 等），Turtle 與 SPARQL 以字串形式出現在 Python 中；Palantir 相關內容依公開資料整理，產品與財務資訊以撰寫時為準。
