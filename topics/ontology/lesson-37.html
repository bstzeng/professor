SHACL：資料驗證

這一課的目標

  • 理解 SHACL 與 OWL 的分工
  • 會寫基本的形狀（shape）
  • 用 pySHACL 驗證資料

OWL 在開放世界中做推論，無法回答「這份資料是否完整、是否符合規格」（第 29 課）。2017 年 W3C 推出 SHACL（Shapes Constraint Language），專門用封閉世界的方式驗證 RDF 資料。

OWLSHACL
目的描述概念、推論新知識檢查資料是否符合約束
世界假設開放封閉
「每本書至少一位作者」遇到沒有作者的書推論：它有某位未知的作者報錯：違反約束
「作者的值域是人」遇到作者是一本書推論：那本書也是一個人報錯：值不是 Person

形狀

SHACL 用形狀描述資料應該長什麼樣子：

  • 目標：這個形狀要檢查哪些節點（例如所有 lib:Book 的實例）。
  • 屬性形狀：某個屬性的值要滿足什麼：個數（sh:minCount、sh:maxCount）、型別（sh:datatype、sh:class）、範圍（sh:minInclusive）、格式（sh:pattern）等。
  • 違反時產生一份驗證報告，說明哪個節點、哪個屬性、違反了什麼。
from rdflib import Graph from pyshacl import validate data = Graph().parse(data=''' @prefix lib: <http://example.org/lib#> . lib:LOTR a lib:Book ; lib:title "The Lord of the Rings" ; lib:writtenBy lib:Tolkien ; lib:year 1954 . lib:Silmar a lib:Book ; lib:year "一九七七" . # 沒有書名、年份格式錯 lib:Tolkien a lib:Person . ''', format="turtle") shapes = Graph().parse(data=''' @prefix sh: <http://www.w3.org/ns/shacl#> . @prefix xsd: <http://www.w3.org/2001/XMLSchema#> . @prefix lib: <http://example.org/lib#> . lib:BookShape a sh:NodeShape ; sh:targetClass lib:Book ; sh:property [ sh:path lib:title ; sh:minCount 1 ; sh:datatype xsd:string ] ; sh:property [ sh:path lib:writtenBy ; sh:minCount 1 ; sh:class lib:Person ] ; sh:property [ sh:path lib:year ; sh:datatype xsd:integer ; sh:minInclusive 1450 ; sh:maxInclusive 2100 ] . ''', format="turtle") conforms, report_graph, report_text = validate(data, shacl_graph=shapes, inference="rdfs") print(conforms) # False print(report_text) # 列出 Silmar 缺少書名、缺少作者、年份型別錯誤

SHACL 的其他功能

  • SHACL-SPARQL：用任意 SPARQL 查詢寫自訂約束（例如「借閱日期必須早於到期日」）。
  • SHACL Rules：根據形狀產生新三元組。
  • 形狀可以拿來自動產生表單與文件，因為它精確描述了資料的結構。

ShEx

另一個類似的語言是 ShEx（Shape Expressions），Wikidata 用它來定義各種實體的資料綱要（EntitySchema）。

🧭 這一課的重點

SHACL（2017）以封閉世界驗證 RDF 資料，和 OWL 的開放世界推論分工：同樣的約束，OWL 會推論、SHACL 會報錯。形狀由目標與屬性形狀組成，可約束個數、型別、類別、範圍與格式，違反時產生驗證報告。pySHACL 可在 Python 中驗證。SHACL 還支援 SPARQL 自訂約束、規則與自動產生表單；Wikidata 則用類似的 ShEx。

🕸️ 本課程的程式範例以 Python 為主（rdflib、owlready2 等），Turtle 與 SPARQL 以字串形式出現在 Python 中；Palantir 相關內容依公開資料整理，產品與財務資訊以撰寫時為準。
