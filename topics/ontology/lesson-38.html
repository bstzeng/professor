鏈結資料與 LOD 雲

這一課的目標

  • 理解鏈結資料四原則
  • 認識五星開放資料
  • 認識 LOD 雲中的代表資料集

2006 年，柏納斯–李提出比語意網更務實的鏈結資料（Linked Data）原則：

  1. 用 IRI 為東西命名。
  2. 用 HTTP IRI，讓人可以查詢這些名字。
  3. 有人查詢 IRI 時，用標準格式（RDF、SPARQL）提供有用的資訊。
  4. 包含連到其他 IRI 的連結，讓人可以發現更多東西。

五星開放資料

星等條件例子
★以開放授權放在網路上（任何格式）掃描的 PDF

LOD 雲

依照這些原則發布、彼此連結的資料集，形成了 LOD（Linked Open Data）雲，涵蓋上千個資料集：

  • DBpedia：從維基百科資訊框抽取的知識（第 42 課）。
  • Wikidata：維基媒體的協作知識庫。
  • GeoNames：全球地名。
  • VIAF：各國國家圖書館的作者權威檔整合。
  • UniProt、PubChem：蛋白質與化學物質。
  • 各國政府、圖書館、博物館的開放資料。

owl:sameAs：連結的關鍵

不同資料集對同一個東西有不同的 IRI。用 owl:sameAs 連起來，就能合併它們的描述。但 sameAs 在邏輯上是嚴格的「完全相同」，實務上常被誤用為「大致相同」或「相關」，造成錯誤的推論——這是鏈結資料最常見的品質問題之一。較寬鬆的連結可用 skos:exactMatch、skos:closeMatch。

import requests from rdflib import Graph # 鏈結資料原則 2、3：對 IRI 做 HTTP 請求，透過內容協商取得 RDF iri = "http://www.wikidata.org/entity/Q892" # 托爾金 resp = requests.get(iri, headers={"Accept": "text/turtle"}, timeout=30) g = Graph().parse(data=resp.text, format="turtle") print(len(g), "triples about Tolkien") # 原則 4：沿著連結找到其他資料集的 IRI q = '''SELECT ?o WHERE { ?s <http://www.wikidata.org/prop/direct/P214> ?o }''' # VIAF ID print([str(r.o) for r in g.query(q)])

🧭 這一課的重點

鏈結資料四原則：以 IRI 命名、使用可查詢的 HTTP IRI、查詢時提供 RDF 等標準格式、包含指向其他 IRI 的連結。五星開放資料從開放授權逐步提升到連結他人資料。依此發布的資料集形成 LOD 雲，包括 DBpedia、Wikidata、GeoNames、VIAF、UniProt 等。owl:sameAs 是連結的關鍵，但常被誤用，較寬鬆的對應可用 skos:exactMatch 或 closeMatch。

🕸️ 本課程的程式範例以 Python 為主（rdflib、owlready2 等），Turtle 與 SPARQL 以字串形式出現在 Python 中；Palantir 相關內容依公開資料整理，產品與財務資訊以撰寫時為準。
