圖書分類與生物分類

這一課的目標

  • 認識林奈的生物分類系統
  • 認識圖書館的分類法
  • 理解分面分類的概念

林奈的生物分類（1735）

瑞典博物學家林奈在《自然系統》中建立了階層分類：界、綱、目、屬、種（後來加入門、科），並推廣二名法：每個物種用「屬名 + 種小名」命名，例如智人 Homo sapiens。這是波菲利之樹在自然界的大規模應用。

達爾文之後，分類開始反映演化關係；今天的系統發生學用 DNA 定序重建演化樹，常常推翻傳統的分類（例如鳥類其實是恐龍的後代）。生物分類一再修正，提醒我們：分類是理論，不是不變的真理。

圖書館的分類

系統年代特點
杜威十進分類法1876把知識分成 10 大類（000 總類、100 哲學、200 宗教……），每類再十進細分，例如 510 數學、516 幾何
美國國會圖書館分類法1897 起字母加數字，大型學術圖書館常用
中國圖書分類法1929（賴永祥修訂版廣用於台灣）仿杜威十進，台灣多數圖書館使用
冒號分類法1933（阮甘納桑）分面分類的開創者

分面分類

印度圖書館學家阮甘納桑發現，嚴格的樹狀分類無法處理「台灣十九世紀的茶葉貿易史」這種主題——它該放在台灣、歷史、茶、貿易的哪個分支下？他的解法是分面：先定義幾個獨立的面向（主題、空間、時間、形式……），一本書在每個面向上各取一個值，再組合起來。

電商網站的篩選器（品牌、價格、顏色、尺寸）就是分面分類。從 Ontology 的角度看，分面就是多個獨立的屬性，而不是一棵大樹——這也是 Ontology 比分類法更有彈性的原因（第 3 課）。

# 分面分類：每本書在每個面向上各有一個值，可以任意組合篩選 books = [ {"title": "台灣茶業史", "subject": "茶", "place": "台灣", "period": "19世紀", "form": "專書"}, {"title": "福爾摩沙貿易", "subject": "貿易", "place": "台灣", "period": "19世紀", "form": "論文集"}, {"title": "英國茶文化", "subject": "茶", "place": "英國", "period": "18世紀", "form": "專書"}, ] def facet(items, **conds): return [b["title"] for b in items if all(b[k] == v for k, v in conds.items())] print(facet(books, subject="茶")) # 兩本 print(facet(books, place="台灣", period="19世紀")) # 兩本

🧭 這一課的重點

林奈 1735 年建立界綱目屬種的階層分類與二名法，演化論與系統發生學後來持續修正分類，顯示分類是理論而非不變真理。圖書館有杜威十進分類、國會圖書館分類、台灣常用的中國圖書分類法。阮甘納桑的冒號分類法開創分面分類，以多個獨立面向組合描述主題，即電商篩選器的原理，對應 Ontology 的多個獨立屬性。
