IPv4 耗盡與 IPv6

這一課的目標

  • 理解 IPv4 位址耗盡的原因與影響
  • 理解 NAT 作為權宜之計
  • 了解 IPv6 的推廣

四十三億不夠

IPv4 位址是 32 位元，最多約 43 億個——在網路設計之初看似很多，但遠遠不足以讓全世界每一支手機、每一台電腦、每一個裝置都有一個位址。2011 年，IANA 分配出了最後的 IPv4 大區塊；同年，亞太地區的 APNIC 也進入最後的配額階段。

權宜之計：NAT

網路位址轉換（NAT）讓許多裝置共用一個公開的 IP 位址：你家裡的路由器就在做這件事；行動業者更以大規模的 NAT，讓成千上萬的手機共用少量的位址。NAT 延長了 IPv4 的壽命，但也讓裝置之間難以直接連線（例如網路電話與點對點應用）。IPv4 位址本身也變成可以買賣的資產。

IPv6

  • IPv6 位址是 128 位元，數量多到幾乎用不完。
  • 每個裝置都可以有自己的公開位址，恢復端對端的連線。
  • 但 IPv6 與 IPv4 不相容，轉換需要網路、設備、軟體全面的支援，所以進展緩慢。

近年 IPv6 的使用持續增加，在部分國家與行動網路中已經相當普及；IPv4 與 IPv6 將會長期並存。

🧭 這一課的重點

IPv4 是 32 位元最多約 43 億個不足以讓每個裝置都有位址，2011 年 IANA 分配出最後 IPv4 大區塊同年 APNIC 進入最後配額；NAT 網路位址轉換讓許多裝置共用一個公開 IP 家用路由器在做行動業者大規模 NAT，延長 IPv4 壽命但裝置難以直接連線，IPv4 位址變成可買賣資產；IPv6 是 128 位元幾乎用不完每個裝置可有公開位址恢復端對端，但與 IPv4 不相容轉換需全面支援進展緩慢；近年持續增加部分國家與行動網路相當普及將長期並存。
