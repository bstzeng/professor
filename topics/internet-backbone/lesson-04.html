模組 A｜網路的網路 · 第 4 課

IP 位址從哪裡來

這一課的目標

  • 理解 IP 位址的分配體系
  • 認識區域網際網路註冊機構
  • 了解台灣的位址與網域管理

位址不能重複

每一個在網際網路上能被找到的位址都必須是唯一的，所以需要一套全球的分配體系：

  1. IANA：管理全球的 IP 位址與 AS 號碼總庫，把大區塊分配給各區域。
  2. 五個區域網際網路註冊機構（RIR）：負責各大洲的分配。亞太地區是 APNIC，北美是 ARIN，歐洲與中東是 RIPE NCC，拉丁美洲是 LACNIC，非洲是 AFRINIC。
  3. 國家級註冊機構：部分國家另有，例如台灣的台灣網路資訊中心（TWNIC）。
  4. 業者與機構：從註冊機構取得位址，再分配給客戶。

網段與宣告

位址以「網段」為單位分配，例如 203.0.113.0/24 代表 256 個連續的位址。取得網段的 AS，會用 BGP 向全世界宣告：「這個網段在我這裡。」——但 BGP 本身並不檢查宣告者是否真的擁有這個網段，這是路由劫持的根源（第 14 課）。

TWNIC

台灣網路資訊中心負責 .tw 網域名稱的管理、台灣的 IP 位址與 AS 號碼的分配，也營運 .tw 的 DNS 伺服器。

🧭 這一課的重點

位址必須唯一需要全球分配體系：IANA 管理全球 IP 位址與 AS 號碼總庫分大區塊給各區域、五個區域網際網路註冊機構 RIR 亞太 APNIC 北美 ARIN 歐洲中東 RIPE NCC 拉美 LACNIC 非洲 AFRINIC、部分國家另有國家級如台灣網路資訊中心 TWNIC、業者機構再分給客戶；位址以網段分配如 203.0.113.0/24 代表 256 個連續位址，取得網段的 AS 用 BGP 宣告這網段在我這裡，但 BGP 不檢查宣告者是否真擁有是路由劫持根源；TWNIC 負責 .tw 網域管理台灣 IP 與 AS 號碼分配營運 .tw DNS 伺服器。
