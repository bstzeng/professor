模組總結：細節的作用

這一課的目標

  • 了解細節設定的三項功能
  • 掌握這些資料的使用時機
  • 認識「設定服務故事」的原則

設定模組收尾。這一課談這些細節為什麼重要。

1. 三項功能

功能例子
製造真實感物價、報紙、節慶讓世界像真的在運作
支撐劇情記錄指針的時間、塗層的必要性直接決定行程
承載主題飲食＝承認、船＝歸屬、資訊＝自由

2. 使用時機

  • 懸賞金表：看到新角色登場時對照世界的評價
  • 時間線：遇到回憶篇章時確認前後關係
  • 族群表：新島嶼登場時對照文化背景
  • 果實體系：戰鬥中判斷能力的類型與剋制

3. 設定服務故事

尾田的設定有一個一貫特徵： 每一個設定都會被用來說一件事。

  • 惡魔果實不能游泳 → 在航海世界裡的諷刺
  • 記錄指針要時間 → 每座島都有故事
  • 船靈 → 船是夥伴
  • 生命卡會變小 → 無聲地表達生命流逝

4. 尚未完全揭曉的設定

  • 惡魔果實的真正來源與「真名」系統
  • 霸氣的起源與大筒木／古代王國的關係
  • 海王類與波塞頓的完整機制
  • 月球與古代文明的關聯（空島篇的壁畫）

模組 X 重點回顧

  • 船不是交通工具，是這群人能聚在一起的空間
  • 懸賞金反映的是政治評價，不是戰力
  • 時間線上的數字全部對得上，證明有完整規劃
  • 餵飽一個人＝承認他的存在
  • 每一個設定都會被用來說一件事

  2. 列出四張資料表的適用時機
  3. 舉出三個「設定服務故事」的例子
