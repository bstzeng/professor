怎麼選資料結構：總整理

這一課的目標

  • 整理所有結構的操作成本
  • 用問題驅動的方式選擇結構
  • 練習幾個設計題

選資料結構的第一步：列出最常做的操作，以及它們的頻率。然後找一個讓這些操作都夠快的結構，或者把幾個結構組合起來。

設計練習

  1. 排行榜：即時更新分數、查詢某人的名次、列出前 10 名。→ 平衡樹或跳躍串列（Redis 有序集合），搭配雜湊表從使用者找到節點。
  2. 自動完成：輸入前綴，列出最熱門的 5 個詞。→ 字典樹，每個節點預先存好底下最熱門的 5 個。
  3. 插入、刪除、隨機取一個，全部 O(1)。→ 動態陣列 + 雜湊表（值 → 索引）；刪除時把最後一個元素搬來補洞。
import random class RandomizedSet: def __init__(self): self.a, self.pos = [], {} def insert(self, x): if x in self.pos: return False self.pos[x] = len(self.a); self.a.append(x); return True def remove(self, x): if x not in self.pos: return False i, last = self.pos[x], self.a[-1] self.a[i], self.pos[last] = last, i # 用最後一個補洞 self.a.pop(); del self.pos[x]; return True def get_random(self): return random.choice(self.a)

最後的建議

  • 先用最簡單、標準函式庫就有的結構；量測之後再最佳化。
  • 大 O 決定能不能擴展，常數與快取決定實際快不快。
  • 很多好設計來自組合：雜湊表 + 串列、雜湊表 + 堆積、陣列 + 雜湊表。

🧭 這一課的重點

選資料結構先列出最常做的操作與頻率，再找讓它們都夠快的結構或組合。總表比較了陣列、排序陣列、鏈結串列、雜湊表、平衡樹、堆積、字典樹與跳躍串列。排行榜可用平衡樹或跳躍串列加雜湊表，自動完成用字典樹預存熱門詞，O(1) 隨機集合用動態陣列加雜湊表並以末元素補洞。先用標準結構，量測後再最佳化，好設計常來自組合。
