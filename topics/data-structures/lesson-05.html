抽象資料型別

這一課的目標

  • 理解抽象資料型別（ADT）的概念
  • 區分介面與實作
  • 認識常見的 ADT 與它們的實作方式

抽象資料型別（ADT）只規定一組資料「能做哪些操作」，不規定怎麼實作。使用者只需要知道介面；實作者可以自由選擇最合適的結構，甚至之後換掉。

ADT主要操作常見實作
串列（List）依位置讀寫、插入、刪除動態陣列、鏈結串列
堆疊（Stack）push、pop、top動態陣列、鏈結串列
佇列（Queue）enqueue、dequeue環狀緩衝區、鏈結串列
集合（Set）加入、刪除、是否包含雜湊表、平衡樹
映射（Map／字典）依鍵存取值雜湊表、平衡樹
優先佇列加入、取出最小值二元堆積
圖（Graph）頂點、邊、鄰居鄰接矩陣、鄰接串列

同一個 ADT 用不同實作，效能特性會不同。例如「映射」用雜湊表實作，查詢平均 O(1) 但沒有順序；用平衡樹實作，查詢 O(log n) 但可以按鍵的順序走訪、找範圍。

Python 內建對照

PythonADT底層實作
list串列、堆疊動態陣列
collections.deque佇列、雙端佇列區塊組成的雙向鏈結串列
dict / set映射 / 集合雜湊表（開放定址）
heapq優先佇列用 list 存放的二元堆積
bisect有序串列的搜尋在排好序的 list 上二分搜尋
from collections import deque q = deque() q.append("A"); q.append("B") # enqueue q.popleft() # dequeue → "A"，O(1) # 如果用 list.pop(0)，每次要把後面全部往前搬：O(n)

為什麼要分開

把介面和實作分開，程式比較好維護：上層程式碼不用改，就能把實作換成更快的版本。這也是物件導向「封裝」的核心精神。

🧭 這一課的重點

抽象資料型別只規定可做的操作，不規定實作。串列、堆疊、佇列、集合、映射、優先佇列、圖都是 ADT，可用不同結構實作而有不同效能，例如映射用雜湊表無序但快、用平衡樹有序可找範圍。Python 的 list、deque、dict、set、heapq、bisect 分別對應這些 ADT。介面與實作分離讓程式易於維護與替換。
