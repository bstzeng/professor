LRU 快取

這一課的目標

  • 理解快取與淘汰策略
  • 用雜湊表與雙向鏈結串列實作 LRU
  • 會用 functools.lru_cache

快取把常用的資料放在快速但容量有限的地方（記憶體、CPU 快取、瀏覽器）。滿了之後要丟掉誰？LRU（最近最少使用）策略丟掉「最久沒被用過」的那一個，賭的是「最近用過的，很快又會再用」。

怎麼做到 O(1)

需要兩件事都快：(1) 依鍵找到資料；(2) 維持「最近使用」的順序，並能把任何一筆移到最前面、從最後面刪除。

  • 雜湊表：鍵 → 雙向串列中的節點，O(1) 找到。
  • 雙向鏈結串列：手上有節點時，O(1) 把它拿出來放到最前面；O(1) 刪除尾巴（第 9 課）。
from collections import OrderedDict # 內部就是雜湊表 + 雙向串列 class LRUCache: def __init__(self, cap): self.cap, self.d = cap, OrderedDict() def get(self, key): if key not in self.d: return None self.d.move_to_end(key) # 標記為最近使用 return self.d[key] def put(self, key, val): self.d[key] = val self.d.move_to_end(key) if len(self.d) > self.cap: self.d.popitem(last=False) # 淘汰最久沒用的

一行搞定

from functools import lru_cache @lru_cache(maxsize=1024) def fetch_price(product_id): ... # 很慢的資料庫查詢

其他淘汰策略

策略淘汰誰特點
FIFO最早放進來的簡單，但會丟掉常用的資料
LRU最久沒用的通用、效果好
LFU使用次數最少的適合熱門度穩定的情況
時鐘演算法近似 LRU作業系統的分頁置換常用，成本低

🧭 這一課的重點

LRU 快取在容量滿時淘汰最久沒用的資料。以雜湊表把鍵對應到雙向鏈結串列節點，使查詢、移到最前與刪除尾端都是 O(1)；Python 的 OrderedDict 正是這種組合，functools.lru_cache 一行即可使用。其他策略有 FIFO、LFU 與作業系統常用的時鐘演算法。
