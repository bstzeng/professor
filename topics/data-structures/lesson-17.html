雜湊表的應用與 Python 的 dict、set

這一課的目標

  • 熟悉 dict、set、Counter 的用法
  • 用雜湊表把 O(n²) 降成 O(n)
  • 知道 dict 能保持插入順序的原因

雜湊表可能是實務上最常用的資料結構。很多 O(n²) 的問題，換成雜湊表就變成 O(n)。

經典：兩數之和

在陣列中找出兩個數，和為 target。暴力法試所有配對 O(n²)。改成一邊走、一邊把看過的數記在 dict 裡，對每個數只要問「target − x 看過沒？」：

def two_sum(nums, target): seen = {} # 值 → 索引 for i, x in enumerate(nums): if target - x in seen: # O(1) 查詢 return seen[target - x], i seen[x] = i return None

常見用法

需求工具例子
計數collections.Counter統計每個字出現幾次
去除重複setlist(set(data))
分組defaultdict(list)把同字母異序詞分在一起：鍵用 sorted(word)
記憶化（快取函數結果）dict 或 @functools.cache費氏數列從 O(φⁿ) 變 O(n)
快速判斷是否出現過set網路爬蟲記錄拜訪過的網址
from collections import Counter, defaultdict Counter("mississippi").most_common(2) # [('i', 4), ('s', 4)] groups = defaultdict(list) for w in ["eat", "tea", "tan", "ate", "nat"]: groups["".join(sorted(w))].append(w) # {'aet': ['eat','tea','ate'], 'ant': ['tan','nat']}

Python dict 的內部

從 Python 3.6 起，dict 改用「緊湊」設計：一個小的索引陣列（開放定址）＋一個依插入順序存放的項目陣列。這樣不但省記憶體，也剛好保持插入順序，3.7 起正式成為語言規格。

鍵必須可雜湊

dict 的鍵與 set 的元素必須是不可變的（int、str、tuple 可以；list、dict 不行）。因為如果鍵放進去之後內容改了，雜湊值也會變，就再也找不到了。

🧭 這一課的重點

雜湊表能把許多 O(n²) 問題降為 O(n)，例如兩數之和邊走邊查 target − x。Counter 計數、set 去重、defaultdict 分組、dict 記憶化與記錄造訪都是常見用法。Python 3.6 起 dict 採緊湊設計，省記憶體並保持插入順序（3.7 起為規格）。鍵必須不可變才能雜湊。
