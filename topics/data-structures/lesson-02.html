記憶體、位址與參考

這一課的目標

  • 理解記憶體是一排有編號的格子
  • 理解指標與參考的概念
  • 理解 Python 變數其實是參考

電腦的記憶體可以想成一長排有編號的格子，編號叫做位址。每格存一個位元組（8 個位元）。一個整數通常佔 4 或 8 格。

  • 連續存放：知道起點位址和每個元素的大小，就能直接算出第 i 個元素在哪：位址 = 起點 + i × 大小。這就是陣列。
  • 用指標串起來：每個元素旁邊記下「下一個在哪個位址」，元素可以散落在任何地方。這就是鏈結串列。

幾乎所有資料結構，都是這兩種方式的組合。

指標與參考

指標就是一個存著位址的變數。C 語言直接操作指標；Python、Java 則用比較安全的參考：變數不是「裝著」物件，而是「指著」物件。

a = [1, 2, 3] b = a # b 和 a 指向同一個串列，沒有複製 b.append(4) print(a) # [1, 2, 3, 4] ← a 也變了！ c = a.copy() # 真的複製一份 c.append(5) print(a) # [1, 2, 3, 4] ← a 不受影響

這也是 Python 新手最常遇到的陷阱之一：[[0] * 3] * 3 建出來的三列其實是同一個串列的三個參考，改一列三列一起變。

記憶體階層

層級大約延遲容量
CPU 暫存器< 1 奈秒幾百個位元組
L1 快取約 1 奈秒數十 KB
L3 快取約 10 奈秒數十 MB
主記憶體（RAM）約 100 奈秒數十 GB
固態硬碟（SSD）約 0.1 毫秒TB 級
網路另一端的機器約 1～100 毫秒無限

從快取讀和從 RAM 讀差了約 100 倍。連續存放的資料一次會被整塊載入快取，所以「連續」本身就是一種速度優勢（第 47 課會再談）。

🧭 這一課的重點

記憶體是一排有位址的格子。資料可以連續存放（陣列，用起點加偏移直接定位）或用指標串起來（鏈結結構，可散落各處），幾乎所有資料結構都是兩者的組合。Python 變數是指向物件的參考，指定不會複製。記憶體階層從暫存器到網路相差數個數量級，連續存放有快取優勢。
