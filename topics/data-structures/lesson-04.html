攤銷分析

這一課的目標

  • 理解攤銷成本的意義
  • 用動態陣列理解攤銷 O(1)
  • 區分攤銷與平均情況

有些操作大部分時候很便宜，偶爾很貴。只看最壞的那一次會太悲觀。攤銷分析看的是：一連串 n 次操作的總成本，平均分到每一次是多少。

例子：動態陣列

Python 的 list 一開始只配置少量空間。滿了之後，配置一塊更大的新空間（例如兩倍），把所有元素搬過去。搬一次要 O(n)，但搬完之後可以便宜地放好多次。

容量倍增時，從 1 長到 n 的過程中，搬移的總量是 1 + 2 + 4 + ⋯ + n/2 < n。加上每次本身寫入的 n 次，總成本 < 3n，所以平均每次 append 是 O(1)。

攤銷 ≠ 平均情況

平均情況是對隨機輸入取平均，運氣不好可能每次都慢。攤銷是對一連串操作取平均，是保證：不管怎麼操作，n 次的總成本一定不超過那個上界。

會計法的直覺

想像每次 append 付 3 元：1 元付自己的寫入，2 元存起來。等到要擴容時，存下來的錢剛好夠付搬家費。這種「預先存錢」的思考方式叫做會計法，是證明攤銷成本的常用技巧。

🧭 這一課的重點

攤銷分析看一連串操作的總成本平均到每次。動態陣列滿了就倍增容量並搬移元素，偶爾 O(n)，但搬移總量小於 n，所以 append 攤銷 O(1)；若每次只加固定格數則總成本 O(n²)。攤銷是對操作序列的保證，不同於對隨機輸入的平均情況；會計法以預存成本來證明。
