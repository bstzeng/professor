減法、溢位與 ALU

這一課的目標

  • 用加法器做減法
  • 推導有號溢位的判斷
  • 設計並驗證 RV32I 用的 32 位元 ALU

減法

\(a - b = a + \bar{b} + 1\)：把 \(b\) 每一位接 XOR（控制訊號 sub = 1 時反相），再把 sub 接到最低位的 \(c_{in}\)。一個加法器加 \(N\) 個 XOR，就同時能加能減。

溢位

有號加法的結果超出 \([-2^{N-1}, 2^{N-1}-1]\) 時發生溢位。只有兩個同號的數相加才可能溢位，而且溢位時結果的符號會「翻過去」。等價的硬體判斷：

\[ V = c_{N} \oplus c_{N-1} \]

即「進入最高位的進位」與「離開最高位的進位」不同。證明：最高位 \(a_{N-1} = b_{N-1} = 0\) 時 \(c_N = 0\)，若 \(c_{N-1} = 1\) 則結果為負——正 + 正得負；\(a_{N-1} = b_{N-1} = 1\) 時 \(c_N = 1\)，若 \(c_{N-1} = 0\) 則結果為正——負 + 負得正；異號時兩者必相同。

例（8 位元）無號解讀有號解讀CV
100 + 50150 ✓−106 ✗01
200 + 10044 ✗−56 + 100 = 44 ✓10
100 − 3763 ✓63 ✓10

注意：無號加法的溢位看 C，有號加法的溢位看 V，兩者完全獨立。RISC-V 的整數指令不偵測溢位（需要時由軟體檢查），這也是一種設計選擇。

ALU

算術邏輯單元把加減法、邏輯運算、比較、移位放在一起，用運算碼選擇結果。概念上就是各種運算平行計算、最後用一個大多工器挑出結果。下面是本課程 CPU 使用的 32 位元 ALU，支援 RV32I 需要的十種運算，另外輸出 zero 給分支指令用：

🔧 範例：alu　執行：iverilog -g2012 -o alu alu.v tb_alu.v && vvp alu

同一個檔案也包含第 25 課的桶式移位器。測試平台檢查每種運算、有號與無號比較的差異，並用 10000 筆亂數比對桶式移位器。

📄 alu.v　下載

// alu.v：RV32I 用的 32 位元 ALU module alu(input [31:0] a, input [31:0] b, input [3:0] op, output reg [31:0] y, output zero); localparam ADD = 4'd0, SUB = 4'd1, AND = 4'd2, OR = 4'd3, XOR = 4'd4, SLT = 4'd5, SLTU = 4'd6, SLL = 4'd7, SRL = 4'd8, SRA = 4'd9; always @(*) begin case (op) ADD: y = a + b; SUB: y = a - b; AND: y = a & b; OR: y = a | b; XOR: y = a ^ b; SLT: y = ($signed(a) < $signed(b)) ? 32'd1 : 32'd0; // 有號比較 SLTU: y = (a < b) ? 32'd1 : 32'd0; // 無號比較 SLL: y = a << b[4:0]; // 只取低 5 位當移位量 SRL: y = a >> b[4:0]; // 邏輯右移：補 0 SRA: y = $signed(a) >>> b[4:0]; // 算術右移：補符號位 default: y = 32'd0; endcase end assign zero = (y == 32'd0); endmodule // barrel.v 的概念：32 位元桶式左移器，用 5 層 2 選 1 多工器組成 module barrel_sll(input [31:0] a, input [4:0] sh, output [31:0] y); wire [31:0] s0 = sh[0] ? {a[30:0], 1'b0} : a; // 移 1 wire [31:0] s1 = sh[1] ? {s0[29:0], 2'b0} : s0; // 移 2 wire [31:0] s2 = sh[2] ? {s1[27:0], 4'b0} : s1; // 移 4 wire [31:0] s3 = sh[3] ? {s2[23:0], 8'b0} : s2; // 移 8 assign y = sh[4] ? {s3[15:0], 16'b0} : s3; // 移 16 endmodule

📄 tb_alu.v　下載

module tb_alu; reg [31:0] a, b; reg [3:0] op; wire [31:0] y; wire zero; alu dut(a, b, op, y, zero); reg [31:0] x; reg [4:0] sh; wire [31:0] ys; barrel_sll bs(x, sh, ys); integer i, err, seed; initial begin a = 32'd7; b = 32'd5; for (i = 0; i < 10; i = i + 1) begin op = i; #1 $display("op=%0d 7, 5 -> %0d", op, $signed(y)); end a = -32'sd8; b = 32'd1; op = 5; #1 $display("slt(-8, 1) = %0d (signed: -8 < 1)", y); op = 6; #1 $display("sltu(-8, 1) = %0d (unsigned: 0xFFFFFFF8 > 1)", y); op = 8; #1 $display("srl(-8, 1) = 0x%h", y); op = 9; #1 $display("sra(-8, 1) = %0d", $signed(y)); a = 32'd42; b = 32'd42; op = 1; #1 $display("42 - 42 = %0d, zero = %b", y, zero); err = 0; seed = 1; for (i = 0; i < 10000; i = i + 1) begin x = $random(seed); sh = $random(seed); #1 if (ys !== (x << sh)) err = err + 1; end $display("barrel shifter: 10000 random tests, errors = %0d", err); end endmodule

▶ 模擬結果（實際執行的輸出）

op=0 7, 5 -> 12 op=1 7, 5 -> 2 op=2 7, 5 -> 5 op=3 7, 5 -> 7 op=4 7, 5 -> 2 op=5 7, 5 -> 0 op=6 7, 5 -> 0 op=7 7, 5 -> 224 op=8 7, 5 -> 0 op=9 7, 5 -> 0 slt(-8, 1) = 1 (signed: -8 < 1) sltu(-8, 1) = 0 (unsigned: 0xFFFFFFF8 > 1) srl(-8, 1) = 0x7ffffffc sra(-8, 1) = -4 42 - 42 = 0, zero = 1 barrel shifter: 10000 random tests, errors = 0

幾個值得注意的地方：$signed() 告訴 Verilog 用有號方式解讀位元；>>> 是算術右移；移位量只取低 5 位（RISC-V 規格如此，32 位元最多移 31）。結果驗證了第 2 課的要點：同樣的 −8 與 1，有號比較為真、無號比較為假。

合成時，a + b 與 a - b 會被共用成一個加法器加 XOR（資源共享），比較也會用減法器的結果。真實 CPU 的 ALU 還會把加法器、移位器、邏輯單元分成不同的執行單元，以便同時發出多條指令。

🧭 這一課的重點

a − b = a + b̄ + 1：一個加法器配 N 個 XOR 與 sub 控制即可加減。有號溢位只在同號相加時發生，V = c_N ⊕ c_{N−1}；無號溢位看進位 C，兩者獨立。ALU 將各種運算平行計算後以多工器選擇，本課程的 32 位元 ALU 支援 ADD、SUB、AND、OR、XOR、SLT、SLTU、SLL、SRL、SRA 與 zero 輸出，以 Verilog 模擬驗證。

🔌 本課程的 Verilog 範例都用 Icarus Verilog 12 實際編譯、模擬過，頁面上的「模擬結果」就是當時的輸出；所有範例可以整包下載。時間單位與延遲數字是教學用的假設值，真實晶片的閘延遲在皮秒等級。
