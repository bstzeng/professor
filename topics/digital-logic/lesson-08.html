最小項、最大項：SOP 與 POS

這一課的目標

  • 由真值表寫出標準積之和與標準和之積
  • 使用 Σm 與 ΠM 記號
  • 理解兩級邏輯的標準形式

三個變數 \(A, B, C\) 的最小項是包含每個變數（原式或反相）恰好一次的乘積，例如 \(A'BC\)。它只在一列真值表為 1。把列號 \(ABC = 011 = 3\) 當成編號，記為 \(m_3\)。最大項則是和，只在一列為 0：\(M_3 = A + B' + C'\)。注意 \(M_i = m_i'\)。

7111ABCA′ + B′ + C′0

標準積之和（canonical SOP）：把 F = 1 的列的最小項 OR 起來。

\[ F = \sum m(1, 3, 5, 6) = A'B'C + A'BC + AB'C + ABC' \]

標準和之積（canonical POS）：把 F = 0 的列的最大項 AND 起來。

\[ F = \prod M(0, 2, 4, 7) = (A+B+C)(A+B'+C)(A'+B+C)(A'+B'+C') \]

兩者描述同一個函數。這直接證明了 {AND, OR, NOT} 的功能完備性：任何真值表都能寫成 SOP。補函數則是互換清單：\(F' = \sum m(0, 2, 4, 7)\)。

兩級邏輯

SOP 對應一層 AND 加一層 OR（若不算反相器），理想上只有兩級閘延遲，無論函數多複雜。這是 PLA 與早期可程式邏輯的結構（第 26 課）。但標準形式往往非常冗長：上例有 4 個三輸入乘積，化簡後是

\[ F = A'C + B'C + ABC' \]

要如何系統化地找到最簡的 SOP？下一課的卡諾圖。

n 個變數有多少函數？

真值表有 \(2^n\) 列，每列可填 0 或 1，所以共有 \(2^{2^n}\) 個布林函數。兩個變數有 16 個（包括 AND、OR、XOR、NAND…），四個變數就有 65536 個，六個變數超過 \(1.8\times10^{19}\)。FPGA 的 6 輸入查表（第 49 課）可以實作其中任何一個。

🧭 這一課的重點

最小項 mᵢ 是只在第 i 列為 1 的乘積，最大項 Mᵢ = mᵢ′ 只在第 i 列為 0。標準 SOP = Σm（F = 1 的列），標準 POS = ΠM（F = 0 的列）。任何真值表都能寫成 SOP，證明 {AND, OR, NOT} 完備；SOP 對應兩級 AND-OR 電路。n 個變數共有 2^(2^n) 個布林函數。
