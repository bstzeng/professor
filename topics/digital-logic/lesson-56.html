回到最初的問題

「CPU 裡每個電晶體都有延遲，訊號怎麼處理？」現在可以完整回答：每個閘的延遲是 RC 充放電（第 12 課）；延遲沿路徑累積，最長的一條決定時脈週期（第 14、41 課）；不同路徑延遲不同會產生毛刺，但同步設計只在時脈邊緣取樣，毛刺來不及造成影響（第 15～17 課）；正反器需要資料在邊緣前後穩定一小段時間，否則可能亞穩（第 32、33 課）；要更快，就改用更好的演算法（超前進位）或把路徑切短（管線化）（第 22、54 課）。整顆晶片的時序由 STA 工具保證（〈晶片 Layout 設計〉第 30 課）。

自己動手

  1. 下載本課程的 Verilog 範例，安裝 Icarus Verilog（Linux：apt install iverilog；macOS：brew install icarus-verilog；Windows 有安裝程式），執行 ./run_all.sh。
  2. 修改 prog.s 寫你自己的程式（例如排序），重新組譯並執行。
  3. 為 rv_single.v 加上缺少的指令：sra、sltu、bltu、auipc、位元組載入儲存。
  4. 把它改成五級管線（第 54 課）。
  5. 買一塊 FPGA 開發板，把 CPU 燒進去，用 LED 顯示結果。

🧭 這一課的重點

本課程從數位抽象與 CMOS 閘出發，經過布林代數、延遲與時序、組合元件、閂鎖器與正反器、有限狀態機、Verilog、記憶體，最後建出一顆執行 RISC-V 程式的單週期 CPU 並討論多週期與管線化。每一層都把下一層的細節藏起來，這種抽象化是數十億電晶體能被設計出來的原因；而延遲問題由同步設計、時序分析與更好的結構共同解決。

🔌 本課程的 Verilog 範例都用 Icarus Verilog 12 實際編譯、模擬過，頁面上的「模擬結果」就是當時的輸出；所有範例可以整包下載。時間單位與延遲數字是教學用的假設值，真實晶片的閘延遲在皮秒等級。
