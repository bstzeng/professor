路徑延遲與關鍵路徑

這一課的目標

  • 計算組合電路中每條路徑的延遲
  • 找出關鍵路徑
  • 在 Verilog 模擬中看到「時脈太快」的後果

組合電路的延遲不是某一個閘的延遲，而是從輸入到輸出所有路徑中最長的那一條：

\[ t_{pd}(\text{電路}) = \max_{\text{路徑}} \sum_{\text{路徑上的閘}} t_{pd,i}, \qquad t_{cd}(\text{電路}) = \min_{\text{路徑}} \sum t_{cd,i} \]

最長的路徑稱為關鍵路徑。要讓電路變快，只能縮短關鍵路徑；優化其他路徑完全沒有用（直到它們變成新的關鍵路徑）。靜態時序分析（STA）工具就是對整顆晶片做這件事：把電路當成一張有向無環圖，用拓樸排序在線性時間內算出每個節點的最晚到達時間（〈晶片 Layout 設計〉第 30 課）。

漣波進位加法器的關鍵路徑

在 8 位元漣波進位加法器裡，若每個閘延遲 1 ns：第 0 位的進位要經過 XOR（或 AND）、AND、OR 才出來，之後每一位多兩級（AND、OR），最後一位的和再加一個 XOR。最長路徑約

\[ t \approx 3 + 2\times 6 + 1 = 16 \text{ ns} \]

但這條路徑只有在進位真的一路傳上去時才會被觸發，例如 127 + 1 或 255 + 1。3 + 4 這種不產生進位的加法很快就算完。

實驗：時脈太快會怎樣

下面的範例把這個加法器夾在兩排暫存器之間：每個時脈邊緣把新的 a、b 打進去，同時把上一拍的結果存起來。我們用 30、10、6 ns 三種時脈週期跑同一組資料。

🔧 範例：timing　執行：iverilog -g2012 -o timing timing.v tb_timing.v && vvp timing

📄 timing.v　下載

// timing.v：時脈太快會怎樣？ // 兩排暫存器之間夾一個 8 位元漣波進位加法器，每個閘延遲 1 ns `timescale 1ns/1ps module fa_d(input a, input b, input cin, output s, output cout); wire p, g, t; xor #1 x1(p, a, b); xor #1 x2(s, p, cin); and #1 a1(g, a, b); and #1 a2(t, p, cin); or #1 o1(cout, g, t); endmodule module adder8_d(input [7:0] a, input [7:0] b, output [7:0] s); wire [8:0] c; assign c[0] = 1'b0; genvar i; generate for (i = 0; i < 8; i = i + 1) begin : st fa_d fa(a[i], b[i], c[i], s[i], c[i+1]); end endgenerate endmodule // 暫存器 → 加法器 → 暫存器：每個時脈把新的 a、b 打進來，同時把上一拍的和存起來 module reg_adder_reg(input clk, input [7:0] a_in, input [7:0] b_in, output reg [7:0] sum); reg [7:0] a, b; wire [7:0] s; adder8_d add(a, b, s); always @(posedge clk) begin a <= a_in; b <= b_in; sum <= s; end endmodule

📄 tb_timing.v　下載

`timescale 1ns/1ps // 每個時脈送進一組新的 a、b；加法器只有「一個週期」的時間算出結果 module tb_timing; reg clk = 0; reg [7:0] a_in, b_in; wire [7:0] sum; reg_adder_reg dut(clk, a_in, b_in, sum); reg [7:0] A [0:5], Bv [0:5]; integer period, i, err; task run(input integer p); begin period = p; err = 0; $display("--- clock period %0d ns ---", p); for (i = 0; i < 8; i = i + 1) begin a_in = A[i % 6]; b_in = Bv[i % 6]; #(p / 2) clk = 1; #(p - p / 2) clk = 0; // 一個時脈週期 if (i >= 1) begin // sum 是上一拍送進去的那一組 $display(" %3d + %3d = %3d (expected %3d) %s", A[(i - 1) % 6], Bv[(i - 1) % 6], sum, (A[(i - 1) % 6] + Bv[(i - 1) % 6]) & 8'hFF, (sum == ((A[(i - 1) % 6] + Bv[(i - 1) % 6]) & 8'hFF)) ? "" : "<-- WRONG"); if (sum != ((A[(i - 1) % 6] + Bv[(i - 1) % 6]) & 8'hFF)) err = err + 1; end end $display(" errors: %0d / 7", err); end endtask initial begin A[0] = 0; Bv[0] = 0; A[1] = 127; Bv[1] = 1; // 進位從第 0 位傳到第 7 位：最長路徑 A[2] = 0; Bv[2] = 0; A[3] = 255; Bv[3] = 1; A[4] = 3; Bv[4] = 4; // 沒有進位：很快 A[5] = 100; Bv[5] = 27; run(30); run(10); run(6); $finish; end endmodule

▶ 模擬結果（實際執行的輸出）

--- clock period 30 ns --- 0 + 0 = 0 (expected 0) 127 + 1 = 128 (expected 128) 0 + 0 = 0 (expected 0) 255 + 1 = 0 (expected 0) 3 + 4 = 7 (expected 7) 100 + 27 = 127 (expected 127) 0 + 0 = 0 (expected 0) errors: 0 / 7 --- clock period 10 ns --- 0 + 0 = 0 (expected 0) 127 + 1 = 96 (expected 128) <-- WRONG 0 + 0 = 0 (expected 0) 255 + 1 = 224 (expected 0) <-- WRONG 3 + 4 = 7 (expected 7) 100 + 27 = 127 (expected 127) 0 + 0 = 0 (expected 0) errors: 2 / 7 --- clock period 6 ns --- 0 + 0 = 0 (expected 0) 127 + 1 = 120 (expected 128) <-- WRONG 0 + 0 = 0 (expected 0) 255 + 1 = 248 (expected 0) <-- WRONG 3 + 4 = 15 (expected 7) <-- WRONG 100 + 27 = 127 (expected 127) 0 + 0 = 0 (expected 0) errors: 3 / 7

30 ns 時全部正確。10 ns 時，127 + 1 與 255 + 1 錯了——正是進位要傳很遠的那兩筆；結果 96（0110 0000）表示高位還沒等到進位就被存進去了。6 ns 時連 3 + 4 都錯了：因為上一筆 255 + 1 的進位「漣漪」還沒平息，新資料就進來了——延遲不只取決於現在的輸入，也取決於前一個狀態。

這正是時序設計的核心：時脈週期必須大於最壞情況的路徑延遲，即使那條路徑很少被用到。下一課開始處理延遲帶來的另一個問題：毛刺。

🧭 這一課的重點

組合電路的 t_pd 是所有路徑延遲中的最大值，t_cd 是最小值；最長的路徑稱為關鍵路徑，只有縮短它才能讓電路變快。STA 用拓樸排序在線性時間內算出關鍵路徑。8 位元漣波加法器的關鍵路徑是進位鏈；Verilog 實驗顯示時脈週期小於最壞路徑延遲時，長進位的加法以及緊接其後的運算都會出錯。

🔌 本課程的 Verilog 範例都用 Icarus Verilog 12 實際編譯、模擬過，頁面上的「模擬結果」就是當時的輸出；所有範例可以整包下載。時間單位與延遲數字是教學用的假設值，真實晶片的閘延遲在皮秒等級。
