比較器

這一課的目標

  • 設計相等比較器
  • 由高位往低位推導大小比較器
  • 用減法實作有號與無號比較

相等

兩個 \(N\) 位元的數相等，當且僅當每一位都相同：

\[ EQ = \prod_{i} (a_i \odot b_i) = \Big(\sum_i (a_i \oplus b_i)\Big)' \]

也就是 \(N\) 個 XOR 加一個大 NOR（用樹狀實作，\(\log N\) 級）。快取的標籤比對、TLB 查詢每個週期都要做大量的相等比較。

大小（無號）

從最高位往下看：第一個不同的位元決定大小。定義 \(e_i = a_i \odot b_i\)（XNOR），則

\[ GT = a_{n-1}b_{n-1}' + e_{n-1}a_{n-2}b_{n-2}' + e_{n-1}e_{n-2}a_{n-3}b_{n-3}' + \cdots \]

這和超前進位的式子形狀一模一樣（第 22 課），也可以用前綴樹加速。實際上大多數處理器根本不做獨立的比較器：直接用減法。

用減法比較

計算 \(a - b = a + \bar b + 1\)，看結果的旗標：

比較條件說明
a = bZ = 1結果為零
a < b（無號）C = 0沒有進位 = 有借位
a < b（有號）N ⊕ V = 1符號位與溢位不同

有號比較為什麼要看溢位？例如 8 位元 \(100 - (-50) = 150\) 超出範圍，結果的位元樣式是 \(-106\)（符號位 N = 1），但正確答案是 a > b。溢位 V = 1 正好把它修正回來。RISC-V 的 slt 與 sltu 就分別做這兩種比較（第 23 課的 ALU 範例會實際驗證：\(-8 < 1\) 有號為真、無號為假）。

ARM 與 x86 的旗標，RISC-V 的選擇

x86 與 ARM 把 N、Z、C、V 存在旗標暫存器，後面的條件跳躍再讀它；RISC-V 刻意不要旗標暫存器，比較直接寫在分支指令裡（blt、bgeu 等），或用 slt 寫進一般暫存器。少了旗標，管線與亂序執行少了一個共享的相依來源。

🧭 這一課的重點

相等比較 = 逐位 XNOR 後全部 AND（或 XOR 後 NOR）。大小比較從最高位找第一個不同的位，式子與超前進位同形，可用前綴樹加速。實務上用減法：Z = 1 為相等，無號 a < b 看 C = 0，有號 a < b 看 N ⊕ V。RISC-V 不使用旗標暫存器，直接在分支或 slt/sltu 中比較。

🔌 本課程的 Verilog 範例都用 Icarus Verilog 12 實際編譯、模擬過，頁面上的「模擬結果」就是當時的輸出；所有範例可以整包下載。時間單位與延遲數字是教學用的假設值，真實晶片的閘延遲在皮秒等級。
