布林代數的公理與定理

這一課的目標

  • 列出布林代數的基本定理
  • 理解對偶原理
  • 用代數化簡布林式

1854 年布爾提出邏輯的代數；1937 年夏農在碩士論文中證明，繼電器開關電路可以完全用布爾代數分析與設計——這是數位邏輯設計的起點。

名稱AND 形式OR 形式
單位元\(A\cdot 1 = A\)\(A + 0 = A\)
零元\(A \cdot 0 = 0\)\(A + 1 = 1\)
冪等\(AA = A\)\(A + A = A\)
互補\(AA' = 0\)\(A + A' = 1\)
對合\((A')' = A\)
交換\(AB = BA\)\(A + B = B + A\)
結合\((AB)C = A(BC)\)\((A+B)+C = A+(B+C)\)
分配\(A(B + C) = AB + AC\)\(A + BC = (A+B)(A+C)\)
吸收\(A(A + B) = A\)\(A + AB = A\)
合併\(AB + AB' = A\)\((A+B)(A+B') = A\)
共識\(AB + A'C + BC = AB + A'C\)\((A+B)(A'+C)(B+C) = (A+B)(A'+C)\)

注意 OR 對 AND 的分配律 \(A + BC = (A+B)(A+C)\) 在普通代數中不成立，在布林代數中卻成立。

對偶原理

把一個恆等式中的 AND ↔ OR、0 ↔ 1 全部互換，得到的式子仍然成立。上表每一列的左右兩欄就是彼此的對偶。這也對應到 CMOS 的上拉／下拉網路互為對偶（第 4 課）。

代數化簡範例

化簡 \(F = A'B'C + A'BC + AB'C + ABC'\)：

\[ \begin{aligned} F &= A'C(B' + B) + AB'C + ABC' \\ &= A'C + AB'C + ABC' \\ &= C(A' + AB') + ABC' \\ &= C(A' + B') + ABC' \\ &= A'C + B'C + ABC' \end{aligned} \]

第四步用了 \(A' + AB' = A' + B'\)（由分配律 \(A' + AB' = (A'+A)(A'+B')\)）。代數化簡需要經驗，而且無法保證結果最簡；第 9、10 課的卡諾圖與 Quine–McCluskey 是系統化的方法。

共識定理的證明

\[ BC = BC(A + A') = ABC + A'BC \]

\(ABC\) 被 \(AB\) 吸收、\(A'BC\) 被 \(A'C\) 吸收，所以 \(BC\) 是多餘的。邏輯上多餘，但在第 17 課我們會看到：加回這個多餘項正好可以消除毛刺。

🧭 這一課的重點

布林代數的基本定理包括單位元、零元、冪等、互補、對合、交換、結合、兩種分配律、吸收、合併與共識定理；每個恆等式都有對偶式（AND↔OR、0↔1）。代數化簡可行但無系統保證最簡。共識項 BC 在 AB + A′C 中邏輯上多餘，卻能消除毛刺。

檢查你的理解

  1. 寫出 A + BC = (A + B)(A + C) 的對偶式。
  2. 證明 A + A′B = A + B。
  3. 化簡 AB + A′C + BC。
