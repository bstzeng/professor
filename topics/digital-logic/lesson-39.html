FSM 設計流程

這一課的目標

  • 依步驟把規格轉成狀態圖、狀態表與邏輯式
  • 比較二進位、格雷碼、one-hot 狀態編碼
  • 用三段式寫法撰寫 Verilog FSM

六個步驟

  1. 理解規格：輸入、輸出是什麼？Moore 還是 Mealy？
  2. 畫狀態圖：每個狀態代表「到目前為止需要記住的資訊」。
  3. 狀態化簡：合併等價狀態（對所有輸入序列輸出都相同者）。
  4. 狀態編碼：給每個狀態一組位元。
  5. 推導下一狀態與輸出邏輯：寫出狀態表，用卡諾圖化簡。
  6. 實作與驗證：寫 Verilog、寫測試平台。

狀態編碼

編碼5 個狀態需要特性
二進位3 個正反器最少正反器；下一狀態邏輯可能較複雜
格雷碼3 個依序轉移的狀態只變一位，減少切換與毛刺
one-hot5 個每個狀態一個正反器；下一狀態邏輯很簡單、很快；FPGA 正反器多，合成工具常自動選它

手算：1011 偵測器（Moore，二進位編碼）

編碼 S0 = 000、S1 = 001、S10 = 010、S101 = 011、S1011 = 100。狀態表（\(q_2q_1q_0\)，輸入 x）：

目前x = 0x = 1y
000 S00000010
001 S10100010
010 S100000110
011 S1010101000
100 S10110100011

101、110、111 不會出現，是無關項。用卡諾圖化簡（4 個變數 \(q_2q_1q_0x\)）可得

\[ q_2^+ = q_1q_0x, \quad q_1^+ = q_0x' + q_1q_0'x + q_2x' , \quad q_0^+ = x\,(q_1q_0)' , \quad y = q_2 \]

例如 \(q_1^+\) 的最小項是 \(q_2q_1q_0x\) = 0010、0101、0110、1000，無關項是 1010～1111，可以把它們填進第 9 課的卡諾圖工具驗證。手算的目的是理解原理；實務上交給合成工具。

Verilog：三段式寫法

最清楚、最不容易出錯的寫法把三個部分分開：狀態暫存器（時序）、下一狀態邏輯（組合）、輸出邏輯（組合）。

🔧 範例：fsm_seq　執行：iverilog -g2012 -o fsm_seq fsm_seq.v tb_fsm_seq.v && vvp fsm_seq

Moore 與 Mealy 兩個版本，餵入同一串 16 個位元。

📄 fsm_seq.v　下載

// fsm_seq.v：偵測輸入序列 1011（允許重疊），Moore 與 Mealy 兩種寫法 module seq1011_moore(input clk, input rst, input x, output y); localparam S0 = 3'd0, S1 = 3'd1, S10 = 3'd2, S101 = 3'd3, S1011 = 3'd4; reg [2:0] state, next; always @(posedge clk) state <= rst ? S0 : next; // 狀態暫存器 always @(*) begin // 下一狀態邏輯 case (state) S0: next = x ? S1 : S0; S1: next = x ? S1 : S10; S10: next = x ? S101 : S0; S101: next = x ? S1011 : S10; S1011: next = x ? S1 : S10; // 重疊：結尾的 1 可以當下一次的開頭 default: next = S0; endcase end assign y = (state == S1011); // 輸出只看狀態 endmodule module seq1011_mealy(input clk, input rst, input x, output y); localparam S0 = 2'd0, S1 = 2'd1, S10 = 2'd2, S101 = 2'd3; reg [1:0] state, next; always @(posedge clk) state <= rst ? S0 : next; always @(*) begin case (state) S0: next = x ? S1 : S0; S1: next = x ? S1 : S10; S10: next = x ? S101 : S0; S101: next = x ? S1 : S10; endcase end assign y = (state == S101) && x; // 輸出看狀態與目前輸入 endmodule

📄 tb_fsm_seq.v　下載

module tb_fsm_seq; reg clk = 0, rst = 1, x = 0; wire ymo, yme; seq1011_moore mo(clk, rst, x, ymo); seq1011_mealy me(clk, rst, x, yme); always #5 clk = ~clk; reg [15:0] bits = 16'b0101_1011_0110_1100; integer i; initial begin @(posedge clk); #1 rst = 0; $display("input bits: %b", bits); $display(" n x | Mealy y | Moore y (one cycle later)"); for (i = 15; i >= 0; i = i - 1) begin x = bits[i]; #1 $write("%2d %b | %b |", 15 - i, x, yme); @(posedge clk); #1 $display(" %b", ymo); end $finish; end endmodule

▶ 模擬結果（實際執行的輸出）

input bits: 0101101101101100 n x | Mealy y | Moore y (one cycle later) 0 0 | 0 | 0 1 1 | 0 | 0 2 0 | 0 | 0 3 1 | 0 | 0 4 1 | 1 | 1 5 0 | 0 | 0 6 1 | 0 | 0 7 1 | 1 | 1 8 0 | 0 | 0 9 1 | 0 | 0 10 1 | 1 | 1 11 0 | 0 | 0 12 1 | 0 | 0 13 1 | 1 | 1 14 0 | 0 | 0 15 0 | 0 | 0

兩者都在第 4、7、10、13 個位元偵測到 1011（允許重疊）。表中的 Moore 欄已經是下一個時脈之後才讀取的值（測試平台在時脈邊緣後才印出），而 Mealy 欄在同一拍、輸入剛給定時就讀到——這就是「Mealy 快一拍」。

注意 localparam 給狀態取名字、case 加 default；合成工具辨識出這是 FSM 後，可以自動重新編碼（例如改成 one-hot）。

🧭 這一課的重點

FSM 設計六步驟：理解規格、畫狀態圖、狀態化簡、狀態編碼、推導邏輯、實作驗證。編碼可選二進位（最少正反器）、格雷碼（少切換）或 one-hot（邏輯簡單快速，FPGA 常用）。以狀態表與卡諾圖可手算下一狀態式，未使用的編碼是無關項。Verilog 三段式寫法分開狀態暫存器、下一狀態與輸出邏輯；模擬驗證 Moore 與 Mealy 都偵測到 1011，Mealy 早一拍。

🔌 本課程的 Verilog 範例都用 Icarus Verilog 12 實際編譯、模擬過，頁面上的「模擬結果」就是當時的輸出；所有範例可以整包下載。時間單位與延遲數字是教學用的假設值，真實晶片的閘延遲在皮秒等級。
