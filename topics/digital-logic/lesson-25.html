移位器與桶式移位器

這一課的目標

  • 區分邏輯、算術移位與旋轉
  • 用 log₂N 層多工器實作桶式移位器
  • 了解移位器在 CPU 中的用途

移位看起來只是重新接線：左移一位就是把每一條線往上接一格。固定的移位確實不需要任何閘；問題是移位量由資料決定（例如 sll x5, x6, x7），要在一個週期內移 0～31 位中的任意位數。

運算空出的位補用途
邏輯左移 SLL0乘以 2ᵏ、組合欄位
邏輯右移 SRL0無號除以 2ᵏ、取欄位
算術右移 SRA符號位有號除以 2ᵏ（向 −∞ 取整）
旋轉 ROL/ROR移出的位密碼學、雜湊（RISC-V 的 Zbb 擴充）

桶式移位器

把移位量寫成二進位 \(sh = \sum sh_i 2^i\)：移 \(sh\) 位等於依序「若 \(sh_i = 1\) 則移 \(2^i\) 位」。每一層是 \(N\) 個 2 選 1 多工器：

// barrel.v 的概念：32 位元桶式左移器，用 5 層 2 選 1 多工器組成 module barrel_sll(input [31:0] a, input [4:0] sh, output [31:0] y); wire [31:0] s0 = sh[0] ? {a[30:0], 1'b0} : a; // 移 1 wire [31:0] s1 = sh[1] ? {s0[29:0], 2'b0} : s0; // 移 2 wire [31:0] s2 = sh[2] ? {s1[27:0], 4'b0} : s1; // 移 4 wire [31:0] s3 = sh[3] ? {s2[23:0], 8'b0} : s2; // 移 8 assign y = sh[4] ? {s3[15:0], 16'b0} : s3; // 移 16 endmodule

第 23 課的測試平台用 10000 筆亂數比對它和 Verilog 內建的 <<，全部一致。面積 \(N\log_2 N\) 個多工器，延遲 \(\log_2 N\) 級。另一種「交叉開關」結構只有一級但需要 \(N^2\) 個開關，適合小寬度。

同一個移位器做左右移

右移可以用「先把資料位元反轉、左移、再反轉」實作，所以一個左移器加兩組反轉多工器就能同時支援 SLL、SRL；算術右移則在補位時填入符號位而不是 0。

用途

  • 移位指令本身；位址計算中的比例因子（ARM 的 ldr r0, [r1, r2, lsl #2]）。
  • 浮點加法中對齊指數、正規化（配合前導零計數，第 19 課）。
  • RISC-V 的 lui 載入高 20 位，概念上就是左移 12 位（第 52 課）。

🧭 這一課的重點

固定移位只是接線，資料決定的移位量需要移位器。邏輯移位補 0，算術右移補符號位，旋轉補移出的位。桶式移位器把移位量拆成二進位，log₂N 層 2 選 1 多工器各移 2ⁱ 位，面積 N log₂N、延遲 log₂N，以亂數比對驗證。右移可透過位元反轉共用左移器。

🔌 本課程的 Verilog 範例都用 Icarus Verilog 12 實際編譯、模擬過，頁面上的「模擬結果」就是當時的輸出；所有範例可以整包下載。時間單位與延遲數字是教學用的假設值，真實晶片的閘延遲在皮秒等級。
