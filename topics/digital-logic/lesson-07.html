笛摩根定律與推泡泡

這一課的目標

  • 證明並使用笛摩根定律
  • 用「推泡泡」把 AND-OR 電路轉成全 NAND
  • 求一個函數的補函數

\[ (AB)' = A' + B', \qquad (A + B)' = A'B' \]

推廣到 \(n\) 個變數也成立。證明只要檢查真值表四列。直觀說法：「不是兩者都成立」等於「至少一個不成立」。

兩種畫法，同一個閘

笛摩根定律告訴我們：NAND 閘也可以畫成「輸入端帶反相圈的 OR 閘」，NOR 也可以畫成「輸入端帶反相圈的 AND 閘」。在電路圖上，反相圈（bubble）可以沿著導線推過閘：推過時 AND ↔ OR 互換，而且泡泡要出現在閘的另一側所有接腳。

把兩級 AND-OR 換成全 NAND

任何積之和 \(F = AB + CD\) 都可以直接換成兩級 NAND：

\[ F = AB + CD = ((AB)'(CD)')' \]

做法是在 AND 的輸出和 OR 的輸入各加一個泡泡（兩個泡泡互相抵消），再把「輸入帶泡泡的 OR」認成 NAND。同理，積之和 → 兩級 NAND，和之積 → 兩級 NOR。由於第 4 課說的 CMOS 特性，這種轉換能讓電路更快、更小。

補函數

求 \(F'\)：對 \(F\) 取對偶，再把每個變數取反。例如

\[ F = AB' + C \;\Rightarrow\; F' = (A' + B)C' \]

檢查：\(F = 1\) 當 \(C = 1\) 或 \((A, B) = (1, 0)\)；\(F' = 1\) 需要 \(C = 0\) 而且 \((A, B) \ne (1, 0)\)，與 \((A' + B)C'\) 一致。

XOR 的性質

  • \(A \oplus B = AB' + A'B\)，\(A \oplus 0 = A\)，\(A \oplus 1 = A'\)，\(A \oplus A = 0\)。
  • 可交換、可結合：多輸入 XOR 就是「1 的個數是否為奇數」，也就是同位元（第 3 課）。
  • \((A \oplus B)' = A \oplus B' = A' \oplus B\)：XOR 的反相可以移到任一輸入。

🧭 這一課的重點

笛摩根定律：(AB)′ = A′ + B′，(A + B)′ = A′B′。NAND 等於輸入反相的 OR，反相圈可以沿導線推過閘（AND↔OR 互換）；因此積之和可直接改成兩級 NAND，和之積改成兩級 NOR。求補函數：取對偶再把變數取反。多輸入 XOR 是奇同位檢查。

🔌 本課程的 Verilog 範例都用 Icarus Verilog 12 實際編譯、模擬過，頁面上的「模擬結果」就是當時的輸出；所有範例可以整包下載。時間單位與延遲數字是教學用的假設值，真實晶片的閘延遲在皮秒等級。

檢查你的理解

  1. 把 F = AB + C′D 改寫成只用 NAND 的兩級電路。
  2. 求 F = (A + B′)C 的補函數。
  3. 三輸入 XOR 在什麼條件下輸出 1？
