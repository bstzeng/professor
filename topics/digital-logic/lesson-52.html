控制訊號與立即值解碼

這一課的目標

  • 寫出主控制單元的真值表
  • 推導各格式立即值的拼接與符號延伸
  • 理解分支條件與下一個 PC 的選擇

主控制表

控制單元的輸入是 opcode（7 位元），輸出是每個控制訊號。rv_single.v 中直接用一組 is_r、is_lw…的比較，再組合成控制訊號：

ALU 控制分兩層：主控制先決定「這是位址計算（加）、比較（減）、還是看 funct」；R 型與 I 型再由 funct3（和 R 型的 funct7 第 5 位區分 add／sub）決定實際運算。兩層解碼讓主控制表保持很小。

// ALU 控制：把 funct3/funct7 翻譯成 ALU 運算碼（與 alu.v 相同的編碼） reg [3:0] alu_op; always @(*) begin if (is_lw | is_sw | is_jalr) alu_op = 4'd0; // 位址計算用加法 else if (is_b) alu_op = 4'd1; // 比較用減法 else case (f3) 3'b000: alu_op = (is_r && f7[5]) ? 4'd1 : 4'd0; // add / sub 3'b001: alu_op = 4'd7; // sll 3'b010: alu_op = 4'd5; // slt 3'b100: alu_op = 4'd4; // xor 3'b101: alu_op = 4'd8; // srl 3'b110: alu_op = 4'd3; // or default: alu_op = 4'd2; // and endcase end

立即值產生器

每種格式把立即值的位元放在不同的地方，產生器的工作是把它們拼回來並符號延伸（第 2 課）：

// 立即值產生器：依指令格式把散落各處的位元拼回來，並做符號延伸 wire [31:0] imm_i = {{20{instr[31]}}, instr[31:20]}; wire [31:0] imm_s = {{20{instr[31]}}, instr[31:25], instr[11:7]}; wire [31:0] imm_b = {{19{instr[31]}}, instr[31], instr[7], instr[30:25], instr[11:8], 1'b0}; wire [31:0] imm_j = {{11{instr[31]}}, instr[31], instr[19:12], instr[20], instr[30:21], 1'b0}; wire [31:0] imm_u = {instr[31:12], 12'b0};
  • {20{instr[31]}} 把符號位複製 20 次。所有格式的符號位都是 instr[31]，這是 RISC-V 刻意的設計。
  • B 與 J 格式的最低位固定是 0（指令至少 2 位元組對齊），所以不存，讓範圍加倍：分支 ±4 KB、jal ±1 MB。
  • U 格式把 20 位放在高位、低 12 位補 0。lui 加上 addi 就能組出任何 32 位元常數。

分支與下一個 PC

wire lt = $signed(rd1) < $signed(rd2); wire take = is_b & ((f3 == 3'b000 & zero) | (f3 == 3'b001 & ~zero) | (f3 == 3'b100 & lt) | (f3 == 3'b101 & ~lt)); wire [31:0] pc_next = is_jal ? pc + imm_j : is_jalr ? (alu_y & ~32'd1) : take ? pc + imm_b : pc4;

beq／bne 用 ALU 減法的 zero 旗標；blt／bge 用有號比較。pc_next 是一個四選一：jal 目標、jalr 目標（最低位清 0）、分支目標、或 PC + 4。jalr 搭配 ra 就是函式返回（ret = jalr zero, 0(ra)）。

這些控制訊號都是組合邏輯，大多數只是幾個閘。在真實的處理器中，指令解碼比這複雜得多（x86 的變長指令尤其困難），但原理相同。

🧭 這一課的重點

主控制單元依 opcode 產生 reg_write、alu_src、mem_write、寫回來源與 PC 選擇；ALU 控制分兩層，先分位址／比較／看 funct，再由 funct3 與 funct7[5] 決定運算。立即值產生器依格式拼接位元並以 instr[31] 做符號延伸，B、J 格式省略恆為 0 的最低位以加倍範圍，lui + addi 可組出任意常數。下一個 PC 在 jal、jalr、分支目標與 PC + 4 之間選擇。

🔌 本課程的 Verilog 範例都用 Icarus Verilog 12 實際編譯、模擬過，頁面上的「模擬結果」就是當時的輸出；所有範例可以整包下載。時間單位與延遲數字是教學用的假設值，真實晶片的閘延遲在皮秒等級。
