JK、T 正反器與重置、致能

這一課的目標

  • 寫出 JK 與 T 正反器的特性方程式
  • 比較同步與非同步重置
  • 用多工器加入致能

JK 與 T 正反器

類型特性方程式說明
D\(Q^+ = D\)現代設計幾乎只用它
JK\(Q^+ = JQ' + K'Q\)像 SR，但 J = K = 1 時翻轉（沒有禁止組合）
T\(Q^+ = T \oplus Q\)T = 1 時翻轉；計數器的基本單元

JK 與 T 在離散 IC 的年代很流行，因為它們讓計數器等電路的激勵式比較簡單。今天，任何 JK 或 T 都可以用 D 正反器加一點邏輯實作（\(D = T \oplus Q\)），合成工具與 FPGA 也只提供 D 型，所以它們主要出現在教科書中。理解它們的價值在於：任何循序電路都是「D 正反器 + 下一狀態邏輯」。

重置

電源打開時，正反器的值是隨機的。系統需要重置把狀態設到已知值。

同步重置非同步重置
寫法always @(posedge clk) if (rst) q <= 0;always @(posedge clk or posedge rst) if (rst) q <= 0;
何時生效下一個時脈邊緣立即，不需要時脈
實作D 輸入前加一個 AND（或多工器）正反器內部的設定／重置電晶體
優點純同步，時序分析簡單；不怕毛刺時脈還沒穩定也能重置；不占資料路徑
風險重置期間時脈必須在跑重置放開時若接近時脈邊緣，會發生亞穩態

業界常見的折衷：非同步觸發、同步放開——重置訊號可以隨時進來，但放開前先經過一個兩級同步器（第 42 課），確保所有正反器在同一個時脈邊緣離開重置。latches.v 最後的 dff 模組就是非同步重置的寫法。

致能

有致能的暫存器只在 en = 1 時更新：\(D = en\cdot d + en'\cdot Q\)，也就是 D 前面加一個 2 選 1 多工器，選「新值」或「自己」。Verilog：

always @(posedge clk) if (en) q <= d; // en = 0 時 q 保持（合成成多工器或時脈閘控）

絕對不要用 AND 閘把 en 和 clk 直接接在一起來做致能：en 的毛刺或在 clk = 1 時改變都會在時脈上產生額外的邊緣（第 15 課）。需要省電時使用工具插入的時脈閘控單元（內含閂鎖器，第 29 課）。

🧭 這一課的重點

JK 正反器 Q⁺ = JQ′ + K′Q（J = K = 1 時翻轉），T 正反器 Q⁺ = T ⊕ Q；兩者都可用 D 正反器加邏輯實作，現代設計只用 D。同步重置在時脈邊緣生效、時序簡單；非同步重置立即生效但放開時可能亞穩，常用「非同步觸發、同步放開」。致能以多工器在 D 前選擇新值或保持，絕不可直接用 AND 閘閘控時脈。

🔌 本課程的 Verilog 範例都用 Icarus Verilog 12 實際編譯、模擬過，頁面上的「模擬結果」就是當時的輸出；所有範例可以整包下載。時間單位與延遲數字是教學用的假設值，真實晶片的閘延遲在皮秒等級。
