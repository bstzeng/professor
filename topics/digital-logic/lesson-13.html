模組 C｜閘延遲與時序 · 第 13 課

扇出、FO4 與邏輯努力

這一課的目標

  • 說明扇出對延遲的影響
  • 使用 FO4 作為與製程無關的延遲單位
  • 用邏輯努力估算多級路徑的最佳延遲

一個閘驅動 \(h\) 倍於自己輸入電容的負載時，延遲大致是線性的：

\[ d = g\,h + p \quad (\text{以 } \tau \text{ 為單位}) \]

  • \(h = C_{out}/C_{in}\)：電氣努力（扇出）。
  • \(g\)：邏輯努力，這種閘相較於反相器提供同樣電流需要多大的輸入電容。反相器 \(g = 1\)，NAND2 \(g = 4/3\)，NOR2 \(g = 5/3\)（假設 pMOS 遷移率為 nMOS 的一半）。
  • \(p\)：寄生延遲，閘自己的輸出電容造成。反相器約 1，NAND2 約 2。
  • \(\tau\)：製程的基本時間常數。

反相器驅動四個反相器：\(d = 1\cdot 4 + 1 = 5\tau\)，這就是 FO4 延遲。因為它把製程差異都吸收進 \(\tau\)，設計者常用「這條路徑有幾個 FO4」來比較不同世代的設計：高效能 CPU 的週期約 15～25 FO4。

多級路徑的最佳化

一條 \(N\) 級的路徑，總努力 \(F = G\,H\,B\)（\(G = \prod g_i\)，\(H\) 是整條路徑的扇出，\(B\) 是分支）。邏輯努力理論（Sutherland 等人）證明：每級努力相等時延遲最小，

\[ \hat f = F^{1/N}, \qquad D_{min} = N F^{1/N} + \sum p_i \]

而最佳的級數使每級努力約為 4（這也是 FO4 被當成「合理」負載的原因）。

例子：驅動一個大負載

一個小反相器要驅動 256 倍於自己的負載（例如一條很長的時脈線）。一級直接驅動：\(d = 256 + 1 = 257\)。改用四級逐漸放大的反相器鏈，每級放大 4 倍：\(d = 4\times(4 + 1) = 20\)——快了十幾倍。這就是為什麼高扇出的訊號要經過緩衝器樹（buffer tree），時脈網路更是如此（〈晶片 Layout 設計〉第 26 課）。

做法級數延遲（τ）
直接驅動1257
每級 ×1622×(16 + 1) = 34
每級 ×444×(4 + 1) = 20
每級 ×288×(2 + 1) = 24

注意：這些數字是簡化模型，但趨勢完全正確，邏輯合成與佈局工具內部就用類似的模型決定閘的尺寸與緩衝器插入。

🧭 這一課的重點

閘延遲 d = gh + p：h 是扇出（電氣努力），g 是邏輯努力（反相器 1、NAND2 4/3、NOR2 5/3），p 是寄生延遲。FO4 延遲（5τ）是與製程無關的速度單位，CPU 週期約 15～25 FO4。多級路徑在每級努力相等時最快，最佳每級努力約 4；驅動大負載應使用逐級放大的緩衝器鏈。

🔌 本課程的 Verilog 範例都用 Icarus Verilog 12 實際編譯、模擬過，頁面上的「模擬結果」就是當時的輸出；所有範例可以整包下載。時間單位與延遲數字是教學用的假設值，真實晶片的閘延遲在皮秒等級。
