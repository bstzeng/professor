移位暫存器與 LFSR

這一課的目標

  • 設計序列輸入、並列輸出的移位暫存器
  • 理解 LFSR 的結構與最大週期
  • 知道移位暫存器的應用

把正反器串起來，每一級的 Q 接下一級的 D：每個時脈邊緣，所有位元同時往後移一格。因為所有正反器在同一個邊緣取樣上一刻的值，不會像閂鎖器那樣一次穿過好幾級（但要注意 hold 條件：正反器之間沒有邏輯，\(t_{cd} = 0\)，必須 \(t_{ccq} \ge t_{hold}\)，第 32 課）。

module shift8(input clk, input rst, input din, output reg [7:0] q); always @(posedge clk) if (rst) q <= 8'd0; else q <= {q[6:0], din}; // 往左移，新的位元從右邊進來 endmodule

{q[6:0], din} 是 Verilog 的串接運算子：把低 7 位往左移一格，新的位元接在最右邊。

用途

  • 序列 ↔ 並列：UART、SPI、I²C、USB、PCIe、乙太網路都是序列傳輸，收發兩端都有移位暫存器（高速介面稱為 SerDes）。
  • 延遲線：把訊號延遲 N 個週期，例如對齊管線中的資料。
  • 掃描鏈：測試時把晶片內所有正反器串成一條長長的移位暫存器，從外部把測試向量移進去、把結果移出來（可測試性設計）。

線性回授移位暫存器（LFSR）

把移位暫存器某幾級的 XOR 接回輸入。如果回授位置對應一個 \(n\) 次的本原多項式（在 GF(2) 上），狀態會走過全部 \(2^n - 1\) 個非零值才重複——最大長度序列。4 位元用 \(x^4 + x^3 + 1\)：週期 15。

// 4 位元線性回授移位暫存器：x^4 + x^3 + 1，會走過全部 15 個非零狀態 module lfsr4(input clk, input rst, output reg [3:0] q); always @(posedge clk) if (rst) q <= 4'b0001; else q <= {q[2:0], q[3] ^ q[2]}; endmodule

為什麼是 \(2^n - 1\) 而不是 \(2^n\)？全 0 狀態 XOR 起來還是 0，會永遠卡住，所以 LFSR 一定要從非零值開始（上面的重置值是 0001）。

LFSR 的硬體極少（n 個正反器、一兩個 XOR），卻能產生統計性質不錯的偽亂數，用於內建自我測試的測試向量產生、CRC 校驗、展頻通訊、資料擾碼（避免長串 0 或 1）。它的輸出是線性的，不能用於密碼學。下一課的模擬會顯示它實際走過的 15 個狀態。

🧭 這一課的重點

移位暫存器把正反器串接，每個時脈所有位元同時移一格，用於序列—並列轉換（UART、SPI、SerDes）、延遲線與掃描鏈測試；正反器直接相連時要注意 hold。LFSR 以 XOR 回授，回授對應本原多項式時走過全部 2ⁿ − 1 個非零狀態，用於 BIST、CRC、擾碼，但輸出為線性不可用於密碼學。

🔌 本課程的 Verilog 範例都用 Icarus Verilog 12 實際編譯、模擬過，頁面上的「模擬結果」就是當時的輸出；所有範例可以整包下載。時間單位與延遲數字是教學用的假設值，真實晶片的閘延遲在皮秒等級。
