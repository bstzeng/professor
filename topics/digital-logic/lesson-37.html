計數器

這一課的目標

  • 設計同步二進位計數器
  • 比較同步與漣波（非同步）計數器
  • 認識模 N、上下數、環形與詹森計數器

計數器是「暫存器 + 加 1 電路」的狀態機：\(Q^+ = Q + 1\)。用 T 正反器的觀點：第 \(i\) 位在所有較低位都是 1 時翻轉，

\[ T_i = Q_{i-1} Q_{i-2} \cdots Q_0 \]

這正是漣波進位加法器加 1 的進位鏈。所有位元由同一個時脈驅動，在同一個邊緣一起更新，這是同步計數器。

🔧 範例：counter　執行：iverilog -g2012 -o counter counter.v tb_counter.v && vvp counter

包含帶致能的 4 位元計數器、上一課的移位暫存器與 LFSR。測試平台在第 10、11 個週期把致能關掉。

📄 counter.v　下載

// counter.v：同步計數器、移位暫存器與 LFSR module counter4(input clk, input rst, input en, output reg [3:0] q); always @(posedge clk) if (rst) q <= 4'd0; else if (en) q <= q + 4'd1; // 所有位元在同一個時脈邊緣一起更新 endmodule module shift8(input clk, input rst, input din, output reg [7:0] q); always @(posedge clk) if (rst) q <= 8'd0; else q <= {q[6:0], din}; // 往左移，新的位元從右邊進來 endmodule // 4 位元線性回授移位暫存器：x^4 + x^3 + 1，會走過全部 15 個非零狀態 module lfsr4(input clk, input rst, output reg [3:0] q); always @(posedge clk) if (rst) q <= 4'b0001; else q <= {q[2:0], q[3] ^ q[2]}; endmodule

📄 tb_counter.v　下載

module tb_counter; reg clk = 0, rst = 1, en = 1, din = 0; wire [3:0] q; wire [7:0] sq; wire [3:0] lq; counter4 c(clk, rst, en, q); shift8 s(clk, rst, din, sq); lfsr4 l(clk, rst, lq); always #5 clk = ~clk; reg [7:0] pattern = 8'b1011_0010; integer n; initial begin @(posedge clk); #1 rst = 0; $display("cycle | counter | shift8 (din) | lfsr"); for (n = 1; n <= 18; n = n + 1) begin din = pattern[7 - (n - 1) % 8]; if (n == 10) en = 0; // 第 10 拍暫停計數 if (n == 12) en = 1; @(posedge clk); #1; $display("%5d | %2d | %b (%b) | %b", n, q, sq, din, lq); end $finish; end endmodule

觀察輸出：計數器在 en = 0 的兩個週期停在 9；從 15 回到 0（模 16 自然繞回）。LFSR 欄從 0001 開始走過 15 個不同的非零值後，第 15 拍回到 0001。

漣波計數器

把每個 T 正反器（T = 1）的輸出接到下一級的時脈：第 0 位每個時脈翻轉一次，它的下降邊緣讓第 1 位翻轉……結構極簡單，但每一位的變化都比前一位晚一個 \(t_{cq}\)，N 位元時輸出要 \(N t_{cq}\) 才穩定，中間會出現錯誤的過渡值（例如 0111 → 0110 → 0100 → 0000 → 1000）。而且它違反了「所有正反器同一個時脈」的同步規則，不應用在同步設計中；它的合理用途是低功耗的時脈分頻。

變形

類型做法用途
模 N到 N − 1 時同步清為 0BCD 計數（模 10）、計時器、鮑率產生
上下數多工器選 +1 或 −1位置編碼器、FIFO 計數
環形計數器one-hot 的 1 在移位暫存器裡繞圈N 個正反器 N 個狀態，解碼免邏輯
詹森計數器反相後回授的移位暫存器N 個正反器 2N 個狀態，相鄰只差一位
格雷碼計數器二進位計數再轉格雷碼跨時脈域（第 42 課）

模 N 計數器搭配比較器就是計時器：每 N 個週期產生一個脈衝。微控制器的 PWM、看門狗計時器、UART 的鮑率產生器都是這樣做的。下一課開始，我們把計數器推廣成任意的狀態機。

🧭 這一課的重點

同步計數器 Q⁺ = Q + 1，第 i 位在所有低位為 1 時翻轉，全部位元同一時脈更新；Verilog 模擬驗證了致能、繞回與 LFSR 的 15 個狀態。漣波計數器以前一級輸出當時脈，延遲累積且出現錯誤過渡值，只適合時脈分頻。變形包括模 N、上下數、環形（N 狀態）、詹森（2N 狀態）與格雷碼計數器；計數器加比較器即計時器。

🔌 本課程的 Verilog 範例都用 Icarus Verilog 12 實際編譯、模擬過，頁面上的「模擬結果」就是當時的輸出；所有範例可以整包下載。時間單位與延遲數字是教學用的假設值，真實晶片的閘延遲在皮秒等級。
