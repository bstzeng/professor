動差生成函數

這一課的目標

  • 理解動差生成函數的定義
  • 理解它如何產生動差
  • 理解它在證明極限定理中的角色

動差

E[X] 是一階動差、E[X²] 是二階動差……一般的 E[Xⁿ] 叫做 n 階動差。平均數、變異數、偏態（不對稱的程度）、峰度（尾巴的厚度）都可以從動差算出來。

動差生成函數

\[M_X(t) = E\left[e^{tX}\right]\]

把 etX 展開成泰勒級數：1 + tX + t²X²/2! + …，取期望值之後，每一項的係數就包含了各階的動差。對 t 微分 n 次再令 t = 0，就得到 n 階動差——這個函數「生成」了所有的動差，因而得名。

兩個關鍵的性質

  1. 唯一性：如果兩個隨機變數的動差生成函數（在 0 附近）相同，它們的分布就相同。動差生成函數就像分布的「身分證」。
  2. 獨立和變成乘積：如果 X 與 Y 獨立，MX+Y(t) = MX(t) MY(t)。原本困難的「求和的分布」（需要做卷積），變成簡單的乘法。

應用

  • 證明分布的性質：兩個獨立的卜瓦松變數相加，仍然是卜瓦松分布，λ 相加；兩個獨立的常態變數相加，仍然是常態分布。用動差生成函數相乘，一行就證明了。
  • 證明中央極限定理（第 24 課）：計算標準化平均數的動差生成函數，證明它在 n → ∞ 時趨近 et²/2——正好是標準常態分布的動差生成函數。
  • 機率的上界：結合馬可夫不等式（第 22 課），可以得到比柴比雪夫強得多的「指數型」上界（切爾諾夫界），廣泛用於電腦科學與資訊理論。

特徵函數

有些分布（例如厚尾的柯西分布）的動差生成函數不存在。數學家改用特徵函數 E[eitX]，它對所有的分布都存在——其實就是機率分布的傅立葉轉換（見〈傅立葉分析與訊號處理〉）。

🧭 這一課的重點

E[Xⁿ] 為 n 階動差，可算出平均、變異數、偏態、峰度；動差生成函數 M(t) = E[eᵗˣ] 展開後對 t 微分 n 次令 t = 0 得 n 階動差；唯一性使其如分布身分證，獨立和的動差生成函數為乘積把卷積變乘法；應用有證明卜瓦松與常態相加仍同分布、證明中央極限定理趨近 e^(t²/2)、結合馬可夫不等式得切爾諾夫界；動差生成函數不存在時用特徵函數 E[e^(itX)]，即分布的傅立葉轉換。
