2. 完整數字範例

電源 V=10∠0°V，角頻率ω=1000 rad/s，R=3Ω、L=4mH、 C=100μF，串聯成一個迴路，求電流。

先分別算出感抗、容抗：
Z_L = jωL = j(1000)(0.004) = j4Ω
Z_C = 1/(jωC) = 1/(j(1000)(0.0001)) = −j10Ω

總阻抗：
Z總 = R + Z_L + Z_C = 3 + j4 − j10 = 3 − j6Ω
換成極座標：|Z總| = √(3²+6²) ≈ 6.71Ω，角度 = arctan(−6/3) ≈ −63.4°
Z總 ≈ 6.71∠−63.4° Ω

電流（歐姆定律的相量版）：
I = V / Z總 = 10∠0° / 6.71∠−63.4° ≈ 1.49∠63.4° A

3. 解讀結果：電流領先電壓63.4°

這個結果代表：電流的振幅是1.49A，相位比電壓超前 63.4°——因為容抗（10Ω）比感抗（4Ω）大，整個電路 表現得比較像電容（電流領先電壓），這種情況稱為 電容性電路。換算回時域，電流的實際波形是：
